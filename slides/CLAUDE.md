MER-DA の結果を説明する資料を作る場所（2026-10-27 研究者の決定：「置き場所は MER-DA に slides を作ってそこでやってほしい」）．
資料は 1 つにつき 1 フォルダ（`<日付>-<用途>/`）で，中に `main.tex`・`parts/`・`figures/`・`scripts/`・`.latexmkrc` を置く．

## 自己完結

- 見た目の設定（`common/preamble.tex`・`theme.tex`・`macros.tex`）は 2026-10-27 に `~/slides/common/` から 1 回だけ写した．
  MER-DA の資料に共通の部品（上端の帯，補足のページを指す `\hosoku`，色，図の部品）は `common/merda.tex`（`~/slides/decks/MER-DA/2026-10-22-6つの問いの整理` の前置きから写した）．
  **以後は `~/slides` を読まない．同期もしない．**直すときはこのフォルダのファイルを直す
- 組むのは MER-DA の中だけで済む（`.latexmkrc` が `common/` を TEXINPUTS に通す）

## 組み方

```bash
cd slides
make DECK=2026-10-27-TAC論文        # PDF（<資料>/<資料>.pdf）．エラー・未定義・Overfull の数を出す
make DECK=2026-10-27-TAC論文 data   # scripts/export_*.py を名前順に流して作図用の CSV を書き出し（数秒．どれも台帳と照合する），付録の出所の表を作る
bash 2026-10-27-TAC論文/tools/buildpart.sh supp_part1 <PNG の場所>   # 1 つの part だけを補足の体裁で試し組みする
make DECK=2026-10-27-TAC論文 png    # 全ページの PNG（目視用）
```

**組んだら全ページを画像にして目視する．**重なりとはみ出しはログに出ない．

## 数値と図の決まり

1. **本文の数値は論文の台帳から `\NUM{key}` で書く．**`main.tex` が `../../paper/numbers.tex` を読み込む．台帳に無い key は組むときに止まる．
   台帳を作り直したら，先に `paper/` で `make numbers` を流す
2. **図の値は `scripts/export_*.py` が作る `figures/*.csv` から読む．**台本は論文の図の台本（`paper/scripts/figures/fig_*.py`）の関数と同じ集計で値を作り，
   台帳に同じ量の key があれば照合して，食い違えば止まる（2026-10-27 の時点で 278 個を照合）．CSV の先頭の `#` 行に出所を書く
3. 論文の図（PNG・PDF）は貼らない．CSV から pgfplots・TikZ で日本語の図に描き直す
4. 模式図と式の値（2 つの山，正解率の式，ソースの価値の曲線，命題の図，弱いラベルの数値例）は，図の下に「実験の値ではない」と書く
5. オラクルの値は手法の性能として出さない（選び方の損を測るときだけ）

## 語

- 語は 10-22 の資料（`~/slides/decks/MER-DA/2026-10-22-6つの問いの整理`．写した時点の語）と `docs/results.md` 3.6 節末の対応表に合わせる：
  利得の総当たり実験（「地図」と書かない），合併・ソースのみ・ターゲットのみ，識別力 $d$，判断基準のずれ $o$，中心化，出発点，5 つの値を選んだ出発点，仮のターゲット，比重（「重み」は分類器の $w_k$ と罰則の重みだけ），ポイント
- 論文で新しく出た語は日本語版の論文（`paper/ja/`）の語：判断基準による損失・向きによる損失，生徒・先生・弱いラベル，調整版・固定版，一般化蒸留，温度つきの蒸留，共訓練，共正則化
- **「段」という語を使わない**（研究者の指摘．10-22 の資料の決まり）．論文の「two-stage reference」は「融合の出発点が教えた単独の生徒の予測の積」と書く
- 基本版と拡張版の先生は台本どおりに書く（2026-10-27 に台本で確かめた．`paper/CLAIM.md` 第 5 版と論文 5・6 節の書き方は台本と違い，直すかは研究者が決める）
  - 基本版（`exp/multimodal_distill.py` の `choose`）：単独の生徒の先生の候補は融合の出発点 pF，単独の出発点の予測の積 poe，2 つの一致で重みづけた pF（agree）．融合の生徒の候補は poe0，pF が教えた単独の生徒の予測の積（ref．弱いラベルにするか，そのまま予測に使う refdirect）
  - 拡張版（`exp/baselines_distill.py` の oursx）：K 本で学び直した融合の生徒 pFK（K=0 では pF）と，pFK が教えた単独の生徒の予測の積だけ．基本版の候補は含まないので「基本版に足す」と書かない
  - 教える側の単独の生徒は，K≥1 では K 本でも学ぶ．「基本版の先生はターゲットのデータを見ない」とは書かない

## pgfplots・TikZ の落とし穴（この資料で踏んだもの）

| 症状 | 原因と対処 |
|---|---|
| `TeX capacity exceeded [input stack size]` | 線の型の名前を色の名前と同じにした（`kA/.style={kA,…}` が自分を呼ぶ）．色は `k<種類>`，型は `s<種類>` |
| 軸の座標で `\NUM` が `Illegal unit` | `\NUM` は数として展開されない．軸の中の値は CSV から `\pgfplotstablegetelem` で読む |
| 軸の中の `\foreach` で `Illegal unit` | pgfplots は軸の中の描画を後回しにするので，ループの変数が消える．線を明示的に書く |
| groupplot の共通の設定で `bar width` や `error bars/.cd` が読めない | `bar width` は `/pgf/bar width=…` と書く．誤差棒の指定は各 `\addplot` に書く |
