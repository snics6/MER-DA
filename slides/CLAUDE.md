## 数値と図の決まり

1. **本文の数値は論文の台帳から `\NUM{key}` で書く．**`main.tex` が `../../paper/numbers.tex` を読み込む．台帳に無い key は組むときに止まる．
   台帳を作り直したら，先に `paper/` で `make numbers` を流す
2. **図の値は `scripts/export_figdata.py` が作る `figures/*.csv` から読む．**台本は論文の図の台本（`paper/scripts/figures/fig_*.py`）の関数と同じ集計で値を作り，
   台帳に同じ量の key があれば照合して，食い違えば止まる（2026-10-27 の時点で 278 個を照合）．CSV の先頭の `#` 行に出所を書く
3. 論文の図（PNG・PDF）は貼らない．CSV から pgfplots・TikZ で日本語の図に描き直す
4. 模式図と式の値（2 つの山，正解率の式，ソースの価値の曲線，命題の図，弱いラベルの数値例）は，図の下に「実験の値ではない」と書く
5. オラクルの値は手法の性能として出さない（選び方の損を測るときだけ）

## pgfplots・TikZ の落とし穴（この資料で踏んだもの）

| 症状 | 原因と対処 |
|---|---|
| `TeX capacity exceeded [input stack size]` | 線の型の名前を色の名前と同じにした（`kA/.style={kA,…}` が自分を呼ぶ）．色は `k<種類>`，型は `s<種類>` |
| 軸の座標で `\NUM` が `Illegal unit` | `\NUM` は数として展開されない．軸の中の値は CSV から `\pgfplotstablegetelem` で読む |
| 軸の中の `\foreach` で `Illegal unit` | pgfplots は軸の中の描画を後回しにするので，ループの変数が消える．線を明示的に書く |
| groupplot の共通の設定で `bar width` や `error bars/.cd` が読めない | `bar width` は `/pgf/bar width=…` と書く．誤差棒の指定は各 `\addplot` に書く |
