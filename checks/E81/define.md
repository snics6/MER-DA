# 関門 1：定義（E81，2026-11-02）

## 判定
直してから通す．論文の書き方を決める「文の鍵」を，台本は IEMOCAP と MELD の 2 コーパスだけで作るが，論文の筋 5 の文は世界の全コーパス（AVT は 3，AV は 5）の過半で決まるので，E81 の「同じ／変わった」は論文の文が変わるかを測っておらず，読み手の規則を評価の値を見る前に直す必要がある（GPU の計算 `exp/g3_split.py` はこの指摘では止めない）．

## 指摘

### [D1] 「結論が同じか」を決める文の鍵が，論文の文と違う単位の集合で作られている
- 重さ：直してから進む
- 該当箇所：`docs/exploratory-analyses.md:9562-9563`，`exp/analyze_e81.py:519-551`（`majority(n_tot)` は 525 行，`statement` は 353 行），`exp/analyze_e79.py:2374-2380`（E79 の過半の母数）
- 問題：設計は「E81 の分割での P5-1〜P5-3 の結論（E79 の過半の規則を 3 つのターゲットの単位に当てたもの）が，今の分割の同じ単位での結論と同じなら，筋 5 の主張に（中略）限定を付けず」と書く．台本は IEMOCAP の 2 群を 1 つのコーパスにまとめるので，単位は IEMOCAP と MELD の 2 つになり，`majority(2) = 2` で文の鍵を決める（`analyze_e81.py:525`）．設計の「3 つのターゲットの単位」と台本の「2 つのコーパス」がまず食い違う．
  さらに，論文の筋 5 の文を決める E79 の `statements_p5` は，過半の母数を世界の全コーパス `cps = {corp(t) for t in groups_for(run)}`（`analyze_e79.py:2375`）で取る．AVT は IEMOCAP・MOSEI・MELD の 3，AV は IEMOCAP・MOSEI・MELD・AFEW・CREMA-D の 5 である．E81 の 2 コーパスの文の鍵は，論文の文とは別の量である．
  2 つの量は食い違いうる．例（AVT，P5-1）：今の分割で IEMOCAP が「上回った」，MELD が「判定できない」，MOSEI が「上回った」なら，論文の文（3 のうち 2 で上回った）は「oursx が相手を上回った」である．G3 で IEMOCAP が「同じ水準」に変わると，論文の文は「判定できない」に変わる．一方，E81 の 2 コーパスの文の鍵は，今の分割でも G3 でも「判定できない」（上回った 1，同じ水準と下回った 0 か 1 で，どちらも 2 に届かない）なので，台本は「同じ」と判定し，筋 5 の主張に限定を付けない．逆向きに，論文の文が変わらないのに 2 コーパスの鍵だけが変わる場合もある．
- 計算の後で直せるか：直せる（読み手 `analyze_e81.py` は CPU で，保存した出力から作り直せる）．ただし規則は評価の値を見る前に決める必要がある．
- 求める対応：設計の 4 節の書き方の規則を次の形に直し，台本をそれに合わせる．
  1. G3 の文の鍵は，E79 の `units.csv` の P5-1〜P5-3 の単位のうち IEMOCAP と MELD の単位だけを E81 の G3 の判定に置き換え，MOSEI・AFEW・CREMA-D の単位は E79 の判定のまま残して，E79 の `statements_p5` と同じ母数（世界の全コーパス）で作る．今の分割の文の鍵は E79 の `statements.csv` の値をそのまま使う
  2. 「同じ／変わった」はこの 2 つの文の鍵で決める．2 コーパスだけの文の鍵は記述として残してよい
  3. 設計の「3 つのターゲットの単位」を「IEMOCAP（2 群をまとめた 1 単位）と MELD の 2 単位．ほかのコーパスは今の判定のまま」に書き直す

### [D1] 書き方の規則が，E81 で測っていない部分の主張まで限定なしにする
- 重さ：記録する
- 該当箇所：`docs/exploratory-analyses.md:9552`（K ∈ {0, 5}），`docs/exploratory-analyses.md:9563`，`exp/analyze_e81.py:64-69`（族は P5-1・P5-2・P5-3・P5-3u だけ）
- 問題：書き方の規則は「同じなら，筋 5 の主張に『候補がテストと同じ対話を含む』の限定を付けず」と書く．筋 5 の判定は E79 で K ∈ {0, 5, 25}，族は P5-1〜P5-4 と配備できる参照（`P5_refs`．融合の生徒の「oursx − 教師 ref」で蒸留の得を主張するかを決める）を含む．E81 は K = 25，P5-4（Co-teaching），P5_refs，ours を回さない．模擬査読の [G3] は ours も求めている．規則のままでは，測っていない K = 25 と P5-4・P5_refs の文からも限定が外れる．
- 計算の後で直せるか：直せる（記述の範囲の問題）．
- 求める対応：書き方の規則に「限定を外すのは P5-1〜P5-3 の K = 0・5 の文だけ．K = 25 と P5-4・P5_refs の文は『候補がテストと同じ対話を含む設定で』の限定を残す（または E81 の範囲の外と書く）」を足す．ours を回さない理由を 5 節に書く．

### [D1・D10] ΔΔ には，同じ対話を除いた効果のほかに 3 つの変化が混ざり，書き方の規則はそれを対話の効果として書く
- 重さ：記録する
- 該当箇所：`docs/exploratory-analyses.md:9548`（K 本の入れ替え），`:9553`（m_eff = n を新しい n で解く），`:9563`，`:9569`，`exp/g3_split.py:143-157`
- 問題：G3 の分割では，(a) テストと同じセッション・対話の発話が候補から消える，(b) 候補の本数が IEMOCAP で 21〜28%，MELD で 35〜42% 減る，(c) K = 5 では今の K 本の 20 本のうち最大 13 本が入れ替わる（`checks/E81/step7_facts.md` 2.3 節），(d) m_eff = n の設定では弱いラベルの総重みが候補の本数に比例して減り，K 本と罰則に対する比が変わる．生徒の中心・尺度・白色化も新しい候補で作り直す（`g3_split.py:157`）．Δ_G3 と ΔΔ はこの 4 つの和であり，設計 5 節は (a) と (b) の混ざりだけを限界に書く．書き方の規則は「違えば（中略）筋 5 の主張を『候補がテストと同じ対話を含む設定で』と限る」で，変化の原因を (a) と書くことになる．
  主張の向きの面では，限定を付ける側に働くので筋 5 の主張を過大にはしない．問題は論文の文が「得の一部は同じ対話から来る」と読める点である．(b)・(d) でも候補を使う手法の得は減りうるので，この読みは E81 からは出せない．
- 計算の後で直せるか：記述は直せる．(a) と (b) を分けるには，同じ本数をでたらめに除いた対照の計算が後から要る（別の GPU の計算として足せる）．
- 求める対応：書き方の規則の限定の文を「テストと同じセッション・対話の発話を候補から除き，候補が 21〜42% 減った分割では」と，分割で起きたことをそのまま書く形にする．K 本の入れ替え (c) が無い K = 0 の ΔΔ を K = 5 と分けて表に出し，K = 0 の方が (a)(b)(d) だけの変化であることを表の注に書く．m_eff = n で選ばれた単位の数を表に添える（(d) の影響を受ける単位を読み手が見分けられるようにする）．

### [D6] 「1 つでも違えば変わった」の規則に，雑音だけで変わる見込みが添えられていない
- 重さ：記録する
- 該当箇所：`docs/exploratory-analyses.md:9563`，`exp/analyze_e81.py:14`，`:546-551`
- 問題：文の鍵は族 3 × 7 生徒 × K 2 の 42 個あり，1 つでも違えば「changed」になる．G3 では K 本・教師・生徒の座標を作り直すので，真の差が変わらなくても，区間の端や δ の近くにある単位の判定は入れ替わる．42 個のどれも変わらない見込みは小さく，この規則は「changed」をほぼ確実に出す．どの文の変化が偶然の入れ替わりで説明できるかを示す量が出力に無い．
- 計算の後で直せるか：直せる（`units.csv` に `dd_point`・`dd_lo`・`dd_hi` がある）．
- 求める対応：`statements.csv` の変わった文ごとに，判定の変わった単位の ΔΔ の区間が 0 を含むかを列にする．本文には「文の鍵が変わった n 個のうち，判定の変わった単位の ΔΔ の区間が 0 を外れたのは m 個」と書く．規則そのもの（限定を付ける側）は変えなくてよいが，この数を限定の文に添える．

### [D8・D3] 模型の仮定の確かめが G3 の行で作り直されず，模型で測った位置の損が注なしで表に出る
- 重さ：記録する
- 該当箇所：`exp/analyze_e81.py:204-218`（`dirloss`・`posloss` の計算），`:483`（Δ の表に `posloss` を出す），`docs/exploratory-analyses.md` の E79 3 節の表の 1〜3 行目（模型に依る単位の印，模型の誤差の基準）
- 問題：P5-3 は向きの損（2 つの山の等分散の正規の模型の量 A(D, 0) − A(d, 0)）で判定する．E79 は，模型に依る単位の印（`a_auc` との差 g，`e_model` の差），模型の誤差が向きの損の 1/3 以上の種類への注を P5-3 の文に付けると決めた．E81 の台本はこの 3 つを G3 の行で計算しない．G3 では none も手法も解き直すので，E79 の印をそのまま流用できない．また Δ の表は位置の損の差（`posloss`）を出すが，E75 の決まり（模型で測った位置の損は模型の誤差と同じ大きさ）の注が無い．D の作り方（G3 の候補のラベルで学んだ LDA．`analyze_e81.py:211`）は今の分割の D と違うが，前向きの順序の「none − 手法」では打ち消し合うので判定には影響しない．逆の順序の量 `dirloss_rev`・`posloss_rev` は D が打ち消し合わないので，2 つの分割の間で比べられない．
- 計算の後で直せるか：直せる（対数の確率と W・b を保存する）．
- 求める対応：下の仮定の表を設計の 4 節に足す．`delta_table.csv` の `posloss` の行に E75 の注を付けるか，表から外す．`rows_g3_*.csv.gz` の `dirloss_rev`・`posloss_rev` は分割の間で比べないと書く．

## 目録に無い種類の不備

- **D12 の案（感度の実験の判定の母数）**：感度の実験で一部の単位だけを測り直すときは，論文の文と同じ単位の集合（測り直さない単位は元の判定のまま）で文の鍵を作り直し，元の文と比べる．測り直した単位だけで作った鍵を「結論が変わったか」の判定に使わない（E81 の関門 1）．
- **D13 の案（変わったかの規則に偶然の水準を添える）**：「元の結論と 1 つでも違えば」の形の規則には，判定の変わった単位のうち差の差（ΔΔ）の区間が 0 を外れた数を添える．学び直しで K 本や教師が入れ替わると，真の差が同じでも判定は入れ替わる（E81 の関門 1）．
