## 判定
直してから進む．台本 `exp/compare_dai.py` は，(1) 向きの損の計算に要るテストの点数を float16 の確率で保存するため，エントロピー最小化と IM で発話の最大 15〜17% の確率が 0 になって対数が −∞ になり，(2) 仮のターゲットの none の発話ごとの出力を保存しないため，判定の基準 δ_d（設計 7.2 節）を出力から計算できない．どちらも起動の前なら保存の形を変えるだけで直るが，起動した後に直すには生徒を作り直す計算が要る．

## 指摘

### [目録に無い（R1 と D の境目）] テストの確率を float16 で保存するので，エントロピー最小化と IM で確率が 0 になり，向きの損の点数（対数の比）が −∞ になる
- 重さ：直してから進む
- 該当箇所：`exp/compare_dai.py:97`，`exp/compare_dai.py:107`，`docs/exploratory-analyses.md:7483`，`proposal_v8.md:23`
- 問題：台本は `probs = torch.softmax(Zte @ Wb[0].T + Wb[1], 1)` を作り，`self.P.append(probs.to(torch.float16)...)` で保存する．設計 1 節の o と d は「6 つの感情の対ごとに，点数の差の平均と幅から d と o を出す」で，既存の実装（`exp/reanalysis_e75.py:659-664` の `L[y == a, a] - L[y == a, b]`）は点数に logit を使う．保存した確率から点数を出すには log p_a − log p_b を取るしかない．float16 は 6×10⁻⁸ 未満を 0 にする．試走の出力（scratchpad の `e77_smoke/avt/IEMOCAP-impro_r0_probs.npy`．評価のターゲットの反復 0．UAR は見ず，確率が 0 の要素だけを数えた）では，3,503 行のうち 192 行に確率 0 の発話があった．発話のうち確率 0 を含むものの割合の最大は，IM 17.4%，エントロピー最小化 15.4%，共訓練の積 3.9%，自己学習 1.9%，dist 1.8%，Saerens 100% である．IM とエントロピー最小化は P4 の主の族の手法であり，筋の 4 の判定量（向きの損の none との差）がこの 2 手法で計算できないか，0 を切り詰める値に左右される
- 計算の後で直せるか：直せる．W・b を保存する行は，テストの座標 Z_te を生徒の作り直しで再現すれば logit を出せる．ただし Z_te は保存しないので，全ターゲット × 全反復で生徒を作り直す計算が要る．massbal・Saerens・共訓練の積・共正則化の和の行は確率しか保存しないので，none や各モダリティの W・b と Z_te から作り直す手順も要る
- 求める対応：起動の前に，保存する量を `log_softmax` の値（float16 でも範囲は足りる．−65504 まで表せ，値の大きさ 16 で刻みは約 0.016）か float32 の確率に替える．UAR の計算は今の argmax のままでよい．替えた後に，試走の行で確率 0 から来る −∞ が無いことを数えて設計の節に書く

- 重さ：直してから進む
- 該当箇所：`proposal_v8.md:274-278`，`exp/compare_dai.py:496`，`exp/compare_dai.py:542`，`exp/compare_dai.py:111-113`

## 主張に要る効果の大きさと検出の見込み

- 判定の単位はコーパス × 生徒 × K で，各単位の「上回った」「減らした」は区間が 0 を外れ，かつ点の推定が δ 以上であることを求める．δ_u は E61 の仮のターゲットから同じ規則で見積もると 1.1〜2.2 ポイントである．δ_d は今の保存からは見積もれない（上の指摘）
- コーパスの数（3〜6）で検定を有意にすることはできない．設計は主張をコーパスごとの記述と「過半のコーパス」の数え上げに限っており，この点は S2 に合う．単位を増やす手段（新しいコーパス）は範囲の外と設計に書かれている（`docs/exploratory-analyses.md:7470`）
- IEMOCAP は話者群 10・各テスト 2 人なので，話者の段の区間が広く，「同じ水準」（区間が ±δ に収まる）にも「上回った」にも当たらない「判定できない」が多く出る見込みがある．A の 6 コーパスのうち IEMOCAP が「判定できない」なら，過半（4）には残り 5 のうち 4 が要る

## 目録に無い種類の不備

- 案 R12：発話ごとの出力は，後で使う量（対数の比，logit の差）を計算できる形と精度で保存する．確率を低い精度で保存すると，確信の強い手法（エントロピー最小化，IM，Saerens）で確率が 0 になり，対数を取る量が計算できない．保存する前に試走の出力で 0 と −∞ の数を数える（E77 の関門 1）
- 案 S8：判定の基準（δ など）を仮のターゲットから作る設計では，その材料（仮のターゲットの発話ごとの出力か，基準の量そのもの）を台本が保存するかを確かめる．基準を評価の値を開く前に計算して書く（E77 の関門 1）
