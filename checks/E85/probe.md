## 指摘

### [D8・D4] proj を「表せる分の上限」と読む仮定を測る表と出力が無く，AFEW と IEMOCAP では候補の数が次元に比べて少ないので，proj が上限を下に見積もる向きに偏りうる
- 重さ：直してから進む
- 該当箇所：`docs/exploratory-analyses.md:10210`，`docs/exploratory-analyses.md:10201`，`exp/analyze_projection_e85.py:80`，`exp/analyze_projection_e85.py:182-185`
- 問題：設計は proj を「これは $E[q\mid z]$ の線形 softmax による当てはめで，手法が疑似ラベルから受け取りうる分の上限の目安である」と書き，その根拠は「ラベル無しの発話が十分あれば」（10199 行）という漸近の式である．しかし AV の世界の仮のターゲット AFEW の候補は 636 本で，音声の f の次元 1024 より少ない．IEMOCAP の 2 群も 2025〜2327 本で次元の約 2 倍しかない．候補の 2 分割ではこの半分になる（AFEW で 318 本）．λ = 1e−3（損失は 1/n の平均なので，候補の数によらず同じ強さ）は弱い罰則で，n < d では proj が候補の q をほぼそのまま再現し，テストでは過学習した分だけ UAR_proj が下がる．proj が上限を下に見積もると，r_rep が小さく出て Q2（「表せない分が主因」）に傾き，r_m/r_rep が大きく出て Q1（「取りこぼし無し」）に傾く．どちらも研究者の問いへの答えを決める判定である．λ の感度は K = 0 の 1e−1 だけで（183 行），感度の値が主の値と違ったときの読み方も無い．さらに，L-BFGS の反復の回数と止まったときの勾配を記録していない（80・88 行）ので，当てはめが収束しなかった単位を見分けられない．proj の候補の上の確率とテストの上の確率も保存しないので，当てはめの忠実さを後から測れない．
- 計算の後で直せるか：直せない（忠実さと収束の値は当てはめの中でしか出ず，保存されない．出すには 96 単位の当てはめをやり直すことになる）
- 求める対応：(1) 設計に仮定の表を足す．行は少なくとも「a. 手法の解が proj に近い（出発点への罰則と K 本の項が meff = n の疑似ラベルの項に比べて小さい）」「b. 候補の数が次元に比べて十分で，proj が母集団の当てはめに近い」「c. 最適化が収束した」「d. 交差エントロピーで最良の線形の当てはめの argmax の UAR を『表せる分』と読める」とし，各行に測る量と基準を書く．(2) 台本で，候補の保留の半分での proj と q の一致（argmax の一致の割合と，q に対する交差エントロピー）を全 K・全 g で出し，問ごとの反復の回数と勾配の最大と n/d を `units.csv` に書く．(3) λ を，ラベルを使わずに保留の半分での q への忠実さで選ぶか，1e−3 と 1e−1 の大きい方の UAR_proj を上限の目安とする規則を計算の前に書く．(4) proj のテストの上の確率（float16）を保存する．

### [D11・S7] 割合を行ごとに割ってから単位の中で平均するので，J ≤ 0 や J ≈ 0 の行が単位の割合を支配する
- 重さ：直してから進む
- 該当箇所：`exp/analyze_projection_e85.py:235-242`，`exp/analyze_projection_e85.py:245`，`docs/exploratory-analyses.md:10212`
- 問題：台本は `u["r_rep_te"] = u.gain_proj_te / u.J_te` を行（T × 反復）ごとに計算し，`r_rep_te=("r_rep_te", "mean")` でコーパスの単位に平均してから，単位の平均の J が正かで絞る（`pos = g[g.J_te > 0]`）．設計は「$J\le 0$ の単位では割合を読まない」と書くが，単位の平均の J が正でも，中の 1 行の J が 0.1 なら比が数十になり，J と得がともに負の行は正の比になる．J = 0 の行があれば平均は inf になる．AFEW のテストは 159 本なので，UAR の標本の揺れは約 4 ポイント（感情ごとの再現率の標準誤差 約 0.077 の 4 つの平均）あり，J が数ポイントの行では比の分母が揺れに埋もれる．r_m_best_te と r_rep_cand（237・238 行）も同じ作りである．
- 計算の後で直せるか：直せる（`units.csv` に行ごとの gain と J がある）．ただし判定の規則なので，値を見てから集計の仕方を変えると L2 になる
- 求める対応：単位の割合を「単位の中の得の平均 ÷ 単位の中の J の平均」（比の平均ではなく平均の比）にし，割合を読む単位の J の下限（例：2 ポイント，またはテストの UAR の標準誤差の 2 倍）と，下限を割った単位の数の報告を計算の前に設計 4 節と台本に書く．

### [S2・S4] Q1 は J を介さずに書け，40 セルの判定を 1 つの答えにまとめる規則が無い
- 重さ：直してから進む
- 該当箇所：`docs/exploratory-analyses.md:10225-10226`，`docs/exploratory-analyses.md:10230`，`exp/analyze_projection_e85.py:254-255`
- 問題：Q1 は「r_m の中央値が r_rep の中央値の 0.8 倍以上」である．r_m/r_rep は単位ごとには gain_method/gain_proj で J が打ち消し合うので，J で割ると揺れを足すだけになる．中央値どうしの比は単位ごとの比の中央値とも違う．r_rep の中央値が 0 以下なら「0.8 倍以上」は向きが逆になる（得が負どうしでは手法が proj より悪くても成り立つ）．単位は 3 と 5 なので中央値は 1 単位の値で，0.8 と 0.6 の閾値がその単位のばらつき（3 反復の幅，テストの標本の揺れ）に比べて意味のある大きさかを測る出力が無い．判定は (world, f, K, g) の 40 セルで出るが，研究者の問い（「説明は正しいか」）に答える文を 40 セルからどう作るか（例：何セルのうち何セルで Q1 が真なら「取りこぼし無し」と書く）が書かれていない．

- 求める対応：Q1 を「gain_proj > 0 の単位で gain_method ≥ 0.8 × gain_proj が成り立つ単位の数」で書き，gain_proj ≤ 0 の単位は Q1 を読まないと書く．単位ごとに反復の幅（最小と最大）を `per_unit.csv` に出す．40 セルの判定を世界と K ごとに数え上げ，答えの文にする規則を計算の前に 4 節に書く．

### [C1・D8] P85-1 の根拠「proj は制約の無い当てはめ，手法は出発点につながれている」は，手法が proj に無い情報（K 本のラベルと出発点）を持つことを無視している
- 重さ：直してから進む
- 該当箇所：`docs/exploratory-analyses.md:10227`
- 問題：手法（dist）は出発点の解からの罰則と，K ≥ 5 では K 本のラベルの交差エントロピーを持つ．proj はラベルも出発点も使わない（10210 行）．出発点が q と違う向きの正しい情報を持てば，手法は proj を上回りうる．したがって UAR_proj ≥ UAR_method は式から出る予言ではなく，「手法の解が proj に近い（仮定 a）」が成り立つときだけの予言である．P85-1 が外れたときに「式が誤り」と読むか「仮定 a が崩れた」と読むかを決められない．K ≥ 5 の proj の差は g（pFK・ref__K）を通した K 本の情報だけで，手法との情報の差が K = 0 より大きい．
- 計算の後で直せるか：直せない（予言の書き直しは値を見る前でないと事前の予言にならない）
- 求める対応：P85-1 を K = 0 に限るか，「仮定 a が成り立つなら」という条件つきの予言に書き直し，K ≥ 5 では proj と手法の情報の差を 5 節に書く．仮定 a を測る量（手法の W と proj の W の距離）は仮のターゲットでは保存されていないので，測れないことを 5 節に書く．

### [範囲] 研究者の問いの前半（同じモダリティのラベル無しの手法は方向を直せない）を E85 は測らず，E85 の値は U19 の 0.45 を直接は説明しない
