- **単位の間で共有するもの**：

  4. 5 つの座標は同じ対数の確率から作る．

## 指摘

### [S2・S3・S5・S7・S11] P87-1・P87-3 は 8 単位の点の中央値だけで当否を決め，族の値にばらつきの基準が無く，3 コーパスを 2 回数える
- 重さ：止める
- 該当箇所：`docs/exploratory-analyses.md:10675`（「族の統計量は，単位の点の値の中央値」），`:10677`，`:10679`，`:10704`（「族の中央値は 8 単位で取るが，独立なコーパスは 5 と書く」）；`exp/analyze_value_split_e87.py:502-505`（`family_of`），`:512-519`，`:540-542`，`:553-555`；`exp/analyze_pairs_e83.py:166-171`（`boot_draws` の種に `run` が入る）
- 問題：
  1. P87-1 は「n_dir(K=0) の中央値 > 0 かつ n_dir(K=25) の中央値 ≥ 0.5 × n_dir(K=0) の中央値」を点で比べる．中央値にも比にも区間が無いので，K = 0 の中央値がわずかに正（例えば 0.05 本）なら，K = 25 は 0.025 本で当たりになる．P87-3 も同じ作りである．単位ごとの区間はあるが，判定に使わない．`summary.md`・`judgments.csv` の中央値と比にも区間の列が無い（S5）．
  2. 中央値は 8 単位で取るので，IEMOCAP・MELD・MOSEI が 2 票，AFEW・CREMA-D が 1 票になる．S7 は「中央値は単位の中で取ってからまとめる」ことを求める．人工の例（`check.py`）では，コーパスの値が IEMOCAP 3，MELD 3，MOSEI −1，AFEW −1，CREMA-D −1 で 2 世界で同じとき，8 単位の中央値は 1.0（正），5 コーパスの中央値は −1.0（負）で，符号が逆になる．
  3. 計算の後に保存した複製（`boot_units.npz`）から族の区間を作ろうとしても，AVT と AV の同じコーパスの抽出が独立なので，2 世界の値を平均するとばらつきを小さく見積もる．2 つの単位はテストの発話も曲線も同じで，強く相関するはずである．正しい族の複製を作るには，抽出の種を世界から外して計算し直す必要がある．
  4. 抽出は 5 コーパスの中の話者だけを引き直すので，族の区間を作っても「この 5 コーパスで」の幅であり，コーパスを越えた一般化には届かない（符号検定の最小 p 0.0625）．
- 計算の後で直せるか：直せない（判定の規則を値を見てから足すと，結果を見てから足した規則になる．加えて，2 世界で共通の抽出は計算し直さないと作れない）
- 求める対応：3 節と台本を次のように直す．(a) 族の統計量を「コーパスごとの値（IEMOCAP・MELD・MOSEI は AVT と AV の単位の平均）の 5 つの中央値」にする．(b) 族の区間のために，種を (seed, corpus) だけにした抽出（2 世界で共通，コーパスの間で独立）を 1 組足し，抽出ごとに 5 つの中央値と，P87-1 の差 med(K=25) − 0.5 × med(K=0)，P87-3 の差 0.5 × med(K=0) − med(K=25) を計算して保存する．単位ごとの区間は今の抽出（E79・E83 と同じ種）のまま残してよい．(c) P87-1 の当たりを「med n_dir(K=0) の 2.5% 点 > 0 かつ差の 2.5% 点 ≥ 0」，外れを「差の 97.5% 点 < 0 か，med n_dir(K=0) の 97.5% 点 ≤ 0」，それ以外を「判定できない」とする．P87-3 も同じ形で書く．(d) コーパスを 1 つずつ抜いた 5 通りの中央値で当否が変わるかを感度の列にする．(e) 当否の文を「この 5 コーパスで」と限り，条件を満たすコーパスの数（x/5）を並べる．

### [S2・S8 に近い] P87-2 は「正の証拠が無い」ことで当たりになり，打ち切りの単位と 2 回数えたコーパスがその当たりの側に寄る
- 重さ：止める
- 該当箇所：`docs/exploratory-analyses.md:10667`（「読めない単位は…族の判定の対象から外す」），`:10678`，`:10705`（「0 に近い値の多い座標（n_pos の K ≥ 5）では，これが予言どおりの振る舞いである」）；`exp/analyze_value_split_e87.py:133-140`（`read_K` の打ち切り），`:487-492`（区分），`:546-549`（`p5["n_pos"] * 2 < p5["n_units"]`）
- 問題：
  1. P87-2 は「K = 5 と 25 で n_pos が『正』の単位が半数未満」で当たりになる．区間が 0 を含む単位はすべて当たりの側に数えるので，位置の分が実際にあっても区間が広ければ当たりになる．設計 10705 行は「区間が 0 を含む単位は判定できない」になることを「予言どおりの振る舞い」と書き，検出力の不足と「消える」を区別しない．「同じ水準」の区分（δ）を置かないので，この予言は外れる道が「4 単位以上で区間の下端 > 0」の 1 つしかない．
  2. 打ち切りの単位は「正」になりにくい．台本の `read_K` では，none と手法がどちらも K = 1 より悪いと両方 1 に置かれて n ＝ 0，どちらも全件より良いと両方 K = all に置かれて n ＝ 0 になる（`check.py` で確かめた）．none が全件より良く手法がそれより悪いと n は大きな負になる．抽出の大半でこうなると，複製の 2.5% 点は 0 になり，区間の下端が 0 を上回らない（`check2.py`：複製の 90% が 0 で残りが正でも 2.5% 点は 0）．台本は `n_pos` を読めない単位も含めた 8 単位で数え（549 行），設計 10667 行の「族の判定の対象から外す」と合わない．読めない単位が 4 つ（許される上限）なら，読める 4 単位のうち 3 単位が「正」でも P87-2 は当たりになる．
  3. 8 単位で数えるので，同じ 2 コーパスが正でも，どのコーパスかで当否が変わる（`check.py`）．IEMOCAP＋MELD が正なら 4 単位で外れ，AFEW＋CREMA-D が正なら 2 単位で当たる．正のコーパスが 2 つの 10 通りのうち 7 通りで当たり，3 通りで外れる．
- 計算の後で直せるか：直せない（判定の規則と分母を値を見てから替えると，結果を見てから足した規則になる）
- 求める対応：(a) P87-2 の当たりの文を「K ≥ 5 で位置の分の正の証拠は過半のコーパスに無い」に限り，「消える」とは書かないと 3 節に書く．(b) 「消える」と書く条件を別に置く．案：前の指摘の (b) の族の抽出で med n_pos(K) の 97.5% 点を出し，その値（「これより大きい位置の分は否定できる」本数）を K = 5・25 で必ず並べる．研究者の見方（向きは運び，位置は運ばない）を判定したいなら，同じ単位の中の差 n_dir − n_pos（抽出は共通なので複製の差がそのまま区間になる）の区間の下端 > 0 を K = 5・25 の予言として足す．(c) 数える単位を 5 コーパス（前の指摘の (a)）にし，分母を読めるコーパスに限る．読めるコーパスが 3 未満の K では「判定できない」とする．

### [S3・目録に無い] 反復ごとの曲線を単調に整えてから「届く最小の K」で読むと，点数のわずかな差が数十本の差に跳ぶ
- 重さ：止める
- 該当箇所：`docs/exploratory-analyses.md:10657`（「累積の最大…で単調に整え…log K について線形に補う」），`:10659`（「平らな区間では，v に届く最小の K を取る」），`:10682`（感度 (c)），`:10687`（仮定 1 の基準「整えた点が全体の 1/4 未満」）；`exp/analyze_value_split_e87.py:108-113`（`monotone`），`:116-140`（`read_K`），`:349`，`:395`，`:404`
- 問題：曲線は（実行，分類器，T，反復）ごとに 6 点で作り，K = 25 → 50 のように点数がほとんど伸びない区間では，テストの揺れで 50 の点が 25 の点を下回りうる．累積の最大で整えると 25〜50 が平らになり，平らな高さをわずかに越えた値は 50 より右（50 と全件の間を log K で補う区間）に跳ぶ．台本の `read_K` で確かめた（`check3.py`）：S_dir の曲線 [60, 70, 74, 80, 79.8, 85]（K = 1, 5, 10, 25, 50, 400）で none が 79.9 のとき，手法が 79.95 なら n ＝ 0.2 本，80.05 なら n ＝ 26.4 本になる．点数の差 0.1 点で本数が 26 本変わる．単調な曲線（50 の点が 80.2）でも同じ差は 5.1 本である．位置の座標（小さいほど良い）でほぼ平らな曲線を作ると，S_pos の差 0.0002 で n ＝ 45 本になった（`check2.py`）．
  - この跳びは none の K' が 25〜50 にある K = 25 の読みで起きやすく，K = 0 の読み（K' が 1〜10 の急な区間）では起きにくい．したがって n_dir(K=25) と n_uar(K=25) が大きく揺れ，P87-1 は当たりの側に，P87-3 は外れの側にずれうる．中央値と比の判定がこの跳びで決まるおそれがある．
  - 百分位のブートストラップと jackknife は，推定量が値について滑らかであることを前提にする．抽出ごとに平らな区間の位置が変わると，複製が 0 付近と数十本付近の 2 つに分かれ，区間の端の位置がどちらの山の重さで決まるかに依る．
  - 仮定 1 の基準は「整えた点の割合」で，跳びの大きさを見ない．感度 (c)（整えない）は，単調でない曲線の最初の交点で読むので，同じ不連続を持つ．
- 計算の後で直せるか：直せない（読み方を値を見てから替えると，結果を見てから足した規則になる）
- 求める対応：主の読みを「反復で平均した曲線に，反復で平均した none と手法の点数を当てて読む」に替える（抽出の中では反復の重み A で曲線と点数の両方を平均してから読む）．平均した曲線を整えたときに，値が整えて平らになった区間に入れば，その読みを打ち切りと同じ扱い（読めない）にし，数を記録する．今の反復ごとの読みは感度の行に下げる．仮定 1 の表に，整えた区間に入った読みの数と，読みが整えた区間の端に跳んだ量の最大を足す．

## 目録に無い種類の不備

- S15（案）：曲線に値を当てて量（換算本数，K* など）を逆に読む解析では，反復ごとの雑音のある曲線を単調に整えてから読むと，整えて平らになった区間の端で読みが跳び，点数のわずかな差が大きな本数の差になる．平均と百分位の区間はこの不連続の影響を受ける．曲線と当てる値を先に平均してから読み，整えた区間に入った読みは打ち切りと同じ扱いにし，その数と跳んだ量を仮定の表に残す（E87 の関門 1）．
- S16（案）：「正の単位が半数未満」「区間が 0 を含む」のような証拠の不在を当たりとする予言は，検出力が低いほど当たる．当たりの文を「正の証拠が無い」に限り，「消える」「無い」と書くには上限（区間の上端）か，対になる量との差の区間を置く．打ち切りで 0 に固まる単位は，そのような予言の分母から外す（E87 の関門 1）．
- S7 への書き足し（案）：世界・構成をまたいで同じテストの発話を使う単位を族にまとめるときは，抽出の種も共通にする．種に世界の名前が入ると，保存した複製から族の区間を作り直せない（E87 の関門 1）．
