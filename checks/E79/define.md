# 関門 1：定義（E79，2026-11-01）

## 判定

直してから通す．3 節の 2 つの基準（2 つの山の模型の「2 ポイント・4/6・0.2」，DA の項の「予測の食い違い 1%」）は，判定に使う量（none と手法の対の差）とも判定の基準 δ とも結びついておらず，模型の基準は模型が正しくてもテストの小さいコーパス（RAVDESS・AFEW）で 4〜9 割の行を外れと判定するので，評価の値を見る前（段 (c) を流す前）に基準を作り直す必要がある．

模型の式の確認：d_AUC = √2 Φ⁻¹(AUC) は，2 つの山が正規分布なら分散が違っても母集団で d（2 つの分散の平均の平方根で割った値）と一致する（AUC = Φ((μ_k − μ_j)/√(σ_k² + σ_j²))．出典：Macmillan & Creelman の等分散の式 A_z = Φ(d′/√2) と，分散が違う場合の d_a = √2 Φ⁻¹(A_z)）．したがって基準 (c)「d と d_AUC の食い違い」は分布の形が正規から外れることを測り，分散の違いは測らない．分散の違いは基準 (b) が測る．

## 指摘

### [D8・D4] 2 つの山の模型の基準「6 対の平均の正解率の誤差 2 ポイント以下」は，模型が正しくても RAVDESS と AFEW の行の 4〜9 割を外れと判定する
- 重さ：直してから進む
- 該当箇所：`docs/exploratory-analyses.md:9184`，`docs/exploratory-analyses.md:9289`，`exp/analyze_e79.py:72`，`exp/analyze_e79.py:1497-1504`
- 問題：3 節は「行 × 反復ごとに，6 対の平均の \|A(d, o) − 実際の 2 感情の正解率\|」が「2 ポイント以下」なら模型が成り立つとし，根拠を「E13 の当てはまり（誤差の平均 1.0 ポイント）だけ」（9289 行）と書く．この量には 3 つの欠点がある．
  1. 誤差の大部分がテストの標本の揺れである．発話一覧から数えたテストの 1 反復の感情ごとの本数（全体 ÷ 5）は RAVDESS で 19・38・38・38，AFEW で 41・43・36・39 である．この本数で等分散の正規分布から人工の標本を引き（各 400 回，o = 0.2，6 対の d を 0.3〜1.5 と 1.0〜3.0 の 2 通り），台本と同じ式で誤差を測ると，**模型が正しいのに** 2 ポイントを超える行の割合は RAVDESS で 0.84 と 0.61，AFEW で 0.73 と 0.43，IEMOCAP 即興で 0.08 と 0.01，MELD で 0.00 だった（誤差の中央値は RAVDESS 2.83・2.23 点，MELD 0.77・0.59 点）．基準は模型の当てはまりではなくテストの大きさを測る．「選んだ行の 2 割を超えて外れる（実行, 生徒）」の注は，RAVDESS と AFEW を含む音声の種類で，模型が正しくても揺れだけで付きうる
  2. 判定に使う量と結びついていない．P4・P4′・P5-3 が判定するのは none と手法の向きの損の差で，水準の誤差のうち none と手法に共通の部分は差で打ち消し合う．差に効くのは none と手法の誤差の差である．また基準の 2 ポイントは判定の基準 δ_d と比べられていない（δ_d はまだ計算していないので，2 ポイントが δ_d より大きいか小さいかはこの時点で分からない）
  3. 前の実験の決まりと結果を引き継いでいない．E75 は同じ模型の仮定を「\|acc_model − acc_actual\| の中央値 ÷ 損の中央値が 1/3 未満」で測り（`docs/exploratory-analyses.md:7876`），向きの損について V で 0.47 と成り立たないことを記録した（同 8094 行）．E79 は V の種類の向きの損で P4 を判定するのに，この結果に触れていない
- 計算の後で直せるか：直せる．`pairs_*.csv` に d，o，d_AUC，acc_actual，acc_model が反復ごとに残る．ただし基準の値は評価の値を見る前に決める必要があるので，段 (c) を流す前に直す
- 求める対応：3 節の模型の行を，下の「D8 の表の案」の 1〜3 行目に替える．要点は次の 2 つである．(i) 判定の単位（コーパス × 生徒 × K）で，none − 手法の向きの損の点の値を Φ(d/2)（今の量）と Φ(d_AUC/2)（順位から作る量．正規なら分散が違っても今の量と一致する）の 2 通りで出し，2 つの差を δ_d と比べる．(ii) 水準の誤差は，そのコーパスのテストの本数で模型が正しいときに出る誤差の分布（人工の正規の標本か，パラメトリックなブートストラップ）と比べる．E75 の V の結果を 3 節の表の注に書く

### [D11] 基準 (c) の \|d − d_AUC\| ÷ \|d_AUC\| は，分母の d_AUC が 0 に近い対で発散する
- 重さ：直してから進む

- 問題：台本は `p["dauc_rel"] = (p.d - p.d_auc).abs() / p.d_auc.abs()` を 6 対で単純平均する．K = 0 の転移では 2 感情がほとんど分かれない対（d が 0 に近い対）がありうる．分母が 0 に近い対が 1 つあれば 6 対の平均が大きくなり，その行は模型の外と判定される．AUC がちょうど 0.5 の対では 0 で割る（上の人工の標本の計算でも 0 で割る警告が出た）．d = 0.3 の対を含む場合，模型が正しくても RAVDESS で 1 割，AFEW で 8% の行が基準 0.2 を超えた．分母が 0 に近い単位の数と扱いを計算の前に決めていない（目録 D11）

### [D8] DA の項の基準「mapctl との予測の食い違い 1%」に，最適化の揺れという比べる基準が無い
- 重さ：直してから進む
- 該当箇所：`docs/exploratory-analyses.md:9185`，`exp/analyze_e79.py:71`，`exp/analyze_e79.py:1037-1055`，`exp/analyze_e79.py:1514-1517`
- 問題：3 節は「1% 未満の単位は『DA の項は予測をほとんど変えなかった』と書く」とし，裏返すと 1% 以上なら DA の項が予測を変えたとみなす．この基準には 2 つの欠点がある．
  1. K ≥ 1 では，DANN・MME と mapctl はどちらも Adam のミニバッチで解く．E78 は同じ種で同じミニバッチの列を通すようにした（`docs/exploratory-analyses.md` の E78 の節「ミニバッチの乱数」）が，DA の項の勾配がわずかでも加われば軌道は離れ，終わりの点は確率的な勾配法の揺れの範囲で違う所に止まる．このとき食い違いは DA の項の働きではなく最適化の揺れを表す．1% がその揺れより小さければ，ほぼ全部の単位で「DA の項が予測を変えた」側に入る．筋の 4 にとっては「DA の項は働いたが向きの損を減らさなかった」という書き方を支える側に働くので，主張に関わる．K = 0 では mapctl が none と同じ解になる（E78 の検算）ので，この問題は K ≥ 1 だけにある
  2. テストの小さいコーパスでは 1% が 1〜2 発話に当たる．テストの本数は 1 反復で RAVDESS 約 134，AFEW 約 159 なので，2 発話が入れ替わると 1% を超える
- 計算の後で直せるか：直せる．E78 は選んだ DANN・MME の設定を種 0・1・2 で評価のターゲットに残す（`exp/compare_dai2.py:571-578`）ので，種の間の食い違いを `_pred.npy` から出せる．ただし台本の段 (c) の `diagnostics` に計算を足すことになり，基準も値を見る前に決めるので，段 (c) の前に直す
- 求める対応：比べる基準を「同じ設定の DANN（MME）の種の間の食い違い」にする．具体的には，単位（コーパス × 生徒 × K．反復で平均）ごとに，a = 同じ種の DANN と mapctl の食い違い（種 0），b = 選んだ DANN の種 0・1・2 の 3 対の食い違いの最大，とし，「a > b かつ a ≥ 1%」のときだけ「DA の項は最適化の揺れを超えて予測を変えた」と書き，そうでなければ「DA の項の効果は最適化の揺れと見分けられなかった」と書く．K = 0 は b を基準にせず a だけで書く（mapctl は none と同じ解なので揺れが無い）．あわせて，E78 が 256d41c で保存するようにした ‖A − I‖_F と判別器の損失・候補のエントロピーの最初と最後の値を `da_effect.csv` に並べる（基準は付けず記述）．予測の食い違いは向き（d）の変化と切片（o）の変化を区別しないので，DA の項が向きを変えたかは既にある「mapctl_match − 手法」の向きの損の判定（`exp/analyze_e79.py:1227-1233`）で読む，と 3 節に書く

## 目録に無い種類の不備

- D12 模型の当てはまりや「効いたか」の基準は，(i) 判定に使う量（差か水準か）と同じ形で測り，(ii) 判定の基準（δ など）と同じ尺度で決め，(iii) 模型が正しいときや効果が無いときにも測定の揺れで出る値（テストの本数で決まる標本の揺れ，確率的な勾配法の種の間の揺れ）と比べて決める．絶対の値（「2 ポイント」「1%」）を 1 つだけ置くと，テストの小さいコーパスや最適化の揺れで基準の当否が決まる（E79 の関門 1）
