# 関門 1：定義（E82，2026-11-02）

## 判定
直してから通す．K = 5 では C′ を 3 倍・10 倍にすると K 本のラベルの項にかかる罰則も弱まるのに，比べる相手の none と「働かなかった」の基準は E39 の C′ のままなので，「none − 手法」の向きの損の差にラベル無しの項の効果と K 本の項の効果が混ざり，筋 4（ラベル無しのデータでは向きが直らない）の判定を変えうる．GPU の計算を始める前に，倍率ごとの none を台本に足す必要がある．

## 指摘

### [D10] K = 5 の「none − 手法」が，C′ を弱めて K 本の項が動いた分を手法の効果として数える
- 重さ：直してから進む
- 該当箇所：`docs/exploratory-analyses.md:9579`（「none，自己学習の出発点，エントロピー最小化と IM の初期値は E39 の C′ で解いた none のままにする」），`exp/s43_penalty.py:110`（`s["cp"] = float(mult) * cp0`），`:155`（none は E39 の C′ だけで解く），`exp/compare_dai.py:178`（`w = self.wt[K] if w4 is None else self.wt[K] + w4`．K 本の重みはどの手法の問にも入る），`exp/logreg.py:242`（目的関数），`exp/analyze_e79.py:1741-1763`・`:1958`（「働かなかった」の材料は E39 の C′ の none との予測の食い違い）
- 問題：E77 の学習器の目的関数は `(Mx * nll).sum(0) / Sx + ((W - Wanc) ** 2).sum() / (2 * Cx * Sx)`（`logreg.py:242`）で，全体を S で割っているので，解は「Σ（K 本の重み × 損失）＋ ラベル無しの項 ＋ ‖W − W_anchor‖² / (2C′)」を最小にする点である．C′ を m 倍にすることは，K 本の項とラベル無しの項の両方を m 倍にすることと同じである（切片の罰則 C_b は変えないので，切片だけは相対的に強くつながる）．
  K = 0 では none は出発点そのもので（`compare_dai.py:180`：重みが全部 0 の問は出発点を返す），C′ に依らない．このため K = 0 の「none − 手法」はラベル無しの項の効果だけを測る．
  K = 5 では，手法の行は「K 本の項 ＋ ラベル無しの項」を弱い罰則で解き，none の行は「K 本の項」だけを E39 の強い罰則で解く．C′ を 10 倍にした手法の向きの損が none より小さく（または大きく）なったとき，その差には「K 本のラベルだけでも罰則を弱めれば向きが動く」分が入る．m_eff = 100 のようにラベル無しの項が小さい設定では，手法の解は「C′ を 10 倍にした none」にほぼ等しく，差のほぼ全部がこの分になりうる．
  「働かなかった」（`inactive`．none との予測の食い違いで判定から外す）も E39 の C′ の none と比べるので，ラベル無しの項が効いていない行でも，K 本の項が動いた分で食い違いが出て「働いた」側に数えられる．
  筋 4 の主張は「ラベル無しのデータでは向きが直らない」である．K = 5 で文の鍵が変わったとき，書き方の規則は「E39 の罰則で出発点につないだとき」と限定を付け，ラベル無しの手法が罰則を弱めれば向きを直したと読める文になる．実際には K 本のラベルが向きを直した可能性を区別できない．
- 計算の後で直せるか：直せるが，倍率ごとの none（K = 5 の 1 問ずつ）を解くために生徒を作り直す GPU の計算をもう一度回すことになる．計算の前に足せば 1 単位あたり 2 問ぶんの増加で済む．
- 求める対応：
  1. `exp/s43_penalty.py` で，倍率 3・10 のそれぞれについて none を同じ C′ で解き，`none` の行を `-C3x`・`-C10x` の param で書く（仮のターゲットと評価の両方．K = 0 は出発点と同じなので書かなくてよいが，書けば恒等の検算になる）
  2. 設計の 2 節に，判定の主の比べ（E79 と同じ「none(E39) − 手法(選んだ倍率)」）に加えて，対照の比べ「none(選んだ倍率と同じ C′) − 手法(選んだ倍率)」を P4・P4′ の 3 手法の行に置くと書く．E79 の CORAL と coralctl，DANN と mapctl の対照の族（P4_ctl）と同じ考えである
  3. 「働かなかった」の材料を，選んだ倍率と同じ C′ の none との予測の食い違いで作る
  4. 書き方の規則を，K = 5 で文の鍵が変わったときに対照の比べでも同じ向きに変わるかで分ける．対照の比べで変わらなければ「罰則を弱めると K 本のラベルで向きが動いたが，ラベル無しの項の上乗せは見えなかった」と書き，筋 4 の文には罰則の限定を付けない．K = 0 の文の鍵の変化は対照が要らない（none が C′ に依らない）と書く

### [D1] 手法ごとの文の鍵と「過半が 10 倍」の数え方が，設計に定義されていない
- 重さ：記録する
- 該当箇所：`docs/exploratory-analyses.md:9588-9589`，`checks/E82/impl.md` の 6 節の 1・2，`exp/analyze_e82.py:297-307`（`statements_of`），`:422-436`（decision），`:437-477`（倍率の数え上げ）
- 問題：E79 の筋 4 の文の鍵（(1)〜(4)．`statements_p4`）は族（P4・P4′）ごとに 8 手法の組み合わせをまとめて 1 つ決める．設計は「3 手法のすべてで文の鍵が固定の版と同じなら」と手法ごとの鍵を前提にするが，手法ごとの鍵の作り方は設計に無く，台本の担当が impl.md の 6 節の 2 で「この読み方でよいか」を尋ねている．台本は E79 の規則を 1 手法の組み合わせ（手法 × 生徒の種類 × K）だけに当て，(3) の追加の条件（δ を半分にした行，模型に依る単位，種 0 の感度）も手法ごとに当てる．族の全手法の鍵（`family_level_same_rule`）も出す．
  「過半が 10 倍」は，母数（手法ごとか 3 手法の合計か，族 × K ごとか．`__none__` の単位を母数に入れるか）が設計に無い．台本は母数に `__none__`（`n_none_or_empty`）を含め（`analyze_e82.py:455-466`），decision では手法ごとと 3 手法の合計の excl の版を使う．新しい同点の規則（倍率の小さい方を先に選ぶ．`choose_e82`，`:90-106`）では同点で 10 倍が選ばれないので，impl.md の 6 節の 1 の「同点で決まった 10 倍」の問いは設計の改訂で解消している．
- 計算の後で直せるか：直せる（記述と読み手の定数）．ただし評価の値を見る前に決める．
- 求める対応：設計の 3 節に次の 2 点を書く．(i) 手法ごとの文の鍵は，E79 の `statements_p4` と種の感度の書き直しを，その手法の組み合わせ（P4 は種類 3 × K 2，P4′ は融合の生徒 2 × K 2）だけに当てて作る．族の全手法の鍵も並べ，2 つが食い違えば両方を書く．(ii) 「過半が 10 倍」の母数は，手法ごとに，excl の版で手法が選ばれた単位（`__none__` を除く）とする．

### [D1] C′ の倍率は，K = 0 ではラベル無しの項の重み m_eff の倍率とほぼ同じつまみである
- 重さ：記録する
- 該当箇所：`docs/exploratory-analyses.md:9579`，`exp/logreg.py:242-244`
- 問題：K = 0 では，目的関数は「m_eff × ラベル無しの項 ＋ ‖W − W_anchor‖² / (2C′) ＋ ‖b − b_anchor‖² / (2C_b)」である．C′ を 10 倍にすると，m_eff を 10 倍にして切片の罰則を 10 倍強めたのと同じ解になる．entmin の今の格子は m_eff ∈ {100, 500, 2000, n} なので，倍率 10 の行の多くは m_eff の格子を n より上に延ばした点に当たる．「罰則を弱めた」と「ラベル無しのデータを重く扱った」は K = 0 では区別できない．
- 計算の後で直せるか：直せる（記述）．
- 求める対応：結果を書くとき，K = 0 の倍率 m の行は「ラベル無しの項の重みを m 倍にし，切片を相対的に強くつないだ設定と同じ」と注を付ける．書き方の規則の限定の文（「E39 の罰則で出発点につないだとき」）を K = 0 で使う場合は，「E39 の罰則と m_eff の格子の範囲では」と書く．

### [D8] 査読の前提（罰則を弱めると重みが向きを変える）を測る量が設計に無い
- 重さ：記録する
- 該当箇所：`docs/exploratory-analyses.md:9575`（「罰則が強いほど重みは向きを変えにくい」），`:9583-9590`
- 問題：E82 は「C′ を大きくすれば解が出発点から離れ，向き（d）が変わりうる」ことを前提にする．選ばれた倍率で解がほとんど動かなければ，判定が変わらないことは「罰則の固定は結論に効いていない」の証拠にならない．また C′ を 0.3（T と AVT の MOSEI・MELD の 10 倍）まで弱めると，凸でない entmin・IM は L-BFGS の反復の上限で止まりやすくなる．どちらも設計に基準が無い．`oracle_dir.csv` の「格子のどの設定でも」は，reselect の版では倍率を含む格子の上で計算される（`analyze_e79.py:2805-2812` は族の候補 `mem` の中の最良を取る）が，設計はこれを使うと書いていない．
- 計算の後で直せるか：直せる（W・b，`_convp.csv` の反復の回数と勾配を保存する）．
- 求める対応：下の表を設計の 3 節に足す．

## 目録に無い種類の不備

- **D14 の案（共通のつまみを動かす感度の実験の基準の行）**：比べる手法と基準の行（none）が共有する項（K 本の損失）にかかるつまみ（罰則の強さ，分割，標準化）を手法の側だけで動かすときは，基準の行も同じつまみの値で解き直し，「基準(同じつまみ) − 手法(同じつまみ)」を対照として置く．「働かなかった」のような基準の行との食い違いで決める量も，同じつまみの基準で測る．D10（いつも含める成分の寄与を引く）の特別な場合で，罰則や重みの倍率は目的関数の中で互いに置き換えられることがある（C′ の m 倍は K 本の項とラベル無しの項の m 倍と同じ）ので，つまみの意味を目的関数の形から書き下してから設計する（E82 の関門 1）．
