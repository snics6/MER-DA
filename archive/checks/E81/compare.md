## 指摘

### [目録に無い種類（C8 の案）] 論文の書き方の規則が，対話の重なりを両方の腕で受ける比較と 2 コーパスの過半だけを見ており，「手法 − none」の得の変化で限定を付けるかを決めない
- 重さ：直してから進む
- 該当箇所：`docs/exploratory-analyses.md:9563`，`exp/analyze_e81.py:345-368`（`statement`），`exp/analyze_e81.py:507-541`（文の鍵と `statement_flag.json`）
- 問題：規則は「E81 の分割での P5-1〜P5-3 の結論（E79 の過半の規則を 3 つのターゲットの単位に当てたもの）が，今の分割の同じ単位での結論と同じなら，筋 5 の主張に『候補がテストと同じ対話を含む』の限定を付けず」と書く．査読 [G3] の問いは「oursx − none の得の一部は新しい対話では出ない得である可能性」であり，求めたのは「『手法 − none』の差が今の分割からどれだけ変わるか」である（`review_v1.md:51-52`）．この規則には 3 つの穴がある．
  1. P5-1（oursx − KD）と P5-2（oursx − 群 B の最良）は，両方の手法が同じ G3 の候補を使うので，対話の重なりの得が両方から同じように消えれば鍵は変わらない．P5-1・P5-2 が変わらないことは「oursx の得が重なりに依らない」ことを示さない．
  2. 「oursx − none」の UAR（P5-3u）は，`analyze_e81.py:68` で族として計算するが，文の鍵には P5-3 が「減らした」に届かないときの受け皿としてしか入らない（`analyze_e81.py:360-363`）．P5-3 の鍵は向きの損で決まるので，oursx の UAR の得が G3 で大きく縮んでも，向きの損の判定が変わらなければ「同じ」になる．kd − none と群 B − none の Δ も `delta_table.csv` に出るが，規則には使わない．ΔΔ の大きさは規則のどこにも入らない．
  3. 鍵は IEMOCAP と MELD の 2 コーパスの過半（`majority(2) = 2`，`analyze_e79.py:164-165`）で作る．2 コーパスでは両方がそろわないと「上回った」「減らした」にならず，今の分割と G3 の分割の両方で「判定できない（受け皿の行）」になれば鍵は「同じ」になり，`statement_flag.json` は same を出す（`analyze_e81.py:537`）．さらに，論文の P5 の文は AVT で 3 コーパス（MOSEI を含む），AV で 5 コーパスの過半で決まる（E79 の 9219 行）．2 コーパスだけの鍵が変わらないことは，論文の文が変わらないことと同じではない．
- 計算の後で直せるか：GPU の計算はやり直さずに直せる（`delta_table.csv`・`units.csv`・発話ごとの確率が残る）．ただし規則は値を見る前に決めると 9558 行に書いてあるので，起動の前に直さないと後付けの規則になる．
- 求める対応：起動の前に 9563 行の規則に次を足す．(a) 限定を外す条件に「oursx − none の UAR（P5-3u）の単位ごとの判定（E79 の judge_unit と δ_u）が今の分割と同じで，かつ ΔΔ の点の値が −δ_u を下回るコーパスが無い」を加える（閾値の形は設計者が決めてよいが，ΔΔ の大きさを使うこと）．kd − none・群 B − none の ΔΔ も同じ表に並べ，oursx の ΔΔ が相手の ΔΔ より大きく負のときを別に書く．(b) 論文の文と同じ単位の集合で判定を作り直す版を足す．IEMOCAP と MELD の単位の判定だけを G3 の分割の判定に替え，MOSEI（AVT）と AFEW・CREMA-D・MOSEI（AV）は今の分割の判定のまま，E79 の statements_p5 を当てて E79 の文の鍵と比べる．(c) 両方の分割で「判定できない」の単位の数を same の判定と並べて出し，「判定できない」どうしの一致は「同じ」に数えない．

## 目録に無い種類の不備

- C8 の案：査読の疑う交絡を測る感度の実験では，判定の規則に，交絡が現れる量（手法 − 基準の差と，その変化 ΔΔ の大きさ）を入れる．比べる両方の手法が同じ交絡を受ける比較（手法どうしの差）だけで「結論は変わらない」と決めない．また，判定は論文の文と同じ単位の集合（同じコーパスの数と過半の規則）で作り直し，両方の版で「判定できない」になった一致を「同じ」に数えない．（E81 の関門 1 の比較）
