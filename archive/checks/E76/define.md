予言に使う式は d_T(K) = D/√(1 + q/K) の 1 つで，別の形として M1（D と q を当てる）と M2（d = a K^b）を置く（設計 7995 行）．設計はこの式を「K ≫ p の古典の展開と同じ形の経験式」と書くと決めている（設計 8010 行）．出典は Okamoto 1963 と Raudys 1998 で，係数を評価すると向きの項は 2(p−1)/(NΔ²) になる（`docs/related-work.md:566`）．この展開は p を固定して N を大きくする展開で，E76 の範囲は K ≤ 50（4 クラスで N ≤ 200）に対し p = 512（映像）〜1,024（音声）〜2,304（融合）なので，K/p は 0.1 未満である．展開の q は p = 1,024，Δ ≈ 1.7 で数百になるのに対し，実測の q_dir の中央値は 16.1（W7）である（`docs/exploratory-analyses.md` E28-9 の結果）．設計が式を経験式として扱い，残差・区間・別の関数形を付ける（D4）こと自体は妥当である．以下の指摘はその診断の作り方についてである．

## 指摘

### [D4・D7] 基準 D（own_d）は d_T(K) の上限になっていないので，「1 母数の形は K ≤ 50 の曲線を表さない」の判定が関数形ではなく D の取り方を測ってしまう
- 重さ：記録する（結果を見る前に設計 2.4.3 節を直す）
- 該当箇所：`docs/exploratory-analyses.md:7995`，`:8007`，`exp/explore_pairs.py:62-77`，`exp/explore_direction_bound.py:43`
- 問題：設計は「D は E13 の own_d．(i) 主：d_T(K) = D/√(1 + q/K) を K ∈ {1, 5, 10} で最小 2 乗，(ii) 延長：K ∈ {1, 5, 10, 25, 50}」とし，判定に「1 母数の形の延長の当てはめで，残差の絶対値の平均が D の 10% を超える種類 … では『1 母数の形は K ≤ 50 の曲線を表さない』と書き」を置く．この形は d_T(K) < D をいつも満たすので，D が K → ∞ の値でなければ残差が出る．D は別の学習器（縮小 LDA）を話者の半分のデータで学んだ有限の標本の値で，ロジスティック回帰の ① の極限ではない．既存の E28-9 の表（`results/fixc_analysis/explore_relation/e28t9_targets.csv`）で，6 対の平均の d_T(10)/D は映像の IEMOCAP-script で 1.60，映像の IEMOCAP-impro で 1.13，映像の AFEW で 1.16，音声＋映像の AFEW で 1.04 で，K=10 ですでに 26 ターゲット中 4 つで D を超えている．K=25・50 では超える数が増える見込みである（RAVDESS の平静は全部で 96 本で，D を測った半分は約 48 本だが，① は K=50 で 50 本を使う）．q の格子の下限は 0.1 で（`explore_direction_bound.py:43`），映像の AFEW の q_dir はすでに 0.186 である．このまま判定すると，D の取り方のずれを「1/K の形が合わない」と書くことになる．また q の区間は「2.4.1 と同じ引き方で d_T を測り直して当てはめ直す」だけで，D の推定の誤差が区間に入らない（D7）．E75 の項目 8 は同じ現象（d が Δ を超え，向きの損が負になる升）を損の分解について扱っているが，E76 の q の当てはめには扱いが書かれていない
- 計算の後で直せるか：直せる（E76 は ① の K=全件の点数を C 4 つで保存し，D は特徴から CPU で作り直せる）
- 求める対応：(a) 当てはめの前に，種類ごとに d_T(K) > D となる（ターゲット，対，K）の数を K ごとに数えて表に出す．(b) 基準の別の版として，E76 の ① の K=全件のテストの点数で測った d（同じ学習器，同じ C の規則）を D′ として当て，D と D′ の比も出す．(c) 「1 母数の形は表さない」は，D でも D′ でも残差が基準を超え，かつ M1（D を自由にした形）でも同じ基準を超える場合に限る．M1 だけが合う場合は「形は合うが own_d は漸近の値ではない」と書く．(d) q が格子の端（0.1 と 1,000）に当たったターゲットの数を書き，端の値を中央値に入れるかを決める．(e) 残差の基準「D の 10%」に加えて，同じ 2 段のブートストラップでの d_T(K) の標準誤差の 2 倍と比べる（K=1 の d_T は雑音が大きく，10% の基準は雑音だけで超えうる）．(f) q の区間に D の誤差を入れるなら，ブートストラップの回ごとに引いた話者で `own_separation` を測り直す．入れないなら「D を固定した区間」と書く

### [D4] 別の関数形との比べ（1 つずつ抜いた予測）の K の集合が決まっておらず，3 点では 2 母数の形の比べが外挿になる
- 重さ：記録する
- 該当箇所：`docs/exploratory-analyses.md:7995`，`:8007`
- 問題：設計は「M1（D と q を両方当てる），M2（d = a K^b）を当て，K を 1 つずつ抜いた予測の 2 乗誤差で比べる」とし，判定は「M1・M2 の方が抜いた予測の誤差が小さいターゲットが 3 分の 2 以上」である．主の当てはめは K ∈ {1, 5, 10} の 3 点で，2 母数の形は 1 点を抜くと残り 2 点を通る曲線になり，K=1 か K=10 を抜いたときの予測は外挿になる．比べを主（3 点）と延長（5 点）のどちらで行うかが書かれていない
- 計算の後で直せるか：直せる（CPU の解析）
- 求める対応：抜いた予測の比べは延長の 5 点（K ∈ {1, 5, 10, 25, 50}）で行い，主の 3 点では行わないと書く．3 つの形の母数の数（1，2，2）と，抜く点が端か内側かで誤差を分けて出す

### [D3・D10] R_o は，切片をどう動かしても消えない o の分を引いていないので，0.5 の基準で「o の減り」を判定できない
- 重さ：記録する（結果を見る前に設計 2.4.4 節を直す）
- 該当箇所：`docs/exploratory-analyses.md:8017`，`:8019`，`:8025-8026`
- 問題：設計は「R_o = 6 対の平均の |o|（h2）÷ 6 対の平均の |o|（②）」とし，「W7 で R_o の組の中央値が 0.5 以下」なら「中心合わせは K 本が直す o の大部分を先に消す」と書く．対 (k, l) の o は，切片のずらし c で o_kl − (c_k − c_l)/s_kl に動く．c の自由度は 3 で対は 6 つなので，6 対の o を同時に 0 にはできず，どの切片でも残る |o| の下限（6 対の平均で）がある（9.3 節 D3 の例そのもの）．中心合わせも切片直しもこの下限より下には |o| を減らせない．下限が大きい組では，中心合わせが直せる分をすべて直しても R_o は 0.5 を超えうる．このとき設計の決まりは「o が小さくなったことでは説明できない」と書くことになり，結論が逆になる．同じ節の「6 対を同時に直せる切片」は `fit_class_bias`（交差エントロピー）で当てた切片で，|o| の平均を最小にする切片とは違うので，下限を与えない
- 計算の後で直せるか：直せる（② と h2 の全発話の点数と y が保存される．台本 302〜305 行，425〜428 行）
- 求める対応：② と h2 のそれぞれで，3 次元の c について 6 対の平均の |o − Δc/s| を最小にした値 floor を求め（E75 の項目 6 と同じ形で，損ではなく |o| で），R_o* =（|o|_h2 − floor_h2）/（|o|_② − floor_②）を主の比にする．R_o はそのまま並べる．分母（|o|_② − floor_②）が 0.05 未満の組は D11 と同じく外して数える．「6 対を同時に直せる切片」の解析は，交差エントロピーの切片と，6 対の位置の損（模型）を最小にする切片の両方で出し，差を「同時に直せない分」と「交差エントロピーと UAR の目的の違い」に分けて書く

### [D2] R_o（o の単位）から UAR の得について結論を書いており，2 つをつなぐ関係が示されない．比べる E13 の位置の損は別の分類器の値である
- 重さ：記録する
- 該当箇所：`docs/exploratory-analyses.md:8019`，`:8025-8026`，`exp/explore_pairs.py:91`
- 問題：判定は R_o（|o| の比）が 0.5 以下かどうかで「その後の切片直しの得は小さい」（UAR の量）と書く．|o| の減りと UAR の得の関係は，対ごとの模型 A(d, o) を通してしかつながらず，設計はその関係を測らない．また「E13 の位置の損と比べる」とあるが，E13 の d と o は `results/shift_<kind>/logits/<s>.npz`（`explore_pairs.py:91`．ずれの指標の台本の分類器）の点数から測った値で，E76 の ② の点数とは学習が違う
- 計算の後で直せるか：直せる
- 求める対応：② と h2 について，模型で予言した切片直しの得 mean_kl[A(d_kl, 0) − A(d_kl, o_kl)] を E76 の点数から計算し，実測の G_crit（h4 − ②）と G_crit_c（h5 − h2）と組ごとに並べる（予言と実測の比と，K=5 の組の中の順位相関．D5 に従い K を混ぜない）．E13 の位置の損と比べる箇所は，E76 の ② の点数で同じ定義を測り直した値と比べる

### [D1] K* と数え上げの定義が一意でない
- 重さ：記録する
- 該当箇所：`docs/exploratory-analyses.md:7959`，`:7960`，`:7967`
- 問題：(1)「K*：区間の下端が 0 を上回る最大の K」は，K=1 と 25 で下端が 0 を上回り K=5・10 で上回らない組では 25 になる．経緯の節の「K*（混ぜて上がる最大の K）」を「上がり続ける最後の K」と読むと 1 になる．どの K でも上回らない組と，K=全件で上回る組の扱い（値を付けないか，0 と「全件以上」として打ち切るか）も書かれていない．(2)「Holm の後に区間が 0 より上の組」は，Holm 法が補正するのは p 値で区間ではないので，「補正した p が 0.05 未満で平均が正」のことか「Holm の水準に合わせて広げた区間」のことかが決まらない
- 計算の後で直せるか：直せる
- 求める対応：K* を「K=1 から順に見て下端が 0 を上回り続ける最後の K」と「下端が 0 を上回る最大の K」の両方で出すか，一方に決めて書く．どの K でも上回らない組は「K* なし」として数え，全件で上回る組は打ち切りとして順位の上で最大にする（E75 の `KSTAR_RANK` と同じ点数の付け方に合わせる）．「Holm の後に区間が 0 より上」を「Holm で補正した両側 p が 0.05 未満で，平均が正」と書き直す

### [D11] 重みつきの量の分母が 0 になる場合の扱いが決まっていない
- 重さ：記録する
- 該当箇所：`docs/exploratory-analyses.md:7957`，`:7976`，`:8008`
- 問題：(1) 主の区間は「重みが 0 の感情を除いた感情で平均する」と感情の単位の扱いだけを決めている．IEMOCAP は話者が 10 人で，各反復のテストは 2 人である（台本と同じ `speaker_folds(k=5, seed=r)` で確かめた．IEMOCAP-impro の反復 0〜9 のテストの話者は [Ses01_M, Ses05_F]，[Ses02_M, Ses05_M]，[Ses03_M, Ses04_M]，[Ses03_F, Ses04_F]，[Ses01_F, Ses02_F] の 5 通りを 2 回ずつ繰り返す）．1 段目で 10 人を戻して 10 回引くと，ある反復のテストの 2 人がどちらも引かれない確率は (8/10)^10 ≈ 0.11 で，その反復の重みつき UAR は定まらない．(2) 性別ごとの値は「性別の中で話者を引く」とあるが，IEMOCAP-impro では反復 0〜9 のうち 8 つ，IEMOCAP-script では 4 つで，テストの 2 人が同じ性別である（同じ確かめ）．その反復では女性 − 男性の差が反復の中で定まらない．(3) q の区間で「同じ引き方で d_T を測り直す」とき，重みつきの d と o（重みつきの平均と分散）の定義が書かれていない．(4) n の実測は「曲線の範囲を超えたら打ち切り，比からは除く」（E32）なので，規則によって打ち切られる組の数が変わると，「n の実測の中央値が規則で 30% を超えて動く」の中央値は別の組の集合で取ることになる
- 計算の後で直せるか：直せる
- 求める対応：(1) テストの重みが 0 になった反復は，その引き方では平均から除き（引いた反復の残りで平均），除いた回数をターゲットごとに記録すると書く．(2) 性別の差は，反復ごとの差ではなく，反復 0〜9 のテストをまとめた性別ごとの重みつき UAR の差として定義し，各性別の話者の数（IEMOCAP は 5 人ずつ）を表に書く．(3) 重みつきの d・o を式で書く．(4) n の比べは，2 つの規則のどちらでも打ち切られない組に限った中央値を主にし，打ち切りの数を規則ごとに並べる

### [D5・D6] 「ターゲットの中の順位相関」の比べる 2 つの量が書かれておらず，言葉系では順位相関が 2〜3 点で計算される
- 重さ：記録する
- 該当箇所：`docs/exploratory-analyses.md:7996`
- 問題：設計は「ターゲットの間の比べ（D5）：順位相関は K ごと，ターゲットの中で取り，K を混ぜない」とだけ書き，何と何の順位相関か（例：組ごとの予言した n と測った n，e と利得）が無い．見出しの「ターゲットの間」と本文の「ターゲットの中で」も食い違う．ターゲットの中でソースを並べると，言葉系 4 種類では IEMOCAP の 2 群がターゲットのとき，同じコーパスの組を除いたソースは MOSEI と MELD の 2 つで，順位相関は ±1 しか取らない．MOSEI・MELD がターゲットのときも 3 つである．でたらめに並べたときの分布と比べないと，±1 や 0.5 の値を一致の証拠と読んでしまう（D6）
- 計算の後で直せるか：直せる
- 求める対応：比べる 2 つの量を書く．ターゲットの中の順位相関は，ソースの数が 4 以上のターゲットだけで計算し，ターゲットごとの値と，ソースの名前を並べ替えた基準（ターゲットの中で並べ替えて同じ集計をした分布）の上位 5% を並べる．ソースが 3 以下のターゲットは数だけ書く．順位相関とは別に，予言と実測の水準の比（中央値）を K ごとに出す（D5 の「水準のずれも示す」）

### [D8] 式 d_T(K) = D/√(1 + q/K) と，R_o・n の読みが置く仮定を測る表が設計に無い
- 重さ：記録する
- 該当箇所：`docs/exploratory-analyses.md` E76 7 節（8121〜8148 行．D8 の行が無い）
- 問題：設計は D2〜D5・D11 を対応表に挙げるが，D8（仮定，測る量，測り方，成り立つとみなす基準）の表が無い．E76 は新しい予言を置かないが，q と n と R_o の読みは下の仮定に立っている．E71 で E73 の仮定が実データで崩れたのと同じく，仮定が崩れたときに結論をどう書くかを先に決めておく必要がある
- 計算の後で直せるか：直せる（どの量も E76 の保存した点数と特徴から CPU で出る）
- 求める対応：次の表を設計の 2.4.3・2.4.4 節に足す（案）
