### [I1-a] 種類の平均（複数ターゲットの単位）の jackknife の自由度と和集合の規則が設計に無い
- 重さ：記録する（本番の結果を読む前に設計に書くこと）

- 問題：設計 2.4.0 節の jackknife の規則は「G_eff が 20 未満のターゲット」についての文で，種類の平均や手の比べのように複数のターゲットにまたがる単位の扱いが書かれていない．台本は，含まれるターゲットの G_eff の最小（IEMOCAP 9.2〜9.8，MELD 8.7）から自由度 7〜8 を取り，種類のすべての人物（A で 2,971 人）を 1 人ずつ抜いた SE に掛ける．種類はどれも IEMOCAP を含むので，種類の平均の区間はすべて和集合になる．これは独立な成分の和に対する Welch–Satterthwaite の自由度の下限で，区間を最も広くとる読みである．2.4.3 の「仮のターゲットの規則の K=1 の区間が 0 を含む」，2.4.4 の「G_crit_c の区間が 0 より上」，2.4.5 の「ほかのすべての手との差の区間が 0 より上」は種類の平均の区間で判定するので，この読みで判定が変わりうる．値は見ていない（読みを決める前に判定が変わるかを数えると，値を見て選ぶことになるので数えていない）
- 計算の後で直せるか：直せる．`jk_lo`・`jk_hi`・`boot_lo`・`boot_hi` が別の列に残るので，自由度を替えた区間も出せる．ただし読みを結果の後で選ぶと事前の決まりにならない

## 目録に無い種類の不備

- **引き方の種を単位ごとに分けると，単位をまたぐ比べの区間が出せない**．この台本は種類ごとに別の種で人物と反復を引くので，「A と AV の利得の差」のような種類をまたぐ差に話者を単位にした区間を付けられない（同じコーパスの同じ人物に，種類ごとに別の重みがかかる）．9.3 節の R に次の案を足す：「R12 話者を単位にした区間を作る解析では，比べうる単位（種類，生徒，手法）をまたいで同じ人物に同じ重みがかかるように，1 段目の重みをコーパスと人物だけで決める．単位ごとに種を変えない」
