## 手順 2：最終の区分の規則は none と手法，当たりと外れに対称か

対称に働く部分：
- `true_direction`（830〜837 行）は，1 つの比較の単位（n = K'(手法) − K'(none)）については 4 つの印の向きを正しく決める．手法の上の打ち切り（全件に置いた K' は本当より小さい → n は本当より小さい → 本当は「＋」），none の下の打ち切り（1 に置いた K' は本当より大きい → 本当は「＋」），手法の下の打ち切りと none の上の打ち切り（本当は「−」）．座標が小さいほど良い（位置）ときも `read_K` が曲線と値の符号を同時に反転するので（184〜185 行），印の意味は「良い側・悪い側」で同じであり，向きも同じになる．印は曲線の値だけで決まり右端の横軸に依らないので，2 つの右端の置き方で同じになる．
- `judge` の最終の区分（1186〜1199 行）は holds・fails・neg に同じ条件（3 つの版が同じ状態）を課す．全コーパスが読める族では 3 つの版のコーパスの集合と値が同じなので，最終の区分は readable の区分と同じになる．
- none を選んだ群と saerens・massbal の向きの座標は印を持たず読める（定義から 0）ので，all_extreme の版で動かない．

対称に働かない部分と，働かない部分は下の指摘 1〜3 に書く．要点は，(i) 3 つの版は「全部の読めないコーパスを記録した値に置く」と「全部を分かっている向きの極端に置く」の 2 つの角だけを見ており，向きの違うコーパスが混ざるときや K = 0 と K = 25 の比を取るときは，本当の値が取りうる範囲の端を見ていない，(ii) 差の量では成分の印を OR で束ねてから `true_direction` に通すので向きを逆に決める，(iii) あいまいの印と下の打ち切りを「向きが決まらない」「±10⁶ 本」に置くので，判定できない区分が必要以上に増える，の 3 つである．(i) と (ii) は当たりの側にも外れの側にも系統的には寄らないが，設計 3 節 10686 行が書く目的（読めないコーパスを外した偏りで区分が反対の側に出ないことを確かめる）を規則が満たさない．
