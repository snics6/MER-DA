## 目録に無い種類の不備

- **I19（案）区分を集計の段ごとに作るときは，同じ区間の規則を当てる．**単位の区分は百分位と jackknife の和集合，コーパスの区分は百分位だけ，のように段によって区間の規則が変わると，「正のコーパスの数」のような数え上げが単位の規則より緩くなる（E87 の対比の条件 (B)．指摘 2）．台本の確認では，区分を数える段ごとに，どの区間の規則で区分を作るかを書き出して設計と照らす．
