  ```

  reps.append(np.where(np.abs(b) >= BIG / 2, b, x + r * (b - x)))
  ```

  とする．倍率 r（≥ 1）は記録した複製 B と jackknife の半幅から作る（989〜992 行）．読めないコーパスでは，点の読みが上に打ち切られて x（点の上限）が 10⁶ に近い値（世界の平均や IEMOCAP の 2 群の平均で 10⁶/2，10⁶/4 など）になる一方，多くの抽出では打ち切られず b が有限の値になる．このとき x + r(b − x) ＝ b + (r − 1)(b − x) は，r > 1 で −(r − 1)·x の向きに大きく動き，U の複製が −10⁵ の桁の負の値になる．L の側では逆に +10⁵ の桁の正の値になる．どちらも判定に有利な側への移動であり，包絡の意味（判定に一番不利な側）が逆になる．`|b| ≥ 10⁶/2` の除外は b だけを見て x を見ないので，この場合を防がない．10⁶ を含まない場合でも，あいまいで x_L が記録した点 x より小さく，抽出では印が付かない（LB ＝ B）とき，広げた L の複製は広げた記録の複製より (r − 1)(x − x_L) だけ上に出る．

## 目録に無い種類の不備
- D19（案）：区間を広げる倍率（jackknife の幅に合わせる係数など）を，点の値の範囲や限り（打ち切りを置いた値，包絡）を持つ量に当てるときは，倍率を記録した複製と記録した点で決めて掛け，限りは掛けた後の複製に「抽出ごとの限り − 記録した複製」を足して作る．限りの点のまわりで掛けると，点だけが打ち切られたとき複製の符号が反転し，不利な側の包絡が有利な側に移る（E87 の関門 1 の第 5 版）．
- D20（案）：読みの範囲（最初と最後の読みの間など）を持たせる規則は，印の付いた読みにだけ当てるのか全部の読みに当てるのかを書く．同じ理由の範囲が印の無い読みにもあるなら，全部に当てるか，印の無い読みを点とみなすと明記する（E87 の関門 1 の第 5 版）．
