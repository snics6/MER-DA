## 手順 2：限りの定義は none と手法，当たりと外れ，足す側と引く側に対称か

対称に働く部分：
- `read_bounds` は none と手法に同じ `bounds_of` を当て，n の限りを lo(K'(手法)) − up(K'(none))，up(K'(手法)) − lo(K'(none)) で作る．none と手法で同じ規則である．
- 位置（小さいほど良い）は `read_K` が曲線と値の符号を同時に反転するので，限りの意味は「良い側・悪い側」で UAR・向きと同じになる．人工の値で位置の鏡像の曲線を読ませ，UAR の側と同じ読みと同じ印が出ることを確かめた（`bnd.py` の末尾）．
- 足す側と引く側：向き−位置（LB(dir) − UB(pos)），直接の差（lo(A) − up(B)），K をまたぐ比（f25L − 0.5·f0U と f25U − 0.5·f0L）のどれも，引く側の限りを逆の端から取っている．
- 当たりと外れ：P87-1〜3 と (A)(C) の各不等式は，それぞれ不利な側の包絡（L か U）で確かめている．外れの確かめは「外れのどれか 1 つの条件が包絡で成り立つ」で，設計 10686 行の「外れを決めた 1 つの条件」とは文言が違うが，どれか 1 つの外れの条件が包絡で成り立てば本当の値でも外れなので，論理として正しい．

対称に働かない部分は 2 つある（指摘 1・2）．どちらも当たりの側と外れの側の両方で確かめを甘くする．
- 族の複製を広げる処理（指摘 1）は L の包絡を上へ，U の包絡を下へ動かす．L を使う確かめ（P87-1 の当たり，P87-3 の外れ，P87-2 の当たりと外れ，(A)，(C)，教師の規則）も，U を使う確かめ（P87-1 の外れ，P87-3 の当たり，P87-2 の当たりと負，(A)）も通りやすくなる．
- 上限の限り（指摘 2）は，下の側では最初の読みの下の打ち切りを使って [0, …) に広げるのに，上の側では最後の読みの上の打ち切りを使わない．下と上で規則が対称でない．

### [C10] 族の複製を jackknife の幅まで広げる処理が，包絡では点の下限・上限を中心にするので，点が打ち切られたコーパスの複製の符号が反転し，最終の区分の確かめが逆の側へ通る
- 重さ：直してから進む
- 該当箇所：`exp/analyze_value_split_e87.py:986`（`b, x = cd[c][bkey], cd[c][pkey]`．env ＝ "L" なら `x` ＝ `pt_lo`，`b` ＝ `LB`），`:994`（`reps.append(np.where(np.abs(b) >= BIG / 2, b, x + r * (b - x)))`）；`docs/exploratory-analyses.md:10671`（「G_eff < 20 のコーパスの複製を点の値のまわりで jackknife の t 区間の半幅まで広げ」），`:10672`（包絡）
- 問題：
  - L の包絡では，コーパスの複製を `pt_lo + r·(LB − pt_lo)` に置く（r ≥ 1）．点の読みで none が上に打ち切られたコーパスでは，`pt_lo` は約 −10⁶ になる．抽出の多くで none が打ち切られなければ，その抽出の `LB` は有限の値（記録した複製と同じ値）である．`np.abs(b) >= BIG/2` の除外は `b` だけを見るので，この抽出は広げる処理に入り，`−10⁶ + r·(LB + 10⁶)` ＝ 約 (r − 1)·10⁶ の正の大きな値になる．下限の側に置くはずの複製が上限より上へ飛ぶ．U の包絡でも同じく，手法が点で上に打ち切られたコーパスは `pt_up` ＝ 10⁶ を中心にして，有限の `UB` の抽出が約 −(r − 1)·10⁶ に飛ぶ．
  - 人工の値で確かめた（`infl.py`・`infl2.py`）．族を 3 コーパス（読める 2 つは点 4 と −3，G_eff ≥ 20）と，読めない 1 つ（点 1，G_eff 9.5，jackknife の半幅 4，none は点で上に打ち切り，抽出の 99% は打ち切られない）にすると，台本の L の包絡の 2.5% 点は ＋3.34 で，`lo[med(0)_L] > 0` の当たりの確かめを通る．同じ複製を記録した点のまわりで広げると 2.5% 点は −2.91 で，確かめは通らない．`infl.py` の例では，読めないコーパスの打ち切られない抽出の L の複製は 1,080,024 本になり，抽出の 60% で L の複製が記録した複製を広げた値より大きかった．
  - 打ち切られない抽出でも，点があいまいで `pt_lo` が記録した点より小さいだけのとき，L の複製は (r − 1)·(記録した点 − `pt_lo`) だけ上へずれる．ずれの向きは常に「L は上へ，U は下へ」で，包絡が限りにならない．
  - この誤りが起きるのは G_eff < 20 で r > 1 のコーパスである．台帳の試走の記録では IEMOCAP の G_eff は 9.8・9.2 で，主の族（音声）に入る．点で打ち切られ抽出では打ち切られないコーパスは，点が曲線の端の近くにあるときに起きるので，読めないコーパスの中で珍しい場合ではない（推測．頻度は数えていない）．
  - 影響は当たりの側にも外れの側にも出る（手順 2）．最終の区分（`*_final`），`contrast_A_robust`・`contrast_C_robust`，`teacher_attrib_K*`（L の包絡．1250 行の `family_stats(..., env="L")` も既定で広げる）のどれもこの複製を使う．

### [C10] 上限の限りが，最初の読みの上の打ち切りの印だけを見るので，整える前の曲線が右端で値より下に戻る読み（最後の読みが上に打ち切られる読み）の上限を K_all か 1 に置く
- 重さ：直してから進む
- 該当箇所：`exp/analyze_value_split_e87.py:554-561`（`bounds_of`：`up_b = np.where(am, np.maximum(Kf, Kl), Kf)`，`up_b = np.where(hi, BIG, up_b)`．`hi` は最初の読みの印），`:566-569`（`read_bounds` は最後の読み `read_K(..., adjust="last")[0]` の K だけを受け取り，その上の打ち切りの印を捨てる）；`docs/exploratory-analyses.md:10661`（「あいまい → 最初の読み…と最後の読み（右からの累積の最小で整えた曲線で読む）の間」，「上の打ち切り → K' ≥ K_all（上限は 10⁶ 本に置く）」）
- 問題：
  - 右からの累積の最小で整えた曲線は，整える前の曲線の右端の値（K = 全件の値）で終わる．整える前の曲線が途中で値 v に届き，右端で v より下に戻ると，最後の読みは v に届かず，`read_K` は K_all に置いて上の打ち切りの印を立てる．`bounds_of` はこの印を使わないので，上限は K_all になる．同じ v が最初から全件の値より上にあるとき（最初の読みが上に打ち切り）は上限 10⁶ にするので，「全件の値より良い」読みの上限が，途中で曲線が v に届いたかどうかで 10⁶ と K_all に分かれる．
