  - 第 7b 版の試走の記録（2.4×10⁻⁴ 本）と同じ種類である．判定は帯（0.5·K 本以上）と 0 との比較なので，1 本の 1,000 分の 1 未満の差は判定を変えない．
- 計算の後で直せるか：直せる（直す必要は無い）
- 求める対応：要らない．直接の差の族で「L ≤ T ≤ U」を書くときは「float32 の丸め（10⁻³ 本未満）を除いて」と書く

## 目録に無い種類の不備

- **I31（案）「結果の表の列の有無が結果の値に依る」**：判定の表を行の辞書から作り，ある条件のときだけ列のキーを書くと，その条件が 1 行も成り立たない計算では列が表から消える．計算の後に読む台本が列の名前を決め打ちしていると，落ちるか，ほかの列を誤って読む．台本の確認では，判定の表の列を固定の一覧で並べ直すか，`reindex(columns=...)` で全列を出すことを求める．計算の後の点検では，作り直した表と保存した表の列の集合が同じかを確かめる．
