### [C10] 向き − 位置の直接の差で，片方が none を選んだ群は none の読みの印が抽出の印に入らず，区間が使えると出る
- 重さ：記録する
- 該当箇所：`exp/analyze_value_split_e87.py:898-905`（`mmask_of`：「|mmask の無い量（向き − 位置，ΔS）は |mask の手法の 3 ビットを使う」），`:653`（none を選んだ群の `mask` は 0），`:693`（向き − 位置の `mask` は dir と pos の `mask` の和）；`docs/exploratory-analyses.md:10661`（「向き − 位置の差と ΔS の直接の差では，手法だけの印の配列が無いので，印の配列の手法の 3 ビットを使う」）
- 問題：B が none を選んだ群では，直接の差 (dir − pos)_A − (dir − pos)_B ＝ n_A(dir) − n_A(pos) で，none の読みは消えない．台本は A の `|mask` から手法の 3 ビットだけを取り，B（none を選んだ群）の `|mask` は 0 なので，none の打ち切りとあいまいの印が抽出の印に入らない．人工の値（`direct7c.py` の場合 8．none は全件の値より良く，抽出の全部で上に打ち切り，oursx は曲線の中，abl_ownK は none を選ぶ）で，oursx − abl_ownK の dir_minus_pos は 抽出の印の割合 0.000，`interval_ok` ＝ 真，区分「判定できない」になった．同じ群の none − oursx の dir_minus_pos の単位は印の割合 1.00，「区間が使えない」である．点の限り（[−999,500, 999,500]）と `is_readable`（偽）は n の限りと読めるかから作るので正しい．
- 判定に届くか：届かない．`judge` が直接の差を使うのは教師の規則と abl_refb・abl_ref0 の文で，どちらも dir だけを読む（1309 行の `CORP_d.get((name, fam, K_, rule, dirq, uv))`）．dir_minus_pos の直接の差は `direct.csv`・`direct_corpus.csv`・`direct_family.csv` の記述の行にだけ出る．none を選んだ行は abl_ownK 1 件（AV の世界，CREMA-D，映像，K = 25．oursx − abl_ownK と abl_refb − abl_ownK に入る）と abl_ref0 3 件（abl_ref0 − abl_ownK の A の側）である．両方が手法を選んだ群（場合 9）では，点の限りは none の幅を 2 回受けて [−1,999,000, 1,999,000] になり，`is_readable` は none の印で偽になる（保守側）が，抽出の印は手法の 3 ビットだけになる．点の限りと抽出の印で none の扱いが揃っていない
- 計算の後で直せるか：直せる（`boot_units.npz` の dir と pos の `|mask`・`|mmask` と `units.csv` の `same_by_definition` から作り直せる）
