### [I1] 1．none を選んだ群では，直接の差の「手法の読み」を none の最初の読みの点に置き，印を付けない
- 重さ：直してから進む
- 該当箇所：`exp/analyze_value_split_e87.py:619`，`:626`，`:643`，`:763`，`:859–862`，`:872`，`:880–885`（読んだうえで流して確かめた）
  ```

      n, n_lo, n_up, m_lo, m_up = 0.0, 0.0, 0.0, float(Kn), float(Kn)
      fl = dict(zero_flags)
  ...

  ...
  ```

- 問題：選び方が none を選んだ群（`chT is None`）では，手法の読みは none の読みそのものである．直接の差 A − B ＝ K'(A) − K'(B) で B が none を選んだなら，B の側の限りは none の読みの限り [lo(K'none), up(K'none)] で，印も none の印である．台本は (i) 点の限りを none の最初の読みの点 Kn に置く（幅 0），(ii) `method_readable` を真にする，(iii) 抽出の印に none の印を入れない（定義から 0 の枝は抽出の読みを作らず，直接の差の印は手法の 3 種類だけ），(iv) `|mlo` を保存しないので，抽出の限りだけが lo(A) − up(B) に戻る（none の幅を含む保守側）．このため，none の読みに印があっても直接の差の行が「読める」になり，点の限りと抽出の限りの作り方が食い違う．本番の範囲で該当する群は 6 つ（fuse-audio-video-text の abl_ref0：MOSEI K25，MELD K5・K25．kd：MELD video K0．fuse-audio-video の groupB：CREMA-D audio K5．abl_ownK：CREMA-D video K25）．試走で 6 群を流すと，none の点の読み 84 個のうち 30 個に印があった．ただし印のある行はどれも相手の手法の読みにも印があり，直接の差はすでに読めなかった．読めて区間が使える直接の差の行で none の抽出の印が 2.5% を超えるものは 0 だった（B ＝ 50 の試走．B ＝ 1,000 では確かめていない）．教師に帰す規則の頑健版（`*_positive_robust_K*`）は抽出の L を使い，その抽出の限りは none の幅を含む lo(A) − up(B) に戻るので，この誤りで通りやすくはならない
