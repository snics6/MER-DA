## 指摘

### [D1・D11] 1．3 つの版で同じ側という規則は，本当の本数が取りうる範囲の最悪の置き方を調べていないので，向きの混ざった（族，K），K をまたぐ比，複数の K や条件の「または」で決まる区分で，偏りに沿う結果を守らない
- 重さ：直してから進む
- 該当箇所：`docs/exploratory-analyses.md:10672`（族の版），`:10686`（最終の区分）；`exp/analyze_value_split_e87.py:904-956`（`family_stats` の extreme），`:1072-1085`（P87-2 の合わせ方），`:1177-1204`（`judge` の最終の区分）
- 問題：設計は「読めないコーパスを外すと族の中央値が偏る…そこで all の版（打ち切りを端に置く）と all_extreme の版（分かっている向きの極端に置く）でも同じ側に出たときだけ，最終の区分を当たり・外れ・負にする」（10686 行）と書く．読めないコーパスの本当の値は，向きが＋なら [記録した値, +∞)，−なら (−∞, 記録した値] にある．族の中央値は各コーパスの値について単調なので，ある不等式が本当の値の全範囲で成り立つかは，その不等式に不利な端（角）で調べれば決まる．all（全部を記録した値）と all_extreme（全部を ±10⁶）がその角になるのは，読めないコーパスの向きが 1 つにそろい，量が 1 つの K の中央値だけで決まるときに限る．台本の関数で次の 3 つの反例を確かめた（`chk_v4b.py`．値は人工）．
  - (i) 向きの混ざった（族，K）．K = 5 の位置で，読める A ＝ 0，B ＝ 1，C ＝ 3，D は＋（記録 −5），E は−（記録 3.9）．readable・all・all_extreme の 3 つとも P87-2 の K = 5 は「当たり」（帯 ±2.5）．all_extreme は D を +10⁶，E を −10⁶ に置くので中央値は動かない．ところが D ＝ 10，E ＝ 3.9 は印と矛盾しない本当の値で，このとき中央値は 3 になり K = 5 は「外れ」になる．中央値を上に動かす角は「＋を +∞，−を記録した値」で，all_extreme の「−を −∞」がこの角を打ち消す．
  - (ii) K をまたぐ比．P87-1 で，E が K = 0（記録 15）と K = 25（記録 3）の両方で＋．3 つの版とも「外れ」（hi[med(25) − 0.5·med(0)] < 0）．all_extreme は K = 0 の E も +10⁶ に置くので med(0) も上がり，差は負のままである．E の本当の値が K = 0 で 15（記録どおり），K = 25 で大きい場合，差は正になり区分は「当たり」になる．差 med(25) − 0.5·med(0) は K = 25 の値について増え，K = 0 の値について減るので，差の最大の角は「K = 25 は上の角，K = 0 は下の角」であり，all_extreme は両方を上の角に置いている．
  - (iii) 「または」で決まる区分．P87-2 は「どちらかの K が外れなら外れ」で，`judge` は合わせた後の `P87_2_status` を版の間で比べる（1183・1188 行）．K = 5 で D・E が＋，K = 25 で D・E が−の例では，readable は K = 25 だけで外れ，all は K = 25 だけで外れ，all_extreme は K = 5 だけで外れになり，3 つとも合わせた区分が「外れ」なので最終の区分は「外れ」になる．しかし K = 5 で D・E を記録した値，K = 25 で D・E を −100 に置くと（どちらも印と矛盾しない），両方の K で「当たり」になる．同じことは P87-1・P87-3 の外れ（hi[med(0)] ≤ 0 または差の条件）にも起こり，版ごとに別の条件で外れても最終の区分は「外れ」になる．3 節の「合わせた読み」（10688 行）はどちらの条件で外れたかで文を変えるので，条件が版の間でそろわないと文が決まらない．
  
  前回の私の案（上の打ち切りで外れたコーパスがあれば偏りに沿う結果を判定できないとする）と比べると，第 4 版の規則は向きが 1 つにそろう 1 つの K の量では正しく，案より判定できる場合が多い．一方で上の 3 つの場合では案も第 4 版も最悪の置き方を調べていない（案は none の上の打ち切りによる−の向きを扱っていなかった）．
- 計算の後で直せるか：直せる．コーパスの値の複製は単位の複製（`boot_units.npz`）の平均で作り直せ，向きは `corpus.csv` の `true_direction` と印の列にある．ただし最終の区分の規則は値を見る前に書く必要がある．
- 求める対応：3 節の最終の区分と `judge` を次の形にする．
  1. 不等式ごとに，その不等式に不利な角で族の統計量を作る．上側の不等式（hi ≤ b，hi ≤ 0，hi < 0）は「＋を +10⁶，−を記録した値」，下側の不等式（lo ≥ −b，lo > 0，lo ≥ 0）は「＋を記録した値，−を −10⁶」．向きが決まらないコーパスは両方の端に置く（上側の角では +10⁶，下側の角では −10⁶）．
  2. K をまたぐ差 med(25) − 0.5·med(0) は，上側の不等式では K = 25 を上の角・K = 0 を下の角に，下側の不等式では K = 25 を下の角・K = 0 を上の角に置く．
  3. 当たり（「かつ」の条件）は，各条件がそれぞれ不利な角で成り立つときに確定とする．外れ・負（「または」の条件）は，同じ 1 つの条件（P87-2 では同じ K）が不利な角で成り立つときに確定とし，どの条件で確定したかを列に残す（「合わせた読み」の文の分け方に使う）．
  4. readable の版の区分が確定と同じ側のときだけ最終の区分にする（今の規則と同じ）．all の版は角の 1 つとして残してよい．
  この形にすれば，最終の区分は「読めないコーパスの本当の値が印と矛盾しないどこにあっても同じ」ことを意味する．設計 2.4 節の all_extreme の説明（10672 行）と仮定 2 の行（10699 行）も合わせて直す．
