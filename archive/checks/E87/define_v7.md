## 包絡の新しい合成（依頼の 3）

2.4 節（10672 行）の定義は「T ＝ x₀ ＋ r·(B − x₀)，L ＝ x₀ ＋ r·(LB − x₀)，U ＝ x₀ ＋ r·(UB − x₀)．こうすると抽出ごとに L ≤ T ≤ U が保たれ，限りの幅にも倍率が掛かる」である．台本は 1028 行の `reps.append(x0 + r * ((b0 if env is None else cd[c][bkey]) - x0))` で，x₀ は記録した点 `cd[c]["point"]`，r は記録した複製の百分位の半幅と jackknife の半幅から決める（1020〜1026 行）．設計と台本は一致する．

1. **式との一致**：`chk_v7.py` の 1 コーパスの族で，G_eff ＝ 10・倍率 2，G_eff ＝ 10・倍率 1（jackknife の半幅が百分位の半幅の 0.5 倍），G_eff ＝ 100・倍率 1，G_eff ＝ 10・倍率 50 の 4 通り × 記録・L・U の 12 通りで，族の複製と式の値の差の最大は 0 であった．
2. **抽出ごとの L ≤ T ≤ U**：r > 0 なので，L ≤ T は抽出ごとに LB ≤ B と同値である．台本の LB・UB は抽出ごとに LB ≤ B ≤ UB を満たす（`bounds_of` の下限は最初の読み以下，上限は最初の読み以上．none を選んだ群は 0．直接の差は lo(K'm_A) − up(K'm_B) ≤ K'm_A − K'm_B）．上の 4 通りと，5 コーパスの族（倍率 1.0・1.5・2.0・2.5・3.0，2 コーパスの抽出の 20% に −5×10⁵，30% に 10⁶）で，全抽出で L ≤ T と T ≤ U が成り立った．族の複製は各コーパスの値の中央値なので，コーパスごとに L ≤ T なら族でも L ≤ T である．
3. **±10⁶ の抽出の意味**：倍率 r の族では，10⁶ の抽出は x₀ ＋ r·(10⁶ − x₀) になる（倍率 2 で 1,999,993，倍率 50 で 49,999,657）．値の大きさに意味は無く，この値の役目は「どの有限の読みより不利な側に置く」ことだけである．有限の読みの限りは K = 全件の横軸（MOSEI で約 930 本）の数倍以内なので，倍率を掛けても順位は変わらない．倍率 50 でも有限の抽出の L は −416.5，U は 474.2 で，10⁶ の抽出とは桁が違った．
