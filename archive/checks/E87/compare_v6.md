## 手順 2：限りの定義は none と手法，当たりと外れ，足す側と引く側に対称か

対称に働くことを確かめた部分：
- **読みの限り**（`bnd6.py`）：単調な曲線，途中で戻る曲線，右端で値より下に戻る曲線，下に打ち切られて一度だけ下に横切る曲線，上と下の打ち切り，平らな区間の 9 通りで，UAR の向きの曲線と，符号を反転した位置の向きの曲線（小さいほど良い）が同じ読み・同じ印・同じ限りを出した．無作為の曲線 20,000 本で，none と手法の値を入れ替えると n の限りが符号を反転して入れ替わり（非対称 0 件），下限 ≤ 記録した n ≤ 上限が全部成り立った．整える前の曲線が値に等しくなる K（全部の交点．端の外は打ち切りの代表の値）は 27,954 点のすべてが [下限，上限] に入った．
- **包絡**（`infl6.py`）：広げる処理は L・U の両側に同じ倍率を同じ中心で掛け，抽出ごとに L ≤ 記録 ≤ U を保つ．L を使う確かめ（P87-1 の当たり，P87-3 の外れ，P87-2 の下端，(A)，(C)，教師の規則）と U を使う確かめ（P87-1 の外れ，P87-3 の当たり，P87-2 の上端，(A)）のどちらにも偏らない．
- **当たりと外れ**：`robust`（1091〜1101 行）は当たりの条件をすべて，外れの条件はどれか 1 つを包絡で確かめ，成り立った条件の名前を `*_final_by` に残す．設計 3 節 10686 行と一致する．
- **足す側と引く側**：n（lo(K'm) − up(K'n)），向き − 位置（LB(dir) − UB(pos)），K をまたぐ比（f25L − 0.5·f0U と f25U − 0.5·f0L）は，どれも引く側の限りを逆の端から取る．

対称でない部分は 1 つある（指摘 1）．直接の差で，手法が none 以外を選んだ群は手法の読みの限りと印を使うのに，none を選んだ群は none の読みを幅の無い点として扱い，印を捨てる．

記録として残す点：あいまいの印を「最後の読みが最初の読みより右」に広げたので，整える前の曲線が値を 1 回しか横切らない読みにも印が付く（`bnd6.py` の「single crossing, dip elsewhere」：曲線 30, 40, 50, 45, 52, 54, 56 に値 42 を当てると，交点は 1 つ（5.74）で，限りは [5.74, 6.60]，印は真）．本当の値を含む側に広げる変更なので結論を誤らせない．読める単位と区間が使える単位が減る向きで，none と手法に同じく当たる．
