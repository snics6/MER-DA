## 指摘

### [D5・D1] P87-1・P87-3 と対比の条件 (A) は，K = 0 と K = 25 の族の中央値を別々の読めるコーパスの集合で取るので，「K とともに減る・残る」がコーパスの入れ替わりで生じうる
- 重さ：直してから進む
- 該当箇所：`docs/exploratory-analyses.md:10668`，`:10678`，`:10680`，`:10681`；`exp/analyze_value_split_e87.py:677-679`，`:729-731`，`:739`，`:773`，`:780`
- 問題：設計は med_x(K) を「族の読めるコーパスの n_x の中央値」と K ごとに定義し（10668 行），P87-1 は「lo[med_dir(25) − 0.5·med_dir(0)] ≥ 0」で判定する（10678 行）．台本は K と座標ごとに読めるコーパスを選び（679 行 `cps = sorted(c for c in cv_ if cv_[c]["readable"])`），`q_of` で K = 0 と K = 25 の族の複製を別々に取り出し，`diff = d25["b"] - HOLD_RATIO * d0["b"]`（739 行）で引く．音声の族は 5 コーパスで 3 コーパスあれば判定するので，たとえば K = 0 は {IEMOCAP，MELD，MOSEI，CREMA-D}，K = 25 は {IEMOCAP，AFEW，CREMA-D} の中央値どうしを比べることが規則の上で起こる．K = 25 で読めなくなるのは上の打ち切り（none が全件のターゲットだけの分類器を超える）と平らに落ちた読みで，これはコーパスの性質（テストの大きさ，曲線の平らさ）で決まる．そのため「K = 25 で残る」「K = 25 で減る」の判定に，K によらないコーパスの違いが入る．P87-3 と (A) の med_pos(25) − 0.5·med_pos(0) も同じ作りである．P87-2 の n_dir − n_pos は同じ単位の中の差で，両方が読める単位だけを使う（台本 524 行）ので，この問題は無い．
- 計算の後で直せるか：直せる．単位の複製は `boot_units.npz` に残るので，族の複製は後から作り直せる．ただし，どちらの集合で判定するかは値を見る前に決める必要がある．
- 求める対応：3 節に「K を比べる予言（P87-1，P87-3，(A)）は，比べる 2 つの K の両方で読めるコーパスだけで中央値を取る（対にした集合）．集合が max(2, ⌈n/2⌉) 未満なら判定できない」と書き，`judge` で d0・d25（u0・u25，p0・p25）を同じ `cps` で作り直す．K ごとの集合で取った今の版は感度として並べる．あわせて，対にした集合の上で中央値の差を取るか，コーパスごとの n(25) − 0.5·n(0) の中央値を取るかを 1 つに決めて書く（後者のほうが対の比較になる）．

### [D5・D6] P87-2 は分解能の条件を満たさないときに「外れ」になり，負の位置の分も「消える」に数える．対比の条件 (A) の後半は位置の分がもともと無い場合を「消える」と書かせる
- 重さ：直してから進む
- 該当箇所：`docs/exploratory-analyses.md:10679`，`:10681`，`:10684`；`exp/analyze_value_split_e87.py:756`，`:760-764`，`:780`
- 問題：(1) 設計は hi[med_pos(K)] ≤ 0.5·K を「分解能の条件」と呼ぶ（10679 行）が，満たさないときの区分を書かず，「判定できない」の規則（10684 行）にも入れていない．台本は 2 つの条件の論理積を `P87_2_holds` にする（760〜762 行）ので，分解能が足りないだけの族は「外れ」になる．分解能が足りないことは位置の分が残る証拠ではない．逆向きの証拠（位置の分が残る）は lo[med_pos(K)] > 0 である．(2) hi[med_pos(K)] ≤ 0.5·K は上の端だけを抑えるので，手法が位置を悪くした族（n_pos が大きく負）も満たす．「位置の分は消える」は 0 の近くにあることを言う文なので，負の位置の分は別の結果として書く必要がある．(3) P87-2 は「n_dir − n_pos > 0」を条件に含む．向きの分も 0 に近い族では，位置の分が消えていても P87-2 は外れる．予言の名前「位置の分は K ≥ 5 で消える」と，判定する内容「位置の分は 0.5·K 以下で，向きの分より小さい」が一致しない．(4) (A) の後半「hi[med_pos(0)] ≤ 0」は K = 0 で位置の分が無いことを言う．このとき「向きは残り，位置は消える」と書くと，K = 0 にあった位置の分が K ≥ 5 で無くなったと読める．

- 求める対応：P87-2 を K = 5 と 25 のそれぞれで次の 4 つに分けると 3 節に書き，台本の `judge` に区分の列を足す．「当たり」：lo[med(n_dir − n_pos)] > 0 かつ −0.5·K ≤ lo[med_pos] かつ hi[med_pos] ≤ 0.5·K．「外れ（位置の分が残る）」：lo[med_pos] > 0 かつ lo[med(n_dir − n_pos)] ≤ 0．「負（手法が位置を悪くした）」：hi[med_pos] < 0 で lo[med_pos] < −0.5·K．それ以外は「判定できない（分解能が足りない）」．下の端の幅 −0.5·K は上と同じ大きさにそろえた案で，別の値にするなら値を見る前に決める．予言の名前を「位置の分は K ≥ 5 で 0.5·K 本以内に収まり，向きの分より小さい」に直す．(A) の後半が成り立って前半が成り立たないときは，対比の文を「向きは K = 25 でも残り，位置の分は K = 0 から認められない」と書くと決める．
