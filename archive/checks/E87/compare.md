## 指摘

### [C1・C10・C8] 題と「合わせた読み」は換算本数を疑似ラベルのモデルの価値として書くが，判定する量は oursx 全体の価値で，教師の寄与を分ける比較は判定に使わず，直接の差も帰属の規則も無い
- 重さ：直してから進む
- 該当箇所：`docs/exploratory-analyses.md:10632`（題「疑似ラベルのモデルの価値（ターゲットのラベル何本ぶん）を，向きの分と位置の分に分ける」），`:10636`（研究者の見方「他のモダリティの予測は，向きだけを持つラベルである」），`:10669`（「比較相手（記述．判定には使わない）」），`:10680`（合わせた読み「P87-1 が外れれば，向きの分も減るので『向きだけのラベル』の見方はこの形では支持されない」），`:10681`（「比較相手の見込み（当否は判定しない）…外れれば記述に書く」）；`exp/analyze_value_split_e87.py:42-43`（`COMPARISONS`，`MAIN_COMP = "none-oursx"`），`:538`（`is_main_judgment` は none-oursx だけ）
- 問題：n_x ＝ K'_x(oursx) − K'_x(none) は，oursx が none に足すもの全部（教師 kept，ラベル無しの候補を学習に足すこと，bal・raw・hard の重みづけ，総重み，仮のターゲットでの選択）の価値である．1 節と 3 節の合わせた読みは，この量を「向きだけを持つラベル」という疑似ラベル（教師）についての見方の当否に使う．しかし次の 2 つの読みを区別する比較が判定に入っていない．(i) 教師を自分の none[K] に替えた abl_ownK でも n_dir が K = 0 で正になり K = 25 まで残るなら，向きの価値は「ラベル無しの候補を疑似ラベルで足すこと」一般の性質であり，教師が運ぶ情報には帰せない．(ii) 教師を使わない groupB で同じ形が出る場合も同じである．設計は abl_ownK と groupB の見込みを書くが「当否は判定しない」「外れれば記述に書く」とするだけで，外れたときに主の読みをどう限るかを書いていない．C10 は「〜に帰せる／帰せない」の規則を比較相手が提案と何を共有し何を欠くかの表から導くことを求める．上の表から，abl_ownK は oursx と候補・重みづけ・総重みの作りを共有し教師だけを欠く行であり，教師の寄与を測る差の内訳の版（C1）にあたる．Snorkel DryBell（Bach ほか 2019．report_C 1.2 節．表 3）も，配備できない資源から作った弱いラベルの価値を，配備できる特徴だけの弱いラベルと並べて示しており，abl_ownK はこの対照にあたる．また，教師 kept はどれも配備する分類器自身のモダリティを含む融合の予測である（`chosen.csv` の param の先頭．4 節 10703 行も同じことを書く）．1 節の「他のモダリティの予測」と，計算する教師が一致しない（C8）．
- 計算の後で直せるか：計算は直せる．台本は（世界，コーパス）ごとに 1 回だけ `E.boot_draws` を呼び，同じ抽出を全比較で使い（`exp/analyze_value_split_e87.py:238`），比較ごとの複製を `boot_units.npz` に保存する（`:476-480`，`:666`）ので，oursx と abl_ownK の対になった差の区間は後から出せる．帰属の規則は値を見た後に書くと L2 の「結果を見てから足した規則」になるので，計算の後では直せない．
- 求める対応：(1) 3 節に，値を見る前に帰属の規則を書く．案：「教師に帰すのは，oursx − abl_ownK の n_dir の直接の差（同じ抽出で対にした差の区間）が音声の族の中央値で正で，かつ abl_ownK が P87-1 の基準を満たさないときに限る．abl_ownK か groupB が P87-1 の基準を満たすなら，向きの価値は手法の価値として書き，疑似ラベルのモデル（教師）の価値とは書かない」．(2) 台本に `none-oursx` と `none-abl_ownK`（あわせて `none-groupB`）の直接の差の単位の行を足す（`docs/methods.md` 9.3 の S14 と同じ扱い）．(3) 題と 2 節の量の名前を「手法（oursx）が none に足す価値」にするか，(1) の規則を満たした場合に限って「疑似ラベルのモデルの価値」と書く，と 3 節に書く．(4) 1 節の見方の「他のモダリティの予測」と計算する教師（自身のモダリティを含む融合）の違いを，合わせた読みの文の中に書く（例：「配備する分類器自身のモダリティを含む融合の予測を疑似ラベルにしたとき」）．

### [C4] 位置の座標の標準の比較相手（ラベルシフトの補正．Saerens の EM と出力の釣り合い直し）が保存済みなのに入っていない．外す理由も書いていない

## 手順 3：主張の種類と標準の比較相手

- 主張の種類：E87 は，半教師ありの DA（ソースのラベル，クラスあたり K 本，ラベル無しのターゲットの候補．`docs/related-work.md` 1.15 節）の設定で，モダリティをまたぐ蒸留（同 1.11・1.12 節）の価値を，ターゲットだけのラベルの本数に換算し，向きと位置に分ける記述の解析である．手法の優劣ではなく，価値の換算と分解を主張する．
- `docs/related-work.md` と report_C で確かめたこと：換算本数の測り方の先例は CLIP（凍結特徴の上のロジスティック回帰の学習曲線で読む）と Snorkel DryBell（手で付けたラベルの学習曲線で読み，配備できる特徴だけの弱いラベルと並べる．表 3）である（report_C 1.2 節．◎）．E87 の物差し（E76 の ①）は CLIP と同じ形である．DryBell の「配備できる特徴だけの弱いラベル」にあたる行は abl_ownK で，E87 に入っているが判定に使わない（上の [C1・C10・C8]）．位置の補正の標準は Saerens ほか 2002 の EM と BBSE（report_C 1.3 節．related-work 1.11 節）で，E77 の saerens・massbal の行として保存されているが E87 に入っていない（上の [C4]）．教師を使わないラベル無しの手法（自己訓練，エントロピー最小化，IM，T3A，LP，CORAL，DANN，MME）は groupB として入っている．温度つきの蒸留は kd として，同じ教師で入っている．
- ウェブで確かめたこと：Oliver ほか，"Realistic Evaluation of Deep Semi-Supervised Learning Algorithms"，NeurIPS 2018（arXiv 1804.09170）は，ラベル無しを使わない強い基準と同じ調整の予算で比べることを求める．E87 では none（ラベル無しを使わない）を基準にし，全比較相手を同じ選び方で調整しているので，この求めは満たす．確かめた水準は検索結果の要約までで，本文は開いていない．
- 結論：手法の価値の換算としては標準の比較相手がそろっている．疑似ラベルのモデル（教師）の価値として書くには，DryBell の形の対照（abl_ownK）を判定に使う必要がある．位置の分の出どころを書くなら，ラベルシフトの補正（saerens，massbal）を並べる必要がある．

### [新] 「向きの分は残り，位置の分は消える」という 2 つの成分の対比を，成分ごとに違う基準で判定する
- 重さ：直してから進む
- 該当箇所：`docs/exploratory-analyses.md:10677`（P87-1：中央値の比 n_dir(25) ≥ 0.5 × n_dir(0)），`:10678`（P87-2：区間が 0 より上の単位が半数未満），`:10680`（合わせた読み「位置の分…が消えるためで，向きの分は残る」），`:10705`（「区間が 0 を含む単位は『判定できない』になる．…これが予言どおりの振る舞いである」）；`exp/analyze_value_split_e87.py:540-551`
- 問題：向きが「残る」は点の値の中央値の比で判定し，位置が「消える」は「区間が 0 より上の単位が半数未満」で判定する．後者は区間が広いほど当たりやすい（検出力が低いと「消える」が当たる）．単位は 8 つ（独立なコーパスは 5）で，換算本数の区間は打ち切りと log K の補間で広がりうるので，向きの分を P87-2 と同じ基準で判定すると，向きの分も「消える」に当たる可能性がある（推測．値は見ていない）．その場合でも合わせた読みは「位置は消え，向きは残る」と書くことになり，2 つの成分の差を示したことにならない．査読者は「向きと位置で違う基準を当てた」と指摘できる．
- 計算の後で直せるか：計算は直せる（`summary.csv` は座標ごとに中央値と区分の数を持つ）．ただし対比の規則を値を見た後に足すと L2 になるので，規則は計算の前に書く必要がある
- 求める対応：3 節に，対比の文を書く条件を値を見る前に足す．案：「合わせた読みの『向きは残り位置は消える』は，(a) 同じ中央値の比の基準を n_pos にも当てて n_pos(K=25) < 0.5 × n_pos(K=0) か n_pos(K=0) ≤ 0，かつ (b) P87-2 と同じ区間の基準を n_dir にも当てて K = 5, 25 で n_dir が『正』の単位が半数以上，の両方が成り立つときに限って書く．どちらかが成り立たなければ，成分ごとの結果を並べるだけにする」．台本の `judgments.csv` にこの 2 つの交差の判定の列を足す．
- `docs/methods.md` 9.3 節に足す項目の案：「C14 2 つの成分（向きと位置，部品 A と部品 B）の対比を主張するときは，『残る』『消える』を同じ判定の基準（点の値の比か区間の区分の数）で両方の成分に当てる．『消える』を区間が 0 を含むことで判定するなら，同じ基準で『残る』側も判定し，検出力の差で対比が生まれていないかを確かめる（E87 の関門 1）」．

### [新] 換算本数の K 間の比較は物差しの曲線の傾きに依るので，座標の差そのもの（ΔS）を並べる計画が無い
- 重さ：記録する
- 該当箇所：`docs/exploratory-analyses.md:10677`・`:10679`（P87-1・P87-3 は n_x を K = 0 と K = 25 で比べる），`:10657`（log K について線形に補う）；`exp/analyze_value_split_e87.py:427-432`（`values_rep.csv` は `S_*_none`・`S_*_method` を持つ）
- 問題：log K で線形に補う物差しでは，同じ点数の差でも none の位置が曲線の右にあるほど多くの本数に換算される（K 単位では Δ本数 ≈ K × Δlog K）．K = 25 の none は曲線の右寄りに乗るので，n_x(K=25) は同じ点数の差でも K = 0 より大きく出やすい．この向きは P87-1（向きが残る）を当たりやすくし，P87-3（UAR で読んだ分が減る）を当たりにくくする．座標ごとに曲線の傾きが違うと，向きと UAR の比較にも同じ偏りが入る．Hernandez ほか 2021 は換算した量と倍率（換算した量 ÷ 本物の量）を分けて書いている（report_C 1.2 節）．
- 計算の後で直せるか：直せる（`values_rep.csv` の点数から出せる）
- 求める対応：記述として，単位ごとの ΔS_x ＝ S_x(oursx) − S_x(none) の中央値を n_x と同じ表に並べる計画を 2 節に書く．これは定義の検査（`gate-define`，D2）と重なるので，そちらの判断に合わせる．
- `docs/methods.md` 9.3 節に足す項目の案：「D19 換算本数（学習曲線で読んだ本数）を K の間や座標の間で比べるときは，物差しの曲線の傾きの違いが比較に入るので，換算する前の点数の差を並べる（E87 の関門 1）」．
