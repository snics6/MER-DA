### [D8・D4] 命題 5 の前提「θ\* は R の最小点」が成り立たない作りで，A1 と G(K) が 1 次の項 gᵀe を落としている
- 重さ：直してから進む
- 該当箇所：`docs/exploratory-analyses.md:7245`，`:7413-7414`，`:7426`，`:7446`．`exp/explore_theory_assumptions.py:101`，`:135-142`，`:248`，`:256-258`，`:355-359`
- 問題：E70 の前提（7245 行）は「θ\* はターゲットの最良の解 …… R(θ) ≈ R\* + ½ (θ − θ\*)ᵀ F (θ − θ\*)」であり，1 次の項が無い．ところが E74 の θ\* は「0 への正則化で解いた頭」（7413 行）で，`VF.star` → `fit_star` は目的関数 (1/S) Σ s_i CE + ‖W‖²/(2CS) + ‖b‖²/(2 C_b S)（`exp/logreg.py:6`，`:242-244`．C は CS_STAR = 0.003〜1.0 から選ぶ，C_b = 8）を解く．`Fisher` の R は罰則の無い同じデータ項なので，θ\* での勾配は g = −(W\*/(C n), b\*/(C_b n)) であり 0 にならない．それにもかかわらず
  - A1 の量は `quad / act`（台本 356-359 行）で，分子に `lin_*`（gᵀe）を入れていない．act = R(θ) − R(θ\*) は gᵀe + ½eᵀFe + 高次の項なので，gᵀe が ½eᵀFe に比べて大きいと，2 次の近似が良くても A1 は外れる．A1 が外れたときに「R の曲がりが 2 次でない」のか「θ\* が停留点でない」のかを区別できない
  - G(K) の式（`gains`，135-142 行）も 2 次の項だけで，1 次の項 gᵀ(r(e0) − r(e_Q)) を含まない．r(e) は CSV に残らないので，この項は計算の後で足せない
  - 設計は gᵀe の大きさを「記述」に置く（7446 行）が，基準を持たないので，A1・A2 の判定にどう使うかが決まっていない
- 計算の後で直せるか：A1 の分子に gᵀe を足す版は，`lin_*` が CSV に残るので後から計算できる．ただし基準を結果を見てから変えると探索の版になる．G(K) の 1 次の項は後から直せない（r(e0)，r(e_Q) を残していない）
- 求める対応：
  1. 表に A0 を足す．仮定「θ\* は R の停留点に近い」，量 |gᵀe| ÷ ½eᵀFe（e = e0，e_Q，K = 5・25 の B の解），基準（例：中央値 0.1 以下）を計算の前に書く
  2. A1 を「2 次の展開 gᵀe + ½eᵀFe と実際の act の比」と「½eᵀFe と act の比」のどちらで判定するかを決めて書く（命題 5 の前提を測る目的なら，A0 と A1（gᵀe 込み）に分けるのが筋である）
  3. `gains` で gᵀr(e0) と gᵀr(e_Q) を K ごとに CSV に残し，A2 を 1 次の項を含めた G でも出せるようにする
  4. 別案として θ\* を「罰則込みの目的関数の最小点」と定義し直し，F に罰則の 2 階微分を足す方法もある．どちらを採るかを計算の前に決める
