## 指摘

### [C1・C3] 罰則を緩めたのは手法の側だけで，none を同じ C′ で解いた対照が無いので，「減らした」の内訳（罰則の効果とラベル無しの項の効果）を分けられない
- 重さ：直してから進む
- 該当箇所：`docs/exploratory-analyses.md:9579`（「none，自己学習の出発点，エントロピー最小化と IM の初期値は E39 の C′ で解いた none のままにする」），`docs/exploratory-analyses.md:9588`，`exp/s43_penalty.py:150-161`（none は E39 の C′ だけで解く），`exp/analyze_e82.py:156-197`（「働かなかった」の材料は E39 の none との予測の食い違い），`exp/analyze_e79.py:1745-1763`
- 問題：E82 の選び直した版は，entmin・IM・自己学習に「C′ を 3 倍・10 倍に緩める」と「ラベル無しの項を足す」の 2 つを同時に与え，基準の none には前者を与えない．P4 の判定の量は「none − 手法 の向きの損」である．K = 5 では none も K 本で学び直すので，C′ を 10 倍にした none（ラベル無しの項なし）は，E39 の C′ の none と違う向きを持つ．したがって選び直した版で「減らした」が出たとき，それが「ラベル無しのデータが向きを直した」のか「出発点への罰則を緩めて K 本が向きを動かした」のかを，E82 の出力からは分けられない．筋 4 の結論は「ラベル無しのデータでは向きが直らない」なので，この 2 つの区別は結論の文そのものに関わる．同じ理由で，E79 の「働かなかった」の判定（選んだ設定のテストの予測が none と食い違う割合）も，10 倍の行では罰則の違いだけで食い違いが出て，ラベル無しの項の重みが小さい設定でも「働いた」に数えられる．K = 0 では none は出発点そのもの（`compare_dai.py` の `Prob2.solve`，重みが 0 なら `(W0, b0)` を返す）で C′ に依らないので，この混ざりは K = 5 の単位だけにある．
- 計算の後で直せるか：直せるが計算を足すことになる（none を倍率の C′ で解く行は E82 の出力に無く，ほかの行からも作れない．1 単位あたり凸の問 2 つ × 倍率 2 で小さい）．
- 求める対応：`s43_penalty.py` の `run_methods` の中で，倍率ごとに none を同じ C′ で解いた行（例 `none` の param `-C3x`・`-C10x`）を評価の単位と仮のターゲットの単位の両方に書く．設計の 3 節に次を足す．(a) 選び直した版で選ばれた倍率 m の単位について，「none(m) − none(1)」（罰則だけの効果）と「none(m) − 手法(m)」（ラベル無しの項の効果）の 2 つの向きの損の差を記述の表に出す．(b) 判定が固定の版から「減らした」に変わった単位について，(a) の後者でも同じ判定の規則（judge_unit と δ_d）を当て，後者が「減らした」に当たらないときは「罰則を緩めた効果」と書き，ラベル無しのデータの効果として書かない．(c) 「働かなかった」の材料に，none(m) との食い違いも足す．none(m) を選択の候補には入れない（none の C′ は E39 で仮のターゲットにより選ばれている）．

## 目録に無い種類の不備

- C9 の案：手法と基準が共有するつまみ（出発点への罰則，C，温度など）を手法の側だけで動かすときは，基準を同じ値で解いた行を同じ計算に入れ，「つまみを動かした効果」と「手法が足す項の効果」を分けて判定する．基準の値だけと比べた判定を，手法の項の効果として書かない．（E82 の関門 1 の比較）
