# ずれの指標：定義と正しい測り方（2026-09-30）

ソースとターゲットの「ずれ」を測る指標ごとに，定義・何に左右されるか・実装の決まり・出典を書く．
**実装は `measure/shift.py` の 1 か所だけ**に置き，実験コードで指標を書き直さない（`CLAUDE.md` の取り決め）．
本ファイルはその実装の根拠である．実装を変えたら，ここも直す．

**指標の値はモデルとデータの形で動く**．このファイルの目的は，動く原因を先に列挙し，
比べてよい値だけを比べることである．出典のうち「本文確認」は原典で該当箇所を読んだもの，
「要旨のみ」は要旨と該当節の拾い読みのもの．

## 0. すべての指標に共通の決まり

| # | 決まり | 理由 |
|---|---|---|
| C1 | **ゼロ点を必ず併記する．**同じ群を話者で 2 つに割ったときの値（同一分布の基準）を同じ手順で計算し，組の値と並べる | 有限標本では同一分布でも値が 0 にならない（MMD の偏り，FID の偏り，coverage の期待値 <1）．ゼロ点の大きさは群の大きさ・次元・話者数で変わる |
| C2 | **標本数をそろえる．**全組で同じ本数を抜き出し（既定 n=300．ゼロ点のために最小の RAVDESS 672 本を話者で半分に割っても 336 本残る），抜き出しを R 回（既定 20）繰り返して平均と幅を出す | FID の偏りは標本数と分布の両方に依存し，固定の本数でも比較を歪める（Chong & Forsyth 2020，要旨と序論）．PAD・coverage も標本数で変わる |
| C3 | **話者で分ける．**判別器の学習と評価，ブートストラップは話者単位で行う | 話者の声・顔の癖で「どちらのコーパスか」が当たってしまう．RAVDESS は 24 人，IEMOCAP は 10 人しかいない |
| C4 | **前処理を固定する．**既定は「その組の 2 標本を合わせたもので各次元を標準化」．群ごとの標準化は**ずれを消す操作**なので指標の既定にしない | 距離はすべて尺度に依存する．群ごとに標準化すると平均のずれが消え，測りたいものが変わる |
| C5 | **モダリティ間で生の値を比べない．**次元が違う（映像 512，音声 1024，言葉 768）．比べるのはゼロ点に対する比か，組の順位 | MMD はガウスカーネル＋中央値の幅で，高次元ではおおむね「平均の差の 2 乗÷次元」になり，1/d で縮む（Ramdas ほか 2015，本文確認） |
| C6 | **広がり（共分散）を使う指標は PCA で次元を落とす**（既定 r=64．必ず r ≪ n） | n=300 < d=1024 では共分散が特異になる．CORAL も単位行列を足して無理に正則化している（Sun ほか 2016，本文確認） |
| C7 | **エンコーダを 2 つとも使う．**組の順位が 2 つのエンコーダでどれだけ一致するか（順位相関）を報告する | 指標は特徴空間の上の量．エンコーダの事前学習データで変わる（Wagner 2023．Naeem 2020 も事前学習した埋め込みの偏りを指摘，本文確認） |
| C8 | **ラベルを使う版を 2 つに分ける．**記述用（ターゲットの全ラベルを使う＝オラクル）と実用（ターゲットは K 本＋ラベルなしだけ）．論文ではどちらかを明記する | 「ずれを測って決める」規則の評価に，テストのラベルを混ぜないため（`CLAUDE.md`：ハイパーパラメータはテストラベルで選ばない） |
| C9 | **入力の指標は感情の割合の差も拾う．**記述用では，両側を感情ごとに同数に抜き出した版（割合をそろえた版）も出す | 判別器は「中立が多い方」を手がかりにできる．割合と入力のずれを分けて議論するため |
| C10 | **指標を増やしすぎない．**1 軸 1 指標を主とし，他は補助 | 指標の優劣は設定で入れ替わる（Agostinelli ほか 2022，要旨と序論） |

## 1. 軸 1：入力の違い

### 1.1 proxy A-distance（PAD）〔主〕

- **定義**：ソース（0）とターゲット（1）を見分ける分類器の誤り率 ε から `PAD = 2(1 − 2ε)`．0（見分けられない）〜 2（完全に見分けられる）．
  Ben-David ほか 2006/2010 と Ganin ほか 2016 の定義（本文確認）．
  **Elsahar & Gallé 2019 は `1 − 2E` で 0〜1 の尺度**を使う（本文確認）．論文間で 2 倍違うので，引用するときに尺度をそろえる
- **実装**：
  - 両側から n 本ずつ抜く（C2）．話者で 5 分割して判別し（C3），外側の誤り率を ε にする
  - 判別器はロジスティック回帰（線形）．C は内側の話者分割で選ぶ
  - ε>0.5 のときは PAD=0 に切る
- **注意**：
  - **Ganin ほか 2016 は「最良の C の誤り率」を同じ評価用の半分で選んでいる**（評価に使う半分で選ぶので楽観的）．本実装は入れ子の交差検証で避ける
  - **判別器の強さと特徴の次元で値が変わる**．Ganin 2016 自身が「表現の次元が大きいほど見分けやすい」ので次元を固定して比べた（本文確認）→ C5
  - **高次元の深層特徴では飽和しやすい**（どの組も 2 近く）．飽和した組どうしは比べられない．飽和の割合を報告する
  - 見分けの手がかりは感情と無関係なもの（録音条件，話者，画角）でもよい．Elsahar 2019 では，無関係な目印を足すと常に 1.0 になった（本文確認）．→ 軸 4 と合わせて読む
  - Ben-David 2010 は「ζ は d_H の下からの見積もりで，上界に要るのは d_HΔH の上からの見積もり」と明記している（本文確認）．**PAD を上界の項に代入するのは近似**である
  - ラベルの割合の差も拾う → C9

### 1.2 MMD（最大平均差）〔補助〕

- **定義**：カーネルで写した 2 つの分布の平均の距離．不偏推定量 `MMD²_u`（Gretton ほか 2012 式 (3)，本文確認）
- **実装**：
  - ガウスカーネル．幅は「2 標本を合わせた点の対の距離の中央値」（中央値の経験則）
  - 両側 n 本（C2）．値は `MMD²_u` のまま報告する（平方根をとらない）
- **注意**：
  - **`MMD²_u` は負になりうる**（不偏なので．Gretton 2012，本文確認）．負の値を 0 に切らずにそのまま平均する
  - **中央値の経験則は経験則にすぎない**．最適な幅は未解決（Gretton 2012 §8，本文確認）．標本から幅を決めると漸近分布の理論の前提から外れるが，実用上の差は小さかった（同 付録 C）
  - **高次元では，中央値の幅の MMD² はほぼ「平均の差の 2 乗 ÷（分散 × 次元）」になる**（Ramdas ほか 2015 Observation 2，本文確認）．つまり高次元では平均の違いしか見ておらず，値は 1/d で小さくなる → C5
  - 分布が複雑だと，単純なガウスカーネルでは差を検出しにくい（Liu ほか 2020，要旨のみ）

### 1.3 フレシェ距離（FID 型）〔補助〕

- **定義**：両側をガウス分布とみなしたときの 2-Wasserstein 距離 `‖μ_s−μ_t‖² + tr(Σ_s + Σ_t − 2(Σ_s Σ_t)^{1/2})`
- **実装**：2 標本を合わせて PCA（r=64，C6），両側 n 本（C2）
- **注意**：
  - **有限標本の値は偏っていて，偏りの大きさは標本数と分布の両方に依存する**．同じ本数でそろえても比較が歪む（Chong & Forsyth 2020，要旨と序論）．
    対策は 1/N に対して外挿した FID_∞．本実装では，C1 のゼロ点との比較で代える．厳密さが必要になったら外挿を実装する
  - 音声版 FAD でも，標本数の偏り・埋め込みの選び方・参照集合の質で値が大きく変わる（Gui ほか 2024，要旨確認）

### 1.4 使わないもの：JS・KL（単語頻度の上の値）

Kashyap ほか 2021 で感情極性の落ち幅と最もよく相関した JS（0.716）・KL（0.715）は，**単語の出現頻度の分布**（上位 1 万語）の上で計算されたもの（本文確認）．
連続値の凍結特徴の上の値ではない．**音声・映像には使えない**．言葉でも本研究の特徴（RoBERTa の平均）とは別物なので使わない．

## 2. 軸 2：覆い方（向きがある）

### 2.1 coverage（と density）〔主〕

- **定義**（Naeem ほか 2020，本文確認）：参照側（ここではターゲット）の各点について，参照側の中での k 番目の近傍までの距離を半径とする球を作る．
  - **coverage** ＝ 球の中にソースの点が 1 つでも入る，ターゲットの点の割合．**「ターゲットの何割がソースに覆われているか」**
  - **density** ＝ ソースの各点が，いくつのターゲットの球に入るかの平均を k で割ったもの．ソースがターゲットの密な所にどれだけいるか
- **実装**：
  - k=5
  - 両側 n 本（M=N．C2）
  - 2 標本を合わせて標準化（C4）した特徴の上のユークリッド距離
  - **向きを両方出す**（ターゲット基準とソース基準）
- **注意**：
  - **同一分布でも 1 にならない．期待値は解析的に分かる**：`E[coverage] = 1 − (N−1)⋯(N−k) / ((M+N−1)⋯(M+N−k))`，M=N→∞ で 1 − 1/2^k（k=5 で 0.969）．
    **この期待値は分布の種類にも次元にもよらない**（Naeem 2020 式 (9)，本文確認）．ゼロ点（C1）として理論値と実測の両方を出す
  - Kynkäänniemi ほか 2019 の precision／recall（k=3）は，**外れ値 1 点で値が大きく変わる**うえ，同一分布でも期待値が解析的に求まらない（Naeem 2020，本文確認）．だから主には coverage を使う
  - **「範囲を含むか」ではなく「ターゲットが密な所に，ソースも同じくらいの密度でいるか」に反応する**．球の半径はターゲット自身の密度で決まるため，広く薄く散らばったソースは，範囲としてはターゲットを含んでいても coverage が低く出る（`measure/test_shift.py` の検算で確認：広さ 2 倍のソースで 0.27）．性質は Kpotufe & Martinet の γ（ターゲットの点のまわりのソースの量）に近い．**「覆っている範囲」と読まない**
  - 近傍は特徴の距離で決まるので，エンコーダ依存が強い → C7

### 2.2 共分散の支配 c〔補助〕

- **定義**：`Σ_s ⪰ c·Σ_t` となる最大の c ＝ `λ_min(Σ_t^{-1/2} Σ_s Σ_t^{-1/2})`．大きいほど，ソースがターゲットの方向を覆う．リスクは 1/c に比例（Du ほか 2021 Assumption 4.2，本文確認）
- **実装**：ターゲットの PCA 上位 r 方向（C6）に両側を射影してから計算
- **注意**：
  - 最小固有値は，小さい固有値の推定誤差に極端に弱い．r を変えて（16・32・64）安定するかを確かめる
  - 理論は線形表現と部分ガウスの仮定のもと

### 2.3 保留：転移指数 γ

Kpotufe & Martinet 2021 の γ は，定義は明快だが有限標本での推定手順が確立していない（1〜3 章を確認）．本研究では測らない．

## 3. 軸 3：感情の割合

### 3.1 ラベル比率の差〔主〕

- **定義**：`‖p_s(y) − p_t(y)‖₁`（0〜2）．Tachet ほか 2020 の分解の第 1 項に入る量（本文確認）
- **実装**：記述用は発話一覧の全ラベルで計算．実用版は，ターゲットの割合を 3.2 で推定した値で計算する
- **注意**：
  - 主指標の UAR はクラスごとの正解率の平均なので，**テスト側の割合の影響はもともと小さい**
  - 割合のずれが効くのは主に，ソースの割合が分類器の判断を偏らせる経路である

### 3.2 ラベルなしのターゲットで割合を推定する（MLLS＋BCTS）

- **手順**（Alexandari ほか 2020，本文確認）：
  1. ソースで学んだ分類器の出力を，ソースの保留データで**クラスごとのバイアスつき温度較正（BCTS）**で較正する
  2. ソースの事前確率を「較正後の予測の平均」に置く（こうしないと，ずれが無くても EM がずれを推定する．同 Lemma A）
  3. ターゲットのラベルなしデータで EM
- **BBSE**（Lipton ほか 2018，本文確認）：混同行列の逆行列を使う．**混同行列が逆行列を持つことが前提**で，クラスが混ざりやすいと不安定．補助としてのみ使う
- **注意**：
  - どちらも「感情ごとの見え方 p(x|y) は同じ」（ラベルシフト）を仮定する．コーパス間では崩れるので，推定値は近似である（Garg ほか 2023 の「緩いラベルシフト」）
  - 記述用（真の割合）との差を必ず報告する

## 4. 軸 4：ラベルの付け方

以下は**分類器に依存する量**である．分類器は「ソースで学んだ，本研究の固定学習器（凍結特徴＋ロジスティック回帰）」に限る．

### 4.1 ソースのみの誤り R_src と混同行列〔主〕

- **定義**：ソースで学んだ分類器を，ターゲットのラベル付き発話で採点した誤り率（UAR で報告）と，4×4 の混同行列（行＝正解，列＝予測．行ごとに割合）
  （Kuzborskij & Orabona 2017 の R_src，本文確認）
- **実装**：
  - 記述用はターゲットの全件
  - 実用版は K 本（クラスあたり K）
  - 混同行列は，ソース自身の保留データ（話者を分けたもの）でも計算して並べる
- **注意**：
  - **K 本での推定はばらつく**．各マスの割合の標準誤差は約 √(p(1−p)/K)．K=5 なら ±0.2 前後
  - 実用版では K 本の抽出を繰り返した幅を必ず出す
  - R_src には入力のずれの影響も入る．**付け方のずれだけを表すものではない**

### 4.2 条件付き誤りの差 Δ_CE と BER（Tachet ほか 2020）〔補助〕

- **定義**（本文確認）：
  - `Δ_CE = max_{y≠y'} |P_s(Ŷ=y'|Y=y) − P_t(Ŷ=y'|Y=y)|`（混同行列の非対角の差の最大値）
  - `BER = max_y P_s(Ŷ≠y|Y=y)`（**クラスごとの誤り率の最大値．平均ではない**）
  - 分解：`|ε_s − ε_t| ≤ ‖p_s(y)−p_t(y)‖₁·BER + 2(k−1)·Δ_CE`
- **注意**：
  - 分類器ごとに値が変わる（定理は任意の分類器 Ŷ について成り立つ）
  - **最大値は推定誤差で上に偏る**（12 マスの雑音の最大をとるため）．最大値だけでなく差の行列全体を報告し，K 本の抽出の繰り返しで幅を出す

### 4.3 OTDD〔保留〕

- 特徴とラベルの両方を使う最適輸送の距離（Alvarez-Melis & Fusi 2020，本文確認）
- 効率版は各感情をガウス分布で近似し，**クラスごとに共分散（d×d）を推定**する．計算量は d³ に比例する．K が小さいと推定できない
- 本研究では C6 の PCA 後の記述用にとどめ，最初の実装には入れない
- 同論文も，小さい標本ではばらつくと報告している

### 4.4 閾値のずれ

- 測るより「消す操作」として使う（`docs/experiment-protocol.md` の操作 D1）
- 較正前後の R_src の差が，閾値のずれの大きさの目安になる（Reeve ほか 2021 の考え方．1〜4 章確認）

### 4.5 注釈者の一致率

- コーパス内のラベルの揺れ．Larsen 2026（IEMOCAP で全員一致は約 20%）
- **現在の発話一覧には注釈者ごとのラベルの列がない**（2026-09-30 確認）．作れるのは IEMOCAP（注釈ファイル）と CREMA-D（評価者の票）の見込み（未確認）

### 4.6 試運転の結果（2026-09-30．1 組・繰り返し 1 回．暫定）

音声（WavLM），ソース CREMA-D → ターゲット RAVDESS，n=300：

| 指標 | 組 | ゼロ点（RAVDESS を話者で半分に） |
|---|---|---|
| PAD | **2.000（飽和）** | 0.247 |
| coverage（ターゲットが覆われる／逆） | **0.000／0.000** | 0.627／0.563（同一分布の理論値 0.970） |
| MMD² | 0.268 | 0.013 |
| フレシェ距離（r=64） | 1624 | 230 |

- 凍結特徴の生の空間では，**コーパスが違うと完全に見分けられ，近傍も重ならない**．PAD と coverage は飽和して組の比較に使えない恐れが高い
- **同じコーパスの中でも**話者を分けるだけで coverage が理論値を大きく下回る．特徴は話者・コーパスの癖を強く含む
- 対処（未決）：感情に関係する部分空間の上で測る（Elsahar 2019 の PAD*＝タスクモデルの内部表現で測る，の考え方）など．全組で試してから決める

## 5. 補助：accuracy-on-the-line

多数のモデルで「ソース内の性能」と「ターゲットでの性能」を並べると直線に乗りやすい（Miller ほか 2021，要旨のみ）．
直線から外れる組は，ずれの種類が違う合図になる．本研究ではエンコーダ 2 系統 × 作り方の組で描ける．最初の実装には入れない．
