# 見たデータの台帳

実験ごとに，**設計の判断のために見たデータ**と，それで決めたことを書く（`docs/methods.md` 9.2 節）．目的は，評価に使うデータを手法の設計に使っていないことを，計算の前に確かめることである．模擬査読 1 回目（`paper/reviews/round1/`）の ML Major-2・感 Major-1 は，教師モデルの候補と拡張版を，評価に使うターゲットの結果を見て決めたことを指摘した．

- 設計の節を `docs/exploratory-analyses.md` に書いた本体のセッションが，計算を起動する前に 2 節の表に 1 行足す
- 関門 1 の `gate-leak` と `gate-probe` は，この台帳と設計の節を照合する
- 「見た」は，そのデータの UAR やラベルを使った数値を見て，設計（候補，格子，部品，比較に入れる生徒やターゲット，判定の基準）を決めたことを指す．結果を報告するために計算しただけのものも，その結果を見て次の設計を決めたなら「見た」に入れる
