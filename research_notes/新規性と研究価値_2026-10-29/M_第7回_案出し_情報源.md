## 2. 案 A：他のモダリティで推した感情の割合で，話者のずれを除く oursx（推す案）

### 2.1 oursx のどこに何を足すか（手順）

足す情報は，ターゲットとソースの発話の話者群（`load_group` が付ける `speaker_group`）と，ソースのラベルである．oursx の教師の作り方，重みの付け方，総重み，同時に学ぶ形，K ごとの選び方は変えない．

1. **ソースの側（ラベルで正確に引く）**：ソースのコーパスごと，モダリティのブロック m ごとに，話者 s のずれ u_{m,s} = w_s · mean_{i∈s}(z_{m,i} − μ_{m,y_i}) を引く．μ_{m,k} はそのコーパスの感情 k の平均，w_s = n_s/(n_s + κ_m) は本数による縮め方である．κ_m = σ²_m/τ²_m は，ソースの話者の残りのばらつき（話者の中 σ²，話者の間 τ²）から推す（メタ学習の部分．仮のターゲットの UAR で選ばない）．引いた特徴で E39 のアンカーと融合の教師 pF を今の設定のまま作り直す
2. **ターゲットの候補の側（ラベル無し．他のモダリティで推す）**：
   - (a) 今の oursx と同じく pFK と ref の部品 c_{m'}（pFK の疑似ラベルで学んだモダリティごとの生徒）を作る
   - (b) モダリティ m について，m を除いた部品の確率の積 q_i^{(−m)} ∝ Π_{m'≠m} c_{m'}(i) を作る（AV の世界では m が顔なら音声だけ）
   - (c) 感情の平均 μ̂_{m,k} = Σ_i q_ik^{(−m)} z_{m,i} / Σ_i q_ik^{(−m)}（K 本は本当のラベルで重み 1 を足す），話者のずれ û_{m,s} = w_s · mean_{i∈s}(z_{m,i} − Σ_k q_ik^{(−m)} μ̂_{m,k}) を出し，引く
   - (d) 引いた特徴で pFK，ref，生徒を今の oursx のとおり作り直す．(b)〜(d) を 2 回まで繰り返す
3. **テストの側**：融合の生徒（運用時も複数モダリティ）は，テストの話者のラベル無しの発話で 2 の (b)〜(c) を行う（他のモダリティの部品はテストの発話でも計算できる）．単独のモダリティの生徒は他のモダリティが無いので，生徒自身の予測で q を作る（自己の推し．案 C はここを置き換える）
4. 比べる相手（同じ oursx・同じ選び方の上で前処理だけを替える）：(i) 話者で引かない今の oursx，(ii) ラベル無しで話者ごとに標準化する（Schuller 2010．`measure/ablate.py` の I2），(iii) 話者ごとの中立の発話だけの統計で標準化する IFN（Busso 2013．中立の判定は同じモダリティの生徒），(iv) 2 の (b) を自己の推しに替えた版（交差モダリティの寄与の除去実験），(v) ソースの側だけ引く版とターゲットの側だけ引く版
5. 帰納の版：テストの話者の統計を使わず，1 と 2 だけで学んだ生徒をそのまま当てる版も出す（運用時に話者が分からない場合）

### 2.2 得が上がる仕組み

- **模型**：モダリティ m の特徴を z_{m,i} = μ_{m,y_i} + u_{m,s(i)} + ε_{m,i} と置く．話者 s の平均は z̄_{m,s} = Σ_k π_{s,k} μ_{m,k} + u_{m,s} + ε̄ である．
  - ラベル無しの中心化（相手 ii）は Σ_k π_{s,k} μ_{m,k} も引くので，話者ごとの感情の割合 π_s が話者の間で違うほど感情の信号を消す．その大きさは η² で測れ，MOSEI 0.29，AFEW 0.22 で大きく，IEMOCAP・MELD・CREMA-D で 0.04 以下である（1.4 節）．E14 のラベル無しの版が損をしたのは 1 人あたりの発話が少ないターゲット（MOSEI，AFEW）だった（`docs/exploratory-analyses.md:1147`）
  - 自己の推し（相手 iii・iv）は，生徒自身の予測が u_{m,s} で引っ張られる（例：顔が怒って見える話者の発話を「怒り」と予測する）ので，ずれを感情の割合と取り違え，引く量が足りない
  - 他のモダリティの部品の予測は，u_{m,s} がモダリティ m に固有なら u_{m,s} の影響を受けない．このとき û_{m,s} の誤差は (π_s − π̂_s) の分だけで，他のモダリティの教師の正確さで決まる
- **1+2 の o と d での読み**：線形の生徒の点数では，u_{m,s} は話者ごとの切片の誤り W u_{m,s} になる（話者の単位の o）．コーパスの平均を引く中心化（第 I 部．ソースのみに +4.9）はコーパスの単位の o を直し，K 本はプールの話者の平均の o を直すが，テストの話者ごとの o は直さない．A はこの話者の単位の o を直す．加えて，ずれが特徴の感情の中のばらつきに入ると，疑似ラベルで学ぶ向き d が話者を分ける向きに引かれる．引くと d も上がりうる
- **新しい 3 での読み**：教師の誤りのうち話者の単位の部分（1.5 節の 1）は，話者を見分けられる生徒の特徴でほぼ全部表せるので，生徒は受け継ぐ．A は生徒の特徴から話者の平均の成分を除くので，この部分を表せなくなる
- **3 の価値での読み**：テストの話者のずれは，ターゲットの候補全体にラベルを付けても全体で 1 つの線形の分類器では直らない．したがって A の得は，K 本の価値でも「候補全体のラベルで学んだ線形の天井 W\*」でも測れない種類の情報である．顔の生徒では，W\* と E39 の差（AVT の K=0 で 2.68．`K_第6回_案出し.md:13`）と，E14 のラベルを使う版の得（映像 +1.9）が同じ桁にある．K を増やしても A の得は減らないと予言でき（2.3 節），学習曲線が寝る大きい K ほどラベル換算の本数は大きくなる

### 2.7 新しい 3 と 1+2 の分解とのつながり

- **新しい 3**：教師の誤りを話者の平均の部分と話者の中の部分に分け，それぞれについて「生徒の特徴で表せる割合」を測る（仮のターゲットのラベルを使う）．予言：話者の平均の部分は顔と音声の生徒の特徴でほぼ全部表せ（話者を見分けられるため），生徒が受け継ぐ誤りのうち話者の平均の部分の割合は，教師の誤りのうちの割合より大きい．A の後はこの部分が消える．4 が失敗しても，この分解は「生徒が受け継ぐ教師の誤りは，話者の単位で共通の部分に偏る」という分析として残る（V3）
- **1+2**：A は o を「コーパスの単位」と「話者の単位」に分ける．第 I 部の中心化はコーパスの単位の o を直し（+4.9），K 本はプールの平均の o を直す．話者の単位の o の大きさは，E14 の S と話者ごとの UAR のばらつきで測れる．A の前後で，話者ごとの切片のばらつきが減り，コーパスの単位の o は変わらないことを記述として出す

## 3. 案 B：話者のずれを除いた教師を，対話の中の感情の持続で組み直す oursx

### 3.1 oursx のどこに何を足すか（手順）

足す情報は，候補の発話の対話（IEMOCAP の `dialog_id`，MELD の `dialogue_id`，MOSEI の `video_id`）と時刻（`start_sec`，`utterance_id`，`clip_id`）である．運用時の生徒は変えない．

1. 今の oursx の 2 段目の教師 ref を作る
2. **話者のずれの除去**：ref の各モダリティの部品の対数確率について，案 A の 2 の (b)〜(c) と同じ推し方で話者ごとのずれを推して引き，積を取り直す（A を特徴ではなく部品の点数の上で行う）
3. **持続の推し**：λ（前の発話の感情を写す確率）をラベル無しで推す．1.6 節の M6 で最尤の λ̂ は大きめに出て，MELD で損をしたので，次のどちらかを計算の前に決める：(a) 別の話者の隣だけで推す（話者のずれを共有しない），(b) ソースの対話のラベルで推した λ を上限にする
4. **平滑化**：対話ごとに，遷移 A_λ = λI + (1 − λ)1π̂ᵀ，出力の尤度 ∝ ref_i/π̂ の前向き後ろ向きで事後確率を出し，π̂ で割って釣り合いを取り直した確率を新しい教師 ref_ctx にする．K 本のラベルは正解に固定する
5. oursx の重みの付け方・総重み・同時に学ぶ形・選び方は変えずに，教師 ref を ref_ctx に替える．主な判定は，重みの付け方と総重みを固定して ref と ref_ctx だけを替えた対の比較で行う
6. 対話の無いターゲット（AFEW，CREMA-D，RAVDESS）では B は oursx と同じになる

### 3.2 得が上がる仕組み

- 教師の誤りのうち対話の中で発話ごとに独立な部分（1.5 節の 2）は，隣の発話の感情が同じ割合が偶然より高いほど，隣の教師の確率で平均すると小さくなる．人工の計算では，誤りが独立なら IEMOCAP 即興で +18.8，台本で +13.2 上がる（1.6 節）

### 4.1 oursx のどこに何を足すか（手順）
