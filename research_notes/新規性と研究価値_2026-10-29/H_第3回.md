## 0. 結論

1. **第 3 回の案は不合格と判定する．**N2 と R1 は満たし，N1・V1・V3 は条件つきで満たすが，V2 と V4 を満たさない（6 節）．
2. **新しい 3 の 3 つの型のうち，写す型と足す型は既知である．**Reimherr, Meng, Nicolae（JRSS-B 2021．以下 RMN）は原文で，価値 M(k) の傾きの最小が −1 で，それが事前分布と尤度の不一致が無限大の極限で起きること，不一致が無いとき M(k) が一定になることを書いている（本調査で原文を確かめた）．同じ 2 つは MER-DA の E67 の命題 2 と E32 の「n(K) の形で手法の型が分かる」にもすでにある．
3. **増やす型は部分的に既知である．**同じ n 本のラベルで学ぶ教師が学びやすい表現を持つと，生徒の学び方の速さが教師の速さで決まり，生徒が教師に合わせきれない分が残る，という形は Lopez-Paz ほか（ICLR 2016）の 4.1 節にある．線形のガウスの模型で特権情報を持つ教師が推定の誤差を減らす定理は Karlsson ほか（AISTATS 2022）にある．どちらも原文で確かめた．ラベル本数の単位で「価値の傾き = q_s/q_T − 1」と書いて実データで測った先例は見つからなかった．
4. **案の価値 n の定義と，案が引く記録の価値の定義が食い違う．**案の模型の n は「ターゲットだけの学習器との差」であるが，E65・E66・G の計算 2 の値は「ソースから出発した学習器（E39）との差」である．案の定義で E65 を読み直すと，写す型の傾きは −1 ではなく −0.43 本／本（66.2 → 55.4 本）である（本調査の計算．4.1・4.2 節）．
5. **Q2 は今の記録で照合でき，予言は大きさで外れた．**E11 の学習曲線の q で，生徒の本数と教師 pFK の本数の比を予言すると，実測の比は予言の中央値 1.74 倍（ref では 2.44 倍）で，仮のターゲットのコーパスごとの並びの順位相関は 0.41 だった（本調査の計算．4.4 節）．
6. **新しい 4 の前提を支える記録は無い．**E61 の AVT の仮のターゲットで，案の形の価値の曲線を候補ごとに K をまたいで当てはめて選ぶと，K ごとに UAR で選ぶ規則との差は K = 0, 1, 5, 10, 25 で +0.03，+0.39，−0.26，−0.07，−0.19 ポイントで，どの K でも区間が 0 を含んだ（本調査の計算．4.6 節）．
7. 新しさが残る最小の主張は，「K 本で学び直す融合の教師から蒸留した生徒では，生徒のラベル換算の本数と教師自身のラベル換算の本数の比が K によらずほぼ一定」という記述の主張だけである（7 節）．新しい 4 には記録と矛盾せずに残る主張が見つからなかった．

## 2. 評価した案の読み方

### 2.1 新しい 3

第 I 部の模型（ターゲットだけの生徒の向きの誤差 ≈ q_s/K，価値 n = K_eq − K）を教師と生徒の連鎖に当て，価値の K 依存を 3 つの型で説明する．写す型は n(K) = N_T − K（傾き −1），足す型は n(K) = N_T（一定），増やす型は n(K) = (q_s/q_T − 1)K + (q_s/q_T)n_T0 で，生徒の特徴で表せない教師の判定の部分（モダリティの隔たり）で頭打ちになる．問いは Q1（3 つの型が記録の値を計算の前に決めた誤差で再現するか），Q2（増やす型の傾きが学習曲線から測った q_s/q_T − 1 と合うか），Q3（傾きの下がり方が隔たりで説明できるか）である．

### 2.2 新しい 4

oursx（教師 pFK・ref × 重みの付け方 bal・raw・hard τ × 総重み，同時に学ぶ形）をそのまま使い，仮のターゲットの上で候補ごとに新しい 3 の価値の曲線（N0，傾き，頭打ち）を全部の K をまとめて当てはめ，各 K で曲線の予言が最大の候補を選ぶ．教師の経路は q_T が小さいものを選ぶ．比べる相手は oursx の K ごとの UAR での選択である．

### 2.3 本調査の読みと，読めなかった点

- **価値 n の基準が一意でない．**案の模型の n = K_eq − K は「ターゲットだけの学習器との差」である（以下 n_tot = K' − K）．案が引く記録（E65 の 29.3〜3.9 本，E66 の 28.3 → 27.5 本，G の計算 2 の 59.1 → 212.1 本）は，どれも「ソースから出発した学習器 E39（none）との差」n_mod = K'(教師あり) − K'(none) である（`exp/explore_teacher_value.py` の `n_mod`，G の調査 4.6 節）．none 自身の本数は K とともに増える（E65 の音声で中央値 28.9 → 73.4 本．4.2 節）ので，2 つの定義では傾きが違う．本調査は両方で読んだ．
- **ref の q_T が定義されていない．**ref は pFK を蒸留したモダリティごとの生徒の確率の積で，ref 自身の UAR は E61 の結果ファイルに無い．本調査は pFK の UAR（融合の生徒の none）を教師の本数の代わりに使った．
- 新しい 4 の曲線の形（N0，傾き，頭打ちの 3 つの数をどの式で持つか）と，当てはめる値（行ごとか中央値か，読めない点の扱い）は案から読めない．4.6 節では n(K) = N0 + A·K/(K + c)（K=0 で N0，初めの傾き A/c，頭打ち N0 + A）を，訓練側の仮のターゲットの n_mod の K ごとの中央値に当てた．
- 「q_T が小さい教師を選ぶ」規則は，今の oursx の教師の候補（pFK と，pFK から作る ref）が同じ融合の特徴の q_T を共有するので，候補を区別しない．

## 4. MER-DA の記録との整合

### 4.1 価値の定義の食い違い（3 つの型すべてにかかる）

| 量 | 定義 | 案の模型 | 案が引く記録 |
|---|---|---|---|
| n_tot | K'(生徒) − K．ターゲットだけの学習器との差（RMN の基準が平らな事前分布であるのと同じ） | 写す型・足す型・増やす型の式はこの量 | 記録には無い（本調査で計算） |

none 自身の本数 K'(none) は K とともに増える（E65 の pF・m=2000・音声で中央値 28.9，29.7，35.6，42.5，73.4 本．E61 の音声で 22.9，24.5，27.1，33.7，71.5 本）．したがって n_mod の傾きは n_tot の傾きより「none の本数の増え方」だけ小さい．RMN の (V)（傾きは −1 より下がらない）は基準が平らなときの性質で，n_tot では E65 の傾きは −0.75，+0.03，−0.78，−0.42 本／本と −1 を下回らないが，n_mod では K=5→10 で −1.92 本／本，AT の世界の K=0→1 で −7.1 本／本と −1 を大きく下回る．**案の 3 つの式と記録を照らすには，基準を 1 つに決めて式を書き直す必要がある．**

## 5. 研究価値

### 5.1 (a) 誰のどの判断が変わるか

- **データを集める人**：学習の段階だけ映像や言葉を手元に置けるとき，増やす型の比 K'_s/K'_T が予言できれば，「融合の教師を経由すると，運用する音声のラベル 1 本が何本ぶんになるか」で，ラベルの予算と，映像や言葉を学習用に集めるかを決められる．ただし記録では比の大きさを q の比で予言できない（4.4 節）．また q_T と q_s はターゲットの学習曲線から測る量で，ラベルの少ないターゲットでは測れない．ソースのコーパスの平均で代えると，コーパスごとの比の散らばり（音声の pFK で 1.35〜4.89）がそのまま誤差になる．

## 7. 新しさが残る最小の主張（条件つき）

1. **K 本で学び直す教師の経路での，本数の比の一定さ（記述）**：凍結特徴の上の線形の頭で，K 本で学び直した融合の教師（pFK）の疑似ラベルを候補全体に付けて単独のモダリティの生徒を学ばせると，生徒のラベル換算の本数 K'_s(K) と教師自身のラベル換算の本数 K'_T(K) の比は K によらずほぼ一定である（AVT の仮のターゲットで，音声 1.87〜2.61，言葉 2.26〜3.29．顔は 1.09〜3.00 で散らばる）．
   - 先例との差：生徒の学び方の速さが教師の速さで決まる形は Lopez-Paz 2016（界と速さの指数），特権情報の利得は Karlsson 2022（分散の差），共有の部分空間での受け継ぎは Dong 2025 にある．比が K によらず一定であることを，実データでラベル本数の比として示したものは見つからなかった．
   - 条件：(a) 比を q_s/q_T で予言するとは書かない（記録では 1.74 倍ずれる）．(b) 本数の基準と単位を計算の前に決める．(c) K'_s が K=50 を超える行は，学習曲線の点を足してから読むか除く．(d) 第 2 のエンコーダの AVT で，学習曲線を作ってから「比が一定」の予言と許す幅を書いて確かめる．(e) 顔は別に示すか除く．(f) 本調査の計算 4 は関門を通しておらず，AVT の第 1 のエンコーダの値はもう見たデータである．
2. **E65 と E66 を RMN の型で読む節**：K 本で学び直さない教師を同時に学ぶ形で使うと，生徒の UAR は K=0→25 で 0.55 ポイントしか動かず（RMN の不一致が無限大の極限にあたる），動かしてから学び直す形では教師の上乗せの本数が K によらない（RMN の ∆² = 1 にあたる）．
   - 先例との差：型は RMN にあり，MER-DA の E67 の命題 2 でも導いている．残る差は，資源が別のモダリティの教師の疑似ラベルで動かしたアンカーであることと，同じ資源の 2 つの使い方を比べたことで，G の調査の主張 1 と同じ大きさである．
