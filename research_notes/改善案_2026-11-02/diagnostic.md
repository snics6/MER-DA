# 提案手法（oursx）を改善する余地の診断：仮のターゲットの値だけで測った表（2026-11-02）

E77・E78・E80 の段 c の仮のターゲットの UAR だけを使い，oursx の水準，選択の取りこぼし，教師との差，KD との差，格子の中の広がり，仮のターゲットどうしの順位の一致を，世界 × 生徒 × K ごとに測った．改善策の提案は書かない．

## 数値から読み取れること（5 行）

1. 選択の取りこぼし（格子の最良 − 1 つ抜いて選んだ値）は，oursx で AV 0.5〜1.2 点，AVT 0.0〜3.1 点である．雑音で高く出る分を除いた交差オラクルで測り直すと AV は −0.4〜+0.6 点に縮み，1 点を超えて残るのは AVT の言葉（1.7〜2.9 点）と AVT の音声 K=0（2.1 点）だけで，この平均は 1 セルで 6.0〜8.1 点を落とした 4 セルが押し上げている（表 0・表 2．AVT の LOPO は 1 コーパスだけで選ぶ．AVT の言葉では，1 反復どうしの候補の順位相関がコーパスの間で 0.28〜0.31 と，同じ群の反復の間の 0.64〜0.76 より低い）．
2. oursx の格子の最良 − KD の格子の最良は −0.3〜+0.8 点（交差オラクルどうしでは −0.6〜+0.5 点）であり，1 つ抜いて選んだ値どうしの差は −1.5〜+2.0 点，世界 × 生徒 × K の 21 行の平均は +0.05 点である（表 4）．
3. 単モダリティの生徒では，残した教師の最良が none を 7.3〜14.9 点上回るのに対し，oursx の格子の最良が none を上回るのは 2.1〜6.0 点で，生徒は教師に 3.1〜12.2 点届かない．教師を超えたセルの割合は 0〜0.33 である．ただし 1 つのモダリティの線形の生徒が届きうる上限は仮のターゲットの出力に無く，この差のうち縮められる部分は測れていない（表 0・表 3）．
4. 融合の生徒では，残した教師の最良が none を 0.9〜2.5 点しか上回らず，oursx の格子の最良はすでにその教師を 0.5〜1.1 点上回る（85〜100% のセル）．1 つ抜いて選んだ値は教師と −0.5〜+0.4 点の差である（表 3）．
5. oursx の格子の中で UAR を最も動かす要因は，AVT の単モダリティの生徒では教師（分散の 44〜65%．教師だけを替えて残りを最良にしたときの幅 2.5〜5.1 点），AV の単モダリティの K=0・5 と融合の生徒では重みの付け方（35〜63%）である．総重みの割合は 1〜21% である（教師が ref の 1 つだけの AVT 融合 K=25 の 38% を除く）（表 5）．

## 何をしたか

### 読んだものと読まなかったもの

- 読んだファイル：`results/e77_<世界>/<T>_pseudo.csv`，`results/e78_<世界>/<T>_pseudo.csv`，`results/e80c_<世界>/<T>_pseudo.csv`，`results/e80/kept.csv` の 31 本（一覧は `diagnostic/out/provenance.json`）．台本 `exp/compare_dai.py`・`exp/compare_dai2.py`・`exp/analyze_e79.py`・`exp/e80_stage_c.py` と，文書 `proposal_v8.md`・`docs/exploratory-analyses.md` の E77・E78・E80 の節を読んだ
- 評価のターゲットの値（`<T>.csv`，`*_logp.npy`，`*_pred.npy`，`*_te.npy`，`*_teachers.npz`，`results/e79*/`，`results/e76*`，`results/e80c_*` の評価の行）は開いていない．台本 `diag.py` は Python の監査の仕掛け（`sys.addaudithook`）で `results/` の下の上の 4 種以外のファイルを開こうとしたら止まる．起動のたびに禁じたファイルを開けないことを確かめる
- `_conv.csv`・`_chosen.csv`・`results/e79/select/` も開いていない．そのため E79 の選択の段との突き合わせはしていない（下の「限界」）
- 計算は CPU だけ（15 秒）．GPU は使っていない

### 単位と語の定義

- **世界**：AVT（fuse-audio-video-text．生徒は音声・顔・言葉・融合）と AV（fuse-audio-video．生徒は音声・顔・融合）．K は 0・5・25
- **セル**：評価のターゲット T と仮のターゲットのコーパス c の組．各候補の値は「c の反復 0〜4 の UAR の平均」である．IEMOCAP の即興と台本は同じ話者なので 1 つのコーパスとし，値は 2 群の平均にした．AVT は 6 セル（T は IEMOCAP・MOSEI・MELD で，c はそれぞれ残りの 2 コーパス），AV は 20 セル（T は AFEW・CREMA-D・IEMOCAP・MELD・MOSEI で，c は残りの 4 コーパス）である
- 評価のターゲット T ＝ IEMOCAP 台本は外した．台本の仮のターゲットの行は即興の行の写し（`--copy-pseudo`）で，3 つの波の全行で値の差は 0，対応の付かない行は 0 だった（`out/checks.csv` の `script_equals_impro`）
- **平均（SD）**：セルの平均と，セルの間の標準偏差．「正の割合」は差が 0 より大きいセルの割合
- **族**（候補の集まり）
  - none：K 本だけで E39 から学び直す基準
  - oursx：dist の行のうち，教師が `kept.csv` で（世界, T, 生徒, K）ごとに残した教師，重みの付け方 5 つ（bal，raw，hard0.5・0.7・0.9），総重み 4 つ（100，500，2000，n）のもの．E79 の oursx と同じ定義
  - KD：kd と kdh の行で，教師が同じ残した教師のもの（温度 2・4 × 総重み 4）．E79 の kd と同じ
  - 群 B：entmin，self，im（総重み 100・500・2000・n），t3a（主の版），lp，coral，dann，mme．E79 の groupB と同じ．融合の生徒には dann・mme が無い
  - oursx77・KD77：教師をふるわない版．教師を E77 の教師（単モダリティの生徒は pF・pFK・ref，融合の生徒は dist が poe0・ref・ref0，KD が poe0・ref）に固定した
  - 教師：teacher の行（教師そのものの予測の UAR）．教師の配列は生徒に依らない
- **格子の最良（オラクル）**：c で測った値が最大の候補の値．c の答えを見て選ぶので，実際には選べない上限である
- **交差オラクル**：c の反復を 1 つ抜き，残り 4 反復で最良の候補を選び，抜いた反復で測る．これを 5 回行って平均する．5 反復の平均の最大は，たまたま高く出た候補を拾う分だけ高く出る（上げ底）．交差オラクルはこの上げ底を除いた上限の見積もりである
- **LOPO（leave-one-pseudo-out．仮のターゲットを 1 つ抜く選び方）**：c を抜き，残りの仮のターゲットの全行（群 × 反復）の UAR の単純平均が最大の候補を選び，c で測る．同点は「method|param|meff」の文字列の順で先頭を取る．E79 の select の段と同じ規則である
- **none 込み**：最良の候補の点数が none の点数より大きいときだけ候補を選び，そうでなければ none を選ぶ（E79 の P5 の規則）．**none 抜き**：必ず候補を選ぶ
- **取りこぼし**：上限 − LOPO の値．none 込みでは上限も none を含めて取る
- **順位相関**：Spearman の順位相関．候補を 2 通りの値で並べた順がどれだけ一致するかの量で，1 なら同じ順，0 なら無関係である

### 検算（`out/checks.csv`）

- E77・E78・E80 の段 c の none の行は，全部の（T, 仮のターゲット, 反復, 生徒, K）で値の差が 0 だった
- K に依らない教師（pF，poe0，agree，ds，mlp，poolC，other_*）は，複数の K に行がある 141 組で値の差が 0 だった．行の無い K はほかの K の値で埋めた
- 教師 agree の UAR は pF と全部のセルで同じだった（agree は pF に行ごとの定数を掛けたもので，最大の感情が変わらない）
- AV の T ＝ AFEW，顔の生徒，K=5 の oursx の 4 セルを別のコードで計算し直し，LOPO で選んだ候補，その値，格子の最良，none の値が一致した

## 限界

- **教師の集合に抜いた仮のターゲットの情報が入っている**：`kept.csv` は T の全部の仮のターゲットで教師をふるって作ったので，oursx と KD の LOPO では，抜いた c の値が教師の集合を通して選択に入る．教師をふるわない oursx77・KD77 の取りこぼしは oursx・KD と同じ程度で，行によって大きい側にも小さい側にも出た（表 2．例：AVT 音声 K=0 で oursx 2.2 点・oursx77 0.8 点，AVT 融合 K=0 で oursx 0.8 点・oursx77 1.9 点）
- **LOPO は E79 より少ないコーパスで選ぶ**：AVT は 1 コーパス（E79 は 2），AV は 3 コーパス（E79 は 4）で選ぶ．そのため LOPO の取りこぼしは E79 の実際の選択の取りこぼしより大きく出やすい．AVT の大きな取りこぼし（表 2）にはこの影響が含まれうる
- **交差オラクルにも上げ底が少し残る**：反復ごとのテストの話者は種を替えて引き直す（`exp/map.py` の `test_mask`）ので，反復どうしでテストの話者が一部重なる．抜いた反復が残りの反復と独立でないぶん，交差オラクルも上限を高めに見積もる．逆に，選ぶのに 4 反復しか使わないぶん低めにも出て，交差オラクルの取りこぼしが負になる行がある（最小 −0.4 点）
- **仮のターゲットは評価のターゲットとソースが違う**：仮のターゲット c のソースからは T と c の両方が抜ける．ここでの値は評価のターゲットの値の代わりにはならない
- **単モダリティの生徒の上限が無い**：候補の全ラベルで学び直した上限の参照（`ref_wstar`）は評価のターゲットでだけ作られ，仮のターゲットには無い．表 3 の「教師に届かない差」のうち，1 つのモダリティの線形の生徒で縮められる部分は分けられない
- **E79 との違い**：(a) E79 は，CORAL の r ごとの候補を，評価のターゲットの全反復で計算されたかを `_conv.csv` で確かめて外す．ここでは `_conv.csv` を開いていないので，その確認をしていない（仮のターゲットの全単位に値の無い候補は E79 と同じく外した．AV の T ＝ CREMA-D・IEMOCAP・MELD・MOSEI で coral の候補が生徒 × K あたり 36〜48 個外れた）．(b) MOSEI・MELD で IEMOCAP 台本を仮のターゲットから外した版（ns）は作っていない．(c) Co-teaching は E78 で回していないので入っていない．(d) E79 の選択の出力（`results/e79/select/chosen.csv`）とは突き合わせていない．全部の仮のターゲットで選んだ結果は `out/full_select.csv` にあり，突き合わせれば規則の写し方を確かめられる
- **関門**：この台本は gate-code の検査を通していない．実験としての登録（E 番号）が無く，出力の場所の指定（このフォルダ）の外に `checks/` を作らないためである．代わりに上の「検算」を台本の中で行った
- **見たデータ**：E77・E78・E80 の段 c の仮のターゲットの UAR を，族ごとに要約した形で見た．`docs/seen-data.md` への記録はしていない（出力の場所の指定による）．記録するなら「2026-11-02，仮のターゲットの値だけ，oursx・KD・群 B・教師の水準と LOPO の取りこぼし」の 1 行になる
