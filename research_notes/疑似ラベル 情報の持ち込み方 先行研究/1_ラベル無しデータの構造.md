## 問い 1：分類器の出力ではなく特徴空間の構造から疑似ラベルを作る手法はどれか（論文ごとのノート）

### Takeaway

手法の論文 14 本（評価の論文 P15 と理論の論文 P16 を除く）のうち 12 本は，分類器の予測かラベル付きの標本を重心の初期値，近傍の値，またはクラスタとクラスの対応づけに使い，疑似ラベルを特徴空間の距離（k 近傍，グラフの拡散，クラスの重心，GMM，k-means のクラスタ）で決める．TURTLE と XDC は分類器の予測もラベルも使わずに構造だけでラベル付け（XDC ではクラスタの番号）を作る．構造と分類器の両方を使う TransCLIP では，ゼロショットの予測への項を外すと 1 ショットの平均が 73.2% から 50.2% に下がる（表 4）．

#### P1．Iscen, Tolias, Avrithis, Chum 2019「Label Propagation for Deep Semi-supervised Learning」CVPR 2019［◎］

- 書誌：Ahmet Iscen, Giorgos Tolias, Yannis Avrithis, Ondrej Chum. CVPR 2019. arXiv:1904.04717. https://arxiv.org/abs/1904.04717 （本文は ar5iv の HTML で読んだ）— [Iscen 2019](https://ar5iv.labs.arxiv.org/html/1904.04717)
- **新しい情報**：学習中のネットワークの特徴 v_i = φ_θ(x_i) から作った k 近傍グラフの上で，ラベル付きの標本のラベルを拡散させた値．疑似ラベルは "pseudo-labels originate in diffusion rather than network predictions"（4 節）である — [Iscen 2019](https://ar5iv.labs.arxiv.org/html/1904.04717)
- **疑似ラベルと損失への入り方**（4 節．式は取得した本文の記述から書き直した．Y はラベル付きの行に one-hot を置いた行列という Zhou ほか 2004 の形と読んだ）— [Iscen 2019](https://ar5iv.labs.arxiv.org/html/1904.04717)

  ```
  a_ij = [v_iᵀ v_j]₊^γ   （v_i が v_j の k 近傍に入るとき．それ以外は 0）        … 式 (10)
  W = A + Aᵀ,   𝒲 = D^(−1/2) W D^(−1/2)
  (I − α𝒲) Z = Y   を共役勾配法で解く                                       … 式 (11)
  ŷ_i = argmax_j ẑ_ij   （ẑ_i は Z の i 行目を正規化したもの）                   … 式 (8)
  ω_i = 1 − H(ẑ_i) / log c        （拡散の結果のエントロピーによる確からしさの重み） … 式 (12)
  ζ_j = (|L_j| + |U_j|)^(−1)      （クラス j の本数に反比例する重み）
  損失 = Σ_{i∈L} ζ_{y_i} CE(f_θ(x_i), y_i) + Σ_{i∈U} ω_i ζ_{ŷ_i} CE(f_θ(x_i), ŷ_i)   … 式 (13)
  ```
- 設定は k = 50，γ = 3，α = 0.99，共役勾配法は最大 20 回である："We set k=50 for graph construction, γ=3 in (10)"（5.2 節）— [Iscen 2019](https://ar5iv.labs.arxiv.org/html/1904.04717)
- **仮定**：多様体の仮定（要旨）："The same holds for the manifold assumption—that similar examples should get the same prediction." — [Iscen 2019](https://ar5iv.labs.arxiv.org/html/1904.04717)
- **エンコーダ**：グラフは毎回の学習の後に今のネットワークの特徴で作り直す（Algorithm 1）．比較相手の GTG は "the network is pre-trained, the graph remains fixed and there is no weighting mechanism." と説明されている — [Iscen 2019](https://ar5iv.labs.arxiv.org/html/1904.04717)
- **報告（表 2，CIFAR-10 の誤り率 %，ラベル 500 / 1k / 2k / 4k 本）**— [Iscen 2019](https://ar5iv.labs.arxiv.org/html/1904.04717)

  - ネットワークの予測を疑似ラベルにし，同じ重みを付けたもの：35.17±2.46 / 23.79±1.31 / 16.64±0.48 / 13.21±0.61
  - 拡散を疑似ラベルにしたもの（提案）：32.40±1.80 / 22.02±0.88 / 15.66±0.35 / 12.69±0.29
  - Mean Teacher：27.45±2.64 / 19.04±0.51 / 14.35±0.31 / 11.41±0.25．Mean Teacher＋提案：24.02±2.44 / 16.93±0.70 / 13.22±0.29 / 10.61±0.28
  - "Diffusion predictions are consistently better than network predictions."（5.3 節），"show that our benefit is larger when the number of labels is reduced"（5.4 節）
- **報告（表 1，ラベル 500 本の除去実験）**：重みなし 36.53±1.42，ω だけ 36.17±1.98，ζ だけ 33.32±1.53，両方 32.40±1.80，GTG 35.20±2.23．取得した表の行と列の対応は崩れていたので，チェック印の位置は本文から推定した — [Iscen 2019](https://ar5iv.labs.arxiv.org/html/1904.04717)

#### P2．Liang, Hu, Feng 2020「Do We Really Need to Access the Source Data? Source Hypothesis Transfer for Unsupervised Domain Adaptation」（SHOT）ICML 2020［◎］

- 書誌：Jian Liang, Dapeng Hu, Jiashi Feng. ICML 2020. arXiv:2002.08546. https://arxiv.org/abs/2002.08546 — [SHOT 2020](https://ar5iv.labs.arxiv.org/html/2002.08546)
- **新しい情報**：ターゲットの特徴空間でのクラスの重心と，各標本から重心までのコサイン距離．動機は "pseudo labels that are conventionally generated by source hypotheses are still noisy due to domain shift."（3.3 節）と "We argue that the harmful effects result from the inaccurate network outputs."（3.3 節）— [SHOT 2020](https://ar5iv.labs.arxiv.org/html/2002.08546)
- **入り方**（3.3 節）— [SHOT 2020](https://ar5iv.labs.arxiv.org/html/2002.08546)

  ```
  c_k⁽⁰⁾ = Σ_x δ_k(f̂_t(x)) ĝ_t(x) / Σ_x δ_k(f̂_t(x))     （δ_k は softmax の k 番目．ĝ_t は特徴） … 式 (4)
  ŷ = argmin_k D_f(ĝ_t(x), c_k⁽⁰⁾)                     （D_f はコサイン距離）                … 式 (5)
  c_k⁽¹⁾ = Σ_x 1(ŷ = k) ĝ_t(x) / Σ_x 1(ŷ = k),   ŷ = argmin_k D_f(ĝ_t(x), c_k⁽¹⁾)          … 式 (6)
  ```
  著者は式 (4) を "similar to weighted k-means clustering," と書き，"experiments verify that updating for once gives sufficiently good pseudo labels." と書く．疑似ラベルは情報最大化（IM．式 (3)）の損失と一緒に交差エントロピーで使う．
- **学ぶもの**："SHOT freezes the hypothesis from source h_t = h_s and learns the feature encoder g_t"（3.3 節）．分類の頭を固定して特徴の抽出器を学ぶ — [SHOT 2020](https://ar5iv.labs.arxiv.org/html/2002.08546)
- **報告（表 6，平均の正解率 %，Office / Office-Home / VisDA-C）**— [SHOT 2020](https://ar5iv.labs.arxiv.org/html/2002.08546)
  - ソースのモデルのまま：79.3 / 60.2 / 46.6
  - 予測の argmax を疑似ラベルにしたもの（naive PL）だけ：83.0 / 64.1 / 76.6
  - 重心による疑似ラベル（self-supervised PL）だけ：87.6 / 68.9 / 80.7
  - L_ent だけ：83.5 / 55.5 / 63.3．L_ent＋L_div（SHOT-IM）：87.3 / 70.5 / 80.4
  - SHOT-IM＋naive PL：87.5 / 70.3 / 82.9．SHOT-IM＋重心の疑似ラベル（SHOT）：88.6 / 71.8 / 82.9
  - 著者の文："our self-supervised PL is always much better than the naive one."
- **限界**："SHOT needs a relatively large target domain to learn the hypothesis"（4.4 節．Office の小さいターゲット D と W で劣る理由として）．付録 B では L_div が "it encourages the target domain to own a uniform target label distribution." ので部分集合の DA には "not suitable" として外した — [SHOT 2020](https://ar5iv.labs.arxiv.org/html/2002.08546)

#### P3．Yang, Wang, van de Weijer, Herranz, Jui 2021「Exploiting the Intrinsic Neighborhood Structure for Source-free Domain Adaptation」（NRC）NeurIPS 2021［◎］

- 書誌：Shiqi Yang, Yaxing Wang, Joost van de Weijer, Luis Herranz, Shangling Jui. NeurIPS 2021. arXiv:2110.04202．arXiv の v3 で表 5 の数値 4 つと対応する本文を直した（書誌のコメント）— [NRC 2021](https://ar5iv.labs.arxiv.org/html/2110.04202)
- **新しい情報**：特徴空間で近い標本（特に互いに近傍である標本）の今の予測．観察（1 節，図 1）："target data of the same class is still expected to form a cluster in the embedding space."，"the blue curve in Figure 1(b) shows that around 75% of the nearest neighbors has the correct label."（Office-Home の Ar→Rw）— [NRC 2021](https://ar5iv.labs.arxiv.org/html/2110.04202)
- **入り方**（3.1・3.2 節．式は本文の記述から書き直した）："we build two memory banks: ℱ stores all target features, and 𝒮 stores corresponding prediction scores"，"We then use the prediction of the neighbors to supervise the training weighted by the affinity values" — [NRC 2021](https://ar5iv.labs.arxiv.org/html/2110.04202)

  ```
  L_N    = −(1/n_t) Σ_i Σ_{k∈N_K(i)} A_ik S_kᵀ p_i       （S_k は記憶にある近傍 k の予測）   … 式 (3)
  相互近傍： j ∈ N_K(i) かつ i ∈ N_M(j)                                                 … 式 (4)
  A_ik   = 1（相互近傍のとき），r（それ以外．既定 r = 0.1）                                … 式 (5)
  L_self = −(1/n_t) Σ_i S_iᵀ p_i                         （自分の今の予測も無視しない）    … 式 (6)
  L_div  = Σ_c KL(p̄_c ‖ q_c)，q は一様分布                                              … 式 (7)
  L_E    = 近傍の近傍（拡張近傍）に重み r を付けた L_N と同じ形                             … 式 (8)
  ```
  拡張近傍について："We directly assign a small affinity value r to those expanded neighbors, since they are further than nearest neighbors and may contain noise" — [NRC 2021](https://ar5iv.labs.arxiv.org/html/2110.04202)
- **仮定**："This assumption is implicitly adopted by most DA methods"，"However, this assumption is not true for all points;"（1 節），"some neighbors belong to different class and will provide the wrong supervision."（3.1 節）— [NRC 2021](https://ar5iv.labs.arxiv.org/html/2110.04202)
- **報告**：VisDA で 85.9（SHOT より 3 ポイント高い．表 3），Office-Home の平均 72.2（SHOT 71.8．表 2），Office-31 の平均 89.4（3C-GAN 89.6．表 1）．除去実験（4.2 節，表 5）："considering higher affinity values for reciprocal neighbors leads to a large performance gain (71.1 on Office-Home)"，拡張近傍は重みと組み合わせたときだけ役に立ち（72.2），"Using expanded neighborhoods without affinity obtains bad performance (65.2 on Office-Home)."．拡張近傍の代わりに K を大きくすると VisDA で 84.0（K = 30），Office-Home で 69.5（K = 9）— [NRC 2021](https://ar5iv.labs.arxiv.org/html/2110.04202)
- **限界**：限界の節は無く，チェックリストの "Did you describe the limitations of your work?" に "[No]" と答えている — [NRC 2021](https://ar5iv.labs.arxiv.org/html/2110.04202)

#### P4．Yang, Wang, Wang, Jui, van de Weijer 2022「Attracting and Dispersing: A Simple Approach for Source-free Domain Adaptation」（AaD）NeurIPS 2022［◎］

- 書誌：Shiqi Yang, Yaxing Wang, Kai Wang, Shangling Jui, Joost van de Weijer. NeurIPS 2022. arXiv:2205.04183. https://proceedings.neurips.cc/paper_files/paper/2022/hash/26300457961c3e056ea61c9d3ebec2a4-Abstract.html （読んだのは arXiv 版）— [AaD 2022](https://ar5iv.labs.arxiv.org/html/2205.04183)
- **新しい情報**：特徴空間の k 近傍（C_i）と，ミニバッチの中の近傍以外（B_i）の今の予測．"We propose to achieve SFDA by attracting predictions for features that are located close in feature space"（3.1 節）— [AaD 2022](https://ar5iv.labs.arxiv.org/html/2205.04183)
- **入り方**（3.1 節，式 (5)）— [AaD 2022](https://ar5iv.labs.arxiv.org/html/2205.04183)

  ```
  L_i(C_i, B_i) = − Σ_{j∈C_i} p_iᵀ p_j  +  λ Σ_{m∈B_i} p_iᵀ p_m                           … 式 (5)
  λ = (1 + 10·iter / max_iter)^(−β)
  ```
  "The first term aims to enforce prediction consistency between local neighbors"．近傍の数は Office-31 と Office-Home で 3，VisDA で 5．β は教師なしの選び方 SND で選ぶ："Based on SND we set β to 0 on Office-Home, 2 on Office-31 and 5 on VisDA."（4 節）

- **仮定**："similar features should have closer predictions than dissimilar ones"（1 節），"if target features are well clustering during training, we can presume the K-nearest neighbors"（3.2 節）— [AaD 2022](https://ar5iv.labs.arxiv.org/html/2205.04183)

#### P5．Zhang, Zhang, Zhang, Chen, Wang, Wen 2021「Prototypical Pseudo Label Denoising and Target Structure Learning for Domain Adaptive Semantic Segmentation」（ProDA）［◎］

- 書誌：Pan Zhang, Bo Zhang, Ting Zhang, Dong Chen, Yong Wang, Fang Wen. arXiv:2101.10979. https://arxiv.org/abs/2101.10979 ．会議名（CVPR 2021）は arXiv の書誌に無く，このセッションでは確かめていない — [ProDA](https://ar5iv.labs.arxiv.org/html/2101.10979)
- **新しい情報**：ターゲットの特徴から作ったクラスのプロトタイプ（重心）までの距離．動機は "high scores are not necessarily correct, making the network fail to learn reliable knowledge in the target domain."（1 節）と "the prototype lies closer to the true centroid of the underlying cluster"（1 節）— [ProDA](https://ar5iv.labs.arxiv.org/html/2101.10979)
- **入り方**（4.1 節）．重みはソースのモデルの**固定した**予測 p_{t,0} にかける — [ProDA](https://ar5iv.labs.arxiv.org/html/2101.10979)

  ```
  ω_t^(i,k) = exp(−‖f̃(x_t)^(i) − η^(k)‖ / τ) / Σ_k' exp(−‖f̃(x_t)^(i) − η^(k')‖ / τ)   （τ = 1）   … 式 (4)
  ŷ_t^(i) = ξ(ω_t^(i) ⊙ p_{t,0}^(i))   （ξ は最大の成分を 1 にする操作）                           … 式 (3)
  η^(k) ← λ η^(k) + (1 − λ) η′^(k)     （η′ はモメンタム・エンコーダの特徴のバッチ平均．λ = 0.9999） … 式 (6)
  ```

- **P10 BMD**：MER-DA のターゲットのラベル無しの発話は感情の割合が偏る（MOSEI・MELD は Neutral が多く，IEMOCAP 即興は Angry が 9.8%．[実験2_設計](/home/snics/MER-DA/DAI/docs/実験2_設計.md) 2.1 節）．予測で重みづけた重心は多いクラス・当てやすいクラスに引っ張られるという BMD の指摘は，この偏りの下で SHOT 型や T3A 型の重心に当てはまる．BMD の上位 M 本を選ぶ規則は M = n_t/(3×4) なので，MER-DA のラベル無しの発話の数に応じて決まる．
- **P11 TAST**：特徴を凍結する点は MER-DA と同じである．近傍の投票の上乗せは T3A に対して平均 0.43 ポイント（TAST-N）と小さく，PACS では Tent より低い．MER-DA で T3A が AFEW でだけ上回ったという記録（[難しさの記録](/home/snics/MER-DA/DAI/docs/難しさの記録_2026-11-05.md) 2 節）と合わせると，T3A に近傍を足すだけで大きな差が出るとは考えにくい．
- **P13 TURTLE**：MER-DA の 3 モダリティの特徴は「複数の凍結した表現空間」にあたり，分類器も線形の頭なので，TURTLE の前提に最も近い．TURTLE の目的が選ぶのは「どの空間でも線形に分けやすいラベル付け」であり，それが感情のラベル付けと一致するかは表現の質による．WavLM や RoBERTa の空間では話者・話題・録音のまとまりが感情より分けやすい可能性があり，その場合はラベル無しの TURTLE は感情以外のラベル付けを選ぶ．TURTLE の外側の損失は「各空間の線形の分類器が同じラベル付けを再現できるか」を測るので，単独の分類器の予測の積を目標にする今の疑似ラベルとは使う情報が違う（積は今の 3 つの頭の出力だけから作るが，TURTLE はラベル付けを変えて各空間で線形の分類器を学び直した結果を使う）．
- **P14 XDC**：xMUDA 型と柔らかい共訓練は別のモダリティの**予測**を目標にした．XDC は別のモダリティの**特徴のクラスタ**を目標にするので，別のモダリティの頭が見ない次元の情報も入る．ただし XDC のクラスタは感情のクラスに対応しない（Kinetics のラベルで見て下位のクラスタはまとまりが無い）うえに，エンコーダをゼロから学ぶ手法なので，凍結した特徴と線形の頭の MER-DA でクラスタの番号をどう使うかは論文から決まらない．
- **P15 Veilleux**：MER-DA の K 本は感情ごとに同じ本数で，ラベル無しの発話の割合は偏るので，Veilleux の「支えは釣り合い，問い合わせは偏る」設定と同じ形である．試した IM（周辺のエントロピーの項）と，感情ごとの総量をそろえたラベル伝播は，どちらも一様の割合を前提にする項を持つ．ただし Veilleux の指標は正解率で，MER-DA の UAR はクラスごとの再現率を等しく重みづけるので，一様の割合へ寄せる項は少ないクラスの再現率を上げて UAR をむしろ上げる場合がある．Veilleux の「偏ると下がる」結果をそのまま UAR に移すことはできない．
- **P16 Cai**：この理論は，疑似ラベルの元の分類器が誤っていても，近傍の一致を強く課せば誤りを直せることを示す．条件は，(i) 各部分集団の近傍が十分に広がる（拡張），(ii) 正解のラベルそのものが近傍でほぼ一定（R_B(g*) < μ），(iii) 学ぶ分類器が近傍で一定の関数を表せることである．凍結した特徴の上の線形の頭は，近傍のグラフの上で一定の関数を一般には表せないので，(iii) が成り立たない可能性がある．また (ii) は「感情が同じ発話どうしが特徴空間で近い」ことを求め，MER-DA で確かめた数は無い．

### Gaps

- 音声・顔・言葉の凍結したエンコーダの特徴で，構造から作る疑似ラベルを感情認識に使って評価した論文は，今回の検索では見つからなかった．候補の「Two-stage adaptation for cross-corpus multimodal emotion recognition」（NLPCC 2023．https://link.springer.com/10.1007/978-3-031-44696-2_34）は検索結果の題名と抜粋だけを見た［△］．Springer のページは認証に回され，AMiner のページは本文を返さなかった．検索結果の抜粋はクラスタに基づく損失と順位による疑似ラベルの選別を書いていたが，原文で確かめていない．
- AaD の NeurIPS の最終版に，ラベルの割合のずれ（VisDA-RSUT など）の実験があるかは確かめていない（読んだのは arXiv 版）．
- ProDA の会議名（CVPR 2021）と TransCLIP の会議名（NeurIPS 2024）は arXiv の書誌に無く，このセッションでは確かめていない．
- TAST と Cai ほか 2021 は本文の前半約 10 万字だけを読み，付録の後半は読んでいない．
- 古典の土台（Zhou ほか 2004 のラベル伝播，Chapelle & Zien 2005 などのクラスタの仮定）は，このセッションでは原文を読み直していない．
- 複数のモダリティの疑似ラベルを融合する SUMMIT（Simons ほか，ICCV 2023．https://arxiv.org/abs/2308.11880）は検索結果だけを見た［△］．検索結果の抜粋では予測の一致による選別とエントロピーによる重みづけを切り替える手法で，予測に基づく族に入ると読めるが，原文で確かめていない．

## 問い 2：構造は分類器に無い何を足すのか．どの条件で効き，どの条件で効かないと著者は言うか

### Takeaway

構造が足す情報は 3 種類に分かれる：(a) 特徴の全次元を使った標本どうしの距離（近傍，グラフ），(b) ラベル無しの標本の集まりから推定したクラスの位置と広がり（重心，GMM，クラスタ），(c) 別の表現空間でのまとまり（XDC，TURTLE）．どの手法も同じクラスの標本が特徴空間でまとまること（TURTLE では線形に大きい余白で分けられること）を前提にしており，その前提が成り立たない標本やクラスタでは疑似ラベルが誤ると著者自身が書いている（NRC の例では近傍のうち正しいラベルを持つのは約 75%）．

### Cited Findings

- **(a) 全次元の距離**：Iscen の疑似ラベルは "originate in diffusion rather than network predictions" で，ネットワークの予測に同じ重みを付けた疑似ラベルより誤り率が低い（ラベル 500 本で 35.17 → 32.40，4000 本で 13.21 → 12.69．表 2）— [Iscen 2019](https://ar5iv.labs.arxiv.org/html/1904.04717)
- AdaContrast は "by aggregating knowledge of nearby points we can get a more informed estimate, potentially recovering the correct label." と書き，近傍の直しで VisDA-C を 55.0 から 86.5 に上げた（表 4，学習率 1 倍）— [AdaContrast 2022](https://ar5iv.labs.arxiv.org/html/2204.10377)
- LaplacianShot のラプラシアンの項は，1 ショットで +3.10（直さないプロトタイプ）と +2.37（直したプロトタイプ），5 ショットで +0.83 と +0.30 を足す（表 4）— [LaplacianShot 2020](https://ar5iv.labs.arxiv.org/html/2006.15486)
- TAST の近傍の予測は T3A に平均 0.43 ポイントを足す（表 2）— [TAST 2023](https://ar5iv.labs.arxiv.org/html/2207.10792)
- **(b) クラスの位置と広がり**：SHOT の重心の疑似ラベルは，単独で使うと予測の argmax より Office-Home で 4.8 ポイント（64.1 → 68.9），Office で 4.6 ポイント高い（表 6）— [SHOT 2020](https://ar5iv.labs.arxiv.org/html/2002.08546)
- ProDA のプロトタイプによる直しは，自己学習の 45.2 を 52.3 に上げる（表 3）— [ProDA](https://ar5iv.labs.arxiv.org/html/2101.10979)
- CAN で，クラスタのラベルを使わずネットワークの出力をそのまま疑似ラベルにすると，VisDA-2017 で 87.2 から 77.5 に下がる（表 3）— [CAN 2019](https://ar5iv.labs.arxiv.org/html/1901.00976)
- SPL で，クラスタの予測は最近傍のプロトタイプより 2.2 ポイント（選ぶ段あり）または 6.4 ポイント（選ぶ段なし）高い（表 5，Office-Caltech）— [SPL 2020](https://ar5iv.labs.arxiv.org/html/1911.07982)
- TransCLIP で GMM の共分散を更新しないと EuroSAT で 65.1 から 51.6 に下がり，ラプラシアンを外したときの差（65.1 → 64.5）より大きい（表 6(a)）— [TransCLIP 2024](https://arxiv.org/html/2406.01837v1)
- BMD は，予測で重みづけた中心 1 つの疑似ラベルを，クラスで本数をそろえた複数の中心に替えて，VisDA-C で 82.9 から 84.7 に上げる（表 5）— [BMD 2022](https://ar5iv.labs.arxiv.org/html/2204.02811)
- **(c) 別の表現空間**：XDC で別のモダリティのクラスタを目標にすると，同じモダリティのクラスタ（SDC）より UCF101 で 12.4 ポイント，つないだ特徴のクラスタ（CDC）より 1.3 ポイント高い（表 1）．理由は "XDC groups samples together when they are similar in one of the two modalities" — [XDC 2020](https://ar5iv.labs.arxiv.org/html/1911.12667)
- TURTLE は空間 1 つで CLIP のゼロショットと同じ水準，空間 2 つで 4〜9 ポイント上回る（5.2 節）— [TURTLE 2024](https://arxiv.org/html/2406.07236v1)
- **構造だけではクラスの名前が決まらない**：TransCLIP でテキストの項を外すと 1 ショットの平均が 73.2 から 50.2 に下がる（表 4）— [TransCLIP 2024](https://arxiv.org/html/2406.01837v1)．SPL はクラスタとクラスの対応にプロトタイプを使い — [SPL 2020](https://ar5iv.labs.arxiv.org/html/1911.07982)，SHOT は重心を予測の確率で初期化する — [SHOT 2020](https://ar5iv.labs.arxiv.org/html/2002.08546)．
- **効く条件（著者の記述）**：NRC "target data of the same class is still expected to form a cluster in the embedding space." — [NRC 2021](https://ar5iv.labs.arxiv.org/html/2110.04202)．AaD "if target features are well clustering during training, we can presume the K-nearest neighbors" — [AaD 2022](https://ar5iv.labs.arxiv.org/html/2205.04183)．TAST "require good prototypes in the embedding space" — [TAST 2023](https://ar5iv.labs.arxiv.org/html/2207.10792)．Cai の理論は拡張の仮定と，正解のラベルが近傍で一致すること（R_B(g*) < μ）を要し，その下で "This result does not rely on the teacher being close to zero error." — [Cai 2021](https://ar5iv.labs.arxiv.org/html/2102.11203)
- **ラベルが少ないほど得が大きい**：Iscen "our benefit is larger when the number of labels is reduced" — [Iscen 2019](https://ar5iv.labs.arxiv.org/html/1904.04717)．TransCLIP "the gain of TransCLIP-ZS on top of few-shot methods tends to decrease when the number of shots is high" — [TransCLIP 2024](https://arxiv.org/html/2406.01837v1)．LaplacianShot の得も 1 ショットで大きく 5 ショットで小さい（表 4）— [LaplacianShot 2020](https://ar5iv.labs.arxiv.org/html/2006.15486)
- **効かない条件（著者の記述）**：NRC "this assumption is not true for all points;"，"some neighbors belong to different class and will provide the wrong supervision." — [NRC 2021](https://ar5iv.labs.arxiv.org/html/2110.04202)．ProDA "the prototypes fail to rectify the labels of the data whose features lie in the far end of the cluster" — [ProDA](https://ar5iv.labs.arxiv.org/html/2101.10979)．SHOT "SHOT needs a relatively large target domain to learn the hypothesis" — [SHOT 2020](https://ar5iv.labs.arxiv.org/html/2002.08546)．AdaContrast "is prone to diverge due to bad hyper-parameter selection and compounding errors." — [AdaContrast 2022](https://ar5iv.labs.arxiv.org/html/2204.10377)．TAST の凍結した特徴の手法は画像の劣化のベンチマークで適応なしより悪い（CIFAR-100C の誤り率 60.74 対 60.35）— [TAST 2023](https://ar5iv.labs.arxiv.org/html/2207.10792)

### Inferences

**MER-DA への当てはまり（推測）**

- 線形の頭の予測は，特徴を 4 本の重みベクトルに射影した値だけで決まる．WavLM の 1,024 次元のうち頭が見るのはこの 4 方向（クラスの差で言えば 3 方向）で，残りの次元の違いは予測に出ない．近傍とグラフ（種類 (a)）は全次元の距離を使うので，今の 3 つの頭の予測に無い情報を持ちうる．今の積の疑似ラベルは 3 つの頭の出力だけから作るので，この全次元の情報を含まない．
- 種類 (b) のうち，硬い最近傍の重心と共通の共分散の GMM は判定の境界が線形なので，融合の頭で表せる．この場合の新しい情報は境界の「形」ではなく，ラベル無しの発話の集まりから推定した重心の位置にある．K = 25（100 本）のラベルで学んだ 2,304 次元の重みの向きのずれ（[難しさの記録](/home/snics/MER-DA/DAI/docs/難しさの記録_2026-11-05.md) 1 節）に対して，ラベル無しの発話の重心がどれだけ向きを直せるかは，論文からは決まらない．
- 種類 (c) は，単独の頭どうしの依存の問題に関わる．今の手法では 3 つの頭が同じ積の目標に向けて学ぶので，誤りがそろう方向に動く．別の空間のクラスタや近傍から作る目標はモダリティごとに違う値になりうる．これが依存を減らすかどうかを調べた論文は今回見つからなかった．
- 複数の論文で得がラベルの少ないときに大きいので，MER-DA で構造の情報が効くとすれば K = 0〜5 であり，K = 25 では小さいと見込める．

### Gaps

- 構造の情報が「分類器の予測と独立な情報をどれだけ持つか」を数で測った論文（例：構造の疑似ラベルと分類器の予測の誤りの相関）は見つからなかった．
- 単独の分類器どうしの依存（誤りの相関）が構造の疑似ラベルで減るかを測った論文は見つからなかった．
- 同じ手法をエンコーダを凍結した場合と学習した場合で比べた論文は見つからなかった（Iscen の GTG との比較は重みの有無も違うので切り分けにならない）．

## 問い 3：凍結したエンコーダと線形の頭だけ（エンコーダの更新なし，データ拡張なし）で動くのはどれか

### Takeaway

特徴の抽出器を更新せず，手法の段にデータ拡張の記述も無いのは，LaplacianShot，TransCLIP，TURTLE，TAST，SPL の 5 本と，評価の論文の Veilleux である（SPL は特徴を微調整したかを書いていない）．このうち分類器も線形のままで済むのは TURTLE（各空間の線形の分類器）と TransCLIP・LaplacianShot（学習を伴わない割り当ての最適化）で，TAST は凍結した特徴の上に小さな部品を足して学び，SPL は特徴の射影を学ぶ．SHOT，NRC，AaD，BMD，CAN，XDC は特徴の抽出器を学び，ProDA と AdaContrast はさらにデータ拡張を要する．

### Inferences

**MER-DA への当てはまり（推測）**

- 特徴を学ぶ手法（SHOT，NRC，AaD，BMD，CAN）のうち，疑似ラベルを作る段（重心，近傍の予測，クラスで本数をそろえた複数の中心，クラスの中心から始める k-means）は，凍結した特徴の上でもそのまま計算できる．失われるのは，学習で特徴空間のまとまりを締め，次の回の疑似ラベルを良くする繰り返しである．凍結した特徴では近傍の構造が最初から最後まで変わらない（[実験2_設計](/home/snics/MER-DA/DAI/docs/実験2_設計.md) 2.4 節と同じ見方）．
- SHOT は頭を固定して特徴の抽出器を学び，MER-DA は特徴を固定して頭を学ぶので，学ぶ部分が逆である．SHOT の重心の疑似ラベルの得は，重心が抽出器の学習で動くことを含んだ数値である．
- MER-DA の条件（凍結，線形，拡張なし）に最も近い形は TURTLE と TransCLIP である．TURTLE はラベルを使わない設定で書かれ，TransCLIP は 1 つの表現空間（画像）とゼロショットの予測を使う．3 つのモダリティの空間と K 本のラベルとソースの予測を同時に入れた形は，どちらの論文にも無い．

### Gaps

- 音声（WavLM），顔（ResNet-50），言葉（RoBERTa）の凍結した特徴の上で，ここに挙げた手法を評価した論文は見つからなかった．
- TAST の適応の部品の構造（層の数や大きさ）は，読んだ範囲では確かめていない．

## 問い 4：クラスタとクラスが合わないとき，ドメイン間でクラスの割合が違うときに何が起きると報告されているか

### Takeaway

一様のクラスの割合を前提にする項は，TIM の周辺のエントロピー，PT-MAP の一様の制約，SHOT と NRC の多様性の項，TURTLE のエントロピーの項，TransCLIP の釣り合った GMM にある．ラベル無し集合の割合が偏ると性能が下がることを数値で示したのは Veilleux ほか 2021 で，PT-MAP が 16.8〜18.2 ポイント下がり，評価した転導的手法の半分より多くが帰納的な基準を下回った．同じ評価で LaplacianShot（プロトタイプと k 近傍のラプラシアン）の低下は 0.2〜4.7 ポイントだった．TURTLE は図だけで示し，SHOT は部分集合の DA で多様性の項を外した．クラスタとクラスが合わない場合を設計して測った論文は見つからず，著者が限界や観察として書いた文があるだけである．

### Cited Findings

- **割合が偏ると何が下がるか**：Veilleux の表 1（mini-ImageNet，ResNet-18，ディリクレ a = 2）で，PT-MAP は ↓16.8〜↓18.2，Entropy-min は ↓5.1〜↓8.0，TIM（λ を調整）は ↓3.7〜↓4.5，LaplacianShot は ↓4.7（1 ショット），↓0.5（5 ショット），↓0.2（10 ショット），↑0.5（20 ショット）．"more than half of the transductive methods evaluated perform overall worse than inductive baselines in our realistic setting." — [Veilleux 2021](https://arxiv.org/pdf/2204.11181)
- 理由について Veilleux は，周辺のエントロピーが一様分布への KL として働くと書く（4 節．記号の表示は整えた）："minimizing marginal entropy H(YQ ) is equivalent to minimizing the KL divergence between the predicted marginal distribution p̂ = (p̂1 , . . . , p̂K ) and uniform distribution"．この項を外すとかえって悪く，重みを下げると改善する — [Veilleux 2021](https://arxiv.org/pdf/2204.11181)
- 偏りを強めると "past a certain imbalance severity, the inductive baseline in [33] becomes more competitive than" 転導的手法になる（6.2 節，図 4）．問い合わせの割合が偏ると転導的なバッチ正規化も性能を下げる — [Veilleux 2021](https://arxiv.org/pdf/2204.11181)
- TURTLE の付録 G："Note that the optimal solution of (11) is to produce a labeling with the equal number of samples for each class."，"a strong entropy regularization might hurt the learning process."（不均衡な 5 データセット：Birdsnap，FER2013，GTSRB，KITTI，HatefulMemes）．付録 H では，訓練の分割が釣り合いテストの分割が偏る Caltech101 と Flowers102 で結果が違うことを，この偏りに帰している — [TURTLE 2024](https://arxiv.org/html/2406.07236v1)
- SHOT の付録 B：多様性の項は "it encourages the target domain to own a uniform target label distribution." なので部分集合の DA では外す — [SHOT 2020](https://ar5iv.labs.arxiv.org/html/2002.08546)
- NRC の多様性の項は q を一様分布とする（式 7）— [NRC 2021](https://ar5iv.labs.arxiv.org/html/2110.04202)．AaD は周辺のエントロピーが "presumes the prior that whole dataset or the mini-batch is class balance/uniformly distributed" と批判し，その前提は "barely true for current benchmarks or in real-world environment" と書く — [AaD 2022](https://ar5iv.labs.arxiv.org/html/2205.04183)
- TransCLIP はデータを "a balanced mixture of multivariate Gaussian distributions" とみなし，読んだ範囲に不均衡の解析は無い — [TransCLIP 2024](https://arxiv.org/html/2406.01837v1)
- 重心やクラスタの側の偏り：BMD は予測で重みづけた重心が当てやすいクラスに偏ると書き，クラスで本数をそろえて作り直した（VisDA-C の c_v 0.155 → 0.118）— [BMD 2022](https://ar5iv.labs.arxiv.org/html/2204.02811)．SPL は信頼度で選ぶと "this strategy has a risk of only selecting samples from specific classes while overlooking the other classes" ので，クラスごとに選ぶ — [SPL 2020](https://ar5iv.labs.arxiv.org/html/1911.07982)．CAN は学習の初めに "it is more likely to exclude partial classes" — [CAN 2019](https://ar5iv.labs.arxiv.org/html/1901.00976)．TAST の付録 D："classifier bias may occur, which may result in assigning most test data only to a subset of classes." — [TAST 2023](https://ar5iv.labs.arxiv.org/html/2207.10792)．ProDA は逆に "prototypes treat different classes equally regardless of their occurrence frequency" を少ないクラスで得をする理由に挙げる — [ProDA](https://ar5iv.labs.arxiv.org/html/2101.10979)
- Iscen はクラスの本数に反比例する重み ζ_j を付け，ラベル 500 本の除去実験で ζ だけで 36.53 → 33.32 に下げた（表 1）— [Iscen 2019](https://ar5iv.labs.arxiv.org/html/1904.04717)
- **クラスタとクラスが合わない場合（著者の記述だけ）**：SPL "they might be boundaries of domains rather than classes"，"the cluster assumption in UDA is different from that in the semi-supervised learning problem" — [SPL 2020](https://ar5iv.labs.arxiv.org/html/1911.07982)．XDC "Many other bottom-ranked clusters appear to lack semantic coherence when viewed through the lens of Kinetics labels." — [XDC 2020](https://ar5iv.labs.arxiv.org/html/1911.12667)．TURTLE は空間 2 つが空間 1 つより悪いデータセット（Rendered SST2，HatefulMemes，GTSRB，Country211，CLEVR）について "the discrepancy might stem from the suboptimality of DINOv2 representations" と書く — [TURTLE 2024](https://arxiv.org/html/2406.07236v1)．NRC "this assumption is not true for all points;" — [NRC 2021](https://ar5iv.labs.arxiv.org/html/2110.04202)．ProDA "the prototypes fail to rectify the labels of the data whose features lie in the far end of the cluster" — [ProDA](https://ar5iv.labs.arxiv.org/html/2101.10979)
- **理論の側**：Cai の上界は，正解の関数そのものの近傍での不一致 R_B(g*) が小さいこと（部分集団の間に 2r の隔たりがあること）を要する．近傍がクラスをまたぐ場合の議論は読んだ範囲に無い — [Cai 2021](https://ar5iv.labs.arxiv.org/html/2102.11203)

### Inferences

**MER-DA への当てはまり（推測）**

- MER-DA のラベル無しの発話は感情の割合が偏り（MOSEI・MELD の Neutral，IEMOCAP 即興の Angry 9.8%．[実験2_設計](/home/snics/MER-DA/DAI/docs/実験2_設計.md) 2.1 節），K 本は感情ごとに同じ本数である．これは Veilleux の設定（支えは釣り合い，問い合わせは偏る）と同じ形である．試した IM と，感情ごとの総量をそろえたラベル伝播は，一様の割合を前提にする項を持つ．
- ただし Veilleux の低下は正解率で測った値である．UAR は感情ごとの再現率の平均なので，一様の割合へ寄せる項は少ない感情の再現率を上げ，UAR を上げる方向にも働く．偏りが UAR に与える影響の向きと大きさは，論文からは決まらない．
- クラスタとクラスの不一致については，凍結した WavLM・ResNet-50・RoBERTa の特徴空間で，近傍が同じ感情である割合（NRC の図 1 の約 75% に当たる数）を MER-DA で測った記録は無い．この数が低い場合，近傍・グラフ・クラスタの疑似ラベルは Cai の理論の前提（正解のラベルが近傍で一致する）を満たさない．SPL の「クラスタがクラスでなくドメインの境界になる」という指摘は，MER-DA では話者や録音条件のまとまりに当てはまりうる．

### Gaps

- クラスタとクラスが合わない状況を人工的に作って（例：クラスタの数をクラスの数とずらす，クラスと関係ないまとまりを足す）構造の疑似ラベルの性能を測った論文は，今回の検索では見つからなかった．
- ソースとターゲットでクラスの割合が違うときに，近傍型の手法（NRC，AaD）の性能を測った数値は，読んだ範囲に無かった（AaD の最終版と NRC の後続の論文は確かめていない）．
- 感情認識の特徴（話者や録音条件でまとまりやすいとされる）で，特徴空間のクラスタが感情と話者のどちらに沿うかを測った論文は，今回は探していない．
- Veilleux の結果を UAR（クラスごとの再現率の平均）で測り直した論文は見つからなかった．
