## 問い 1：ラベルシフトの推定と補正は何を仮定し，p(x|y) が変わると（コーパスをまたぐ感情のデータのように）どうなるか

### Takeaway

ラベルシフトの推定法（Saerens の EM，BBSE，RLLS，較正つきの最尤法）はすべて「クラスの中の特徴の分布 p(x|y) がソースとターゲットで同じ」ことを仮定し，ターゲットのラベル無しのデータから得る新しい情報は「クラスの割合 q(y) という 4 次元の集計値」だけである．p(x|y) も変わるデータでは BBSE が補正なしより悪くなる結果（DomainNet でクラスごとの正解率の平均 62.52% → 55.25%）があり，割合の推定の当たりは p(x|y) のずれ方に左右される．さらに，UAR（クラスごとの再現率の平均）を最大にする判定はクラスの割合に依存しないので，MER-DA で割合の補正が直せるのはロジットの切片の部分だけだと推測する．

### Cited Findings

#### 1-1 Saerens, Latinne, Decaestecker 2002（EM で新しい割合を推定する）◎

書誌：M. Saerens, P. Latinne, C. Decaestecker, "Adjusting the Outputs of a Classifier to New a Priori Probabilities: A Simple Procedure," Neural Computation 14(1):21–41, 2002．DOI 10.1162/089976602753284446．本文 PDF：[ULB リポジトリ](https://dipot.ulb.ac.be/dspace/bitstream/2013/68391/1/Decaestecker_NeuralComp02.pdf)．

- **新しい情報：**ラベル無しの新しいデータ全体での，識別器の出力の平均が作る新しい割合 p̂(ωᵢ)．識別器を学び直さず，出力だけを直す．— [Saerens 2002](https://dipot.ulb.ac.be/dspace/bitstream/2013/68391/1/Decaestecker_NeuralComp02.pdf)
- **入り方（2.2 節の式 (4)）：**学習時の割合を p_t(ωᵢ)，学習した識別器の出力を p_t(ωᵢ|x) と書くと，直した事後確率は次になる．各クラスに定数 p̂(ωᵢ)/p_t(ωᵢ) を掛けて正規化するだけである．— [Saerens 2002](https://dipot.ulb.ac.be/dspace/bitstream/2013/68391/1/Decaestecker_NeuralComp02.pdf)
  ```
  p̂(ωᵢ|x) = [p̂(ωᵢ)/p_t(ωᵢ)]·p_t(ωᵢ|x) / Σⱼ [p̂(ωⱼ)/p_t(ωⱼ)]·p_t(ωⱼ|x)
  ```
- **EM の反復（3 節の式 (9)）：**初期値 p⁽⁰⁾(ωᵢ) = p_t(ωᵢ) から，E 段で上の式の事後確率を各標本 x_k について計算し，M 段で割合をその平均で置き換える．— [Saerens 2002](https://dipot.ulb.ac.be/dspace/bitstream/2013/68391/1/Decaestecker_NeuralComp02.pdf)
  ```
  p⁽ˢ⁾(ωᵢ|x_k) = [p⁽ˢ⁾(ωᵢ)/p_t(ωᵢ)]·p_t(ωᵢ|x_k) / Σⱼ [p⁽ˢ⁾(ωⱼ)/p_t(ωⱼ)]·p_t(ωⱼ|x_k)
  p⁽ˢ⁺¹⁾(ωᵢ) = (1/N) Σ_k p⁽ˢ⁾(ωᵢ|x_k)
  ```
- **仮定（2.2 節）：**"In the sequel, we will assume that the generation of the observations within the classes, and thus the within-class densities, p(x|ωi), do not change from the training set to the new data set (only the relative proportion of measurements observed from each class has changed)." 結論（6 節）では仮定を 3 つに整理し，3 つ目を "The new data set to be scored is large enough in order to be able to estimate accurately the new a priori class probabilities." と書く．— [Saerens 2002](https://dipot.ulb.ac.be/dspace/bitstream/2013/68391/1/Decaestecker_NeuralComp02.pdf)
- **報告された数値：**2 クラスで，学習の割合を (50%, 50%) にした多層パーセプトロン．表 4（実データ 3 つ，真の割合 20%）の正解率は，Diabetes で補正なし 67.4% → EM 76.3%（真の割合を使うと 78.3%），Breast で 91.3% → 92.0%（92.6%），Liver で 68.0% → 75.7%（79.1%）．EM が推定した割合は Diabetes 24.8%，Breast 18.0%，Liver 24.6%．表 2（人工データ Ringnorm）では，真の割合が 10% のとき 90.1% → 93.6%，50%（ずれ無し）のとき 87.0% → 86.9% である．— [Saerens 2002](https://dipot.ulb.ac.be/dspace/bitstream/2013/68391/1/Decaestecker_NeuralComp02.pdf)
- **著者が書いた限界：**"We also observed that adjusting the outputs of the classifier when not needed (i.e. when the a priori probabilities of the training set and the real-world data do not differ) can result in a decrease in classification accuracy."（6 節）．このため尤度比検定で割合が変わったかを先に判定することを勧める．また 4.1 節で "The a priori estimates appeared as slightly biased towards 50%; this appears as a bias affecting the neural network classifier trained on an equidistributed training set." と書く．指標は正解率で，クラスごとの再現率の平均ではない．— [Saerens 2002](https://dipot.ulb.ac.be/dspace/bitstream/2013/68391/1/Decaestecker_NeuralComp02.pdf)

#### 1-2 Lipton, Wang, Smola 2018（BBSE：混同行列で割合を推定する）◎

書誌：Z. C. Lipton, Y.-X. Wang, A. J. Smola, "Detecting and Correcting for Label Shift with Black Box Predictors," ICML 2018（PDF の頁に "Proceedings of the 35th International Conference on Machine Learning" とある）．[arXiv 1802.03916](https://arxiv.org/abs/1802.03916)．

- **新しい情報：**ソースの取り置きデータ（学習に使っていない分）で測った識別器 f の混同行列 C と，ターゲットのラベル無しのデータでの予測の頻度 μ̂_ŷ．混同行列は「ソースの標本で f がどう間違えるか」の情報で，f の出力だけからは得られない．— [Lipton 2018](https://arxiv.org/abs/1802.03916)
- **入り方：**ターゲットの予測の頻度は混同行列と重み w(y) = q(y)/p(y) の積になる．推定した重みで，ソースの標本の損失に重みを掛けて学び直す（重要度重みつきの経験損失最小化．BBSC）．負の重みは 0 に切る．— [Lipton 2018](https://arxiv.org/abs/1802.03916)
  ```
  μ_ŷ = C_ŷ|y μ_y = C_ŷ,y w
  ŵ = Ĉ_ŷ,y⁻¹ μ̂_ŷ ,   μ̂_y = diag(ν̂_y) ŵ
  ```
- **仮定（2 節の A.1〜A.3）：**A.1 "p(x|y) = q(x|y) ∀ x ∈ X, y ∈ Y."，A.2 ターゲットに現れるクラスはソースにも現れる，A.3 "Access to a black box predictor f : X → Y where the expected confusion matrix Cp(f) is invertible." 著者は A.1 について "This assumption is strong but reasonable in many practical situations, including medical diagnosis, where diseases cause symptoms." と書く．要旨では "BBSE works even when predictors are biased, inaccurate, or uncalibrated, so long as their confusion matrices are invertible." と主張する．— [Lipton 2018](https://arxiv.org/abs/1802.03916)
- **誤差の上界（定理 3 の式 (2)）：**‖ŵ − w‖₂² は C の最小の特異値 σ_min の 2 乗に反比例し，‖w‖₂² とソースの標本数 n・ターゲットの標本数 m に依存する．著者は "If f cannot distinguish between certain classes at all, then Cŷ,y will be low-rank, σmin = 0, and the technique is invalid, as expected." と書く．— [Lipton 2018](https://arxiv.org/abs/1802.03916)
- **報告された数値：**MNIST と CIFAR10 で割合のずれを人工的に作った実験で，推定の誤差と補正後の正解率を図 2〜4 に示す．数値は図だけで，表は無い．— [Lipton 2018](https://arxiv.org/abs/1802.03916)
- **著者の主張と限界：**5.2 節で "It is one of the first things to try even when the label-shift assumption doesn't hold." と主張する（この主張は 1-8 の COAL の結果と食い違う）．7 節では "when no label shift occurs, applying BBSC might damage the classifier" と書き，また f をデータの半分で学ぶので "which makes BBSE to perform worse than baseline when the data set is extremely small." と書く．混同行列が退化したときは，硬い予測の代わりに確率の出力を使う（ソフトな混同行列），クラスをまとめる，擬似逆行列を使う，の 3 つを挙げる．— [Lipton 2018](https://arxiv.org/abs/1802.03916)

#### 1-3 Azizzadenesheli, Liu, Yang, Anandkumar 2019（RLLS：少数標本のための正則化）◎

書誌：K. Azizzadenesheli, A. Liu, F. Yang, A. Anandkumar, "Regularized Learning for Domain Adaptation under Label Shifts," ICLR 2019．[arXiv 1903.09734](https://arxiv.org/abs/1903.09734)．

- **新しい情報：**BBSE と同じく，ソースの取り置きデータの混同行列とターゲットの予測の頻度．加えて「標本が少ないときは推定した重みを信用しすぎない」という縮小の量 λ．— [Azizzadenesheli 2019](https://arxiv.org/abs/1903.09734)
- **入り方（2.1 節の式 (3) と 2.2 節）：**ずれの量を θ = w − 1 とおき，b = q − C1 = Cθ を正則化つきで解いて，重みを 1 の方へ縮める．Δ_C は ‖Ĉ − C‖ の高確率の上界である．— [Azizzadenesheli 2019](https://arxiv.org/abs/1903.09734)
  ```
  θ̂ = argmin_θ ‖Ĉθ − b̂‖₂ + Δ_C ‖θ‖₂ ,   b̂ = q̂ − Ĉ1
  ŵ = 1 + λθ̂ = (1 − λ)·1 + λ·(1 + θ̂)
  ```
- **動機（2 節）：**"Intuitively, when there are very few samples, the weight estimation will have high variance in which case it might be better to avoid importance weighting altogether." 2.2 節："When a few samples from the target set are available or the label shift is mild, the estimated weights might be too uncertain to be applied." — [Azizzadenesheli 2019](https://arxiv.org/abs/1903.09734)
- **報告された数値（1 節の要約）：**"For large target sample sizes and large shifts, when applying the regularized weights fully, we achieve an order of magnitude smaller weight estimation error than baseline methods and enjoy at most 20% higher accuracy and F-1 score in corresponding predictive tasks. For low target sample sizes, applying regularized weights partially also yields an accuracy improvement of at least 10% over fully weighted and unweighted methods." 数値の本体は図 2〜4（CIFAR10 と MNIST）にある．3.2 節は，大きなずれでは正解率だけでなくクラスごとの F1 の平均を見るべきだと書く（多数派のクラスに寄せると正解率が上がるため）．— [Azizzadenesheli 2019](https://arxiv.org/abs/1903.09734)
- **仮定：**ラベルシフト p(x|y) = q(x|y)（1 節）．λ の選び方は σ_min と想定するずれの上限 θ_max に依存し，著者は "in practice, we do not know σmin in advance" と書く．— [Azizzadenesheli 2019](https://arxiv.org/abs/1903.09734)

#### 1-4 Alexandari, Kundaje, Shrikumar 2020（較正つきの最尤法が強い）◎

書誌：A. Alexandari, A. Kundaje, A. Shrikumar, "Maximum Likelihood with Bias-Corrected Calibration is Hard-To-Beat at Label Shift Adaptation," ICML 2020, PMLR 119．[arXiv 1901.06852](https://arxiv.org/abs/1901.06852)．

- **新しい情報：**ソースの検証データ（取り置き）で合わせた較正（出力の確率の補正）の係数と，検証データでの予測確率の平均で定めたソースの割合．— [Alexandari 2020](https://arxiv.org/abs/1901.06852)
- **入り方（3.1・3.2 節）：**BCTS（Bias-Corrected Temperature Scaling）は温度での割り算にクラスごとの切片を足した較正で，検証データの負の対数尤度を最小にして係数を決める．較正した確率を Saerens の EM に入れる．ソースの割合 p̂(y=i) はラベルの頻度ではなく，検証データでの p̂(y=i|x) の平均にする．— [Alexandari 2020](https://arxiv.org/abs/1901.06852)
  ```
  BCTS：p̂(y=i|x) ∝ exp(zᵢ(x)/T + bᵢ)   （z はロジット，T と bᵢ を検証データで合わせる）
  ```
- **主張（要旨と 1.1 節）：**Saerens の方法の "limiting assumption of this algorithm is that p(y|x) is calibrated, which is not true of modern neural networks." と書き，"Best results are obtained with variants of TS containing class-specific bias parameters that can correct for systematic bias." と報告する．対数尤度が凹で有界なので EM は大域最適に収束することを示す（3.3 節）．— [Alexandari 2020](https://arxiv.org/abs/1901.06852)
- **報告された数値（表 1，CIFAR10，Dirichlet のずれ α = 0.1，n = 8000）：**重みの平均二乗誤差の中央値は，EM＋BCTS 0.00022，BBSL-soft＋BCTS 0.00104，RLLS-soft＋BCTS 0.00093，較正なしの EM 0.00795．較正なしでは EM が BBSL・RLLS より悪い．— [Alexandari 2020](https://arxiv.org/abs/1901.06852)
- **著者が書いた限界（5 節）：**"If the source-domain priors p̂(y = i) are not defined in a way that mirrors the systematic bias in the predicted probabilities p̂(y = i|x), then maximum likelihood will estimate a label shift even if the target domain is identical to the source domain (Lemma A) and can produce highly detrimental results (Tables A.1)." また 4.1 節の脚注で，BBSL・RLLS の割合を E 段に入れて出力を直す方法について "when the predictions are not calibrated, this adaptation can sometimes decrease test-set accuracy." と書く．実験はすべて人工的に作ったラベルシフトで，p(x|y) は変えていない．— [Alexandari 2020](https://arxiv.org/abs/1901.06852)

#### 1-5 Garg, Wu, Balakrishnan, Lipton 2020（BBSE と最尤法を 1 つの見方でまとめる）◎

書誌：S. Garg, Y. Wu, S. Balakrishnan, Z. C. Lipton, "A Unified View of Label Shift Estimation," NeurIPS 2020（PDF の頁に "34th Conference on Neural Information Processing Systems (NeurIPS 2020)" とある）．[arXiv 2003.07554](https://arxiv.org/abs/2003.07554)．

- **新しい情報：**BBSE も最尤法（MLLS）も，識別器の出力で決まる空間 Z の上で「ソースの p(z|y) を重み w で混ぜた分布」をターゲットの p(z) に合わせる手続きである，という見方．— [Garg 2020](https://arxiv.org/abs/2003.07554)
  ```
  p_w(z) = Σ_y p(z|y) p_s(y) w_y = Σ_y p_s(z,y) w_y ,  これを p_t(z) に合わせる（式 (1)(2)）
  ```
- **主張（要旨と 6 節）：**"Our analysis attributes BBSE's statistical inefficiency to a loss of information due to coarse calibration." 実験では "Across all shifts, MLLS (with BCTS-calibrated classifiers) uniformly dominates BBSE, RLLS, and MLLS-CM in terms of MSE (Figure 1)." 混同行列で較正した MLLS（MLLS-CM）は BBSE とほぼ同じで，"MLLS's superior performance is not because of differences in loss function used for distribution matching but due to differences in the granularity of the predictions, caused by crude confusion matrix aggregation." と結論する．— [Garg 2020](https://arxiv.org/abs/2003.07554)
- **仮定：**ラベルシフト p_s(x|y) = p_t(x|y)，識別器の正準較正（Definition 1），{p(z|y)} の線形独立（Lemma 1）．MLLS の誤差を較正の誤差と有限標本の誤差に分ける（定理 3）．— [Garg 2020](https://arxiv.org/abs/2003.07554)
- **報告された数値：**人工データで MLLS-CM のヘッセ行列の最小固有値が 0.195 で，区間に分けて較正した予測（区間 4 個以上）より小さく，誤差が大きいことと一致する（6 節，図 2）．ほかの数値は図だけである．— [Garg 2020](https://arxiv.org/abs/2003.07554)
- **限界（6 節）：**"In practice, with a fixed source dataset size, increasing the number of bins could lead to overfitting, worsening our calibration." 実験はすべて p(x|y) を変えない人工のずれ（ソースは均等，ターゲットは Dirichlet）である．— [Garg 2020](https://arxiv.org/abs/2003.07554)

#### 1-6 Tachet des Combes, Zhao, Wang, Gordon 2020（一般化ラベルシフト GLS とクラスの重みつきの整列）◎

書誌：R. Tachet des Combes, H. Zhao, Y.-X. Wang, G. Gordon, "Domain Adaptation with Conditional Distribution Matching and Generalized Label Shift," NeurIPS 2020（PDF の頁の記載による）．[arXiv 2003.04475](https://arxiv.org/abs/2003.04475)．

- **何を示したか（定理 2.1）：**ソースとターゲットでクラスの割合が違うとき，表現の分布をそろえるほど，ソースとターゲットの誤差の和の下界が大きくなる．Z̃ は表現（DANN）か予測と表現の外積（CDAN），D_JS はジェンセン・シャノン距離である．抜き出した文字から読んだ式は次である．— [Tachet des Combes 2020](https://arxiv.org/abs/2003.04475)
  ```
  ε_S(h∘g) + ε_T(h∘g) ≥ ½ ( √D_JS(D_S^Y ‖ D_T^Y) − √D_JS(D_S^Z̃ ‖ D_T^Z̃) )²
  ```
  著者の解釈："Hence algorithms learning invariant representations and minimizing the source error are fundamentally flawed when label distributions differ between source and target domains."（2 節）．
- **仮定 GLS（定義 3.1）：**表現 Z = g(X) が D_S(Z|Y=y) = D_T(Z|Y=y) をすべての y で満たす．入力の空間ではなく学んだ表現の空間でのラベルシフトである．著者は "Next, GLS is always achievable for any distribution pair (DS, DT): any constant function g ≡ c ∈ R satisfies the above definition." とも書き，ラベルシフトそのものについて "label shift clearly fails in most practical applications, e.g. transferring knowledge from synthetic to real images [55]. In that case, the input distributions are actually disjoint." と書く．— [Tachet des Combes 2020](https://arxiv.org/abs/2003.04475)
- **誤差の分解（定理 3.1）：**BER（balanced error rate．クラスごとの誤り率の平均．UAR の 1 からの差）と割合の差の L1 距離の積，およびクラスの条件つきの誤差の差 Δ_CE で，ソースとターゲットの誤差の差を抑える．— [Tachet des Combes 2020](https://arxiv.org/abs/2003.04475)
  ```
  |ε_S(h∘g) − ε_T(h∘g)| ≤ ‖D_S^Y − D_T^Y‖₁ · BER_{D_S}(Ŷ‖Y) + 2(k−1) Δ_CE(Ŷ)
  ```
- **新しい情報と入り方（3.4 節と算法 1）：**ソースの混同行列 C（表現の上の識別器の予測とソースのラベル）とターゲットの予測の分布 μ から，二次計画で重み w を推定する．w でソースの表現の分布に重みを掛けてから敵対的な整列をする（IWDAN，IWCDAN）．重みは各エポックで w_{t+1} = λ·QP(Ĉ, μ̂) + (1 − λ)w_t と更新する．— [Tachet des Combes 2020](https://arxiv.org/abs/2003.04475)
  ```
  minimize_w ½‖μ̂ − Ĉw‖₂²   subject to  w ≥ 0, wᵀD_S(Y) = 1   （式 (5)）
  ```
- **報告された数値（表 2，5 種の平均）：**ソースを間引いて割合のずれを大きくした Office-Home（sO-H）で DANN 51.83 → IWDAN 57.61（真の重みを使う IWDAN-O は 60.87），元の Office-Home で 59.62 → 62.27，sDigits で 83.24 → 92.54．CDAN 系の得はより小さい（Office-Home 64.59 → 65.66）．— [Tachet des Combes 2020](https://arxiv.org/abs/2003.04475)
- **著者が書いた限界：**"Lemma 3.3 shows that the weight estimation is stable once the DA losses have converged, but it does not imply convergence to the true weights"（3.4 節）．結論では，複数のソースには組ごとに重みを持てばよいと書き，"label shift could explain the observation from Zhao et al. #### 1-10 Menon ほか 2021（クラスごとの誤りの平均を最小にする判定は割合に依存しない）◎（3 節のみ）

書誌：A. K. Menon, S. Jayasumana, A. S. Rawat, H. Jain, A. Veit, S. Kumar, "Long-Tail Learning via Logit Adjustment," [arXiv 2007.07314](https://arxiv.org/abs/2007.07314)（v2，2021-07-09）．掲載先（ICLR 2021 と記憶しているが）は PDF に書かれておらず，確かめていない．

- **式 (2)(7)(8)：**BER（balanced error．クラスごとの誤り率の平均．UAR = 1 − BER）を最小にするベイズ最適な判定は，事後確率を割合で割ったもの（ロジットから log P(y) を引いたもの）の最大である．— [Menon 2021](https://arxiv.org/abs/2007.07314)
  ```
  BER(f) = (1/L) Σ_y P_{x|y}( y ∉ argmax_{y′} f_{y′}(x) )
  argmax_y f*_y(x) = argmax_y P_bal(y|x) = argmax_y P(x|y) = argmax_y s*_y(x) − ln P(y)
  ```
- **著者の言い方（3 節）：**"In words, the Bayes-optimal prediction is the label under which the given instance x ∈ X is most likely. Consequently, for fixed class-conditionals P(x | y), varying the class priors P(y) arbitrarily will not affect the optimal scorers." — [Menon 2021](https://arxiv.org/abs/2007.07314)

- **MER-DA への当てはまり（推測）．UAR では，ターゲットの割合 q(y) は判定には要らない．**UAR は 1 − BER なので，p(x|y) が同じなら UAR を最大にする判定は argmax p(x|y) で，q(y) に依存しない（1-10 の式 (7)）．Saerens・BBSE・RLLS・MLLS の出力の補正は正解率を上げるためのもので，判定を q(y) の方へ寄せると，MELD のように Neutral が多いターゲット（`data/README.md` 2 節の件数で Neutral 56.7%，Happy 20.3%，Sad 8.8%，Angry 14.2%）では，UAR が下がる向きに働くと推測する．UAR に効くのは，識別器が学習で取り込んだ割合を割り引くことである．

## 問い 2：ターゲットのラベルが少ないとき，ソースの識別器ではなくソースの標本から何の情報を使うか

### Takeaway

ソースの標本から使われている情報は，(1) ターゲットの少数のラベルとの合い方で決める標本ごとの重み（TrAdaBoost），(2) ターゲットのラベルつきの参照集合との損失の差で決めるソースごとの重み（Konstantinov & Lampert 2019），(3) ソースとターゲットで共通の重みと別々の重みを同時に学ぶための特徴の複製（Daumé 2007），(4) ターゲットの重心でソースのラベルを書き直すこと（SLA），(5) ソースの標本で学ぶ識別器とターゲットのラベルだけで学ぶ識別器を分けて，誤り方の違う 2 つの識別器を作ること（DECOTA），の 5 種である．MER-DA の今の方法はソースを「識別器の平均を初期値と L2 の引き戻しに使う」形でしか使っておらず，これは Daumé 2007 の PRIOR 型に当たる．

### Cited Findings

#### 2-1 Daumé III 2007（特徴の複製．frustratingly easy domain adaptation）◎

書誌：H. Daumé III, "Frustratingly Easy Domain Adaptation," ACL 2007, pp. 256–263．[PDF](https://aclanthology.org/P07-1033.pdf)．

- **入り方（3 節）：**特徴 x を 3 つに複製し，ソースの標本は「共通・ソース用」，ターゲットの標本は「共通・ターゲット用」に置く．K 個のドメインなら (K+1) 倍にする（3.3 節）．— [Daumé 2007](https://aclanthology.org/P07-1033.pdf)


#### 2-2 Dai, Yang, Xue, Yu 2007（TrAdaBoost：ソースの標本ごとの重み）◎

書誌：W. Dai, Q. Yang, G.-R. Xue, Y. Yu, "Boosting for Transfer Learning," ICML 2007（PDF の頁に "Appearing in Proceedings of the 24th International Conference on Machine Learning, Corvallis, OR, 2007." とある）．[PDF](https://cse.hkust.edu.hk/~qyang/Docs/2007/tradaboost.pdf)．

- **新しい情報：**ソースの各標本が，ターゲットのラベルつきの少数の標本で学んだ境界にどれだけ合うか．3 節："What we can do is to label a small amount of data from the new domain and call it Ts, and then use these data to find out the useful part of Td." — [Dai 2007](https://cse.hkust.edu.hk/~qyang/Docs/2007/tradaboost.pdf)
- **入り方（算法 1）：**各回の弱い識別器 h_t の誤りを，ターゲットのラベルつきの標本だけで測る（ε_t）．ソースの標本（i = 1..n）は間違えるほど重みを下げ，ターゲットの標本（i = n+1..n+m）は AdaBoost と同じく間違えるほど重みを上げる．— [Dai 2007](https://cse.hkust.edu.hk/~qyang/Docs/2007/tradaboost.pdf)
  ```
  w_i^{t+1} = w_i^t · β^{|h_t(x_i) − c(x_i)|}        （ソース，1 ≤ i ≤ n）
  w_i^{t+1} = w_i^t · β_t^{−|h_t(x_i) − c(x_i)|}     （ターゲット，n+1 ≤ i ≤ n+m）
  β_t = ε_t/(1 − ε_t) ,  β = 1/(1 + √(2 ln n / N))
  ```
  β の式は抜き出した文字では "β = 1/(1 + 2 ln n/N)" で根号が落ちている．結論の収束の速さも "O( ln n/N )" と根号が落ちているので，同じ落ち方と判断して √ を補った．元の組版の画像では確かめていない．
- **報告された数値：**表 3（ターゲットとソースのラベル数の比 0.01，誤り率）で，例えば rec vs talk は SVM（ターゲットのみ）0.222，SVMt（両方を混ぜる）0.127，AUX 0.127，TrAdaBoost(SVM) 0.080．表 4 は "very few same-distribution training instances (one positive and one negative)"（クラスあたり 1 本）での半教師あり版で，rec vs talk は TSVM 0.059，TSVMt 0.040，TrAdaBoost(TSVM) 0.021，sci vs talk は 0.173，0.106，0.075，people vs places は 0.307，0.225，0.179．いずれも 2 クラスの文書分類である．— [Dai 2007](https://cse.hkust.edu.hk/~qyang/Docs/2007/tradaboost.pdf)
- **著者が書いた限界（5.3 節と 6 節）：**"TrAdaBoost does not guarantee to improve the basic learner either."，"the improvement that we obtain is sensitive to the quality (or KL-divergence) of diff-distribution examples."，"TrAdaBoost is able to transfer knowledge from only one distribution at one time, and cannot deal with multiple different distributions simultaneously." — [Dai 2007](https://cse.hkust.edu.hk/~qyang/Docs/2007/tradaboost.pdf)

#### 2-3 Konstantinov & Lampert 2019（ターゲットの参照集合でソースごとの重みを決める）◎

書誌：N. Konstantinov, C. H. Lampert, "Robust Learning from Untrusted Sources," ICML 2019（PDF の頁に "Proceedings of the 36th International Conference on Machine Learning" とある）．[arXiv 1901.10310](https://arxiv.org/abs/1901.10310)．

- **新しい情報：**ソースごとの「ターゲットとのずれ」を，仮説の集合 H の中で損失の差が最も大きくなる識別器で測った量（discrepancy）．測るのにターゲットの少数のラベルつきの参照集合 S_T を使う．3.1 節："Intuitively, the discrepancy between the two distributions is large, if there exists a predictor that performs well on one of them and badly on the other." — [Konstantinov 2019](https://arxiv.org/abs/1901.10310)
  ```
  d_H(Sᵢ, S_T) = sup_{h∈H} | (1/mᵢ) Σⱼ L(h(x_{i,j}), y_{i,j}) − (1/m_T) Σⱼ L(h(x_{T,j}), y_{T,j}) |   （式 (5)）
  ```
- **入り方（式 (6) と算法 1）：**ソースの重み α を次の凸の問題で決め，α で重みを付けた経験損失を最小にする．第 1 項はずれの小さいソースに重みを集め，第 2 項は標本数に比例して重みを広げる．— [Konstantinov 2019](https://arxiv.org/abs/1901.10310)
  ```
  min_α Σᵢ αᵢ d_H(Sᵢ, S_T) + λ √( Σᵢ αᵢ² / mᵢ )   subject to Σᵢ αᵢ = 1, αᵢ ≥ 0
  ```
  著者は "As λ → ∞, all tasks are assigned weights proportional to the amount of training samples they provide" と "as λ → 0, ... until all weight is assigned to the source closest to the target domain" と書く．λ は参照集合での交差検証で選ぶ．— [Konstantinov 2019](https://arxiv.org/abs/1901.10310)
- **報告された数値：**Amazon の商品レビュー（2 クラス）で，ターゲットの本の参照集合 100 件，ソースは 10 個（各 100 件）．図 1 で，ターゲットのみと全部を混ぜる方法の両方より誤りが小さい（数値は図だけ）．Animals with Attributes 2（参照集合 500 枚，ソース 59 個）の表 2 は「有意に良い／同じ／有意に悪い」の回数で，例えば壊れたソースが 30 個のとき「全部を混ぜる」に対して 370/140/0 である．— [Konstantinov 2019](https://arxiv.org/abs/1901.10310)
- **著者が書いた限界（5 節）：**"In our experiments we observed that a relatively small clean dataset was enough to protect the learning from the effects of corrupted data. Quantifying the trade-off between the size of the reference dataset and the gains of our algorithm in terms of achieved test-time performance is thus an interesting and promising direction for future work." 対象は壊れた・無関係なソースで，割合のずれは扱っていない．WADN の著者は，割合が違う Amazon のレビューでこの方法（RLUS）が "is unable to select the related source when label distribution varies" と報告している（3-2）．— [Konstantinov 2019](https://arxiv.org/abs/1901.10310)；[Shui 2021](https://arxiv.org/abs/2105.04051)

#### 2-4 Yang ほか 2021（DECOTA：ソースで学ぶ識別器とターゲットで学ぶ識別器を分ける）◎（本文と表 2・5，図 3）

書誌：L. Yang, Y. Wang, M. Gao, A. Shrivastava, K. Q. Weinberger, W.-L. Chao, S.-N. Lim, "Deep Co-Training with Task Decomposition for Semi-Supervised Domain Adaptation," [arXiv 2007.12684](https://arxiv.org/abs/2007.12684)．掲載先は既存ノートの記録で ICCV 2021, pp. 8886–8896（本ノートでは確かめていない）．

- **問題意識（1 節）：**"A single classifier learned together with both sources of supervision is thus easily dominated by the labeled source data and is unable to take advantage of the additional labeled target data." — [Yang 2021](https://arxiv.org/abs/2007.12684)
- **新しい情報と入り方（3.1 節）：**ソースのラベルとターゲットのラベル無しで学ぶ識別器 w_g（UDA の課題）と，ターゲットのラベルとラベル無しで学ぶ識別器 w_f（半教師あり学習の課題）を分け，互いの確信度が閾値 τ を超えた疑似ラベルを相手の学習に渡す（共同学習）．疑似ラベルはラベルつきの標本と MixUp（2 つの標本の線形の混ぜ合わせ）してから使う．著者は "Second, learning with distinct labeled data implies that the two classifiers will converge differently in what types of mistakes they make and on which samples they are confident and correct, meaning that they are complementary to each other." と書く．— [Yang 2021](https://arxiv.org/abs/2007.12684)
- **報告された数値：**DomainNet（ResNet-34，7 組の平均）で，クラスあたり 3 本では S+T 61.2，MME 68.0，APE 71.7，DECOTA 75.6（表 2）．1 本では S+T 58.1，MME 65.3，APE 67.6，DECOTA 73.9（表 5）．— [Yang 2021](https://arxiv.org/abs/2007.12684)
- **誤りの違いの証拠（図 3(a)，DomainNet Real → Clipart，3 本）：**"The two tasks hold unique expertise (i.e., there is a 14% portion of the data that exactly one view is confident on), satisfying the condition of co-training in Eq. - **前提：**深い網の微調整と画像のデータ拡張・MixUp を使う．凍結した特徴の上の線形の識別器での結果は無い．

#### 2-5 Yu & Lin 2023（SLA：ターゲットの重心でソースのラベルを書き直す）◎（3 節，表 2〜5，限界）

書誌：Y.-C. Yu, H.-T. Lin, "Semi-Supervised Domain Adaptation with Source Label Adaptation," [arXiv 2302.02335](https://arxiv.org/abs/2302.02335)（v2，2023-03-24）．PDF の書式は CVPR のものだが，掲載先の記載は確かめていない．

- **新しい情報（要旨）：**"Our key idea is to view the source data as a noisily-labeled version of the ideal target data." ソースの標本の特徴に，ターゲットの重心で作った識別器の出力を当てて，ソースのラベルを書き直す．— [Yu & Lin 2023](https://arxiv.org/abs/2302.02335)
- **入り方（3.1〜3.3 節の式 (6)〜(9)）：**ラベル無しのターゲットに現在のモデル g の argmax で疑似ラベルを付け，その重心（疑似の重心 C̃_f）でプロトタイプの識別器（重心への距離の softmax）を作る．準備の期間 W の後，ソースのラベルを元のラベルとこの識別器の出力の凸結合にする．— [Yu & Lin 2023](https://arxiv.org/abs/2302.02335)
  ```
  P_C(x)_k = exp(−d(f(x), c_k)·T) / Σⱼ exp(−d(f(x), c_j)·T)
  ỹᵢˢ = yᵢˢ                                     （e ≤ W）
  ỹᵢˢ = (1 − α)·yᵢˢ + α·P_{C̃f}(xᵢˢ)            （e > W）
  ```
- **自分の予測で書き直しても効かない理由（3.1 節）：**"However, in DA, such a method might not be helpful since the model usually overfits the source data, which makes g(xsi) ≈ yis." — [Yu & Lin 2023](https://arxiv.org/abs/2302.02335)
- **重心の誤差（3.2 節と表 3，Office-Home A → C，3 本）：**"Since we have only a few target labels per class, the labeled target centers Cℓf are far away from the ideal centers C∗f." 理想の重心までの L2 距離は，ラベルつきのターゲットの重心で 10.02，疑似の重心で 4.06．— [Yu & Lin 2023](https://arxiv.org/abs/2302.02335)
- **報告された数値：**表 2（Office-Home A → C）で，ソースのラベルを理想のターゲットの識別器の予測に置き換えた ideally-adapted S+T は 1 本／3 本で 82.9／87.4，S+T は 52.9／58.1．表 4（DomainNet，平均，1 本／3 本）で MME 66.4／68.9 → MME＋SLA 68.8／70.0，CDAC 73.6／76.0 → CDAC＋SLA 75.0／76.9．表 5（Office-Home）で MME 70.4／73.1 → 72.0／75.6，CDAC 71.0／74.8 → 72.9／76.3．— [Yu & Lin 2023](https://arxiv.org/abs/2302.02335)
- **著者が書いた限界（4.3 節）：**"Our SLA framework might not be helpful if the label adaptation loss approaches 0. Although we have applied the Protonet with Pseudo Centers to avoid the issue, the loss will converge to 0 in MME + SLA." — [Yu & Lin 2023](https://arxiv.org/abs/2302.02335)

### Inferences

- **MER-DA への当てはまり（推測）．今のソースの使い方は Daumé の PRIOR 型である．**MER-DA の識別器はソースの識別器の平均から始め，L2 でその平均に引き戻す（タスクの説明による）．これは Daumé 2007 の PRIOR（λ‖w − w_s‖²）と同じ形で，ソースの標本は平均の識別器を通してしか入らない．Daumé は，AUGMENT（ソースとターゲットの重みを同時に学ぶ）が PRIOR より良い理由を「同時に決めること」に求め，一方で「ソースだけの識別器がターゲットだけの識別器に勝つ課題では AUGMENT が負ける」と書く（2-1）．MER-DA の K = 1〜25 で，ソースの平均とターゲットの K 本だけの識別器のどちらが強いかは，本ノートでは確かめていない．
- **MER-DA への当てはまり（推測）．試した「ソース×モダリティの重みつきの積」と，Konstantinov・WADN・TrAdaBoost の重みは入る場所が違う．**試した方法は予測の段で識別器の出力に重みを掛ける．Konstantinov 2019 と WADN（3-2）はソースの標本の損失に重みを掛けて識別器を学び直し，TrAdaBoost は標本ごとに重みを掛ける．後者では，ソースの標本の中でターゲットに合う部分だけが識別器の向き（重み）を決めるので，予測の段の重みづけとは別の情報（標本の中のどれがターゲットに近いか）を持ち込むと推測する．ただし Konstantinov のずれ d_H はターゲットのラベルつきの参照集合で測るので，K = 1（4 本）では推定のばらつきが大きいと推測する．著者自身も参照集合の大きさと得の関係を今後の課題としている（2-3）．
- **MER-DA への当てはまり（推測）．DECOTA の説明は，MER-DA で単独の識別器どうしが依存し合うことと同じ向きである．**MER-DA の 3 つの単独の識別器と融合のヘッドは，どれもソースの平均から始めて同じ平均に引き戻すので，DECOTA の言う「ソースのラベルに支配された」識別器になっている可能性がある．DECOTA が「誤り方の違う識別器」を作るために使った手段は，ターゲットのラベルとラベル無しだけで学ぶ識別器（ソースの初期値も引き戻しも使わない）を別に持つことである．ただし DECOTA は深い網と MixUp とデータ拡張を使っており，凍結した 2,304 次元の特徴で K = 1 のターゲットだけの線形の識別器がどれだけ弱いかは分からない．
- **MER-DA への当てはまり（推測）．SLA の「ソースのラベルの書き直し」は，凍結した特徴でもそのまま計算できる．**SLA の書き直しは，ソースの標本の特徴とターゲットの疑似の重心だけで計算できるので，特徴抽出器を学ばない MER-DA でも形の上では使える．ただし SLA 自身が「自分の予測で書き直すと g(xˢ) ≈ yˢ になって効かない」と書く（2-5）ように，書き直しに使う識別器が今の識別器と同じ誤り方をすれば得は無い．重心の識別器は線形の softmax と決め方が違う（ユークリッド距離の最小）ので，誤り方が違う可能性はあるが，確かめた結果は無い．

## 問い 3：ターゲットのラベルがクラスあたり 1〜数十本の結果と，複数ソースの結果はあるか

### Takeaway

複数ソースで割合のずれを明示的に扱う研究として，JCPOT（ターゲットのラベル無し．最適輸送でターゲットの割合とソースの標本からのラベル伝播を同時に求める）と WADN（ターゲットのラベル 1〜10%．ソースごとの重みをクラスの条件つきの距離で決める）がある．ターゲットのラベルがクラスあたり 1 本の結果は TrAdaBoost（2 クラス）と SSDA の 1 本・3 本の設定（DECOTA，SLA）にあるが，これらは単一ソースで，割合のずれを扱っていない．「複数ソース・割合のずれ・クラスあたり 1〜25 本」を同時に満たす結果は見つからなかった．

### Cited Findings

#### 3-1 Redko, Courty, Flamary, Tuia 2019（JCPOT：複数ソースでの割合の推定と最適輸送）◎

書誌：I. Redko, N. Courty, R. Flamary, D. Tuia, "Optimal Transport for Multi-source Domain Adaptation under Target Shift," AISTATS 2019, PMLR 89:849–858．[PMLR](https://proceedings.mlr.press/v89/redko19a.html)；[arXiv 1803.04899](https://arxiv.org/abs/1803.04899)．

- **仮定（4.1 節）：**"JCPOT works under the target shift assumption presented in Section 3." すなわち各ソースとターゲットで p(x|y) が同じで，割合だけが違う．— [Redko 2019](https://arxiv.org/abs/1803.04899)
- **新しい情報と入り方（4.2 節の式 (6)）：**ソースごとの標本の質量をクラスの割合 h で配り直し（演算子 D₂^{(k)}），ターゲットの経験分布への正則化つきのワッサースタイン距離の重みつきの和を最小にする h をターゲットの割合とする（制約つきのワッサースタインの重心）．— [Redko 2019](https://arxiv.org/abs/1803.04899)
  ```
  ĥ = argmin_{h ∈ Δ_C} Σ_k λ_k W_{ε,C^{(k)}}( (D₂^{(k)} h)ᵀ δ_{X^{(k)}} , μ )
  ```
- **ソースの標本からの疑似ラベル（4.3 節）：**輸送の計画 γ^{(k)} で，各ターゲットの標本に届く質量がどのクラスのソースの標本から来たかを数え，L = Σ_k λ_k D₁^{(k)} γ^{(k)} をターゲットのクラスの確率の推定にする（JCPOT-LP）．著者は "Note that this label propagation technique can be seen as boosting, since the expression of L corresponds to a linear combination of weak classifiers from each source domain." と書く．— [Redko 2019](https://arxiv.org/abs/1803.04899)
- **報告された数値（表 2，Zurich Summer の衛星画像，4 クラス，ソース 2〜17 枚）：**正解率は，補正なし 0.61〜0.63，ラベルシフトの EM（beta EM）0.58〜0.59，JCPOT-LP 0.66〜0.73，Target only 0.61〜0.673．ソースが 17 枚のとき補正なし 0.63，JCPOT-LP 0.73．著者は "the results obtained by JCPOT-LP outperform the “Target only" baseline. This shows the benefit brought by multiple source domains as once properly adapted, they represent a much larger annotated sample that the target domain sample alone." と書く．Target only の作り方は本文から読み取れなかった．— [Redko 2019](https://arxiv.org/abs/1803.04899)
- **限界（結論）：**"In the future, we plan to extend JCPOT to estimate proportions in deep learning-based DA methods suited to for larger datasets." WADN の著者は，p(x|y) が全ドメインで同じという JCPOT の仮定を "this assumption is restrictive for many real-world cases" と書く（3-2）．— [Redko 2019](https://arxiv.org/abs/1803.04899)；[Shui 2021](https://arxiv.org/abs/2105.04051)

#### 3-2 Shui, Li, Li, Gagné, Ling, Wang 2021（WADN：割合の違う複数ソースをクラスの条件つきの距離で選ぶ）◎（本文，表 3，付録 L の一部）

書誌：C. Shui, Z. Li, J. Li, C. Gagné, C. X. Ling, B. Wang, "Aggregating From Multiple Target-Shifted Sources," ICML 2021（PDF の頁に "Proceedings of the 38th International Conference on Machine Learning" とある）．[arXiv 2105.04051](https://arxiv.org/abs/2105.04051)．

- **主張（要旨）：**"the model aggregates multiple sources mainly through the similarity of semantic conditional distribution rather than marginal distribution" — [Shui 2021](https://arxiv.org/abs/2105.04051)
- **新しい情報と入り方（3・4 節）：**ソース t ごとに (i) 割合の比 α_t(y) = T(y)/S_t(y) で重みを付けたソースの予測損失と，(ii) クラスごとの表現の分布のワッサースタイン距離 E_{y∼T̂(y)} W₁(T̂(z|Y=y) ‖ Ŝ_t(z|Y=y)) を測り，ソースの重み λ を凸の問題で決める．ターゲットのラベルがある場合は "When the target labels are available, α̂t can be directly estimated from the data with α̂t(y) = T̂(y)/Ŝ(y)"（4.1 節）．λ を決める問題は，抜き出した文字の並びから次の形と読んだ（β_t の定義は確かめていない）．— [Shui 2021](https://arxiv.org/abs/2105.04051)
  ```
  min_λ Σ_t λ[t] R̂_{S_t}^{α̂_t}(h, g) + C₁ √( Σ_t λ[t]² / β_t ) + C₀ Σ_t λ[t] E_{y∼T̂(y)} W₁( T̂(z|Y=y) ‖ Ŝ_t(z|Y=y) )
  subject to λ[t] ≥ 0, Σ_t λ[t] = 1
  ```
  選び方の規則："Balance the trade-off between assigning a higher λ[t] to the source t that has a smaller weighted prediction loss and semantic conditional Wasserstein distance, and assigning balanced λ[t]."
- **ラベル無しの場合の仮定（5 節）：**GLS（1-6）を仮定し，"(Combes et al., 2020) further pointed out that the clustering assumption (Chapelle & Zien, 2005) on Z is one sufficient condition to reach GLS" と書く．— [Shui 2021](https://arxiv.org/abs/2105.04051)

## 問い 4：今の識別器と誤り方の違う疑似ラベル（新しい情報）を作れるか

### Takeaway

割合の補正（問い 1）で作る疑似ラベルは，今の識別器の出力に各クラスの定数を掛けただけで，誤り方はほぼ同じである（変わるのは境界の近くの標本だけ）．誤り方の違う疑似ラベルの根拠を示した研究は，ソースの標本で学ぶ識別器とターゲットのラベルだけで学ぶ識別器を分けた DECOTA（片方だけが確信をもつ標本が 14%）だけで，SLA の重心の識別器と JCPOT のソースの標本からの伝播は，誤り方の違いを測っていない．MER-DA の積の疑似ラベルについては，3 つの事後確率の積がクラスの割合を 3 回数える形になっているが，MER-DA の識別器は均等の割合で学んでいるので，その影響は小さいと推測する．

### Cited Findings

- **割合の補正は各クラスに定数を掛けるだけである．**Saerens の式 (4) と EM の E 段（式 (9)）は p_t(ωᵢ|x) に p̂(ωᵢ)/p_t(ωᵢ) を掛けて正規化する（1-1）．RLSbench の再重みづけも f′_j = p̂_t(j)·f_j / Σ_k p̂_t(k)·f_k である（1-9）．— [Saerens 2002](https://dipot.ulb.ac.be/dspace/bitstream/2013/68391/1/Decaestecker_NeuralComp02.pdf)；[Garg 2023](https://arxiv.org/abs/2302.03020)
- **較正の偏りは割合の推定を誤らせる．**Alexandari は，ソースの割合を予測の偏りに合わせて定めないと，ずれの無いターゲットでも最尤法が割合のずれを推定してしまうと書く（1-4 の 5 節の引用）．— [Alexandari 2020](https://arxiv.org/abs/1901.06852)
- **誤り方の違う 2 つの識別器の証拠．**DECOTA の図 3(a) で，ソースとラベル無しで学ぶ識別器と，ターゲットのラベルとラベル無しで学ぶ識別器を別々に学ぶと，"there is a 14% portion of the data that exactly one view is confident on"（DomainNet Real → Clipart，3 本，ラベル無しの 18,325 本）．測ったのは確信度の重なりで，誤りの相関そのものではない．— [Yang 2021](https://arxiv.org/abs/2007.12684)
- **重心の識別器はラベルつきの重心より理想に近い．**SLA の表 3 で，疑似の重心は理想の重心から 4.06，ラベルつきのターゲットの重心は 10.02 離れている（Office-Home A → C，3 本）．— [Yu & Lin 2023](https://arxiv.org/abs/2302.02335)
- **ソースの標本からのラベル伝播はソースごとの弱い識別器の線形結合である．**JCPOT-LP の L = Σ_k λ_k D₁^{(k)} γ^{(k)}（3-1）．— [Redko 2019](https://arxiv.org/abs/1803.04899)
- **積で確率を組み合わせる規則は，条件つきの独立から導かれる．**検索結果に示された Kittler ほかの要旨の文は "Under the assumption of conditional statistical independence of representations, the product rule for combining a posteriori probabilities is derived." である（原文の頁では確かめていない．○）．同じ検索結果の要約によれば，等しい割合を仮定した実験で積の規則の成績が最も悪く，和の規則は推定の誤差を増幅しにくいと要旨に書かれている．書誌：J. Kittler, M. Hatef, R. P. W. Duin, J. Matas, "On Combining Classifiers," IEEE TPAMI 20(3):226–239, 1998, DOI 10.1109/34.667881．— [CTU DSpace の書誌](https://dspace.cvut.cz/handle/10467/9443)（○．本文は読んでいない）

### Inferences

- **MER-DA への当てはまり（推測）．積の疑似ラベルは割合を 3 回数える．**音声 a・顔 v・言葉 t が感情 y のもとで独立なら，ベイズの式から次になる（本ノートの導出）．
  ```
  p(y|a,v,t) ∝ p(y)·p(a|y)p(v|y)p(t|y) ∝ p(y|a)·p(y|v)·p(y|t) / p(y)²
  ```
  今の疑似ラベル「3 つの事後確率の積を正規化したもの」は，識別器が学習で取り込んだ割合 π(y) を π(y)³ として含み，独立のもとでの事後確率より π(y)² だけ多い．UAR に合う「割合を除いた」形は Π_m p(y|x_m) / π(y)³ である．MER-DA の識別器は感情の件数の逆数で重みを付けて学んでいる（`DAI/exp/dai_solver.py` の `balanced_onehot`）ので，π(y) はソースの上ではほぼ均等で，この補正の影響は小さいと推測する．ターゲットの上での実効の割合（ラベル無しの発話での予測の平均）が均等から離れているかは確かめていない．
- **MER-DA への当てはまり（推測）．割合の情報で疑似ラベルを直しても，融合のヘッドが学ぶものは増えない．**割合の補正はロジットへのクラスごとの定数の足し算なので，融合のヘッドの切片で表せる．タスクの説明にある「融合のヘッドは積を正確に表せるので新しいことを学ばない」という状況は，割合を補正した積でも変わらないと推測する．変わるのは，均等にそろえた疑似ラベルの量の重みが学び直しの向きに与える影響だけである（問い 1 の推測）．
- **MER-DA への当てはまり（推測）．今の予測に含まれない情報の出どころ．**本ノートで読んだ研究から，今の疑似ラベル（ソースの平均から始めて K 本で直した 3 つの識別器の出力の積）に含まれない情報として次が挙がる．(1) ソースの取り置きデータ，またはターゲットの K 本で測る混同行列（1-2，問い 1 の推測）．(2) ラベル無しのターゲット全体での割合の集計（1-1，1-4）．(3) ソースの標本ごと・ソースごとの，ターゲットとの近さ（2-2，2-3，3-2）．(4) ソースの標本の配置そのもの（輸送の計画．3-1）．(5) ソースの初期値も引き戻しも使わない，ターゲットのデータだけで学ぶ識別器（2-4）．(6) 特徴の空間の重心までの距離という，線形の softmax と違う決め方（2-5）．このうち DECOTA の (5) だけが，誤り方の違いの測定（確信度の重なり）を伴っている．
- **MER-DA への当てはまり（推測）．試した手法の失敗の説明として使える記述．**DECOTA の「両方のラベルで学ぶ 1 つの識別器はソースに支配される」（2-4）は，試した S+T が K 本だけの基準を上回らなかったことの説明として使える．SLA の「自分の予測でラベルを書き直すと g(xˢ) ≈ yˢ になって効かない」（2-5）は，試した自己学習・温度つき蒸留で融合の識別器が伸びなかったこと（教師の判定が生徒と 80〜92% 一致．`DAI/docs/難しさの記録_2026-11-05.md` 3 節）と同じ構造の説明である．どちらも MER-DA の上で確かめた因果ではない．

### Gaps

- 疑似ラベルの誤りと今の識別器の誤りの相関（同じ標本で間違えるか）を測った研究は，DECOTA の確信度の重なり以外に見つけていない．JCPOT・SLA・WADN は正解率だけを報告している．
- Kittler 1998 の本文（積の規則に割合の何乗が入るかの式）は読んでいない．上の式は本ノートの導出である．
- 凍結した特徴の上の線形の識別器で，DECOTA のような「ターゲットだけで学ぶ識別器」を K = 1〜25 で作った結果は見つけていない．
