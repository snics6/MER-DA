# 自由度を上げた研究提案と仮想査読の記録（流れ B．2026-10-29 夜〜10-30 朝）

研究者の指示（2026-10-29）：「私の MER-DA における実験を生かしつつも，もっとあなたに高い自由度を委ねるから，研究提案 → 仮想査読を回して，新規性がある良い研究を提案してくれない？3 個ほど．何回も回して OK．明日の朝まで回し続けていい」．新しい 3・4 の検査（流れ A．`research_notes/新規性と研究価値_2026-10-29/`）と並べて回す．

## 回し方

1. 案出し：見方の違う担当 3 体が，それぞれ研究提案を 3 個書く（`案_<見方>.md`）
2. ふるい：1 体が全部の案を短い検索でふるい，深く査読する上位を選ぶ（`ふるい_<回>.md`）
3. 仮想査読：上位の案 1 つに 1 体をあて，新しさを原文で確かめ，査読者の立場で価値を判定する（`査読_<案の番号>.md`）
4. 判定：本体のセッションが下の基準で判定する．不合格の案は，査読の指摘で直して査読し直すか，新しい案と入れ替える
5. 合格した案が互いに違う 3 個になるか，朝になるまで続ける．同時に動かす担当は流れ A と合わせて 4 体まで．長い計算や GPU は使わない（実験の起動は研究者の承認が要る）

## 合格の基準

| 番号 | 基準 |
|---|---|
| N1 | 中心の主張のうち少なくとも 1 つについて，同じ設定で同じ主張をした先行研究が見つからない |
| N2 | 最も近い先行研究 2〜3 本を原文（◎）で確かめてあり，違いが「感情認識に当てた」以外の，確かめられる性質で書ける |
| V1 | 結果によって，誰か（研究者，実務者）の具体的な判断が変わる |
| V2 | 査読者の最も強い反論に，今ある記録か，計画した実験の結果で答えられる |
| V4 | 案の前提に直接反する MER-DA の記録が無いか，あればその点を設計で扱っている |
| F1 | MER-DA にある 7 群の特徴・発話一覧・結果・コードで実行でき，新しい計算の規模を書ける（`~/MER` は使わない．新しいコーパスが要る案は，要る理由と代わりを書く） |
| S1 | MER-DA の実験の結果を活かしている（土台か，説明の対象か，比べる相手として） |
| D1 | 合格した他の案と，問いが違う |
