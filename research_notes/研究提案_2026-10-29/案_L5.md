### 1.3 定理の主張（証明は 4 段で行う）

**記号**：θ = (W, b) は感情の平均を除いた頭（E74 の `theta` と同じ）．R(θ) は仮のターゲットの候補の上の，感情の釣り合いの重みをつけた交差エントロピーの平均．θ\* = argmin R(θ) + ½ θᵀPθ で，P は W に 1/C′，切片に 1/C_b の罰則をかける正定値の対角の行列（R の正規化に合わせて定数倍する）．候補 θ について，P の内積で θ\* に射影した係数を α = ⟨θ, θ\*⟩_P ／ ⟨θ\*, θ\*⟩_P とし，e⊥ = θ − α θ\*，u = e⊥/α とする．したがって θ − θ\* = (α − 1) θ\* + e⊥，⟨e⊥, θ\*⟩_P = 0 である．

**定理 1**
- (a)（恒等式．θ\* が停留点であることだけを使う）g = ∇R(θ\*) = −Pθ\* である．したがって gᵀ(θ − θ\*) = (1 − α) ‖θ\*‖²_P が成り立つ．特に，1 次の項が正であることと α < 1 は同値である
- (b)（UAR の射線の不変性．仮定なし）α > 0 なら，θ と θ/α = θ\* + u は同じ発話に同じ感情を答える．したがって UAR(θ) = UAR(θ\* + u) である
- (c)（分解．A1 を使う）R(θ) − R(θ\*) = S(θ) + D(θ) と分ける．S(θ) = R(θ) − R(θ/α) は候補を α 倍に戻す操作だけで変わる損失（尺度の部分），D(θ) = R(θ/α) − R(θ\*) は向きの部分である．gᵀu = 0 なので，D(θ) = ½ uᵀFu + O(‖u‖³) で 1 次の項を持たない．1 次の項 (1 − α)‖θ\*‖²_P はすべて S(θ) に入る．UAR は D の側の u だけで決まり，S の大きさには依らない
- (d)（順位の条件．命題）候補の集まり {θ_i} について，損失の得 R(θ_i) − R(θ_j) で UAR の得を順位づけられるのは，(i) 尺度の部分の候補の間の分散 Var_i(S_i) が向きの部分の分散 Var_i(D_i) より十分小さく，(ii) UAR の θ\* での勾配の u_i 方向の成分が小さく，(iii) UAR の 2 階の行列 G が u_i の張る空間で F に比例するとき，に限られる．G は境目の近くの発話だけで決まる行列（Efron 1975 の型の展開）であり，一般には F と一致しない
- (e)（見方の誤差の相関．系）任意の内積 M（E71 の出力の差の 2 乗の平均など）で α を M の射影で定めると，2 つの見方 τ, τ′ の誤差の相関は corr_M = [(1 − α_τ)(1 − α_τ′)‖θ\*‖²_M + ⟨e⊥τ, e⊥τ′⟩_M] ／ (‖e_τ‖_M ‖e_τ′‖_M) である．残りの成分が負に相関しなければ corr_M ≥ √(ψ_τ ψ_τ′) で，ψ_τ = (1 − α_τ)²‖θ\*‖²_M ／ ‖e_τ‖²_M は誤差に占める尺度の成分の割合である．α がそろった見方の組では，対ごとの差 θ_τ − θ_τ′ から尺度の成分が消えるので，食い違いの最小 2 乗（three-cornered hat）はこの共通の成分を誤差として数えない

**定理の範囲**：(a)(b) は停留の条件と argmax の性質だけから出る 2 行の事実である．(c) は A1 のもとでの書き換えである．新しさは，この分解で E74 の A0 と A2，U7，U8 を同時に説明できるかを数で確かめる点と，(e) で相関の出どころを 1 つの方向（θ\*）に特定する点にある．

### 2.3 定理の主張（証明は 4 段で行う）

**記号**：ソースのみの頭 (W, b)（ソースの統計で標準化した特徴の上）．4 つのロジットから平均を除いた 3 次元の差 ζ = Q(Wx + b) を使う（Q は 3 × 4 の正規直交の対比の基底）．ターゲットのコーパスで，感情 c の発話の ζ の分布を平均 m_c，共分散 V_c の正規分布で近似する（仮定 G1）．感情 c の再現率を R_c(m, V) = P(argmax(m + η) = c)，η ∼ N(0, V)，UAR = ¼ Σ_c R_c(m_c, V_c) と書く．中心化は，すべての感情の m_c から同じベクトル QWδ を引く操作である（δ はターゲットの平均 − ソースの平均．ソースの統計の座標）．

**定理 2**
- (a)（Price の恒等式の形）任意の対称行列 Δ について，d/dt R_c(m, V + tΔ) = ½ tr(Δ ∇²_m R_c(m, V + tΔ)) が成り立つ．特に Δ が半正定値なら R_c(m, V + Δ) = E_{ξ∼N(0,Δ)} R_c(m + ξ, V)（ロジットの散らばりが増えることは，平均をでたらめにずらして平均した再現率に等しい）
- (b)（分解）ターゲットの値をソースの値からのずれ（m_c^S + Δm_c，V_c^S + ΔV_c）で書くと，UAR_T − UAR_S は，共通の平均のずれ QWδ の項 L_com，感情ごとの平均のずれ Δm_c − QWδ の項 L_spec，散らばりの項 D = ⅛ Σ_c tr(∇²R_c ΔV_c)，と高次の項に分かれる．中心化は L_com だけを（すべての次数で）消し，L_spec と D を残す．ソースとターゲットの感情の比率が違えば，δ には比率の違いから来る分 Σ_c (π_c^T − π_c^S) μ_c も入り，中心化はそれも引く
- (c)（TV が 2 つの和であること）予測した感情の割合 f_c = Σ_y π_y^T P(答え = c | y) の変化も同じ形に分かれる．平均の項 Δf_loc = f（中心化なし）− f（中心化あり）はラベル無しで厳密に計算できる．散らばりの項 Δf_disp は，ΔV の 3 × 3 の対比の空間での向きがそろっていない（感情の差ごとに散らばりの増え方が違う）ときに 0 でなく，平均のずれが 0 でも答えの偏りを作る．中心化の上がり幅は L_com で決まり，L_com の大きさはロジットの散らばりを単位にした平均のずれ ‖QWδ‖_{V⁻¹} で決まる（傾き ∇R_c は境目の密度で，散らばりに反比例する）．TV は平均の項と散らばりの項の両方で決まるので，散らばりの項が組の間で大きく変わる符号化器では，TV は中心化の上がり幅を表さない
- (d)（損をする条件．命題）中心化が UAR を下げるのは，L_spec と D の作った状態での UAR の勾配が QWδ と同じ向きを持つとき，つまり中心化の前の平均のずれが散らばりの項や感情ごとのずれを打ち消していたときである．ラベル無しの指標として κ = −⟨Δf_loc, Δf_disp⟩ ／ ‖Δf_loc‖² を置く（Δf_disp は全体のロジットの共分散の差から計算する近似）

**測る仮定**：G1（感情ごとの ζ がほぼ正規分布．仮のターゲットで正規分布の式の再現率と実際の再現率の差の中央値が 2 ポイント以内），G2（感情の間で V_c がほぼ等しい），G3（ラベル無しで測れる全体の共分散の差が，感情の中の共分散の差をおおむね表す．仮のターゲットで割合を測る）．G3 が崩れれば (c)(d) のラベル無しの指標は使えず，仮のターゲットでの分析にとどまる．

### 3.3 定理の主張（証明は 4 段で行う）

**記号**：ターゲットの特徴を x = μ_y + ν_s + ε と書く（μ_y は感情の平均，ν_s は話者 s のずれ，ε は残り．特徴はソースの統計で標準化し，ターゲットの平均を 0 にとる）．仮定 N1：ε は感情と話者の組 (y, s) と独立で，組の中でほぼ正規分布 N(0, Σ_ε)（仮のターゲットで，アンカーのロジットの方向への射影の歪度と尖度を測る）．頭 θ = (W, b) をアンカー θ_a から，ラベル無しの目的関数 L(θ) = E_x H(p_θ(x)) − β H(E_x p_θ(x))（エントロピーと釣り合いの項．β = 0 が単純なエントロピー最小化）で動かす．発話ごとの目的のロジットについての勾配の符号を変えたものを ψ(z) と書く．

**定理 3**
- (a)（動く向きの分解．Stein の補題）−∇_W L(θ_a) = A_emo + A_spk + A_res と分かれる．A_emo = Σ_c π_c E[ψ(z) | y = c] μ_cᵀ，A_spk = Σ_s π_s E[ψ(z) | s] ν_sᵀ（感情の割合が話者で違えば交わりの項が足される），A_res = E[J_ψ(z)] W_a Σ_ε である．A_res の各行は W_a Σ_ε の行の 1 次結合なので，A_res は Σ_ε W_aᵀ の張る空間の外に新しい特徴の向きを足さない．したがって，1 歩で新しく入る向きは感情の平均の差と話者のずれだけである
- (b)（話者の項が 0 になる条件）A_spk = 0 であるのは，各感情 c で E[ψ(z) | c, s] が s に依らないとき，つまりアンカーのロジットの分布が感情を固定すると話者に依らないときに限る．N1 のもとで感情の割合が話者で同じとき，その大きさは，ψ のリプシッツ定数，アンカーのロジットの対比 ζ の話者の間の分散，話者のずれ ν_s の大きさ，の積で上から抑えられる．ζ の話者の間の分散を全体の分散で割った割合を Γ_spk = Σ_s π_s ‖E[ζ | s] − E[ζ]‖² ／ E‖ζ − E[ζ]‖² と置く（話者の ID があればラベル無しで測れる）
- (c)（尺度を固定したときの行き先．Chen ほかの仮定の外）頭の尺度を固定する（重みのノルムを固定するか，アンカーへの罰則で縛る）と，L を小さくする頭は，ζ の上で塊の間の分散と塊の中の分散の比（フィッシャーの比）が大きい分け方に向く．ずれの特徴が正規分布のとき（Chen ほかの場合）は話者の分け方の比が 0 で，アンカーは話者の向きに安定である．話者のずれが塊を作り，境目の近くでの話者の比 F_spk が感情の比 F_emo を上回るとき，L の値の低い頭は話者の向きにあり，アンカーがすでに話者に反応していれば（Γ_spk > 0），勾配の流れはそちらへ進む．EM（共通の共分散）でも，Σ̂⁻¹ の計量での話者の塊の離れ方が感情の塊の離れ方を上回るとき，同じことが起きる．比の閾値の形は 4 段で導く
- (d)（話者の平均を引く操作）話者ごとの平均を引くと ν_s が消え，A_spk と (c) の話者の向きの解が消える．ただし話者ごとの感情の割合 π(y | s) の違いも引くので，その割合が話者で大きく違うコーパスでは感情の信号を失う．その大きさは第 7 回の案出しで測った η²（MOSEI 0.29，AFEW 0.22，IEMOCAP 即興 0.03，台本 0.04，MELD 0.02，CREMA-D と RAVDESS 0）で見積もれる

### 3.6 定理から出る手法と判断

- **MER-DA の結論の見直し**：E28 の 10 節は「向きを直す情報源はラベルであり，ラベル無しのターゲットは位置（中心合わせ）にだけ使える」と結論し，論文 2 の手法から半教師つきの部品を外した．P3-4 で話者の平均を引いた EM が d を上げれば，この結論は「話者の塊を除かない限り」という条件つきに書き直す必要がある．上げなければ，結論は話者の塊を除いても成り立つと強められる．どちらでも論文の文が変わる
- **論文の比べる相手の節**：E61・E62 でエントロピー最小化が世界によって大きく動く理由を，「塊の仮定に依る」という定性の文から，Γ_spk の数に置き換えて書ける
- **実務者**：凍結した特徴の感情認識でテスト時の適応（TENT，SHOT，情報最大化）を使う前に，話者の ID でラベル無しの Γ_spk を測り，大きければ使わないか，話者の平均を引いてから使う（η² が小さいとき）．この規則は，モダリティを足すとき（顔を足すと Γ_spk が上がる）の判断にも使える

### 3.7 MER-DA の何を使うか，新しく要る計算

- 使うもの：発話一覧の話者の列（7 群すべて．`measure/split.py` が話者を分けるのに使っている列），E28 の 10 節の台本 `exp/explore_unlabeled_direction.py`，E61・E62 の台本と記録された値（世界 × ターゲットのエントロピー最小化の得），E39 のアンカー，第 7 回の η²
- 新しい計算：(1) 話者ごとの平均，Γ_spk，F_spk を種類 × ターゲットごとに出す（CPU で数分．ラベルを使わない）．(2) E28 の 10 節の EM を，W の経路を保存し，話者の平均を引いた版を足して流し直す（元の所要は CPU で約 3 時間なので，3〜6 時間）．(3) 釣り合いの項つきのエントロピー最小化を，話者の平均を引いた版とともに仮のターゲットで流す（E61 と同じ台本で GPU 1〜2 時間）．(2)(3) の仮のターゲットの分は `gate-probe` の 1 体，評価のターゲットに当てる分は関門 1 の 4 体を通す
- P3-3 は E61・E62 の文書に書かれた値と，新しく測る Γ_spk（ラベル無し）だけで調べられる

### 3.8 弱点と，査読者の最も強い反論

- **最も強い反論**：「話者の正規化は SER で標準の前処理で，エントロピー最小化が目立つ塊に引かれることも知られている．定理は Stein の補題と塊の隙間の議論の組み合わせで新しくない」．答え：主張の中心は Chen ほかの仮定が崩れる範囲の測定と，世界の違いのラベル無しの予言（P3-3）である．また P3-4 の結果は MER-DA の E28 の 10 節の結論を書き直すかどうかを決める
- U21 の値は比べる相手の固定版の結果で，確かさは低い．IEMOCAP 即興の反復 0〜9 のテストの話者の集合は 5 通りしかない．P3-3 は世界 × ターゲットの組の数（十数組）で判定するので，順位相関の区間は広い
- U2 の EM は 1,024 次元で共通の共分散を Ledoit–Wolf で推しているので，悪くなる原因が次元の高さによる推定の不安定さである可能性がある．P3-1（動きが話者のずれの空間に入るか，でたらめな方向と比べる）と，話者の平均を引いた対照（P3-4）でこの可能性と区別する
- AFEW と MOSEI では話者の ID の意味（映画の人物，動画の投稿者）がほかのコーパスと違う．(d) の η² が大きいコーパスでは話者の平均を引くと感情の信号を失うので，P3-4 はそこで逆の予言を置いた

- **ラベル換算の価値の K 依存のスペクトルの定理（U9・U26，外の 9・30 番）**：中心の誤差のスペクトルと F の固有値の減り方で価値の増減を決める形は，Lin & Reimherr（ICML 2024．相手との差の滑らかさで速さが決まる仮説転移．△）と Reimherr ほか（2021）への代入で済む見込みで，新しさの検査の第 2・3 回で既知と判定された型と同じなので外した
