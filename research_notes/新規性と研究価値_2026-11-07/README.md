# 新しい手法の案の検査の記録（2026-11-07〜）

研究者の指示（2026-11-07）：「ここまでDAI,DAI_paperや，MERーDA全体でいろんな実験をしてきましたね．それで，なぜ色々な提案手法が良い結果を出せないか，なぜ蒸留は有効的か，根本的なところから数学的に調べた上で，新たな提案手法，あるいは，新たな提案手法が効きそうな新たな実験設定を考えて提案して」．

手順は 2026-10-29 の記録（`research_notes/新規性と研究価値_2026-10-29/README.md`）と同じ：本体が案を作り，検査のサブエージェント 1 体（新規性の検索と査読者の立場での価値の判定）に回し，下の基準で本体が判定する．全部を満たした案だけを研究者に出す．満たさないまま上限の回数に達したら，その事実と最も近かった案を報告する．計算（実験）の起動は研究者の承認が要る．この取り決めは案の検査の段に限る．

## 合格の基準

| 番号 | 基準 |
|---|---|
| N1 | 中心の主張のうち少なくとも 1 つについて，同じ設定で同じ主張をした先行研究が見つからない |
| N2 | 最も近い先行研究 2〜3 本は原文（◎）で確かめてあり，違いが「感情認識に当てた」以外の，確かめられる性質で書ける |
| V1 | 結果によって，誰かの具体的な判断が変わる |
| V2 | 査読者の最も強い反論に，今ある記録か，計画した実験の結果で答えられる |
| V3 | 手法が成績で負けても，結果として出せるもの（仮定の測定と説明）が残る |
| V4 | 案の前提に直接反する MER-DA の記録が無いか，あればその点を設計で扱っている |
| R1 | DAI の実験 1〜5 の結果と，いまの提案（実験 1 の `joint`）を土台にしている |

上限は 3 回とする．
