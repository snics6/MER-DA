## 7.1 動機：強さはコーパスで入れ替わり，感情ごとの形は似ていた

6.2 節と 6.3 節では，K 本のラベルが直したのは主に切片のずれで，重みの向きのずれは K 本では直りが遅かった．このため提案は，切片に依らない信頼度を使い，K 本からは分類器ごとに 1 つの数（水準）だけを測る．

分類器ごとの水準はコーパスによって入れ替わり，水準を除いた感情ごとの形はコーパスをまたいで似ていた（図 7）．感情ごとにモダリティの強さが違うことは，Busso ほか [@busso2004] が報告している．Albanie ほか [@albanie2018] も，顔と声に共通する感情の手がかりの量は感情ごとに違いうると述べたが，その量は測っていない．本研究では，この形がコーパスをまたいで同じかを，4 コーパスを 1 つずつ仮のターゲットにした仮のターゲットの回（4.3 節．K = 5．ソースは残るうちの 2 つ）で測った．分類器 × 感情の信頼度の表（7.2 節）を，ソースで測った表と，仮のターゲットの候補の全ラベルで測った表の 2 つ作り，反復ごとに比べた．以下の値は，仮のターゲットのコーパスごとに反復で平均した値の，4 コーパスの最小と最大である．3 つの分類器の水準を 2 つの表で並べた相関は −0.954〜+0.365 で，水準の最も高いモダリティが 2 つの表で一致した反復の割合は 0〜0.367 だった（K 本で測った水準では 0.433〜0.967）．一方，表から水準，どの分類器にも共通の感情ごとの当てやすさ，その掛け算の項を除いた残り（分類器 × 感情の成分．Tukey の非加法性の 1 自由度 [@tukey1949] の当てはめの残り）は，2 つの表の相関が 0.493〜0.770 で，感情の並びを入れ替えて元の相関以上になる割合が 0.096〜0.192 だった．ソースで測った表は計算の前に決めた基準（相関の平均 0.3 以上，入れ替えの割合の平均 0.2 以下）を 4 コーパスとも満たし，K 本で測った表はどのコーパスでも満たさなかった．ただし，感情ごとに信頼度の最も高い分類器が 2 つの表で一致する割合が，ソースの表で水準の最も高い分類器を 4 感情すべてに当てたときの一致の割合を 0.1 以上上回るという別の基準を満たしたのは，MOSEI だけである．

## 7.2 手法：感情ごとの信頼度による late fusion

提案は，5 節の疑似ラベルによる学び直しと同じ声・顔・言葉の線形分類器の答えを，積の代わりに感情ごとの信頼度の表で重みづけてまとめ，まとめた答えを疑似ラベルにする（図 8）．ラベルが感情ごとに数本しか無い設定で答えを決定の段でまとめると，K 本から推す数を水準の 3 つにでき，感情ごとの形はラベルの多いソースで測れる．

<!-- round3 の C-12 を受けて，TFN の批判の文（2.3 節，2.4 節，8.3 節と同じ内容の 4 か所目）を 7.2 節から外した．原文 "This prevents the model from learning inter-modality dynamics in an efficient way by assuming that simple weighted averaging is a proper fusion approach." の出所は ../notes/書き方_有名なMER論文_融合系_2026-11-15.md 55 行 -->

**信頼度．**分類器 k の確率を p_k(i | x) とし，中心化した対数確率を点 z_k(i | x) と呼ぶ．

```
z_k(i | x) = log p_k(i | x) − (1/4) Σ_j log p_k(j | x)                                   (7.1)
d_k(i) = max(0, √2 Φ⁻¹(A_k(i))),   A_k(i) は [0.02, 0.98] に切る                         (7.2)
```

A_k(i) は，本当の感情が i の発話と j の発話を点 z_k(i | ·) で分ける AUC の j ≠ i の 3 つの平均，Φ⁻¹ は標準正規分布の分位点の関数で，d_k(i) の上限は 2.90 である．点の順位は切片をずらしても変わらないので，d_k(i) は分類器の切片にもターゲットの感情の割合にも依らない．水準を L_k = (1/4) Σ_i d_k(i)，相性を r_k(i) = d_k(i) − L_k とする．

<!-- 出所: 上限 2.90 ＝ √2 Φ⁻¹(0.98) は exp/dai16_probe.py の AUC_CLIP = (0.02, 0.98)，docs/設計/実験20_設計.md 3 節の 1 -->

**ソースで測る相性．**ソース s の中の話者を分けた 5 分割の交差検証で d^in_{s,m}(i) を，s の全発話で学んだ分類器を別のソース t に当てて d^out_{s→t,m}(i) を測り，モダリティ m の残り方 η_m（ほかのコーパスで信頼度が残る割合）を全部の向きと感情をまとめた比とする．

```
η_m = Σ_{s→t} Σ_i d^out_{s→t,m}(i) / Σ_{s→t} Σ_i d^in_{s,m}(i)   （[0, 1.5] に切る）
d^src_m(i) = η_m · (1/|S|) Σ_s d^in_{s,m}(i),   r^src_m(i) = d^src_m(i) − (1/4) Σ_j d^src_m(j)   (7.3)
```

3 つの分類器は同じモダリティのソースの分類器の平均をアンカーに学び直したものなので，分類器 k にはそのモダリティの r^src_m を使う．

<!-- 出所: [0, 1.5] の切り詰めは exp/dai16_probe.py 328 行の clip(0, 1.5)，ソースの向き 6 つは docs/設計/実験20_設計.md 3 節の 2．CREMA-D のソースが 4 コーパスであることは docs/結果/実験21_結果の文の下書き_2026-11-15.md 冒頭の事実の記録 5．第 2 版で残り方の記号を ρ_m から η_m に替えた（5 節の疑似ラベルの重み ρ と区別するため．値は同じ）．「η_m は感情で共通と置いた」は式の形（感情で和を取る）から読めるので本文から外した -->

**K 本で測る水準と表．**K 本を感情ごとに 5 組に分け，組 j を除いた K 本で 5 節と同じ手順で 3 つの分類器を学び直して組 j の発話に確率を付け，5 組の確率から式 (7.2) で測った信頼度の 4 感情の平均を L^K_k とする．

```
L_k = (n · L^K_k + n0 · L^0_k) / (n + n0),   n = 4K                                       (7.4)
D(k, i) = max(0, L_k + β · r^src_k(i))                                                     (7.5)
```

式 (7.4) は L^K_k を戻し先 L^0_k（3 つの L^K_k の平均 eq か，ソースで測った水準 src）へ n0 本ぶん戻し，β は相性を使うか（1）使わないか（0）を表す．ハイパーパラメータの格子は n0 ∈ {0, 20, 80, ∞}，β ∈ {0, 1}，戻し先 2 つの 16 点（中身の違う点は 14）で，n0 = ∞，β = 0，戻し先 eq の点は積と同じ判定になる．

<!-- 出所: 5 組と 4K 本は docs/設計/実験20_設計.md 3 節の 3．格子は exp/dai16_probe.py の N0S・BETAS・PRIORS・GRID（16 点），中身の違う点 14 は docs/設計/実験20_設計.md 62 行．戻し先 src は結果ファイルでは `ext` と書く -->

**まとめ方と学び直し．**表を全体の平均で割って重み W(k, i) にし，感情ごとに 3 つの分類器の点を足す．

```
W(k, i) = D(k, i) / ((1/12) Σ_{k′, i′} D(k′, i′)),   s(i | x) = Σ_k W(k, i) · z_k(i | x)     (7.6)
```

感情ごとに違う重みを掛けると答えが特定の感情に寄るので，ラベルを使わずに切片 c をずらす．c は，候補（ターゲットのテスト以外の発話．K 本を含む）の上で softmax(s(· | x) + c) の平均が積の確率の平均と等しくなる点として不動点の反復で求め，推定時の答えを argmax_i (s(i | x) + c_i) とする．q(i | x) = softmax_i(s(i | x) + c_i) を候補に付けて疑似ラベル（soft label）とし，つないだ特徴の分類器（AVT．声・顔・言葉の特徴をつないだ特徴の上の線形分類器．CREMA-D は声と顔の AV）を 5 節と同じ損失で学び直す（以下，提案の学び直した AVT）．疑似ラベルの重み ρ と K 本の倍率 a は，積の疑似ラベルのために選んだ点を借りた．

## 7.3 評価の設定と比べる相手

評価のターゲットは AFEW，IEMOCAP（即興の部），MOSEI，MELD で，ソースは残りの 3 コーパス，反復は分割 5 × K 本の引き方 10 の 50 である．K 本，候補，テストの発話，3 つの分類器は 5 節の評価と同じで，新しく学んだのは水準を測る分類器と提案の学び直した AVT だけである．CREMA-D（声と顔）も 50 反復で評価し，ソースは 4 コーパスで学んだ分類器とした．K は 5，10，25 で，3 つを同じ扱いで並べる．提案は水準を K 本で測るので，K = 0 の条件は無い．K = 10 の疑似ラベルによる学び直し（積）の値は，この評価の計算の中で同じ手順で学び直して求めた．

## 7.7 上がらなかった試み：取り違えの表による疑似ラベルの補正

K 本の別の使い方として，K 本の交差の推定で推した取り違えの表で疑似ラベルを前向きに補正する Gold Loss Correction [@hendrycks2018glc] も試したが，K = 5 で疑似ラベルによる学び直し（積）の UAR を上げなかった．声の分類器では仮のターゲットで 4 コーパスとも「補正しない」が選ばれ，選択を含まない版（縮めない表で補正し，確率の平均をそろえた版）は，補正しない版を IEMOCAP（−1.1 点 [−2.2, −0.1]），MELD（−3.2 点 [−4.7, −1.7]），MOSEI（−2.1 点 [−3.0, −1.1]）で下回り，AFEW（−0.3 点 [−1.2, +0.7]）でも上回らなかった．MOSEI の声では候補の全ラベルで数えた表での補正が補正しない版を +0.8 点 [+0.1, +1.6] 上回った．この結果は，MOSEI の声で上がらなかった理由が，K 本（20 本）から取り違えの表を推定する精度の不足であることを示唆する．AVT では，MELD と MOSEI で選ばれた補正が疑似ラベルによる学び直し（積）を下回った（−1.1 点 [−1.9, −0.2]，−1.2 点 [−2.2, −0.2]）．
