## 1. 手法の呼び方と書き方（7 節）

- 7 節の手法を README の仮の名前どおり「融合の疑似ラベルによる学び直し」と呼んだ．損失は形 (a)（感情ごとの総量をそろえる交差エントロピー．実験 1 の `joint`）と形 (b)（温度つきの交差エントロピー．実験 1 の `kd`）の 2 つに分け，同じ疑似ラベル q を使う 1 つの方法の 2 つの形として書いた．形 (a) を主の形とした．

## 4. 主張の骨格と評価の回の値の食い違い（8 節）

採用した主張の骨格（`DAI/docs/主張_採用した説明_2026-11-13.md`）は捨てずに 8 節の柱にした．ただし，骨格の「モダリティごとの理由」の一部は下調べの値（`results/dai11_probe/req_vs_gain.csv`）から作られており，評価の回の表（実験 14 の 4 節）と次の点で違う．本文は評価の回の値で書いた．

1. **IEMOCAP の顔**：骨格は「余地がほぼ無い（条件 1）」で，その根拠は「向きの余地 0.4」（`results/dai3/eval/decomp.csv` の direction）．LOCO 設定では「向き」の語を使わない方針で，IEMOCAP の顔は物差しの確かめ 2 にも合格していない．本文では「余地の区間が 0 を含み（4.7 [−2.3, +11.6]），P も −1.1」として条件 1 と 3 を挙げた．
2. **AFEW の言葉**：骨格は「まねできない（条件 3）」（下調べの P 1.3）．評価の回では P が R0 で 2.8 [+1.3, +4.4]，R1 で 0.7 [−2.0, +3.3] と読み出しで分かれる．本文はこの分かれ方をそのまま書き，欠けた条件を名指ししなかった．
3. **IEMOCAP の声**：骨格は「3 つともそろう」．評価の回の P は 0.4 [−3.8, +4.5] で 0 を含む（下調べでは 2.9）．本文の柱の文「3 つの条件が 4 コーパスでそろったのは声の分類器だけ」は，IEMOCAP の声の P の点推定が正であることと下調べの値に頼っている．「4 コーパスで 3 つの量の点推定が正だったのは声だけ」と弱めるかを決めてほしい．
4. **融合の MELD**：骨格の表では欠けた条件「なし」で，Δ 2.6・gain +2.5．本文は「MELD の融合だけは Δ と gain がともに正」と書いた．柱の文「そろったのは声だけ」は「4 コーパスすべてで」の意味で正しいが，読み手が融合の MELD を例外と読めるよう書き足すかを決めてほしい．
5. **表 8.1 の値の出所が混ざっている**：声・顔・言葉の Δ と P は評価の回（実験 14．照合済み），融合の Δ と P は仮のターゲット（実験 11 の `req_vs_gain.csv`．この 4 行の値は照合の対象の文に無い），余地の区間と融合の余地は `results/dai3/eval/decomp.csv`（結果の文 C6 で「表に区間を添える」と約束した記述の出力．照合の対象の文に無い）．言葉の行は decomp.csv に無いので余地に区間を付けていない．融合の行を表から外して本文に回すか，このまま † で分けるかを決めてほしい．
