## 9.1 方法

層の重みつき和は，SUPERB [@yang2021superb] が自己教師ありの音声モデルを凍結して評価するときに定めた方式で，WavLM の原論文 [@chen2022wavlm] も感情認識の評価にこの方式を使う．IEMOCAP では，wav2vec 2.0 base を凍結した特徴で，最終層だけを使う場合の 58.5% に対して全層の重みつき和で 67.2% になったという報告がある [@pepino2021]．この節では，層 l の発話ごとの特徴 h_l(x) を

```
φ(x) = Σ_{l=0}^{24} α_l · h_l(x)，  α = softmax(β)
```

とまとめ，φ の上の線形分類器と β を，疑似ラベルとの交差エントロピーで同時に学んだ．ターゲットのラベルは使わない．疑似ラベルは，顔と言葉の K 本だけの分類器の確率の積（以下 pair）である．pair は 7 節の q と違い，学び直す声の分類器自身の予測を含まない．比べる相手は，同じ目標で学んだ最終層だけの線形分類器（最終層）と，α を 1/25 に固定した一様な平均（一様平均）である．

量は，候補を 2 つに分けて交差に予測した判定の，K 本を除いた候補の上の本当の感情に対する UAR の差である．主の量は「重みつき和 − 最終層」で，あわせて「一様平均 − 最終層」と「重みつき和 − 一様平均」を測った．対照として，目標を声の分類器自身の K 本だけの予測にした版と，同じ感情の中で pair を入れ替えた版も学んだ．仮のターゲットの手順は 7.1 節と同じで（30 反復），値は 30 反復の平均である．区間は（分割，種）の 10 組を単位にし，3 つの仮のターゲットを平均してから，候補の塊の引き直し（MOSEI）か塊の jackknife（AFEW・IEMOCAP・MELD）に種の項を足して作った．ハイパーパラメータ（正則化 5 点，保存点 8 点）は，目標との交差エントロピーで選んだ．計算の前に，4 つの K のうち 3 つ以上で区間の下端が 0 を超え点推定が 1.0 以上なら「再現できる分が増えた」とする規則を決めた．

表 9.1 は，AFEW，MELD，MOSEI で，25 層の重みつき和が最終層より pair の判定を本当の感情に合う形で再現したことを示す．K = 5 の差は AFEW +3.91，MELD +2.32，MOSEI +1.05 点で，区間の下端は 0 を超え，4 つの K（1，5，10，25）すべてで規則の「増えた」を満たした．30 反復のうち差が正の反復は，AFEW 30，MELD 28〜29，MOSEI 28〜30 だった．IEMOCAP の差は +0.03 [−1.81, +1.86] で，4 つの K のどれでも規則を満たさなかった．IEMOCAP では重みつき和の交差エントロピーが最終層を上回った半分が 41% あり，層の重みの最適化が足りていない．塊が 5 つのセッションで区間も広く，筋書きの話題の共有とも分けられない．

増えた分の大きさは，層の重みを学んだことではなく，最終層以外の層を足したことから生じた．一様平均 − 最終層は AFEW +3.26，MELD +2.39，MOSEI +1.06 点で，重みつき和 − 最終層とほぼ同じだった．重みつき和 − 一様平均は AFEW +0.65 [−0.52, +1.82]，MELD −0.06，MOSEI −0.01 点で，MELD と MOSEI では 1.0 点以上の寄与を区間で除けるが，AFEW では除けない．IEMOCAP では −1.70 点と負だった．対照の 2 つの版はこの読みに次の断りを加える．声の分類器自身の予測を目標にした版でも，AFEW では層を足すと UAR が +0.22〜+0.68 点（K = 0〜25．区間はすべて 0 を含む）上がったので，AFEW の値はこの分を割り引いて読む（最大の 0.68 を引いても +3.2〜+4.1 点）．同じ感情の中で pair を入れ替えた目標でも，3 コーパスで同じ程度に再現できる分が増えた（AFEW +3.5〜+4.2，MELD +1.0〜+2.3，MOSEI +1.3〜+2.0 点）．したがって，増えた分の少なくとも一部は，感情そのものか感情と結びついた手がかりを通っている．

最終層以外の層を足すと，本当のラベルで学んだ分類器も上がった．候補の全ラベルで学んだとき，重みつき和 − 最終層は AFEW +3.85〜+4.12，MELD +3.81〜+3.86，MOSEI +2.99〜+3.02 点で区間の下端が 0 を超え，IEMOCAP は +1.73〜+1.77 点で区間が 0 を含んだ．全ラベルで学ぶと，層の重みを学ぶことが一様平均にさらに MELD で +1.14〜+1.17，MOSEI で +0.58〜+0.60 点を足した．

## 9.3 読み方

最終層で再現できない分と比べると，中間層から取り戻せた分は一部だった．K = 1〜25 の平均で，最終層で再現できない分は AFEW 21.3，MELD 7.0，IEMOCAP 3.7，MOSEI 3.2 点，重みつき和で取り戻せた分は 4.3，2.3，0.4，1.2 点で，比は 0.20，0.33，0.11，0.36 だった（AFEW の比は 9.2 節の割り引きの前の値である）．残りの 6〜9 割が，線形の頭では取り出せないのか，音声の入力に無いのかは，この計算では分けられない．以上から，凍結した WavLM の上の声の分類器では，最終層以外の層を特徴に加えることが，疑似ラベルの判定のうち再現できる分を増やす手段の 1 つであり，その場所はエンコーダの側にある．
