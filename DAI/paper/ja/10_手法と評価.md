本節では，4〜8 節の解析から組み立てた手法（以下，提案）を定義し，LOCO 設定で評価する．提案は 7 節の手法（融合の疑似ラベルによる学び直し）と同じ 3 つの線形分類器を使い，答えのまとめ方だけを変える．7 節の手法は 3 つの確率を同じ重みで掛けた答え（以下，積）を疑似ラベルにした．提案は，水準をターゲットの K 本で，相性をソースで測った信頼度の表で点を重みづけて足し，その答えを疑似ラベルにする．

## 10.1 手法

### 10.1.1 手法の組み立ての根拠

提案の組み立ては，前半の解析の 2 つの結果に基づく．1 つ目に，4 節と 5 節の結果から，K 本の少数のラベルが直せるのは主に切片のずれであり，重みの向きのずれは少数のラベルでは直りが遅い．このため提案では，信頼度を切片に依らない量で定義し，K 本からは分類器ごとに 1 つの数（水準）だけを測る．

2 つ目に，4 コーパスを 1 つずつ仮のターゲットにした下調べ（K = 5．ソースは残る 2 つ）で測った値では，分類器ごとの水準はコーパスで入れ替わり，水準を除いた感情ごとの形はコーパスをまたいで似ていた．ソースで測った水準と仮のターゲットの全ラベルで測った水準の相関は −0.954〜+0.365，最強のモダリティが一致した割合は 0〜0.367 だった（K 本で測った表では 0.433〜0.967）．信頼度の表から水準，共通の感情ごとの当てやすさ，その掛け算の項を除いた残り（分類器 × 感情の成分）では，ソースの表と全ラベルの表の相関が 0.493〜0.770 で，感情の並びを入れ替えて元の相関以上になる割合は 0.096〜0.192 だった．K 本だけで測った表では，この基準を満たしたコーパスは無かった．感情ごとに最も強いモダリティの一致の基準を満たしたのは MOSEI だけである．

### 10.1.2 信頼度

分類器 k（声，顔，言葉）の確率を p_k(i | x) とし，中心化した対数確率を点と呼ぶ．

```
z_k(i | x) = log p_k(i | x) − (1/4) Σ_j log p_k(j | x)                      (10.1)
```

点の和が最大の感情は，積の確率が最大の感情と同じである．感情 i の信頼度 d_k(i) は，本当の感情が i の発話と j の発話を点 z_k(i | ·) で分ける AUC を j ≠ i の 3 つで平均した値 A_k(i) から作る．

```
A_k(i) ← min(0.98, max(0.02, A_k(i)))
d_k(i) = max(0, √2 Φ⁻¹(A_k(i)))                                              (10.2)
```

Φ⁻¹ は標準正規分布の分位点の関数であり，d_k(i) の上限は 2.90 である．切片をずらしても発話どうしの点の順位は変わらないので，d_k(i) は分類器の切片にも，ターゲットの感情の割合にも依らない．分類器 k の水準を L_k = (1/4) Σ_i d_k(i)，感情 i の相性を r_k(i) = d_k(i) − L_k とする．

### 10.1.3 ソースで測る相性

相性はソースのラベルだけで測る．ソース s の中の話者を分けた 5 分割の交差検証で信頼度 d^in_{s,m}(i) を測り，ソース s の全発話で学んだ分類器を別のソース t に当てて信頼度 d^out_{s→t,m}(i) を測る．モダリティ m の残り方 ρ_m を，ソースの全部の向き (s → t) と全部の感情をまとめた比として定め，[0, 1.5] に切る．

```
ρ_m = Σ_{s→t} Σ_i d^out_{s→t,m}(i) / Σ_{s→t} Σ_i d^in_{s,m}(i)
d^src_m(i) = ρ_m · (1/|S|) Σ_s d^in_{s,m}(i)                                  (10.3)
r^src_m(i) = d^src_m(i) − (1/4) Σ_j d^src_m(j)
```

ρ_m は感情で共通と置いた．評価の回ではソースは 3 つで，向きは 6 つである（CREMA-D ではソースは 4 つ）．3 つの分類器は同じモダリティのソースの分類器の平均から学び直したものなので，分類器 k の相性にはそのモダリティの r^src_m を使う．

### 10.1.4 ターゲットの K 本で測る水準

水準はターゲットの K 本（4K 本）で測る．K 本を感情ごとに 5 組に分け，組 j を除いた K 本で 7 節と同じ手順で 3 つの分類器を学び直し，学び直した分類器の確率を組 j の発話に付ける．5 組すべての発話に付けた確率から式 (10.2) で信頼度を測り，その 4 感情の平均を K 本の水準 L^K_k とする．
<!-- 出所: 5 組と 4K 本は docs/設計/実験20_設計.md 3 節の 3 -->

### 10.1.5 表の組み立て

水準は，K 本の水準を戻し先 L^0_k へ n0 本ぶん戻した値とし，信頼度の表は水準に相性を足して作る．

```
L_k = (n · L^K_k + n0 · L^0_k) / (n + n0),   n = 4K                          (10.4)
D(k, i) = max(0, L_k + β · r^src_k(i))                                       (10.5)
```

n0 は「戻し先をラベル何本ぶん信じるか」を表す．戻し先 L^0_k は，3 つの分類器の L^K_k の平均（eq）か，ソースで測った水準（src）のどちらかである．β は相性を使うか（1）使わないか（0）を表す．ハイパーパラメータの格子は n0 ∈ {0, 20, 80, ∞}，β ∈ {0, 1}，戻し先 ∈ {eq, src} の 16 点で，n0 = 0 では戻し先が答えに関わらないので，中身の違う点は 14 である．n0 = ∞，β = 0，戻し先 eq の点は積と同じ判定になる．

ハイパーパラメータは，評価するコーパスを含まない計算で選んだ．評価のターゲット T と K ごとに，下調べで T 以外の 3 コーパスを仮のターゲットにした 30 反復（ソースも T を含まない．ソースは 2 つ）の，テストの UAR の平均が最大の点を選び，評価の回では選び直さない．選ばれた点はどれも β = 1 で，n0 = 20 は AFEW の K = 5・25（戻し先 eq）と MELD の K = 5・10（戻し先 src）の 4 条件，ほかの 8 条件は n0 = 0 だった．CREMA-D の点は，CREMA-D と RAVDESS を足した 6 コーパスの下調べのうち CREMA-D を含まない 40 反復で選び，3 つの K とも n0 = 0，β = 1 だった．

### 10.1.6 まとめ方と切片

信頼度の表を全体の平均で割って重み W(k, i) にし，感情ごとにその感情の列の重みで 3 つの分類器の点を足す．

```
W(k, i) = D(k, i) / ((1/12) Σ_{k′, i′} D(k′, i′))
s(i | x) = Σ_k W(k, i) · z_k(i | x)                                          (10.6)
```

重みがすべて 1 なら，s の最大の感情は積の判定と同じである．感情ごとに違う重みを掛けるとまとめた点が特定の感情に寄るので，ラベルを使わずに切片 c = (c_1, …, c_4) をずらす．c は，候補（ターゲットのラベル無しの発話．K 本を含み，テストを含まない）の上での softmax(s(· | x) + c) の平均が積の確率の平均と等しくなる点として，不動点の反復で求める．提案の推定時の答えは argmax_i (s(i | x) + c_i) である．

### 10.1.7 学び直し

提案の答えの確率 q(i | x) = softmax_i(s(i | x) + c_i) を候補に付けて疑似ラベル（soft label）とし，融合の分類器（AVT．CREMA-D は AV）を 7 節の形 (a) の損失で学び直す．7 節の手法との違いは，疑似ラベルを積から q に置き換えることだけである．疑似ラベルの重み ρ と K 本の倍率 a には，積の疑似ラベルのために選ばれた点をそのまま使う．4 コーパスでは 7 節で選んだ ρ = 1，a = 1，CREMA-D では CREMA-D を含まない下調べの反復で選んだ点（K = 5 で ρ = 1，a = 16，K = 10・25 で ρ = 4，a = 1．3 つのモダリティの融合で選んだ値を借りた）である．

### 10.1.8 先行研究との関係

積の規則と和の規則は Kittler ほか [@kittler1998] が整理し，分類器 × クラスの重みで答えをまとめる形は Kuncheva と Rodríguez [@kuncheva2014] の枠組みに含まれる．感情認識では，Kaya ほか [@kaya2017] と Kahou ほか [@kahou2015] が AFEW でモデル × 感情の重みを検証データの上の乱数探索で決めた．Busso ほか [@busso2004] は感情ごとにモダリティの強さが違うことを報告し，取り違えの表から作った重みの融合の正解率（0.86）が積の正解率（0.89）を下回ったことも報告した．Marín ほか [@marin2026classwise] は，全ラベルで学んだ MLP が発話ごとに出す感情ごとのモダリティの重みを，コーパスの中で使った．推す数を減らす考えは，1 つの数の temperature scaling が，クラスごとの数を推す vector scaling や matrix scaling より良かった Guo ほか [@guo2017calibration] の結果にある．著者らは較正のずれが低次元であることをその理由に挙げた．評価するドメインを含まない計算でハイパーパラメータを選ぶ手順は，ドメイン汎化の leave-one-domain-out の選択 [@gulrajani2021] と同じ形である．今回の文献の検索では，信頼度の表を水準と相性に分けて水準をターゲットの K 本で，相性をソースで測る組み立ても，10.1.1 節の 2 つの測定を感情認識で別々に行った例も見つからなかった．
