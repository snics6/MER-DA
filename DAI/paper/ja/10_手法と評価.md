# 10 分析から作った手法とその評価

本節では，4〜8 節の解析の結果から組み立てた手法（以下，提案）を定義し，LOCO 設定で評価する．提案は，7 節の手法（融合の疑似ラベルによる学び直し）と同じ声・顔・言葉の 3 つの線形分類器を使い，3 つの分類器の答えのまとめ方だけを変える．7 節の手法は 3 つの確率を同じ重みで掛け（以下，積），積を疑似ラベルにして融合の分類器を学び直した．提案は，分類器ごと・感情ごとの信頼度の表で 3 つの分類器の点を重みづけて足し，その答えを疑似ラベルにして融合の分類器を学び直す．信頼度の表のうち，分類器ごとの水準はターゲットの K 本で測り，感情ごとの相性はソースで測る．10.5 節には，同じ時期に試して UAR が上がらなかった方法を記す．

## 10.1 手法

### 10.1.1 手法の組み立ての根拠

提案の組み立ては，前半の解析の 2 つの結果に基づく．1 つ目に，4 節と 5 節の結果から，K 本の少数のラベルが直せるのは主に切片のずれであり，重みの向きのずれは少数のラベルでは直りが遅い．このため提案では，信頼度を切片に依らない量で定義し，K 本からは分類器ごとに 1 つの数（水準）だけを測る．

2 つ目に，4 コーパスの下調べ（K = 5）で，分類器ごとの水準はコーパスによって入れ替わり，水準を除いた感情ごとの形はコーパスをまたいで似ていた．ソースで測ったモダリティの水準とターゲットの全ラベルで測った水準の相関は −0.954〜+0.365 で，ソースで測った表の最強のモダリティがターゲットの全ラベルの表の最強のモダリティと一致した割合は 0〜0.367 だった（K 本で測った表では 0.433〜0.967）．信頼度の表から，分類器ごとの水準，どの分類器にも共通の感情ごとの当てやすさ，その 2 つの掛け算の項を除いた残りを分類器 × 感情の成分と呼ぶ．この成分の，ソースで測った表とターゲットの全ラベルの表の間の相関は 0.493〜0.770 で，感情の並びを入れ替えたときに元の相関以上になる割合は 0.096〜0.192 だった（K = 10 では 4 コーパスのうち MELD を除く 3 で同じ基準を満たした）．K 本だけで測った表では，この基準を満たしたコーパスは無かった．ただし，感情ごとに最も信頼度の高いモダリティが一致したかを見る基準を満たしたのは MOSEI だけで，「どの感情でどのモダリティが最も強いか」が持ち越せたとまでは言えない．

### 10.1.2 信頼度

分類器 k（声，顔，言葉）の確率を p_k(i | x) とし，中心化した対数確率を点と呼ぶ．

```
z_k(i | x) = log p_k(i | x) − (1/4) Σ_j log p_k(j | x)                      (10.1)
```

点の和が最大の感情は，積の確率が最大の感情と同じである．感情 i の信頼度 d_k(i) は，本当の感情が i の発話と j の発話を点 z_k(i | ·) で分ける AUC を j ≠ i の 3 つで平均した値 A_k(i) から作る．

```
A_k(i) ← min(0.98, max(0.02, A_k(i)))
d_k(i) = max(0, √2 Φ⁻¹(A_k(i)))                                              (10.2)
```

Φ⁻¹ は標準正規分布の分位点の関数であり，d_k(i) の上限は 2.90 である．切片をずらしても発話どうしの点の順位は変わらないので，d_k(i) は分類器の切片にも，ターゲットの感情の割合にも依らない．分類器 k の水準を L_k = (1/4) Σ_i d_k(i)，感情 i の相性を r_k(i) = d_k(i) − L_k とする．

### 10.1.3 ソースで測る相性

相性はソースのラベルだけで測る．ソース s の中の話者を分けた 5 分割の交差検証で信頼度 d^in_{s,m}(i) を測り，ソース s の全発話で学んだ分類器を別のソース t に当てて信頼度 d^out_{s→t,m}(i) を測る．モダリティ m の残り方 ρ_m を，ソースの全部の向き (s → t) と全部の感情をまとめた比として定め，[0, 1.5] に切る．

```
ρ_m = Σ_{s→t} Σ_i d^out_{s→t,m}(i) / Σ_{s→t} Σ_i d^in_{s,m}(i)
d^src_m(i) = ρ_m · (1/|S|) Σ_s d^in_{s,m}(i)                                  (10.3)
r^src_m(i) = d^src_m(i) − (1/4) Σ_j d^src_m(j)
```

ρ_m は感情で共通と置いた．評価の回ではソースは 3 つで，向きは 6 つである．3 つの分類器は同じモダリティのソースの分類器の平均から学び直したものなので，分類器 k の相性にはそのモダリティの r^src_m を使う．

### 10.1.4 ターゲットの K 本で測る水準

水準はターゲットの K 本（4K 本）で測る．K 本を感情ごとに 5 組に分け，組 j を除いた K 本で 7 節と同じ手順で 3 つの分類器を学び直し，学び直した分類器の確率を組 j の発話に付ける．5 組すべての発話に付けた確率から式 (10.2) で信頼度を測り，その 4 感情の平均を K 本の水準 L^K_k とする．
<!-- 出所: 5 組と 4K 本は DAI/docs/実験20_設計.md 3 節の 3 -->

### 10.1.5 表の組み立て

水準は，K 本の水準を戻し先 L^0_k へ n0 本ぶん戻した値とし，信頼度の表は水準に相性を足して作る．

```
L_k = (n · L^K_k + n0 · L^0_k) / (n + n0),   n = 4K                          (10.4)
D(k, i) = max(0, L_k + β · r^src_k(i))                                       (10.5)
```

n0 は「戻し先をラベル何本ぶん信じるか」を表す．戻し先 L^0_k は，3 つの分類器の L^K_k の平均（eq）か，ソースで測った水準（src）のどちらかである．β は相性を使うか（1）使わないか（0）を表す．ハイパーパラメータの格子は n0 ∈ {0, 20, 80, ∞}，β ∈ {0, 1}，戻し先 ∈ {eq, src} の 16 点で，n0 = 0 では戻し先が効かないので，中身の違う点は 14 である．n0 = ∞，β = 0，戻し先 eq の点は積と同じ判定になる．
<!-- 出所: 格子は DAI/exp/dai16_probe.py の N0S・BETAS・PRIORS・GRID（16 点），中身の違う点 14 は DAI/docs/実験20_設計.md 62 行．戻し先 src は結果ファイルでは `ext` と書く -->

ハイパーパラメータは，評価するコーパスを含まない計算で選んだ．評価のターゲット T と K ごとに，下調べで T 以外の 3 コーパスを仮のターゲットにした 30 反復（ソースも T を含まない．ソースは 2 つ）の，テストの UAR の平均が最大の点を選び，評価の回では選び直さない．選ばれた点は，K = 5 で AFEW が n0 = 20・戻し先 eq，IEMOCAP と MOSEI が n0 = 0，MELD が n0 = 20・戻し先 src，K = 10 で AFEW が n0 = 0，MELD が n0 = 20・戻し先 src，K = 25 で AFEW が n0 = 20・戻し先 eq，MELD が n0 = 0 で，ほかは n0 = 0 だった．どの (T, K) でも β = 1（相性を使う点）が選ばれた．CREMA-D の点は【TBA】である．

### 10.1.6 まとめ方と切片

信頼度の表を全体の平均で割って重み W(k, i) にし，感情ごとにその感情の列の重みで 3 つの分類器の点を足す．

```
W(k, i) = D(k, i) / ((1/12) Σ_{k′, i′} D(k′, i′))
s(i | x) = Σ_k W(k, i) · z_k(i | x)                                          (10.6)
```

重みがすべて 1 なら，s の最大の感情は積の判定と同じである．感情ごとに違う重みを掛けると，まとめた点が特定の感情に寄る．この寄りを除くため，ラベルを使わずに切片 c = (c_1, …, c_4) をずらす．c は，候補（ターゲットのラベル無しの発話．K 本を含み，テストを含まない）の上での softmax(s(· | x) + c) の平均が，同じ候補の上での積の確率の平均と等しくなる点として，不動点の反復で求める．提案の推定時の答えは argmax_i (s(i | x) + c_i) である．

### 10.1.7 学び直し

提案の答えの確率 q(i | x) = softmax_i(s(i | x) + c_i) を候補に付けて疑似ラベル（soft label）とし，融合の分類器（AVT．CREMA-D は AV）を学び直す．損失は 7 節の式（7.【TBA：7 節の式番号】）と同じで，疑似ラベルの確率だけを積から q に置き換える．すなわち，K 本の感情の釣り合いの重みつきの交差エントロピーに，感情ごとの総量をそろえた q を重みにした交差エントロピーを足し，ソースの分類器の平均をアンカー（L2 正則化の中心）とする L2 正則化を加える．疑似ラベルの重みと K 本の倍率のハイパーパラメータは【TBA：評価の回の固定のファイルに合わせて書く】．

### 10.1.8 先行研究との関係

提案の部品は既知の考え方に基づく．積の規則と和の規則は Kittler ほか [@kittler1998] が整理し，分類器 × クラスの重みで答えをまとめる形は Kuncheva と Rodríguez [@kuncheva2014] の枠組みに含まれる．感情認識では，Kaya ほか [@kaya2017] と Kahou ほか [@kahou2015] が AFEW でモデル × 感情の重みを検証データの上の乱数探索で決めた．Busso ほか [@busso2004] は感情ごとにモダリティの強さが違うことを報告し，取り違えの表から作った重みの融合の正解率（0.86）が積の正解率（0.89）を下回ったことも報告した．Marín ほか [@marin2026classwise] は，全ラベルで学んだ MLP が発話ごとに出す感情ごとのモダリティの重みを，コーパスの中で使った．推す数を減らす考えは，1 つの数の temperature scaling が，クラスごとの数を推す vector scaling や matrix scaling より良かった Guo ほか [@guo2017calibration] の結果にある．著者らは較正のずれが低次元であることをその理由に挙げた．評価するドメインを含まない計算でハイパーパラメータを選ぶ手順は，ドメイン汎化の leave-one-domain-out の選択 [@gulrajani2021] と同じ形である．今回の文献の検索では，信頼度の表を水準と相性に分けて水準をターゲットの K 本で，相性をソースで測る組み立ても，10.1.1 節の 2 つの測定を感情認識で別々に行った例も見つからなかった．

## 10.2 評価

### 10.2.1 評価の手順

評価は，7 節の LOCO 設定の評価の回の保存の上で行った．評価のターゲット T は AFEW，IEMOCAP（即興），MOSEI，MELD の 4 つで，T ごとに分割 5 × 種 10 の 50 反復，合計 200 反復である．ソースは T 以外の 3 コーパスである．K 本，候補，テストの発話，3 つの分類器は 7 節の評価の回の保存をそのまま使い，新しく学んだのは 10.1.4 節の水準を測るための分類器の学び直しと，10.1.7 節の融合の分類器の学び直しだけである．CREMA-D（声と顔）は【TBA：評価の回の反復の数とソース】で評価した．手法の形とハイパーパラメータは下調べの出力だけで決めてファイルに固定し，評価の回は 1 回だけ流した．

提案の形は，各コーパスを仮のターゲットにした下調べの結果を見た後に決めた．評価の回のテストの発話は，下調べで同じコーパスを仮のターゲットにしたときのテストの発話と同じであり，種 0・1 の反復では K 本と候補も同じである．下調べとの違いはソースの数（下調べは 2，評価の回は 3）と，それによる分類器である．比べる相手のうち水準だけの重み，K 本だけの表，表で読み替えて掛ける版は，下調べで同じテストの発話の上で比べた版である．
<!-- 出所: DAI/docs/実験20_設計.md 2 節（34 行：50 反復，200 反復，ソース 3 つ），1 節の 1（14 行：テストの重なり，種 0・1，ソースの数） -->

K は 5，10，25 を同じ扱いで並べ，主の K と判定の規則は置かない．区間は 7 節と同じ作り方の 95% 区間で，多重比較の補正はしていない．区間はテストの塊（話者や作品など）の取り方と K 本の引き方（種）の揺れを含み，ソースの取り方，学習側の発話，手法とハイパーパラメータの選び方の揺れは含まない．3 つの K は同じテストの発話の上の値なので，K どうしの差の区間は作らない．

ハイパーパラメータは 10.1.5 節の固定した点を主とし，参考として，評価の回で T 以外の 3 つの評価のターゲットの UAR の平均が最大の点（T はほかのターゲットの反復でソースに入るので，T の全発話のラベルを使う）と，T のテストで最良の点（オラクル）を並べる．

提案の部品を 1 つずつ外した版を作り，提案との差を部品の寄与とする．表 10.4 に外す部品と差の読み方を示す．重みは max(0, 水準 + 相性) で作るので，部品の寄与は外す順序で変わる．このため提案 − 積を，相性を先に外す順序（提案 − 相性を外した版，相性を外した版 − 積）と，水準の違いを先に外す順序の 2 通りで分ける．相性を使った分は，さらに分類器 × 感情の成分の分と，それ以外（共通の感情ごとの重み，水準と感情の掛け算の項）に分ける．分類器 × 感情の成分は，重みの表（3 × 4）に「全体の平均 + 行の差 + 列の差 + λ × 行の差 × 列の差」（Tukey の非加法性の 1 自由度 [@tukey1949]）を当てはめた残りである．

## 10.4 前半の道具による解析

### 10.4.1 切片の分と向きの分

2 節の誤りの分け方を提案の gain に当てる．提案と積のそれぞれについて，ターゲットの候補の全ラベルで切片 4 つを最良にそろえた答え（感情ごとに等しい重みの対数尤度を最大にする切片を足した答え．実際には使えない参照）を作る．切片をそろえた答えどうしの差 gain_向き =（提案の切片をそろえた答え − 積の切片をそろえた答え）を向きの分とし，gain（提案 − 積）から向きの分を引いた残りを切片の分とする．評価の回の各反復には，切片の扱いを変えた 4 通りの答え（切片をずらさない答え，ラベルを使わずにずらした答え，K 本で決めた切片を足した答え，全ラベルでそろえた答え）が保存されており，計算の後にこの分解を集計する．学び直した融合の分類器については保存した重みから，2 節と同じ方法で切片のずれと向きのずれを測る．値は【TBA】である．

### 10.4.2 3 条件の当てはめ

8 節の 3 条件を，提案の答えを疑似ラベルにした融合の分類器の学び直しに当てる．条件 2（疑似ラベルが学び直す前の分類器より当たる）の量として，候補の上での疑似ラベルの UAR の上がり幅（提案の答え − 積）を測る．これと学び直した融合の分類器の上がり幅（提案の疑似ラベル − 積の疑似ラベル）の関係を，(T, K) ごとに並べる．条件 3（疑似ラベルの判断を自分の特徴で再現できる）の量として，学び直した融合の分類器の判定が候補の上で疑似ラベルの判定と一致する割合を測る．条件 1（余地）の量は 8 節と同じ定義で測る．値は【TBA】である．

## 10.5 上がらなかった試み

K 本で推した取り違えの表で疑似ラベルを前向きに補正する方法（Gold Loss Correction の前向き補正 [@hendrycks2018glc]）も試したが，UAR は 7 節の手法より上がらなかった．この方法では，K 本の交差の推定で疑似ラベルの取り違えの表を推し，学び直す分類器の確率にその表を掛けてから疑似ラベルとの交差エントロピーを取る．補正するかどうかと表の縮め方を仮のターゲットの回で選ぶと，声の分類器では 4 コーパスすべてで「補正しない」が選ばれ，評価の回の差は 0 だった．選択を含まない版（縮めない表で補正し，候補の上の確率の平均をそろえた版）では，声の分類器は補正しない版を IEMOCAP（−1.1 点 [−2.2, −0.1]），MELD（−3.2 点 [−4.7, −1.7]），MOSEI（−2.1 点 [−3.0, −1.1]）で下回り，AFEW（−0.3 点 [−1.2, +0.7]）でも上回らなかった．MOSEI の声では，候補の全ラベルで数えた表で補正すると補正しない版を +0.8 点 [+0.1, +1.6] 上回り，K 本の表で補正した版を +2.9 点 [+2.1, +3.8] 上回ったので，K 本の補正が上がらなかった理由は，K 本（K = 5 で 20 本）からの表の推定の不足である．融合の分類器では，MELD と MOSEI で縮めた表の補正が選ばれ，7 節の手法を MELD で −1.1 点 [−1.9, −0.2]，MOSEI で −1.2 点 [−2.2, −0.2] 下回った（候補の上の確率の平均をそろえない差．そろえた差では MOSEI は −0.8 点 [−1.7, +0.1] で，下回ったとは言えない）．
