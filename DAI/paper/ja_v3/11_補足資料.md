# S1 声の特徴は言葉の分類器の判定を予測できるか

5 節で声の分類器の gain が出たことの理由の候補の 1 つとして，声の特徴が，積に含まれる言葉の分類器の判定を予測できるかを調べた．

## S1.1 設定

声の分類器の gain が正だった理由の 1 つとして，音声には声の調子と話す言葉の両方が入っているという説明を調べる．積の疑似ラベルには言葉の分類器の答えが入っているので，声の特徴から言葉の分類器の答えを真似できるなら，声の分類器はその分を疑似ラベルから学べる．真似できる度合いを次の手順で測る（図 S1）．

1. あるモダリティの K 本の基準の分類器の判定 J（例：言葉の分類器の判定）を目標にする．
2. 別のモダリティの特徴（例：声の特徴）の上の線形分類器で J を当てる．J を正解とみなした UAR を R とする．当てる分類器は別の発話で学んで予測する．
3. 本当の感情と話者のクラスタ（IEMOCAP と AFEW では性別も）の層の中で J を入れ替えた目標で同じことをし，その UAR を R′ とする．
4. D ＝ R − R′ を，感情と話者で説明できる一致を除いた，真似できる度合いとする．

![図 S1　真似できる度合い D の測り方（説明のための例）．言葉の分類器の答え J を声の特徴だけで当てた一致を R，J を同じ感情・同じ話者のまとまりの中で入れ替えた J′ を当てた一致を R′ とし，D ＝ R − R′ を求める．例では一致の割合で数えたが，実験では J を正解とみなした UAR で数える．発話と答えは説明のための例である](../figures/fig_D_toy_ja.pdf)

判定の規則は計算の前に K = 5 で固定し，言葉が音声の書き起こしである AFEW は声と言葉の比べから外した．さらに，IEMOCAP（即興の部），MOSEI，MELD の音声を逆再生して WavLM-large の最後の層の特徴を作り直し，同じ D を測った（予言と数えの規則は計算の前に固定し，問いは逆再生しない D の結果を見た後に立てた）．逆再生した音声では，Whisper large-v3 の書き起こしの語の一致率が偶然の水準を超えた分は 0.005〜0.012 だった（元の音声では 0.79〜0.80）．

## S1.2 結果：声の特徴は，言葉の分類器の判定を顔の特徴より真似できた

AFEW を除く 3 コーパスで，言葉の分類器の判定を真似できる度合い D は，声の特徴が IEMOCAP 19.3，MOSEI 10.5，MELD 17.7 点で，顔の特徴（2.0，0.3，3.8 点）より大きかった（差は +17.3，+10.2，+13.9 点で，どれも区間が 0 を上回った）．顔の分類器の判定を声の特徴が言葉の特徴よりよく真似できるかは，K = 5 では計算の前に決めた規則を満たさなかった．D には，覚醒度，話者の属性，発話の長さ，録音の場面による一致も含まれうる．

音声を逆再生して言葉を聞き取れなくすると，言葉の分類器の判定を真似できる度合い D は，19.3，10.5，17.7 点から 10.5，3.1，10.5 点に下がり，差は 3 コーパスとも区間の下端が 0 を超えた（IEMOCAP 8.8 [3.0, 14.7]，MOSEI 7.5 [6.3, 8.6]，MELD 7.2 [4.7, 9.8]）（図 S2）．逆再生した声の D は，それでも顔の特徴の D より大きかった（差は IEMOCAP 8.5 [3.8, 13.1]，MOSEI 2.7 [1.3, 4.1]，MELD 6.7 [3.8, 9.6] 点）．声が言葉の分類器の判定を真似できる分は，聞き取れる言葉だけでは説明できなかった．残る分の候補には，平均のスペクトル，基本周波数の分布，発話の長さ，同じ感情のラベルの中の強さの違い，WavLM の特徴に残りうる言葉の情報があり，この実験ではどれかに帰せない．

## S1.3 限界

**言葉を聞き取りにくくする操作．** S1.2 節の逆再生は，Whisper large-v3 の書き起こしで言葉を聞き取れなくしたことを確かめたが，人の聞き手では確かめていない．逆再生は時間の向きのある手がかりも反転し，WavLM の学習で見ていない種類の音声を作る．このため，逆再生で下がった D の分を，聞き取れる言葉の情報だけに帰さない．逆再生とは別の操作で言葉を聞き取りにくくした音声で同じ D を測ることが次に試すことである．

# S4 疑似ラベルを目標にするほかの損失の形

本文の蒸留は，温度を使わない形 (a) の損失で積を目標にして学び直す（本文 5.1.1 節）．主の損失は評価の回の前に形 (a) と決めた．比べのために，疑似ラベルを目標にするほかの 5 つの損失の形も同じ手順で学び，評価のターゲット，分類器，K の組ごとに仮のターゲットで UAR が最も高い形を形 (a) と比べた．5 つは，温度つきの損失（形 (b)．[@hinton2015distilling]．τ = 2 は Albanie ほか [@albanie2018] の値），一致した発話だけの疑似ラベル [@shi2024audioguided]，自分の予測と混ぜる方法 [@zhang2021combining]，柔らかい共訓練（[@blum1998] の考えを著者らが変形したもの），共正則化 [@sindhwani2005coreg] である．どれも原論文の損失の形を疑似ラベルを受け取るように移した版で，原論文と同じ手法ではない．

損失の形を替えても，声の分類器の UAR の差は 1 点未満だった（主の損失を仮のターゲットで選ばれた温度つきの形 (b) に替えた，声の K = 0，5，10，25 の 16 条件で −0.79〜+0.87 点）．また，仮のターゲットで選んだハイパーパラメータは，声の 16 条件すべてで調整しないときの値と同じ分類器になった．声の gain は，損失の形とハイパーパラメータの選び方から生じたものではないことを示唆する．
