## 絞った主張（ver3 の 1 文）

新しいコーパスに感情ごとに数本のラベルしか無いとき，ほかのモダリティを含む疑似ラベルは，ほかの情報源ではほとんど減らない残りの誤りを減らし，蒸留で声の分類器の UAR を上げたが，上がったのは疑似ラベルの UAR が学び直す前の分類器より高いときだけだった．そこで，疑似ラベルの UAR を上げるために，分類器の強さを数本のラベルで，感情ごとの得意不得意をソースで測る late fusion を提案した．

この 1 文に要らない解析は，本文から外すか補足資料（`11_補足資料.md`．英語版では Supplementary Information）に移す．ver2 から外したものは ver2 のファイルと git に残っている．
