本節は，3.6 節の A〜C の群の条件を比べ，4 つの情報源が誤りのどの部分を直すか（問い 1(a)）と，蒸留がどの分類器の UAR をどんな場合に上げるか（問い 1(b)）を解析する．

## 4.1 誤りの 2 つの部分

線形分類器は，感情の対ごとに特徴の空間に境目を引いて答える．境目の向きは重みで，位置は切片で決まる（補足資料の図 S2）．境目の向きは正しいが位置がずれ，答えが一方の感情に偏る誤りを**答えの偏り**（切片のずれ）と呼ぶ．この誤りは切片だけを直せば消える．偏りを直しても残る誤りを**残りの誤り**（重みの向きのずれ）と呼ぶ．この誤りは重みの向きを変えないと減らない．

2 つの誤りの大きさは次のように測る．分類器の感情 $k$ の点数を $s_k(x)=w_k^\top x+b_k$ とすると，感情 $k$ と $l$ を分ける判定は $z_{kl}=(w_k-w_l)^\top x+(b_k-b_l)$ の符号で決まる．ターゲットのテストの感情 $k$ の発話の $z_{kl}$ の平均と分散を $\hat\mu_k$，$v_k$ とし（$l$ も同じ），$\sigma=\sqrt{(v_k+v_l)/2}$ として

$$d_{kl}=\frac{\hat\mu_k-\hat\mu_l}{\sigma},\qquad o_{kl}=-\frac{\hat\mu_k+\hat\mu_l}{2\sigma}$$

と定める．$d$ は 2 つの感情の発話の判定の軸の上での離れ方，$o$ は 2 つの感情の $z_{kl}$ の平均の中点から境目（$z_{kl}=0$）までのずれを $\sigma$ で割った量である．2 つの感情の $z_{kl}$ を分散の等しい正規分布とみなすと，対の正解率は $A(d,o)=\tfrac12[\Phi(d/2-o)+\Phi(d/2+o)]$ で，ターゲットのラベル付きの発話の線形判別分析（共分散は Ledoit–Wolf の縮小推定 [@ledoit2004]）の向きでの離れ方を $D^{*}$ とすると，対の損は

$$A(D^{*},0)-A(d,o)=\underbrace{[A(D^{*},0)-A(d,0)]}_{\text{向きの損}}+\underbrace{[A(d,0)-A(d,o)]}_{\text{切片の損}}$$

に分かれる．切片だけを変えると $z_{kl}$ はすべての発話で同じ数だけずれるので，$d$ は変わらず $o$ だけが変わる．全感情に共通の特徴のずれ $x\to x+\delta$ も $o$ だけを動かすので，コーパスごとに特徴の平均を引く操作は向きの損を変えない．$D^{*}$ は評価にだけ使い，線形の向きの中で最大の離れ方ではない．単一ソース設定のソースだけの分類器でこの模型の当てはまりを確かめると，模型の誤差の中央値は切片の損の中央値の 0.41〜1.27 倍で，計算の前に決めた基準（1/3 未満）を満たさなかったので，答えの偏りは模型ではなく UAR の差で測る．向きの損では 0.05〜0.13 倍で，顔（V）の 0.47 倍を除いて基準を満たした．

## 4.2 問い 1(a) の比べ方

A の群（単一ソース設定，K = 5）では，次の比べで，K 本とソースが答えの偏りと残りの誤りのどちらを直すかを確かめる．

- **(A2) − (A0)**：ソースだけの分類器に K 本を足して学んだ gain（以下，合併の gain）．
- **(A3) − (A0) と (A4) − (A0)**：切片だけの直しと平均を引く方法は，どちらも向きの損を変えない（4.1 節）．この 2 つの gain が合併の gain のどれだけにあたるかで，答えの偏りを直すだけで得られる分を測る．
- **(A5) − (A4)**：平均を引いた後に，K 本で切片を直す分がさらにあるかを測る．
- **(A1) の離れ方 $d_T(K)$ の $D^{*}$ に対する比**（K = 1，5，10）：ソースを使わずに K 本だけで学ぶと，重みの向きが $D^{*}$ の向きにどこまで近づくか（残りの誤り）を測る．

A の群の区間は，話者（MOSEI ではクラスタ）と反復の 2 段のブートストラップの百分位区間で，実効の話者数が 20 未満のターゲットでは話者の jackknife の t 区間との和集合を使う．

B の群（全ソース設定）では，(B1) と (B2)〜(B9) のそれぞれが，(B0) より 6 つの感情の対で平均した向きの損を減らすかを測る．(B1) の疑似ラベルの出所と重みの付け方は条件ごとに仮のターゲットで選び（選ばれた出所の多くは各モダリティの分類器の確率の積），どれも学び直す分類器自身のモダリティの予測を含む．(B1) は声・顔・言葉の組（3 コーパス）と声・顔の組（5 コーパス）の各分類器，K = 0，5，25 の 81 条件で，(B2)〜(B9) は単一のモダリティ，K = 0，5 の 210 条件で測るので，2 つは同じ条件の比べではない．ハイパーパラメータはソースの群を 1 つずつ仮のターゲットにして選び，区間は話者と反復の 2 段のブートストラップの百分位区間で，手法と (B0) に同じ抽出を当てて差を取る．計算の前に決めた規則で，向きの損の差（(B0) − 手法）の 95% 区間が 0 より上で点推定が δ 以上なら「減らした」，0 より下で −δ 以下なら「増やした」，区間が −δ〜+δ に入れば「同じ水準」，ほかは「判定できない」とした．δ（81 条件で 0.82〜1.11 点，210 条件で 0.89〜1.10 点）は仮のターゲットの出力だけから決めた．疑似ラベルの選択肢の一部（積など）は，同じコーパスで以前の版の手法の結果を見た後に足した．

## 4.4 問い 1(b) の比べ方

C の群（LOCO 設定）の蒸留 (C1) では，声・顔・言葉の分類器と AVT の分類器のそれぞれを学び直す．疑似ラベル $q_i$ は候補の発話ごとに 2 段で作る（補足資料の図 S3）．1 段目で，(C0) の AVT の分類器の確率を候補に付ける．2 段目で，声・顔・言葉の線形分類器をそれぞれアンカーから K 本とこの確率で学び直し，3 つの確率を発話ごとに掛け合わせて正規化する（以下，積）．$q_i$ は学び直す分類器自身のモダリティの予測も含む．学び直す線形分類器の損失は，K 本の交差エントロピーと，候補の疑似ラベルとの交差エントロピー（温度を使わずに疑似ラベルの確率をそのまま目標にする）と，アンカーへの L2 正則化の和である．

```
L(W, b) = (1/S) [ a·Σ_{i∈𝒦} −log p(y_i | x_i) + Σ_{i∈𝒰} Σ_k g_ik·(−log p(k | x_i))
                  + ‖W − W₀‖² / (2C′) + ‖b − b₀‖² / (2C_b) ]
p(· | x) = softmax(W x + b)，  g_ik = (ρn/4) · q_ik / Σ_{j∈𝒰} q_jk
```

𝒦 は K 本，𝒰 は候補の全体（n 本．K 本を含む），(W₀, b₀) はアンカー，S は損失の重みの和である．疑似ラベルの重みの合計を感情ごとに ρn/4 にそろえる．この損失の形は評価の回の前に決めた．温度つきの損失（[@hinton2015distilling]．Albanie ほか [@albanie2018] の形）など，ほかの 5 つの損失の形との比べは補足資料 S4 に示す．正則化の強さ C′，C_b は (C0) で選んだ値を使う．ρ ∈ {1/16, 1/4, 1, 4}，a ∈ {1, 4, 16} と積を作るときの各モダリティの指数（{0, 0.5, 1, 2}³ の 63 通り）は，仮のターゲットの回（3.4 節）の平均の UAR が最大の点を選び，最良との差が 2 標準誤差以内の点が複数あるときは調整しないときの値（ρ = 1，a = 1，指数 (1, 1, 1)）に最も近い点を選んだ．K = 5，10，25 の 48 条件では，選んだ値はどれも調整しないときの値と同じ分類器になったので，(C1) と (D0) の積は 3 つの確率を同じ重みで掛けたものである．選んだ値を固定してコミットした後に，評価の回を 1 回だけ計算した．著者らは，評価の回の途中（AFEW と IEMOCAP）と計算が終わった後の集計の前（4 コーパス）に，(C1) と (C2)〜(C12) の UAR と差（区間なし）を見た．集計の台本と設計は評価の回の前に固定し，見た後に変えていない．

C の群では，次の 3 つの比べを行う．

- **(C1) − (C0)**（声，顔，言葉，AVT．K = 0，5，10，25）：蒸留でどの分類器の UAR が上がるかを確かめる．
- **(C1) − (C2)〜(C12)**（K = 5，10，25）：蒸留の gain が，ほかのモダリティを含む疑似ラベルを使わずに得られるかを確かめる．11 手法は同じアンカーと K 本から学び，ハイパーパラメータを同じ手順で選んだ．エンコーダを凍結しているので，DANN と MME は線形の写像と分類器に損失の項を入れた版で，特徴抽出器も学ぶ元の手法とは同じではない．
- **(C13) の当たる幅と gain**（K = 5，25）：蒸留で UAR が上がるかどうかが，疑似ラベルの当たり具合とどう関わるかを確かめる．

(C13) は，評価の回で 4 つの学び直す分類器のそれぞれについて，積の代わりにほかの分類器の予測を疑似ラベルにして，損失のハイパーパラメータを調整しないときの値（ρ = 1，a = 1）で学び直したものである．疑似ラベルの出所は，(C0) の分類器（学び直す分類器と違うモダリティの単独の分類器，2 つのモダリティの特徴をつないだ分類器，AVT），積，積を作る 3 つの分類器，アンカーの AVT，ソースの各コーパスの分類器である．組み合わせごとに次の 2 つを測る（補足資料の図 S4）．

- **当たる幅**：疑似ラベルの出所の判定の UAR − 学び直す前の分類器 (C0) の UAR．K 本を除いた候補の発話の上で，候補の正解ラベルを使って測る．候補の正解ラベルは学び直しには使わず，この解析にだけ使う．
- **gain**：その疑似ラベルで学び直した分類器 − (C0) の，テストの発話の上の UAR の差．

K は，(C0) の候補の上の判定を保存してある 5 と 25 である．AVT を AVT 自身の予測で学び直す点と，ほかの出所と同じ予測になる点を除き，K ごとに 360 の組み合わせを数えた．除いた点のうち K = 25 の MOSEI の AVT の 1 点は，疑似ラベルの出所が (C0) と同じ予測のため当たる幅が定義から 0 になり，gain の区間の下端が 0 を超えた（+0.30 [+0.07, +0.54]）．この解析は計算の後に組んだ記述の解析で，計算の前に予測を立てていない．著者らは，声・顔・言葉の分類器を一部の出所で学び直した gain と区間を見た後にこの解析を組んだ．組み合わせどうしは同じ候補，テストの発話，疑似ラベルの材料を共有するので，以下の順位相関と数え上げは検定ではない．

### 4.5.1 (C1) − (C0)：蒸留の gain

### 4.5.3 (C13)：当たる幅と gain

例えば，MOSEI の K = 25 で声の分類器を顔と言葉をつないだ分類器の疑似ラベルで学び直すと，当たる幅は +4.6 点（42.2 対 37.6）で gain は +2.05 [+0.74, +3.35] 点だった．AFEW の K = 5 で顔の分類器を声と言葉をつないだ分類器の疑似ラベルで学び直すと，当たる幅は −16.7 点（54.4 対 71.1）で gain は −4.40 [−7.70, −1.09] 点だった．

360 の組み合わせ全体では，当たる幅の順位と gain の順位がそろった．順位相関は K = 5 で 0.80，K = 25 で 0.83 で，（コーパス，学び直す分類器，K）の 32 組の中の順位相関は 32 組すべてで正だった（中央値 0.92，最小 0.39）．図 2 は，組み合わせを当たる幅の符号と gain の区間で分けて数えた結果である．当たる幅が負の組み合わせ（K = 5 で 173，K = 25 で 184）には，gain の区間の下端が 0 を超えたものは無く，区間の上端が 0 を下回ったものが 125 と 144 あった．当たる幅が正の組み合わせ（187 と 176）では，gain の区間の下端が 0 を超えたのは 58 と 42 だった．当たる幅が正なのに gain の区間の上端が 0 を下回った組み合わせも 16 と 20 あった（MOSEI の言葉の分類器 17，MELD の顔の分類器 8 など）．この 36 のうち 28 は，出所が学び直す分類器自身のモダリティを含まなかった．

### 4.5.4 問い 1(b) の結果のまとめ

以上から，問い 1(b) への答えは次のとおりである．蒸留は声の分類器の UAR を 12 条件すべてで点推定で (C0) より高くし（IEMOCAP を除く 9 条件で区間の下端が 0 を超えた），顔・言葉・AVT の分類器の gain はコーパスによって正負が分かれた．UAR が上がった (C13) の組み合わせは，どれも疑似ラベルの UAR が学び直す前の分類器より高かった．
