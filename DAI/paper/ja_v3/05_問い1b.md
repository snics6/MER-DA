問い 1(b) は，ほかのモダリティを含む分類器の疑似ラベルで学び直す蒸留が，どの分類器の UAR をどんな場合に上げるかを問う．LOCO 設定で，声の分類器の UAR は感情ごとに 5，10，25 本のラベルの 12 条件すべてで，学び直す前の分類器（K 本の基準の分類器）より点推定で高かった．ほかのモダリティを含む疑似ラベルを使わない 11 手法の UAR は，声の分類器では K = 5，10，25 の 132 の比べすべてで蒸留より点推定で低かった．疑似ラベルの出所を替えた K = 5，25 の 360 ずつの組み合わせを計算の後に並べると，声・顔・言葉・AVT のどの分類器でも，UAR が上がった（差の 95% 区間の下端が 0 を超えた）のは，疑似ラベルの判定の UAR が学び直す前の分類器の UAR より高い場合だけだった．

## 5.1 設定

### 5.1.1 蒸留の作り方

LOCO 設定（3.4 節）で，声・顔・言葉の分類器と，3 つの特徴をつないだ分類器（AVT）のそれぞれを学び直す．疑似ラベル $q_i$ は候補の発話ごとに 2 段で作る（図 4）．1 段目で，K 本の基準の AVT の分類器の確率を候補に付ける．2 段目で，声・顔・言葉の線形分類器をそれぞれアンカーから K 本とこの確率で学び直し，3 つの確率を発話ごとに掛け合わせて正規化する（以下，積）．$q_i$ は学び直す分類器自身のモダリティの予測も含む．

![図 4　蒸留の疑似ラベルの作り方と使い方．① ターゲットの候補の発話（K 本を含む）に，② K 本の基準の AVT の分類器が 4 感情の確率を付け，③ 声・顔・言葉の分類器をアンカーから K 本とその確率で学び直し，④ 3 つの確率を掛けて正規化した積を疑似ラベルにし，⑤ 学び直す分類器を K 本と疑似ラベルで学び直してテストの UAR を比べる．テストの発話はどの段でも使わない．図の確率は説明のための例である](../figures/fig_pl_flow_ja.pdf)

学び直す線形分類器の主の損失（形 (a)）は，K 本の交差エントロピーと，候補の疑似ラベルとの交差エントロピー（温度を使わずに疑似ラベルの確率をそのまま目標にする）と，アンカーへの L2 正則化の和である．本論文の「蒸留」は，この形 (a) で積を目標にして学び直すことを指す．

```
L(W, b) = (1/S) [ a·Σ_{i∈𝒦} −log p(y_i | x_i) + Σ_{i∈𝒰} Σ_k g_ik·(−log p(k | x_i))
                  + ‖W − W₀‖² / (2C′) + ‖b − b₀‖² / (2C_b) ]
p(· | x) = softmax(W x + b)，  g_ik = (ρn/4) · q_ik / Σ_{j∈𝒰} q_jk
```

𝒦 は K 本，𝒰 は候補の全体（n 本．K 本を含む），(W₀, b₀) はアンカー，S は損失の重みの和である．疑似ラベルの重みの合計を感情ごとに ρn/4 にそろえる．主の損失は評価の回の前に形 (a) と決めた．温度つきの損失（[@hinton2015distilling]．Albanie ほか [@albanie2018] の形）など，疑似ラベルを目標にするほかの 5 つの損失の形との比べは補足資料 S4 に示す．正則化の強さ C′，C_b は K 本の基準の分類器で選んだ値を使う．ρ ∈ {1/16, 1/4, 1, 4}，a ∈ {1, 4, 16} と積を作るときの各モダリティの指数（{0, 0.5, 1, 2}³ の 63 通り）は，仮のターゲットの回（3.4 節）の平均の UAR が最大の点を選び，最良との差が 2 標準誤差以内の点が複数あるときは調整しないときの値（ρ = 1，a = 1，指数 (1, 1, 1)）に最も近い点を選んだ．選んだ値を固定してコミットした後に，評価の回を 1 回だけ計算した．著者らは，評価の回の途中（AFEW と IEMOCAP）と計算が終わった後の集計の前（4 コーパス）に，蒸留と比べる手法の UAR と差（区間なし）を見た．集計の台本と設計は評価の回の前に固定し，見た後に変えていない．

### 5.1.2 比べる手法

蒸留と，ほかのモダリティを含む分類器の疑似ラベルを使わない 11 の手法を比べる．11 手法は，同じモダリティのラベル無しの発話，ソースのラベル付きの発話，または単独のモダリティの分類器どうしの真似を使う．どの手法も同じアンカーと K 本から学び，ハイパーパラメータを同じ手順で選んだ．

- **同じモダリティのラベル無しの発話を使う**：自己学習 [@lee2013pseudolabel]，エントロピー最小化 [@grandvalet2004]，IM [@liang2020; @boudiaf2020]，T3A [@iwasawa2021]，ラベル伝播 [@zhou2004; @iscen2019]，学び直す分類器自身の K 本の基準の分類器の確率を疑似ラベルにして同じ損失で学ぶ版．
- **ソースのラベル付きの発話を使う**：ソースのラベル付きの発話と K 本を合わせて学ぶ版（S+T），CORAL [@sun2016coral]，DANN [@ganin2016dann]，MME [@saito2019mme]．
- **ほかのモダリティを互いに真似る**：xMUDA 型 [@jaritz2020xmuda]（単独のモダリティの分類器どうしで解いた版）．

エンコーダを凍結しているので，DANN と MME は線形の写像と分類器に損失の項を入れた版で，特徴抽出器も学ぶ元の手法とは同じではない．

### 5.1.3 当たる幅

蒸留で UAR が上がるかどうかが，疑似ラベルの当たり具合とどう関わるかを調べるため，疑似ラベルの出所を替えた学び直しを並べる．評価の回は，4 つの学び直す分類器のそれぞれについて，積の代わりにほかの分類器の予測を疑似ラベルにした学び直しも，損失のハイパーパラメータを調整しないときの値（ρ = 1，a = 1）で計算していた．疑似ラベルの出所は，K 本の基準の分類器（学び直す分類器と違うモダリティの単独の分類器，2 つのモダリティの特徴をつないだ分類器，AVT），積，積を作る 3 つの分類器，アンカーの AVT，ソースの各コーパスの分類器である．

各組み合わせで，次の 2 つを測る（図 5）．

- **当たる幅**：疑似ラベルの出所の判定の UAR − 学び直す前の分類器（K 本の基準の分類器）の UAR．K 本を除いた候補の発話の上で，候補の正解ラベルを使って測る．候補の正解ラベルは学び直しには使わず，この解析にだけ使う．
- **gain**：その疑似ラベルで学び直した分類器 − 学び直す前の分類器の，テストの発話の上の UAR の差．

![図 5　当たる幅と gain の測り方（説明のための例）．① 候補の発話ごとに正解（解析のときだけ使う），ⓐ 疑似ラベルの出所の判定，ⓑ 学び直す前の分類器の判定を並べ，感情ごとの再現率から UAR を求める．② 当たる幅 ＝ ⓐ の UAR − ⓑ の UAR．③ ⓐ の確率を疑似ラベルにして学び直し，テストの発話の上で gain を測る．④ 出所を替えて ② と ③ の組を並べる．8 本の発話と判定は説明のための例である](../figures/fig_margin_toy_ja.pdf)

K は，学び直す前の分類器の候補の上の判定を保存してある 5 と 25 である．AVT を AVT 自身の予測で学び直す点と，ほかの出所と同じ予測になる点を除き，K ごとに 360 の組み合わせを数えた．除いた点のうち K = 25 の MOSEI の AVT の 1 点は，疑似ラベルの出所が学び直す前の分類器と同じ予測のため当たる幅が定義から 0 になり，gain の区間の下端が 0 を超えた（+0.30 [+0.07, +0.54]）．この解析は計算の後に組んだ記述の解析で，計算の前に予測を立てていない．著者らは，声・顔・言葉の分類器を一部の出所で学び直した gain と区間を見た後にこの解析を組んだ．組み合わせどうしは同じ候補，テストの発話，疑似ラベルの材料を共有するので，以下の順位相関と数え上げは検定ではない．

## 5.2 結果

### 5.2.1 蒸留で学び直した声の分類器の UAR は，12 条件すべてで K 本の基準の分類器より点推定で高かった

表 5 は，蒸留（積の疑似ラベルによる学び直し）− K 本の基準の分類器の gain を示す．蒸留で学び直した声の分類器の UAR は，K = 5，10，25 の 12 条件すべてで K 本の基準の分類器より点推定で高く，IEMOCAP を除く 9 条件で差の区間の下端が 0 を超えた（AFEW +3.32〜+4.15，MOSEI +3.19〜+4.11，MELD +2.71〜+3.12 点）．これに対し，IEMOCAP の差は +1.45〜+2.41 点で，3 つの K とも区間が 0 を含んだ．

ラベルを使わない K = 0 でも，声の分類器の gain は 4 コーパスとも区間の下端が 0 を超えた（+2.13〜+4.86 点）．疑似ラベルだけで学び直した声の分類器（K = 0）の UAR は，K = 5 と 10 の K 本の基準の分類器の UAR より 4 コーパスすべてで点推定で高かった（AFEW 53.4 対 50.1 と 51.1，IEMOCAP 69.2 対 67.1 と 68.3，MOSEI 36.5 対 34.9 と 35.1，MELD 45.2 対 41.5 と 41.8．差の区間は作っていない）．声の分類器では，ラベル無しの発話と疑似ラベルが，感情ごとに 10 本のラベルと少なくとも同じ程度に UAR を高めたことを示唆する．

### 5.2.3 当たる幅が負の組み合わせで，UAR が上がったものは無かった

当たる幅と gain の実際の 2 例を挙げる．MOSEI の K = 25 で，声の分類器を顔と言葉をつないだ分類器の疑似ラベルで学び直すと，疑似ラベルは学び直す前の分類器より 4.6 点多く当たり（42.2 対 37.6），gain は +2.05 [+0.74, +3.35] 点だった．AFEW の K = 5 で，顔の分類器（AFEW で最も強いモダリティ）を声と言葉をつないだ分類器の疑似ラベルで学び直すと，疑似ラベルは 16.7 点当たらず（54.4 対 71.1），gain は −4.40 [−7.70, −1.09] 点だった．


360 の組み合わせ全体では，当たる幅の順位と gain の順位がそろった．順位相関は K = 5 で 0.80，K = 25 で 0.83 で，（コーパス，学び直す分類器，K）の 32 組の中の順位相関は 32 組すべてで正だった（中央値 0.92，最小 0.39）．図 8 は，組み合わせを当たる幅の符号と gain の区間で分けて数えた結果である．当たる幅が負の組み合わせ（K = 5 で 173，K = 25 で 184）には，gain の区間の下端が 0 を超えたものは無く，区間の上端が 0 を下回ったものが 125 と 144 あった．当たる幅が正の組み合わせ（187 と 176）では，gain の区間の下端が 0 を超えたのは 58 と 42 だった．ただし，当たる幅が正なのに gain の区間の上端が 0 を下回った組み合わせも 16 と 20 あった（MOSEI の言葉の分類器 17，MELD の顔の分類器 8 など）．この 36 のうち 28 は，出所が学び直す分類器自身のモダリティを含まなかった．

## 5.3 問い 1(b) への答え

蒸留は，ラベルが感情ごとに数本しか無いコーパス間の設定でも，声の分類器の UAR の点推定を 12 条件すべてで K 本の基準の分類器より高くし，IEMOCAP を除く 9 条件では差の区間の下端が 0 を超えた．これは，顔の分類器の予測で声の分類器を学べることを示した Albanie ほか [@albanie2018] の結果と同じ向きである．ほかのモダリティを含む疑似ラベルを使わない 11 手法は，声の分類器ではどれも点推定で蒸留より低かった．

UAR が上がった組み合わせは，どれも疑似ラベルの判定の UAR が学び直す前の分類器より高かった．当たる幅と gain の順位はそろい（順位相関 0.80 と 0.83），当たる幅が負の組み合わせ（173 と 184）で UAR が上がったものは無かった．一方，当たる幅が正でも UAR が上がったのは 187 のうち 58 と 176 のうち 42 だった．これらの結果は，疑似ラベルが学び直す前の分類器より当たることが，蒸留で UAR が上がるための必要な条件であることを示唆する．声の分類器で gain が出たことの 1 つの可能な説明は，声が IEMOCAP 以外のコーパスで最も強いモダリティではなく，積の疑似ラベルのほうが当たったことと，声の特徴が言葉の分類器の判定を顔の特徴より真似できたこと（補足資料 S1）である．当たる幅の解析は計算の後に組んだ記述の解析であり，D の解析は判定の規則を計算の前に固定したが gain との関係は測っていないので，どちらも gain の原因を測ったものではない．

逆に，そのコーパスで最も強いモダリティの分類器は，ほかの 2 つのモダリティの疑似ラベルで学び直すと 8 点すべてで gain の点推定が負だった．最も強いモダリティはコーパスによって違い（AFEW の顔，IEMOCAP の声，MOSEI の顔，MELD の言葉），同じ重みの積はこの違いを使わない．そこで 6 節（問い 2）では，疑似ラベルの判定の UAR を高めるために，コーパスと感情ごとに 3 つの分類器の答えの重みを変えてまとめる．
