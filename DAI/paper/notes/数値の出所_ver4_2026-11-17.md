# 数値の出所と計算の環境（ver4．内部の記録）

2026-11-17 夜に `../ja_v4/99_申告.md` から移した（研究者の承認：論文には書かず，計算の環境は公開するリポジトリの README に書く）．数値の検査役（paper-numbers）は，本文の数の出所をこの一覧で確かめる．公開するときは，計算の環境の段落を README に写す．

**計算の環境と再現の情報．** 解析には Python 3.12.3 を使い，ライブラリの版は公開するコードの `requirements.txt` で固定した（主なものは NumPy 2.5.2，pandas 3.0.6，SciPy 1.18.1，scikit-learn 1.9.1，PyTorch 2.11.0（CUDA 12.6），Transformers 4.44.0）．4.1 節と 4.3 節の評価の回の疑似ラベルの計算，学び直し，比べる手法の学習はクラウドの計算機の NVIDIA H200（PyTorch 2.8.0，CUDA 12.8）で，4.4〜4.6 節の計算と補足資料 S3 の真似できる度合いの計算は NVIDIA RTX A5000（24 GB）の 1 台で行った．4.2 節の全ソース設定の学び直しと比べる手法の計算は，クラウドの計算機の NVIDIA H100 80GB（PyTorch 2.11.0，CUDA 12.6）で行った（各結果の provenance.json の gpu と host の項目：`results/e77_*/`，`results/e78_*/`，`results/e80*/`）．5 分割は，コーパスごとにクラスタを壊さない分け方を種 0 で 1 回だけ作り，すべての実験で同じ分割を使った．K 本は，用途の名前，コーパス，分割，種（0〜9）の組から NumPy の `SeedSequence` で作った乱数で抜くので，K について入れ子になる．表と図の値を出した計算のコミットは次のとおりである．
