## 2. 数え方

- PDF の取得：Springer のサイトは curl に対して JavaScript の確認画面を返したため，WebFetch で `idp.springer.com/authorize` を経由して誌の版の PDF を取得した．PDF は `/tmp/claude-1000/-home-snics-MER-DA/1c397eb5-7560-4b25-97d9-b9ef70549ea7/scratchpad/dai_survey/pdf/` に DOI の名前で置いた．
- 頁数：`pdfinfo` の Pages の値である．参考文献と申告を含む全頁である．
- 語数：`pdftotext -layout` の文字列から数えた目安である．要旨（Abstract）から，後付け（Acknowledgements，Author contributions，Funding，Data availability，Declarations，References のうち最初に現れる見出し）の直前までを本文とした．頁の頭書きと 1 頁目の利用許諾の文は除いた．表の数値や図の中の文字を数えないように，英字 2 文字以上を含む語が 7 語以上ある行の語だけを数えた（表の「語数」の列）．すべての行の語を数えた値（表と図の中の文字を含む上限の目安）も「全行」の列に載せた．式は数えていない．1 頁目では要旨の行に所属の欄の文字が混ざるため，数十語の誤差がある．
- 図と表：本文の行頭にある「Fig. N」「Table N」の見出しの最大の番号である．
- 参考文献：References の後の「N.」で始まる番号の最大値である（1 から N までの 90% 以上がそろう最大の N を取った）．
- ESM：PDF の後付けの「Supplementary Information」の節（Springer の PDF では「The online version contains supplementary material available at ...」と書かれ，ファイル名と大きさが並ぶ）を探した．ESM を持つ 1 本は記事の頁の一覧と ESM の PDF そのものも確かめた．ESM が無い 2 本（02548-7，00955-4）は記事の頁でも確かめ，02548-7 は後付けの終わりまで ESM の節が無いことを確かめた．00955-4 は WebFetch が頁の途中までしか読めず，記事の頁では確かめきれていない（PDF には ESM の記載が無い）．
- 付録：PDF の中の「Appendix」「Appendices」の語を探した．
- コードとデータの公開：Data availability と Code availability の節の文と，参考文献を除く本文の URL（GitHub，Zenodo，figshare，Kaggle など）を読んだ．
