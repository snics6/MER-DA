# 日本語の下書き ver4（2026-11-17 夜〜）

ver3（`../ja_v3/`）を，論文の書き方の型（Mensh & Kording 2017 の 10 の規則，MIT CommLab の序論・結果・考察の式，Nature の要旨の型）に合わせて組み直した版である．ver3 はそのまま残す．英語版はまだ作っていない（ver3 の英語版は `../main_v3.tex` と `../sections/v3_*.tex`）．

## 研究者の指示（2026-11-17 夜）

- 「今の要旨は，単に実験設定と結果の説明になっていて全くダメ．数値を示すことも大事だが，それは最後の提案手法だけでいいよ．MER の問題点 → 解析，提案手法 → 結果 → 結論を示さなきゃ」
- 「もう一度 Nature や MIT の論文の書き方をみて，今の論文の良くない点を列挙して」「まずは型どおりに書こう」
- 段落ごとに 1 文の骨組み（`../notes/骨組み_型どおり_2026-11-17.md`）に「よい」．「方法 → 結果 → 提案 → 結果 にならざるを得ないかな？」への答え（提案を方法の節に入れ，結果を 1 本にする）に「よい」．
