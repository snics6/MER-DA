## 4.1 蒸留で学び直した声の分類器は，ほかのモダリティを含む疑似ラベルを使わない 11 の手法より UAR が高かった

表 3 は，蒸留で学び直した声の分類器と基準の分類器の UAR の差を示す．声の分類器の UAR は，4 コーパスと K = 5，10，25 の 12 条件すべてで基準の分類器より高く，IEMOCAP を除く 9 条件で差の区間の下端が 0 を超えた（+2.71〜+4.15 点）．IEMOCAP の差は +1.45〜+2.41 点で，3 つの K とも区間が 0 を含んだ．ほかのモダリティを含む疑似ラベルを使わない 11 の手法と比べても，蒸留の UAR は 12 条件の 132 の比べすべてで高く，区間の下端が 0 を超えなかったのは IEMOCAP の 10 の比べだけだった（図 3．K = 5 の UAR は補足資料の表 S2）．学び直す分類器自身の基準の確率を疑似ラベルにした版は，基準の分類器との差が −1.0〜+0.5 点だった．声の分類器では，ほかのモダリティを含む疑似ラベルが，それを使わない 11 の手法より UAR を高くした．

## 4.2 ほかのモダリティを含む疑似ラベルは偏りを直しても残る誤りを減らし，同じモダリティのラベル無しの発話はほとんど減らさなかった

表 4 は，全ソース設定で，蒸留と同じモダリティのラベル無しの発話を使う 8 つの手法が，基準の分類器より残る誤り（向きの損）を減らしたかを判定した数を示す．蒸留は 81 条件のうち 38 で残る誤りを減らし，増やしたのは 1 だった．蒸留の UAR は 81 条件のうち 32 で基準の分類器を上回り，下回った条件は無かった．同じモダリティのラベル無しの発話を使う 8 つの手法が残る誤りを減らしたのは 210 条件のうち 7 で，増やしたのは 79 だった．差が 0 のときに偶然に「減らした」となる条件の数の見込みは，条件を独立とみなすと 81 条件で 2.02，210 条件で 5.25 である．同じアンカーと同じ条件（2 つのモダリティの組，K = 0 と 5）で点推定を比べると，373 対のうち 341 対で蒸留のほうが残る誤りを多く減らした（対は独立でない）．全ソース設定では，偏りを直しても残る誤りを減らしたのは主にほかのモダリティを含む疑似ラベルで，同じモダリティのラベル無しの発話はこの誤りをほとんど減らさなかった．

## 4.3 疑似ラベルが学び直す前の分類器より正しいほど，学び直した分類器の UAR は高かった

疑似ラベルの出所を替えた学び直し（3.4 節）で，当たる幅と gain の関係を調べた．例えば，MOSEI の K = 25 で声の分類器を顔と言葉をつないだ分類器の疑似ラベルで学び直すと，当たる幅は +4.6 点（42.2 対 37.6）で gain は +2.05 [+0.74, +3.35] 点だった．AFEW の K = 5 で顔の分類器を声と言葉をつないだ分類器の疑似ラベルで学び直すと，当たる幅は −16.7 点（54.4 対 71.1）で gain は −4.40 [−7.70, −1.09] 点だった．

360 の組み合わせ全体では，当たる幅の順位と gain の順位がそろった．順位相関は K = 5 で 0.80，K = 25 で 0.83 で，（コーパス，学び直す分類器，K）の 32 組の中の順位相関は 32 組すべてで正だった（中央値 0.92，最小 0.39）．図 4 は，組み合わせを当たる幅の符号と gain の区間で分けて数えた結果である．当たる幅が負の組み合わせ（K = 5 で 173，K = 25 で 184）には，gain の区間の下端が 0 を超えたものは無く，区間の上端が 0 を下回ったものが 125 と 144 あった．当たる幅が正の組み合わせ（187 と 176）では，gain の区間の下端が 0 を超えたのは 58 と 42 で，区間の上端が 0 を下回ったものも 16 と 20 あった（内訳は補足資料 S2）．数えた 360 の組み合わせのうち，UAR が上がったものは，どれも疑似ラベルが学び直す前の分類器より正しかった（数えるときに除いた，当たる幅が定義から 0 の 1 点では，UAR が上がった．補足資料 S2）．

![図 4　当たる幅の符号ごとに数えた，疑似ラベルの出所を替えた学び直しの組み合わせ（K = 5 と 25，360 ずつ）．帯の色は gain の 95% 区間で分けた：下端が 0 を超えた（上がった），0 を含む，上端が 0 を下回った（下がった）．当たる幅が負の側で上がった組み合わせは 0 だった](../figures/fig_margin_counts_ja.pdf)

単独のモダリティの分類器のうち，基準の分類器の候補の上の UAR が最も高いもの（以下，そのコーパスで最も強いモダリティ）は，K = 5，25 とも AFEW の顔，IEMOCAP の声，MOSEI の顔，MELD の言葉だった．最も強いモダリティの分類器を，ほかの 2 つのモダリティの特徴をつないだ分類器の疑似ラベルで学び直すと，gain の点推定は 4 コーパスの 2 つの K の 8 つの場合すべてで負だった（−4.40〜−1.02 点）．最も強いモダリティの分類器は，ほかの 2 つのモダリティだけから作った疑似ラベルで学び直すと，UAR が学び直す前より低かった．

## 4.4 提案でまとめた予測は，同じ重みでまとめた積より 12 条件のうち 11 で UAR が高かった

表 5 は，3 つの分類器の予測のまとめ方ごとに，まとめた予測の UAR と提案との差を示す（図 5）．まとめた予測は，どの分類器も学び直さずに，テストの発話で 3 つの分類器の予測をまとめた答え（argmax）である．提案 − 積は 12 条件のうち 11 で正で，そのうち 7 条件（AFEW の 3 つの K，IEMOCAP と MOSEI の K = 25，MELD の K = 10・25）で 95% 区間が 0 を含まなかった．差が最も大きかったのは AFEW だった（+2.13〜+3.51 点）．AFEW では，積を作る顔の分類器の UAR が声と言葉の分類器より 17 点以上高く（K = 5 で顔 70.70，声 53.24，言葉 45.76），顔の分類器 1 つの UAR は K = 5・10 で積より高かった（70.70 対 69.23，71.93 対 70.88）．IEMOCAP，MOSEI，MELD の 9 条件では，提案 − 積は −0.09〜+0.83 点だった．確率の平均との差は 12 条件のうち 8 で正で，AFEW の 3 つの K と MOSEI の K = 25 で区間の下端が 0 を超え，区間の上端が 0 を下回った条件は無かった．提案は，同じ重みでまとめる積より 12 条件のうち 11 で，確率の平均より 8 で，正しい予測を作った．

## 4.5 強さの違いを外すと AFEW で，感情ごとの形を外すと MOSEI で UAR が下がった

提案から部品を 1 つずつ外した版と比べた（表 5）．MOSEI では，感情ごとの形を外した版との差の区間の下端が 3 つの K とも 0 を超えた（+0.51〜+0.73 点）．CREMA-D でも 3 つの K とも 0 を超えた（補足資料 S7）．AFEW では，強さの違いを外した版との差の区間の下端が 3 つの K とも 0 を超え（+1.74〜+3.20 点），AFEW の提案 − 積（+2.13〜+3.51 点）の大部分はこの差にあたる．評価の 50 反復で計算の後に数えると，K 本で測った強さが最も高い分類器は，0.70〜1.00 の割合の反復で，候補の全ラベルで強さが最も高い分類器（AFEW で顔，IEMOCAP で声，MELD で言葉）と一致した．ソースで測った強さが最も高い分類器は，3 コーパスとも別の分類器だった．MOSEI では 1 位と 2 位の強さの差が小さく，この割合は 0.30〜0.38 だった（コーパスと K ごとの値は補足資料 S5）．強さの違いはモダリティの強さの差が大きい AFEW で，感情ごとの形は強いモダリティが感情ごとに入れ替わる MOSEI で，提案の UAR を高くしていた．

## 4.6 提案の疑似ラベルで学び直した AVT の UAR も，積の疑似ラベルで学び直した AVT より 12 条件のうち 11 で高かった

提案の疑似ラベルで AVT の分類器を学び直した（表 5 の下の段）．その UAR は，積の疑似ラベルで学び直した AVT より 12 条件のうち 11 で高く，5 条件（AFEW の 3 つの K と MOSEI・MELD の K = 25）で区間の下端が 0 を超えた（AFEW は +1.01，+1.95，+1.21 点）．AFEW 以外の 9 条件の差は −0.05〜+0.82 点だった．基準の AVT との差は 12 条件のうち 10 で正で，7 条件で区間の下端が 0 を超えた．CREMA-D（声と顔）では，まとめた予測の提案 − 積と，提案の疑似ラベルで学び直した AV − 積の疑似ラベルで学び直した AV は +0.31〜+0.63 点で，6 つの区間はどれも 0 を含まなかった（補足資料 S7）．提案でまとめた予測のほうが正しかったことは，その疑似ラベルで学び直した分類器の UAR にも表れた．
