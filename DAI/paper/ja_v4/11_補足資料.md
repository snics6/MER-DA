# S2 解析の補足

図 S2〜S4 は，本文 3.4〜3.5 節の誤りの 2 つの部分，蒸留の疑似ラベルの作り方，当たる幅と gain の測り方を示す．表 S4 は，本文 4.1 節の 11 手法の K = 5 の UAR を示す．続く段落は，本文の手順と結果の細部と，本文から移した単一ソース設定の解析である．

**誤りの 2 つの部分の式（本文 3.5 節）．**分類器の感情 $k$ の点数を $s_k(x)=w_k^\top x+b_k$ とすると，感情 $k$ と $l$ を分ける判定は $z_{kl}=(w_k-w_l)^\top x+(b_k-b_l)$ の符号で決まる．ターゲットのテストの感情 $k$ の発話の $z_{kl}$ の平均と分散を $\hat\mu_k$，$v_k$ とし（$l$ も同じ），$\sigma=\sqrt{(v_k+v_l)/2}$ として

$$d_{kl}=\frac{\hat\mu_k-\hat\mu_l}{\sigma},\qquad o_{kl}=-\frac{\hat\mu_k+\hat\mu_l}{2\sigma}$$

と定める．$d$ は 2 つの感情の発話の判定の軸の上での離れ方，$o$ は 2 つの感情の $z_{kl}$ の平均の中点から境目（$z_{kl}=0$）までのずれを $\sigma$ で割った量である．2 つの感情の $z_{kl}$ を分散の等しい正規分布とみなすと，対の正解率は $A(d,o)=\tfrac12[\Phi(d/2-o)+\Phi(d/2+o)]$ で，ターゲットのラベル付きの発話の線形判別分析（共分散は Ledoit–Wolf の縮小推定 [@ledoit2004]）の向きでの離れ方を $D^{*}$ とすると，対の損は

$$A(D^{*},0)-A(d,o)=\underbrace{[A(D^{*},0)-A(d,0)]}_{\text{向きの損}}+\underbrace{[A(d,0)-A(d,o)]}_{\text{切片の損}}$$

に分かれる．切片だけを変えると $z_{kl}$ はすべての発話で同じ数だけずれるので，$d$ は変わらず $o$ だけが変わる．全感情に共通の特徴のずれ $x\to x+\delta$ も $o$ だけを動かすので，コーパスごとに特徴の平均を引く操作は向きの損を変えない．$D^{*}$ は評価にだけ使い，線形の向きの中で最大の離れ方ではない．

**単一ソース設定の解析：ソース 1 つと K 本が直したのは主に予測の偏りだった．**単一ソース設定では，表 1 の 7 群の順序つきの組（ターゲット，ソース）ごとに，ソースの 1 群の全発話とターゲットの K 本（K = 5）をまとめて学ぶ（合併の分類器）．ソースだけで学ぶ分類器と，ターゲットの K 本だけで学ぶ分類器（K = 1，5，10）も作る．テストはターゲットの話者を 5 つの組に分けたうちの 1 組で，反復 0〜9 で組の分け方とテストにする組を替える．重み $W$ に L2 正則化をかけ（強さの逆数を C とする），切片には正則化をかけない．C ∈ {0.01, 0.1, 1, 10} を話者で分けた 3 分割の交差検証で選び，合併の分類器は同じ反復のソースだけの分類器の C を使う．声は WavLM-large に加えて HuBERT-large [@hsu2021] の最終層でも同じ手順で特徴を作った（声（HuBERT））．AFEW の言葉の特徴はこの設定の計算の後に作ったので，この設定では使っていない．次の比べを行った（記号は表 S9）．

- 合併の gain（(A2) − (A0)）：ソースだけの分類器に K 本を足して学んだ gain．
- 切片だけの直し（(A3) − (A0)）と平均を引く方法（(A4) − (A0)）：どちらも向きの損を変えない（上の式）．この 2 つの gain が合併の gain のどれだけにあたるかで，予測の偏りを直すだけで得られる分を測る．
- 平均を引いた後に K 本で切片を直す分（(A5) − (A4)）．
- ターゲットだけの分類器 (A1) の離れ方 $d_T(K)$ の $D^{*}$ に対する比（K = 1，5，10）：ソースを使わずに K 本だけで学ぶと，重みの向きが $D^{*}$ の向きにどこまで近づくかを測る．

**誤りの分け方の模型の当てはまり（本文 3.5 節）．**単一ソース設定のソースだけの分類器で模型の当てはまりを確かめると，模型の誤差の中央値は切片の損の中央値の 0.41〜1.27 倍で，計算の前に決めた基準（1/3 未満）を満たさなかった．このため，予測の偏りは模型ではなく UAR の差で測る（上の単一ソース設定の解析）．向きの損では 0.05〜0.13 倍で，顔（V）の 0.47 倍を除いて基準を満たした．

**単一ソース設定と全ソース設定の区間と判定の規則（本文 3.5 節）．**単一ソース設定の区間は，話者（MOSEI ではクラスタ）と反復の 2 段のブートストラップの百分位区間で，実効の話者数が 20 未満のターゲットでは話者の jackknife の t 区間との和集合を使った．全ソース設定のハイパーパラメータはソースの群を 1 つずつ仮のターゲットにして選び，区間は話者と反復の 2 段のブートストラップの百分位区間で，手法と基準の分類器に同じ抽出を当てて差を取った．計算の前に決めた規則で，向きの損の差（基準 − 手法）の 95% 区間が 0 より上で点推定が δ 以上なら「減らした」，0 より下で −δ 以下なら「増やした」，区間が −δ〜+δ に入れば「同じ水準」，ほかは「判定できない」とした．δ（81 条件で 0.82〜1.11 点，210 条件で 0.89〜1.10 点）は仮のターゲットの出力だけから決めた．

**疑似ラベルの出所を替えた学び直しで除いた組み合わせと例外（本文 3.4 節と 4.3 節）．**AVT を AVT 自身の予測で学び直す点と，ほかの出所と同じ予測になる点は，360 の組み合わせから除いた．除いた点のうち K = 25 の MOSEI の AVT の 1 点は，疑似ラベルの出所が基準の分類器と同じ予測のため当たる幅が定義から 0 になり，gain の区間の下端が 0 を超えた（+0.30 [+0.07, +0.54]）．当たる幅が正なのに gain の区間の上端が 0 を下回った 36 の組み合わせ（K = 5 で 16，K = 25 で 20）のうち，17 は MOSEI の言葉の分類器，8 は MELD の顔の分類器で，28 は出所が学び直す分類器自身のモダリティを含まなかった．

**ラベル無しで学び直した声の分類器（本文 4.1 節）．**疑似ラベルだけで学び直した声の分類器（K = 0）と，K = 5 と 10 の基準の分類器の UAR は，AFEW で 53.4，50.1，51.1，IEMOCAP で 69.2，67.1，68.3，MOSEI で 36.5，34.9，35.1，MELD で 45.2，41.5，41.8 だった（差の区間は作っていない）．

# S3 声の特徴は言葉の分類器の判定を予測できるか

本文 4.1 節で声の分類器の gain が出たことの理由の候補の 1 つとして（本文 5 節），声の特徴が，積に含まれる言葉の分類器の判定を予測できるかを調べた．

## S3.1 設定

声の分類器の gain が正だった理由の 1 つとして，音声には声の調子と話す言葉の両方が入っているという説明を調べる．積の疑似ラベルには言葉の分類器の答えが入っているので，声の特徴から言葉の分類器の答えを真似できるなら，声の分類器はその分を疑似ラベルから学べる．真似できる度合いを次の手順で測る（図 S5）．

1. あるモダリティの基準の分類器の判定 J（例：言葉の分類器の判定）を目標にする．
2. 別のモダリティの特徴（例：声の特徴）の上の線形分類器で J を当てる．J を正解とみなした UAR を R とする．当てる分類器は別の発話で学んで予測する．
3. 本当の感情と話者のクラスタ（IEMOCAP と AFEW では性別も）の層の中で J を入れ替えた目標で同じことをし，その UAR を R′ とする．
4. D ＝ R − R′ を，感情と話者で説明できる一致を除いた，真似できる度合いとする．

![図 S5　真似できる度合い D の測り方（説明のための例）．言葉の分類器の答え J を声の特徴だけで当てた一致を R，J を同じ感情・同じ話者のまとまりの中で入れ替えた J′ を当てた一致を R′ とし，D ＝ R − R′ を求める．例では一致の割合で数えたが，実験では J を正解とみなした UAR で数える．発話と答えは説明のための例である](../figures/fig_D_toy_ja.pdf)

判定の規則は計算の前に K = 5 で固定し，言葉が音声の書き起こしである AFEW は声と言葉の比べから外した．さらに，IEMOCAP（即興の部），MOSEI，MELD の音声を逆再生して WavLM-large の最後の層の特徴を作り直し，同じ D を測った（予言と数えの規則は計算の前に固定し，問いは逆再生しない D の結果を見た後に立てた）．逆再生した音声では，Whisper large-v3 の書き起こしの語の一致率が偶然の水準を超えた分は 0.005〜0.012 だった（元の音声では 0.79〜0.80）．

## S3.2 結果：声の特徴は，言葉の分類器の判定を顔の特徴より真似できた

AFEW を除く 3 コーパスで，言葉の分類器の判定を真似できる度合い D は，声の特徴が IEMOCAP 19.3，MOSEI 10.5，MELD 17.7 点で，顔の特徴（2.0，0.3，3.8 点）より大きかった（差は +17.3，+10.2，+13.9 点で，どれも区間が 0 を上回った）．顔の分類器の判定を声の特徴が言葉の特徴よりよく真似できるかは，K = 5 では計算の前に決めた規則を満たさなかった．D には，覚醒度，話者の属性，発話の長さ，録音の場面による一致も含まれうる．

音声を逆再生して言葉を聞き取れなくすると，言葉の分類器の判定を真似できる度合い D は，19.3，10.5，17.7 点から 10.5，3.1，10.5 点に下がり，差は 3 コーパスとも区間の下端が 0 を超えた（IEMOCAP 8.8 [3.0, 14.7]，MOSEI 7.5 [6.3, 8.6]，MELD 7.2 [4.7, 9.8]）（図 S6）．逆再生した声の D は，それでも顔の特徴の D より大きかった（差は IEMOCAP 8.5 [3.8, 13.1]，MOSEI 2.7 [1.3, 4.1]，MELD 6.7 [3.8, 9.6] 点）．声が言葉の分類器の判定を真似できる分は，聞き取れる言葉だけでは説明できなかった．残る分の候補には，平均のスペクトル，基本周波数の分布，発話の長さ，同じ感情のラベルの中の強さの違い，WavLM の特徴に残りうる言葉の情報があり，この実験ではどれかに帰せない．

## S3.3 限界

**言葉を聞き取りにくくする操作．** S3.2 節の逆再生は，Whisper large-v3 の書き起こしで言葉を聞き取れなくしたことを確かめたが，人の聞き手では確かめていない．逆再生は時間の向きのある手がかりも反転し，WavLM の学習で見ていない種類の音声を作る．このため，逆再生で下がった D の分を，聞き取れる言葉の情報だけに帰さない．逆再生とは別の操作で言葉を聞き取りにくくした音声で同じ D を測ることが次に試すことである．

# S4 蒸留の損失の補足

本文の蒸留は，温度を使わない形 (a) の損失で積を目標にして学び直す（本文 3.4 節）．損失のハイパーパラメータ ρ ∈ {1/16, 1/4, 1, 4}，a ∈ {1, 4, 16} と積を作るときの各モダリティの指数（{0, 0.5, 1, 2}³ のうちすべて 0 を除く 63 通り）は，仮のターゲットの回（本文 3.7 節）の平均の UAR が最大の点を選び，最良との差が 2 標準誤差以内の点が複数あるときは調整しないときの値（ρ = 1，a = 1，指数 (1, 1, 1)）に最も近い点を選んだ．主の損失は評価の回の前に形 (a) と決めた．比べのために，疑似ラベルを目標にするほかの 5 つの損失の形も同じ手順で学び，評価のターゲット，分類器，K の組ごとに仮のターゲットで UAR が最も高い形を形 (a) と比べた．5 つは，温度つきの損失（形 (b)．[@hinton2015distilling]．τ = 2 は Albanie ほか [@albanie2018] の値），一致した発話だけの疑似ラベル [@shi2024audioguided]，自分の予測と混ぜる方法 [@zhang2021combining]，柔らかい共訓練（[@blum1998] の考えを著者らが変形したもの），共正則化 [@sindhwani2005coreg] である．どれも原論文の損失の形を疑似ラベルを受け取るように移した版で，原論文と同じ手法ではない．

損失の形を替えても，声の分類器の UAR の差は 1 点未満だった（主の損失を仮のターゲットで選ばれた温度つきの形 (b) に替えた，声の K = 0，5，10，25 の 16 条件で −0.79〜+0.87 点）．また，仮のターゲットで選んだハイパーパラメータは，声の 16 条件すべてで調整しないときの値と同じ分類器になった．声の gain は，損失の形とハイパーパラメータの選び方から生じたものではないことを示唆する．
