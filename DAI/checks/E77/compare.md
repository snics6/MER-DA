### 4. 質問への答えの要約

1. 残る手法の間では，同じ仮のターゲット（台本では即興の写し）・同じ K 本・同じ選び方が渡されており，提案だけが受け取る情報は増えていない．共正則化のオラクルは UAR の比べでは相手に有利な側だけに働く．向きの損の比べと，AVT の IEMOCAP 即興の仮のターゲットの行の扱いは，指摘 2 の規則を書くまで有利とは言えない．Co-teaching を外しても，蒸留の標準の相手（KD・GD）は残る．ただし判定する同じ情報の相手は KD だけになり，DKD・DIST を回さない理由と，生徒の損失で選ぶ選び方を比べていないことを書く必要がある（指摘 3）

3. 比べはターゲットの中で行うので，GPU が問題になるのは AVT の世界の IEMOCAP 即興（E77 が A5000，E78 が H100）と，同じ世界の台本（E77 の選択が A5000 の写し，評価が H100）だけである．照合は，本番の引数で反復 0 と仮のターゲットの反復 0 を計算し，全行の予測の一致と対数の確率の差（1e−5 以下）を，結果を見る前に決めた基準で確かめれば足りる．外れたら即興の E77 を H100 で計算し直す（指摘 1）．E78 は全部 H100 で回すので GPU をまたがない．ただし E78 は TF32 と Adam を使い，同じ設定の値が束の組み方で種の違いと同じほど変わる（`checks/E78/code.md` の I5-2）ので，E78 の値は H100 と同じ `--ks`・`--methods` の束の組み方でだけ再現できることを再現の手順に書く
