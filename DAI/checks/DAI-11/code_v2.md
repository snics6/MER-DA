## 指摘

### [設計との食い違い] 検査の途中で書き換わった設計が求める `pool_projbal_t` と部分集合の名前が，台本に無い
- 重さ：直してから進む
- 該当箇所：設計 `DAI/docs/実験11_下調べ_設計.md:80`，`:111`（終わりの時点の版 1f51e44f…）．台本 `DAI/exp/dai11_probe.py:491-497`，`:744`，`:754-758`
- 問題：設計 80 行は「出所の総量でそろえた射影の判定 `pool_projbal_t` も保存し，(i)(ii) はこちらでも出す」と書く．台本は `pool_projbal`（射影自身の総量でそろえた判定）だけを保存し，D8 の (i)(ii) も `pool_projbal` でだけ数える．設計 111 行は切り分けの主の版を `AVT_students_excl_other` と呼ぶ．台本の部分集合の名前は `AVT_excl_other_excl` である．さらに設計 80 行は，(i) と (ii) の両方を満たすときに限って「射影の側へ動いた」と書くと定める．台本の `rank_corr.csv` は (i) と (ii) の割合を別々に出すだけで，両方を満たすセルの割合を出さない．ただし両方の割合は `req_cells.csv` の列から CPU で数えられる．
- 計算の後で直せるか：
  - 名前と (i)(ii) の両方の割合：集計の段だけで直せる．
  - `pool_projbal_t`：射影の確率を保存していないので，そのままでは直せない．リッジ回帰を作り直せば出せる（分類器の学び直しは要らない）．
- 求める対応：
  - 段 B の 491〜497 行で，出所の確率 `P` の感情ごとの総量 `P.sum(0)` を使って射影の確率をそろえた判定を `pool_projbal_t_K{K}_{m}_{t_}` として保存する．そろえ方は，設計の「出所の総量でそろえた」の式を 1 つに決めて台本の注に書く．
  - 一致率（`d8_agree_*_projbal_t`）と D8 の (i)(ii) をこの判定でも出す．
  - 部分集合の名前を設計に合わせる．
  - `rank_corr.csv` に，(i) と (ii) の両方を満たすセルの割合の行を足す．

### [I14] `fuse1` と `ret` の W の照合の許し 1e-2 が，別の K の解の差より大きく，取り違えを見つけられない
- 重さ：直してから進む
- 該当箇所：`DAI/exp/dai11_probe.py:61`（`W_TOL = 1e-2`），`:469-473`
- 問題：
  - DAI-1 の `ret` の W は，要素の絶対値の中央値が 0.006〜0.013，最大が 0.036〜0.077 である．
  - 同じ単位の K=5 と K=10 の `ret` の W の差の最大は，IEMOCAP_AFEW_f0_r0 の音声で 0.0057，言葉で 0.0072 で，どちらも許しの 1e-2 より小さい．つまり K の取り違えや引き戻しの取り違えがあっても，この照合は通る．
  - 実際に観測した差の最大は 7.7e-6（MOSEI）と 3.7e-9（AFEW）である（`code_run_v3/runA`，`runB` の `mismatch`）．

- 求める対応：`W_TOL` を 1e-4 にする（観測の最大の約 13 倍で，別の K の解の差の最小 0.0057 の約 60 分の 1）．
