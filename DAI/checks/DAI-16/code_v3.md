## 目録に無い種類の不備

- **割合をそろえる層と，切片だけを変える対照の組み合わせ**：切片の後処理（割合をそろえる，K 本で切片を決める）をすべての版に掛ける設計では，「切片だけを変えた版」はその後処理で基準に戻り，対照として働かない．`docs/methods.md` 9.3 節の I（または D）に，「すべての版に掛ける後処理があるとき，各対照の版がその後処理の後に基準と同じにならないかを，人工の数で確かめる」を足す案を出す．
- **入れ子の交差の中の後処理**：入れ子の交差で「量」を抜いた組から決めても，同じ回の後処理（割合をそろえる切片など）を全部のラベルで学んだ分類器の出力から決めると，抜いた組のラベルが戻る．9.3 節の I2 に，「交差の推定では，ラベルを使わない後処理の入力も，抜いた組を学習に含まない分類器の出力にする」を足す案を出す．
