## 指摘

### [D1・D3・D8] L2 の帰無の値は 0 でなく，D の一律の縮みの下では D(A ← T) − D(A ← V) に比例する
- 重さ：止める
- 該当箇所：`docs/設計/実験23_設計.md:37`（L2 の定義），`:52`（E2），`:60`（E1・E2 が当たったときの文），`:77`（D(A ← V) の 2 点の行），`docs/seen-data.md:261`（設計の前に 3×3 の R と D の表を見た）
- 問題：L2 は「L2 = [D(A ← T) − D(L ← T)] − [D(A ← V) − D(L ← V)]」と絶対の差で定義されている．設計 60 行の文「その減り方は顔の分類器の判断の再現の減り方より大きかった……言葉の中身から来たことを示唆する」は，言葉以外の手がかりの消失が J_T と J_V の D を**同じ点数だけ**減らすという帰無を暗に置いている．しかし，低域通過で WavLM の特徴の質が全体に下がり，どの判断の D も同じ割合 c で縮む場合（D(L ← m) = c·D(A ← m)）には，L2 = (1 − c)·[D(A ← T) − D(A ← V)] になる．このとき L2 の符号は D(A ← T) と D(A ← V) の大小だけで決まり，言葉の中身は関わらない．この 2 つの値は実験 14 の保存で決まっていて，この実験では変わらない（A と V の予測は実験 14 の保存を使う．設計 29 行）．台帳 261 行によれば，設計者は 3×3 の D の表を見た後でこの定義を選んでいる．
  - 床：D(L ← V) の期待値は 0 より下がらない（作りの上で期待値 0 の揺れ．実験 14 の設計 44 行）．このため L2 の引く項 D(A ← V) − D(L ← V) の大きさは，揺れを除けば D(A ← V) で抑えられる．L が感情と話者の単位の外の情報をほぼ全部失う極端な場合（D(L ← ·) ≈ 0）は，L2 ≈ D(A ← T) − D(A ← V) になり，E1 が当たれば E2 もほぼ自動的に当たる．
  - 6 節の 2 つの行はこの問題を解かない．「R(L ← y) − 25 と R(A ← y) − 25 の比が 0.5 未満」（74 行）は情報が大きく失われた場合だけを拾い，比が 0.6 でも一律の縮みは L2 を正にする．「D(A ← V) が 2 点未満なら L2 を L1 と並べて書き，L2 だけを根拠にしない」（77 行）は書き方の注意で，E2 の数え（52 行）は変えない．2 点という値は D(A ← V) の点推定を見た後に決めたので，この行がどのコーパスで立つかは計算の前に分かっている．
- 計算の後で直せるか：直せない．比の版は保存した予測から後で計算できるが，E2 の判定の規則と書き方の表は計算の前に固定したことが実験の売り（設計 8 行「予言を計算の前に固定した探索」）であり，結果を見てから規則を差し替えると探索の後付けになる．
- 求める対応：
  1. 帰無を 2 つ（同じ点数だけ減る，同じ割合だけ減る）書き，E2 は両方の下で上回るときだけ数える．割合の版の量の例：L2r = D(L ← V)/D(A ← V) − D(L ← T)/D(A ← T)（残った割合の差．正なら言葉の判断のほうが割合で多く減った）．`dai14.combo_stats` は線形の組み合わせしか扱わないので，塊の jackknife と引き直しを比の値に当てる関数を `exp/dai23.py` に足すか，実験 14 の点推定から固定した重み w_T = 1/D̂(A ← T)，w_V = 1/D̂(A ← V) で L2w = w_V·D(L ← V) − w_T·D(L ← T) を線形の量として作る（この場合は分母の推定の誤差が区間に入らないことを限界に書く）．
  2. E2 を数える前提に，D(A ← V) に減る余地があることを区間で求める．例：実験 14 の P3b（D(A ← V)．R1・#shufcl・K = 5・分け方の揺れを足した区間）が「上回る」のコーパスだけで E2 を数え，それ以外は「対照に減る余地が無いので判定できない」と書く．2 点の点推定の基準は使わない．
  3. 設計者は D(A ← T) と D(A ← V) の値を見ているので，各コーパスで同じ割合の帰無の下の L2 の符号の見込み（D(A ← T) − D(A ← V) の符号）と，2 の前提がどのコーパスで満たされるかを設計の文書に書いてから計算する．

### [D1] 操作の確かめの WER の平均は，Whisper が作る余分な単語で上がり，「言葉を聞き取れない」を一意に測らない
- 重さ：直してから進む
- 該当箇所：`docs/設計/実験23_設計.md:22`，`features/check_lowpass_asr.py:48-66`（`norm_words`，`edit_distance`，`pick`），`:93`（`wer=edit_distance(r, hw) / len(r)`），`:100-107`（平均での規則）
- 問題：WER は「（置換 + 削除 + 挿入）÷ 参照の単語数」で，挿入があれば 1 を超え，上限が無い．聞き取れない音や雑音に近い音に対して Whisper が無い文を作ると，挿入で発話の WER が 2 や 3 になる．すると 100 本の平均が 0.80 以上でも，参照の単語の半分を正しく書き起こしている場合がありうる．「3 コーパスのすべてで WER の平均が 0.80 以上」という規則は，言葉が残っているかではなく，挿入の多さにも反応する．`asr_check_summary.csv` は中央値も残すが，規則は平均だけを見る．ほかに次の 3 点が定義に入っていない．
  - 標本の範囲：`pick` は `common.load_manifest(corpus)` の全発話から選ぶ．IEMOCAP では本番に使わない台本の発話も入る（LOCO 設定は即興だけ．設計 21 行）．
  - 30 秒の窓：`WhisperProcessor` は入力を 30 秒で切るので，30 秒を超える発話（MOSEI に多い）は後ろの参照の単語が元の音声でも削除として数えられる（推測．HF の Whisper の既定の動作から．台本は長い発話を分けていない）．元の音声の WER と低域の WER の両方を上げる．
  - 0.80 の根拠：設計にも出典（`Lolli ほか 2015`）にも，この値の根拠は無い（下の D4 の指摘を参照）．
- 計算の後で直せるか：直せる（`asr_check.csv` は書き起こし `hyp` を残すので，挿入を除いた量は後から出せる）．ただし fc の選び方の規則は書き起こしの前に固定しておく必要がある．
- 求める対応：規則の量を，参照の単語のうち正しく書き起こされた割合（ヒット率 H/N．N は参照の単語数，H は編集距離の整列で一致した単語の数）にする．例：「3 コーパスのすべてで H/N の平均が 0.20 以下になる最も高い fc」．WER は上限を 1 で切った版と切らない版を並べ，挿入の数と，書き起こしが空の発話の割合も出す．標本は IEMOCAP では即興の発話に限る（または両方を出し，規則は即興で当てる）．30 秒を超える発話は標本から外すか，本数を書く．

### [D4] 出典の主張は 500 Hz・48 dB/oct の濾波についてのもので，候補の 400 Hz と 300 Hz では基本周波数そのものが削られうる
- 重さ：直してから進む
- 該当箇所：`docs/設計/実験23_設計.md:10`，`:19`，`:22`，`:63`（L3 の書き方），`:93`
- 問題：設計 10 行の出典（Frontiers in Psychology 2015，10.3389/fpsyg.2015.01340．Lolli ほか「Sound frequency affects speech emotion perception: results from congenital amusia」）を原文で確かめた．原文は「500 Hz より上を減衰させ，聞き取りやすさを損ないつつ基本周波数を保つ」と書き，濾波は Logic X の Channel EQ（Q = 0.75，傾き 48 dB/oct）である．聞き取りやすさはこの研究では測っておらず，Knoll ほか 2009 と Guellaï ほか 2014 の引用で支えている．この出典が「韻律が残る」と言える範囲は 500 Hz・48 dB/oct までである．
  - 設計の濾波は `sosfiltfilt` で前後 2 回かけるので，振幅は 8 次の Butterworth の 2 乗になる．`scipy` で計算すると，どの fc でも fc で −6.0 dB，1.25·fc で −31 dB，1.5·fc で −57 dB，2·fc で −97 dB である（傾きは約 96 dB/oct．出典の 2 倍）．
  - 候補の 300 Hz では，375 Hz の成分が 31 dB，450 Hz の成分が 57 dB 減る．女性の話者の喜びや怒りの発話では基本周波数が 300 Hz を超える区間がある（感情の音声の研究で，喜びと怒りは基本周波数の平均と幅を上げ，女性は男性より高いと報告されている．例：Zhou ほか 2021，arXiv 2105.14762）．この区間では基本周波数も消えるので，L は韻律の一部も失う．失い方は性別と感情（覚醒度）に依るので，R(L ← y) と D(L ← ·) の減り方に性別と感情の偏りが入る．#shufcl の層は MOSEI では性別を含まない（実験 14 の設計 41 行）．
  - このため，fc が 300 Hz か 400 Hz に決まったときの L3 の書き方（63 行「声の調子など低域に残る手がかり」）と，9 節の限界（93 行．低域通過が消すのは高い周波数の声の手がかりとしている）は，基本周波数そのものの消失を含まない．
- 計算の後で直せるか：直せる（元の音声の基本周波数は後から測れる）．ただし基準は計算の前に固定する必要がある（D8）．
- 求める対応：6 節に「低域通過の後も基本周波数が残る」の行を足す．測るもの：操作の確かめの標本（ラベルを見ない）の元の音声で，有声の区間のうち基本周波数が 0.8·fc（濾波の減衰が 0.2 dB 以内の上限）を超える区間の割合をコーパスごと（IEMOCAP は話者の性別ごとにも）に出す．基準の例：割合が 0.10 を超えるコーパスでは「この fc では基本周波数の一部も消えた」と結果の文と限界に書き，L3 の文の「声の調子が低域に残る」を使わない．設計 10 行の出典の記述を，原文で確かめた内容（500 Hz，48 dB/oct，聞き取りやすさは測っていない）に直し，設計の濾波の減衰（fc で −6 dB，約 96 dB/oct）を 2 節に書く．

### [D8] 仮定の表に，L2 を言葉の中身に結びつける仮定と，特徴の作り方が元の声の特徴を再現する仮定の行が無い
- 重さ：直してから進む

  3. WavLM の特徴に言葉の手がかりが残っていない．Whisper の書き起こしの誤りは聞き取りの代わりの量で，WavLM の特徴に音素の手がかりが残るかは測らない（設計 94 行の限界）．表には「測らない」の行として置く．
