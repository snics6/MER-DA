## 指摘

### [S3] κ を固定した M3 の区間は κ の推定の揺れを入れず，A と X の D の揺れが点数でそろうと標準誤差を小さく出す
- 重さ：直してから進む（単位の段は流してよい．summary の段の区間の作りを，計算の前に設計で決め直す）
- 該当箇所：`docs/設計/実験23_設計.md:46`，`:53`（「κ_T は固定の係数として扱い，κ_T の推定の揺れは区間に入れない（A の項の揺れは係数つきで入る）」），`:114`，`exp/dai23.py:78`，`:317`，`:326`
- 問題：κ_T は実験 14 の D(A ← T) ÷ D(A ← V) で，この実験の A の項は同じ予測である．このため候補の全体では A の項 a = D(A ← T) − κ_T D(A ← V) の点推定は 0 になる（実験 14 の保存で計算し直すと IEMOCAP 0.003，MOSEI 0.001，MELD −0.001．κ を小数 3 桁に丸めたための残り）．設計 47 行のとおり，M3 の点推定は −D(X ← T) + κ̂ D(X ← V) で，κ̂ はデータから推定した比である．この推定量の揺れを 1 次で展開すると，X の項の揺れ x と A の項の揺れ a を使って x + c_V·a になる（c_V = D(X ← V) ÷ D(A ← V)，顔の判断の D が残った割合）．台本は κ を定数として x + a の分散を区間に入れる．2 つの差は (1 − c_V)[(1 + c_V)Var(a) + 2Cov(a, x)] で，Cov(a, x) が −(1 + c_V)Var(a)/2 より小さいと台本の標準誤差が真の値より小さくなる．
  この条件は，帰無（D(X ← m) = c·D(A ← m)）のもとで A と X の D の揺れが割合ではなく点数でそろうときに成り立つ．A と X は同じ目標，同じ候補，同じ 2 組と別の分け方の上で測るので，塊を 1 つ除いたときや分け方を替えたときの変化が A と X で同じ点数になることはありうる．極端な場合（X の揺れが A の揺れと同じ点数）は，x = −a になり台本の標準誤差の A と X の部分は 0 になるが，真の揺れは (1 − c)·a で，標準誤差は (1 − c)·SE(a) である．実験 14 の保存から計算し直した SE(a) は次のとおりで（`combo_stats` に分け方の揺れを足した値），c = 0.5 なら台本が落としうる標準誤差は IEMOCAP 2.5，MOSEI 1.3，MELD 0.9，MELD の共有を除いた版 1.4 点になる．4 節の見込みで M3 の下端が 0 を超えるのに要る大きさ（22.7，7.0，6.4，8.6 点）は，A と X の項が相関しない仮定の値で，この条件のもとでは台本の区間はこれより狭く出る．

  | コーパス | a = D(A ← T) − κ D(A ← V) の点推定 | SE(a) | そのうち分け方の揺れの分散 | D(A ← T) − D(A ← V) の SE |
  |---|---|---|---|---|
  | IEMOCAP | 0.003 | 4.92 | 18.9 | 1.90 |
  | MOSEI | 0.001 | 2.54 | 4.95 | 0.64 |
  | MELD | −0.001 | 1.90 | 3.18 | 1.20 |
  | MELD（共有を除く） | −1.614 | 2.90 | 7.58 | 1.97 |

  M2 は推定した係数を持たないので，この問題は無い．
- 計算の後で直せるか：直せる（保存した予測から summary の段を流し直せば出る）．ただし主の判定の区間を結果の後に選ぶことになるので，計算の前に決める必要がある．
- 求める対応：
  1. M3 の区間を，κ の推定を 1 次で入れた形でも作る．同じ点推定に対し，A の項の係数を (ĉ_V, −κ_T ĉ_V)，X の項の係数を (−1, κ_T) にした組み合わせを `combo_stats` に渡せば標準誤差が出る（ĉ_V = D̂(X ← V) ÷ D̂(A ← V)．分母は 6 節の前提のとおり 3 コーパスとも区間が 0 を上回る）．
  2. 主の判定は「M3 の点推定と，標準誤差を max(SE_固定, SE_1 次) にした区間」で行う，と 4 節と 5 節に書く．`main.csv` に 2 つの標準誤差と ĉ_V を残す．
  3. 試しの段に，L に元の声の特徴に雑音を足した特徴（言葉の中身は残し，質を一律に下げる）を入れた合成の対照を足し，M2 が正，M3 が 0 の近くに出ること，SE_固定 と SE_1 次 の比を確かめる（前回の求める対応 4．今の `selftest` の (3) は式の算術だけで，`combo_stats` を通していない）．

### [S8] 操作の確かめの一致率 H/N は，Whisper が無関係な長い文を作るだけで 0.13〜0.31 になり，規則の 0.20 と同じ水準にある
- 重さ：直してから進む（`features/check_lowpass_asr.py` を流す前に規則を直す．流した後に直すと fc を選び直すことになり，本番の特徴を作り直す）
- 該当箇所：`docs/設計/実験23_設計.md:30-31`，`:85`，`features/check_lowpass_asr.py:136`（`max_new_tokens=200`），`:176`（`hit=lcs(r, hw) / len(r)`），`:186-187`
- 問題：設計 30 行は「Whisper が無い文を作って足した単語は，参照の単語と順に一致しない限り H を増やさない」と書く．最長共通部分列は，参照の単語の順を保つ部分列を出力のどこからでも拾うので，出力が長いほど，"you"・"the"・"I" などのよく出る語で H が増える．検査役は，台本の `pick` と同じ条件（3 モダリティがそろう発話，3 語以上，sha256 の順に 100 本．30 秒の条件は波形が要るので省いた）で選んだ人の書き起こしを，同じコーパスの別の発話の人の書き起こしと組んで H/N を計算した（台本の `norm_words` と `lcs` を使った）．

  | コーパス | 参照の単語数の中央値 | 別の 1 本と組んだ H/N | 別の 3 本をつないだ文と組んだ H/N | 別の 10 本をつないだ文と組んだ H/N |
  |---|---|---|---|---|
  | IEMOCAP | 10 | 0.077 | 0.176 | 0.313 |
  | MOSEI | 17 | 0.073 | 0.168 | 0.298 |
  | MELD | 9.5 | 0.065 | 0.133 | 0.306 |

  言葉を聞き取れない音声に Whisper が 30〜100 語程度の無関係な文を作ると，言葉の中身が残っていなくても H/N の平均が 0.20 を超えうる．このとき規則（`:185-189`）は低い fc を選ぶか，どの fc も満たさず `rule_met` を false にして，結果の文と限界に「Whisper では言葉の中身を十分に消せなかった」と書くことになる（31 行）．逆再生 B の仮定の行（85 行）も同じ量で判定するので，同じ向きに誤る．低い fc を選ぶと fc より上の声の手がかりも多く消し，M1 の一般の劣化の分が増える．
- 計算の後で直せるか：直せない（fc は操作の確かめの出力で決まり，本番の特徴を作る前に固定される）．今は流す前なので，台本と設計を直せば足りる．
- 求める対応：
  1. 同じコーパス・同じ条件の中で，各参照を別の発話の Whisper の出力と組み替えた H/N（偶然の水準．組み替えは sha256 の順で 1 つずらすなど，計算の前に決める）を `asr_check_summary.csv` に足す．
  2. 規則の量を「H/N の平均 − 偶然の水準の平均」にし，閾値を計算の前に決める（例：0.15 以下）．逆再生の仮定の行も同じ量で判定する．
  3. 出力の単語数 ÷ 参照の単語数の中央値と，元の音声（orig）の H/N の平均を同じ表に並べる．元の音声の H/N が低いコーパスでは，人の書き起こしと Whisper の表記の違いで 0.20 の意味が変わるので，その値も結果の文に書く．
  4. 平均には発話を単位にした引き直しの区間を添える（話者の情報のあるコーパスは話者を単位にする．前回の求める対応のうち未対応の分）．規則は点推定で判定してよいが，区間が閾値をまたぐコーパスを名指しで書く．
