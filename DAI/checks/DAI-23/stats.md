## 指摘

### [S8] L2 は「低域通過が D を目標によらず同じ割合で減らす」帰無でも正になるので，E2 の当たりを言葉の中身の根拠に使えない
- 重さ：直してから進む（計算の前に設計の予言を直せば足りる．計算の後に主の量を変えると，予言を結果の後に選ぶことになる）
- 該当箇所：`docs/設計/実験23_設計.md:37`（L2 の定義），`:52`（E2），`:60`（E1・E2 が当たるときの文），`:77`（顔の判断の D に減る余地の仮定）
- 問題：設計 37 行は「L2 = [D(A ← T) − D(L ← T)] − [D(A ← V) − D(L ← V)]：その減り方が，顔の判断を再現する D の減り方より大きい分」と定義し，60 行は E1・E2 が当たれば「声の特徴が言葉の判断を再現した分の一部は，音声の中の聞き取れる言葉の中身から来たことを示唆する」と書く．L2 が 0 になる帰無は「低域通過が D を目標によらず同じ点数だけ減らす」である．一方，設計 93 行が認めるとおり，低域通過は高い周波数の手がかりを消し，WavLM の特徴の質を全体に下げる．特徴の質の低下が D を目標によらず同じ割合 c で残す（D(L ← m) = c·D(A ← m)）とすると，L2 の期待値は (1 − c)·[D(A ← T) − D(A ← V)] になる．実験 14 の K = 5，R1，候補の全体の値（`results/dai14/summary/descriptive.csv`）では，D(A ← T) は IEMOCAP 19.30，MOSEI 10.51，MELD 17.71，D(A ← V) は 6.00，1.70，9.09 である．差は 13.3，8.8，8.6 点で，3 コーパスすべてで L2 の期待値が正になる．たとえば c = 0.5 なら 6.7，4.4，4.3 点で，下の [S2] の見込みの半幅（IEMOCAP 約 9，MOSEI 約 1.7，MELD 約 4）と比べると，MOSEI と MELD では言葉の中身が無関係でも E2 が「上回る」になりうる．したがって E2 の「当たり」は，言葉の中身の消失と特徴の質の一律の低下を区別しない．
  さらに MOSEI の D(A ← V) は 1.70 点で，設計 77 行の基準「2 点未満」をすでに下回る．D(L ← V) の期待値が 0 より下がらないとすると，MOSEI の L2 はほぼ L1 − 1.7 点以上になり，E1 が当たれば E2 もほぼ自動的に当たる．77 行は「L2 を L1 と並べて書き，L2 だけを根拠にしない」と書くが，52 行の数えには MOSEI がそのまま入る．
- 計算の後で直せるか：直せない（主の量と数えの規則を結果の後に変えることになる）．今は計算の前なので，設計の文書を直せば足りる．
- 求める対応：
  1. E2 の主の量を，一律の割合の低下の帰無で期待値 0 になる量に替える．`combo_stats` の係数で書ける形として，κ_T = D(A ← T) ÷ D(A ← V) を実験 14 の点推定（上の値．IEMOCAP 3.22，MOSEI 6.18，MELD 1.95，MELD の共有の対話を除いた版 1.78）で計算の前に固定し，L2κ = [D(A ← T) − D(L ← T)] − κ_T·[D(A ← V) − D(L ← V)] とする（D(L ← T)/D(A ← T) < D(L ← V)/D(A ← V) を線形にした形）．今の L2（一律の点数の帰無）は記述の量に移す．
  2. MOSEI は D(A ← V) が 2 点未満と分かっているので，E2 の数えから外すか，外さない理由を書く．外すなら E2 の数えは IEMOCAP と MELD の 2 コーパスになり，下の [S2] のとおり IEMOCAP はほぼ検出できないので，E2 はコーパスごとの記述（MELD を名指し）にとどめる，と計算の前に書く．
  3. 60 行の「示唆する」の文は，L2κ が上回ったコーパスに限って書く．今の L2 だけが上回ったときの文（「減り方は点数では大きかったが，元の D の大きさに比例した減りと区別できない」）を書き方の表に足す．
  4. selftest に，L を「A に雑音を足して質を一律に下げた特徴」（言葉の中身は消さない）にした合成の対照を足し，L2 が正に寄り L2κ が 0 に近いことを確かめる．

### [S2] 3 コーパスの数えは検定ではなく，IEMOCAP の L2 は効果の上限に近い大きさでないと検出できない

## 目録に無い種類の不備

- S18 の案：差の差で「ある操作で量がどれだけ減ったか」を 2 つの目標の間で比べるときは，操作が量を目標によらず同じ割合で減らす帰無での期待値を，前の実験の値から計算の前に出す．減る前の量が目標の間で違うなら，点数の差の差ではなく，割合の帰無で 0 になる量（比，または前の値で固定した係数を掛けた差）を主にする（DAI-23 の関門 1．D(A ← T) と D(A ← V) が 8.6〜13.3 点違い，点数の差の差は一律の割合の低下でも正になった）．
- S19 の案：操作の成否を誤り率の平均の閾値で決めるときは，誤り率の上限（挿入で 1 を超える）と少数の外れ値の影響を計算の前に決め，平均に区間を添える（DAI-23 の関門 1．Whisper の挿入で WER の平均が上がり，言葉の残る操作を選びうる）．
