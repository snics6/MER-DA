## 指摘

### [C4・C10] 低域通過だけでは，減った分を言葉の中身に帰す比べにならない
- 重さ：直してから進む
- 該当箇所：`docs/設計/実験23_設計.md:60`，`:37`，`:74`，`:93`，`:10`
- 問題：E1・E2 が当たったときの文は「声の特徴が言葉の判断を再現した分の一部は，音声の中の聞き取れる言葉の中身から来たことを示唆する」（設計:60）である．一方で設計自身が，低域通過は「高い周波数にある声の手がかり（声質，スペクトルの傾き，子音の強さ）も消し，WavLM の学習で見ていない種類の音声になる」と書き，L2 と R(L ← y) は「この混ざりの一部を分けるが，全部は分けない」と書く（設計:93）．C10 に従い，L2 の対照（顔の判断の再現の減り）が何を共有し何を欠くかを表にすると次のようになる．

  | 低域通過で消える成分 | J_T の再現（L1）を減らすか | J_V の再現の減りで差し引けるか |
  |---|---|---|
  | 聞き取れる言葉の中身 | 減らす（確かめたい成分） | 差し引かない（狙いどおり） |
  | WavLM にとって見たことの無い音声になることによる，特徴の全般の劣化 | 減らす | 劣化が J_T と J_V に同じ割合で効くときだけ差し引ける（次の指摘 [C18] のとおり，絶対の差では差し引けない） |
  | fc より上の言葉以外の手がかり（声質，スペクトルの傾き，高い帯域のエネルギー．高い帯域のエネルギーとスペクトルの傾きは声の大きさや覚醒度に結びつく） | 言葉の分類器の判断が感情の層の中で覚醒度や強さと結びついていれば減らす | 顔の判断がこれらと結びつく度合いが言葉の判断と違えば差し引けない |
  | fc より下に残る手がかり（F0，エネルギーの輪郭，発話の長さ） | 減らさない | — |

  顔の判断と声の間で共有される一致は，F0 やエネルギーの輪郭のように低い帯域に残る手がかりを通る可能性が高い．その場合，言葉の中身の有無に関係なく，J_V の再現の減りは J_T の再現の減りより小さくなり，E2 は当たる．つまり E2 は「言葉の中身が効いている」の下でも「言葉の判断の再現が fc より上の言葉以外の手がかりに J_V より多く頼っている」の下でも当たり，この 2 つを分けない．R(L ← y) は感情の情報の量を測るが，D は感情の層を通る一致をはじめから除く量なので，R(L ← y) の比が 0.5 以上（設計:74）であることは，D の中の言葉以外の手がかりが残ったことを示さない．

  人の知覚の研究では，内容を隠す操作はどれも言葉以外の手がかりの一部も壊すので，複数の操作を並べて共通する部分だけを内容の寄与と読むのが標準の作りである．Friend & Farrar（1994，JASA 96(3)）は低域通過・ランダムな切り貼り（random splicing）・反復音声の 3 つを比べ，「どの操作も一部の音響の情報を残し，別の情報を壊す」ので評定に偏りが出たと報告した．Scherer ほか（1985，J Psycholinguist Res 14(4)，10.1007/BF01067884）は，濾波・切り貼り・逆再生・音高の反転などの条件を並べた．Scherer ほか（1972）は，濾波で感じられる活動性が下がり，切り貼りで評価の次元が正に寄ると報告した．Johnson ほか（1986）の要約では，切り貼りは声の大きさ・F0・声質を変えず，抑揚と速さを部分的に隠す（いずれも検索で抄録を確かめた．全文は読んでいない）．機械学習の側でも，Burkhardt ほか（ICASSP 2023）は切り貼りで内容を隠した音声に事前学習の Transformer の感情モデルを当てている．設計の 0 節が引く Lolli ほか（2015，Frontiers in Psychology，10.3389/fpsyg.2015.01340）は確かに 500 Hz の低域通過を使い，比べの条件として高域通過を置いている（設計:10 の「原文は関門の段で確かめる」はこれで確かめた）．Knoll ほか（2009，Speech Communication 51(3)）は 1200・1000・700・400 Hz を比べ，1000 Hz より上の切れ目では意味の情報が残ると書いた．設計の 300〜500 Hz の候補はこの範囲の内側にある．

  依頼の中で挙がった「同じだけ情報を落とすが言葉は残す操作」は，上の表の 2 行目（全般の劣化）を分ける．しかし 3 行目（fc より上の言葉以外の手がかり）は分けない．言葉を残す操作は高い帯域を残すか，別の帯域を壊すかのどちらかで，低域通過と同じ成分を消さないからである．3 行目を分けるには，言葉を消し，かつ fc より上の言葉以外の手がかりを残す 2 つ目の操作が要る．
- 計算の後で直せるか：直せる．ただし 2 つ目の操作の特徴を作り，生徒を 1 つ学び足す計算が要る．L の結果を見た後に対照と帰属の規則を足すと，規則が計算の後に決まる．このため計算の前に足すべきである．
- 求める対応：次の 1 案を推す．
  1. 2 つ目の生徒として，逆再生した波形（`w[::-1]`）から A と同じ流れで作った WavLM の最後の層の特徴 Rv を足す．逆再生は長い区間の平均のスペクトル（声質，スペクトルの傾き，高い帯域のエネルギー），F0 の分布，声の大きさの分布，発話の長さを元のまま残し，言葉を聞き取れなくする．低域通過と同じく，WavLM が学習で見ていない種類の音声になる．つまみが無いので fc のような選びも要らない．Whisper の WER の確かめ（設計 2 節）を同じ規則で Rv にも当てる．
  2. 帰属の規則を計算の前に書く．「言葉の中身に帰してよい」のは，L と Rv の両方で E1・E2 に当たる量（Rv 版の L1・L2）が上回るときだけとする．L で上回り Rv で上回らないときは，「fc より上の周波数の成分（声質などの言葉以外の手がかりを含む）の消失に伴って減った」と書き，言葉の中身には帰さない．
  3. 結果の文の表（設計:58-64）に，この 2 通りの行を足す．
  4. 制約：WavLM の最後の層は時間平均なので，逆再生でも母音の分布のような順序に依らない音素の情報が平均の中に残りうる．Rv の D が減らなくても「言葉の中身は効いていない」の根拠にしない，と 9 節に書く．
  5. 2 つ目の生徒を足さない場合は，設計:60 の文の「音声の中の聞き取れる言葉の中身から来たことを示唆する」を「fc Hz より上の周波数の成分（言葉の中身と，声質などの言葉以外の手がかりを含む）から来たことを示唆する」に替える．これは記述を変えるだけで済み，計算は増えない．

### [C18・C10] L2 は絶対の差なので，どの情報も同じ割合で減る帰無の下でも正になりうる
- 重さ：直してから進む
- 該当箇所：`docs/設計/実験23_設計.md:37`，`:52`，`:77`
- 問題：L2 = [D(A ← T) − D(L ← T)] − [D(A ← V) − D(L ← V)]（設計:37）である．低域通過が言葉に限らず，声の特徴の中の感情の層の内側の情報を一律に割合 ρ だけ壊すとする（言葉に固有の効果が無い帰無）．このとき期待値は L1 ≈ ρ·D(A ← T)，顔の判断の側の減りは ≈ ρ·D(A ← V) なので，L2 ≈ ρ·[D(A ← T) − D(A ← V)] となる．つまり D(A ← T) が D(A ← V) より大きいコーパスでは，言葉に固有の効果が無くても L2 は正になる．E2 の主の数え（設計:52）はこの帰無を区別しない．仮定の表は D(A ← V) が 2 点未満のときだけを扱い（設計:77），D(A ← T) と D(A ← V) の大きさが違う一般の場合を扱わない．この検査では実験 14 の D の値を開いていないので，実際に D(A ← T) > D(A ← V) かは確かめていない．ただし式の上では，帰無の下で L2 が正になる条件は D(A ← T) > D(A ← V) だけである．
- 計算の後で直せるか：計算のやり直しは要らない（保存した予測から比を後で作れる）．ただし主の判定の量を結果を見てから替えることになるので，計算の前に直すべきである．
- 求める対応：E2 の主の量を割合の減りの差 L2r = [D(A ← T) − D(L ← T)] / D(A ← T) − [D(A ← V) − D(L ← V)] / D(A ← V) にするか，比の対数 log D(L ← T)/D(A ← T) − log D(L ← V)/D(A ← V) にし，帰無の下での期待値が 0 であることを設計に式で書く（C18）．区間は，既存の塊の jackknife と引き直しを比の量に当てる（gate-stats と相談）．分母が 0 に近い場合の扱い（例：D(A ← V) の区間が 0 を含むコーパスでは L2r を判定に使わない）を仮定の表に足す．今の絶対の差の L2 は記述に残す．

- 重さ：直してから進む（fc の規則は計算の前に固定するので，確かめを流した後に替えると規則が後から決まる）

- 問題：WER = 編集距離 ÷ 参照の単語数（`check_lowpass_asr.py:114`）は上限が無く，挿入で 1 を超える．Whisper は聞き取れない音声で参照に無い文を作ることがある（設計が AFEW について書く「声の無い区間で定型の文を作る」と同じ現象）．参照が 3〜4 語の発話で 10 語の作り話が出ると，その発話の WER は 2〜3 になる．このため「WER の平均が 0.80 以上」（設計:22）は，半分の発話で言葉の多くが聞き取れていても，残りの発話の作り話で満たされうる．選びの母集団は manifest の全体（IEMOCAP の台本の部，3 つのモダリティがそろわない発話，テストの発話を含む．`check_lowpass_asr.py:66-69`）で，解析の母集団（IEMOCAP は即興の部だけ，3 つのモダリティがそろう発話）と違う．
- 求める対応：規則の量を，作り話で上がらない量にする．たとえば「参照の単語のうち，書き起こしと揃えたときに一致した単語の割合（一致の数 ÷ 参照の単語数）の平均が 0.20 以下」か，発話ごとの WER を 1 で切ってから平均する．元の WER も並べて残す．選ぶ母集団を解析の母集団（`dai_data.load_corpus` の発話．IEMOCAP は即興の部）に合わせる．
- 9.3 節に足す項目の案：「操作で情報を消したことを確かめる指標は，消えなかった場合に上がらない向きの偏りを持たないかを確かめる（ASR の WER は挿入と作り話で 1 を超えて上がり，聞き取れる発話が残っていても平均が下限を満たしうる）．確かめの母集団を解析の母集団に合わせる」．

### 内容を隠す操作が 1 つだけで，その操作が壊す言葉以外の手がかりを分ける対照が無い
- 9.3 節に足す項目の案（C の項目として）：「入力の一部（言葉の中身など）を消す操作で寄与を測るときは，その操作が同時に消すほかの手がかりを表にし，言葉を消すが副作用の違う 2 つ目の操作か，副作用を揃えて対象を残す操作を置く．置かないなら，帰属の文を操作が消した成分の全体（「fc より上の周波数の成分」など）に限る（DAI-23 の関門 1．人の知覚の研究の標準は複数の内容を隠す操作の比較：Friend & Farrar 1994，Scherer ほか 1985）」．
- 9.3 節に足す項目の案（C18 への追記）：「2 つの目標の再現の減りを絶対の差で比べるときは，操作が一律の割合で情報を壊す帰無の下での期待値を式で書く．元の大きさが違う 2 つの量の絶対の減りの差は，その帰無の下でも 0 にならない」．
