## 指摘

### [L2・L8] `exp/dai23.py` は `--l-kind` と `--b-kind` を省けば，本番でない置き場で本物の L と B の特徴から主の量と判定を計算できる
- 重さ：直してから進む
- 該当箇所：`exp/dai23.py:509`（本番の置き場だけが分割・種・特徴の名前の変更を止める），`:511`（fc.json があれば `--l-kind` 無しでも通る），`:514`（`kinds = {"L": args.l_kind or f"audio_wavlm-lp{int(fcj['fc'])}", "B": args.b_kind or "audio_wavlm-rev"}`），`:515`（`if any(k is not None and k != DD.ENC1["A"] for k in (args.l_kind, args.b_kind))` は None を通す）．設計 8 節 111 行（「言葉を消した声の特徴ができた後に流す試しは退化の試しと行の数の確かめだけで，L と B の量は本番の単位でだけ作る」）
- 問題：設計 111 行は，L と B の量を本番の単位でだけ作ると決めている．しかし台本は，fc.json と L・B の特徴ができた後に `exp/dai23.py --stage units --out-dir <一時の置き場> --folds 0 --seeds 0 --allow-partial` と `--stage summary --out-dir <同じ置き場> --allow-partial` を流すと，`kinds` が本物の `audio_wavlm-lp<fc>` と `audio_wavlm-rev` になり，M1〜M3d・L3 と `criteria.json` の数えまで出す．`--b-kind audio_wavlm` だけを付けて L の本物の量を出すこともできる（:515 は `--l-kind` が None なら止めない）．前回の対応 (b) は `--l-kind` と `--b-kind` に渡せる名前を制限したが，名前を省いたときの既定値が本物の特徴を指すので，試しの置き場で本物の量を作る経路は閉じていない．一時の置き場の `provenance_log.jsonl` は消せるので，本番の前に量を見ていないことを後から示せない．
- 計算の後で直せるか：直せない（本番の前に本物の L・B の量を見た後では，設計の第 4 版や予言の扱いが見た値の影響を受けていないことを示せない）．今は特徴も fc.json も無いので，何も起きていない．
- 求める対応：`exp/dai23.py` の main で，本番でない置き場（`prod` が偽）では `--l-kind` と `--b-kind` の両方が `audio_wavlm` であることを求め，どちらかが省かれていれば止める（例：`if not prod and (args.l_kind != DD.ENC1["A"] or args.b_kind != DD.ENC1["A"]): sys.exit(...)`）．設計 8 節の「行の数の確かめ」が `exp/dai23.py` の段を要るなら，その段が量を書かないことを台本で決める．gate-code にこの差分を再検査させる．
