## 指摘

### [C18] κ を候補の全体の値で固定したまま部分集合に当てるので，MELD の共有を除いた版では同じ割合の帰無の下でも M3 が 0 にならない
- 重さ：直してから進む
- 該当箇所：`docs/設計/実験23_設計.md:46-47`，`:58`；`exp/dai23.py:261-272`，`:316-327`，`:275-279`
- 問題：設計は κ_T = D(A ← T) ÷ D(A ← V) を「候補の全体」の点推定で固定し（設計:46），帰無の D(X ← m) = c · D(A ← m) の下で M3_X = (1 − c)[D(A ← T) − κ_T D(A ← V)] = 0 と書く（設計:47）．この 0 は，κ_T がその量を計算する発話の集合の上の比 D(A ← T)/D(A ← V) に等しいときだけ成り立つ．台本は `kappa_from_dai14` で `subset == "all"` の行だけから κ を作り（`dai23.py:264`），その κ で `all`・`nonshared`・`nomarker` のすべての M3 を作る（`dai23.py:315-327`）．部分集合 s の上では，帰無の下で M3_X,s = (1 − c)[D_s(A ← T) − κ_all · D_s(A ← V)] となり，D_s(A ← T)/D_s(A ← V) が κ_all と違えば 0 にならない．MELD の E2 は `nonshared` の M3 も「上回る」ことを条件にする（設計:58，`dai23.py:278`）ので，この偏りは主の判定に入る．比 D_s(A ← T)/D_s(A ← V) が κ_all より大きければ M3_ns は帰無の下で正に偏り（E2 が出やすい），小さければ負に偏る．実験 14 の `predictions.csv` には P3・P3b の `nonshared`（MELD）と `nomarker`（3 コーパス）の行がある（列と部分集合の名前だけを確かめた）ので，部分集合ごとの κ は計算の前に固定できる．
- 計算の後で直せるか：直せる（単位の計算は要らず，`summary` を流し直すだけ）．ただし主の判定の条件の量を結果を見てから替えることになるので，計算の前に直す．
- 求める対応：κ を (T, 部分集合) ごとに実験 14 の P3 ÷ P3b の同じ部分集合の行から作り，設計 3 節に MELD の `nonshared` と 3 コーパスの `nomarker` の値を書き足して固定する（今の値の照合と同じく台本で小数 3 桁で照らす）．`selftest` に「部分集合の比が全体の比と違うとき，部分集合の κ を使えば帰無で M3 = 0，全体の κ では 0 にならない」の項を足す．`main.csv` の `kappa` の列には部分集合ごとの値を入れる．

### [C10・C8] 2 つの操作が共通に作る「WavLM の学習で見ていない種類の音声」の劣化が言葉の判断の再現に偏って効く可能性を，両方で E2 が成り立つときの文が名指ししていない

- 問題：H/N は作り話の挿入では上がらないが，作り話の中の短い語（"you"，"the"，"i"）が参照の語と順に一致すれば上がる．参照が 3 語の発話では偶然の 1 語の一致で H/N = 0.33 になり，基準の 0.20 を 1 本で超える．このため「H/N の平均 ≤ 0.20」が満たされない理由が，言葉が残ったことか偶然の一致かを分けられない．向きは「規則を満たしにくくなる」側で，fc を低い側に寄せるか `rule_met = false` を出しやすくする．主張を強める向きの偏りではないが，基準 0.20 の意味が決まらない．
- 求める対応（記録）：同じ標本で，発話 i の Whisper の出力と別の発話 j の参照を組んだ H/N の平均（偶然の一致の水準）を `asr_check_summary.csv` に並べて出す．規則は今のまま固定し，結果の文で基準と偶然の水準を並べて書く．
- 9.3 節に足す項目の案：「操作で情報を消したことを確かめる指標の基準値は，消し切った場合の偶然の水準（別の標本と組んだときの値など）を同じ標本で測って並べる．偶然の水準が基準に近いと，基準を満たさないことが情報の残りを示さない」．

### 帰無の比を固定の係数にした量を部分集合に当てるとき
