- 実験 2 が支える主張は「提案と標準の手法との差を，使う情報の差として記述する」ことで，優劣の主張ではない（`DAI/docs/実験2_設計.md:116`）．比べる種類は，SSDA（S+T，エントロピー最小化，MME の項），教師なしの DA（DANN の項，CORAL），ソースのデータを使わない適応（IM，T3A，自己学習，ラベル伝播），マルチモーダル（xMUDA 型）である．
- 先に `docs/related-work.md` 1.15 節（SSDA の 7 本．水準はすべて ◎ と記録）を読んだ．SSDA の代表の手法はすべてソースのラベルの損失を使う．
- 足りない分をウェブで確かめた．確かめた水準は検索の結果の抄録だけ（本文と表は読んでいない）である．
  - AGLP（arXiv 2411.13152，2024）：S+T，DANN，ENT，APE，DECOTA，MME，CDAC などを相手にする．
  - Inter-Domain Mixup（arXiv 2401.11453，2024）：S+T，DANN，MME，CDAC などを相手にし，S+T と DANN の値は MME の論文から引いている．
  - MME（arXiv 1904.06487）の表は S+T，DANN，ENT，MME を並べる．
- 結論：S+T とエントロピー最小化は入っている．MME と DANN は SSDA の表の形（ソースのラベルの損失あり）ではなく，ソースのラベルを使わない形で入っている．名前の扱いは設計で決まっているので，残るのは限界の文（指摘 2-J）である．CDAC と APE は入力の変形を前提にするので回さない理由が書かれている（2.4 節）．

## 6. 目録に無い種類の不備

`docs/methods.md` 9.3 節の C に足す案（DAI-1 の報告の C33 に続ける）：

- C34 評価の回の出力をまとめる集計の台本は，全部の実験について評価の回のコミットに入れ，固定のファイルか `eval_gate.json` に sha256 を残す．ほかの実験の主張の文（族 3 のコーパスの文など）がこの実験の集計の値を使うときは，とくにそうする（DAI-2 の評価の回の前の関門 1）

- C36 解が束の組み方や計算の順で変わる手法では，選ぶ段の選択がその揺れで替わりうることを限界に書く．測るなら，仮のターゲットの回で格子の全点を別の組み方でも解く（DAI-2 の勾配法の手法）
