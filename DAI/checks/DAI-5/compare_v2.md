## 指摘

### [C6] `srcw_top1` の保存の接頭辞が，設計と台本の説明では `p5t`，実装では `p5o` である
- 重さ：記録する
- 該当箇所：`DAI/docs/実験5_設計.md:154`（「保存の接頭辞は p5・p5m・p5s・p5t」），`DAI/exp/dai5.py:21`（「保存の接頭辞は p5m・p5s・p5t」），`DAI/exp/dai5.py:381`（`P5.pred` の説明「p5t（srcw_top1．β は inf）」），実装は `dai5.py:163`（`"srcw_top1": "p5o"`）と `dai5.py:164`（`TETHER_PREFIX = "p5t"`），設計 89 行（引き戻しの曲線を `p5t_<生徒>_K<K>_*`）
- 問題：`p5t` は実装では引き戻しの曲線の接頭辞であり，`srcw_top1` は `p5o` に保存される．stats は `p5o` を読む（dai5_stats.py 115 行）ので計算は正しい．説明の文を信じて `P5.pred(s, K, inf, "p5t")` を呼ぶと，β = inf の問が無いので KeyError で止まり，黙って違う行を読むことは無い．後から保存を読む人が `srcw_top1` を探せない．
- 計算の後で直せるか：直せる（説明の文を直すだけ．保存の中身は変わらない）
- 求める対応：設計 154 行を「p5・p5m・p5s・p5o（`srcw_top1`），引き戻しの曲線は p5t」に，`dai5.py:21` と `dai5.py:381` も同じに直す．pseudo の後は `dai5.py` を変えない決まり（設計 87 行）なので，説明の文だけでも pseudo の前に直すか，設計の文書だけを直して台本の説明の誤りを設計に注として書く．

### [C11] `srcw − srcw_mod`・`srcw − srcw_src` で両方が β = 0 を選んだセルに「同じ識別器」の印が無い
- 重さ：記録する
- 該当箇所：`DAI/exp/dai5_stats.py:449`（`identical_by_construction=bool(B == "srcw_b0" and (s, K) in ident)`），設計 27・51 行
- 問題：`srcw` と軸を分けた版がどちらも β = 0 を選んだ (T, K) では，3 つとも `srcw_b0` と同じ教師で，`srcw − srcw_mod` と `srcw − srcw_src` は構造的に 0，区間は [0, 0] になる．印は `B == "srcw_b0"` にだけ付くので，このセルが「ソースの軸を外しても変わらない」と読まれうる．`srcw` が β > 0 で版が β = 0 を選んだセルでは，`srcw − srcw_mod` は `srcw − srcw_b0` と同じ量になる．
- 計算の後で直せるか：直せる（desc.csv に `beta` と `beta_variant` の列が残るので，印は保存から付けられる）
- 求める対応：stats か読み方の規則に「`beta` と `beta_variant` がどちらも 0 のセルは `identical`，片方だけ 0 のセルは `srcw − srcw_b0` または `版 − srcw_b0` と同じ量」と書き，3 節の数え上げと同じく数から外す．

### [C6] 引き戻しの曲線の固定の点で，曲線の値と本番の値が一致するかの照合が無い

- 計算の後で直せるか：直せる（判定は両方とも保存される）

## 第 1 版の後に新しく見た点で，指摘にしないもの
- `srcw_top1` の指数は 3 で，Q は 1 位の識別器の確率の 3 乗の正規化になり，指数 1 の「その識別器の確率」より鋭い．`srcw` の β → ∞ の極限と一致させた選び方で，両端の比べとしては筋が通る．鋭さは版ごとの `_teacher_stats`（`variant=srcw_top1` の maxp・entropy）に残るので，`srcw − srcw_top1` を読むときに並べればよい．

- 少数のターゲットラベルの尤度で重みを学ぶ相手（Tommasi ほか 2014，SUR）は入っていない．設計 11 節はこれを「書けないこと（先例がある）」に挙げ，8 節は採点に K 本以外の情報を混ぜる版を範囲の外にしている．論文で「この規則は重みを学ぶ方法より良い」と書かなければ，C4 の欠けにはならない．
