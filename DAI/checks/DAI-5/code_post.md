## 5．3 節の規則の列

- `rule_d`：AVT × K ∈ {5, 25} の 8 行で，設計 3 節 (d) の式（区間全体が ±δ の中なら「差が小さい」，区間が 0 を含まず |点推定| > δ なら「見込みと違う」，ほかは「判定できない」，`identical` は数えない）で作り直した値との食い違い 0．値が入っているのは β = 0 が選ばれていない 4 行（IEMOCAP の K5・K25，AFEW・MOSEI の K25）で，AVT 以外の行に `rule_d` は無い．
- `rule_b_chance`：MELD は K = 25 で β = 0 が選ばれたので 3 セルとも `identical` で外れ，分母は AFEW の 3 セルだけになった．同じ反転の数え上げ（32 通り）を作り直して，「4 以上が正」0.0，「2 以下が正」0.875，点推定が正のセルの数が表と一致した．分母が 4 未満なので，設計 3 節 (b) の規則では「判定しない」になる．分母が 4 未満のとき `selfcheck_indep_ge4` が NaN になるのは台本（dai5_stats.py:379）のとおりである．
- `identical`：上の 4 (b)．軸を分けた版の比べ（`srcw − srcw_mod`，`srcw − srcw_src`）の印は「`srcw` も軸を分けた版も β = 0」のときだけ真で，設計 2 節の定義どおりである（読んだだけ．dai5_stats.py:575–576）．
- `split_half_regret_ge_delta`：240 行で「2 組で測った取りこぼし ≥ δ」から作り直した値との食い違い 0．`n_grid_points` は `srcw` が 5（K = 0 は 1），`joint` が 24．同じテストで測った取りこぼしは，生徒ごとに選ぶ行では負の行が 0 で，4 生徒の平均で最良を選ぶ行では負の行が 6 ある（設計 2 節の「生徒ごとの行は負になりうる」のとおり）．
- `usable_rule`：上の 4 (d)．K = 25 だけに真が立ちうる式（dai5_stats.py:747–748）で，設計 2 節の「|採点で選んだ損| ≤ |でたらめの損|/2，かつ対の差の jackknife の下端 > 0」と同じである．
- `interval_within_delta`：K > 0 の区間のある行すべてで作り直しとの食い違い 0．
