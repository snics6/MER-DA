## 指摘

### 直す点

### [D19・D16・D10] 1. R の比較に，特徴の違いのほかに生徒の学び方（引き戻しの強さ，次元，切片の罰則）の違いが入り，その向きが P1 では声に有利，P2 では言葉に有利にそろう
- 重さ：直してから進む
- 該当箇所：`DAI/docs/実験14_設計.md:27`（「生徒 s と同じ形の線形の識別器（s の出発点から，(s, K) の実験 1 の引き戻しで）」），`DAI/exp/dai14.py:234-236`（`W0, b0 = u.start[s]`，`cw, cb = sv.teth[(s, K)]`），`DAI/frozen/dai1_frozen.json` の `tether`
- 問題：R(A ← T) − R(V ← T) は，同じ判断 J_T を，声の特徴と顔の特徴で別々の罰則と別々の次元の識別器に学ばせた結果の差である．固定のファイルの K = 5 の引き戻しは，AFEW が A・V で Cw = 0.001，T で 0.003，MELD が A・T で 0.003，V で 0.001，IEMOCAP は T だけ切片の C_b = 10（ほかは 1）である．次元は A 1024，V 512，T 768 である．同じ罰則でも次元と分散の広がりで識別器の自由度が違う．
  確認の計算として，候補を「分割 0 のテスト以外」で近似し，候補で標準化した特徴の 1 つの組（`pool_halves` の組 0）の XᵀX の固有値 s_i から，リッジの実効の自由度 Σ c·s_i / (c·s_i + 1/Cw)（c はロジスティックの曲率．上限の 0.25 を使う）を出した（読むだけの計算．スクリプトは `/tmp/claude-1000/-home-snics-MER-DA/76085a37-4610-4922-b8ae-ced34f163c39/scratchpad/df.py`）．

  | コーパス | 声 A | 顔 V | 言葉 T | Cw（A / V / T） |
  |---|---|---|---|---|
  | AFEW | 37 | 15 | 71 | 0.001 / 0.001 / 0.003 |
  | IEMOCAP | 77 | 28 | 95 | 0.001 / 0.001 / 0.001（T の C_b = 10） |
  | MELD | 365 | 77 | 361 | 0.003 / 0.001 / 0.003 |
  | MOSEI | 300 | 102 | 311 | 0.001 / 0.001 / 0.001 |

  （概算である．MELD は実際の候補より本数を多く取った近似で，実際の組は 2,443〜2,998 本．c = 0.1 でも順序は変わらない．）
  顔の識別器の自由度は 4 コーパスとも声の 1/5〜2/5 である．したがって P1（声 − 顔）は，声の特徴に言葉の手がかりが無くても，学び方の差だけで正の向きに出うる．P2（声 − 言葉）は，AFEW と IEMOCAP では言葉の自由度が声より大きく，予言と反対の向きに偏る．P4a・P4b は入れ替えの対照を引くので一部は打ち消すが，自由度が大きい識別器ほど「感情のラベルを通らない J_m の癖」を多く拾えるので，打ち消しは保証されない．切片の罰則の違い（IEMOCAP の T）は R に入り，入れ替えた目標は感情ごとの判断の割合が同じなので D では打ち消す．
  主張の文書 3 節の説明は「音声には…入っている」「言葉の特徴には…入っていない」と**特徴**についての文である．いまの R は「その生徒の学び方で再現できる度合い」で，条件 3（自分の特徴で再現できる）の量としては妥当だが，特徴に入っている情報の比較としては D19 の不備（罰則のかけ方の違いが差に入る）を持つ．
- 計算の後で直せるか：直せない（共通の作りの版は新しい学習が要るので，後から足すと計算をやり直す）．
- 求める対応：
  1. 「共通の作りの版」を足す．候補の特徴をラベル無しで同じ次元 r（例えば 256．V の 512 以下）へ主成分で縮め，出発点を 0 にし，罰則 C は学習側の組の中で J_m を目標にした交差検証（本当のラベルを使わない）で格子から選ぶ．入れ替えた目標にも同じ規則で C を選ぶ．
  2. 5 節に，説明の文（特徴に入っている・入っていない）は共通の作りの版の P1〜P4 で判定し，条件 3 の文は生徒の作りの版で判定する，と書く．2 つの版で当たり外れが食い違ったら両方を書き，説明の文は書かない．
  3. 両方の版の実効の自由度（上の式）と n/d を単位ごとに出力に残す．

### [D8・D6] 2. 入れ替えの対照は「感情は 4 クラスのラベルで尽きる」を仮定しており，同じラベルの中の感情のばらつきが D に入る．P3 は説明が偽でも当たり，P4a は声と顔がそのばらつきを同じだけ表すという測っていない仮定に依る
- 重さ：直してから進む
- 該当箇所：`DAI/docs/実験14_設計.md:13`（「感情を通した一致（両方が同じ感情を当てていること）を除いても残るか」），`:29`（「特徴が感情しか知らないなら 0 に近くなる」），`:45-46`（P3・P4），`:67`（限界），`DAI/exp/dai14.py:182-191`
- 問題：入れ替えは本当の 4 クラスのラベル y の中でだけ行う．D = 0 の帰無は「y を与えたとき，生徒の特徴と J_m が独立」である．この帰無は，声に言葉の中身が入っていなくても次の 3 つで崩れ，D は正になる．
  (a) 同じラベルの中の感情の強さ・覚醒度・感情価のばらつき．`docs/related-work.md` 1741〜1743 行の Larsen ほか 2026 は，IEMOCAP で同じカテゴリの中の VAD の値が大きくばらつき，注釈者の全員一致が約 20% であると報告している．J_T も声の特徴も，このラベルの中のばらつきに反応しうる．
  (b) J_A・J_V・J_T は同じ K = 5 本ずつの発話で学んでいる（`u.kpos[K]`）．20 本の偏り（たとえば Happy の 5 本が覚醒度の高い発話）が 3 つの判断に共通に入る．
  (c) 3 つの出発点は同じソースのコーパスのラベルで学んでいる．ソースのラベルの付け方（MOSEI の Neutral が消去法で付くことなど）が 3 つの判断に共通の癖を作る．
  このため P3（D(A ← T) の下端 > 0）は，どの対でも当たりうる量で，説明を支持する証拠としての特異性が低い．P4a = D(A ← T) − D(V ← T) は，顔を「言葉の中身を持たない特徴」の参照にした差であり，(a)〜(c) の成分が声と顔に同じ大きさで入るという仮定の下でだけ「声の中の言葉の分」と読める．声の特徴は覚醒度をよく表す（`docs/related-work.md` 777〜780 行の Wagner ほか 2023 は，音声で覚醒度の低下が感情価より小さいことと，感情価の成功が音声に含まれる言葉の情報によることを報告している）．声が顔より覚醒度を多く持てば，言葉の中身が無くても P4a は正になる．設計 8 節 67 行は話者・録音の環境・場面を挙げるが，ラベルの中の感情のばらつきを挙げていない．
- 計算の後で直せるか：直せない（細かい層の入れ替えは新しい目標の学習が要る．後から足すと計算をやり直す）．
- 求める対応：
  1. 細かい層での入れ替えの対照 R_shuf2 を足す．IEMOCAP は y × 覚醒度・感情価（`iemocap_utterance_manifest.csv` の `arousal`・`valence`）の 3 分位，MOSEI は y × 感情の強さ（`int_*`）か `sentiment` の符号，MELD は y × `sentiment_raw` で層を作り，層の中で入れ替える．AFEW は細かい注釈が無いので記述にとどめる．D2 = R − R_shuf2 で P3・P4 を副として判定する．使う注釈は候補のラベルの側なので，gate-leak に台帳との照合を回す．
  2. 5 節に「P3 の当たりは説明の支持に数えない．説明の文に使うのは P4（と副の D2 の P4）だけ」と書く．
  3. 13 行の「両方が同じ感情を当てていること」を「本当の感情のラベルに依る部分（感情ごとの系統的な取り違えも含む）」に直す．入れ替えは感情ごとの J_m の割合を全部残すので，y に依る取り違えも R_shuf に入る．

### [D7・D17] 3. R は，学び直す前から生徒の識別器が J_m と一致している分を含み，「J_m の判断を学べる度合い」と区別できない
- 重さ：直してから進む
- 該当箇所：`DAI/docs/実験14_設計.md:27`，`DAI/exp/dai14.py:233-240`（出発点の判定は保存しない．保存するのは `none_{s}` の判定だけ）
- 問題：生徒の識別器はソースで学んだ出発点 W0 から始まり，Cw = 0.001〜0.003 で引き戻される．引き戻しが強いと，学んだ識別器は W0 の近くにとどまり，R は「ソースで学んだ声の識別器と，ソースで学んだ言葉の識別器（K 本で少し動かしたもの）が，もともとどれだけ一致するか」に近づく．このとき D は 2 つの識別器の誤りの相関であり，指摘 2 の (c) を大きく含む．条件 3 の「再現できる」を「学び直しで取り込める」と読むなら，学び直す前の一致を引いた量が要る．設計にも台本にも，学び直しで W がどれだけ動いたか（‖W − W0‖）の記録が無い．
- 計算の後で直せるか：一部だけ直せる．`none_{s}` と目標の判定は保存されるので，none の一致は後から出せる．出発点の判定と ‖W − W0‖ は保存されないので，後からは計算のやり直しが要る．
- 求める対応：
  1. 単位ごとに出発点の判定 `start_{s}` を保存し，‖W − W0‖_F / ‖W0‖_F を目標ごとに `csv` に残す．
  2. R_start(s ← m) = 出発点の判定と J_m の一致，R_none(s ← m) を，入れ替えた目標についても出し，R − R_start と D − D_start を記述として並べる．
  3. 5 節に，D − D_start が 0 以下のコーパスでは「声の特徴は言葉の判断を学び直しで取り込んだ」と書かず「もともと一致していた」と書く，という読みの規則を足す．

### [D1] 4. 説明の文と測る量の対応が設計の中で食い違い，説明の否定の 3 文を測る予言が無い
- 重さ：直してから進む（文の規則だけの直しで計算は増えないが，計算の後に決めると結果を見てからの規則になるので，計算の前に固定する）

### 記録する点

### [D1] 6. 「発話ごとの分」という名前が，D の中身（塊をまたぐ入れ替えで残る，話者・場面・映画の水準の一致）より狭い
- 重さ：記録する
- 該当箇所：`DAI/docs/実験14_設計.md:13`，`:29`，`:67`，`DAI/exp/dai14.py:186-190`（入れ替えは候補全体で，塊をまたぐ）
- 問題：入れ替えは感情ごとに候補全体で行うので，同じ話者や同じ映画の発話がそろって持つ癖（たとえば，ある話者の言葉の判断が Sad に寄り，その話者の声が低い）も R には残り R_shuf には残らない．この分は 1 つの発話の中の言葉と声の対応ではないが，D に入る．設計 67 行は限界に書いているが，名前は「発話ごとの」である．AFEW は塊が人物で，同じ映画の場面が 2 組に分かれうる．
- 計算の後で直せるか：名前は直せる．塊の中の入れ替えは新しい学習が要る．
- 求める対応：名前を「感情のラベルを通らない分」にするか，(塊，y) の中で入れ替える版を記述として足し，塊の水準の分（2 つの入れ替えの差）を分けて出す．(塊，y) の層が 1 本だけの発話は入れ替わらないので，その割合も出す．

### [D6・D7] 7. 偶然の水準と読みの範囲が書かれていない
- 重さ：記録する
- 該当箇所：`DAI/docs/実験14_設計.md:27`（「でたらめなら 25」），`:43-46`，`DAI/exp/dai14.py:77-84`，`:225`
- 問題：
  1. `uar_present` は目標に現れた感情だけで再現率を平均する．J_m がある感情を出さない単位では，でたらめの水準は 25 でなく 100 / （現れた感情の数）になる．
  2. R_shuf の上限は J_m の当たり方で決まる（J_m が y とほとんど関係しなければ R_shuf は 25 に近く，R の偶然を超える分の大半が D になる）．D の取りうる幅は 100 − R_shuf までで，判断ごとに違う．J_m の当たり方（K 本を除いた候補での UAR）は保存から出せるが，設計の表に無い．
  3. 意味のある大きさの下限が無い．MOSEI は組が 7,454 本で，1 ポイント未満の D でも下端 > 0 になりうる．
  4. 入れ替えは単位ごとに 1 回で，その揺れは種の項にだけ入る．負の D の扱い（そのまま報告するか）が書かれていない．
- 計算の後で直せるか：直せる（2 は保存から出せる．4 の入れ替えを増やすのは追加の学習で，指摘 2 の追加と同時に行える）．
- 求める対応：6 節の 3×3 の表に J_m の当たり方，R − 25，D / (100 − R_shuf) を並べる．意味のある下限（例えば 1 ポイント）を 5 節に書くか，下限を置かないことを書く．負の D はそのまま報告すると書く．余裕があれば入れ替えを単位ごとに複数回にして平均する．

## 目録に無い種類の不備

`docs/methods.md` 9.3 節に足す項目の案：

- **D22**　入れ替えや層別で「ラベルを通る分」を除くときは，層にしたラベルより細かい変動（同じラベルの中の強さ，覚醒度，感情価，注釈者の不一致）が「ラベルを通らない分」に残ることを書く．細かい注釈があるコーパスでは，層を細かくした入れ替えを副に置く（DAI-14 の関門 1）．
- **D23**　2 つの特徴の識別器を比べるときは，次元と罰則から実効の自由度（Σ c·s_i / (c·s_i + λ)）を計算の前に出し，その違いが予言と同じ向きに入るか反対の向きに入るかを書く．同じ向きなら，次元と罰則の選び方をそろえた版を置く（DAI-14 の関門 1．D19 を部分空間の外の比較に広げたもの）．
- **D24**　説明の文に「入っていない」「無い」という否定の文があるときは，文と量の対応表に入れ，同じ水準の幅を決めて判定するか，判定しないと書く．「下端 > 0」の規則だけでは否定の文を判定できない（DAI-14 の関門 1）．
- **D25**　学び直した識別器と目標の一致を「再現できる」と読むときは，学び直す前の出発点と目標の一致を並べ，その差を「取り込めた分」として分ける（DAI-14 の関門 1）．
