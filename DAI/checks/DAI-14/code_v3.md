## 指摘

### [R1] H1：探針の確率を真の目標だけで保存するので，確率の一致で測った D を後から出せない
- 重さ：止める（直すのは 1 行の条件で，費用はほぼ無い）
- 該当箇所：`DAI/exp/dai14.py:455`（`if K == K_MAIN and split == "main" and ver == "true" and info.get("prob") is not None:`），設計 6 節の保存の一覧（「交差の予測の確率（K = 5，元の分け方，真の目標，R0・R1．float16）」）
- 問題：R は argmax の一致で測る．確率の一致（目標の判定に探針が置く確率の平均，交差エントロピーなど）で同じ向きかを問われたとき，R（P1・P2）は保存の `prob__*` から出せるが，D ＝ R − R_shufcl（P3・P4a・P4b）は #shufcl の目標で学んだ探針の確率が要り，保存に無い．第 2 版の G4 は「真と #shufcl」を求めていた．確率は `fit_r0`（`dai14.py:296`）と `fit_r1_multi`（`dai14.py:387`）で全版について既に計算しており，捨てているだけである．試しの MELD の 1 単位で確率の保存は 0.72 MB で，#shufcl を足すと 200 単位で約 +150 MB になる．
- 計算の後で直せるか：直せない（探針の学び直しが要る）
- 求める対応：条件を `ver in ("true", "shufcl")` にし，鍵に版の名前を入れる（例：`prob__K5__main__R1__A__single_T__shufcl`）．設計 6 節の一覧も直す．足さないなら，設計 7 節に「確率の一致は R だけを記述として出し，D は argmax の一致だけで測る」と範囲の外を書く．

### [I・S2] H2：R1fixC の数えに MELD の共有の対話の規則が当たらず，R1 との判定の比べ方がそろわない
- 重さ：直してから進む（summary の段だけで直せる）
- 該当箇所：`DAI/exp/dai14.py:703-704`（`if ro == "R1fixC" and (ctrl != "cl" or subset != "all"): continue`），`748-751`
- 問題：R1fixC は subset = all の行だけを作るので，criteria の MELD の規則（共有の対話を除いた版で「上回る」でなければ数えない）が R1fixC では空振りし，MELD を常に全体の判定で数える．R1 では規則が当たるので，MELD で全体だけ「上回る」とき，R1 と R1fixC の数えが C′ と無関係に食い違い，設計 5 節の「C′ の選び方に依る」と誤って書くことになる．試しの summary で R1fixC の行の subset は 4 コーパスとも `all` だけだった．
- 計算の後で直せるか：直せる（格子の予測と `nonshared` は npz にある．`posthoc.py` で計算できることを確かめた）
- 求める対応：MELD では R1fixC にも `subset = nonshared` の行を作る（`cell` に `subset` を渡す）．

### [R3] H3：内側の曲線は 2 つの内側の組の平均だけで，組ごとの値が無い
- 重さ：直してから進む
- 該当箇所：`DAI/exp/dai14.py:366`（`cur = np.array([float(np.mean(ag[(isp, hh, nm, c)])) for c in GRID_C])`）

### [R4・設計 8 節] H4：下端 1e−6 の旗は，調整不足ではなく C′ → 0 の極限に届いた印でありうる
- 重さ：記録する
- 該当箇所：`DAI/exp/dai14.py:779-782`，設計 8 節の 1 行目
- 問題：試しの AFEW では顔の生徒の C′ の 25〜36%，言葉の 25% が 1e−6 に選ばれ，旗（0.25 を超える）が立つ見込みである．ただし AFEW の格子の 1e−6 と 1e−5 の外側の予測は 98.4〜99.3% の発話で同じで，下端で選ばれた 23 個のうち 11 個は 1e−6 と 1e−5 の内側の値が同点だった．罰が強い側では W が感情ごとの重みつきの平均の差の向きに近づき，判定がほぼ変わらなくなる（設計 3 節の説明のとおり）．このため AFEW で格子をさらに下へ広げても判定は 2% 未満の発話でしか変わらない．MELD と MOSEI では 1e−6 と 1e−5 の予測の違いが 6〜12% あるが，下端の割合は 0.11 以下だった．設計 8 節の「名指しで限界に書く」は残るが，限界の文が「読み出しの調整がそろわない」とだけ読めると誤りになる．
- 計算の後で直せるか：直せる（`inner__*` と格子の予測から出せる）
- 求める対応：結果の文で旗の立った組を書くとき，曲線が下端で平らか（1e−6 と 1e−5 の同点の割合）と，1e−6 と 1e−5 の予測が同じ発話の割合を並べる．`assumptions.csv` に列を足すなら summary の段で足せる．

### [I12] H5：summary が r = 0 の `n_alt` が 0 の単位を止めず，候補の数と塊の数を convergence.json に書かない

## 目録に無い種類の不備

- **対照の版の出力をそろえる**：真の目標と入れ替えた目標の差（D）を主の量にする実験では，後から別の一致の測り方（確率，重みつき）で D を作るために，真と対照の両方の版で同じ出力（確率など）を保存する．真の版だけを保存すると，R は出せても D は出せない（DAI-14 の H1）．9.3 節の R に足す案：「R13 差を主の量にするとき，差の両方の項で同じ種類の出力を保存する」．
- **格子の端の旗の読み方**：罰則の格子の強い側の端に選ばれた割合を数えるときは，曲線がその端で平らか（隣の点と同点か）と，隣の点との予測の一致の割合も数える．平らなら極限に届いた印で，調整不足ではない（DAI-14 の H4）．第 2 版で足した R4b の案に添える項目．
