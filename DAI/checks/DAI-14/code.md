## 目録に無い種類の不備

- **探針の比較での能力の差**：「同じ目標を 2 つの特徴の線形の探針で再現できる度合い」を比べるときは，罰則の強さ・特徴の次元・出発点を探針の間でそろえた行を同じ計算に入れる．前の実験の別の目的（K 本で学ぶ）のために選んだ罰則を探針に流用しない（DAI-14 の F1）．9.3 節の I か R に足す案．
- **入れ替えの対照の層**：目標を入れ替えて「感情を通した一致」を取り除く対照は，塊（話者，場面）をまたいで入れ替えると塊の水準の共有を残す．入れ替えの層（感情だけか，感情と塊か）を設計に書き，両方を出すか主張を限る（DAI-14 の F2）．9.3 節の D か R に足す案．
