- 重さ：記録する
- 該当箇所：`DAI/exp/dai14.py:547-548`
  ```
  gap = pf.max(1) - pf[np.arange(len(pk)), pk]                 # 丸めで同点になった発話は許す
  if not (gap <= 1e-3).all():
  ```
- 問題：流して確かめた．float32 では正しい組の gap の最大は 0.0 で，版を取り違えた 432 組の gap の最大は最小でも 0.0026 なので，AFEW の 2 単位では 1e−3 で取り違えを全部見つける．ただし余裕は 2.6 倍しかなく，C′ が下端の識別器が多いコーパス（MOSEI は今回流していない）では，取り違えた組の gap が 1e−3 を下回る可能性を確かめていない．1e−6 にしても正しい組は通る（gap の最大 0.0）．
- 計算の後で直せるか：直せる（取り違えは npz の確率と予測から後で調べられる）
