# E76 の計算の後の解析（ステップ 4）の実装の記録：`exp/analyze_e76.py`

（台本の担当が書いた本文を本体のセッションが保存した．担当の環境では .md の報告ファイルを書けなかった．台本のコミットは 9f569a2．）

`docs/exploratory-analyses.md` の E76 の 2.4 節を実装した．9 節の直しと 10 節の A(HuBERT) の扱いを含み，step2_design.md と食い違うところはこちらに従った．入力は E76 の保存した出力で，計算は CPU で行う．判定の表は値を見ずに当てた．

## 1. 起動

`CUDA_VISIBLE_DEVICES= ./.venv/bin/python exp/analyze_e76.py --out results/e76_analysis`

試しは `--kinds`，`--targets`，`--B` で小さくし，`--allow-dirty` を付ける．

| 引数 | 既定・意味 |
|---|---|
| `--seed` | 76 |
| `--e76` | `results/e76` |
| `--fixc-map` | `results/fixc_map` |
| `--e13` | `results/fixc_analysis/explore_relation/e13_pairs.csv` |
| `--compare-prefix` | `results/compare_`．`explore_compare.load_compare` が固定の場所を読むので，既定以外を渡すと止まる |
| `--out` | `results/e76_analysis`．ファイルがあれば止まる |

起動時の守り：

- import より前に `CUDA_VISIBLE_DEVICES` を空にする（43 行）．BLAS の糸の数は 8 である．
- 台本か読み込む部品にコミットしていない変更があれば止まる（`main`，2004 行〜）．
- E76 の json のコードのハッシュは次の 3 つだけを受け入れる．
  - E76 の本番の 9891f066…
  - `check_rule_finish.json` の `written` にある 17f73131…（AFEW と RAVDESS）と b5b36158…（CREMA-D）
- `check_rule_finish.json` の包み台本を除いたハッシュが E76 の本番と違えば止まる．
- `check_failed` が空でないファイルは，`accepted_existing` か `waived` に載ったもの（MELD，RAVDESS，CREMA-D）だけを受け入れる．
- 設定（反復，K，手，`merged_all_c`，ソースの絞り，C の格子，α の格子，l2）が違えば止まる（`accepted_hashes`・`check_target_meta`，242〜279 行）．
- dry run での受け入れ：A(HuBERT) の 3 ターゲットは包み台本のハッシュ，ほかの 39 ターゲットは E76 の本番のハッシュで通った．

## 3. 節ごとの計算（行番号）

### 2.4.0 共通

- **引き方**（`Draws`，317〜366 行）
  - 1 段目は，コーパスごとに，反復 0〜9 のテストに出た人物の和集合から，人物の数だけ戻して引く（多項）．IEMOCAP の 2 群は同じ人物で同じ重みにする．
  - 2 段目は反復を戻して引き，種類の中のすべてのターゲットで共通にする．
  - あるターゲットで引いた反復がすべて重み 0 になったら，その引き方の 1 段目を全コーパスで引き直す．
- **重みつき UAR**（`rep_engine`・`uar_from_counts`・`accumulate`，369〜446 行）
  - 人物 × 感情の疎な指示行列と，重みの行列との積で計算する．
  - 重みが 0 の感情は平均から除く．
  - 反復の平均は「2 段目の重み × その反復の値が定まるか」で重みをつける．
  - 同じ集計から，全データの値と，人物を 1 人抜いた値も出す．
- **重みつきの d**（`weighted_do`，448〜485 行）：頻度の重みの不偏分散で計算する．
- **区間**（`interval`，525〜551 行）
  - 百分位の 95% 区間を出す．p 値は (数 + 1)/(B + 1) の形で出す．
  - G_eff < 20 のターゲットを含む単位では，`analyze_e79.jk_interval` の t 区間との和集合を取り，p は 2 つのうち大きい方を使う．
  - 1 段目だけの区間（補足）も出す．
- **線形の結合**（`Store.combo`・`Store.ival`，559〜606 行）

### 2.4.1 地図の区間（`section1`，916〜1000 行）

- 利得は ③ − ① の主の規則である．
- Holm の族は 1 つの種類 × 1 つの K の中の組とした．
- K* は「続く最後の K」と「最大の K」の 2 通りで，区間を 5 通り使う．

- 反復 0〜29 の補足の行は地図の CSV から作る（`fixc_gains`，1506 行）．

### 2.4.2 性別と部分集合（`gender_tables`，1018〜1139 行；`subset_tables`，1142〜1170 行；仮面は `run_target`）

- 性別ごとの UAR は，反復 0〜9 のテストの予測をまとめて出す．1 段目は性別の中で人物を引く．

### 2.4.3 ターゲットのみの C の規則（609 行，1226〜1376 行）

- 規則は次の 6 つである：主の規則，仮のターゲットの規則（E76 の csv の `test_uar_C*` を使い，`map.choose_c` で選ぶ），C を固定した 4 本．

### 2.4.4 主張 1 の中心合わせの手（`section4`，1539〜1626 行；点の d・o と切片は `run_target`）

## 5. 曖昧な点と実装した読み

値を見て決めた点は無い．

1. **1 段目の「一緒に引く」**：コーパスごとに層に分けて引き，引き方の番号を種類の中で共有した．E79 の `boot_draws` と同じ読みである．
2. **引き直しの範囲**：あるターゲットで引いた反復がすべて除かれたら，その引き方の 1 段目を全コーパスで引き直す．2 段目は残す．
3. **種類の平均の jackknife**：種類のすべての人物を 1 人ずつ抜く．自由度は，含まれるターゲットの G_eff の最小から取る．和集合は，G_eff < 20 のターゲットを 1 つでも含めば使う．このため，IEMOCAP か MELD を含む種類の平均はすべて和集合になる．
4. **性別の G_eff**：性別ごとに数え，小さい方で和集合を使うか（< 20）と自由度を決めた．重みが 0 になる性別が出る引き方では，1・2 段目を両方引き直した．IEMOCAP-impro は 8 反復が片方の性別だけなので，1 段目だけの引き直しでは決まらない場合がある．
5. **部分集合の判定の単位**：ソースで平均したターゲットの値を使い，種類 × K ごとに判定した．組ごとの行も出す．
6. **転写の正規化**：小文字にし，文字・数字以外と下線を空白に替え，空白をまとめた．
7. **2.4.3 の残差の基準**：F0 は対 × K の |残差| の平均を，max(D の 10%，対 × K の SE の平均 × 2) と比べた．M1 は対の平均の曲線に当て，同じ 10% と，対の平均の d の SE × 2 の大きい方と比べた．種類の判定は，ターゲットを合わせた残差の平均と基準の平均を比べた．ターゲットごとに基準を超えた数も出す．
8. **M1 と M2 の形**：M1 は d = D_s/√(1 + q/K)，M2 は d = a K^b（b は −1〜2 の 3,001 点の格子）とした．K を抜いた予測の対象は，抜いた K の対の平均の d の 2 乗誤差である．「M1・M2 の方が小さい」は，M1 か M2 のどちらかの誤差が F0 より小さいこととした．残差と抜いた予測の判定は主の規則に当てた．
9. **予言した n の q**：規則ごとの E76 の q（D，3 点）を使った．e は E32 と同じく E13 の d ÷ own_d とした．
10. **d・o・s の平均の順序**：反復で平均してから，floor，|o|，橋を計算した．R_d は 6 対の平均の |d| とした．
11. **6 対を同時に直す切片の (a)**：`fit_class_bias` を l2 = 1e−2 で，プールの全ラベルに重みなしで当てた．E75 の項目 6 は，感情をそろえた部分集合と l2 = 0 を使っていた．
12. **l2 = 1e−2 の h4・h5**：保存したずらしを使い，解き直した値との差を検算に記録した．
13. **2.4.1 の「上」が半分未満のターゲット**：K=1 で数えた．
14. **2.4.3 の「正のまま」**：仮のターゲットの規則の K=1 の種類の平均の区間の下端が 0 より上，と読んだ．
15. **α のメタ検証**：E76 の h10 の UAR を使った．「平均で最も高い手」は K=5 と K=10 のそれぞれで選ぶ．
16. **H1，H5，H6 の測り方**：H1 は主の規則で，K = 25・50・全件の割合と，D′/D の中央値で測る．H5 は，① は主の C ですべての K を使い，②・h2 と合わせて，ターゲットごとの中央値の中央値を出す．H6 は K=5 で，② と h2 の両方の組の中央値が 0.2 以下なら成り立つとした．
17. **q の区間**：6 規則 × D・D′ × 3 点・5 点のすべてで出した．
18. **副の区間の ρ**：csv の tgt_only の行の n_test/n_tgt を反復で平均した．
