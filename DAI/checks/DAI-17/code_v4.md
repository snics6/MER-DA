## 目録に無い種類の不備

- **選んだ点が後で決まる出力の保存**：主の比べが「集計の段で選ぶ格子の点」になると，前の段では選ぶ点が分からないので，前の段で特定の点（既定の点）の出力だけを保存すると，主の点の追加の解析ができなくなる（指摘 1）．`docs/methods.md` 9.3 節の R の項に次を足す案：「R14 選ぶ点を集計の段で決める比べでは，前の段で格子の全点について，判定だけでなく後の解析に要る量（確率など）を保存する．既定の点だけを保存しない（DAI-17 の gate-code 第 4 回）」．
- **入れ子の選択の間接の経路**：版 X の選択に c を使った単位が入り，その版を使った単位で別の設定を選ぶと，c のラベルが 2 段を通って c の設定の選択に入る（指摘 5）．9.3 節の S6 に「選んだ版を使う単位でさらに設定を選ぶときは，前の選択に使った単位を遡って評価のコーパスが入らないかを確かめ，入るならその経路を設計に書く」を足す案．
