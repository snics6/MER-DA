## 指摘

### 1. [R13・I9（選びの上乗せ）] C の生徒の設定は，積の疑似ラベルに合わせて同じ単位のテストの UAR で選ばれた値で，積の生徒だけが選びの上乗せを受ける
- 重さ：直してから進む
- 該当箇所：dai17_probe.py:684–687（`cw, cb = sv.teth[(s, K)]`，`pt = sv.fz["select"][f"{s}|{K}|joint|one"]`），設計 3.9 節・4 節 R5・7 節
- 問題：`pt` の ρ と a，`sv.teth` の引き戻しの強さは，実験 1 の選ぶ段が (T，生徒，K) ごとに「T の仮のターゲットの 30 単位の UAR の平均」で選んだ値である（`DAI/docs/実験1_設計.md` 93 行と 193 行．読んだだけ）．この 30 単位は，この下調べの C で比べる単位そのものである．したがって「積の疑似ラベルの生徒」は自分のテストで選んだ設定で学び，`MN_*_sel` の生徒はその設定を借りるだけになる．設計 3.8 節は B で同じ理屈（「`base` だけが選びの上乗せを受ける」）から重みごとの選び直しを主にしたが，3.9 節は「積の疑似ラベルに合わせて選ばれた値」とだけ書き，同じ単位のテストで選んだことを書いていない．R5 の「上回る」は控えめの向きなので誤りにはならないが，「下回る」と「言えない」は，選びの上乗せと区別できない．R5 は本番に進む目安の 12 回を占めるので，計算の後に「疑似ラベルごとに選び直せ」と求められると，C の段を格子つきでやり直すことになる．
- 計算の後で直せるか：直せる（C の段は約 20 分でやり直せる）．ただし主の数えが変わるので，事前に決めた規則として扱えなくなる
- 求める対応：次のどちらかをする．(i) B と同じ形にする：5 つの疑似ラベルのそれぞれで (ρ, a) を `dai1.RHO_GRID` × `dai1.A_GRID` の 12 点で解き（引き戻しの強さは固定のまま），コーパス c を評価するときは c を T にした単位の生徒の UAR の平均で選ぶ（`prod` も同じ手順で選び直す）．`<疑似ラベル>_sel − prod_sel` を主にし，今の固定の設定の差を副に並べる．`prod` の固定の設定の解が実験 1 の提案と一致する検算は残す．(ii) 設計 3.9 節に「生徒の設定は，積の疑似ラベルの生徒について，この下調べと同じ単位のテストの UAR で選ばれた値である」と書き，4 節 R5 の「下回る」の文を「積に合わせて同じ単位で選んだ設定を使った分と区別できなかった」に替える（B の固定の強さの文と同じ形）．

### 2. [I1・設計 3.4 節] `N_eq` の `joint` の答えにも 3 を掛けているが，設計の表は「全部 1」
- 重さ：記録する
- 該当箇所：dai17_probe.py:413（`specs[f"N_eq_c{ci}"] = tuple(x.sum(0) * 3.0 / nE ...)`），設計 3.4 節の表と 102 行
