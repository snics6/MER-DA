## 語の説明（この報告で使う）

- **候補**：仮のターゲット c のうちテスト以外の発話．ラベル無しとして扱う．**K 本**：候補の中で感情ごとに K 本だけラベルを使う発話．**塊**：話者を分ける単位．
- **出所 `pair`**：顔と言葉の K 本だけの分類器の確率の積（音声の情報を含まない）．**`pair_shuf`**：`pair` の確率を，同じ感情の発話の間で 2 つの半分をまたいで入れ替えた対照．**`self`**：音声自身の K 本だけの分類器の確率（手順の雑音の対照）．
- **`lw`**：WavLM-large の 25 個の隠れ状態（標準化したもの）に softmax(α) の重みを掛けて足し，線形の写像で 4 感情の点数にするネット．α（25 個）と線形の写像を，出所の確率を目標にラベル無しで学ぶ．**`final`**：α を添字 24（最終層）だけに固定した同じネット．DAI-12 の `lince` と同じ計算である．
- **主の量 `layers_minus_final`**：候補のうち K 本を除いた発話の上で，本当の感情に対する UAR の差 `lw` − `final`．
- **交差の予測**：候補を話者の塊で 2 つの半分に分け，片方で学んだネットでもう片方を予測すること．**格子の端**：wd（重みの罰則の強さ）と保存点（学習のステップ数）のそれぞれの軸で最小か最大の値が選ばれること．

## 重大な指摘

### [M1] 入れ替えの対照の読み (A)(B)(C) が DAI-12 の規則と違い，「言えない」を「感情を通らない共有を含む」と読む

- 箇所：設計 4.2 節 114 行「読みは DAI-12 の 3 つの場合 (A)(B)(C) と同じ：(A) `pair` が取り戻し，`pair_shuf` も同程度 → 感情を通る分．(B) `pair` が取り戻し，`pair_shuf` は言えない → 感情を通らない共有を含む．(C) `pair` が取り戻さない → …」．1 節 34 行「`pair` との差が「感情を通らない共有（話者・場面）」の分である」．
- 問題：DAI-12 の設計 4.2 節（159 行）の 3 つの場合は，(A) `pair_shuf` も 3 本以上の K で「上回り」，MOSEI・MELD では部分集合（`channel`・`dlgfree`）でも頑健 → 有利な読み，(B) 3 本以上で「上回る」が部分集合で頑健でない → 有利とも不利とも書かない，(C) 「上回る」K が 2 本以下 → 「ラベルを通らない結びつきから出た**疑いがある**」に，検出力の非対称の添え書きを付ける，である．DAI-13 の (A) には数の規則が無く（「同程度」），(B) は DAI-12 の (C) に当たるのに「疑い」でなく「含む」と断定し，部分集合の頑健さが (A) と (B) を分ける条件から消えている．DAI-12 の 3.6 節 121 行は「`pair_shuf` の目標は行ごとの雑音が大きいので上積みが下限 1.0 に届きにくい．`pair_shuf` で「上回る」K が少ないことを，ラベルを通る経路が無いことの証拠にはしない」と明記している．DAI-13 はこの対照をそのまま受け継ぎながら，その注意だけを落としている．この下調べの結論（第 2 段の LoRA に進む根拠があるか）は，取り戻した分が感情を通るかどうかの読みで決まるので，読みの規則の誤りは結論の誤りになる．
- DAI の基準との関係：報告の誤り（証拠の無いところに断定の文が出る）．
- 直し方：4.2 節の (A)(B)(C) を DAI-12 の 159 行の規則（数の条件と部分集合の条件，(C) の「疑い」と検出力の非対称の添え書き）のとおりに書き直し，「`pair` が取り戻さない」は R1 の「言えない」「下回った」の側に戻す．台本 648〜661 行の規則の数え上げに，`pair_shuf` の行の `n_K_up` と部分集合の頑健さの数（655 行の `sub_*_n_K_robust`）から (A)(B)(C) の札を付ける列を足す（DAI-12 の `note_label_route`・`note_shuf_shared`・`note_not_label_route` に当たるもの）．`pair_minus_shuf_gap`（658 行）は記述のまま残してよい．あわせて 1 節 30 行の「これが正なら，最終層に無い感情の情報が中間層にあり，ラベル無しの目標で取り出せる」を，「対照の読みが (A) のときに限る」と条件づけ，「最終層に無い」は「最終層から線形に読めない」と書く（`final` は線形の腕なので，測れるのは線形に読める範囲である．DAI-12 の途中の値「非線形 − 線形は 0.00〜0.30」は 0 節に引けるが，正式な値は DAI-12 の点検の後のものを引く）．

### [M2] 「層の重みをラベル無しで学ぶ」ことの効果を，重みを一様に固定した腕と分けていない．見込み (f) は α がほぼ初期値でも満たされる

- 箇所：設計 0 節 14 行「第 1 段はエンコーダの重みを凍結したまま層の出力の重みつき和の重みだけを学ぶ」，1 節 30 行「層の重みつき和の表現（ラベルを使わず，`pair` を目標に層の重みと線形の写像を学ぶ）から読むと」，4.5 節 136 行「(f) 層の重み：添字 24 の重みは 0.3 未満で，重みの山は中間層（添字 6〜18）にある」．台本 126 行（α の初期値 0 ＝ 一様 1/25）と 146〜156 行（保存点 10・25・…から予測する半分の損失で選ぶ）．
- 問題：`lw` の族は，α が一様のまま（25 層の単純な平均）でも `final` と違う入力を使う．保存点の下端 10 や 25 が選ばれれば，Adam の学習率 10⁻² では α は 0 から 0.1〜0.25 しか動かず，重みは 1/25 ＝ 0.04 の近くに留まる．このとき (1) 主の量が正でも，それは「25 層を平均した特徴が最終層より `pair` を読める」ことであって「ラベル無しの目標で層の重みを**学んだ**」ことの効果ではない．(2) 見込み (f) の「添字 24 の重みは 0.3 未満」は作りの上でほぼ必ず満たされ，「重みの山」の位置は一様に近い 25 個の値の argmax なので雑音である．設計は α の集中（最大 > 0.9，添字 24 > 0.5）と保存点の端を数えるが（3.2 節 71 行，台本 677〜678 行），α が**一様に近い**ことを数える規則と，学ぶ効果を分ける腕が無い．先行研究の報告の 6 節も「学んだ層の重みの大きさを，その層にある感情の情報の量として書くこと」は書けない（Yang ほか 2024 の表 VI：重みと層ごとの成績の順位相関 0.371．https://arxiv.org/abs/2404.09385）としている．
- DAI の基準との関係：主張と証拠の対応（帰属を支える除去実験が無い）．そのまま書くと「層の重みの学習が効いた」の文に根拠が無い．
- 直し方：次のどちらか．(a) α を 1/25 に固定した腕 `unif` を同じ格子・同じ選び方で足す．α が固定なら ψ は 25 層の平均 (n, 1024) に前もって縮められるので，`P12.crossfit_nets(Xp.mean(1), Q, half, Xt.mean(1), 種, 0)` の 1 回で済み，所要は `final` と同じである．`lw − unif`（学ぶ効果）と `unif − final`（平均の効果）を記述として出し，R1 は `lw − final` のまま．(b) 腕を足さないなら，Q1・0 節・4.5 (f) の文から「層の重みを学ぶ」への帰属を外し，「25 層の重みつき和（重みはラベル無しで学ぶ）が最終層を上回るか」とだけ書く．どちらの場合も (f) には，選んだ版の α が一様から離れている単位の割合（例：最大の重み ≥ 2/25，またはエントロピー ≤ log 25 − 0.1．値は `alpha_stats` の `alpha_max`・`alpha_entropy`（台本 230〜234 行）から出せる）を併記し，一様に近い版が過半なら (f) の山の位置は判定しないと 4.3 節に書く．層ごとに情報の場所を言うのは 3.3 節の層ごとの表（1 層ずつのリッジ）から行い，α からは言わない．

## 確かめたこと

### 漏れ（設計 7 節と台本の照合）

- 評価のターゲット T のデータは単位に入らない（`Unit2(D11/"enc2", T, c, srcs, f, r)` は c の発話だけを読み，T はソースの集合から除くためにだけ使う．台本 249・260 行）．
- `lw`・`final` の学習と (wd, 保存点) の選択は出所の確率との損失で行い，ラベルを使わない（台本 146〜156 行の選択は `Qte`（出所の確率）との交差エントロピー）．標準化は候補（K 本を含み，テストを含まない）の統計（285〜286 行）．テストは 2 つの半分のネットの log-softmax の平均の判定を保存するだけ（458〜461 行，407〜410 行）．
- ラベルを使う量は設計 7 節 158 行の列挙と一致する：候補の上の UAR（本当の感情），`pair_shuf` の作成（316〜323 行），Q2・Q3 の全ラベルの分類器（351〜359 行），Q4 の K 本の読み出し（440〜446 行），層ごとの全ラベルのリッジ（368 行）．
- Q3 の α の固定（357〜359 行）：半分 h を予測する α は，`pair` を目標に半分 ≠ h で学んだもの（`alpha_sel[h]`）で，`crossfit_lw` の h の回では半分 ≠ h で W・c を学び半分 h を予測する．α の学習に半分 h のデータは入らない．
- Q4 の読み出し（203〜227 行）：入力は交差の予測の対数確率なので，K 本の行の入力はその行を学習に使っていないネットの出力である．K 本のラベルは顔と言葉の `none` を通して `pair` の目標には入るが，ネットの出力には K 本の行の自分のラベルは入らない．K 本の行と K 本以外の行は入力の作り方が同じで，読み出しの学習側と評価側の入れ替わりは無い．

### `final` が「α を添字 24 に固定した `lw`」と同じ計算であること（設計 3.2 節 69 行）

- 初期値：`train_lw_batched`（台本 122〜124 行）と `dai12_probe._init`（97〜99 行）はどちらも W (B, 1024, 4)・c (B, 4) を ±1/√d の一様分布から，同じ生成器で W → c の順に引く．α は 0（一様）で乱数を使わない．
- 損失：`P12._ce`（Σ Q (−log softmax) ÷ Σ Q）＋ wd/2 × ‖W‖²（α と c は罰しない．台本 143 行，`dai12_probe.py` 121・153 行）．
- 最適化と選択：Adam，学習率 `FIXED_LR` = 10⁻²，全バッチ 500 ステップ，保存点 (10, 25, 50, 100, 200, 300, 400, 500)，予測する半分の損失が最小の保存点を半分ごと・目標ごとに選ぶ，wd は {10⁻⁴, 10⁻², 10⁻¹, 1, 10}（台本 51〜52 行が `dai12_probe` の値を読む）．`crossfit_lw`（164〜200 行）の半分の回し方・種の作り方（`seed * 4 + h * 2`）・固定の版の取り出しは `crossfit_nets`（175〜217 行．学習率は 1 つ）と同じ．
- 違いは乱数の種（[m1]）と，`lw` が `einsum("nld,bl->bnd")` で ψ を作る点だけである．

### 区間と規則

- 種が 1 つのとき：`effect_stats_pool`（`dai12_probe.py` 286〜287 行）は分割の中の種が 1 つなら分散を 0 にする（`if R[f] > 1 else 0.0`）ので `v_seed` は 0 になり NaN にならない．jackknife の枝 `dai1_stats.effect_stats`（168 行）も同じ．設計 2 節 41 行・4.1 節 106 行の添え書きと一致する．
- 3 つの T の平均：`_add`（651〜658 行）は同じ (f, r) の塊ごとの数を足し，`_finish` が T の数で割る．塊の並びが違えば止まる．
- R1 の判定（台本 648〜652 行）：`pair` は `_verdict`（下端 > 0 かつ点推定 ≥ 1.0 が 3 本以上），`self` は `|est| ≤ 0.5` が 4 本すべて，`pair_shuf` は `_verdict` で記述．設計 4.2 節 112〜113 行と一致．部分集合の頑健さは `_robust`（符号が同じ，端が 0 をまたがない，点推定が全体の半分以上）．
- 多重比較：R1 は (c, `pair`) の 4 組だけで，DAI-12 の 60 組より少ない．K は候補を共有するので「3 本以上」は独立な 3 回ではない（DAI-12 4.1 節の注意を受け継ぐ．設計に明記は無いが規則の数は同じ）．

### 集計の鍵の振り分け（台本 546〜561 行）

- 候補の判定の鍵：`pool_{none,teacher,lw,lwfix,final,finalfix,read_lw,read_final}_K…` は 553 行，`pool_lw_lab_fixalpha_K…` は 556 行，`pool_lw_lab_A`・`pool_final_lab_A`・`pool_lw_labfix_A`・`pool_final_labfix_A` は 559 行（K ごとに展開）で拾われ，`lab_pairs`（626〜627 行）と `pairs`（606〜610 行）の鍵の名前と一致する．`pool_half`・`pool_y`・`pool_sub_*`・`pool_layer{l}_*`（int8）はどの枝にも当たらず飛ばされる（層ごとの値は csv から集計する）．テストの判定は `K…` と `labtest_…` の鍵で拾う．
- α の鍵の分解（587 行）：`alpha_lw_K5_A_pair_shuf_h0` → K = 5，出所 `pair_shuf`，半分 0．`alphafix_…` は拾わない．

### 全層の特徴の取り出し（`features/build_audio_layers.py`）

- 25 個の隠れ状態（入力 1 ＋ Transformer 24 層）を `output_hidden_states=True` で取り，最後が `last_hidden_state` と一致することを `torch.equal` で確かめる（59〜60 行）．詰め物を除いた時間方向の平均（61〜65 行）．fp32，評価モード．前処理は `build_audio.py` の `decode`・`normalize` を使う．
- WavLM-large（stable layer norm）では添字 1〜23 の隠れ状態は最終の層正規化を通る前の残差の値で，添字 24 だけが層正規化の後の値である．台本は層ごと・次元ごとに候補の統計で標準化する（285〜286 行）ので，層の間の尺度の違いは主の量に効かない．
- 添字 24 の平均と既存の `X` の差は試走 24 発話で最大 1.66e−5（台帳 214 行．私は値を見ていない）．台本は単位ごとに生の差を測り 10⁻² を超えれば止める（281〜284 行）．

### 比較の公平さと比較相手

- `lw` と `final` は損失・最適化・格子・保存点・選び方・候補の数（40 点）が同じで，違いは α を学ぶかどうかだけ（上）．`lw` の入力 ψ は一様の α では 25 層の平均なので，次元ごとの分散が 1 より小さく，同じ wd でも W への罰則の効き方が違いうる．wd は腕ごとに 5 桁の格子から選ぶので，端の割合（EDGE）が過半でなければ問題にならない．
- 手法を提案しない下調べなので，先行研究の比較相手は要らない（DAI-12 の第 1 回からの判断と同じ）．層の重みつき和は SUPERB 以来の標準の作法で，別のモダリティの凍結したモデルの出力を目標に層の重みを学ぶ形は SpeechCLIP（Shih ほか 2022．https://arxiv.org/abs/2210.00705）にある．設計 0 節 20 行「手法として新しいと書く予定は無い」と合う．
- 後からの指摘への備え：「層を選ぶ効果か平均の効果か」は [M2] の腕を足せば保存した判定から出せる．「最も良い 1 層との比較」は層ごとのリッジの判定（`pool_layer{l}_ridge_K{K}_A_pair`）を保存するので，学び直さずに出せる．感情ごとの内訳は候補とテストの判定と `pool_y`・`test_y` から出せる．
