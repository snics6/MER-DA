## 語の説明（第 1 回に足すもの）

- **`unif`**：層の重み α を 25 層すべて 1/25 に固定した腕．`lw`（α を学ぶ）− `unif` が「層の重みを学んだ」効果，`unif` − `final` が「中間層を一様に足した」効果．
- **入れ子の選択**：半分ごと・目標ごとに，`final` の選んだ版の損失が `lw` の選んだ版の損失以下なら `lw` の版を `final` の版で置き換えること．これで `lw` − `final` は「層の重みを学ぶことを許したときの上積み」になる．
- **v_init**：種が 1 つで区間から抜けた「初期値の揺れ」の代わりの見積もり．`final` は DAI-12 の `lince` と同じ計算を初期値だけ変えて流したものなので，分割ごとの UAR(`final`) − UAR(`lince`₁₂) の分散 ÷ 分割の数を，層の重みの量の差の se² に足す．
- **jackknife の枝**：塊の実効数が 20 未満のコーパス（AFEW・IEMOCAP・MELD）で使う区間の作り方．塊を 1 つずつ外して差を測り直し，その散らばりから se を出し，端は t 分布の分位点 × se で作る（自由度は実効数 − 1）．MOSEI は引き直し（ブートストラップ）の枝で，端は 1.96 × se．

## 重大な指摘

### [M1] v_init を足した後の区間の端を 1.96 × se で作り直しているが，AFEW・IEMOCAP・MELD の元の区間は t 分布の分位点で作られているので，「初期値の揺れを足した」区間が元より狭くなる

- 箇所：台本 `DAI/exp/dai13_probe.py` 818〜822 行
  ```
  Dd["lo_raw"], Dd["hi_raw"], Dd["se_raw"] = Dd["lo"], Dd["hi"], Dd["se"]
  ...
  Dd.loc[adj, "se"] = np.sqrt(Dd.loc[adj, "se_raw"] ** 2 + Dd.loc[adj, "v_init"])
  Dd.loc[adj, "lo"] = Dd.loc[adj, "est"] - 1.96 * Dd.loc[adj, "se"]; Dd.loc[adj, "hi"] = Dd.loc[adj, "est"] + 1.96 * Dd.loc[adj, "se"]
  ```
  設計 4.1 節 145 行「se² に足し，区間を作り直す（`diffs.csv` の `lo`・`hi` は足した後，`lo_raw`・`hi_raw` は足す前）」．
- 問題：候補の上の区間は `P12.effect_stats_pool` が作る．塊の実効数 g_eff が 20 以上（MOSEI）なら引き直しの枝で，端は est ± 1.96 × se である．20 未満（AFEW・IEMOCAP・MELD．設計 4.1 節「塊の jackknife の枝」）なら `dai1_stats.effect_stats` の jackknife の枝に入り，端は **est ± t₀.₉₇₅(df) × se，df = ⌊g_eff⌋ − 1** である（`dai1_stats.py` 215〜218 行）．IEMOCAP は自由度 3（設計 4.4 節 171 行）なので分位点は 3.18 である．台本は足した後の端を一律に 1.96 で作るので，jackknife の枝では足した後の区間が元より狭くなりうる．IEMOCAP で，設計 4.1 節の「判定に届く差の目安 3.9」は 3.18 × se から出た数なので se ≈ 1.23 である．足した後の半幅は 1.96 × √(1.23² + v_init) で，これが 3.9 を超えるのは v_init > 2.5（初期値の揺れの標準偏差が 1.6 ポイント以上）のときだけである．それより小さい v_init では，初期値の揺れを「足した」はずの区間が元より狭くなり，R1 の「取り戻した」「下回った」が出やすくなる．AFEW（目安 2.1）と MELD（目安 1.2）でも，v_init がそれぞれ約 0.2・約 0.1 より小さければ同じことが起きる（同じ計算）．MOSEI だけは元の分位点が 1.96 なので正しく広がる．`p` の列は足す前のままなので，`lo`・`hi` と `p` が食い違う行も出る．
- DAI の基準との関係：報告の誤り（区間の定義が設計の文と逆向きに働く）．R1 の判定が 4 コーパスのうち 3 つで甘くなる．
- 直し方：元の区間の分位点を行ごとに戻して使う．`_diff` の戻りに `df` は無いので，`q = (est − lo_raw) / se_raw`（se_raw > 0 の行）で分位点を復元し，`lo = est − q × se`，`hi = est + q × se` とする（引き直しの枝では q = 1.96，jackknife の枝では t₀.₉₇₅(df) に戻る）．se_raw = 0 の行（同じ判定の 2 行）は q = 1.96 にする．`p` も同じ分位点の分布で作り直すか，`p_raw` に改名して「足した後の p は出さない」と設計 4.1 節に書く．自由度は元のまま使う（v_init の自由度 4 を合わせる Welch 型の補正は入れない．入れないことを 4.1 節に 1 文書く）．`dai12_probe.py` は変えない（DAI-12 の `provenance.json` が参照する部品なので）．直したら gate-code に，人工の `diffs.csv`（jackknife の枝の行と引き直しの枝の行を 1 つずつ）で足した後の半幅が足す前以上になることを確かめさせる．
