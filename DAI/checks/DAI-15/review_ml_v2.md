## 重大な指摘

### [N1] C′ で補正した生徒は，実効の「感情の割合」が 4 等分からずれる．主の差 sel − prop と対照 C1 にこのずれが混ざる

- 箇所：設計 3 節「その目標に合う前向きの表は C′ = 行の正規化(C_λ · diag(w)) …（第 1 版は C_λ をそのまま掛けており，偏りを 2 回直す食い違いがあった）」．設計 7 節 A3「感情ごとの総量をそろえる重みと表が整合する — C′ を使う（3 節）」．台本 `weight_table`，`run_unit` の `opts`．
- 用語：
  - 実効の割合：生徒が学ぶ問の中で，本当の感情がどの割合で現れるかである．UAR（感情ごとの再現率の平均）を目的にするなら，この割合は 4 等分が正しい．提案（補正なし）は，疑似ラベルの総量を 4 等分にそろえるので，実効の割合が 4 等分になる．
  - ロジットの調整：分類器の出力の対数の確率から，実効の割合の対数を引いて，割合の偏りを取り除く標準の操作である（Menon ほか 2021，https://arxiv.org/abs/2007.07314）．
- 問題：
  - 疑似ラベルの感情 j の重み w_j をかけると，本当の感情 i の発話が受ける重みの平均は Σ_k C_ik w_k になる．このため重みをかけた後の集団では，(a) 「本当が i のとき疑似が j」の確率は C′_ij になり（第 2 版の直しはここに合っている），(b) 本当の感情の割合は π′_i ∝ π_i · Σ_k C_ik w_k になる（π は候補の本当の割合）．前向き補正の生徒は (b) の割合のもとでの事後の確率を学ぶ．π′ は C が単位行列のときだけ 4 等分になる．π′ は保存の C′ から π′ = C′⁻ᵀ·(1/4, 1/4, 1/4, 1/4) としても求まる（重みをかけた疑似ラベルの割合が 4 等分であることから出る）．
  - 数値例（selftest の表 Ct：Neutral の 40% が Happy と読まれる）：
    - 候補の本当の割合が 4 等分のとき，π′ = (0.30, 0.20, 0.25, 0.25)．第 1 版の (0.43, 0.07, 0.25, 0.25) より小さいが，0 にはならない．
    - 候補の本当の割合が selftest の 6 項目目と同じ (0.57, 0.15, 0.14, 0.14) のとき，π′ = (0.44, 0.11, 0.22, 0.23)．生徒は Neutral を 4 割強，Happy を 1 割強の割合の問として学ぶ．
    - 対称の表（λ = 1）に C′ を当てると，同じ候補で π′ は λ = 0 と違う値になる（上の偏った割合の例で，selftest の Ĉ からの見積もりは Neutral 0.32，Happy 0.35 前後．λ = 0 は Neutral 0.47，Happy 0.12 前後）．
  - 人工データでの大きさ（selftest の 6 項目目と同じ作り，種 0〜2）：偏った割合では，C′ の生徒の UAR は 89.6〜90.4，同じ生徒の出力に log π′ を引くロジットの調整をすると 90.5〜91.3 で，差は約 +0.9〜1.1 点だった．4 等分の割合では差は −0.2〜0 点だった．人工データは特徴がよく分かれているので，本物のデータ（UAR が 40〜50% 台）では割合の偏りの影響はこれより大きくなりうる（推測）．この大きさは設計 4 節の検出できる差の目安（0.2〜2.2 点）と同じ桁である．
  - 帰結：
    1. 主の差 sel − prop に，「取り違えの補正の効き目」と「実効の割合が 4 等分からずれた効き目」が混ざる．後者は補正に不利な向きに働くことが多いが，向きは Ĉ の形と候補の割合で決まり，いつも不利とは言えない．
    2. C1（λ0 − sym）は「表の非対称な形の情報」を測る量として置かれたが，λ = 0 と λ = 1 で π′ が違うので，形の情報と割合のずれの違いが混ざる．第 1 版の [M1] (b) で「対称の表なら割合のずれが起きない」と書いたのは C をそのまま掛ける場合の話で，C′ を使う第 2 版では対称の表でもずれが起きる．
    3. 設計 5 節の確かめ「Neutral の予測を少ない感情へ移しただけでないか」は，このずれと逆の向き（Neutral を増やす向き）を見落とす．
    4. 設計 A3 の「整合する」は (a) にしか当てはまらず，報告の文として正しくない．
  - selftest の 6 項目目は C′ と C の比較（Neutral の再現率と UAR）だけを確かめ，C′ と補正なし（I）や割合の 4 等分との比較をしていないので，このずれを検出しない．
- DAI の基準との関係：報告の誤り（A3 の「整合する」と C1 の解釈が計算と合わない）．直さずに C1 を「表の非対称な形の情報で上がった」と書けば，主張と証拠の対応の欠陥になる．
- 直し方（設計の文と集計の段で解ける．補正の問を解き直す必要は無い）：
  1. 設計 3 節と A3 を直す：「C′ は条件つきの確率を重みに合わせる．重みをかけた後の本当の感情の割合 π′ = C′⁻ᵀ·(1/4, …) は C′ が単位行列でないとき 4 等分にならず，補正した生徒はこの割合で学ぶ」と書く．
  2. 版ごと・単位ごとに π′ を計算して記録する（保存する `Cw_K*_*` から計算できる．C′ が特異に近く π′ が 0 から 1 の範囲を出る単位は旗を立てて数える．MOSEI で起きやすい）．結果の文に π′ のコーパスごとの範囲を並べる．
  3. ロジットの調整をした版（補正した各版の保存のテストの確率から log π′ を引いて判定し直したもの．I は π′ が 4 等分なので変わらない）を，計算の前に副の版として設計に固定する．保存の `prob_K*` と `Cw_K*` から集計の段で作れるので，学び直しは要らない．少なくとも次の 2 つを予め決める．
     - C1 の量をどちらにするか．推すのは，調整した版どうしの差（λ0_adj − sym_adj）を C1 の主にすること．そうしないなら，C1 の文を「表の形の違い（実効の割合の違いを含む）で上がった」に弱める．
     - H1 の主の量は sel − prop のままでよい（「この手順と提案の比較」としては正しい）．ただし結果の文に sel_adj − prop を並べ，「補正の効き目のうち割合のずれで打ち消された分」の目安として書くと予め決める．選ぶ段の候補は変えなくてよい（変えるなら仮のターゲットの回の出力から同じく作れる）．
  4. 設計 5 節の確かめを「予測の割合が，Neutral に寄る向きと少ない感情に寄る向きのどちらにずれたか」の両向きに直す（`per_emotion.csv` の `pred_share` で出せる）．
  5. selftest の 6 項目目に，C′ の π′ が 4 等分でないことと，調整した版の UAR が調整しない版を下回らないこと（偏った割合のとき）を確かめる項目を足すと，集計の段の調整の実装の検算になる．

## 軽微な指摘

- [m1] H3 の帰し方：「oracle − I が上回り，かつ sel − prop が上回らないときだけ『K 本の表の推定の不足』と書く」は，後半が「上回らない」（判定できないを含む）なので，前回の [M3] と同じく検出力の不足だけでも成り立つ．MOSEI は検出できる差が最も小さいコーパス（0.2〜0.35 点）なので実害は小さいが，CONTRASTS に oracle − λ0（または oracle − sel）を足し，「それが上回る」ことも条件にすると，推定の不足に帰す根拠が直接の比較になる．保存の判定から集計の段で出せる．
- [m2] 交差の推定の表の対角の平均が 0.25 以下の単位では λ の版が単位行列になり，sel はその単位で I と同じ判定になる（提案ではなく I）．I と提案の重みの差は小さい（試しで最大 5.1e-5）ので数値の影響は無視できる見込みだが，選ばれた版の内訳と一緒に，補正しなかった単位の数（`_table` の行の `skip`）をセルごとに並べると書いておくとよい．
- [m3] `provenance` の `frozen_sha256` は置き場によらず本番の `DAI/frozen/dai15_frozen.json` を読む．試しの置き場では `frozen_path(out)` を読むようにすると記録が正しくなる（本番には影響しない）．
- [m4] 検算の許し `CHECK_W = 1e-2` は，試しで見た最大 5.1e-5 の約 200 倍である．止まらなくても判定が入れ替わる単位が出うるので，結果の文に入れ替わった発話の数の最大と I − prop の区間を並べると設計に書いておくとよい（記録は台本にある）．
- [m5] H1 が外れたときの 3 通りの文で，「下回る」と「上回る」が両方あるコーパスの組み合わせのときは 1 と 3 の両方の文を書く，と一言足すと書き方が一意になる．

## 確かめたこと

- **差分の範囲**：台本の差分は，`weight_table` の追加，`fit_glc` の log-sum-exp 化（`S.DT` は float64 なので，単位行列の 0 の成分を 1e-300 で切った対数 −690 は有限で，勾配に NaN を生まない），疑似ラベルのモデルの作り直しの収束と組ごとの UAR の記録，`naive` と `oracle` の版を両方の回で解くこと，`kd_one` の相手，確率と目的関数の値の保存，検算の重みの差への切り替え，`frozen_path` と `--allow-partial`，感情ごとの割合と再現率の集計，selftest の 6 項目目，記録の追加である．本番の経路を壊す変更は見つからなかった（[N1] は直しの式の性質で，実装の誤りではない）．
- **w の一致**：`run_unit` の `w = 1 / Q.sum(0)` は，同じ Q を `soft_rows(Q, ρn)` に渡す列の正規化と同じ倍率である（全体の倍率の違いは行の正規化で消える）．`weight_table(np.eye(4), w)` は単位行列になる（selftest）．
- **温度つき蒸留の相手 `kd_one`**：実験 1 の固定のファイルに，4 コーパスとも `<生徒>|<K>|kd|one` の鍵が 20 個ずつあり，項目は `temp`・`rho`・`pseudo_uar` である（値は見ていない）．実験 1 で仮のターゲットの回で選んだ設定を使うので，調整の予算は提案と同じ手順である．
- **sel の当て方**：`stage_summary` の `key["sel"]` は，補正しないなら `prop`，λ を選んだなら `0.0`・`0.5`（`run_unit` の版の名前と一致）を指す．
- **漏れ**：版の追加（naive，oracle を仮のターゲットでも解く）は選ぶ候補を変えない（`stage_select` は I・0.0・0.5・1.0 の行だけを使う）．oracle は候補の本当のラベルを使うが，仮のターゲットの回では評価に使わないソースのコーパスのラベルで，評価の回では選ばない参照である．選ぶ段の値を評価の段の後まで開かない取り決め（設計 2・8 節）と，表示しない台本（`stage_select` の print）が一致している．台帳の第 2 版の試しの記録は，見た量を検算の量と行数に限っている．
- **統計**：区間の作り（`dai14.combo_stats`）と予言の規則は第 1 版から変わらず，同じ単位の 2 つの版の差を対応のある比較で計算する．H1 と H3 が MOSEI の声のセルを共有することは設計 5 節に書かれた．
- **再現性**：python・pandas の版，定数（`MAX_ITER`，`SEL_OPTS`，`D_MIN`，`CHECK_*`，同点の扱い，乱数の種）が記録に入った．本番では `--allow-partial` を拒む．
- **人工データの計算**（[N1] の根拠）：selftest の Ct と同じ表，n = 6000，特徴は感情の one-hot × 2 にノイズ 0.8，疑似ラベルは Ct で混ぜた硬いラベルを 0.9 + 0.025 でならしたもの，引き戻し 100，K 本の項なし，種 0〜2．Ĉ は全部の候補で数えた表．π′ の解析の式の値は種によらず上の数値例と一致した．
