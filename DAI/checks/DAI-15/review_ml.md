## 重大な指摘

### [M1] 総量そろえと前向き補正を組み合わせると，生徒が学ぶ感情の割合が一様でなくなる

- 箇所：`DAI/docs/実験15_設計.md` 3 節「目的関数：[ K 本の項 … ＋ 疑似ラベルの項 Σ soft_rows(q, ρn)·(−log p̃) … ]」．台本 `dai15.py` 202 行 `GQ = S.soft_rows(Q, dai1.mval(rho, u.n))`．
- 用語：
  - 総量そろえ（`soft_rows` の `balance=True`）は，疑似ラベルの確率を感情ごとの列の和で割り，どの感情の疑似ラベルも合計の重みが同じになるようにする操作である（`dai_solver.py` 54 行）．
  - 前向き補正は，生徒の確率 p に取り違えの表を掛けた p̃ = Cᵀp（「この生徒の判断を，取り違える癖のある疑似ラベルのモデルが出したらこう見える」という確率）を疑似ラベルに合わせる操作である．
- 問題：
  - 提案（C = 単位行列）では，総量そろえは「疑似ラベルの空間で感情の割合を 4 等分にする」ことであり，生徒の空間でも割合を 4 等分にすることと同じになる．UAR（感情ごとの再現率の平均）を目的にするので，これは目的に合っている．
  - 前向き補正を入れると，2 つの空間は一致しなくなる．疑似ラベルの空間で割合を 4 等分にそろえた目標に Cᵀp を合わせると，生徒の確率の平均 p̄ は Cᵀp̄ = (1/4, 1/4, 1/4, 1/4) を満たす向きに動く．つまり p̄ = C⁻ᵀ·(1/4, …) になり，一様にならない．
  - 数値例：台本の selftest の 4 項目目の表（Neutral が Happy に 40% 取り違えられる表．`dai15.py` 382 行）で計算すると，本当の感情が 4 等分のときの疑似ラベルの割合は (0.16, 0.34, 0.25, 0.25) である．逆に疑似ラベルの割合を 4 等分にそろえると，生徒に求める割合は (0.43, 0.07, 0.25, 0.25) になる．Neutral を 4 割，Happy を 1 割未満と予測するように生徒を押すことになる．
  - 補正は「Happy の疑似ラベルの一部は本当は Neutral」と差し引き，総量そろえはそれとは別に「疑似ラベルの Neutral が少ないので Neutral の重みを上げる」と差し引く．同じ取り違えを 2 回差し引くことになる．
  - 帰結は 2 つある．(a) sel − prop の差に，取り違えの補正の効き目と，この割合のずれの効き目が混ざる．補正が正しくても割合のずれで UAR が下がりうる．(b) 対称の表（λ = 1）は行の和も列の和も 1 なので Cᵀ·(1/4, …) = (1/4, …) となり，割合のずれが起きない．λ = 0，0.5 の表では起きる．このため C1（sel − sym）の差は「取り違えの向きの情報」と「割合のずれ」を分けられない．
  - selftest の 4 項目目は `balance=False` で解いているので（385 行），本番の経路のこの性質を確かめていない．
- DAI の基準との関係：根本的な欠陥（主の量 sel − prop と対照 C1 が，設計の言う「取り違えを打ち消す補正」を測らない）．台本の 1 か所を直せば解ける．
- 直し方：
  - 版ごとに，疑似ラベルの列の総量の目標を一様ではなく C_λᵀ·(1/4, 1/4, 1/4, 1/4) に比例させる．具体的には，Q を列の和で割った後に列 j へ (C_λᵀ·(1/4, …))_j を掛け，全体を ρn に合わせる．C = 単位行列と対称の表では目標が 4 等分のままなので，提案との一致の検算（設計 3 節）と λ = 1 の対照はそのまま残る．
  - 設計 3 節に，総量そろえと補正の順番と，この式を書く．
  - selftest に，`balance=True` の経路で補正した生徒の予測の割合が 4 等分に近いこと（あるいは直さない版で上の数値例のずれが出ること）を確かめる項目を足す．
  - 設計の選択として今の目的関数を残すなら，その理由と，割合のずれを分けて測る量（生徒のテストの予測の感情ごとの割合）を保存・報告する計画を書く．ただし C1 の解釈は成り立たなくなる．

### [M2] 「補正しない」が選ばれたときの比較の相手が，設計と台本で違う

- 箇所：設計 5 節「選ばれた版が「補正しない」なら sel − prop は 0 で」．設計 3 節「保存の提案のテストの UAR と 0.001 点を超えて違えば止める」．台本 329 行 `key = {**VERS, "sel": ("I" if opt == "off" else opt)}`，56 行 `CHECK_PROP = 5e-3`，217〜219 行．
- 問題：
  - 台本は「補正しない」を，同じ問を別の解き方（`fit_glc`）で解き直した版 `I` で表す．`I` と保存の提案 `prop` は，テストの判定が最大で 0.5% 違ってよいことになっている（コミット cd39b90 で「UAR の差 0.001 点」から「判定の入れ替わりの割合 0.5%」に緩めた）．したがって「補正しない」が選ばれたセルでも sel − prop は 0 にならない．設計 5 節の文は台本と合わない．
  - 設計 3 節の検算の基準（0.001 点）も，台本の基準（判定の 0.5%）と合わない．緩めた理由（同じ凸の問を別の手順で解くと境目の発話の判定が入れ替わる）も設計と台帳に書かれていない．
  - λ を選んだセルでは，sel − prop に「補正の効き目」と「解き方の違い」が混ざる．解き方の違いは小さい見込みだが，区間が狭いコーパスでは判定に影響しうる．
- DAI の基準との関係：報告の誤り（設計の文と計算が一致しない）．
- 直し方（どちらか 1 つに決めて設計と台本をそろえる）：
  - (a) 補正の効き目を測る比較は，同じ解き方の `I` を基準にする（sel − I，λ − I，sym − I）．`I` − prop を解き方の違いとして別に報告する．「補正しない」が選ばれたセルは sel − I がちょうど 0 になる．
  - (b) 「補正しない」が選ばれたセルは sel に `prop` を当てる（329 行の `"I"` を `"prop"` にする）．λ を選んだセルの解き方の違いは，`_I_vs_prop_frac` と I − prop の区間で上限を示す．
  - どちらでも，設計 3 節の検算の基準を台本の値（判定の 0.5%）に直し，緩めた理由と，緩める前に何を見たか（試走で見た量が UAR の差だけか）を台帳 `docs/seen-data.md` に書く．

### [M3] 「上回らない」ことを当てる予言（H2，H4）と外れたときの文が，検出力の低さだけでも成り立つ

- 箇所：設計 5 節の H2「顔と言葉の分類器の sel − prop がそれぞれ 4 コーパスで上回るが 1 以下」，H4「MOSEI の 4 つの分類器の sel − prop が 4 つとも上回らない」，「H2〜H4 は当たり外れをそのまま書き，分析の予言の確かめとして扱う」，「外れれば「補正は提案を上回らなかった」と書き」．
- 問題：
  - 前回 0 節と 1 節 (4) のとおり，テストの実効の塊は AFEW 15，IEMOCAP 5，MELD 8 で，1〜2 ポイントの差は有意になりにくい．声の得の上限の目安は 0.2〜1.3 ポイントである．
  - このため，補正が顔・言葉・MOSEI で本当に効いても効かなくても，H2 と H4 は高い確率で「当たる」．当たっても，条件 3（自分の特徴で再現できるか）や推定の揺れの説明を支える証拠にならない．これを「予言の確かめ」と書くと，査読者は「証拠が無いことを，無いことの証拠として扱った」と読む．
  - 「補正は提案を上回らなかった」は，区間が 0 をまたぐ（判定できない）場合と，上端 < 0（下回る）場合を区別しない．
- DAI の基準との関係：主張と証拠の対応の欠陥（報告の誤りにつながる）．
- 直し方：
  - H2 と H4 は，「上回らない」だけでは当たりにしない．代わりの説明を退ける量を計算の前に決める．たとえば H2 は，全ラベルの表で補正した版（oracle − prop）が声では上回り顔・言葉では上回らない，という対比で判定する．H4 は，MOSEI で oracle − prop と sel − prop の差（K 本で推したことによる損）が他のコーパスより大きいか，交差の推定の表の単位の間の揺れ（保存する `C_cf` から計算できる）が大きいかで判定する．いずれも保存する出力から出せる．
  - 判定の結果が「判定できない」だけのときは，「予言と矛盾しない」と書き，「確かめた」とは書かないと設計に固定する．
  - 外れたときの文を 3 つに分けて固定する：上回る数が規則に届かず残りが「判定できない」なら「上回るとは言えなかった」，下回るセルがあれば「下回った（コーパス名）」，区間の幅を並べる．

## 確かめたこと

- **評価への漏れ**：取り違えの表 Ĉ は，ターゲットの K 本のラベルと候補の特徴だけで作る（`tables`，`teachers`）．テストの発話は Ĉ にも疑似ラベルのモデルにも使わない．選ぶ段は `dai3.pseudo_units(OUT1, T)` の単位（T を除いた 3 コーパスを仮のターゲットにした単位）の平均だけを使う（`stage_select`）．評価のターゲットの候補のラベルは oracle の表にだけ使い，選ばない参照として並べる．台帳 243 行に設計の前に見たものが書かれている．案が評価の回の解析の後に出たことは設計 0 節と 7 節の限界にある．
- **交差の推定の作り**：K 本を感情ごとに並びの順で 5 組に配り（`kfold_of`．K = 5 なら各組に各感情 1 本），組を抜いた K 本で融合の K 本だけの分類器 → 3 つの学び直し → 積 を作り直す．抜いた K 本の発話は，作り直したモデルにとって「疑似ラベルの目標 F だけを持つ候補」になり，ほかのラベル無しの候補と同じ立場になる．したがって抜いた組の上の疑似ラベルの誤り方は，ラベル無しの候補の上の誤り方の推定として筋が通る．全部の K 本で作り直した場合の検算（10⁻⁴）がある．`teachers` の G の作りは `pass2` の `G = gK(K) + soft_rows(F, n)` と同じである．
- **補正の向き**：`torch.bmm(lp.exp(), Cm)` は p̃_j = Σ_i p_i C_ij で，設計の p̃ = Cᵀp と一致する．GLC の前向き補正の向きである．K 本の項は補正しない（本当のラベルなので正しい）．
- **提案との同じ設定**：ρ と a は実験 1 の固定の `s|K|joint|one` から読む．固定のファイルの主の版は 4 コーパス・全 K で `one` なので，`Saved.prop` が読む版と一致する．出発点と引き戻しも提案と同じ．補正の版は ρ と a を選び直さないので，提案より調整の予算は小さいか同じである（補正の側に不利な向き）．
- **温度つき蒸留の相手**：K = 5・25 の 32 の（T，生徒，K）で，族 3 の相手は `kd`（温度つき蒸留）で，設計 4 節の記述と合う．調整は実験 1 で仮のターゲットで選んだもの．
- **やわらかくする効果の対照**：λ = 1 の表は Ĉ の対角の平均を保ち，非対角を等しくする．選ぶ候補に入れず，sel − sym を C1 で使う．[M1] を直せば，この対照は「平均の当たりは同じで，取り違えの向きの情報だけが無い」版として働く．
- **統計**：区間は実験 1・14 と同じ `dai14.combo_stats`（塊の jackknife または共通の塊の引き直し ＋ 種の項）．差の区間は，同じ単位の 2 つの版の数をまとめて計算する（対応のある比較）．H1 の規則（4 コーパスのうち 3 以上で下端 > 0）は，偶然で当たる確率が小さい．多重比較の補正をしないことは設計 4 節に書かれている．乱数の種は `[20261113, コーパスの番号]` で固定．
