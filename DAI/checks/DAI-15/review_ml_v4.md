## 重大な指摘

### [N3] π′ に負の成分がある単位では，log π′ を引いた版の判定がほぼ全部 1 つの感情になる．その単位がそのまま記録の差に入る

- 箇所：
  - 台本 `lpi_pred`（405〜410 行）「π′ が 0 以下の成分は 1e-6 に切って正規化（旗を返す）」．`pi = np.clip(pi, 1e-6, None); pi = pi / pi.sum()` の後に `log(prob) − log(pi)` の argmax をとる．
  - 台本 `stage_summary` の `lcell`（453〜464 行）．旗 `ok_` が偽でも，その単位の判定を差の計算にそのまま入れる．
  - 設計 3 節 44 行「π′ に 0 以下の成分がある単位の数を添える」．
- 問題：
  - π′ の成分が負のとき，1e-6 に切ると log π′ はその感情だけ約 −13.8 になり，ほかの感情（約 −1.1〜−1.4）より約 12.5 小さい．これを引くと，その感情の対数の確率に約 12.5 が足される．生徒の確率がその感情で 10⁻⁵ 程度より小さい発話でない限り，判定はその感情になる．
  - 人工の確かめ：4 感情の確率（ロジットを正規分布 N(0, 1.5²) から作った 5,000 発話．確率の最小は 1.2 × 10⁻⁴）に，π′ = (0.357, 0.357, 0.357, −0.071) になる表を当てて `lpi_pred` を呼ぶと，判定の割合は (0, 0, 0, 1.00) になった．その単位の UAR は 25%（でたらめと同じ）になる．π′ がすべて正の表では判定の割合は元と同じだった．
  - 台帳によると，第 3 版・第 4 版の試しで π′ が 0〜1 に入った割合は 0.92 だった（oracle の版を含む）．π′ の和は 1 なので，0〜1 の外は負の成分があることと同じである．λ = 0 の版だけの割合は分からないが，K = 5 の表（20 本から 12 個の数を推す）では負の成分が出る単位が少なくないと見込まれる．
  - その単位で sel_lpi − prop と λ0_lpi − I は，補正と無関係な大きな負の値を持ち，コーパスの区間の中心と幅を動かす．記録の差は予言の判定に使わないが，結果の文に「log π′ を引いても上回らなかった（または下回った）」と書くと，その原因は補正ではなく切り方の作りである．
  - 設計 2 節は「選ぶ段から評価の段までの間に，設計・台本・共通の部品・格子・予言の規則を変えない」と決めている．集計の段だけの直しでも，選ぶ段の後に直すと探索の扱いになるので，選ぶ段の前に直す必要がある．
  - あわせて，`lpi_bad` は 2 つの記録の差の間で 0 に戻らない．2 行目（λ0_lpi − I）の `n_pi_nonpos` は 1 行目（sel_lpi − prop）の数を足した値になる（sel が λ = 0 のセルでは同じ単位を 2 回数える）．
- DAI の基準との関係：報告の誤り．記録の版として数値を出すと，作りが生んだ値を補正の性質として読ませる．計算の重い段（pseudo，eval）は変えなくてよいので，根本的な欠陥ではない．
- 直し方（集計の段と設計の文だけで解ける．生徒の学び直しは要らない）：
  1. π′ に 0 以下の成分がある単位は，log π′ を引いた版の差から外す．差の両側（例：sel_lpi と prop）から同じ単位を外して `combo_stats` に渡し，外した単位の数を行に残す．または，切って作った判定を使わずに「その単位では作らない」を明示する．どちらにするかを設計 44 行に書く．
  2. `lpi_bad` を差ごとに 0 に戻す（`for A_, B_ in LPI_CONTRASTS:` の中で数える）．
  3. 外した単位がコーパスの単位の半分を超える場合は，そのコーパスの記録の差を出さない，などの線を計算の前に書く（線の値は設計者が決める）．
