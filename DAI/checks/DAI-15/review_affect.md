# 感情認識の査読者の検査：DAI-15 第 1 版（2026-11-13）
判定：条件つき OK

対象：設計 `DAI/docs/実験15_設計.md`（第 1 版），台本 `DAI/exp/dai15.py`（コミット cd39b90．作業木の版と差分なし），台帳 `docs/seen-data.md` の DAI-15 の行（243 行），採用した主張の骨格 `DAI/docs/主張_採用した説明_2026-11-13.md`．関門の報告（`DAI/checks/DAI-15/`）は，この検査の時点では 1 本も無かった．結果の値（`results/dai15`）は見ていない．本番の計算はしていない．

この実験は，提案の疑似ラベル（3 つのモダリティの分類器の確率の積）が本当の感情 i をどの感情 j と取り違えるかの表 C を K 本の正解で推し，その表で生徒の確率を混ぜてから疑似ラベルに合わせる（Gold Loss Correction の前向き補正．以下 GLC）．感情認識のデータの扱い（話者の分離，ラベルの対応，コーパスの選び方）には新しい欠陥は無い．ただし，感情ごとの件数の偏りに関わる重大な指摘が 1 つある．提案は疑似ラベルを「感情ごとの総量をそろえる」重みで使うが，台本はその重みを入れない表 C で補正する．この食い違いは，Neutral が多い MELD と MOSEI で最も大きくなり，補正が Neutral を予測しなくなる向きに働きうる．もう 1 つは，「補正しない」が選ばれたときの比べ方の誤りである．どちらも設計と台本を直せば解ける．

## 重大な指摘

### [A1] 疑似ラベルの項は感情ごとの総量をそろえてあるのに，補正の表 C はそろえる前の疑似ラベルで数えている．Neutral が多いコーパスで補正が Neutral を消す向きに偏る
- 箇所：
  - 台本 `run_unit`：`GQ = S.soft_rows(Q, dai1.mval(rho, u.n))`．`dai_solver.soft_rows` は既定で `balance=True` で，疑似ラベルの確率 q の列 j を「候補の全体での列 j の和」で割ってから全体を ρn にそろえる（`P = P / P.sum(0)`）．つまり疑似ラベルの項は，疑似の感情 j ごとに重み w_j = 1 /（候補の上の q の列 j の和）を掛けた交差エントロピーである．
  - 同じ関数で，補正の表は `tables` が `table_from(qcf, yk)` で作る．これは重みを掛けない q の行の平均で，Ĉ_ij ≈ P(疑似 = j | 本当 = i) である．`fit_glc` は p̃ = Ĉᵀp をそのまま重みつきの目標に合わせる．
  - 設計 3 節「前向き補正の生徒：生徒の確率 p に C_λ を掛けた p̃ = C_λᵀ p を，疑似ラベルの項の目標に合わせる」．
- 問題：
  - 前向き補正が正しく働くのは，「生徒が当てるべき目標」が「本当の感情の確率に C を掛けたもの」で表せるときである．疑似の感情 j の重みを w_j 倍すると，この関係が崩れる．重みを掛けた後の目標は w_j · Σ_i p*_i C_ij に比例し，これを表に直すと C^w_ij = C_ij w_j / Σ_k C_ik w_k（行ごとに和を 1 にした表）になる．このとき生徒の確率は p*_i · Σ_k C_ik w_k に比例する形に動く．正しい表は C ではなく C^w である．C^w は単位行列なら単位行列のままなので，「C = 単位行列なら提案と同じ」という台本の確かめはこの食い違いを見つけられない（selftest の 4 は `balance=False` で確かめている）．
  - 食い違いの大きさは，疑似ラベルの感情ごとの総量の偏りで決まる．評価の 4 コーパスの感情ごとの件数（`DAI/splits/*.csv` の `label_4` で数えた．3 モダリティがそろう発話の全体）は次のとおりである．Neutral・Happy・Sad・Angry の順．
    - AFEW：205・211・177・197（ほぼ釣り合っている）
    - IEMOCAP（即興）：1,099・947・608・289（Neutral 37%，Angry 10%）
    - MELD：6,383・2,283・999・1,602（Neutral 57%，Sad 9%）
    - MOSEI：8,637・6,734・1,814・1,449（Neutral 46%，Angry 8%）
    疑似ラベルの総量も同じ向きに偏るなら，MELD と MOSEI では w の最大と最小の比が 5〜6 倍になる（疑似ラベルの総量そのものは結果の値なので見ていない）．
  - 例として，作業用の一時の場所で，生徒の確率を発話ごとに自由に動かせる理想の場合を計算した（線形の分類器でも，K 本の項と引き戻しのある実際の問でもない）．感情の割合を MELD に合わせ（57・20・9・14%），Neutral を他の感情と取り違えやすい表 C を置いた．重みの比は 4.4 倍だった．このとき，C で補正した生徒は Neutral を 1 本も予測せず（予測の割合 0・24・56・20%），UAR は補正しないときの 95.1 から 72.5 に下がった．C^w で補正した生徒は Neutral を 59% 予測し，UAR は 89.6 だった．実際の問では K 本の項と引き戻しがあるので下がり方はずっと小さいはずだが，向きは同じで，**Neutral の再現率を下げ Sad や Angry の再現率を上げる向き**に偏る．
  - この偏りは予言の読み方を変える．H4 は「MOSEI は表の推定が揺れるので補正が効かない」と予言するが，MOSEI と MELD で補正が効かなかったときに，表の推定の揺れ（予言の理由）と表の作り方の食い違いを分けられない．「全ラベルの表」の版（oracle）も同じ C で補正するので，oracle − prop が 0 以下でも「全ラベルの表でも上がる余地が無かった」とは言えなくなる．逆に UAR は感情ごとの再現率の平均なので，多数の Neutral を少数の感情へ移すだけで UAR が上がることもあり，そのとき「取り違えを打ち消して上がった」と書くのは誤りになる．
- DAI の基準との関係：根本的な欠陥と報告の誤りの両方に当たりうる．補正の式が，提案の疑似ラベルの項（感情の総量をそろえる重み）と合っていない．感情認識の査読者は，Neutral が過半を占める MELD・MOSEI で補正が Neutral の扱いを変えていないかを最初に確かめる．
- 直し方（設計をやり直す必要は無い．表の変換を 1 つ足し，記録を足す）：
  1. （必須）補正に使う表を C^w にする．w は `soft_rows` が使うのと同じ，候補の全体の上の q（`Q`）の列の和の逆数である．交差の推定 Ĉ を作った後に，縮小 C_λ を作り，それに w を掛けて行ごとに和を 1 にする（縮小と重みの順は設計に書いて固定する）．対称の対照（λ = 1）と全ラベルの表（oracle）にも同じ変換を当てる．単位行列は変わらないので，提案との一致の確かめはそのまま使える．
  2. （必須）selftest に，感情の割合が偏っていて `balance=True` の場合を足す．C^w で補正すると補正しないより当たり，C のままだと当たらないことを確かめる．
  3. （必須）単位ごとに，各版のテストの予測の感情ごとの割合と感情ごとの再現率を保存するか，summary の段で出す（`pred_*` と `y` が保存されるので，後者で足りる）．結果の文では，sel − prop を書くときに，どの感情の再現率が上がりどれが下がったかを並べる．Neutral の再現率が大きく下がって UAR が上がった場合は，「取り違えの補正で上がった」と書かず，「Neutral から他の感情へ予測が移った」と書く．
  4. 設計 3 節と 7 節に，「疑似ラベルの項は感情ごとの総量をそろえてあるので，補正の表はその重みを入れた形にした」と書く．w と C^w は単位ごとに保存する．

### [A2] 「補正しない」が選ばれたセルで，sel は保存の提案ではなく解き直した単位行列の版になる．設計の「sel − prop は 0」と食い違い，数値の誤差で「上回る」が出うる
- 箇所：
  - 設計 5 節「選ばれた版が『補正しない』なら sel − prop は 0 で，そのセルは『上回る』にならない」．
  - 台本 `stage_summary`：`key = {**VERS, "sel": ("I" if opt == "off" else opt)}`．`"I"` は `fit_glc` で単位行列を使って解き直した生徒の予測である．台本は，この予測と保存の提案の予測が違う発話の割合が `CHECK_PROP = 5e-3`（0.5%）以下なら通す．
- 問題：「補正しない」が選ばれたセルでも，sel − prop は 0 にならず，最大でテストの発話の 0.5% の判定の違いが残る．差の区間は，同じ発話の判定どうしの差で作るので，違う発話が少ないと区間が非常に狭くなる．たまたま違う発話の多くが正解の側に動くと，区間の下端が 0 を超えて「上回る」になりうる．このとき H1〜H3 の数えに，補正をしていないセルが「上回る」として入る．λ = 0 や λ = 0.5 と保存の提案の差（lam0 − prop など）にも，解き直しによる違いが同じように混ざる．
- DAI の基準との関係：報告の誤りに当たる．補正の効果ではない差が，予言の判定に数えられうる．
- 直し方（台本の 1 行と設計の 1 文）：
  1. （必須）「補正しない」が選ばれたセルでは，sel を保存の提案（`"prop"`）にする．これで設計 5 節の文と合う．
  2. （勧める）補正の版どうしの比べ方を揃えるため，lam0 − I，lam05 − I，sym − I（解き直した単位行列の版との差）も CONTRASTS に足し，結果の文では prop との差と並べる．設計 3 節の「0.001 点を超えて違えば止める」と台本の「判定が 0.5% を超えて違えば止める」の食い違い（a4）も同時に直す．

## 軽微な指摘

- [a1] 「取り違え」の語と，クラスごとに決まる誤りの仮定：設計 7 節は「クラス条件つきの雑音を仮定した（疑似ラベルの誤り方は本当の感情だけで決まる）」と書く．感情認識では，この仮定が崩れる具体的な理由がコーパスのラベルの決め方にある．限界の節にこの具体例を書く．
  - IEMOCAP の Happy は元のラベルの excited（興奮）と happy を合わせたもの（`data/README.md` 198 行．即興の Happy の 70% が excited であることは DAI-14 の検査で数えた）．声の分類器は覚醒度（興奮の度合い）を手がかりにするので，excited と happy では疑似ラベルの誤り方が違いうる．表 C はその平均だけを持つ．
  - MOSEI の Neutral は「どの感情の強さも 0.5 未満」という消去法で決まる（`data/README.md` 206 行）．Neutral の発話に弱い Happy や弱い Sad が混ざるので，疑似ラベルが Neutral の発話に Happy を付けるのは，分類器の誤りではなく，コーパスのラベルの決め方との違いであることがある．結果の文で表 C の中身を書くときは「疑似ラベルの誤り」と書かず，「疑似ラベルとコーパスのラベルの決め方の食い違い」と書く．
  - 先行研究にも，音声の感情認識でこの仮定（遷移の確率が発話によらない）を限界として挙げたものがある（Mao, Ching, Lee 2021．https://arxiv.org/abs/2103.16456 ）．関連研究の節で引く．
- [a2] 表 C の記述（設計 6 節）は，コーパスごとに感情の対のどこに取り違えが集まるかを書くことになる．感情ごとの表の 1 行は K = 5 では 5 本の発話の平均なので，表の各数値には単位（分割と種）の間のばらつき（例えば 200 単位の 2.5〜97.5% の幅）を付ける．「MELD では Sad が Neutral に取り違えられる」のような感情の対の主張は，幅とともに書く．
- [a3] 交差の推定で抜いた組の疑似ラベルは，K = 5 では感情ごとに 4 本で作り直したモデルのものである．設計 7 節は「わずかに違う」と書くが，K が 5 から 4 に減ると K 本だけの分類器の当たりは下がりうる（ラベルが少ない側ほど K による変化が大きい）．この違いで Ĉ の対角は本当の値（全部の K 本で作った疑似ラベルの誤り方）より小さく出る向きに偏る．台本は 5 つの作り直したモデルの候補の上の確率（`Qs[1:]`）を持っているので，それぞれの候補の上の当たり（K 本を除いた候補の本当のラベルで数えた表の対角の平均）を記録し，全部の K 本で作ったモデルの値と並べる．「わずかに」は記録の数で置き換える．
- [a4] 提案との一致の確かめの基準が，設計 3 節（「テストの UAR と 0.001 点を超えて違えば止める」）と台本（`CHECK_PROP`：判定が違う発話の割合 0.5%）で違う．どちらかに揃える．A2 の 1 を入れれば，この基準は「解き直しが保存と同じ問を解いているか」の確かめだけに使われる．
- [a5] K 本を 5 組に配る規則：`k_orders` が K 本を `sample_id` の順に並べ，`kfold_of` が感情ごとにその順で 0, 1, 2, … と配る．IEMOCAP（候補は 4 セッション・8 人）や MELD（主な登場人物が多い）では，抜いた組の発話と同じ話者の発話が，作り直しに使う組に残る．ラベル無しの候補の発話も同じ割合で K 本の話者と重なるので，これは推定を偏らせる要因にはならないと判断した．MELD で同じ対話の発話が 2 つの組にまたがる場合も，候補の大きさに比べて K 本は 20 本なので影響は小さい．設計 7 節に「K 本の組は話者や対話で分けていない」と 1 文書く．
- [a6] 「全ラベルの表」の版（oracle）を設計 3 節は「上限の参照」と呼ぶ．この表は K 本を除いた候補の本当のラベルで数えた疑似ラベルの誤り方で，テストのラベルは使っていない（台本 `tables` で確かめた）．ただし補正の効果の上限ではない（生徒は線形で，引き戻しもある）．結果の文では「候補の全ラベルで数えた表を使った版」と書き，「上限」と書かない．
- [a7] 引き継ぐ限界：MOSEI の話者の代わり（チャンネルか動画），AFEW の言葉が Whisper large-v3 の書き起こしであること，MELD の複数の人の声と合同発話を落としたこと，IEMOCAP は即興だけであることは，実験 1 の評価の回からそのまま引き継ぐ．DAI-15 で新しく入った扱いは無い．結果の文には，実験 1 の限界の節を参照する 1 文を書く．
- [a8] 先行研究との対応：音声の感情認識で，ラベルを推し直しながら学ぶ研究に Fujioka ほか 2019（https://arxiv.org/abs/1911.02216 ．曖昧なラベルの補正と標本の重みをメタ学習で推す）がある．これらはソースのラベルの雑音を扱い，本実験は別のモダリティの分類器から作った疑似ラベルの誤りを扱う．違いを関連研究の節に 1 文書く．設計 0 節の Albanie ほか 2018 との関係（顔の教師から声の生徒へ移す）は，実験 1 の書き方をそのまま使える．
