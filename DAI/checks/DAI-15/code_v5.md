  ```python
  if n_used < LPI_MIN_SHARE * len(U) or len({f for f, _ in cA_}) < 2:
  ```
- 問題：設計 3 節は「使える単位が半分未満なら，その行は作らない」とだけ書く．後半の条件は設計に無い．本番の単位は 1 コーパス 50（5 分割 × 10 種）で，25 以上を使えば 3 分割以上に入るので，本番の出力は変わらない．試しの置き場（`--allow-partial`）でだけ効く．人工の型で効くこと（2 行）を確かめた．

### [記録-g] 単位を外すと，種の揺れの項が一部の分割で 0 に数えられうる
- 重さ：記録する
- 該当箇所：dai14.py:127–129（`s2 = … if R[f] > 1 else 0.0`）を，dai15.py:473 が単位の部分集合で呼ぶ（読んだだけ）

- 計算の後で直せるか：直せる（npz から分割ごとの使った種の数を数えられる）．
- 求める対応：結果の文で記録の版を書くときに，`n_folds` と，分割ごとに使った種の最小の数を添える．

### [記録-h] 教師の判定し直しの特異の旗を，summary の行に数として出さない
