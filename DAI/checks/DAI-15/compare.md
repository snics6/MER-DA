## 指摘

### [C11・C10] 予言 H2・H4 は，補正がどの分類器でも効かない場合にも「当たり」になり，条件 3 や推定の揺れの証拠として読めない
- 重さ：直してから進む
- 該当箇所：`DAI/docs/実験15_設計.md:49`，`:51`，`:55`
- 問題：H2 は「顔と言葉の sel − prop が 4 コーパスで上回るが 1 以下」，H4 は「MOSEI の 4 つの分類器の sel − prop が 4 つとも上回らない」である．55 行は「H2〜H4 は当たり外れをそのまま書き，分析の予言の確かめとして扱う」と書く．補正がすべての分類器で効かなければ（例えば表の推定が K = 5 で揺れすぎるだけでも），H1 は外れ，H2 と H4 は当たる．このとき H2 の当たりは「条件 3 が欠けるから」と，H4 の当たりは「MOSEI で推定が揺れるから」と区別できない．目録 C11（対照で効果が出ないことを部品の寄与の証拠にしない）と C10（帰せるかどうかの規則は共有するものと欠くものの表から導く）に当たる．設計は全ラベルの表の版（`oracle`）を持っており，これを使えば区別できる．条件 3 の予言は「全ラベルの表で直しても，まねできない分類器では上がらない」なので，推定の揺れを含まない `oracle − prop` で判定するのが予言の形に合う．推定の揺れの予言（H4）は「全ラベルの表なら上がるが，K 本の表では上がらない」なので，`oracle − prop` と `sel − prop` の組で判定するのが形に合う．
- 計算の後で直せるか：計算はやり直さずに直せる（全部の版のテストの判定を単位ごとに保存する．`dai15.py:221-227`）．ただし判定の規則を評価の回の値を見た後に替えると後付けになるので，評価の回の前に直す必要がある．
- 求める対応：(1) H2 を「顔と言葉で oracle − prop が上回るコーパスが 1 以下，かつ声で oracle − prop が上回る」のように，`oracle` の版で書き直すか，H2 の当たりを「H1 が当たったときだけ条件 3 の証拠として読む」と条件づける．(2) H4 を「MOSEI で oracle − prop が上回り，sel − prop が上回らない分類器の数」として書き直す．oracle − prop も上回らないなら「余地が無い」と書き，推定の揺れには帰さない．(3) 設計 5 節に「H1 が外れたとき H2・H4 の当たりは分析の確かめとして数えない」を足す．

### [C10・C2] 対照 C1（sel − sym）は，選び方の違い（sel は「補正しない」に戻れ，sym は戻れない）を取り違えの向きの情報と取り違える
- 重さ：直してから進む
- 該当箇所：`DAI/docs/実験15_設計.md:33-34`，`:52`；`DAI/exp/dai15.py:51`，`:290-292`，`:302-303`
- 問題：sel は仮のターゲットで {補正しない，λ = 0，λ = 0.5} の 3 つから選び（`SEL_OPTS = ("off", "0.0", "0.5")`），sym（λ = 1）は選ばずに常に当てる．sym があるコーパスで提案より下がるなら，sel はそのコーパスで「補正しない」か λ = 0.5 を選べるので，sel − sym は向きの情報が無くても正になりうる．また λ = 0.5 は対称の表を半分含む．したがって「C1 の上回るが 3 以上なら取り違えの向きの情報で上がった」（52 行）は，候補の数と選び方の差を向きの情報に帰す規則になっている．向きの情報だけが違う比べは，どちらも選ばない `lam0 − sym` である（同じ q，同じ ρ・a・引き戻し，同じ対角の平均 d̄ で，非対角の形だけが違う）．しかし `CONTRASTS`（`dai15.py:302-303`）に `("lam0", "sym")` は無い．
- 計算の後で直せるか：計算はやり直さずに直せる（全部の版の判定を保存する）．規則は評価の回の前に直す必要がある．
- 求める対応：(1) C1 の判定量を `lam0 − sym`（と `lam05 − sym`）にし，`CONTRASTS` に足す．(2) sel と比べたいなら，sym にも同じ規則で「補正しない／λ = 1」を仮のターゲットで選ばせた版（sym_sel）を `select` の段で作り，`sel − sym_sel` を並べる．(3) 設計 52 行の書き方を「向きの情報で上がった」の前提として「lam0 − sym が上回る」を要件にする．

### [C8] 設計の「補正しないを選べば sel − prop は 0」と台本が食い違い，ソルバーの違いが H1 の数え上げに入りうる
- 重さ：直してから進む
- 該当箇所：`DAI/docs/実験15_設計.md:32`，`:54`；`DAI/exp/dai15.py:56`，`:217-219`，`:329`
- 問題：設計 54 行は「選ばれた版が『補正しない』なら sel − prop は 0 で，そのセルは『上回る』にならない」と書く．台本は「補正しない」を選んだセルで sel に再計算の版 `I` を当てる（`key = {**VERS, "sel": ("I" if opt == "off" else opt)}`，329 行）．`I` は保存の提案と同じ凸の問を別のソルバー（`fit_glc`，TOL = 1e-6）で解いたもので，テストの判定が最大 0.5% 違ってよい（`CHECK_PROP = 5e-3`，56 行）．設計 32 行の「UAR が 0.001 点を超えて違えば止める」もコミット cd39b90 で判定の入れ替わりの割合に替わり，設計の文と台本が食い違う．ソルバーの収束の差が単位をまたいで同じ向きに出ると，判定の入れ替わりは少数でも区間が狭くなり，「補正しない」のセルが「上回る」か「下回る」に数えられうる（推測．大きさは計算していない）．補正の版（λ = 0，0.5）は `I` と同じソルバー・同じ問の束で解くので，補正の効果だけを測る比べは `sel − I` である．

### [C1・C8] 補正の版が受け取る目標（感情ごとに総量をそろえた q）と，表 Ĉ を推した q（そろえない q）が合っておらず，比べる版は GLC の前向き補正そのものではない
- 重さ：直してから進む
- 該当箇所：`DAI/exp/dai15.py:202`（`GQ = S.soft_rows(Q, ...)`），`DAI/exp/dai_solver.py:53-55`（`balance=True` で列を列の和で割る），`DAI/exp/dai15.py:169-175`（表は割る前の Q から作る），`DAI/docs/実験15_設計.md:7`，`:56`
- 問題：疑似ラベルの項の目標は，q の各列を列の和 π̂_j で割った重み q_j / π̂_j である．表 Ĉ は割る前の q から作る．GLC の仮定（q = Cᵀp*）の下では，目標は normalize(D⁻¹Cᵀp*)（D = diag(π̂)）になり，前向きの補正をした生徒は Cᵀp ∝ D⁻¹Cᵀp* を解く．これは p* にも，感情ごとに釣り合わせた p*/π にも一致しない（C = 単位行列か π̂ が一様のときだけ一致する）．したがって sel・λ・sym・oracle の版は「感情ごとに総量をそろえた目標に GLC の表を当てた版」であり，設計 7・56 行の「手順は GLC」と一致しない．oracle も「GLC の上限の参照」にはならない．π̂ の偏りが大きいコーパス（MELD の Neutral，MOSEI の Happy など）でずれが大きいと推測する（大きさは計算していない）．自己検査 4（`dai15.py:378-391`）は `balance=False` で確かめており，台本が実際に使う `balance=True` の場合を確かめていない．
- 計算の後で直せるか：直せるが計算をやり直す（生徒を解き直す）．
- 求める対応：次のどちらかを評価の回の前に決める．(a) 表を目標に合わせる（例：Ĉ′ = 行を正規化した Ĉ D⁻¹）か，釣り合いを本当の感情の側の重みとして掛け直す．(b) 今の形を保つなら，設計に「感情ごとに総量をそろえた目標への前向きの補正（GLC の変形）」と書き，GLC と同じとは書かない．どちらでも，π̂ を偏らせた合成データで `balance=True` の自己検査を足し，補正で取り違えが戻ることを確かめる．（式の定義の問題でもあるので，gate-define の判断と照らし合わせてほしい．）

### [C10] λ = 1 の対照は平滑化の対照ではなく，目標を鋭くする対照である．「平滑化との切り分け」という呼び方を直す
- 重さ：記録する
- 該当箇所：`DAI/docs/実験15_設計.md:34`，`:52`
- 問題：S(Ĉ) = a·I + b·11ᵀ（a = (4d̄ − 1)/3，b = (1 − d̄)/3）なので，前向きの補正は p̃ = a·p + b·1 になる．生徒は p̃ を目標に合わせるので，p は目標より鋭く（確率の最大が大きく）なる．これは平滑化（目標を一様に近づける操作．Lukasik ほか 2020）の逆の向きである．また Ĉ_ii は「本当の感情 i の発話での q_i の平均」なので，argmax がすべて当たっていても q が柔らかければ 1 より小さい．Ĉ の非対角には，誤り（argmax の取り違え）と q の柔らかい広がりの両方が入る．したがって lam0 − sym が正でも，言えるのは「表の非対称な形（取り違えと確率の広がりの両方）の情報で上がった」までであり，「argmax の取り違えを直した」とは言えない．平滑化（温度で柔らかくする）の比べは，温度 {1, 2, 4} を選んだ温度つき蒸留との差 `sel − kd` が受け持つ．
- 計算の後で直せるか：直せる（書き方だけ）．
- 求める対応：設計 5 節の C1 の見出しを「向きの無い一様な補正（目標を鋭くする）との切り分け」に替える．結果の文では Ĉ の意味を「本当の感情ごとの疑似ラベルの確率の平均（取り違えと広がりを含む）」と書く．

### [C16・C5] 補正の版は提案の (ρ, a) と引き戻しを流用し，選び直していない．λ の選び方も実験 1 の規則（δ_sel の幅で既定に寄せる）と違う

### [C4] 雑音のあるラベルの補正と「ラベル無しの例での蒸留」の標準の比べる相手のうち，入っていないものを限界に書き，否定の結論を GLC の前向き補正に限る
- 重さ：記録する
- 該当箇所：`DAI/docs/実験15_設計.md:7`，`:55`，`:65-71`
- 問題：設計 7 節と先行研究の差分から，この実験の主張の種類は「少数の正しいラベルで教師の誤り方を推して蒸留を直す（雑音のあるラベルの補正）」を既知の手法として当て，分析の予言を確かめることである．新しい手法の優越は主張しない．この種類の標準の相手を原典で確かめた．
  - GLC（Hendrycks ほか 2018，arXiv 1802.05300，本文の 4.2・4.3 節を pdftotext で読んだ．◎）：正しいデータだけ，補正しない，Forward（Patrini ほか 2017．正しいラベルを使わずに表を推す），Forward Gold，Distillation（Li ほか 2017），Confusion Matrix（硬い混同行列）．
  - SLaM（Kontonis ほか 2023，arXiv 2302.03806，本文の 4.2 節と表 1 を読んだ．◎）：Vanilla，Taylor-CE，UPS，VID，Weighted（Iliopoulos ほか 2022）．
  - DAI-15 にあるのは，正しいデータだけ（`none`），補正しない（`prop`，`I`），温度つき蒸留（`kd`），向きの無い補正（`sym`），全ラベルの表（`oracle`）である．Forward（正しいラベルを使わない表），硬い混同行列の表，例ごとの補正（SLaM・Weighted），頑健な損失（Taylor-CE）は無い．
  - H1〜H4 は「この補正がどの分類器で効くか」という分析の予言なので，SLaM などとの優劣の比べは予言の判定に要らない．GLC の形は介入そのものなので，別の比べる相手としては要らない．ただし H1 が外れたときに「補正は提案を上回らなかった」（55 行）と書くと，読み手は「補正という介入全般が効かない」と読みうる．SLaM の著者は，ラベル無しの例での蒸留では教師の誤りが例ごとに違い，クラスごとの遷移行列は合わないと書いている（差分の報告 2.2 節）．外れの原因が条件 3 か，クラスごとの表という雑音の模型かを，この設計は分けられない．
