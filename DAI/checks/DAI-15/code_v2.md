### [R5′] C′ は補正した生徒の実効の感情の割合を提案と変える．sel − prop は雑音の補正と感情の割合の変化を含む

- 該当箇所：dai15.py:100–103，205，215（読んで式を確かめた．合成の表で数値を出した）
- 問題：提案の疑似ラベルの項の重みつきの分布は，本当の感情 i と疑似ラベル j の組に π_i C_ij w_j の重みを置く．C′_ij = C_ij w_j / r_i（r_i = Σ_k C_ik w_k）はこの重みつきの分布の P(疑似 = j | 本当 = i) で，前向き補正の表として正しい．ただし，その最小化の解は p_i ∝ r_i P(本当 = i | x) で，生徒の実効の感情の割合は π_i r_i に比例し，等分にはならない．提案（C = I）は疑似ラベルの空間で等分になる．selftest 4 の取り違えの表と，感情の割合 (0.57, 0.15, 0.14, 0.14) では，π_i r_i を平均 1 にそろえた値が (1.76, 0.44, 0.88, 0.92) になり，等分 (0.25 ずつ) でも (1.20, 0.79, 1.00, 1.01) になる（合成の数）．UAR は感情の割合の傾きに敏感なので，sel − prop の差は雑音の補正だけでなく生徒の事前の割合の変化も含む．設計 5 節は Neutral を少ない感情へ移した場合だけを確かめると書くが，向きは Neutral へ寄せる場合もある．
- 計算の後で直せるか：直せる．保存した確率・`C_cf`・`w` と候補の感情の数から，r_i π_i で割り戻した判定の UAR を CPU で出せる（B の表）．
