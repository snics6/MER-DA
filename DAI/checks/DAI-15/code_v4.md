## 指摘

### [I-lpi] 記録の版 lpi は，π′ に 0 以下の成分がある単位で判定のほぼすべてを切った成分の感情に寄せる
- 重さ：直してから進む
- 該当箇所：dai15.py:405–410
  ```python
  pi = np.linalg.solve(a[f"Cw_K{K}_{opt}"].T, np.full(4, 0.25))
  ok = bool(np.all(pi > 0))
  pi = np.clip(pi, 1e-6, None); pi = pi / pi.sum()
  return (np.log(np.clip(a[f"prob_K{K}_{s_}_{opt}"], 1e-12, None)) - np.log(pi)[None]).argmax(1), ok
  ```
  設計 3 節「保存した確率から log π′ を引いて判定した版（sel_lpi，λ0_lpi）を集計の段で作る．…π′ に 0 以下の成分がある単位の数を添える」
- 問題：0 以下の成分を 1e-6 に切ると，その感情の対数の確率に約 12 を足すことになり，ほとんどの発話の判定がその感情になる．試走（`check_lpi_clip_v4.py`）では，π′ に 0 以下の成分があった単位・K・版のすべて（評価の 5 組，仮のターゲットの 5 組 × 4 生徒）で，lpi の判定が切った感情に入る割合は 0.892〜1.000 だった（切る前の補正の版では 0.000〜0.514）．その単位の lpi の UAR はでたらめ（25%）に近くなる．π′ に 0 以下の成分がある組は f0 r0 だけでも AFEW・MELD の K = 5 の λ0 と MOSEI の K = 5・25 の λ0，K = 5 の λ0.5 に現れた．summary は単位をまとめて区間を作るので，sel_lpi − prop と λ0_lpi − I の行は，log π′ を引く操作の効果ではなく切り方の人工物で大きく下回る見込みが高い．設計はこの扱いを決めていない．
- 計算の後で直せるか：直せる（保存した確率と `Cw_*` から CPU で出し直せる）．ただし effects.csv と criteria.csv に人工物の行が残り，結果の文で読み違える．
- 求める対応：設計 3 節に扱いを 1 文で書き，台本をそれに合わせる．推す案は「π′ に 0 以下の成分がある単位は，その差の両方の版から除き，使った単位の数と除いた単位の数を添える．使える単位が無ければその行は空にする」である．単位を除くので，`dai14.combo_stats` に渡す 2 つの辞書を同じ単位の部分集合にそろえること．

- 重さ：直してから進む
- 該当箇所：dai15.py:451 `lpi_bad = 0`（`for A_, B_ in LPI_CONTRASTS:` の外），454 `nonlocal lpi_bad`，467 `n_pi_nonpos=lpi_bad`
