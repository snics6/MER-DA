## 軽微な指摘

- [d1] **3 節の「C_λ diag(w) の列の和がすべて 1 のときだけ変わらない」は数式として誤りである．**
  - 箇所：設計 3 節「補正は感情の割合も変える：…（候補の割合 π と r_i = Σ_k C_λ,ik w_k に依る．C_λ diag(w) の列の和がすべて 1 のときだけ変わらない）」．
  - π′ = C′⁻ᵀ(1/4, …) が 4 等分のままになるのは，C′ の列の和がすべて 1 のとき（C′ の行も列も和が 1 のとき）であり，C_λ diag(w) の列の和の条件とは一致しない．w の大きさを何倍しても C′ は変わらない（`weight_table` は行で割る）ので，w の大きさに依る条件は正しくない．私の計算での反例を 2 つ示す．
    - C_λ = 単位行列，w = (2, 1, 0.5, 0.5)：C_λ diag(w) の列の和は (2, 1, 0.5, 0.5) で 1 ではないが，C′ は単位行列になり π′ は 4 等分のままである．
    - C_λ の行が (0.7, 0.1, 0.1, 0.1)，(0.2, 0.6, 0.1, 0.1)，(0.1, 0.1, 0.6, 0.2)，(0.1, 0.2, 0.2, 0.5) で，w を列の和の逆数にして C_λ diag(w) の列の和をすべて 1 にしても，π′ = (0.237, 0.248, 0.253, 0.262) で 4 等分にならない．
  - 計算には影響しない（台本は `np.linalg.solve(Cw.T, 0.25)` で π′ を正しく出す）．直し方：括弧の最後を「C′ の列の和がすべて 1 のときだけ変わらない（たとえば C′ が単位行列のとき）」に直す．
- [d2] **記録の列 `n_pi_nonpos` が 2 つの記録の差で合算される．**
  - 箇所：台本 `stage_summary` の `lpi_bad = 0` と `lcell` の `nonlocal lpi_bad`．
  - `lpi_bad` は (T, K, 生徒) ごとに 1 回だけ 0 に戻り，`LPI_CONTRASTS` の 2 行（sel_lpi − prop，λ0_lpi − I）の間では戻らない．このため 2 行目の `n_pi_nonpos` は，sel_lpi の数と λ0_lpi の数の和になる．設計 3 節「π′ に 0 以下の成分がある単位の数を添える」の数が，λ0_lpi の行では多めに出る．予言の判定には使わない記録の版なので軽微である．直し方：`for A_, B_ in LPI_CONTRASTS:` の中で毎回 `lpi_bad = 0` に戻す．単位ごとの π′ は保存の `Cw_K*_*` から後で数え直せるので，計算の後に直してもよい．
- [d3] **教師の判定し直しが上回ったときの読み方が無い．**
  - 箇所：設計 3 節「判定し直しの得が上回らないコーパスでは，融合の H2 の当たりを『疑似ラベルの当たりを上げた』とは読まない」．
  - C′⁻ᵀ を掛けると，教師の判定の感情ごとの割合も変わる（前回の B1 と c2 と同じ仕組み）．判定し直しには割合をそろえた版が無いので，判定し直しが上回っても，その得が取り違えを差し引いた分か割合の変化の分かは分からない．直し方：上回ったときも「表の逆で判定し直した記録が上回った」と書くにとどめ，仕組みの根拠に使うなら，`teacher_w` と `teacher_rj0` の感情ごとの判定の割合と再現率を並べる（保存の `pred_K*_teacher_w`，`pred_K*_teacher_rj0` と `y` から，学び直さずに出せる）と 3 節か 5 節に 1 文足す．
