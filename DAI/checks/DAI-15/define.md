## 指摘

### [D8・D4] GLC の前向き補正が正しいための仮定は，入力の決まった関数である疑似ラベルでは，入力から感情が一意に決まる場合にしか成り立たず，Ĉ は教師の取り違えと入力の上の本来の曖昧さを区別しない
- 重さ：直してから進む
- 該当箇所：`DAI/docs/実験15_設計.md:13`（「取り違えの補正は 2 つ目（疑似ラベルの当たり）を直接強める介入である」），`:55`（「GLC の前向き補正で，声の分類器は提案より上がった」），`:68`（クラス条件つきの雑音の仮定），`research_notes/先行研究_改善案_2026-11-13/report.md:193-195`，`DAI/exp/dai15.py:80-87`，`:378-391`（selftest 4）
- 問題：
  - 報告 4 節の 1 は，GLC の仮定を「x が決まれば疑似ラベルは本当のラベルに依らず，誤り方はクラスだけで決まる」と 2 つ並べ，そこから q(x) = Cᵀp(y|x) を出す．原典では，前者（ỹ ⊥ y | x）は Ĉ の推し方に要る仮定で，後者（ỹ ⊥ x | y）は前向き補正の模型 q(x) = Cᵀp(y|x) に要る仮定である．原典の付録 A は，前者がデータの分離（y が x の決まった関数であること）から従うと示している．
  - この実験では q は特徴の決まった関数なので，前者は作りの上で成り立ち，Ĉ_ij = E[q_j(x) | y = i] は P(疑似 = j | 本当 = i) の偏りのない推定になる．しかし，2 つの仮定が同時に成り立つには，特徴の上で感情が重なる領域が無いこと（分離）が要る．重なる領域があれば，そこに属する感情どうしの Ĉ の行は等しくなければならないからである．
  - 分離していないと，Ĉ の対角は教師の誤りだけでなく，入力の上の本来の曖昧さと教師の確率の柔らかさの分だけ下がる．人工の数での確かめ（`glc_check2.py`）では，教師がベイズ最適（q = p(y|x)．取り違えは無い）でも Ĉ の対角は 0.52 になり，前向き補正をすると生徒の最大の確率の平均が 0.59 から 0.82 に上がった（目標を鋭くする向きに直す）．この設定の分類器の UAR は 40〜57 程度（実験 1 の仮のターゲットの値）で，分離からは遠い．
  - 原典の実験は，人工のクラス条件つきの雑音（入力に依らずにラベルを入れ替える）を，ほぼ分離できる画像と文のデータに足したものである．信頼できるラベルの本数は最小で MNIST の 0.1%（10 クラスに約 60 本．クラスあたり約 6 本）と Clothing1M の 100 本（14 クラス．クラスあたり約 7 本）で，K = 5 は本数ではこの範囲の端にある．範囲から外れているのは雑音の型と分離の程度である．
  - selftest 4（`dai15.py:378-391`）は，感情ごとに離れた点（`np.eye(4)[yv] * 2.0 + 雑音 0.8`）に，入力に依らない入れ替えで硬い疑似ラベルを付けている．これは原典の範囲の中の確かめで，本番の範囲（柔らかい疑似ラベル，分離しない特徴）を確かめていない．
  - したがって sel − prop が正になっても，それが「教師の系統的な取り違えを打ち消した」ことによるのか，「目標を鋭くした」ことによるのか，「感情ごとの判定の境目を動かした」ことによるのかを，設計の量だけでは分けられない．
- 計算の後で直せるか：一部は直せる．曖昧さの分の目安（下の表の A1）は実験 1 の保存（段 1 の全ラベルの参照の解）から後で計算できる．結果の文の言い方は計算の前に決める必要がある．
- 求める対応：
  1. 設計 1 節と 5 節の書き方の文から「取り違えを打ち消す」「疑似ラベルの当たりを強める」を外し，「GLC 型の前向き補正（K 本で推した表．表は教師の取り違えと入力の上の曖昧さの両方を含む）」と書く．
  2. 仮定の表（下の「D8 の表の案」）を設計に足し，A1〜A3 の量を計算の前に台本の出力に加えるか，後で計算する手順を書く．
  3. selftest に，分離しない入力でベイズ最適な柔らかい教師を使う項目を足し，補正が目標を鋭くする向きに働くことを記録として出す（失敗にはしない）．

### [目録に無い種類] 感情ごとの総量をそろえた目標に GLC の表をそのまま掛けると，正しい表でも分布の偏りを 2 回直す
- 重さ：直してから進む
- 該当箇所：`DAI/exp/dai15.py:202`（`GQ = S.soft_rows(Q, dai1.mval(rho, u.n))`．既定の `balance=True`），`DAI/exp/dai_solver.py:50-55`（`P = P / P.sum(0, keepdim=True)` で列ごとの総量をそろえる），`DAI/exp/dai15.py:385`（selftest 4 は `balance=False`），`DAI/docs/実験15_設計.md:30`（`soft_rows(q, ρn)`）
- 問題：
  - 提案の疑似ラベルの項は，q の列（予測された感情）ごとの総量をそろえてから使う．列の重みを w_j = 1/Σ_x q_j(x)，D = diag(w) とすると，発話 x の目標は D q(x) で，これは q(x) = Cᵀp(y|x) のもとで (C D)ᵀ p(y|x) になる．発話ごとに正規化すると，目標は C′ᵀ p′(x) になる．ここで C′ = (C D の各行を和 1 に割ったもの)，p′_i ∝ s_i p_i(y|x)，s_i = Σ_j C_ij w_j である．したがって，この目標に合う前向き補正の表は C ではなく C′ であり，台本は C を掛けている．
  - 総量をそろえる操作は，教師が多く予測する感情の重みを下げるので，それだけで教師の分布の偏りを直す．C を掛ける前向き補正も，C の列の和の偏りを通じて同じ偏りを直す．台本の組み合わせでは，この偏りを 2 回直す．
  - 人工の数での確かめ（`glc_check.py`．感情は等しい割合，教師は本当の表で Neutral に 0.3 ずつ寄せる．学ぶ側は発話ごとの最適解）：
    - 総量をそろえない目標に本当の表を掛けると，生徒は本当の事後確率に戻る（差 0.000，UAR 0.716）．ここまでは原典どおりである．
    - 総量をそろえた目標では，補正しない版の UAR が 0.707 だった．本当の表を掛けると 0.657，推した表 Ĉ を掛けると 0.651 に下がり，Neutral と判定する割合が 0.09（本当の表）と 0.085（Ĉ）になった（本当の割合は 0.25）．C′ = 行の正規化(Ĉ D) を掛けると 0.702 で，補正しない版とほぼ同じだった．
  - この人工の数は 1 つの例で，本番の大きさを示すものではない．示すのは，sel − prop の符号に，取り違えの直しとは別の「偏りを 2 回直す」成分が入りうることである．この成分は提案の疑似ラベルの列の和の偏りが大きいコーパスほど大きい．
  - λ = 1 の対照（S(Ĉ)）は列の和がすべて 1 なので，この成分を持たない．したがって sel − sym（C1）にもこの成分が入る．
  - selftest 4 は `balance=False` で確かめているので，本番の組み合わせを確かめていない．
- 計算の後で直せるか：直せない．補正の表を替えるには単位の解き直しが要る．
- 求める対応：次のどちらかを計算の前に決め，設計 3 節に書く．
  1. 補正の表を C′_λ = 行の正規化(C_λ D) に替える．D は単位ごとに，候補の上の q の列の和の逆数（`soft_rows` と同じ値）から作る．C = 単位行列なら C′ も単位行列なので，提案と同じ問になる性質は保たれる．
  2. 補正の版だけ総量をそろえない目標（`balance=False`）にする．ただし「補正の有無だけが違う」（設計 31 行）が崩れるので，総量をそろえない補正なしの版も並べる．

  どちらでも，selftest 4 を `balance=True` と本番に近い列の偏りで回し直し，単位ごとに q の列の和の最大と最小の比を記録する．

### [D1] 「補正しない」が選ばれたセルの sel − prop は，設計の定義では 0 だが，台本では解き直した版と保存の提案の差になる
- 重さ：直してから進む（直すのは段 summary だけで，単位の計算はやり直さない．評価の回の前に直す）
- 該当箇所：`DAI/docs/実験15_設計.md:54`（「選ばれた版が「補正しない」なら sel − prop は 0 で，そのセルは「上回る」にならない」），`:32`（「保存の提案のテストの UAR と 0.001 点を超えて違えば止める」），`DAI/exp/dai15.py:329`（`key = {**VERS, "sel": ("I" if opt == "off" else opt)}`），`:56`（`CHECK_PROP = 5e-3`），`:217-219`
- 問題：
  - 台本は，off が選ばれたとき sel に解き直した版 `I` を当てる．`I` と保存の `prop` は，判定が最大 0.5% の発話で違ってよい（`:217-219`）．違う発話が少なく一方向に偏ると，塊の jackknife やブートストラップの区間は非常に狭くなり，sel − prop の区間が 0 を含まず「上回る」と判定されうる．設計 54 行はこれを起こらないと書いている．
  - 補正の版（λ = 0，0.5，1，oracle）と prop の差にも，同じ解き直しの差が入る．補正の効果だけを測るなら，比べる相手は同じ解き方で解いた `I` である．
  - 設計 32 行の止める基準（UAR で 0.001 点）と台本の基準（判定の違う発話の割合 0.5%）が食い違う．
- 計算の後で直せるか：直せる．全部の版の判定が単位ごとに保存される（`:222`，`:226`）．
- 求める対応：段 summary で，off が選ばれたセルの sel を `prop` にする（sel − prop が恒等的に 0 になる）か，補正の差をすべて `I` を相手に定義する（sel − I，λ − I，sym − I，oracle − I）．どちらにするかを設計 4・5 節に書く．設計 32 行の基準を台本に合わせて書き直す．

### [D16・D10] C1 の sel − sym は「取り違えの向きの情報」を測らず，対照の sym は平滑化ではなく目標を鋭くする操作である
- 重さ：直してから進む
- 該当箇所：`DAI/docs/実験15_設計.md:34`（「λ = 1（対称の表．取り違えの向きの情報を持たず，平均の当たりだけを持つ）」），`:52`（C1 の規則と「平滑化と分けられない」），`DAI/exp/dai15.py:90-94`，`:302`
- 問題：
  - S(Ĉ) = aI + b11ᵀ（a = (4d̄ − 1)/3，b = (1 − d̄)/3）なので，sym の前向き補正は p̃ = a p + b である．発話ごとの最適解は p = (q − b)/a（実行できる範囲で）で，q の最大の感情を変えずに目標を鋭くする．つまり sym はラベル平滑化の逆向きの操作であり，「平滑化と分けられない」という言い方は向きが逆である．
  - Ĉ の非対称は 2 つの成分を持つ．1 つは列の和の偏り（教師がどの感情を多く予測するか．判定の境目，つまり切片の動きに当たる），もう 1 つは対ごとの取り違えである．sel − sym はこの 2 つを分けない．前者は切片だけを動かせば得られる成分で，指摘 2 のとおり総量をそろえる操作とも重なる．
  - 台本は sel − sym をすべてのコーパスで数える．off が選ばれたコーパスでは sel − sym = I − sym になり，補正を選ばなかったのに「向きの情報で上がった」と数えられうる．
- 計算の後で直せるか：数え方の直しは後でもできるが，計算の前に決めないと結果を見てからの規則になる．切片の成分を分ける対照を足すなら解き直しが要る．
- 求める対応：
  1. C1 の数え方を「sel が off でなく，かつ sel − prop が上回るコーパスのうち，sel − sym が上回る数」に替える．
  2. 書き方を「上回れば：対称の表（目標を鋭くするだけの補正）では説明できない．そうでなければ：目標を鋭くした効果と分けられない」に替える．
  3. 「向き」を主張したいなら，列の和だけを持つ表（Ĉ と同じ列の和を持ち，行ごとの形は対称に近いもの）か，prop の生徒の切片だけを K 本で直した版を対照に足す．足さないなら，「向きの情報」には切片の成分を含むと結果の文に書く．

### [D8・予言の意味] H2 の導出は補正の模型と合わず，H2 と H4 の「上回らない」は補正がどこでも効かないときにも当たる
- 重さ：直してから進む（規則の直しだけで計算は増えないが，計算の後に決めると結果を見てからの規則になる）
- 該当箇所：`DAI/docs/実験15_設計.md:15`（「3 つ目が欠ける顔・言葉では……補正しても得はほぼ 0 と予言する」），`:17`（MOSEI の推定の揺れ），`:49`（H2），`:51`（H4），`research_notes/先行研究_改善案_2026-11-13/report.md:205`（4 節の 6．「推測」と明記），`:206`（4 節の 7）
- 問題：
  - 交差エントロピーは目標について線形なので，特徴 x_s しか見ない生徒の母集団の最適解は E[q | x_s] にだけ依る（報告 4 節の 6 のとおり）．ところが補正の模型 q(x) = Cᵀp(y|x) が成り立つなら，C は x に依らないので E[q | x_s] = Cᵀ p(y | x_s) である．このとき前向き補正は，生徒が自分の特徴で再現できる部分だけを受け取るかどうかに関係なく，p(y | x_s) を取り戻す．つまり補正の模型の上では，補正の得は 3 つ目の条件（疑似ラベルの判断を自分の特徴で再現できる）を要しない．H2 は補正の模型からは出ない．H2 が当たっても「条件 3 が欠けると補正が効かない」の証拠にはならず，「補正の模型が成り立たない」ことと区別できない．
  - H2 の規則（上回るが 1 以下）は，補正で下がったコーパスも当たりに数える．設計の文は「得はほぼ 0」で，下がることとは別である．
  - H4（MOSEI の 4 つとも上回らない）は，補正がどのコーパスでも効かないときに必ず当たる．H1 が外れた場合の H4 の当たりは，推定の揺れについて何も言わない．
  - H4 の仕組みとして書かれた「表が特異に近いと推定が揺れて効きにくい」は，報告 4 節の 7 が後ろ向き補正（逆行列を掛ける）と BBSE の誤差の上界から推したものである．前向き補正は表の逆行列を掛けないので，同じ形の議論はそのままは移らない．また引いている特異値は出所 `pair` の表のもので，この実験の疑似ラベル（`one`）の表のものではない（設計 17 行が自ら書いている）．
- 計算の後で直せるか：直せない（予言の規則は計算の前に固定するもの）．
- 求める対応：
  1. H2 を，声との差で書き直す．例：「(sel − prop)[声] − (sel − prop)[顔]，同じく言葉，の区間が 0 より上のコーパスが 3 以上」．あわせて導出を「補正の模型の上では条件 3 に依らないが，模型が崩れて x_s に依る誤りが主なら，条件 3 の欠ける生徒では補正が目標の再現できない部分に掛かる」のように，模型のどの崩れを仮定したかを書く．書けないなら H2 を「記述」に下げる．
  2. H2 の当たりを「上回らず，かつ下回らない」に替えるか，同等性の幅 δ を決めて「区間が ±δ の中」にする．
  3. H4 は「H1 が当たった場合にだけ判定する」とし，判定に推定の揺れの量を足す．例：MOSEI の ‖Ĉ_cf − Ĉ_oracle‖ が他の 3 コーパスより大きく，かつ oracle − prop が上回るのに sel − prop が上回らない．Ĉ_cf と Ĉ_oracle は単位ごとに保存される（`dai15.py:190-191`）ので，追加の計算は要らない．

### [D7] Ĉ の推定の誤差と偏り，対角が小さいときの扱い，oracle を上限と読むことが決まっていない
- 重さ：記録する
- 該当箇所：`DAI/docs/実験15_設計.md:27`，`:34`（「候補の全ラベルで数えた表を使う版（上限の参照）」），`:55`（「oracle − prop（全ラベルの表でも上がる余地があったか）」），`:69-70`，`DAI/exp/dai15.py:90-94`，`:164-176`
- 問題：
  - 交差の推定で使う疑似ラベルのモデルは K 本の 4/5（K = 5 なら感情あたり 4 本）で作るので，生徒の学習に使う全部の K 本の教師より弱い．Ĉ_cf は取り違えを多めに見積もる向きに偏る．設計 70 行は「わずかに違う」と書くが，K = 5 では K 本の 20% を抜くので，わずかとは言えない．偏りの向きは補正を強める（目標をさらに鋭くする）向きである．
  - K = 5 では各行を 5 本の平均で推す．d̄ ≤ 1/4 なら S(Ĉ) の a = (4d̄ − 1)/3 が 0 以下になり，sym の補正が向きを反転する．対角より大きい非対角を持つ行が出たときの扱いも書かれていない．起こる見込みは小さいが，起きた単位の数と扱いを計算の前に決める（D11 と同じ考え）．
  - oracle の表は全ラベルで数えるが，指摘 1 の曖昧さと指摘 2 の重ねての直しを同じだけ含む．人工の数では，総量をそろえた目標に本当の表を掛けると補正しない版より下がった．したがって oracle − prop ≤ 0 は「上がる余地が無かった」ことを意味しない．言えるのは「この目的関数では，全ラベルで数えた表でも上がらなかった」までである．

### [D4・D3] 疑似ラベルが Ĉ の行の作る範囲の外にある発話では，前向き補正の目標に届かず，解は引き戻しの罰で決まる
- 重さ：記録する
- 該当箇所：`DAI/exp/dai15.py:116-121`，`:80-87`
- 問題：前向き補正で生徒が出せる p̃ は C_λ の行の凸結合に限られる．Ĉ の行は感情ごとの q の平均なので，作りの上で，自信の強い発話の q（例えば q_i が Ĉ_ii より大きい発話）の多くはこの範囲の外にある．提案の疑似ラベルは 3 つの確率の積で鋭い．範囲の外の発話では，目的関数を下げる向きがロジットを際限なく大きくする向きになり，止めるのは引き戻しの罰だけになる．補正の版の解が「補正」よりも「引き戻しの罰とのつり合い」で決まる割合を，設計は測らない．
- 計算の後で直せるか：直せる．q は実験 1 の保存から作り直せ，C_λ は保存の Ĉ から作れる．
