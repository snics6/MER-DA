## 記録

1. **(c, m, 出所) ごとに格子の端が過半になる組は `self` と `pair_shuf` だけだった．**`lince` の軸と端ごとの割合が過半（K ∈ {1, 5, 10, 25} × 2 半分 = 8 のうち 5 以上）になったのは，`self` の wd の下端 10⁻⁴（MOSEI の A・V・T，MELD の A・V・T．6〜8/8）と，`pair_shuf` の wd の上端 10（AFEW の A・V・T 5〜7/8，MELD の A・V・T 6〜8/8）だった．`nl` も同じ組だった（入れ子により `nl` = `lince` の半分が多い）．`self` は特徴の線形の関数そのものなので，罰則の 0 の側が最適なのは見込みどおりで，10⁻⁴ は罰則 0 の近くである．`pair_shuf` は wd 100 を足しても 100 が選ばれたのは AFEW 0/24・MELD 1/24 だったので，上端 10 は最適点を囲んでいる（AFEW の `pair_shuf` の判定の中で最も多い感情の割合は中央値 0.33〜0.49，MELD は 0.79〜0.97 で，MELD の線形のネットはほぼ 1 つの感情を出す）．R1c と R1shuf の行の `note_edge`（「格子の端に縛られている」）はこの組で立つ見込みである．結果の文では，`self` の下端は罰則 0 の近くであること，`pair_shuf` の上端は 100 を試して移らなかったことを添える．設計 3.3 節にこの 2 つを書くとよい．

- **入れ子の選択（小さいモデルの選んだ版で大きいモデルの選んだ版を置き換える）では，置き換えの後に残る記録（損失の履歴，重み，選んだ点，格子の判定）がどちらのモデルのものかが混ざる．**9.3 節の I に「選んだ版を別のモデルの版で置き換える台本は，置き換える量（点数，損失，選んだ点）と置き換えない量（損失の履歴，重み，格子の判定）を一覧にし，置き換えない量から作る印（収束，端）と，後から選んだ版を作り直す手順が，置き換えた半分でも正しいモデルの記録を使うかを確かめる」を足す案を出す（DAI-12 の gate-code の第 3 回．収束の印が置き換えた半分で隠れ層のネットの損失の履歴を読み，`conv` の `cfg` を `grid_pred_nl` に当てると置き換えた半分の 95% 以上で作り直せなかった）．
- **束ねて学ぶネットの初期値を 1 つの乱数の列から一度に引くと，束ねる数を変えただけで全部のネットの初期値が変わる．**I18 の「格子を広げた後は新しい端を数える」に「広げる前と後の判定の違いには初期値の違いの分が入る．比べるときは初期値に依らない版（初期値 0 など）で比べるか，ネットごとに種を決める」を追記する案を出す（DAI-12．wd を 1 点足しただけで `pair_shuf` の線形のネットの判定が 11〜16% 変わり，初期値 0 の版は 0.07〜1.2% だった）．

当てた項目：I1〜I18（I1 は指摘 2〜4，I13 は自己検査と入れ子の一貫，I18 は指摘 1 と記録 1，I7 は照合 0 本，I10 は MOSEI の予約の最大 10.7 GB，I11 は有限でない値 0），R1〜R13（B の表．R4 は指摘 5），S3・S18（`effect_stats_pool` の検算），L4（表の組），C18（入れ替えの読みと R3 の (iii) の部分集合），A24（見込みの数の拾い方）．
