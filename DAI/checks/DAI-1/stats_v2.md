## 指摘

### [S3] 2 つの行の判定が同一のとき，jackknife の側は p = 0 を返し，Holm で有意になる
- 重さ：直してから進む
- 該当箇所：`DAI/exp/dai1_stats.py:205-206`，族 4 の定義 `dai1_stats.py:49・112`，設計 211 行
- 問題：`tval = est / se if se > 0 else np.inf` と `p = float(2 * st.t.sf(abs(tval), df))` は，se = 0 のとき p = 0 を返す．族 4 は「提案の主の版・選んだ設定」と「版 (1,1,1)，ρ = 1，a = 1」の差である．選ぶ段の同点の規則は δ_sel の中で選択なしの値に最も近い点を選び（`dai1_select.py:83`），主の版も δ_main を超えないかぎり (1,1,1) になる（同 133 行）．したがって，選んだ設定が選択なしの設定と一致するセルは起こりやすく，そのセルでは 2 つの行が同じ問になり，d_fr がすべて 0，V_jk = V_seed = 0 になる．合成の数で確かめると，G_eff = 8.6 では effect = 0，se = 0，p = 0.0 を返し，Holm の後も 0 のままである（`holm([0, 0.3, 0.5])` → `[0, 0.6, 0.6]`）．差が 0 のセルが AFEW，IEMOCAP，MELD の族 4 で「有意」と書かれる．MOSEI のブートストラップの側は p = 1.0 を返すので正しい．
- 計算の後で直せるか：直せる（統計の台本だけ）．ただし評価の結果を見る前に規則を決めておく．
- 求める対応：se = 0 かつ θ = 0 のとき p = 1 にする（`tval = 0`）．se = 0 かつ θ ≠ 0 は起こらないはずなので止める．族 4 の表には「選んだ設定が選択なしと同じ」セルの数を書き，そのセルも族の大きさ 12 に数えたまま Holm にかけると設計に書く．

### [S3] 塊が分割と一致する場合（IEMOCAP の全セル，AFEW の分割 0）に，種の揺れを二重に数える．detect では R = 2 の種の揺れが塊の項に残る
- 重さ：直してから進む
- 該当箇所：`DAI/exp/dai1_stats.py:183-203`，設計 218-221 行，`dai1_stats.py:297-299`（detect の見込み）
- 問題：IEMOCAP では塊を抜くと分割が丸ごと外れるので，θ_(−g) は残る 4 分割の d̄_f の平均になる．このとき V_jk = (4/5) Σ_g (θ_(−g) − θ̄)² は 5 つの d̄_f の不偏分散 ÷ 5 に一致する．d̄_f は R 個の種の平均なので，その分散は「分割の間の真の差の分散 ＋ 平均の σ_f²/R」であり，V_jk の期待値は種の項 (1/5)·平均(σ_f²/R) をすでに含む．これに V_seed = (1/25) Σ_f s_f²/R（期待値は同じ (1/5)·平均(σ_f²/R)）を足すので，種の項が 2 回入る．AFEW の分割 0 で `M:Aviator` を抜く 1 項も同じ形で，分割 0 の種の揺れを含む．
  - 評価の回：IEMOCAP の K > 0 の全セルで標準誤差が大きく出る（保守の向き）．IEMOCAP はすでに記述に回す見込みなので主張は変わりにくいが，「同じ水準」の判定（下の指摘 5）も遠ざかる．
  - detect：仮のターゲットの回は R = 2 なので，IEMOCAP の V_jk に R = 2 の種の揺れが入ったまま，評価の回の見込みの塊の項として使われる（`dai1_stats.py:297`）．`vseed` だけを 2/R に縮めても，塊の項に入った R = 2 の種の揺れは縮まない．IEMOCAP の検出できる差を大きく見積もり，R を決める「種の項の割合」（`dai1_stats.py:290`）を小さく見積もるので R = 10 を選びやすくなる．
- 計算の後で直せるか：直せる（統計の台本だけ）．ただし評価の回の前に式を決める．
- 求める対応：抜いた塊が分割を外すとき（θ_(−g) がその分割の値を含まないとき）は，その項の計算に d̄_f ではなく「種の揺れを除いた値」を使うか，その場合に限り V_seed を足さない規則を式で書く．簡単な案は，分割ごとに「塊 g を抜いた値」を種ごとに作って jackknife の分散を種ごとに出し（種を固定した塊の揺れ），R 個の平均を V_jk とし，そこに V_seed を足す形にすることである．IEMOCAP（塊 = 分割）では V_jk を「5 つの d̄_f の分散 ÷ 5 − V_seed」（負なら 0）とし，全体の分散を d̄_f の分散 ÷ 5 にする案もある．どちらかを設計 9.3 節に書き，detect の見込みも同じ式にする．

### [S3] MOSEI の detect は，ブートストラップの分散から解析の種の項を引くので，塊の項を v_seed/2 だけ小さく見積もる
- 重さ：直してから進む
- 該当箇所：`DAI/exp/dai1_stats.py:173-174`（種の復元抽出），`:181`（se = ブートストラップの標準偏差），`:290`（`tot = (r.se ** 2 - r.v_seed) + vs`），`:297`（`((g.se ** 2) - g.v_seed).clip(lower=0)`）
- 問題：ブートストラップは各分割で R 個の種を復元抽出して平均するので，平均の分散のうち種の分は s_f²(R−1)/R² である．R = 2 では s_f²/4 で，解析の V_seed の s_f²/2 の半分しかない．detect は `se² − v_seed` を塊の項とするので，塊の項を (1/25) Σ_f s_f²/4 だけ小さく見積もる．MOSEI はテストが分割ごとに 3,700 本あり塊の項が小さい見込みなので（推測．UAR は見ていない），`se² − v_seed` が 0 以下になりうる．そのとき `:291` の割合は 0 になり（`tot > 0` でない），R = 10 を選ぶ向きに動き，`:297` は塊の項を 0 に切り，検出できる差を小さく見積もる．どちらも MOSEI の検出の見込みを楽観の向きにずらす．
- 計算の後で直せるか：直せる．ただし R は評価の回の前に決めるもので，評価の後に種を足すと結果を見て単位の数を決めたことになる．
- 求める対応：detect では，MOSEI の塊の項を「種を固定し，分割ごとに塊だけを引き直したブートストラップの分散を種で平均した値」として別に出し，種の項は解析の V_seed を使う．評価の回のブートストラップも，種の復元抽出は plug-in の分散（R = 10 で真の 0.9 倍，R = 20 で 0.95 倍）しか出さないので，区間がわずかに狭いことを記録するか，種の引き直しの値を √(R/(R−1)) 倍に広げる補正を書く．

### [S2] 「記述に回すセル」の判定に使う見えた差を，選んだのと同じ仮のターゲットの単位で測っている．2 倍の規則は検出力の低いセルを残す

### [S2][S4] 「同じ水準」の δ は単一の手法の種の標準誤差で，差の区間の半幅より作りの上で小さくなりやすく，R を増やすほど縮む
- 重さ：直してから進む
- 該当箇所：設計 202 行，計画 272 行，`DAI/exp/dai1_stats.py:305-318`
- 問題：δ = 2√(V/n)，n = 5R で，V は比較の基準 1 つの UAR の種の間の分散である．「同じ水準」は差の区間が ±δ に収まるときに書く．差の区間の半幅は t × √(V_jk + V_seed) で，V_seed は差の種の分散 s_d² を 5R で割った値である．2 つの手法の種の分散がともに V で，種の間の相関を ρ とすると s_d² = 2V(1−ρ) なので，V_jk = 0 かつ θ = 0 の最良の場合でも，半幅 ÷ δ = t·√(2(1−ρ))/2 になる．

  | ρ | MOSEI（t = 1.96） | AFEW（2.16） | MELD（2.36） | IEMOCAP（3.18） |
  |---|---|---|---|---|
  | 0 | 1.39 | 1.53 | 1.67 | 2.25 |
  | 0.5 | 0.98 | 1.08 | 1.18 | 1.59 |
  | 0.8 | 0.62 | 0.68 | 0.75 | 1.00 |

  比が 1 以上のセルでは，差が 0 でも「同じ水準」と書けない．実際には V_jk > 0 が加わり，AFEW・MELD・IEMOCAP では V_jk が分散の大部分を占める見込みである（前回の報告の書き出しのとおり塊の数で決まる）．V_jk は R で縮まないのに δ は 1/√R で縮むので，detect が R = 20 を選ぶと「同じ水準」はさらに書けなくなる．計画の説明の判定の規則（計画 299-300 行の「同じ水準か上回る」「δ 以上上回る」「同じ水準なら」）はこの δ に頼るので，「同じ水準」が空になると，実験 3 の判定は「上回る」か「判定できない」だけになる．
- 計算の後で直せるか：直せる（定義と統計の台本）．ただし評価の回を流す条件に実験 3 の設計が入っているので，その前に決める．
- 求める対応：δ を R に依らない値（UAR のポイントで，計算の前に決める実質の幅）にするか，δ を残すなら detect でセルごとに「θ = 0 のときの差の区間の半幅の見込み」を δ と並べ，半幅 ≥ δ のセルでは「同じ水準」と書けないことを固定のファイルに書く．実験 3 の判定の規則は，「有意でも同じ水準でもない」セルを「判定できない」と数える形にし，そのセルを「同じ水準」にも「下回る」にも数えないと書く（実験 3 の設計の検査で確かめる）．
