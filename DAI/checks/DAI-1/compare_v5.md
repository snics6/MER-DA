## 2. 指摘

### [C10] 共正則化の ρ = 0 が族 3 の相手に選ばれたセルでは，族 3 の差は別のモダリティの情報を使わない相手との差になる
- 重さ：記録する
- 該当箇所：`DAI/docs/実験1_設計.md:126`（共正則化の行），`:135`（温度 1 の点の注），`:139`（候補の数）．`DAI/exp/dai1.py:363-374`（`coreg`），`DAI/exp/dai1_select.py:39`（`PARTNERS`）
- 問題：設計 126 行は ρ = 0 を「一致の罰を使わない」と書く．台本の `coreg` は各モダリティの引き戻しに `tether[(m, max(K, 1))]` を使い（`dai1.py:371`），これは比較の基準 none[K] と同じ (C′，C_b) である．したがって ρ = 0 の単一の生徒の識別器は，解き方の許容の範囲で none[K] と同じになる（K = 0 では出発点そのもの）．AVT の生徒の ρ = 0 は，none[A]・none[V]・none[T] の点数の和（K 本だけで学んだ 3 つの識別器の後段の融合）であり，none[AVT] とは違う．族 3 の相手は 5 手法の中で仮のターゲットの成績が最良（δ_sel の中の同点は `PARTNERS` の並びで先）の手法なので，ρ = 0 の共正則化が選ばれたセルでは，族 3 の差「提案 − 相手」は単一の生徒で族 1 の差「提案 − none[K]」と同じものになり，「同じ情報を受け取る相手との差」とは読めない．設計 135 行は，温度つき蒸留の T = 1 と，AVT の生徒の共訓練について同じ種類の注を置いているが，共正則化の ρ = 0 についての注は無い．
- 計算の後で直せるか：直せる．族 3 の相手と相手の選んだ ρ は固定のファイル（`partner`，`select`）に残るので，評価の回の後でも該当するセルを数えられる．ただし注の文は評価の前に決める．
- 求める対応：設計 135 行の並びに「共正則化の ρ = 0 が族 3 の相手に選ばれたセルでは，単一の生徒の相手は none[K] と同じ識別器で（K = 0 では出発点），族 3 の差は族 1 の差と同じものになる．AVT の生徒の相手は none[A]・none[V]・none[T] の点数の和になる．該当するセルの数を族 3 の表の注に書き，族 3 のコーパスの文の数え上げでは該当するセルを含めた数と除いた数の両方を書く」を足す．数は選ぶ段の固定のファイルから数える（選び直さない）．
