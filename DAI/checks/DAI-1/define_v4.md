### [D1] 7 節に足した「格子の端を選んだセルの数を固定のファイルに残す」が，選ぶ段の台本に入っていない
- 重さ：記録する
- 該当箇所：`DAI/docs/実験1_設計.md` 7 節「格子の端（比較の検査の 3 回目の 4）」の項，`DAI/exp/dai1_select.py`（`grep -n "端\|edge"` で該当する行が無い）
- 問題：設計は「選ぶ段で，提案と相手のつまみが格子の端を選んだセルの数を手法ごとに数えて固定のファイルに残し，結果の表に書く」と書く．`select_T` と `main` は，選んだ設定，同点の数，指数の安定さは書くが，格子の端の数は書かない．`frozen.json` の `select` には選んだつまみの値が残る．格子は `dai1_select.GRIDS` にある．したがって数はあとから一意に数えられる．ただし，設計が「固定のファイルに残す」と決めた量が固定のファイルに入らない．固定のファイルの sha256 は評価の関門で固めるので，後から書き足すと sha256 が変わる．
- 計算の後で直せるか：直せる（固定のファイルの `select` と格子から数える）．固定のファイルに入れるなら，選ぶ段を流す前に台本を直す．
- 求める対応：`select_T` で，各 (生徒，K，手法，版) の選んだ値がつまみごとに格子の最初か最後の値かを数え，手法ごとの数を `frozen[T]["grid_edge"]` に書く．または設計の文を「固定のファイルの `select` から数えて結果の表に書く」に直す．

## 確かめたこと

- `fit_coreg` の目的関数は，第 3 版の torch の版（`coreg` の closure）と同じ式である．モダリティごとの K 本の交差エントロピー，引き戻し，平均を引いた点数の 2 つずつの差の二乗の和に ρ/2 を掛けたものを，S_p = 3ΣG ＋ ρ_p n で割る．問は ρ ごとに独立で，`f.sum()` の勾配は問ごとの勾配になる．
- ρ > 0 での確かめ（selftest は ρ = 0 だけを確かめる）：3 つのモダリティ（次元 12，8，10），n = 300，K 本 40，引き戻し (0.3, 1)，(0.1, 10)，(1, 1)，ρ ∈ {0.0625, 1, 4}，tol 1e-10 で `fit_coreg` を解いた．別に書いた S で割らない目的関数を autograd で微分し，解での勾配の最大を測った．値は 5.7e-10，3.7e-8，5.7e-9 で，`grad_p`（S で割った値）× S と同じ大きさである．`stalled` はどれも偽だった．台本は `/tmp/claude-1000/-home-snics-MER-DA/b1f27254-32c7-45f0-ac5a-dee1c5e3ec8a/scratchpad/coreg_check.py`（CPU，数秒）．
- 行の和：段 source（W0 = 0）と引き戻しの解は，交差エントロピーの点数に対する勾配が感情について和 0 になる．引き戻しの勾配は (W − W0)/C′ なので，出発点の行の和が 0 なら解の行の和も 0 のままである．共正則化の一致の項は平均を引いた点数の関数なので，同じく和 0 を保つ．
