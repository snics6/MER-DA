- **固定**：選んだ設定と規則をファイルに書いてコミットし，以後変えないこと．

- **疑似ラベル**：ラベルの無い発話に，別の識別器の予測から付けた正解の代わり．**硬いラベル**は 1 つの感情だけに 1 を置くもの，**柔らかいラベル**は 4 感情の確率をそのまま置くもの．
- **出発点**：ソースのコーパスごとの識別器の重みと切片を平均した識別器．全手法がここから学び始める．
- **引き戻し**：学び直す識別器が出発点から離れすぎないようにかける罰則．
- **jackknife**：テストの塊を 1 つずつ抜いて値を計算し直し，その揺れからばらつきを見積もる方法．

## 重大な指摘

### [M18] 「別のモダリティと自分の予測を混ぜる手」が，出どころに挙げた Zhang ほか 2021 の形になっていない
- 箇所：
  - `DAI/docs/実験1_設計.md` 7 節の表「別のモダリティと自分の予測を混ぜる手（Zhang ほか 2021）｜K 本（倍率 1）＋ (α·生徒自身の none[K] の確率 ＋ (1−α)·予測)（総量をそろえない）の重みの合計 ρn ＋ 引き戻し」「α は計画で決めた値（Zhang ほか 2021 は顔の予測と声自身の予測を混ぜた．混ぜる割合は原文で確かめていない）」
  - `DAI/exp/dai1.py` 372〜374 行
    ```
    if method == "mix":
        al = float(it["alpha"])
        return gk + S.soft_rows(al * own + (1 - al) * Q, mval(it["rho"], u.n), balance=False), zero, 1.0
    ```
  - 計画 8.2 節の族 3 の行（相手の候補に「別のモダリティと自分の予測を混ぜる手」）
- 問題：
  - Zhang ほか 2021 の重み付き和（論文の FF2）は，次の形である（Knowledge-Based Systems 229, 107340．著者の所属先に置かれた PDF の本文で式 (8)・(9) と 4.2 節を読んだ．https://users.monash.edu/~yli/assets/pdf/2021-KBS-SpeechEmotionRecognition.pdf ，https://doi.org/10.1016/j.knosys.2021.107340 ）．
    1. 声のモデル自身の確率 p_a に α，顔の確率 p_v に 1−α をかけて足す：p_av = α p_a + (1−α) p_v（式 (8)）．
    2. その最大の感情を硬いラベルにする：ỹ = argmax(p_av)（式 (8)）．
    3. 最大の確率が τ を超える発話だけを損失に入れる：L = −(1/|B_U|) Σ 1{max(p_av) > τ} log p̃[ỹ]（式 (9)）．τ = 0.9（4.2 節）．
    4. 疑似ラベルの損失の重みは λ = 0.1（4.2 節）．α = 0.2 の版を表 5（IEMOCAP，UA 62.50%）で報告している．α は声（学ぶ側のモダリティ）の重みである（4.4 節 "α denotes the weight of emotion information from the audio modality"）．
    5. 声のモデル自身の確率 p_a は，学習中のモデルが弱く変形した入力に出す今の予測である（論文の擬似コード 4 行目）．
  - 台本は，混ぜた確率を柔らかいラベルのまま全部の候補に置き，argmax も確信度のしきい値もかけない．α の向き（学ぶ側のモダリティの重み）と既定値 0.2 は原論文と合う．設計の「混ぜる割合は原文で確かめていない」は，上のとおり確かめられる．
  - 硬いラベルと 0.9 のしきい値の有無で，疑似ラベルが置かれる発話の数と重みは大きく変わる（しきい値を超える発話だけが残る）．凍結した特徴の上の線形の識別器でも，2 つの形の解は一致しない．
  - この手法は族 3 の相手の候補 4 つの 1 つである（`dai1_select.py` の `PARTNERS`）．仮のターゲットでこの手法が最良になったセルでは，論文の族 3 の表に「Zhang ほか 2021 と比べた」と書くことになり，実装と出どころが食い違う．
  - 生徒自身の予測が，学習中に更新される予測ではなく固定した none[K] の予測であることも原論文と違う．これは凸の線形の設定に移すための違いとして書けば足りる．
- DAI の基準との関係：報告の誤り（比較相手の名前と出どころが実装と合わない）．前回の M17 と同じ種類である．
- 直し方（仮のターゲットの回の前に，どちらかを選んで設計の 7 節と計画 8.2 節に書く）：
  1. 原論文の形に合わせる：疑似ラベルを argmax(α·生徒自身の none[K] の確率 ＋ (1−α)·予測) の硬いラベルにし，その最大の確率が τ を超える発話だけに置く．τ = 0.9 は原論文の値で固定し，1 本あたりの重みは一致した発話だけの疑似ラベルと同じく f で表す（格子は α ∈ {0.2, 0.5, 0.8} × f ∈ {1/4, 1, 4} の 9 点 × 版 2 つなど．選択なしの値は α = 0.2，f = 1）．
  2. 今の形を残す：名前を「自分の予測と混ぜた柔らかい疑似ラベル（Zhang ほか 2021 の重み付き和を，硬いラベルとしきい値を外して柔らかいラベルにした変形）」に替え，論文で Zhang ほか 2021 の手法とは書かない．
  - どちらの場合も，Albanie ほか 2018 の行と同じく「Zhang ほか 2021 との違い」（生徒自身の予測は固定した none[K]，K 本と引き戻しがある，疑似ラベルの重みの決め方）を表の下に書く．1 を選ぶと `make_G` の `mix` と `GRIDS["mix"]` を直すので，`gate-code` に差分を確かめさせる．
