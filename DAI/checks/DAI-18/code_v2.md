## 指摘

### [I（失敗の印）] 起動の台本は，`SHA18` を渡し忘れると失敗の印を出さずに終わる
- 重さ：記録する
- 該当箇所：`DAI/run/dai18_probe.sh:9`
  ```
  [ "$(sha256sum DAI/exp/dai18_probe.py | cut -d' ' -f1)" = "${SHA18:?}" ] || { echo "dai18_probe.py の sha256 が違う"; touch logs/dai18_probe.failed; exit 1; }
  ```
- 問題：同じ形の台本を一時の置き場で流すと，`SHA18` が無いときは「parameter null or not set」で終了コード 1 になり，`trap ... ERR` は動かず `.failed` ができなかった．`.done` か `.failed` を待つ仕組みで見張ると，待ち続ける．起動した直後に端末に出るので，起動した人は気づける．
- 計算の後で直せるか：直せる（数値に影響しない）
- 求める対応：起動の前に `SHA18` を確かめる行（`[ -n "${SHA18:-}" ] || { touch logs/dai18_probe.failed; exit 1; }`）を sha の比べの前に置く．直さないなら，起動のときに `SHA18` を渡したことを画面で確かめる．

### [I（読み方）] `students_sel.csv` に，RAVDESS の生徒の `M_F6_mixsel` の行が 3 つ出る
- 重さ：記録する
- 該当箇所：`dai18_probe.py:832-844`
