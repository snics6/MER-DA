## 重大な指摘

### [E1] HYP の規則は，感情の違いを消した τ や，EM が動かなくなった τ でも「頂上が近づいた」と書く
- 箇所：設計 4 節 78〜81 行「gc か nap10 か nap50 で，次の 2 つがともに成り立つコーパスでは，『感情でないまとまりの成分を除くと，EM の尤度の頂上は感情の割り当てに近づいた』と書く．raw の読みが (b) で，τ の読みが (b) でない．EM_truth^τ − LDA_O^τ が raw の同じ量より 2 ポイント以上大きい」．台本の集計の段 269〜274 行．
- 問題：2 つの抜け道がある．
  1. **基準の側が下がっても条件を満たす**．
     - 2 つ目の条件は差 EM_truth^τ − LDA_O^τ だけを見る．このため，τ が感情の違いも消して LDA_O^τ が下がると，EM_truth が良くならなくても差が縮んで条件を満たす．
     - 数値の例：raw で LDA_O = 60，EM_truth = 50（差 −10．読み (b)）．gc で LDA_O = 45，EM_truth = 44（差 −1．読み (b) でない）．このとき，EM_truth の UAR は 50 から 44 に下がったのに，「頂上は感情の割り当てに近づいた」と書くことになる．
     - 設計 8 節 111 行は，MOSEI と AFEW では gc と nap がグループの間の感情の違いも消しうると認めている．そこで，ラベルだけから 2 つの量を数えた（`DAI/splits/*.csv`．DAI-8 の第 1 回の報告の表）．
       - 同じ塊の 2 本が同じ感情である確率：MOSEI 0.499（無作為なら 0.361），AFEW 0.304（同 0.251）．
       - MOSEI のテストの発話のうち，5 本以下のグループにある割合：22%（3 本未満 5.3%，3〜5 本 16.7%．分割 0〜4 でほぼ同じ）．
     - 3〜5 本の動画の平均を引くと，その動画に共通する感情も，発話自身の値の 1/3〜1/5 も一緒に引くことになる．
  2. **読み (c) でも条件を満たす**．
     - 1 つ目の条件は「τ の読みが (b) でない」なので，(c) を含む．
     - (c) は，EM がどの初期値からもほぼ動かない場合である．このとき EM_truth は正解の割り当てをほぼ保つので，EM_truth^τ は LDA_O^τ にほぼ等しくなり，差は 0 に近づく．raw の差が −2 より小さければ，2 つ目の条件は自動的に満たされる．
     - (c) の定義は「EM が流れたかどうかから，分布が感情の情報を持つかは言えない」であり，「頂上が近づいた」と書ける場合ではない．
- DAI の基準との関係：報告の誤りに当たる．規則が予想の向きの文を書く場合に，予想と無関係な理由（感情の違いを消したこと，EM が動かないこと）が入る．
- 直し方（保存する EM_truth^τ・LDA_O^τ のテストの判定から作れるので，単位の段は変えなくてよい．規則の文は計算の前に固定する）：
  1. 1 つ目の条件を「raw の読みが (b) で，τ の読みが (a)」に直す．
  2. 3 つ目の条件を足す．EM_truth^τ のテストの UAR − EM_truth^raw のテストの UAR の点推定が ≥ 0（または設計者が決める下限）であること．集計の段の比べに `{tau}_emtruth_vs_raw`（`{tau}_emtruth` − `raw_emtruth`）を足す．
  3. 4 節に読み方の文を足す．LDA_O^τ − LDA_O^raw（S5）が −2 ポイント以下か，Q3 の top3ex_emo^τ が raw より明らかに小さいコーパスでは，「τ は感情の違いも消した」と書き，S1〜S3 の τ の値を「感情でないまとまりを除いた効果」とは書かない．どの大きさで「明らかに小さい」とするかは設計者が計算の前に決める．

### [E2] NAP で消す向きの数が，候補のグループの数から決まる上限を超える
- 箇所：設計 3.1 節 43〜46 行「候補のグループの平均（重みつき）の散らばり S_g の上位 r 個の固有ベクトル V（r = 10，50）」．台本 `transform` の 70〜81 行 `V = V[:, -r:]`．
- 問題：
  - G 個のグループの平均の散らばり S_g は，平均を引いた後の G 個のベクトルから作るので，0 でない固有値は最大で G − 1 個しかない．
  - 候補のグループの数は分割ごとに次のとおりである．グループの印の列の値の種類だけを数え，ラベルは使っていない．
    - IEMOCAP：8（4 セッション × 2 話者）なので，上限は 7 である．
    - AFEW：48，40，40，39，37 なので，上限は 47〜36 である．
    - MELD：202〜270．
    - MOSEI：約 2,090．
  - IEMOCAP では，nap10 が 3 本，nap50 が 43 本，固有値がほぼ 0 の向きを消す．AFEW の nap50 は 3〜14 本を消す．
    - 人工データで確かめた．2,304 次元で 8 グループのとき，S_g の固有値は上位 7 つが 52〜63，8 番目からは 2 × 10⁻¹⁴ 以下だった．
    - 固有値が 0 の向きは，固有値分解の数値の誤差で決まる任意の向きである．グループとは無関係な向きを消すことになり，感情の向きにも当たりうる．
  - したがって IEMOCAP の nap10 と nap50 は，「話者の向き 7 本を消す」ことに「グループと無関係な向きを 3 本または 43 本消す」ことが加わった操作である．設計の説明と一致しない．
  - HYP の規則は gc・nap10・nap50 を数えるので，IEMOCAP と AFEW の nap の結果が，「グループの向きを除いた効果」として数えられる．
- DAI の基準との関係：報告の誤りに当たる．方法の節に書いた操作と，実際に計算した操作が，IEMOCAP と AFEW で違う．
- 直し方：
  1. `transform` で，消す数を r_eff = min(r, 候補のグループの数 − 1) にする．
  2. 単位ごとに r_eff と，消した向きの固有値を残す．
  3. 設計 3.1 節に「IEMOCAP では候補の話者が 8 人なので r_eff = 7 で，nap10 と nap50 は同じ操作になる」と書く．
  4. 自己検査に，グループが r より少ない場合を足す．

## 軽微な指摘

- [e1] **gc を「話者正規化」と呼ぶ範囲と，IFN との違い**：
  - gc がする操作は，コーパスによって違う．
    - IEMOCAP と MELD：話者正規化になる．
    - MOSEI：多くは動画ごとの正規化になる．
    - AFEW：俳優と作品の塊ごとの正規化になる．
  - Busso ほか 2013 の IFN は，中立と判定した発話だけで正規化の統計を推定し，それを繰り返す（https://doi.org/10.1109/T-AFFC.2013.26．書誌と要旨で確かめた）．gc はグループの全部の発話の平均を引くので，IFN の形ではない．
  - 直し方：0 節 11 行の出どころを「話者ごとの平均の正規化（Schuller ほか 2010，Sethu ほか 2007）」に直し，IFN は「中立の発話だけで統計を作る別の形」として違いを書く．4 節と 8 節の語は「グループの平均を引く（コーパスごとの中身）」にする．
  - Sethu, Ambikairajah, Epps 2007, "Speaker normalisation for speech-based emotion detection," DSP 2007, pp. 611–614（https://dblp.org/rec/conf/icdsp/SethuAE07.html．書誌だけを確かめた）．
- [e2] **NAP の形の感情認識での先例**：0 節 12 行は NAP の出どころを話者認識だけに置く．感情認識にも，話者認識の手法と，セッションの間の揺れの補償を当てた研究がある．
  - Kockmann, Burget, Černocký 2011, "Application of speaker- and language identification state-of-the-art techniques for emotion recognition," Speech Communication 53(9):1172–1185, doi 10.1016/j.specom.2011.01.007．FAU Aibo で評価し，Interspeech 2009 の 5 クラスの Open Performance Sub-Challenge で UAR 41.7% で 1 位だった（https://www.fit.vut.cz/research/result/c76396/．要旨で確かめた．本文は読んでいない）．
  - prior-work-diff の調べに入れ，位置づけの差分に写すとよい．
- [e3] **gc と nap のもとでのグループの Q3 は，作りの上で小さくなる**：
  - gc は 3 本以上の候補のグループの平均を 0 にするので，gc のもとの top3ex_grp_xe は作りの上で 0 に近い．nap は上位 r 本のグループの向きを消すので，同じ量は作りの上で小さくなる．
  - S4 の「感情か，感情で説明されないグループ・対話か」の比べは，gc と nap ではグループの側が作りの上で負ける．
  - 直し方：S4 に「gc と nap のグループの値は取り除き方そのものの結果で，比べには使わない．対話と感情の値を比べる」と書く．
- [e4] **取り除いた向きと残した向きのモダリティの内訳**：
  - AVT は音声 1,024，顔 512，言葉 768 次元をつなぐ．話者や俳優の違いは主に音声と顔に，話題の違いは主に言葉に乗ると考えられる（推測）．
  - nap が消した向きと pca が残した向きが，どのモダリティの次元に乗っているかが分からないと，取り除き方の効果をモダリティの言葉で説明できない．
  - 直し方：単位ごとに，消した（残した）向き V のブロックごとの二乗の和の割合（音声，顔，言葉の 3 つの数）を残す．V は単位の段にしか無いので，計算の前に足す必要がある．
- [e5] **gc のテストの側の小さいグループ**：
  - 3 本未満のテストのグループの発話は，テストの集合の全体の平均だけを引く（台本 `_center_groups`）．MOSEI のテストの発話の約 5%，MELD の約 1.6%（分割 4 は 0%），AFEW の 0〜1.9% が当たる（グループの大きさだけを数えた）．
  - これはテストの集合で中心を合わせる操作で，グループを除く操作とは違う．
  - 直し方：当たる発話の割合を単位ごとに残し，8 節に書く．
- [e6] **感情ごとの主張**：設計に「感情ごとの主張はしない」と書く（DAI-8 と同じ）．gc で中心に寄った発話がどの感情に判定されるかは，保存したテストの判定から感情ごとの再現率として記述で出せる．

## 確かめたこと

- **話者と内容の分離**：
  - LDA と EM の推定に使うのは，候補の特徴と K 本のラベルだけである（台本 141〜167 行）．
  - nap と pca の写像は，候補の特徴と候補のグループの印だけから作り，テストには同じ写像を当てる．
  - gc はテストの発話のグループの平均を，テストのラベル無しの発話から作る．テストのラベルは使わない．テストの話者の印を使うことは，設計 4 節 86 行と 7 節 105 行に書かれている．感情認識の話者正規化では，テストの話者の印とラベル無しの発話を使う形が普通に使われるので，条件を明記してあれば欠陥ではない．
  - 候補はテストの塊を含まず，MELD はテストの対話も除く（`dai_data.pool_mask`）．評価のターゲット T のデータは入らない．
- **単位**：
  - K 本の抜き方は T に依らない（`dai_data.k_orders` の乱数は (c, f, r) で決まる）．LDA と EM_fromK は T の頭を使わないので，T を 1 つに固定して 40 単位にするのは正しい．
  - 区間は (f, r) を単位にする．
- **ラベルの対応と評価の慣行**：ラベルの照合は DAI-8 と同じ（台本 121〜124 行）．判定は等しい事前で，主指標は UAR である．
- **対話の印**：DAI-8 の `dialogue_ids` を使う．前回までの検査で 4 コーパスの 5 分割すべてで動くことを確かめた．
- **限界の文**：MOSEI の漏れと IEMOCAP の筋書きの共有は 8 節 112 行に，MOSEI と AFEW の感情の違いの消去は 8 節 111 行に書かれている．

  - `DAI/splits/*.csv` のグループの印の列から数えた，分割ごとの候補のグループの数と，テストのグループの大きさの割合．ラベルは使っていない．
