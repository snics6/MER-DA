- 問題：`if not (raw[m] == Pt[j].argmax(1)).all(): raise SystemExit(...)`．保存の `pred_raw_K<K>_ret_<m>` は float64 の確率の argmax で作られ（`exp/dai16_probe.py:649`），`p_test_ret_*` はそれを float32 に丸めて保存している（548 行）．200 単位 × 3 つの K × 3 分類器のテストの発話で，丸めで 1 位の確率が並んだ発話は 1 つ（MELD_ALL_f3_r7，K = 5，声，テストの 2031 番．確率 [0.1473, 0.1116, 0.3705, 0.3705]，保存の判定は 3，float32 の argmax は 2）で，保存の判定の確率は最大と等しい．台本は保存の判定をそのまま使うので，この違いは計算の結果に影響しない
