## 指摘

### [C・I] 提案は切片をずらした判定，単独の分類器はずらさない判定で比べている
- 重さ：直してから進む
- 該当箇所：`tools/dai20_select_strongest.py:91〜92`
- 問題：`single = {m: z[f"pred_raw_K{K}_ret_{m}"] …}`，`"prop": z[f"pred_adj_K{K}_M_F6_mix{i_fz}"]`．提案の adj は，候補の上の確率の平均を積の平均に合わせる切片のずらし（ラベルを使わない．`dai16_probe.py:576〜583`）で，同じ操作は単独の分類器にもラベル無しで当てられる．流して確かめると，このずらしで単独の分類器のテストの判定は中央 3〜5％，最大 15％変わる．したがって prop − sel_* には「まとめ方の違い」と「ずらしの有無」の 2 つが混ざる．prod − sel_K は積のずらしが 0 なので層の違いは無い．実験 20 の本体も A の組では adj どうしと raw どうしの両方の対を出している（`dai20_eval.py:540〜541`）
- 計算の後で直せるか：直せる（学び直しは要らない）．ただし値を見た後に層を選ぶ形になるので，前に入れる
- 求める対応：次の 2 つを足し，主に読む対を値を見る前に docstring に書く．
  1. 同じ層（両方ずらす）：単独の分類器の adj の判定を，`add_extra` の `put` と同じ式で作る．
     ```
     LMt = {m: P16.centered(z[f"p_test_ret_{m}_K{K}"].astype(np.float64)) for m in MODS}
     LMp = {m: P16.centered(z[f"p_pool_ret_{m}_K{K}"].astype(np.float64)) for m in MODS}
     target = np.exp(P16.norm_log(sum(LMp.values()))).mean(0)      # 積の候補の上の平均（add_extra の target と同じ）
     dl, rs = P16.match_shift(LMp[m], target); pred = (LMt[m] + dl).argmax(1)
     ```
     版 `sel_K@adj`・`sel_ext@adj`・`sel_orc@adj` を作り，対 `prop − sel_*@adj`，`prod − sel_K@adj` を足す．自己検査に，同じ式で作った `avg` の adj の判定が保存の `pred_adj_K<K>_avg` と全部の組で一致することを加える（検算では 600 組で一致した）．`rs` の最大も provenance に書く
  2. 同じ層（両方ずらさない）：`"prop@raw": z[f"pred_raw_K{K}_M_F6_mix{i_fz}"]` を足し，対 `prop@raw − sel_*` を足す．自己検査 (1) に `levels.csv` の `prop@raw` の水準と `effects.csv` の `prop − prop@raw` の照合を加える（どちらも集計にある）

### [D・R] 「K 本で最強の 1 つ」を d′ の平均だけで選び，UAR で選ぶ版が無い
- 重さ：直してから進む
- 該当箇所：`tools/dai20_select_strongest.py:93`，docstring 8〜9 行
- 問題：sel_K は `D_M_K_K<K>` の 4 感情の平均（AUC から作る順位の良さで，切片に依らない）で選ぶ．docstring の動機（「最強の 1 つを選べば済むのでは」）に対して査読者が最初に考える選び方は，K 本の上の交差の UAR が最大の分類器である．保存の `pcf_<m>_K<K>`（K 本の各発話に，その発話の組を抜いた分類器が付けた確率）から作ると，d′ の選びと同じ分類器になるのは 600 組中 480 組で，120 組は選びが変わる．UAR の最大は 70 組で同点になる
- 計算の後で直せるか：直せる．ただし選び方を値の後に足すと，結果を見てから相手を選んだ形になる
- 求める対応：版 `sel_Kuar` を足す（`ku = [S.uar(y_pool[kpos], pcf_m.argmax(1)) for m in MODS]`）．同点の規則を値を見る前に決めて書く（推す規則：同点の中で `D_M_K` の平均が最大のもの，それでも同点なら A，V，T の順）．同点の数を `n_tie` に書く．対 `prop − sel_Kuar` を足し，1 の adj の版も同じく作る

### [D] sel_orc を「選び方の上限の目安」と書いているが上限ではない
- 重さ：直してから進む（読んだだけではなく，作りを読んで確かめた）
- 該当箇所：docstring 11〜12 行
- 問題：sel_orc は K 本を除いた候補の上の d′ の平均で選ぶ．候補の発話は疑似ラベルの学び直しに使われた発話で，テストの発話とは話者が別である．テストの UAR で選んだ分類器のほうが高くなる単位がありうるので，sel_orc は「1 つを選ぶ相手の上限」ではない
- 計算の後で直せるか：直せる（説明の語の直し）
- 求める対応：説明を「候補の全ラベルで選んだ参照（新しいコーパスでは手元に無い情報．上限ではない）」に直す．上限を示したいなら，単位ごとにテストの UAR が最大の分類器を使う参照の版 `sel_test` を足し，役割を参照（テストのラベルを使う）と明記する
