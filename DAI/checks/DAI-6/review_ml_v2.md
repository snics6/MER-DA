## 重大な指摘

### [M1′] A1′ の閾値 0.8 は，設計の次元の規則の大きさでは前提が成り立つ場合にも届かず，「共有の方向が入る」と書く結論が前提の真偽によらず出る

- 箇所：
  - 設計 3.4.1 の A1′ の行「0.8 以上なら「上位 3 個は感情の部分空間に近い」，0.8 未満なら「上位 3 個に感情の中の共有か弱い感情の方向が入る」．0.8 は人工データの検算（`--selftest` の (8)：感情の部分が強いとき 0.960，主成分 0.001，感情の中の共有の要因が強いとき 0.644）で決めた」
  - 台本 `DAI/exp/dai6_probe.py:790` の `"top3_emotion": bool(c_s3 >= 0.8)`，`--selftest` の (8)（`:1000-1021`）
- 問題：
  1. **閾値を決めた人工データは，実データより推定がずっと易しい．**`--selftest` の (8) は n = 5,000，30 次元（候補の数 ÷ 次元 ≈ 167）で，感情の間の正準相関は約 0.4 である（感情ごとの平均と雑音の大きさからの本検査の概算）．設計 3.1 の規則では候補の数 ÷ 次元 ≈ 45（p ≈ 0.022 n）になり，検出できる最小の正準相関は約 0.15 である．この大きさでは，前提が厳密に成り立っていても，標本から求めた上位 3 個の方向は母集団の方向から大きくずれる．
  2. **本検査は台本と同じ手順の人工データで確かめた．**`DAI/checks/DAI-6/review_ml_run/a1prime_sim.py`（ログ `a1prime_sim.log`）は，台本の `pca`・`cca`・`_lda_basis`・`sigma_orth`・`principal_cos2` を呼んで A1′ を計算する．CPU だけで流し，実データは読んでいない．
     - 前提が厳密に成り立つ場合（感情の中の共有なし，感情の間の正準相関が 3 つとも 0.25）の S3–LDA の値の平均は，AFEW の大きさ（n = 632，p = 13）で 0.792，IEMOCAP の大きさ（2,212，48）で 0.746，MELD の大きさ（5,995，131）で 0.723，MOSEI の大きさ（14,907，200）で 0.833 だった．0.8 以上になったのは，順に 20 回中 11 回，10 回中 0 回，5 回中 0 回，3 回中 3 回である．
     - 感情の間が不ぞろい（0.40，0.25，0.12）で共有なしの場合，0.8 以上は 4 つの大きさで合わせて 38 回中 1 回だった．値の平均は 0.56〜0.68 である．
     - 感情の中の共有が強い場合（0.40）の値の平均は 0.49〜0.57 だった．前提が成り立つ不ぞろいの場合（0.56〜0.68）との差は 0.1 前後しかない．
     実データの感情の方向は強さが不ぞろいで中程度の見込みが高いので，今の規則では 4 コーパスすべてで「上位 3 個に感情の中の共有か弱い感情の方向が入る」と書く見込みが高い．前提の真偽によらず同じ言葉が出るので，この行は A1′ の問い（上位 3 個を感情の部分が占めるか）に答えない．
  3. **言葉の行は 6 次元と 3 次元を比べる．**言葉の S3 は 2 つの組の上位 3 個ずつの和で 6 次元（設計 3.4.1 の S3 の注，台本 `S3_i_T`），LDA は 3 次元である．でたらめな部分空間どうしでも値は約 6/p になり（AFEW では 6/13 ≈ 0.46），音声と顔の約 3/p（AFEW では 0.23）と同じ閾値では比べられない．
- DAI の基準との関係：報告の誤り．仮定の表は設計 0 節 12 行の目的（前提が成り立つかを測る）に直接答える表であり，前回の M1 と同じ種類の誤り（推定の揺れで決まる言葉を，母集団の性質として書く誤り）が残る．
- 直し方（`summarize` と設計の文だけを変える．`run_unit` と保存する出力は変えない）：
  1. 閾値 0.8 をやめ，単位ごとに「前提が成り立つ」とした参照の分布と比べる．作り方は次のとおりである．
     - 単位の候補の主成分の白色化した座標で，感情ごとの平均をモダリティごとに推定する．
     - 同じ n・p・感情の並びで，「感情ごとの平均 + モダリティごとに独立な正規の雑音（共分散は 単位行列 − 感情の間の共分散）」のデータを作る．
     - このデータで S3–LDA の値を求める（40 回程度）．
     - 観測がこの分布の 5% 点を下回れば「上位 3 個は，前提から予想される範囲より LDA の部分空間から離れている」と書く．下回らなければ「離れているとは言えない」と書く．
     本検査はこの作り方を人工データで試した（`review_ml_run/a1prime_ref_sim.py`，ログ `a1prime_ref_sim.log`）．前提が成り立つ 4 つの設定では「離れている」が 12 回中 1 回，12 回中 0 回，6 回中 0 回，6 回中 1 回で，ほぼ名目の 5% だった．共有が強い設定（0.40）では 12 回中 11 回，6 回中 6 回が「離れている」になった．共有 0.20 が感情の 0.25 より弱い設定でも，12 回中 10 回，6 回中 5 回が「離れている」になった．この設定では A1 が崩れているので，前提の検定としては正しく働いている．ただし，この判定は「上位 3 個を感情が占めない」という意味ではないので，言葉は「前提から予想される範囲より離れている」に限る．共有 0.20 が不ぞろいの感情の 3 番目（0.12）より強い設定では，12 回中 3 回，6 回中 2 回しか検出できない．したがって「離れているとは言えない」も「棄却できない」と同じく検出力の範囲で書く．
  2. 言葉は 2 つの組ごとに，言葉の側の上位 3 個（3 次元）と LDA を比べる．どの行も 3 次元どうしの比べにする．
  3. 主角の値，同じ次元の主成分の値，でたらめの期待値 3/p は記述として並べる．
  4. 参照の回数と乱数の種を `assumptions_lda.csv` に残す．`--selftest` の (8) を，設計 3.1 の大きさ（例：n = 632，p = 13 と n = 2,212，p = 48）で前提が成り立つ場合に「離れている」が約 5% になることを確かめる段に替える．
  5. A1′ は版 (i) だけで計算することを設計に書く（台本 `:779` は `S3_i_*` だけを読む）．

## 確かめたこと

- 前回の指摘と第 4 版の対応は上の表のとおりである．前回の m2 は人工の判定で，前回の m3 は `_hypergeom_p` の定義で確かめた．
- `_lda_basis`（`:709-714`）は，候補の主成分の白色化した座標で Sw⁻¹（感情ごとの平均 − 平均の平均）の 3 列を取る．4 つの差の和は 0 なので，3 列で差の空間の全部を張る．感情の間の共分散を Σ = Sw + Sb の形に足しても張る空間は変わらない（Woodbury の式）．したがって，前提が成り立つときの正準の方向の母集団の空間と同じものを推定している．主角を Σ_mm の計量で測ることは，点数の共分散で測ることに当たり，`--selftest` の (1) と同じである．
