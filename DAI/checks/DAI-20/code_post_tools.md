## 指摘

### [I] 1 本目の照合が，食い違っても NaN でも止まらない（`dai20_posthoc_intercept.py`）
- 重さ：直してから進む
- 該当箇所：`dai20_posthoc_intercept.py:121-136`
- 問題：「全体 ＝ 切片 ＋ 向き」の検算（123 行）と集計の段との照合（125〜131 行）は値を画面とファイルに書くだけで，ずれが大きくても NaN でも終了コード 0 で終わる．集計の段との照合は，`summary/effects.csv` が無いと黙って NaN になり（127 行），合わせられた行の数も確かめない．照らすのも `prop` の adj の点推定だけである．なお，足し合わせの検算は単位ごとの足し算が線形であることを確かめるだけで，ほぼ恒等式である（下調べでずれ 3.5e-14）．版の名前の取り違えを捕まえられるのは集計の段との照合だけである．
- 計算の後で直せるか：直せる（学び直しは要らない）．ただし，照合の弱いまま出た表を文書に写すと取り違えを見逃しうる．
- 求める対応：
