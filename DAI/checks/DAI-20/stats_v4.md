### 指摘 2 の確認（`same_as` が設計 154 行の版を取りこぼさないか）

台本の基準は「(T, K) の全部の単位 (f, r) で，塊ごと・感情ごとの正解の数（`_finish` の後の `dd[k_][1]`）がビット単位で同じ」である．設計 154 行が挙げる同じになる版を 1 つずつ式で当てた．格子の番号は n0 ×4 ＋ β ×2 ＋ 戻し先（`dai16_probe.py:74`）で，点 0 ＝ (0, 0, eq)，点 2 ＝ (0, 1, eq)，点 12 ＝ (∞, 0, eq)，点 14 ＝ (∞, 1, eq) である．固定した点は AFEW K=5・25 が点 6，MELD K=5・10 が点 7，残りの 8 つの (T, K) が点 2 である（固定のファイル．β はすべて 1）．

1. **n0 = 0 の 8 つの (T, K) で，相性を外した版 ＝ 水準だけの重み**：`prop_noprof` は `same_but(2, beta=0)` ＝ 点 0 で，`mix_rel`（`dai16_probe.py:174-182`）は n0 = 0 で w = 1 なので L ＝ 1·L_K ＋ 0·L_0 ＝ L_K になり，β = 0 で重みは行ごとに一定の max(0, L_K)（d′ は 0 以上なので L_K ≥ 0）．`to_w` で平均 1 に割ると行 k の重みは L_K[k] ÷ L_K の平均である．`M_F2_K` は `to_w(D_K)` の行の平均（`combine` の F2，`dai16_probe.py:410-411`）で，数式では同じ値である．計算の順序が違うので重みは丸めの分だけ違いうる．確かめの台本で，人工の数 200 組（判定 600,000 件）について 2 つの道を通すと，重みの差の最大は 6.7e-16 で，raw と adj のどちらの判定も 1 件も違わなかった．どちらの版も `names`（台本 460-462 行）に入るので，同じ群になる．
2. **n0 = 0 の (T, K) で，n0 を外した版 ＝ 提案**：`same_but(i, n0=0)` は i 自身を返すので，2 つの版は npz の同じ配列を読む．同じ群になる．
3. **相性を使わない点を選び直した版が点 0 を選んだ (T, K) で ＝ 水準だけの重み**：点 0 は n0 に依らず 1 と同じ式なので，n0 = 20 の (T, K)（AFEW K=25，MELD K=10）でも同じ群になる．

5. **重みの表を探す版で等しい重みの表だけが選ばれた場合**：その単位の判定は積の raw の判定の写しである（台本 326-328 行）．積の adj は，切片の目標が積自身の候補の上の平均なので `match_shift` の最初の反復で止まり（`dai16_probe.py:134-143`），ずれは 0 で raw と同じ判定になる．全部の単位でこれが起きた (T, K) では，`wf` と積は同じ群になる．一部の単位だけで起きた場合は版として同じではないので，群にしないのが正しい．

## 差分で足した量のうち，指摘の無かった点

- `prop_levelfree`（点 14）は下調べの格子の中の点で，固定した点が全部 β = 1，戻し先 eq か ext なので，相性の強さは提案と同じである（違いは水準だけ．上の指摘 3 の (a) を除く）．比べの対は台本 520 行の `("prop_levelfree", "prod")` と 518 行の `("prop", "prop_levelfree")` で，2 つの順序の 4 つの項がすべて `effects.csv` に出る．`("prop_noint", "prop_noprof")` も足された．
- 提案の adj − 相手の raw（台本 521 行．積を除く 12 個）：同じ単位の上の対の差で，`effect_stats` を同じく通る．設計 98 行（`review_ml_v3.md` の n1 への対応）が，adj と raw で判定の違う割合と，raw が重みの全体の倍率に依らないことを書いている．`tcal`・`temp`・`tempb` の raw は Σ w_k L_k の argmax なので，倍率に依らないことは正しい．
- `tcal`：K 本だけで重みを合わせ，K 本での見積もり（入れ子）を `temp` と同じ道で出す（台本 307-318 行）．テストのラベルは選びに入らない．罰則と範囲は `temp` と同じ定数で，この相手のために選んでいない．範囲の端に当たった割合 `w_bound` を残す．
- `psel`：指数は実験 1 が T を含まない仮のターゲットの回で選んだ値で，T のテストは選びに入らない．平均 1 に割る操作は raw の判定を変えない．raw の判定が実験 1 の `prod_sel` と一致する割合 `psel_agree` を集計が画面に出す．
- 区間の数の注（設計 157 行）：77 × 12 ＝ 924，種で分けた値を入れて 2,772 個．台本の対の一覧と合う．差が全部 0 でも，補正しない 95% の区間は片側 2.5% の割合で 0 をまたがないので，1.0 点の下限が無ければ 924 個のうち 23 個前後に印が付きうる（下限と行どうしの依存のため実際はこれより少ない）．設計は「偶然の印は付きうる」「印の数を主張に使わない」と書いており，これで足りる．
- `per_emotion.csv` の `n_per_seed`（台本 514 行）：全単位の合計 × 分割の数 ÷ 単位の数で，各分割に種 10 がそろうとき，種 1 つぶんの別々の発話の数に等しい．
- 検出の見込みと符号検定の下限（2^(1−4) ＝ 0.125）は前回と変わらない．
