## 2．`md_tables_dai20.py` の差分と表の文書

### 差分
- `fest`：差を小数 2 桁で書く．丸めると ±1.00 になる値には桁を足す（3〜5 桁）．
- `fend`：区間の端を小数 1 桁で書く．|x| < 0.05 で 0 でない値には，0 でなくなるまで桁を足す（2〜4 桁）．
- 記録 5 への対応として，C の表の単位の数が {50, 15} の外なら止まる．
- 桁の注を 1 行足した．

読んだ限り，±1.00 と 0 の境目を読めるようにする意図どおりに動く．具体例：
- −0.996 は「−0.996」になる．
- 1.004 は「+1.004」になる（↑ の印は推定が 1.0 以上で付くので，表示と印が合う）．
- −0.03 は「−0.03」になる．
- NaN は「+nan」のまま出る．
