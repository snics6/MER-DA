用語：
- **LDA（共通の広がりのガウスの判別）**：感情ごとの平均と，全感情で共通の広がり Σ を使い，発話を「広がりで測った距離が最も近い平均」の感情に分ける手続きである．
- **計量**：距離を測る物差しのことで，ここでは Σ⁻¹ を指す．LDA_K は K 本の発話から作った物差し，LDA_T はラベル無しの候補の全体の散らばり T から作った物差し A = (1 − α)T + αI を使う．
- **NCM（最近傍の平均．等方の計量）**：Σ = I の LDA である．特徴は候補の統計で次元ごとに標準化してあるので，「標準化した特徴の普通の距離で，K 本の平均に最も近い感情を選ぶ」ことになる．α = 1 の LDA_K と α = 1 の LDA_T はどちらも NCM と同じになる．
- **オラクル**：実際には使えない候補の全ラベルを使う比べである．仕組みを分けて測るためだけに使う．
- **縮みの係数**：計量 A が感情の平均の散らばり自身を含むために，感情の向きの重みが何倍に縮むかを表す数である．

### [M2] 縮みの係数の式が α = 0.5 で誤っている．λ > 1 のとき負の縮みを出す
- 箇所：設計 56 行（「A⁻¹B の固有値 λ の大きい 3 つ（α = 0.5）…信号の縮みは 1 − λ，向きの誤差の拡大は 1/(1 − λ) である（調べの 6.1 節．A の縮小を入れると近似）」），23 行（「T⁻¹M̂ は…(I + ΠG)⁻¹ で縮め」），台本 `emo_eigs` の説明（107〜108 行）
- 問題：
  1. **式の導出．**候補の全ラベルで，T = S_O + B が厳密に成り立つ（S_O は群内，B は割合 π で重みづけた感情の平均の散らばり．`lda_from_R` の Sm と同じ）．したがって A = (1 − α)T + αI = Σ_O + (1 − α)B である（Σ_O = (1 − α)S_O + αI は LDA_SO と LDA_O の物差し）．Woodbury の式から
     ```
     A⁻¹M = Σ_O⁻¹M·C，  C = (I + (1 − α)·Π·Mᵀ Σ_O⁻¹ M)⁻¹
     ```
     である．C の固有値（感情の向きの縮み）は 1/(1 + (1 − α)λ_O) で，λ_O は Σ_O⁻¹B の固有値である．台本が出す λ（A⁻¹B の固有値）とは λ = λ_O / (1 + (1 − α)λ_O) の関係がある．まとめると次のとおりで，どれも近似ではなく厳密である．
     ```
     信号の縮み        = 1 − (1 − α)·λ          （α = 0.5 では 1 − 0.5λ）
     向きの誤差の拡大  = 1 / (1 − (1 − α)·λ)  = 1 + (1 − α)·λ_O
     λ の取りうる範囲  = 0 以上 1/(1 − α) 未満  （α = 0.5 では 0 以上 2 未満）
     ```
     設計の「1 − λ」は α = 0 のときだけ正しい．23 行の (I + ΠG)⁻¹ も，α > 0 では (I + (1 − α)ΠG)⁻¹（G は Σ_O で白色化した座標での感情の平均のグラム行列）になる．
  2. **人工データで確かめた**（`DAI/checks/DAI-10/review_ml_run/shrink_sim.py`，`shrink_sim.log`．台本の `emo_eigs`・`metric_chol` と DAI-8 の `lda_from_R` を呼び，A⁻¹M と Σ_O⁻¹M から C を直接解いて固有値を出した）．d = 50，候補 2,000 本，感情の平均の離れ方 4，α = 0.5 のとき，λ = 1.363，1.058，0.569 で，設計の 1 − λ は −0.363，−0.058，0.431 になる．正しい 1 − 0.5λ は 0.319，0.471，0.715 で，C の固有値（0.319，0.471）と 3 桁で一致した．λ_O/(1 + (1 − α)λ_O) と λ の一致も，α ∈ {0.01，0.5，0.9} の 12 通りの設定すべてで 3 桁まで確かめた．
  3. **実データでも λ > 1 が出ている．**DAI-8・9 の結果の文の下書き 248〜252 行の表は，同じ計量 A = 0.5T + 0.5I での感情の割り当ての上位 3 つの固有値の和（帰無を引かない値）を，DAI-9 の raw の空間で AFEW 4.67，IEMOCAP 3.93 と書く．3 つの和が 3 を超えるので，最大の λ は AFEW で 1.56 以上，IEMOCAP で 1.31 以上であり，設計の式では縮みが負になる．DAI-10 の `emo_eigs` の和は DAI-8 の `_top3` と同じ量である（設計 56 行，自己検査 461 行）．
- DAI の基準との関係：報告の誤りに当たる．このまま結果の文に縮みの係数を書くと，負の縮みや負の拡大の倍率が出る．
- 直し方：設計 56 行と 23 行の式を上の形に直し，「近似」の語を外す（候補の全ラベルの B と S_O で厳密に成り立つ．K 本の平均の雑音を含む LDA_T の判定への効き方は記述である，と書く）．台本の計算は変えなくてよい．`emo_eigs` の説明の文（107〜108 行）を直し，集計の `diag.csv` に `shrink_k = 1 − (1 − α)·eigs_k` の列を足すか，結果の表を作るときにこの式で計算する．帰無の平均を引いた λ を使う場合も同じ式に入れる．
