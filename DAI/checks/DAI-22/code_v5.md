- **止まった記録のファイルを通して値が見える**（[記録 2]）．`docs/methods.md` 9.3 節に「照合で止まったときに書く記録のファイルには識別子と照合の列だけを入れるか，量の列を含むなら開く前に列を選ぶ手順を設計に書く」を足す案．
- **検査の途中で台本が替わる**．今回は検査の途中で台本が ff3a64b から 540bba2 に替わり，その時点で流れていた試走は，どちらの版で流れたかが分からなくなった．9 節の手順に「検査役に渡した後に台本を直すときは，検査役に知らせ，検査役はそれまでの試走を新しいコミットで流し直す」を足す案．
