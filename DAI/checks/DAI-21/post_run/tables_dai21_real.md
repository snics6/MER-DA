- 値は UAR（%）．差は UAR の点の差で，括弧は 95% 区間（補正していない）．↑・↓ は読みやすさのための印（区間が 0 を含まず，差が 1.0 点以上）で，判定ではない．印の無い差は「同じ水準」を意味しない．
- 「提案の手法」は，感情ごとの信頼度の表で分類器の答えをまとめる手法である．「推定時の答え」はまとめた答えそのもの，「学び直した融合」は，その答えを疑似ラベルにして融合の分類器を学び直したものである．
- 「今の提案」は，分類器の確率の積を疑似ラベルにして融合の分類器を学び直す手法（実験 1）である．
- 「切片をずらした答え」は，ラベルを使わずに切片をずらした答えである．ずらす量は，ラベル無しの候補の発話の上で，その版の確率の平均が，積の確率の平均と同じになるように決める（積はずらす前と後で同じ答えになる）．「切片をずらす前」はそのままの答えである．
- 学び直しの設定（疑似ラベルの重みと K 本の倍率）は，積の疑似ラベルのために選ばれた点を，どの疑似ラベルにも使った（主の点）．
