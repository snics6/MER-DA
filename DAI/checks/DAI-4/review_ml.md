### [M1] 案の出どころの扱い：根本的な欠陥ではないが，申告の文だけでは足りない
- 箇所：設計 0 節「案の出どころ（正直な申告．漏れの L2）」「手法の形と格子はこの文書で固定し，設定の選択は仮のターゲットの回の出力だけで行う」，7 節「評価のターゲットの成績は，評価の段の後の stats まで見ない」，`docs/seen-data.md` の DAI-4 の行「評価のターゲットの成績は見ていない」
- 問題 1（再現の独立性）：設計は，評価の回の診断を「仮のターゲットの回の 120 単位で再現した」と書く．しかし仮のターゲット c = X の単位の候補は，評価のターゲット T = X の単位の候補と同じコーパス・同じ 5 分割・同じ発話・同じラベルである（違いはソースが 2 つか 3 つかだけ）．実際，`consensus_cells.csv`（評価の回）と `consensus_pseudo_cells.csv` の教師の正解率は，AFEW の音声の生徒で一致群 0.87 対 0.86，不一致群 0.62 対 0.63，AVT で 0.91 対 0.91 と，ほぼ同じ数である．同じ発話のラベルを数えているので当然であり，別のデータでの再現にはなっていない．この診断が支えるのは「教師の正解率が一致の有無で分かれる」ことが，ソースが 2 つでも 3 つでも成り立つ，という範囲だけである．
- 問題 2（見たもの）：`results/explore_consensus/teacher_adv_cells.csv` と `teacher_adv_units.csv` に，評価のターゲットのテストの UAR（`none_uar_test`，`prop_uar_test`，`kd_uar_test`，`gain_prop`，`gain_kd`）が入っている．`docs/seen-data.md` の 99 行目にも，探索で「提案と KD の得」を研究者と本体が見たと書いてある．実験 1 の評価の回の途中の値（95〜98 行目）も見ている．したがって設計 7 節と seen-data の DAI-4 の行の「評価のターゲットの成績は見ていない」は事実と合わない．見ていないのは，この実験の手法 `cons` のテストの成績だけである．比較相手 `joint`・`kd`・`none` の評価のターゲットでの成績は，一部の T で見ている．
- 問題 3（候補のラベルの経由）：評価の回の診断は候補のラベルを数えた．候補は分割ごとに入れ替わるので，5 分割を合わせると，全発話のラベルが診断のどこかに入る．テストの発話のラベルも，コーパス全体の「一致の有無ごとの教師の正解率」という集計の形で設計に入っている．個々の発話の判定を選ぶ使い方ではないが，T のテストを設計に使っていない，とは書けない．
- DAI の基準との関係：選択は仮のターゲットの回で行い，案は K 本の外のラベルを学習に使わないので，結果を捏造する形の漏れではない．根本的な欠陥には当たらない．ただし，報告に不正確な文が残る（問題 2）ことと，p 値を確認の検定と読ませる書き方になりうること（M4）は，報告の誤りとして不採択の理由になりうる．
- 直し方（どれも設計と文書の書き換えで済む）：
  1. 設計 7 節と seen-data の DAI-4 の行から「評価のターゲットの成績は見ていない」を外し，「`cons` のテストの成績は見ていない．`joint`・`kd`・`none` の評価のターゲットでの成績は，評価の回の途中で一部の T について見た（seen-data の 95〜99 行目）」と書く．
  2. 設計 0 節の「再現」を「仮のターゲットの回（ソース 2 つ）でも，同じ候補のラベルに対して同じ傾向だった」に直す．独立した確認とは書かない．
  3. 論文の限界には「手法の案は，評価に使う 4 コーパスの候補のラベルを数えた診断から出た．選択は仮のターゲットで行ったが，仮のターゲットの候補は評価の候補と同じ発話である．4 コーパスの外の確認は行っていない」と書く．方法の節にも同じ文を置く．
  4. 事前登録の語を，設計 3 節の見込みに使わない（M4）．
- 補足（推測）：4 コーパスの外に未使用のコーパスは無い（CREMA-D などは 4 ラベルの設定で別の群）ので，実験 1 の 9.5 節の第 2 のエンコーダの繰り返しも，同じ発話を使う以上，独立した確認にはならない．これは限界に書く事柄であり，設計の欠陥ではない．

### [M2] 比べる相手と，印の定義を支える除去実験が無い（主張が「得」だけなら記述の追加で足りる）
- 箇所：設計 2 節の表と「並べる量」，1 節「生徒自身のモダリティの判定は使わない（生徒と一致する発話には生徒がまだ知らない情報が無いため．実験 1 の『一致した発話だけの疑似ラベル』との違い）」
- 問題：(a) 最も近い相手は実験 1 の `agree`（一致した発話だけの疑似ラベル）であり，`cons` の γ = 0 に近い．`cons` − `agree` が表に無い．ここが無いと，「重みづけ」の得か，「生徒以外の一致」の定義の得か，単に疑似ラベルを減らした得かを分けられない．(b) 印の定義が生徒以外の 2 つに決まっている根拠は，設計の文の理屈だけで，生徒を含む 3 つの一致を使う版との比較が無い．(c) 設計は目的関数全体の重みを ρ n に正規化し直すので，印の無い発話を γ 倍にすると印の有る発話の重みが相対的に増える．印の中身に意味があるのか，印をでたらめに付けて同じ割合の発話を弱めた場合でも同じ得が出るのか，確かめる比較が無い．
- DAI の基準との関係：論文が「一致の情報が効く」「なぜ効くか」を書くなら，代わりの説明を退ける比較が無い報告の誤りになる．「joint より良いか」だけを書くなら不要である．
- 直し方：設計 0 節か 8 節に，論文が書く主張の範囲を 1 文で固定する．そのうえで次のどちらかを選ぶ．(i) 主張を「`joint` との差」に限り，「効く理由」を書かないと決める．(ii) 理由まで書くなら，選んだ設定の点だけで，次の 3 行を評価の回に足す（記述．p 値なし．仮のターゲットで選ぶ規則を同じに保つ）：`agree`（実験 1 の保存から読む），印を生徒を含む一致にした版（AVT 以外の生徒），印を同じ割合でランダムに付けた版（印の割合は実際の割合に合わせ，乱数の種は固定）．

### [M3] 計算機の取り決めが実験 1 と食い違う
- 箇所：設計 6 節「研究室の GPU で回せる」，4 節の `eval`
- 問題：実験 1 の設計 9.1 節は，評価の回を全単位同じ種類の計算機（H200）で回し，計算機の名前を行ごとに残し，A5000 の単位があれば同じ 1 単位を両方で回して W と UAR の一致を記録する，と決めている．この設計は A5000 でも回せると書くだけで，どこで回すか，計算機の名前を残すか，を決めていない．族 6 の差は `joint`（H200 で解いた保存）と `cons`（別の機械で解く）の対応のある差になる．機械が違うと，浮動小数点の差で決定境界に近い発話の判定が変わり，差に機械の差が混ざる．
- DAI の基準との関係：再現性の記述の欠けであり，根本的な欠陥ではない．放置すると，差が 0.5〜1.5 ポイントと小さい見込みのとき，機械の差を分けられない．
- 直し方：評価の段は H200 に固定する．計算機の名前を単位ごとに残す．仮のターゲットの回を A5000 で回す場合は，実験 1 の 9.1 節と同じ「同じ 1 単位を両方で回して一致を記録する」手順を足す．

### [M4] 事前の見込み（3 節）が，結果を見て変えられない形になっていない
- 箇所：設計 3 節「事前に書く見込み（結果を見てから書き換えない）」
- 問題：(a) 見込みの方向と大きさ（音声と言葉で +0.5〜1.5，顔と AVT は 0 付近，MELD と MOSEI は効かない）は，診断の表（評価の回の診断を含む）を見たうえで書かれており，事前登録ではない．設計 0 節がその事実を認めているのに，3 節の題が「事前に書く」である．(b) 「正」「0 に近い」「効かない」を，どの数でどう判定するかの規則が無い．結果が出た後で「0 に近い」を後から広く取れば，どの結果も見込みと合ったことにできる．(c) 「+0.5〜1.5 ポイント」の出し方（診断のどの数から計算したか）が書かれておらず，検出力の見積もりに使えない．
- DAI の基準との関係：「結果が正確に報告されているか」に関わる．見込みと一致したと報告するなら，判定の規則が先に必要である．
- 直し方：題を「診断を見たうえでの見込み（事前登録ではない）」に変える．各見込みに，判定の規則を数で足す（例：音声と言葉の生徒の 8 セル（4 コーパス × 2 生徒．K = 5，25 の平均）のうち，点推定が正のものの数が何個以上なら「見込みどおり」，何個以下なら「見込みと違う」，その間は「判定しない」）．「+0.5〜1.5」の計算の根拠を 1 つの式か表で書くか，数を削る．コミット後は変えない．

### [M5] 台本に入れる検査（gate-code への申し送り）
- 箇所：設計 1 節「γ = 1 で実験 1 の同時に解く版（a = 1）に一致する」，4 節「教師と印は段 2 の保存した重みから作る」
- 問題：この一致は設計の主張であって，まだ検査されていない．段 2 の保存した重みから作り直した教師が，実験 1 で使った教師の判定と一致する保証も書かれていない．さらに，γ = 0 では，ある感情に印の付いた発話が 1 つも無い単位（AFEW の K = 0 や，K = 5 の少数の感情）で，感情ごとの総量をそろえる段が 0 で割る，または全重みが 1 つの感情に集まるおそれがある．
- DAI の基準との関係：台本の誤りが結果の誤りにつながるおそれがある（報告の正確さ）．
- 直し方：台本に (1) γ = 1 を数単位で解き，実験 1 の `joint` の a = 1 の行と W・判定が一致することを確かめる，(2) 作り直した教師の argmax が実験 1 の保存の判定と一致する割合を残す，(3) 感情ごとの印の数が 0 のとき止めるか，その単位を数えて報告する，の 3 つを入れる．gate-code に検査させる．

6. 再現性：コミット，固定のファイルの sha256，保存の契約，再開の規則は実験 1 を引き継いでおり良い．計算機の名前と，ライブラリの版，種の残し方は設計 4 節に明記が無い（実験 1 の 11 節に頼っている）．M3 と m7 で補う．
