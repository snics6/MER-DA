## 指摘

### [D1] K = 0 の教師の書き方が，実験 1 の実際の作り方と食い違う
- 重さ：直してから進む
- 該当箇所：`DAI/docs/実験4_設計.md:20`（「K = 0：…教師は出発点の識別器から作る（実験 1 と同じ）．信頼の印も同じ識別器から作る」），`DAI/exp/dai1.py:263-270`（`build_tk`），`:280-290`（`pass2`）
- 問題：実験 1 の K = 0 の教師は，出発点の識別器の積ではない．`pass2` は K = 0 でも，融合 AVT の出発点の予測を疑似ラベルにして A・V・T の識別器を学び直し（`p2_K0_ret_<m>_W/_b`），`build_tk` は全 K でこの `ret_m` から積を作る．設計 20 行をそのまま実装すると，出発点の識別器（`u.start[m]`）の積を使って，joint と違う教師になる可能性がある．その場合は γ = 1 でも joint に一致しない．
- 計算の後で直せるか：直せない（評価の回は 1 回だけ）
- 求める対応：20 行を「K = 0 でも段 2 の `p2_K0_ret_<m>_W/_b` から教師と印を作る」に書き直す．台本の検査で，K = 0 の教師が `build_tk` の `ret_m` の積と一致することを確かめさせる．K = 0 の印は，診断（K = 5・25 だけ）で一度も測っていないので，3 節の見込みは K = 0 に根拠が無いと書く．

### [D1] 印の定義が一意でない細部が 4 つある
- 重さ：直してから進む
- 該当箇所：`実験4_設計.md:14-16, 33`，`explore_consensus_pseudo.py:23-31`
- 問題：
  1. K 本の発話は候補に入っており（`dai1.py:402` の joint は K 本にも疑似ラベルの重みを置く），印 c_i と重みを K 本の発話にも付けるのか，印の割合と教師の正解率の分母から K 本を除くのかが書かれていない．診断は分母から K 本を除いている（`nk`）が，学習の G は除いていない．AFEW の K = 25 では候補 632 本のうち 100 本で，無視できない．
  2. 診断は段 2 が保存した float16 の `_pool` 確率の argmax で印を作った．設計は float32 の重みと切片を候補の標準化した特徴に当てて作り直す（14 行）．float16 の同値や接近した 2 つの確率の扱いが両者で違い，設計に書いた「診断と同じ傾向」の数値は作り直した印では少し動く．同値のときの argmax（先の番号）と，計算の型（float64 で作る．保存は int8）を固定する．
  3. 印のある発話の割合は生徒で大きく違う．仮のターゲットの回で，2 つの一致（A・V・T の生徒）は 34〜59%，3 つの一致（AVT の生徒）は 22〜50% だった．同じ γ が生徒ごとに違う重みの比を生む（次項）．AVT の生徒の γ の効きは，A・V・T の生徒と同じ尺度ではない．
  4. 「生徒自身のモダリティの判定は使わない（生徒がまだ知らない情報が無いため）」（15 行）は，成り立たない．学び直した V と T の識別器は，A を含む融合 AVT の予測を疑似ラベルにして学んでいる（`dai1.py:285-288`．実験 1 の設計 7 節「予測に入るモダリティ（a5）」が既に書いている）．A の生徒の印（V と T の一致）には A の情報が入っている．
- 計算の後で直せるか：直せない（印の定義は評価の回の保存に固定される）
- 求める対応：(1)(2) を設計に書く（推す定義：印と重みは K 本を含む全候補に付け，印の割合と正解率の分母は K 本を除く．argmax は float64 の確率で，同値は小さい番号）．(3) を重みの読み（次項）に書く．(4) は 15 行の理由の文を「生徒以外のモダリティの識別器の判定だが，それらも生徒のモダリティを含む AVT の予測で学んでいる」に直し，D8 の表（後述）の行 2 で測る．

### [D1・D3] 重みの式の読み方（γ = 1 の一致と合計 ρ n は成り立つ．印の有無の比は感情ごとに違う）
- 重さ：記録する（読みを書き，出力に有効な本数を残す）
- 該当箇所：`実験4_設計.md:16`，`dai_solver.py:46-50`
- 問題：式を展開すると，S_k = Σ_j m_j Q_jk として G_ik = m_i Q_ik · ρ n / (4 S_k) である．
  - 「γ = 1 で joint に一致」：m ≡ 1 なら `soft_rows(Q, ρ n)` そのものなので，式は厳密に一致する．
  - 「全体の重みの合計 ρ n」：厳密に成り立つ（各感情の列の総量は ρ n / 4）．ただし γ = 0 で，ある感情に印の付いた発話の確率の質量が無い（S_k = 0）と，`clamp(1e-12)` で列が 0 のままになり，その感情の重みが 0 になる（合計は ρ n だが「感情ごとの総量をそろえる」が崩れる）．
  - 感情 k の中で，印の無い発話の 1 本あたりの重みは，同じ確率の印の有る発話の γ 倍である．しかし印の無い発話に置かれる重みの割合は γ U_k / (M_k + γ U_k)（M_k，U_k は印の有る・無い発話の Q_ik の和）で，感情ごとに違う．印の有る発話の重みは joint より (M_k + U_k)/(M_k + γ U_k) 倍に増える．
  - 仮のターゲットの回で数えた値：γ = 1/4 のとき，印の無い発話の重みの割合は感情ごとに 0.14〜0.55（例：IEMOCAP ← MELD，K = 0，AVT の生徒は 0.55・0.36・0.48・0.43．MOSEI ← AFEW，K = 0，A の生徒は 0.27・0.23・0.16・0.14）．γ = 1 の joint では 0.40〜0.83 で，印のある発話は少数派（22〜59%）だから，γ = 1/4 でも印の無い発話の絶対の重みは joint の約 0.5〜0.65 倍にしか下がらず，代わりに印の有る発話が約 1.5〜2.5 倍になる．
  - γ = 0 では，感情ごとの重みの有効な本数 (Σw)²/Σw² が joint の 1/2〜1/5 になる（仮のターゲットの最小は 46．joint は 175〜272．MOSEI ← AFEW，K = 0・5，AVT の生徒）．評価のターゲットの AFEW（候補 約 630 本）は仮のターゲットのどの c より小さく，更に小さい見込みである．
- 計算の後で直せるか：読みは直せる．有効な本数の記録は計算の前に決めないと残らない
- 求める対応：設計 16 行に上の読み（「γ は感情の中の 1 本あたりの重みの比であり，印の無い発話の重みの割合ではない．割合は感情と生徒で違う」）と，γ = 1/4 の実際の割合の幅を書く．単位ごとに，感情ごとの S_k，有効な本数，印の無い発話の重みの割合を保存の契約（設計 55 行）に足す．S_k が 1 未満の感情があれば数える．

### [D2] 診断の正解率（micro）と，学習が目指す UAR（感情の釣り合い）が違う
- 重さ：記録する（保存した印と W・b とラベルから後でも出せる）
- 該当箇所：`実験4_設計.md:6, 33, 38`，`explore_consensus_pseudo.py:30`（`tr[g].mean()`）
- 問題：診断の「教師の正解率」は発話の数の平均（micro）である．G は感情ごとの総量をそろえており，評価は UAR（感情ごとの再現率の平均）である．重みづけで直す量は，感情ごとの重みの中で正しい感情に置かれた割合である．設計の「並べる量」の正解率をこのまま作ると，重みの式にも UAR にも直結しない．
- 求める対応：並べる量に次を足す．(a) 疑似ラベルの重みのうち正解の感情に置かれた割合を感情ごとに出して平均した値（macro）を，cons（選んだ設定）と joint で．K 本を除く候補のラベルで数える．(b) 教師の正解率の差（印の有る・無い）は，教師の予測感情ごとに差を出して平均した値と，生の差の両方．参考：仮のターゲットの回（K = 5，12 組）で，(a) は joint が 51.5%，γ = 1/4 の cons は A・V・T・AVT の生徒でそれぞれ +5.1・+3.5・+4.7・+6.9 ポイント，γ = 0 は +8.9・+5.7・+7.8・+14.5，γ = 1/2 は +2.7・+2.0・+2.7・+3.4 だった．この量の伸びが UAR の伸びにどう結びつくかは設計に書かれておらず，3 節の大きさ（+0.5〜1.5）は導かれていない（次項）．

### [D6] 偶然の水準（印を無作為に付けた対照）が無い
- 重さ：直してから進む（評価の回は 1 回だけで，後から足せない）
- 該当箇所：`実験4_設計.md:24-34`
- 問題：「cons − joint」が正でも，それが「一致という情報」によるのか，「重みを偏らせたこと」によるのかを分ける対照が無い．γ < 1 の重みは有効な本数を減らすので，印が無作為でも cons − joint は 0 にならず負に偏る見込みがある．「印の有無の教師の正解率の差」にも，印が無作為なときの水準が書かれていない．
- 求める対応：行 `cons_rand`（印の割合を同じにし，教師の予測感情ごとに印を並べ替えた版．選んだ設定と同じ (ρ, γ)）を並べる量に足す．格子ごとの解き直しは要らず，選んだ設定の 1 点（4 生徒 × K 3）を足すだけである．診断側は，教師の予測感情で層別に印を並べ替えた差の分布を偶然の水準にする．参考：仮のターゲットの回（K = 5）で，無作為の印（γ = 1/4）の (a) の量は −0.1〜+0.2 ポイント（本物の印は +3.5〜+6.9）で，教師の予測感情で層別にした差は生の差とほぼ同じ（A の生徒で 15.1 と 14.9 ポイント）．つまり診断の差は感情の構成による見かけではなく，この点は設計の主張を支える．

### [D1・D5] 事前の見込み（3 節）の量と規則が定まっていない
- 重さ：直してから進む（結果を見る前に固定する節であり，後からは直せない）
- 該当箇所：`実験4_設計.md:32, 38-42`
- 問題：
  1. 主の量の符号と単位は「正が cons に有利」（32 行）で足りるが，大きさ「+0.5〜1.5 ポイント」（38 行）の導き方が無い．根拠の「直す・壊すの割合」から UAR の差への換算が書かれていない．上の (a) の伸び（+3〜+7 ポイント）が UAR の差にどう移るかも書かれていない．
  2. 見込みの規則が衝突する．「音声と言葉の生徒で正」（38 行）と「MELD と MOSEI では効かない」（41 行）は，MELD と MOSEI の A・T の生徒のセルで両立しない．優先を決めていない．
  3. 「0 に近い」（39・40 行）の基準が無い．検出できる差の見込みは，実験 1 の族 3（K = 5）で AFEW 1.9〜2.7，IEMOCAP 1.2〜3.1，MELD 1.4〜1.6，MOSEI 0.3〜0.6 ポイント（`DAI/frozen/dai1_frozen.json` の `detect`．族 6 は同じ単位の対なので近い値になる見込みの参考値）である．+0.5〜1.5 の見込みは MOSEI でだけ検出できるが，MOSEI は「効かない」と予言している．検出できる所では 0，検出できない所で正を予言しているので，見込みは判定できない．
  4. 「AVT の生徒は 0 に近い」（40 行）は，AVT の生徒で上の (a) が最大（+6.9）であることと，一致する発話は生徒が既に当てている所であることの両方から，符号が負になる可能性もある（3 つの一致の外の発話に，生徒が直すべき発話が残るため）．符号を書いていない．
  5. cons の格子に γ = 1 が無い（18 行）ので，cons − joint は「γ ∈ {0, 1/4, 1/2} の最良 − γ = 1」であり，印が無効なとき 0 を中心にしない（選択で最良の点を取る分だけ上に，γ < 1 の有効な本数の減りの分だけ下に動く）．joint の a の格子は実験 1 の固定のファイルで全 80 セル（コーパス 4 × 生徒 4 × K 5）a = 1 に選ばれており，有効な格子は ρ の 4 点だけで，cons の 12 点との自由度が違う（C の項目．ここには記録だけ）．

## 目録に無い種類の不備
1. **評価の回の保存を見た後に作った案で，事前の見込みの根拠に評価の回の値が入る**．設計 3 節の「診断の直す・壊す」は，評価の回の候補のラベル（K = 5・25，AFEW・IEMOCAP・MELD の 50 単位と MOSEI の 39 単位）から出た値を含む（6 行）．台帳 99 行の探索（目標の予測と none[K] の候補での UAR，提案と KD の得）と 100 行の探索は，評価の回の値を見ている．一方，設計 74 行と台帳 101 行は「評価のターゲットの成績は見ていない」と書く．候補のラベルでの教師の正解率と，提案と KD の得（成績）は別の量だが，後者は台帳 99 行で見ており，cons − joint はその得の延長にある．「見ていない」の範囲を「評価のテストの発話の UAR」と限定し，台帳 99・100 行を引いて書き直すことを `gate-leak` に回す（L2・L12 の領域．ここでは記録）．
2. **評価の回で再度数える量が，既に見た量と同じである**：並べる量（印の割合，印の有無の教師の正解率）の評価の回の値（K = 5・25）は，台帳 100 行で既に見たものと同じ発話の同じ量である．新しい確認の根拠にしない．評価の回で初めて見る値は K = 0・1・10 と，AVT の生徒の cons − joint などに限る．

提案する目録の項目（`docs/methods.md` 9.3 節 D に足す案）：
- D9 重みの式に，正規化（感情ごとの総量をそろえる）が掛け算の後に入るとき，掛けた係数の「比」が感情ごと・生徒ごとに変わることを書き，実際の割合の幅を出力に残す（DAI-4 の関門 1）．
- D10 疑似ラベルの重みづけの対照は，印を無作為（教師の予測感情で層別）に付けた版を同じ設定で置き，有効な本数の減りの効果を分ける（DAI-4 の関門 1）．
