用語：
- **EM**：今の感情の割り当て（各発話がどの感情らしいかの重み r）から各感情の平均と共通の広がりを推定する段（M 段）と，その推定で割り当てを直す段（E 段）を交互に繰り返す手続きである．
- **EM の目的**：EM が回ごとに大きくする量で，ここではラベル無しの候補の発話がガウスの混合から出た確からしさ（尤度）である．EM は初期値の近くの「目的の山の頂上」へ進む．
- **判別の正しさと生成の模型の正しさ**：LDA を全ラベルで推定してテストを分ける正しさ（R4 が測るもの）と，ラベル無しの発話の尤度の山の頂上が感情の割り当ての近くにあること（EM が要るもの）は別の性質である．前者が成り立っても後者は成り立たないことがある（M1 の人工データ）．
- **縮める（α）**：共分散を Σ = (1 − α)·S + α·I にすることである．α が大きいほど，特徴の相関を無視した形に近づく．
- **人工データ**：この検査のために乱数で作ったデータである．実データは読んでいない．

## 軽微な指摘

- **[m1] β の強さの測り方が 1 回目の E 段だけで，最後の E 段での強さを表さない．**
  - 箇所：第 2 版 3.3 節 91 行（「1 回目の E 段で…の比．10 を超える (c, 空間) では，β = 0 と β = 1 の区別がほとんど無いと書く」）．
  - 人工データ（`review_ml_run/beta_ratio_sim.py`・`.log` と `em_selfterm_sim.py`・`.log`．d = 2,304，α = 0.5，K = 5．none[K] はずれたソースの頭に引き戻した K 本の頭）では，第 2 版の比は 1 回目の E 段で AFEW 型（候補 632 本）1.01〜1.07，IEMOCAP 型 0.65〜0.68，MELD 型 0.52〜0.57 で，どれも 10 より小さい．一方，最後の E 段で β log q を外すと argmax が変わる割合は，AFEW 型で 3 回とも 0.0% だった（IEMOCAP 型 6.4〜7.7%，MELD 型 16.6〜17.1%）．候補の上の δ の上位 2 つの差の中央値が，回を重ねて 8.8〜9.3 nat（テストの上では 2.9〜3.2 nat）に広がり，log q の差（1.9〜2.1 nat）を上回るためである．第 2 版の規則では，AFEW で β が効いていないのに「区別がある」と読まれうる．
  - 直し方：同じ比を最後の E 段でも残す．加えて，1 回目と最後の E 段で「β log q を外すと argmax が変わるラベル無しの発話の割合」を残し，β の強さの文はこの直接の量で書く（境は計算の前に決める）．費用はほぼ 0 である．
- **[m2] 0 節の TransCLIP の記述が原文と違う．**
  - 箇所：0 節 9 行「TransCLIP は，凍結した特徴の上で GMM のクラスの平均と共通の共分散を…推定し直す．除去実験では，Σ を更新しないと EuroSAT で 65.1 → 51.6 に下がる」．
  - 原文は "we deploy a common diagonal covariance matrix Σ across all classes" と書き，GMM の項は問い合わせの集合（テストの集合）の上で和を取り，特徴は単位球に正規化し，少数ショットでは λ = 0.5 とする（[TransCLIP 2024](https://arxiv.org/html/2406.01837v1)）．案の出どころの調べの報告も「全クラスで共通の対角の共分散 Σ」と書いている（`reports/疑似ラベル 情報の持ち込み方 先行研究.md` 128 行）．DAI-8 は対角でない共分散を I に縮め（AVT で自由な値が約 266 万個．候補は 632〜約 15,000 本），テストではなく候補の上で推定し，特徴を次元ごとに標準化する．65.1 → 51.6 は対角の Σ の更新の寄与であり，対角でない Σ を推定し直す根拠にはならない．
  - 直し方：9 行に「対角の」と「問い合わせの集合の上で」を足し，8 節に上の 4 つの違いを並べる．prior-work-diff の報告（`research_notes/先行研究_半教師ありのガウス判別_2026-11-08/report.md`）はこの検査の時点で無いので，届いたら同じ違いを写す．
- **[m3] 推定した平均の雑音が，本数の少ない感情を判定で不利にする．**
  - 平均を n_k 本から推定すると，−½·μ̂_kᵀΣ⁻¹μ̂_k は平均でおよそ ½·tr(Σ⁻¹S)/n_k だけ大きく引かれる（Σ を固定したときの雑音の分）．感情の事前を等しくして判定しても，この項は本数の少ない感情を不利にする．LDA_oracle と EM は候補の割合どおりの n_k を使い，LDA_K は n_k = K で等しいので，この項は LDA_oracle と EM にだけ偏りとして入る．
  - 人工データ（`em_selfterm_sim.log`．d = 2,304，α = 0.5）では，IEMOCAP 型（最も少ない感情が 10%）で tr(Σ⁻¹S) が 767〜774，感情の間のこの項の差が 1.11〜1.34 nat で，LDA_oracle の最も少ない感情の再現率は 25.8〜36.6%（最も多い感情は 65.2〜76.0%）だった．この項を足し戻すと UAR は +0.35〜+1.48 ポイント変わった．R4 の境 −2 ポイントと同じ桁である．AFEW 型（ほぼ釣り合い）では差は 0.26〜0.50 nat で，UAR の変化は 0.4 ポイント以内だった．
  - 直し方：LDA_oracle と EM の各推定で tr(Σ⁻¹S) と n_k を残す（Cholesky の解 1 回で出る）．R4 を満たさないときの書き方に「本数の少ない感情の平均の推定の誤差を含む」を足し（第 2 版は n/d < 1 だけを挙げるが，IEMOCAP 即興の候補の Angry は約 230 本である），R3（EM_fromK − LDA_K）にも「EM の側だけがこの偏りを持つ」と添える．感情ごとの再現率は保存する判定から出せるので，表に並べる．
- **[m4] R5 の「話者の一致」は，IEMOCAP 以外では話者ではない．**
  - 箇所：3.1 節 46 行，4 節 R5．台本 `:152`（`gcol = "speaker_id" if c == "IEMOCAP" else "cluster"`）．`DAI/exp/dai_data.py:74-80` では，AFEW の塊は俳優と作品のつながりでまとめたもの，MELD は別名をまとめた話者，MOSEI は `speaker_group`（`data/README.md` 3 節のチャンネルか動画）である．さらに，感情の一致は 4 感情で平均した値（でたらめなら 0.25），塊の一致は発話で平均した値（でたらめなら Σ p_g²）で，平均の取り方が違う．
  - 直し方：R5 と 3.1 節の名前を「塊の一致」にし，コーパスごとの塊の定義を書く．2 つの伸びは平均の取り方が違うので大小を比べる意味は記述に限る，と書く（第 2 版は R5 を R1 の解釈に使わないと決めたので，文だけの直しでよい）．同じ対話・筋書きの一致は感情認識の査読者の A2 に従う．
- **[m5] K 本が M 段の重みに占める割合が小さく，「K 本を固定する」の効きは弱い．**K 本は候補 n 本のうち 4K 本である．AFEW では K = 1 で 4/632 ≈ 0.6%，K = 25 で 100/632 ≈ 16%，MOSEI では K = 1 で約 0.03%，K = 25 で約 0.7% である．8 節にこの割合を書き，「K 本を正解に固定した半教師ありの EM」が実際にはほぼラベル無しの EM であることを読み手が分かるようにする．
- **[m6] R6 の EM − EM_μ が測る量の名前．**EM_μ が固定する Σ は「最初の M 段の Σ」（第 2 版 78 行）で，これはすでに none[K] の確率で重みづけたラベル無しの候補から推定した Σ である．EM − EM_μ は「Σ を回ごとに推定し直す寄与」であり，「ラベル無しの発話で Σ を推定する寄与」ではない．R6 の文と 0 節の根拠の文をこの意味に合わせる．

## 第 2 版と関門の報告で済んだ点（ML の観点で確かめた）

- **区間の単位**（gate-probe の 1，gate-code の記録 11）：第 1 版は 6 単位（3 つの T × 2 つの種）を種の 6 回として種の項を作っていた．K 本の抜き方は (c, f, r) で決まり T に依らない（`dai_data.py:131-133`）．6 個の値を「T による固定の差 a_T + 種による差 e_r」と書くと，T による差が 0 のとき第 1 版の種の項は正しい値の 5 分の 1 になり，T による差が大きいときは逆に大きくなる．第 2 版（97 行）は (f, r) を単位にし，3 つの T の塊ごとの数を足す．同じ (c, f) のテストは 3 つの T で同じ発話なので，足した数の UAR は 3 つの T の UAR の平均と一致する．正しい．
- **R3 の比べ**（gate-probe の 2，gate-code の I3・I4）：第 2 版は EM_fromK − LDA_K を R3 にし，EM − LDA_K を R3′（記述）にした．EM_fromK は none[K] を使わないので，ソースの情報とテストで選んだ引き戻しが入らない．正しい．
- **選んだ点の向き**：8 節（第 2 版 136 行）が「初期値と事前は選んだ none[K] から来る」と書き，R1・R2 は EM に不利，R3′ は EM に有利な向きに寄ると書く．oracle も選んだ引き戻しの点であることを R4 に書く．正しい．
- **収束，係数と候補の上の事後の保存，0 回目の LDA の版，同じ教師の識別型の相手（tt・fused_AVT）**：gate-code の 1〜4・8 が求めている．私の M1 の EM_truth・EM_rand も同じ保存の形（判定，δ，残った割合）に入れれば足りる．

## 確かめたこと

- **漏れ**：EM と LDA の推定は候補（K 本とラベル無しの発話）だけを使い，テストの発話は判定にだけ使う（台本 `:159-217`）．標準化は候補の平均と標準偏差（`dai1.py:176`）．評価のターゲット T のデータは単位に入らない（`Unit` は c だけから候補とテストを作る）．MELD はテストの対話を候補から除く（`dai_data.py:121-128`）．IEMOCAP 即興はセッションで分ける．候補の全ラベルは LDA_oracle と診断にだけ使い，テストのラベルは判定の採点にだけ使う．M1 の 2 つの版も候補のラベルだけを使う．
- **式**：`lda_from_R` の S = (XᵀX − Σ_k n_k μ_k μ_kᵀ)/N は，各行の重みの和が 1 のとき 3.2 節の M 段の S と一致する．E 段で −½·xᵀΣ⁻¹x を省いているが，感情によらない数なので softmax を変えない．ブロック対角にしても S は半正定値のままで，α > 0 なら Σ は正定値である．テストの判定は等しい事前（δ_k だけ）で，UAR を主指標にすることと合う．自己検査は通った（係数の差 1.78e-14，K 本の行の固定 True）．
- **比較相手**：下調べとしては，none[K]，joint，oracle，LDA_K，LDA_oracle，第 2 版の EM_fromK・EM_μ，gate-code が求める同じ教師の識別型の頭で足りる．この形を論文の手法にするなら，最も近い先行研究の TransCLIP（対角の共分散，[arXiv 2406.01837](https://arxiv.org/html/2406.01837v1)）と LaplacianShot（[arXiv 2006.15486](https://ar5iv.labs.arxiv.org/html/2006.15486)）の形と比べるか，比べない理由を書く必要がある（計算の後の設計の話で，この下調べの不備ではない）．
- **統計**：R1〜R3 は「区間の下端 > 0 かつ点推定 ≥ 0.5」を K の 3 つ以上で数え，K が同じテストと候補を共有することを書いている．満たさなかった規則を言い換えない規則がある．規則の点（α = 0.5，β = 1）は計算の前に固定し，格子は記述である．4 コーパスで言えるのは数え上げと記述までで，設計もそれ以上を主張しない．
- **再現性**：`provenance.json` にコミット，dirty，入力の sha256，ソフトの版，GPU，定数を残す．行のファイルのコミットと集計の止め方は gate-code の I12・I8・I9 が求めている．
- **後からの指摘への備え**：テストの判定と塊と感情を行のファイルに残すので，感情ごと・ターゲットごと・K ごとの内訳は計算し直さずに出せる．第 2 版はテストの δ も残す．候補の上の事後と係数は gate-code の 2・3 が求めている．
