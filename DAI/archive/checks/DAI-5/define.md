## 指摘

### [D2] 「参照の割合」w_sm/3 は指数の割合であり，疑似ラベルへの影響の割合ではない
- 重さ：直してから進む
- 該当箇所：`DAI/docs/実験5_設計.md:8`（「どのソースのどのモダリティを何 % 参照したか」），`:41`（「選んだ β の w_sm / 3 を単位で平均した『参照の割合（%）』…（例：MELD の顔 18%）」），`DAI/exp/dai5_stats.py:333, 354`
- 問題：上の表のとおり Q = softmax(Σ w_sm z_sm) であり，識別器 (s, m) が Q を動かす量は w_sm と点数 z_sm の大きさの積で決まる．z_sm の大きさは識別器ごとに大きく違う．`results/dai1/source/summary.csv` の単一モダリティの識別器の ‖W‖ は 0.070（IEMOCAP の顔，C = 1e-5）から 2.38（IEMOCAP の音声，C = 0.01）まで 34 倍の幅がある．例えば MOSEI を評価のターゲットにした回の顔の 3 個は AFEW 2.14，MELD 0.38，IEMOCAP 0.070 である．β = 0 の表では 3 個とも 11.1% と書かれるが，IEMOCAP の顔の点数は AFEW の顔の約 1/30 の大きさで，Q にはほとんど入らない．研究者の問い（「MELD の顔は 20%，MOSEI の音声は 5%」）に答える表がこの量だけだと，表の数値は影響の割合として読まれる．関門 0 の報告（`report.md` 9 行，241〜245 行）も「指数の割合は影響の割合を意味しない」と書いているが，設計 11 節はまだ写していない．
- 計算の後で直せるか：直せる（ソースの識別器と特徴から Q を作り直せる）．ただし影響の量の定義を評価の結果の後に選ぶことになり，作り直しの計算も要る
- 求める対応：(1) 41 行の名前を「指数の割合（%）」に替え，「影響の割合ではない．点数の大きさの違う識別器では同じ指数でも Q への入り方が違う」と書く．(2) 影響の量を 1 つ計算の前に定義し，`dai5.py` の保存に足す．推す定義：単位・K・β ごとに，候補の発話の上で，感情の平均を引いた w_sm·z_sm の二乗の和の平方根を (s, m) ごとに出し，|C| 個の合計で割った割合（`p5_K{K}_infl_b{β}`）．もう 1 つの読みとして，(s, m) を抜いた Q の argmax が元の Q の argmax と変わる候補の割合も残す．(3) 指数の割合と影響の割合の両方を，モダリティごとの和（Σ_s）とソースごとの和（Σ_m）でも出す（研究者の問いは「ソースのモダリティ」の単位なので，周辺の和で読みが変わるかを示す）．(4) 11 節に関門 0 の報告の 9 行と 241〜245 行を写す．

### [D1] β = 0 の教師は「出発点の 3 モダリティの積」と同じであり，K = 0 の主の量の多くのセルは実験 1 の既存の行の再計算になる

### [D1] 採点と重みの同点で，「最も重い識別器」と「最も高い識別器」が名前の並びの先頭（音声）に寄る
- 重さ：直してから進む
- 該当箇所：`dai5.py:111`（`heaviest=names[int(np.argmax(w))]`），`dai5_stats.py:336`（`top_s, top_t = int(np.argmax(sc)), int(np.argmax(test_uar))`），`:356`（`heaviest_mode`），設計 `:41-42`
- 問題：(1) β = 0 と K = 0 では 9 個の重みがすべて等しく，`np.argmax` は先頭を返すので，「最も重い (s, m)」は常に 1 番目のソースの音声になる．設計の見込み (a) は K = 5 で β = 0 か 2.5 が選ばれるとしており，その場合の重みの表の「最も重い識別器」は定義に依る値になる．(2) U_sm は K = 5 で 5 点刻み，K = 1 で 25 点刻み，K = 10 で 2.5 点刻みの値しか取らないので，最大の採点が複数の識別器で同点になる単位が出る．`argmax` は名前の並び（A のソース → V → T）の先頭を返すので，`top_agree` と `top_score_mode` は音声に寄る．研究者の問いは「どのモダリティを参照するか」であり，この寄りは結論の向きに入る．(3) `pd.Series.corr(method="spearman")` は同順位に平均の順位を当てるので Spearman 自体は定義できるが，採点がすべて等しい単位は NaN になり，`dfk.spearman.mean()` が黙って除く．
- 計算の後で直せるか：直せる（採点と重みは保存される）．ただし同点の規則を評価の結果の後に選ぶことになる
- 求める対応：設計 41・42 行に同点の規則を書き，`dai5_stats.py` を直す．推す規則：最大が t 個で同点なら，一致は「テストの最良がその t 個に入れば 1/t」と数える．最も重い識別器は，同点なら「同点（t 個）」と書き，β = 0 と K = 0 の行には出さない．同点の単位の数と，Spearman が NaN の単位の数を `scores.csv` に残す．`teacher_stats_row` の `heaviest` も同点の数を残す．

### [D6・D5] 採点の妥当性の 2 つの量に，偶然の水準・ばらつき・モダリティを混ぜた見かけの一致の分離が無い
- 重さ：直してから進む
- 該当箇所：設計 `:42`，`:103`（「K = 25 で一致が 5 割未満なら『採点では決められない』と書く」），`dai5_stats.py:335-338, 358-362`
- 問題：(1) 偶然の水準が無い．採点を無作為に並べ替えたときの一致の割合は同点が無ければ 1/9 ≈ 11% で，同点があれば規則に依る．5 割の基準の根拠も書かれていない．(2) 評価の回の 9 個の識別器は，ソースの全発話で学んだ同じ識別器であり，50 単位で違うのは標準化の統計，K 本，テストの分割だけである．テストの最良の識別器は単位をまたいでほぼ同じで，50 単位は独立でない．単位平均にばらつき（区間か単位の間の標準偏差）と独立な単位の数（分割の 5）が付いていない（S5・S7）．(3) 9 個の Spearman はモダリティの間の大きな差で決まりやすい．例えば言葉の識別器がどのソースでも強いターゲットでは，モダリティの順位が合うだけで ρ は高くなり，同じモダリティの中でどのソースが良いか（研究者の問いの「どのソースの」の部分）を採点が当てているかは分からない．これは課題の 4 で確かめる「K やターゲットを混ぜて見かけの一致を作る」形と同じで，混ぜているのはモダリティである．(4) 「一致」は，テストの 1 位と 2 位の差が 0.3 ポイントでも 15 ポイントでも同じに数える．
- 計算の後で直せるか：量は直せる（`p5_src_test_pred` と採点を保存する）．基準は評価の回の前に決めないと事後になる
- 求める対応：(a) 主の読みを「採点で選んだ識別器のテストの取りこぼし」（テストで最良の識別器の UAR − 採点で最も高い識別器の UAR．同点は平均）にし，偶然の水準を「単位の中で採点を無作為に並べ替えたときの同じ量」（手続きどおりの置換．S10）で出す．(b) Spearman と一致の割合は，9 個の全体に加えて，モダリティの中（3 ソース．一致の偶然の水準 1/3）とモダリティの間（モダリティごとの採点の平均とテストの UAR の平均）に分けて出す．(c) 単位の間の標準偏差と，分割ごとに平均してから 5 つの値で作る区間を添える．(d) D8 の行 1 の基準を (a) で書き直す（案：K = 25 で，採点で選んだ識別器のテストの取りこぼしの単位平均が無作為の並べ替えの 95% 点より小さくなければ「K 本の採点では識別器を選べない」と書く）．

### [D13・S8] 取りこぼしの定義が一意でなく，作りの上で正になる量に帰無の水準が無い
- 重さ：直してから進む
- 該当箇所：設計 `:40`（「取りこぼし（評価のテストで平均が最良の β − 選んだ β．格子 5 点）」），`:75`，`:106`（「取りこぼしが δ を超えるコーパス・K の数を書く」），`dai5_stats.py:288-302`
- 問題：(1) 40 行の文は β の差とも UAR の差とも読める．台本は UAR の差を `srcw − oracle`（0 以下）で出しており，106 行の「δ を超える」は正の向きを前提にしているので，符号が合っていない．(2) oracle は (生徒, K) ごとに評価のテストで選ぶが，`srcw` の β は (T, K) ごとに 4 生徒で共有する．取りこぼしには「生徒ごとに選べる自由度」の分が混ざる．(3) oracle は同じテストの 5 点の平均の最大なので，β の効果が 0 でも取りこぼしの期待値は正である（D13・S8）．106 行の基準は帰無の水準と比べていないので，「ソースが 2 つの回で選んだ β が 3 つの回でも最良に近い」の判定に使えない．
- 計算の後で直せるか：直せる（β の全点の判定を保存する）．基準は評価の回の前に決める
- 求める対応：40 行を「取りこぼし ＝ 評価のテストで平均が最良の β の UAR − 選んだ β の UAR（0 以上．β は (T, K) ごとに 4 生徒の平均で選んだものと，生徒ごとに選んだものの両方）」に書き直し，台本の符号を合わせる．帰無の水準を手続きで出す：単位ごとの β の間の差を，単位の中で β の名前を並べ替えてから同じ最大を取った値の分布（S10）．D8 の行 4 の基準を「取りこぼしが帰無の 95% 点と δ の両方を超える (T, K) の数」にする．

### [D8] 仮定と測る量の表に，結論に関わる仮定が 3 つ足りず，既存の行 2 つに基準が無い

- 該当箇所：設計 `:99-106`
- 問題：設計の重みの規則は「K 本の UAR が高い識別器ほど疑似ラベルの作り手として役に立つ」と「指数を変えれば Q への入り方がそれに比例して変わる」を前提にしているが，表は前者の一部（採点がテストの強さを当てるか）しか測らない．関門 0 の報告は Heskes 1997 から「対数線形プールの最適な重みは個々の誤差だけでなく専門家どうしの重なり（あいまいさの項）にも依る」を引いている（`report.md` 108 行）．同じ報告の 232 行は MER-DA でモダリティの間の誤りの相関が 0.77〜1.00 だった記録を挙げている（検査前の値）．行 3（Q の鋭さ）は有効な本数にしか基準が無く，鋭さそのものに基準が無い．行 4 は上の [D13・S8] のとおり帰無の水準が無い．
- 計算の後で直せるか：量の多くは保存から作れる（影響の量は [D2] の保存の追加が要る）．基準は評価の回の前に決めないと事後になる
- 求める対応：次の表を 9 節に足す（基準の数値は案．設計者が根拠とともに固定する）．

| 仮定 | 測る量 | 測り方 | 成り立つとみなす基準（案） |
|---|---|---|---|
