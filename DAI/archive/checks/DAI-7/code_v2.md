## 指摘

### [記録 1] none_tw の 14 点は 3 つのモダリティに同じ引き戻しを当てるので，none はどの点にも重ならない
- 重さ：記録する
- 該当箇所：`DAI/exp/dai7_probe_v2.py` の `classifier_sets`（`for cw, cb in dai1.TETHER: sets[f"none_tw{cw}_{cb}"] = {m: p1_wb(z1, m, f"{K}|{cw}|{cb}") for m in MODS}`），設計 3.2 節の none_tw の行
- 問題：none はモダリティごとに選んだ引き戻しを使う．試走の 8 単位 × 4 K の 32 個のうち，3 つのモダリティの引き戻しがそろったものは 0 個だった．このため「none_tw の 14 点の上で none がどこにあるか」は，3 組の平均 D では読めない．読めるのは，対の 2 つのモダリティの引き戻しが同じ場合（試走では 18 個．差は 0.0）か，モダリティごとの引き戻しの比で並べた場合だけである．
- 計算の後で直せるか：直せる（記述）．
- 求める対応：設計 3.2 節の none_tw の行に「none はモダリティごとに選んだ引き戻しを使うので，一般に 14 点のどれとも一致しない．none と比べるときは対ごとに，2 つのモダリティの引き戻しが同じ点か，近い点を使う」と一文足す．

### [記録 2] none_tw の行には n_e0〜n_e3 と副の量の列が無い
- 重さ：記録する
- 該当箇所：`run_unit` の none_tw の分岐（`urows.append(dict(..., phi=ph, n_emotions_phi=nph, **{d_e, d0_e}))`）
- 問題：none_tw の 168 行では，D_pool，D_cent，D_partial_t，n_dropped_cent，n_e0〜n_e3 が NaN になる．副の量は設計どおり（テストの D と φ だけ）である．n_e は同じ単位のほかの組の行と同じ値なので，そこから補える．
- 求める対応：n_e0〜n_e3 を none_tw の行にも書くと，読む側の取り違えが減る．

### [記録 3]（読んだだけ）単位を外す規則で，抜き直しの分布の中の分割の重みが変わる
- 重さ：記録する
- 該当箇所：`boot_uar_unit`，`fold_combine`
- 問題：AFEW の分割 0 は，大きい塊（154 本）が抜かれない約 29% の回で，UAR から作る量について外れる．このため抜き直しの分布の中では，分割 0 の重みが点推定（分割を等しく平均）より小さくなる．D の抜き直しも同じ回に分割 0 を外す（感情が 15 本未満になるため）ので，この点は D と UAR で一貫している．区間の中心が点推定からどれだけずれるかは確かめていない．
- 求める対応：結果の文で AFEW の区間を述べるときに，分割 0 の構造（塊 3 つ，最大 97%）を添える．
