## A．小さく流した結果

- 自己検査：`./.venv/bin/python DAI/exp/dai10_probe.py --selftest` は通った（1.9 秒）．
- 試走のコマンド：`./.venv/bin/python -W always DAI/exp/dai10_probe.py --out <作業用のフォルダ>/out_iem --units <c = IEMOCAP の 30 単位>`，同じく c = MOSEI の 30 単位，AFEW_IEMOCAP_f0_r0 と AFEW_MOSEI_f0_r0，IEMOCAP_MELD_f0_r0 と IEMOCAP_AFEW_f0_r0（合わせて 64 単位．出力は `/tmp/claude-1000/-home-snics-MER-DA/b1f27254-32c7-45f0-ac5a-dee1c5e3ec8a/scratchpad/dai10/` の下で，検査の後に消した）．続けて `--summarize --allow-partial` を c = IEMOCAP と c = MOSEI の出力で流した．
- 所要：単位あたり AFEW 2 秒，IEMOCAP 3 秒，MELD 4 秒，MOSEI 約 6 秒．c = IEMOCAP の 30 単位で壁時計 1 分 12 秒，c = MOSEI の 30 単位で 2 分 56 秒．集計は IEMOCAP 4.5 秒，MOSEI（塊の引き直し 2,000 回）55 秒．
- 例外と警告：どの実行も終了コード 0．`-W always` で警告（収束，NaN，型の変換）は 1 つも出なかった．
- 出力の形：1 単位に判定の鍵 292，係数の鍵 48（A・μ は float16，c は float32），判定はすべて 0〜3，係数に有限でない値 0，診断に有限でない値 0．`cells.csv` は 292 行で，各行の単位の数が 30，UAR の NaN 0．`diffs.csv` は 196 行で，effect・lo・hi の NaN 0，各行の `n_units` は 10，区間の作り方は IEMOCAP が `jk+seed`，MOSEI が `boot_cl+seed`（設計 4 節のとおり）．
- 全く同じ判定になる列の組は 12 組で，すべて K = 1 の LDA_K の α 3 点どうし（4 空間 × 3 組）だった．K = 1 では群内の散らばり S_K が 0 なので Σ_K = αI になり，α によらず同じ判定になる．式から出る一致で，誤りではない．1 つの感情しか出さない判定の列は 0 だった．
- **退化した場合の検算**（2 単位 AFEW_IEMOCAP_f0_r0，AFEW_MOSEI_f0_r0 × 空間 A，AVT × K 1，5，25．`check_degen.py`）：
  - α = 1 では LDA_T も LDA_K も Σ = I になる．LDA_T^1 と LDA_K^1 の判定の不一致はすべてのセルで 0 本だった．
  - `lda_metric` に K 本の Σ_K の Cholesky を渡した判定と，DAI-8 の `lda_from_R` の LDA_K の判定の不一致は 0 本だった．
  - EM_Kmet を 0 回で止めた解は，K 本を one-hot，残りを初期値 q0 で重みづけた平均と Σ_K の LDA と係数が 1e-10 で一致した．
- **保存済みの値の再現**：
  - K 本だけの LDA を解き直した判定と DAI-8 の保存の不一致は，64 単位のすべてのセルで 0 本だった（`checks` の `ldaK_mismatch` が 0）．
  - DAI-8 の EM_fromK（β = 0，10 回）を同じ関数 `P8.em_fit` と同じ初期値で解き直した判定は，上の 12 セルのすべてで DAI-8 の保存と 0 本違いだった．EM_Kmet と EM_fromK は同じデータ，同じ K 本，同じ初期値から始まっている．
  - 保存した LDA_T（α = 0.5）と EM_Kmet の判定は，検算の台本で解き直した判定と 0 本違いだった．
- **手法の間でテストと K 本が同じか**：DAI-10 の行の `test_sample_id` は DAI-8 の行と単位ごとに照合され（`:143-144`），写した判定と新しく解いた判定は同じ npz に同じ並びで入る．K 本は同じ `u.kpos[K]` から取り，LDA_K の照合の不一致 0 がそれを裏づける．

## 指摘

### [R4，R6] 設計 0 節の数理の予想を UAR で確かめる 2 つのオラクルの角が無い
- 重さ：止める
- 該当箇所：`DAI/exp/dai10_probe.py:163-197`（K ごとの方法の一覧），設計 0 節の「数理の予想」と Krijthe & Loog 2016 の行
- 問題：設計 0 節は「計量の分の得は感情でない分散の向きを抑える分で，損はこの縮みである」と予想し，その記述として A⁻¹B の固有値だけを出す（`emo_eigs`）．固有値は縮みの大きさを示すが，縮みが UAR をどれだけ下げたかは示さない．この予想を UAR で確かめる最も直接の比べは，同じ K 本の平均で計量を T から候補の全ラベルの群内の散らばり S_O に替えた LDA（`ldaSO`）との差である．LDA_T と `ldaSO` の差は計量 T と S_O の違いだけで決まる．もう 1 つ，平均を候補の全ラベルの平均にして計量を T にした LDA（`ldaOT`）と LDA_O の差は，平均が正しいときの T の損を示す．どちらも設計 0 節が引く Krijthe & Loog 2016 の分け方（共分散の分と平均の分）に当たり，査読者がまず求める比べである．保存の出力からは作れない．DAI-8 が保存した `C_A_{s}_ldaO_a0.5` は Σ_O⁻¹μ_Oᵀ で，Σ_O⁻¹μ_Kᵀ は作れない．
- 計算の後で直せるか：直せない（単位の段を流し直す）．
- 求める対応：単位の段の空間ごとに `fO = P8.lda_from_R(Xp, onehot_all, Xp.T @ Xp, a)` を α の格子で作り，K ごとに `pred[f"K{K}_{s}_ldaSO_a{a}"] = P8.delta(Xt, lda_metric(mu, fO["chol"])).argmax(1)` を足す．空間ごとに `pred[f"{s}_ldaOT_a{a}"] = P8.delta(Xt, lda_metric(fO["mu"], chols[a])).argmax(1)` を足す．どちらも候補のラベルを使うオラクルであることを鍵の名前と設計 3 節に書く．`COMPARE` に `ldaT_ldaSO`（K ごと）と，K = 0 の行として `ldaOT_ldaO` を足す（DAI-8 の `COMPARE_K0` と同じ形）．自己検査に「`ldaSO` で K 本を候補の全部にすると LDA_O と同じ判定になる」を足す．

### [R9] EM_Kmet の候補の上の割り当ての正しさと回ごとの値を保存しない
- 重さ：止める
- 該当箇所：`DAI/exp/dai10_probe.py:82-99`（`em_kmetric` が返すのは `hist` と `moved` だけ），`:196-197`（診断に残すのは `moved` と最後の `hist` だけ）
- 問題：経路 2 の「割り当てを先に回す分」（EM_Kmet − LDA_K）の得と損の理由を問われたときに，DAI-8 の R9 と同じく「割り当てが感情でない分け方へ移ったか」を候補の上で示す必要がある．DAI-8 は EM_fromK について回ごとの候補の上の UAR（`pool_hist`）と最後の割り当てを保存したが，DAI-10 は EM_Kmet について保存しない．診断の `hist` も最後の 1 つしか残さない．このままでは EM_fromK と EM_Kmet の割り当ての移り方を比べられない．
- 計算の後で直せるか：直せない（単位の段を流し直す）．
- 求める対応：`em_kmetric` に `yU`（候補のうち K 本以外のラベル．測定だけに使う）を渡し，各回の `R[U].argmax(1)` の候補の上の UAR を `pool_hist` として返す．診断に `hist` の全部と `pool_hist` を残し，最後の割り当ての argmax を `P_K{K}_{s}_emKmet_a0.5`（int8）として保存する．あわせて EM_Kmet の係数 `C_A`，`C_mu`，`C_c` を保存すると，EM_fromK との向きの近さを後から出せる（こちらは記録の範囲）．

### [R4] α の格子が先行の推定量（縮小なし）に近い点を含まない
- 重さ：直してから進む
