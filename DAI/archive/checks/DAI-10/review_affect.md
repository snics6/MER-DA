この報告で使う語：
- **候補**：仮のターゲットのコーパスのうち，テストの分割以外の発話である．感情ごとに K 本のラベル付きの発話と，残りのラベル無しの発話からなる．
- **LDA_K**：K 本のラベル付きの発話だけで感情ごとの平均と共通の共分散を推定するガウスの判別である．**LDA_T** は，平均は K 本から作り，共分散の代わりに候補の全部（ラベルを使わない）の散らばり T から作った計量 A = 0.5·T + 0.5·I を使う．
- **計量**：2 つの特徴の距離を測るときに，どの向きの差をどれだけ重く見るかを決める行列である．LDA_T の判定は，特徴に A^(−1/2) を掛けて「白色化」（候補の散らばりの大きい向きを縮め，小さい向きを伸ばす操作）した後で，最も近い感情の平均を選ぶことと同じである（δ_k(x) = −½(x − μ_k)ᵀA⁻¹(x − μ_k) + x だけの項）．
- **筋書き**：IEMOCAP 即興で演者に与えた 8 種類の場面の設定である．どのセッションでも同じ筋書きを演じ，筋書きがほぼ感情を決める．
- **回**：MELD の元のドラマ（Friends）のシーズンとエピソードの組である．1 つの回に多数の対話がある．

## 軽微な指摘

- [b1] **LDA_K もラベル無しの候補を使っている．G1 の文の「K 本だけの LDA」と位置づけ**
  - 特徴は候補の全部（ラベル無しを含む）の平均と標準偏差で標準化してある（`dai1.py` 176 行）．このため LDA_K も，ラベル無しの発話の次元ごとの分散を計量に使っている．K = 1 では S_K = 0 なので，LDA_K は「次元ごとに標準化した空間で最も近い平均を選ぶ」判定になる（gate-code の第 1 回 46 行の確かめと同じ）．したがって K = 1 の G1 は，「候補の次元ごとの標準化」と「候補の全共分散による白色化（0.5 で I へ縮めたもの）」の比べである．G1 で新しく測るのは，ラベル無しの発話の次元どうしの共分散（T の非対角の部分）を足した効果である．
  - 感情認識では，ラベル無しのコーパスの統計で特徴を直す方法が広く使われている．
    - コーパスごとの標準化：Schuller ほか 2010，IEEE TAC 1(2):119–131（https://doi.org/10.1109/T-AFFC.2010.8．`docs/related-work.md` 169 行にある）．
    - ラベル無しの発話から推定した中立の発話の統計で正規化を繰り返す方法：Busso ほか 2013，IEEE TAC 4(4):386–397（https://doi.org/10.1109/T-AFFC.2013.26）．
    - ラベル無しの第 3 の言語のデータの共分散（+I）で，学習とテストの特徴を白色化して色づけし直す N-CORAL：Kshirsagar & Falk 2022，Sensors 22(17):6445（https://pmc.ncbi.nlm.nih.gov/articles/PMC9460701/．式 (6)〜(9) を読んだ．回帰器は 2 層の BLSTM で，ガウスの判別ではない）．
  - 直し方：
    - G1 の文を「候補の標準化に加えて，ラベル無しの発話の全体の共分散を計量にすると，K 本のラベルで共分散を推定する LDA を上回った」のように，両方が候補の標準化を使うことが分かる形にする．
    - 0 節の「新しく書けないこと」に「感情認識で，ラベル無しのコーパスの統計で特徴を正規化・白色化すること（上の 3 本）」を足す．
    - 結果の文では，LDA_T を「ターゲットの候補の共分散で白色化した空間での最も近い平均の判定」とも書く．
- [b2] **感情ごとの扱いと LDA_Tc の偏りの向き**
  - 設計には「感情ごとの主張をしない」の文が無い（DAI-8 の a3，DAI-9 の e6 と同じ扱いにする）．
  - LDA_Tc は，等しい割合で 4 つの平均を中心に合わせる．すべての平均を同じ量 m̄（4 つの平均の平均）だけ動かすと，感情 k の判定の切片に μ_kᵀA⁻¹m̄ が足される．候補の標準化で Σ_k π_k μ_k = 0 なので，m̄ ≈ Σ_k (1/4 − π_k) μ_k である（調べの 6.4 節と同じ式）．
  - 候補の Neutral の割合は，MELD で 54.8〜58.0%，MOSEI で 46.1〜46.5% だった（`DAI/splits/*.csv` と `pool_mask` から，割合だけを数えた）．このコーパスでは，m̄ は Neutral の平均から離れて少ない感情（Sad，Angry）の側を向く．このため LDA_Tc は，Neutral の判定を減らし，少ない感情の判定を増やす向きに動くと考えられる（推測）．LDA_Tc − LDA_T の UAR の差は，Neutral の再現率と少ない感情の再現率の交換になりうる．MOSEI の Neutral は，どの感情の強さも 0.5 未満という消去法で決まる（`data/README.md` 205 行）ので，Neutral の再現率の変化は MOSEI のラベルの定義とも分けられない．
  - 直し方：
    - 8 節に「感情ごとの主張をしない」と書く．
    - LDA_T，LDA_Tc，LDA_Tcpi（AVT，α = 0.5）のテストの感情ごとの再現率を記述として並べると 5 節に書く（rows の判定と `test_y` から作れる）．
    - 52 行の「MOSEI 46.8%」は，3 モダリティで絞る前のコーパス全体の値（8,847 / 18,919）に当たる．候補の値（46.1〜46.5%）に直すか，「コーパス全体」と書く．
- [b3] **モダリティごとの事情と LDA_Tblk の読み方**
  - LDA_Tblk − LDA_T は，ラベル無しの発話のモダリティをまたぐ共分散を計量に入れた効果である．その共分散には，感情のほかに，話者の性別（声の高さと顔），MELD の回の場面，AFEW の書き起こしの失敗（音楽や雑音の区間に Whisper が出す決まり文句と，そのときの音声の特徴）のような，感情でない共通の要因が入る．結果の文で「モダリティをまたぐ感情の情報」とは書かず，「モダリティをまたぐ共分散を計量に入れた効果」と書く．
  - 部分集合の記述（DAI-8 の a7 と同じ）：AFEW は書き起こしの疑いの 35 / 790 本を除いた `asr_ok` で T と AVT の差を，MELD は顔が競らない `face_single`（MELD の 3 モダリティの 11,267 本のうち 6,019 本．競る 5,234 本，決まらない 14 本）で V と AVT の差を並べる．どちらも rows から作れる．5 節に書く．
  - AVT は 1,024 + 512 + 768 次元をつなぐ．α = 0.5 では計量の半分が I なので，音声 44%，顔 22%，言葉 33% の次元の割合による重みが残る．8 節に 1 文書く．
- [b4] **仮定 (c) と話者の分離**：候補の T が抑える感情でない向きのうち，性別や収録の条件の向きはテストの話者にも共通するが，話者そのものの向きはテストの新しい話者に移らない．仮定 (c) を測らないなら，8 節の限界に「得が出ても，それが話者に共通する向きを抑えた分か，回や筋書きのようにテストと候補が共有する向きを抑えた分かは分けない」と書く．

## 確かめたこと

- **話者と内容の分離**：
  - LDA_T，LDA_Tc，LDA_Tblk，EM_Kmet の計量と平均は，候補の特徴 `Xp` だけで推定し，テストの特徴 `Xt` は判定にだけ使う（台本 171〜233 行）．標準化は候補の統計で行う（`dai1.py` 176〜177 行）．
  - 候補はテストの分割の塊を含まない．IEMOCAP はセッション，AFEW は俳優と作品のつながり，MELD は話者，MOSEI はチャンネルか動画が塊である．MELD はテストの対話の発話も候補から除き，テストと候補の話者の名前の重なりは 5 つの分割すべてで 0 だった．
  - 評価のターゲット T のデータは単位に入らない．
  - 候補のラベルを使う量（LDA_Tcpi，LDA_SO，LDA_OT，縮みの係数）は，鍵の名前と設計 3 節でオラクルか記述と書き分けてある．
