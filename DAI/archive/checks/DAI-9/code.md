## 指摘

### [I1] nap の後に候補で標準化し直すと，消した向きのグループの散らばりが戻る
- 重さ：直してから進む
- 該当箇所：`DAI/exp/dai9_probe.py:81`
  ```
  return _restd(Xp - (Xp @ V) @ V.T, Xt - (Xt @ V) @ V.T)
  ```
- 問題：射影の直後は Vᵀx = 0（候補で 4.5e-14）である．しかしその後に列ごとの標準偏差で割ると，消した部分空間が列ごとの尺度で歪み，グループの平均の成分が戻る．AFEW_f0_r0 で測った値は次のとおりである．
  - 割り直した後，元の V の 10 本の向きのグループの間の散らばりは 0.251 だった（割り直す前は 0）．
  - グループの間の散らばり全体（trace）は raw の 0.570 倍だった．上位 10 本の固有値は全体の 60.6% なので，割り直さなければ 0.394 倍のはずである．
  - nap50 は AFEW でも IEMOCAP でも全部の向きを消すので，0 倍だった（指摘 2）．
  - gc は割り直した後も 0.032 倍（AFEW．3 本未満のグループの分）で，列ごとの尺度の変更ではグループの平均の 0 は崩れない．pca も，成分ごとの尺度を変えるだけなので崩れない．
- 計算の後で直せるか：直せない（取り除きの後の特徴は保存しない）
- 求める対応：nap だけは割り直さない（入力はすでに候補で標準化してある）か，割り直した後にもう一度射影する．どちらかを設計 3.1 節に書く．あわせて，τ ごとのグループと感情の散らばりの割合を q1 の行に残す．

### [I1] nap の r がグループの間の散らばりのランクを超えると，任意の向きを消す
- 重さ：直してから進む
- 該当箇所：`DAI/exp/dai9_probe.py:79-80`（`V = V[:, -r:]`）
- 問題：S_g のランクは（候補のグループの数 − 1）以下である．
  - IEMOCAP の候補の話者は 8 人で，正の固有値は 7 個だった．このため nap10 は 3 本，nap50 は 43 本の固有値 0 の向きも消す．
  - AFEW の候補は 48 塊で，正の固有値は 47 個だった．nap50 は 3 本の余分な向きを消す．
  - 固有値 0 の固有ベクトルは数値の誤差で決まる任意の向きである．IEMOCAP では nap10 と nap50 の違いがこの任意の向きだけになり，予想の書き方（gc・nap10・nap50 のどれか）の nap50 の読みに意味が無くなる．
  - MELD（154 人）と MOSEI（2,093 塊）では起きない．
- 計算の後で直せるか：直せない
- 求める対応：r を min(r, 固有値 > 1e-10·最大 の数) に切り，切った後の r を診断に残す．設計に「IEMOCAP では nap10 と nap50 はどちらも 7 本の話者の向きを全部消す」と書く．

### [I12] S2 の段 1 の量と Q3 の行のそろいを確かめない

## 目録に無い種類の不備

- **射影で消した後の列ごとの標準化**：部分空間を射影で消した後に列ごとに尺度を変えると，消した成分が戻る．`docs/methods.md` 9.3 節に次を足す案を出す．
  - I22 射影で向きを消す前処理（NAP など）は，消した後に列ごとの標準化をしない．するなら，消した向きの成分が 0 のままかを台本で確かめる．消す向きの数は，消す散らばりのランクで上限を切る（DAI-9 の関門 1）．
