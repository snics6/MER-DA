# この課題の難しさの記録（2026-11-05．研究者の指示「いかに難しいかを記録しておこう」）

対象：4 コーパス（AFEW，IEMOCAP 即興，MELD，MOSEI）の leave-one-corpus-out．新しいコーパスには感情ごとに K 本のラベルとラベル無しの発話だけがある．凍結した特徴（WavLM・ResNet-50・RoBERTa）の上の線形の識別器．主指標は UAR（でたらめで 25%）．
数は評価の回（4 コーパス × 50 単位）の途中の値で，区間は付いていない（集計の正本は `results/dai1/stats/` ほか）．出どころは `docs/seen-data.md` の 2026-11-05 の行．

## 1. どれだけ足りないか

- ソースの 3 コーパスの識別器を平均してそのまま当てると，テストのラベルで作れる最良の線形の識別器（上限）より UAR で **14〜15 ポイント低い**（AFEW・IEMOCAP の AVT）．
- K = 25（100 本のラベル）で学び直しても，上限との差は AVT で約 4〜8 ポイント残る．損の大半は切片（位置）ではなく重み（向き）のずれで，少数のラベルでは 2,304 次元の重みを直し切れない．

## 2. ラベル無しの発話と標準手法では埋まらない

- 自己学習・エントロピー最小化・IM・T3A・ラベル伝播・S+T・CORAL・DANN・MME・xMUDA 型（14 手法）のどれも，融合した識別器で K 本だけの基準をはっきり上回らない．上回る手法はコーパスごとに違い（AFEW は T3A，MELD は S+T，MOSEI は CORAL），差は 1〜3 ポイントである．
- エントロピー最小化と MME は崩れることがある（IEMOCAP の AVT で 47.8%，43.0%）．

## 3. 別のモダリティの予測は，弱いモダリティにしか効かない

- 3 モダリティの積の予測で学ぶ手法（提案・温度つき蒸留）は，音声の単独の識別器を 4 コーパスすべてで +1.5〜+4.9 ポイント上げ，IEMOCAP の言葉を +5〜+7.5 上げる．
- しかし融合した識別器（AVT）には効かない．教師（積の予測）が AVT の生徒より 0.1〜2.5 ポイントしか当たっておらず，判定も 80〜92% で一致するので，学ぶものが無い．
- 顔の生徒は，教師が当たっていても得をしない（IEMOCAP の顔は切片がかえって悪くなる）．
- MELD と MOSEI では教師そのものが弱い（候補での正解率 41〜51%）．

## 4. 「どのモダリティを信じるか」が決められない

- 直した単独の識別器の積で，指数（モダリティの重み）をそのターゲットに合わせれば，AFEW で AVT の生徒を 3〜8 ポイント上回れる（上限）．最良の指数はコーパスごとに違う（AFEW は顔，IEMOCAP は音声，MELD は言葉を重くする）．
- しかし，その指数を決める手がかりが無い．
  - ラベル無しの一致率：強いモダリティほど弱いモダリティと意見が合わないので，一致率は強さの手がかりにならない．
  - K 本のラベル：学習に使った発話なので，どのモダリティも当たりすぎて差が見えない．K 本で選んだ指数は (1,1,1) より悪い．
  - 仮のターゲット（ほかのコーパス）で選んだ指数：コーパスごとに強いモダリティが違うので，移らない．

## 5. 確かめることも難しい

- テストの話者の数が少ない（AFEW 15，IEMOCAP 5，MELD 8 の実効の塊）ので，1〜2 ポイントの差は有意にならない．検定に残るセルは，実験 1 の 128 セルのうち 15 セルである．
- 手法の形は評価に使う同じ 4 コーパスの上で作った．別のコーパスは無い．

## skeleton の項目 2（どれほど解くのが難しいか）の案（75 字以内）

> ソースの識別器の平均は最良の線形識別器より UAR で 14〜15 ポイント低く，14 の標準手法とラベル無し発話を足しても融合識別器では 1〜3 ポイントしか埋まらない．
