**量と範囲．**提案（論文 7 節）は，積を作る声・顔・言葉の分類器（融合の分類器の疑似ラベルで学び直した ret_A，ret_V，ret_T）の強さを，感情ごとの分離の度合い d′ で測る．実験 20 は，3 つの d′ を作って保存している．(i) は，K 本を感情ごとに 5 組に分け，1 組を抜いて学び直した 5 つの分類器の，抜いた組の上の予測から作った d′ である（提案が使う量）．(ii) は，K 本を全部使って学び直した 1 つの分類器の，K 本を除いた候補の全ラベルの上の d′ である（新しいコーパスでは手元に無い量）．(i) と (ii) のずれには，ラベルの本数と分類器の違いの分が入る．(iii) は，ソースのコーパスで学んだ分類器（ターゲットで学び直していない）のソースの中の交差の d′ に，ソースどうしで測った残り方を掛けてソースで平均した値で，ソースの組だけで決まる（同じコーパスの 50 単位と 3 つの K で同じ値）．各単位と K について 4 感情の平均を取り，(ii) で最も大きい分類器を (i) と (iii) が選んだかを数えた．(i) の d′ は K が小さいと粗く，2400 個の値（コーパス × 50 単位 × 3 分類器 × 4 感情）のうち上限の 2.90 に張り付いた値が K = 5，10，25 に 167，66，26 個，0 に張り付いた値が 225，115，39 個あった．この「最も強い」は積を作る分類器の d′ についてで，論文 6.7 節の「最も強い単独のモダリティ」（K 本の基準の分類器の候補の上の UAR）とは別の量である．(ii) で最も強い分類器の名前は AFEW・IEMOCAP・MELD で 6.7 節の最も強いモダリティと同じだが，この一致は 6.7 節の量を K 本で当てた証拠ではない．6.7 節の意味で K 本から当てられるかは，この解析では答えない．論文 7.1 節は，仮のターゲットの計算で同じ種類の量（水準の最も高いモダリティが 2 つの表で一致した反復の割合）を書いている．この節は，それを評価の回の単位で数えたものである．

**要点 11（ソースだけで決めた強さは，3 コーパスで最も強い分類器と違う分類器を選んだ）．**(ii) で最も強い分類器は，AFEW で顔，IEMOCAP で声，MELD で言葉（3 つの K の 50 単位すべて）だった．(iii) が選んだ分類器は，AFEW で声，IEMOCAP で顔，MELD で顔，MOSEI で顔で，3 つの K と 50 単位で同じだった．AFEW・IEMOCAP・MELD では，この 3 つの選択が 3 つとも (ii) の最も強い分類器と違ったので，(iii) の一致の割合は 0 になった（450 回の独立な外れではなく，3 つの決まった選択の外れである）．(iii) と (ii) の 3 つの順位の Kendall の τ の平均は，AFEW で 0.32〜0.33，IEMOCAP で −0.60〜−0.33，MELD で 3 つの K とも −1.000 だった（MELD では (iii) の順位が (ii) の順位の逆で，(iii) が選んだ顔は (ii) で最も弱い）．MOSEI では (ii) の 1 位と 2 位の差が小さく（中央値 0.017〜0.030），(ii) で最も強い分類器は単位によって変わり，最頻の分類器は K = 5 で顔（50 単位のうち 0.64），K = 10，25 で声（0.60，0.88）だった．(iii) はいつも顔を選ぶので，(iii) の一致の割合は K = 5 で 0.64，K = 10 で 0.40，K = 25 で 0.12 だった．

**要点 12（K 本で測った強さは，AFEW・IEMOCAP・MELD では多くの単位で最も強い分類器を選び，MOSEI ではでたらめに選んだときの 1/3 と同じ水準だった）．**(i) が (ii) と同じ分類器を選んだ割合は，AFEW で K = 5，10，25 に 0.94，0.96，1.00，IEMOCAP で 0.86，0.92，1.00，MELD で 0.70，0.76，0.88 だった．外側の分割ごとの割合の範囲は，MELD の K = 5 で 0.60〜0.80 などである．MOSEI では 0.30，0.36，0.38 で（分割ごとの範囲は K = 5 で 0.20〜0.50），K = 5，10 では (iii) の決まった選択（0.64，0.40）のほうが一致の割合が高かった．MOSEI の (i) は，(ii) で一度も最も強くならなかった言葉の分類器を，K = 5，10，25 で 50 単位のうち 13，8，6 単位で選んだ．損（(ii) の d′ の，最も強い分類器 − 選んだ分類器．4 感情の平均）を，当てた単位の 0 を含めた 50 単位で平均すると，(i) は 0.000〜0.084，(iii) は 0.005〜0.742 だった．MOSEI では 3 つの K とも (iii) のほうが小さかった（(i) 0.047，0.035，0.037，(iii) 0.005，0.016，0.033）．外した単位だけで平均すると，(i) の損は AFEW で 0.784（K = 5．3 単位）と 0.784（K = 10．2 単位），IEMOCAP で 0.473（7 単位）と 0.351（4 単位），MELD で 0.281，0.273，0.254（15，12，6 単位），MOSEI で 0.067，0.054，0.060（35，32，31 単位）だった．K = 25 の AFEW と IEMOCAP では (i) は外さなかった．外した単位だけで同じ K の (iii) と比べると，(i) の損は AFEW と IEMOCAP で (iii) と同じくらいかやや大きく（(iii) は AFEW 0.724，0.742，IEMOCAP 0.448，0.344．各 50 単位），MELD で小さく（(iii) 0.448，0.455，0.497），MOSEI で大きかった（(iii) 0.015，0.026，0.038．18，30，44 単位）．50 単位の平均で (i) の損が小さかった AFEW・IEMOCAP・MELD の差は，主に (i) が外す回数が少なかったことによる．

## 3. 書き方（論文で守ること）

- 2 節は計算の後の探索の記述で，予言は置いていない（論文では「計算の後に組んだ記述の解析」と書き，見た値の順を書く）．margin（候補の上）と gain（テストの上）は測る発話の集合が違う．点どうしは同じ候補とテストと先生の材料を共有するので，順位相関と数え上げは検定ではない．p 値は書かない．
- margin は候補の全ラベルで測った量で，新しいコーパスでは手元に無い（数本のラベルでの見積もりは調べていない）．
- 先生の種類によって，生徒自身のモダリティを含む先生と含まない先生がある（`teacher_margin.csv` の no_own_modality）．
