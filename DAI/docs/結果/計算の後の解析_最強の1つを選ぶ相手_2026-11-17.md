## 1. 比べたもの

- 提案：論文の下書き 7 節の推定時の答え（ラベルを使わずに，候補の上の確率の平均を積に合わせて切片をずらした答え）．
- 選ぶ相手：積を作る声・顔・言葉の分類器（融合の分類器の疑似ラベルで学び直した ret_A，ret_V，ret_T）から 1 つを選び，その答えだけを使う．K 本だけで学んだ単独の分類器から選ぶ相手と，CREMA-D は範囲に入れていない．
  - 手元にある情報だけで選ぶ版：sel_K（K 本のラベルで測った強さ（4 感情の d′ の平均．提案が K 本で測る水準の材料）が最大．主），sel_Kuar（K 本の上の交差の答えの UAR が最大），sel_ext（ソースのコーパスだけで測った強さが最大．コーパスごとに 1 つの分類器に決まる）．
  - 新しいコーパスでは手元に無い情報で選んだ参考の版：sel_test（単位ごとにテストのラベルで UAR が最大．1 つを選ぶ方法の上限の目安），sel_orc（K 本を除いた候補の全ラベルで測った強さが最大．テストで選んだ最良の 1 つの上限ではない）．sel_orc と sel_test は 12 条件のうち 7 条件で全単位に同じ分類器を選び，差も同じ値になるので，独立の 2 つの確かめではない．
- 2 つの層：adj 層（主）は単独の分類器にも提案と同じ切片のずらしを当てた判定（sel_*@adj）と提案を比べ，raw 層はどちらもずらさない判定を比べる．
- 比べたのは推定時の答えどうしだけである．選んだ 1 つの分類器の答えを疑似ラベルにして AVT を学び直した版は，学び直しが要るので作っていない．

## 2. 結果

**要点 1（主）**：adj 層の 提案 − sel_K は，AFEW，IEMOCAP（即興の部），MOSEI，MELD × K = 5，10，25 の 12 条件すべてで点推定が正で（+2.70〜+5.52 点），7 条件（IEMOCAP の K = 5，MOSEI と MELD の 3 つの K）で区間の下端が 0 を超えた．AFEW の 3 条件と IEMOCAP の K = 10・25 では区間が 0 を含んだ．区間の上端が 0 を下回った条件は無かった．AFEW と IEMOCAP の区間は広かった（幅 10.61〜12.01 点と 8.48〜14.27 点．MOSEI は 1.52〜1.64 点，MELD は 2.99〜3.66 点）．

**要点 2（差の内訳）**：提案 − sel_K は，丸める前の値で 提案 − 積と 積 − sel_K（adj 層）の和に等しい（小数 2 桁に丸めた値の和は 0.01 ずれることがある）．AFEW では 積 − sel_K が +0.57，+0.67，+0.66 点（3 つとも区間が 0 を含む）にとどまり，差の大部分は 提案 − 積（+2.13，+3.51，+3.14 点）から来た．IEMOCAP，MOSEI，MELD では 積 − sel_K が +2.04〜+5.02 点で，差の大部分はこちらから来た（提案 − 積は −0.09〜+0.83 点）．この 3 コーパスでは，積も 1 つを選ぶ相手より点推定で高かった（9 条件のうち区間の下端が 0 を超えたのは 7 条件で，IEMOCAP の K = 10 と 25 は区間が 0 を含む）．（出所：select_strongest_effects.csv の a = prod，b = sel_K@adj と，results/dai20_eval/summary/effects.csv の a = prop，b = prod．）

**要点 3（水準と選んだ分類器）**：sel_K@adj の UAR は AFEW 68.65，70.21，72.79，IEMOCAP 67.05，68.42，71.51，MOSEI 36.83，37.92，39.20，MELD 46.79，47.39，50.08（K = 5，10，25 の順）で，提案は AFEW 71.36，74.39，76.58，IEMOCAP 72.56，73.80，75.03，MOSEI 41.16，42.82，44.47，MELD 50.05，50.68，52.95 だった．sel_K が選んだ分類器（50 単位のうち声／顔／言葉の数）は，AFEW で 2/47/1，1/48/1，0/50/0，IEMOCAP で 43/6/1，46/4/0，50/0/0，MOSEI で 21/16/13，20/22/8，18/26/6，MELD で 11/4/35，10/2/38，6/0/44 だった．sel_K の選びが sel_test（adj 層）の選びと一致した単位の割合は，AFEW 0.90，0.94，1.00，IEMOCAP 0.86，0.92，1.00，MOSEI 0.44，0.42，0.36，MELD 0.70，0.76，0.88 だった．（出所：select_strongest_levels.csv の version = sel_K@adj と prop の uar と n_A，n_V，n_T．一致の割合は select_strongest_picks.csv の sel_K_mod と sel_test_adj_mod．）

**要点 4（手元に無い情報で選んだ参考の版）**：テストのラベルで単位ごとに最良の 1 つを選んだ sel_test（adj 層）と比べても，提案 − sel_test は 12 条件すべてで点推定が正で（+1.18〜+3.93 点），区間の下端が 0 を超えたのは MOSEI の 3 つの K と MELD の K = 25 の 4 条件だった．sel_orc との差も 12 条件すべてで点推定が正だった（+1.20〜+4.49 点）．ただし sel_orc と sel_test は 7 条件で同じ値である（1 節）．（出所：select_strongest_effects.csv の b = sel_test@adj，sel_orc@adj，seeds = all．）

**要点 5（ほかの選び方と層）**：K 本の交差の UAR で選んだ sel_Kuar（adj 層）との差は，12 条件すべてで点推定が正（+2.88〜+8.59 点）で，区間の下端が 0 を超えたのは 8 条件だった（AFEW の 3 つの K と IEMOCAP の K = 25 は区間が 0 を含む）．ソースだけで選んだ sel_ext との差は +3.94〜+21.78 点で，12 条件すべてで区間の下端が 0 を超えた．どちらの判定もずらさない raw 層では，提案 − sel_K は 12 条件すべてで点推定が正（+1.86〜+6.11 点）で，8 条件で区間の下端が 0 を超えた．raw 層で最も小さい差は AFEW の K = 5 の 提案 − sel_test（+0.31 [−5.44, +6.06]）だった．raw 層の 積 − sel_K は AFEW の K = 5 で −0.02 点（点推定が負）で，ほかの 11 条件では正だった．切片のずらしは AFEW の sel_K の UAR を 0.44〜0.65 点下げたので，AFEW の差は adj 層のほうが raw 層より大きい．

**要点 6（感情ごと）**：UAR では 12 条件すべてで提案が上だったが，感情ごとの再現率の差の点推定には負のものがあった．adj 層の 提案 − sel_K では，AFEW の Happy（K = 5，10，25 で −6.42，−4.64，−4.39 点），MELD の Neutral（−2.74，−3.14，−4.32 点），IEMOCAP の Sad の K = 25（−0.21 点）が負だった．提案 − sel_test では，これに MELD の Happy（−2.68，−1.52，−0.12 点）が加わった．raw 層の 提案 − sel_K では，MOSEI の Neutral（−6.00，−4.24，−2.68 点）も負だった．感情ごとの差の区間は作っていない（出力にあるのは感情ごとの再現率の区間だけ）．（出所：select_strongest_per_emotion.csv の recall の差．）

**要点 7（種の部分集合）**：種 0・1 の単位は，提案の設定を選んだ下調べと K 本・候補が同じなので（実験 20 の設計），種 0〜1 と種 2〜9 を分けて読む．主の対の点推定は，種 0〜1 だけ（各分割 2 通りの K 本の抜き方，10 単位）でも種 2〜9 だけ（40 単位）でも 12 条件すべてで正だった．区間の下端が 0 を超えたのは種 0〜1 で 4 条件（MOSEI の 3 つの K と，IEMOCAP の K = 10．MELD の 3 つの K は区間が 0 を含む），種 2〜9 で 7 条件だった．

## 3. 書き方の注意

- 「最強の 1 つを選べば済む」への答えとしては，「K 本で最も強い分類器を 1 つ選んでその答えを使う相手より，提案の UAR は 12 条件すべてで点推定が高く，7 条件で差の区間の下端が 0 を超えた」と書く．同じ段落で，AFEW の 3 つの K と IEMOCAP の K = 10・25 は区間が 0 を含んだこと，IEMOCAP・MOSEI・MELD では積も 1 つを選ぶ相手より点推定で高く，差の大部分が 積 − sel_K の分から来たこと（要点 2）を書く．
- 比べたのは推定時の答えだけで，疑似ラベルで学び直した AVT の比べではない．また，実験 20 の本体が出している「提案（ずらした答え）− 相手（ずらさない答え）」の層をまたぐ対は作っていない（水準の差だけで見ると，AFEW の K = 5 の 提案 − sel_test（ずらさない側）は +0.56 で，同じ層どうしの +1.18 より小さい．区間は無い）．論文に並べるなら，追加の計算をするかを研究者と決める．
- sel_test と sel_orc は，新しいコーパスでは手元に無い情報で選んだ参考の版と書く．sel_orc は上限と書かない．
- 計算の後に，研究者との相談を受けて足した比べである（論文の評価の手順の外）と書く．
- 感情ごとには負の差がある（要点 6）ことを，表の注か本文に 1 文書く．
