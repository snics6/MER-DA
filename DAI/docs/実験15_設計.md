## 1. 問いと分析からの予言

採用した骨格の 3 つの条件は「余地がある」「疑似ラベルが今の分類器より当たる」「疑似ラベルの判断を自分の特徴で再現できる」である．取り違えの補正は，生徒が疑似ラベルの系統的な偏りをそのまま写さないようにする介入で，2 つ目（疑似ラベルの当たり）に働きかける．
- 声の分類器は 3 つがそろい，提案で上がった．補正が疑似ラベルの系統的な偏りを差し引くなら，提案より上がりうる（H1）．
- 融合の分類器は積の疑似ラベルを表せるが，疑似ラベルが融合とほぼ同じだけしか当たらない（2 つ目が欠ける）．補正で目標が疑似ラベルの偏りから離れれば上がりうる（H2）．
- 顔と言葉は，分類器ごとに欠ける条件が違う（主張の 2 節）．補正の式からは顔・言葉の得について予言を導けないので，予言を置かず記述にする（第 1 版の H2 を外した）．
- MOSEI は取り違えの表が特異に近い（実験 12 の 7 節．出所 pair の値）．K 本の表の推定の不足で効かない場合は，候補の全ラベルで数えた表なら上がるはずなので，その形で切り分ける（H3）．

## 3. 手法

- **取り違えの表の交差の推定 Ĉ**：K 本を感情ごとに並びの順で 5 組に配る（K = 5 なら各組に各感情 1 本）．組 j を抜いた K 本で，疑似ラベルのモデルを実験 1 の段 1・2 と同じ手順で作り直す（K 本だけの融合の分類器 → その確率で声・顔・言葉を学び直す → 積．引き戻しは実験 1 の固定の値）．抜いた組の発話の上の疑似ラベルの確率を本当の感情ごとに平均して Ĉ_ij（≈ P(疑似 = j | 本当 = i)）を作る（GLC の推し方）．K 本を全部使って作り直した疑似ラベルが保存の積と 10⁻⁴ を超えて違えば止める．作り直したモデルは K 本の 4/5 で作るので，取り違えを多めに見積もる向きに偏る（組ごとの疑似ラベルのモデルの候補の上の UAR を記録する）．K 本の組は話者や対話で分けない（ラベル無しの候補も同じ割合で K 本の話者と重なるので，推定を偏らせる要因にはならないと判断した）．
- **縮小**：C_λ = (1 − λ)Ĉ + λ S(Ĉ)．S(Ĉ) は Ĉ の対角の平均 d̄ を対角に，(1 − d̄)/3 を非対角に置いた表．λ ∈ {0, 0.5, 1}．d̄ ≤ 0.25（でたらめと同じ当たり）なら補正しない（単位行列）．
- **目標の重みに合わせる**：提案の疑似ラベルの項は，感情ごとの総量をそろえる（`soft_rows` の balance：列 j に w_j = 1 / Σ_n q_nj を掛ける）．その目標に合う前向きの表は C′ = 行の正規化(C_λ · diag(w))，つまり C′_ij = C_λ,ij w_j / Σ_k C_λ,ik w_k である．補正にはこの C′ を使う（第 1 版は C_λ をそのまま掛けており，偏りを 2 回直す食い違いがあった）．単位行列なら C′ も単位行列で，提案と同じ問になる．
- **前向き補正の生徒**：生徒の確率 p に C′ を掛けた p̃ = C′ᵀp（p̃_j = Σ_i p_i C′_ij．log-sum-exp で計算）を，疑似ラベルの項の目標に合わせる．
  - 目的関数：[ K 本の項 Σ a·gK·(−log p) ＋ 疑似ラベルの項 Σ soft_rows(q, ρn)·(−log p̃) ＋ ‖W − W₀‖²/(2C_w) ＋ ‖b − b₀‖²/(2C_b) ] ÷ 重みの和．
  - a，ρ，出発点 (W₀, b₀)，引き戻し (C_w, C_b) は提案の選んだ設定（実験 1 の固定のファイルの `s|K|joint|one`．32 セルすべて ρ = 1，a = 1）と同じ．補正の版のために選び直さない（補正の版に不利な向き）．
  - **補正は感情の割合も変える**：C′ で補正すると，生徒が学ぶ問の本当の感情の割合が 4 等分でなくなる（候補の割合 π と r_i = Σ_k C_λ,ik w_k に依る．C_λ diag(w) の列の和がすべて 1 のときだけ変わらない）．したがって補正の版と提案の差には，取り違えの補正の分と予測の割合の変化の分が混ざる．
  - **割合をそろえた版（_adj）**：各版（I，λ，naive，oracle）について，ラベルを使わずに切片だけをずらし，候補の上の予測の確率の平均を提案の候補の上の平均と同じにする（不動点の反復．残りが 10⁻⁴ を超えたら止める）．同じずれをテストの出力に足して判定する．前向きの模型が含意する，生徒が学ぶ問の本当の割合 π′ = C′⁻ᵀ(1/4, …) も記録し（和は常に 1 なので，0〜1 の外は負の成分があることと同じ），旗を立てる．実際の候補の上の予測の確率の平均（candmean）と並べる．割合をそろえた版がそろえるのは候補の上の確率の平均で，判定（argmax）の割合やテストの上の割合はそろわない．また，偏りがあるときは，取り違えの補正が本来起こす割合の変化（補正の効き目の一部）も消す（人工の数で，補正の生の差が約 7 点でも割合をそろえた差はほぼ 0 になる例がある）．
  - C′ ≠ 単位行列の問は凸でない．出発点は提案と同じ出発点で，解いた目的関数の値を記録する．
  - 検算：C′ = 単位行列の版（I）を毎単位で解き，保存の提案との重み (W, b) の相対の差が 10⁻² を超えたら止める．同じ凸の問を別の束で解くので，境目の発話の判定は入れ替わりうる．入れ替わった発話の数は記録だけにする．
- **版**：I（補正なしを解き直したもの），λ = 0，λ = 0.5，λ = 1（対称の表），naive（K 本の上でそのまま数えた表．交差の推定を外した除去実験），oracle（候補の全ラベルで数えた表．参照．上限ではない）．仮のターゲットの回でも評価の回でも全部の版を解く．
- **選び方**：(T, 生徒, K) ごとに，仮のターゲットの回の 30 単位の平均のテストの UAR で「補正しない（提案）／λ = 0／λ = 0.5」から 1 つを選ぶ（割合をそろえない版で選ぶ．評価の回の前に決めた）．厳密な最大で選び，同点は補正しないを残す．仮のターゲットの回の「補正しない」の値は解き直した I の値を使う（試しで I と提案の判定の入れ替わりは 0）．固定のファイル `DAI/frozen/dai15_frozen.json` をコミットしてから評価の回を流す．
- **教師の判定し直し（記録）**：疑似ラベルのモデルのテストの確率 q（保存する）に，生徒の目標と同じ列の倍率 w を掛けた w⊙q の判定と，それに λ = 0 の C′ の逆を掛けて判定し直した C′⁻ᵀ(w⊙q) の判定を比べる（d̄ ≤ 0.25 の単位は単位行列）．負の値を含む線形の変換で確率としては読めないので，「表の逆で判定し直した記録」とだけ書く．判定し直しの得が上回らないコーパスでは，融合の H2 の当たりを「疑似ラベルの当たりを上げた」とは読まない．
- **log π′ を引いた記録の版**：保存した確率から log π′ を引いて判定した版（sel_lpi，λ0_lpi）を集計の段で作る．予言の判定には使わない．π′ に 0 以下の成分がある単位の数を添える．

## 5. 予言（計算の前に固定）

主のセルは K = 5．「上回る」は区間の下端 > 0，「下回る」は上端 < 0，それ以外は「判定できない」．

| 予言 | 量 | 当たりの規則 |
|---|---|---|
| H1（改善．主） | 声の分類器の sel − prop と sel_adj − prop | 両方が上回るコーパスが 4 のうち 3 以上 |
| H2（融合，条件 2） | 融合の分類器の sel − prop と sel_adj − prop | 両方が上回るコーパスが 4 のうち 2 以上 |
| H3（MOSEI の推定） | MOSEI の声の分類器 | oracle_adj − I_adj と oracle_adj − λ0_adj がともに上回り，かつ λ0_adj − I_adj が上回らないときだけ「K 本の表の推定の不足」と書く（選択を含まない版どうしで判定する）．それ以外は推定の不足に帰さない．補正しない単位（d̄ ≤ 0.25）の数を添える |
| C1（表の形の情報） | 声の λ0_adj − sym_adj と λ0_adj − I_adj | λ0_adj − I_adj が上回るコーパスのうち，λ0_adj − sym_adj も上回るものが 3 以上なら「表の対角の違いと非対称さの情報で上がった」と書く．そうでなければ「表の形の情報によるとは言えない」 |

- 顔と言葉の sel − prop と oracle − I は記述として並べ，予言にしない．
- H1・H2 は，割合の変化を通らない得だけを数える保守的な規則である．外れても，補正が効かなかったことは示さない．
- sel − prop が上回るが sel_adj − prop が上回らないコーパスは，「割合を提案に合わせると上回るとは言えなかった．割合の変化が取り違えの補正によるのか π′ のずれによるのかは区別できない」と書き，H1・H2 の数えに入れない．sel_adj − prop だけが上回るコーパスは，「割合を提案に合わせると上回ったが，生の差は上回らなかった」と書き，数えに入れない．
- H1・H2 の判定の量は，どのセルでも sel − prop と sel_adj − prop である（hypotheses.csv）．λ を選んだセルの I − prop が「判定できない」以外なら，sel − I と sel_adj − I_adj を結果の文で並べて読むが，数えは変えない．
- H3 の形で MOSEI の声が上回らないとき，H1 は AFEW・IEMOCAP・MELD の 3 つすべてで上回る必要がある（数えの規則は変えない．この重なりを結果の文に書く）．
- H1 と H3 は MOSEI の声のセルを共有する．H3 の形で MOSEI が上回らないなら，H1 は AFEW・IEMOCAP・MELD の 3 つすべてで上回る必要がある．
- 数えが偶然に当たる見込み（4 コーパスを独立とみなした下限）：「4 中 3 以上」6.1 × 10⁻⁵，「4 中 2 以上」3.6 × 10⁻³．コーパスを単位にした符号検定の p は最小でも 0.125 で，主張はコーパスごとの記述にとどめる．

**書き方**
- H1 が当たれば：「GLC の前向き補正（K 本で推した取り違えの表．感情ごとの総量の重みに合わせた形）で，声の分類器は提案より上がり，予測の確率の平均を提案に合わせた版でも上がった（K = 5，4 コーパスのうち x．差 …）」．
- H1 が外れたときは，次の 3 通りで書く（主語は「GLC の前向き補正（クラスごとの表）」．「上回る」は生の差と割合をそろえた差の両方が上回ったコーパスを指し，片方だけのコーパスは上の文で別に書く）．
  1. 「下回る」があれば：「補正は y のコーパスで提案を下回った（差 …）」．
  2. すべて「判定できない」なら：「補正と提案の差は検出できなかった（差 …，そのコーパスで検出できる差の目安 …）」．「差が無い」とは書かない．
  3. 上回るが 1〜2 なら：「上回ったのは x のコーパスだけで，規則（3 以上）を満たさなかった」．
  - 「上回る」と「下回る」が両方あれば，両方を名指しで並べる．
  - 補正しないが選ばれたコーパスは，「仮のターゲットの回で補正しないが選ばれた（差は 0）」と分けて書き，「検出できなかった」に入れない．
- H2 が外れたときも同じ 3 通りで書く．
- どの場合も，選ばれた版の内訳，oracle − I（全ラベルの表なら上がる余地があったか），naive − λ0（交差の推定の影響），予測の感情ごとの割合と再現率（`per_emotion.csv`）を並べる．
- 「取り違えを打ち消した」とは書かない（7 節の A2）．書けるのは「K 本で推した表で前向きに補正した」まで．新しい手法とも書かない．
- 予測の割合の変化は両方の向き（Neutral を減らす向きと増やす向き）がありうる．H1・H2 の数えは割合をそろえた版でも上回ることを要るので，切片のずれで作れる分の得は数えに入らない（判定の割合はそろわないので，割合の変化が全く入らないとは言えない）．上回ったコーパスでは，sel_adj と提案の判定の割合（pred_share）を並べる．感情ごとの予測の割合と再現率（`per_emotion.csv`．種を重ねて数えた記述で区間は無い）は向きの記述として並べ，感情ごとの主張はしない．

## 6. 記述として出すもの

- 取り違えの表（交差の推定，K 本の上でそのまま，全ラベル）と，重みに合わせた表，対角の平均・特異値，単位の間のばらつき．
- 組ごとに作り直した疑似ラベルのモデルの候補の上の UAR と，全部の K 本で作ったものの UAR．
- 選ばれた版の内訳，仮のターゲットの平均の UAR の表（`select_means.csv`，仮のターゲットのコーパスごとの `select_means_by_c.csv`）と差の大きさ（評価の段の後に開く）．
- K = 25 の同じ予言の判定（副）．
- 収束（補正の問と作り直しの勾配の最大，止まり，目的関数の値），I と提案の重みの差と判定の入れ替わりの数．
- 予測の感情ごとの割合と再現率（全部の版）．
- 保存（単位ごと）：全部の版のテストの判定と確率（float32），表，抜いた組の疑似ラベルの確率，K 本の感情，テストの塊と sample_id．後から感情の対ごとの効果，較正，話者を単位にした区間，実験 1 の感度の部分集合を学び直さずに出せる．

## 7. 仮定の表と限界

| 仮定 | 中身 | 測る量 | 成り立つとみなす基準と，崩れたときの書き方 |
|---|---|---|---|
| A1 | 疑似ラベルの誤りは本当の感情だけで決まる（クラス条件つき） | 測らない | ラベル無しの例の蒸留では教師の誤りは例ごとに違いうる（SLaM）．補正は平均の誤り方しか差し引かないと書く．例ごとの補正は比べていない |
| A2 | Ĉ の推し方と補正の式の 2 つの条件付き独立が同時に成り立つ（感情が特徴から一意に決まる） | 疑似ラベルのモデルの候補の上の UAR（全部の K 本）と Ĉ の対角 | 成り立たない前提で書く．Ĉ は本来の曖昧さを含むので，「取り違えを打ち消した」とは書かない |
| A3 | 感情ごとの総量の重みと表が整合する | C′ の式（3 節） | 整合する．ただし予測の割合が変わる（A8） |
| A4 | K 本の 4/5 で作り直した疑似ラベルのモデルが全部の K 本のものに近い | 組ごとのモデルの候補の上の UAR と全部の K 本のモデルの UAR の差 | 差の平均が 2 点以内なら近いとみなす．超えたら「Ĉ は取り違えを多めに見積もった」と書く |
| A5 | 疑似ラベルが C′ の行の作る範囲の中にある | 測らない（Ĉ の非対角が対角を超える行の数は保存した表から数えて書く） | 範囲の外の発話では解が引き戻しで決まると限界に書く |
| A6 | 補正の問（凸でない）が十分に解ける | 勾配の最大，止まり，目的関数の値 | 勾配 10⁻⁶ 以下で止まりが 0 なら解けたとみなす |
| A7 | 提案の (ρ, a) と引き戻しを補正の版に流用してよい | 測らない | 補正の版に不利な向きと書く |
| A8 | 補正で予測の割合が変わる | 割合をそろえる切片のずれ，π′（模型の含意する割合）と candmean，予測の感情ごとの割合 | H1・H2 は割合をそろえた版でも上回ることを要る（保守的）．π′ が 0〜1 の外に出た単位の数とコーパスごとの範囲を版ごとに書く |
| A9 | 表の対角の平均がでたらめより大きい | d̄ | d̄ ≤ 0.25 の単位は補正しない（単位行列）．その数をセルごとに書く |

限界（結果の文に書く）：
- 確認ではない（評価の回の解析の後の案，同じ 4 コーパス）．補正の手順は既知（GLC）．
- K = 5 では 20 本で 12 個の数を推す．交差の推定の組は 5 つ．縮小の強さは仮のターゲットで厳密な最大で選んだ（実験 1 の選び方の幅は使っていない）．
- ほかの雑音に強い損失（後ろ向きの補正など）と，例ごとの補正（SLaM）は範囲の外．Fujioka ほか 2019 との違いは関連研究に書く．
- 表の中身は「疑似ラベルとコーパスのラベルの決め方の食い違い」も含む（IEMOCAP の Happy は excited と happy を合わせたもの，MOSEI の Neutral は消去法で決まる．Mao ほか 2021）．
- 検算の重みの差は出発点を含む重み全体で割った値（value）と，出発点からの移動で割った値（value_moved）の両方を記録する．
- 実験 1 の 9.4 節の感度の部分集合での H1・H2 の差は出さない（この実験は分析の予言の確かめを兼ねる探索で，セルを増やすと判定の数が増えるため）．保存した sample_id と塊から，学び直さずに後で出せる．
- 実験 1 から引き継ぐ限界：MOSEI はチャンネルか動画で話者の代わりにした，IEMOCAP は即興だけで 2 つの組が筋書きを共有する，MELD はエピソードの筋を共有する，AFEW の言葉は Whisper の書き起こし．
- 線形の生徒，凍結した特徴，1 組のエンコーダ．
- 区間は候補（ラベル無しのプール）を固定したもの．
