### 2.3 保存するもの（R1〜R3）

1 ターゲットにつき `<out>/<kind>/<ターゲット>.npz` を 1 つ書く．鍵の一覧は台本の `KEYS_DOC` にある．要点は次のとおりである．

- 点数：4 感情の対数オッズ（float32）．① は (K, C, テスト, 4)，② はターゲットの全発話，③・h3・h6・h7・h8 はテスト，h2 は全発話，h4・h5 はずらし b
- 係数：生の特徴の上の係数 A（float32）と切片 a0（float64）．点数 = X Aᵀ + a0（中心合わせの手は X − 平均）．テストの外の発話（プール）での点数も CPU で作り直せる（ML Major-3 の「切片だけをプール全ラベルで最適化」など）

- 収束：条件ごとの L-BFGS の反復回数と止まったときの勾配（`<ターゲット>.csv` の `n_iter`・`grad`）

`<ターゲット>.csv` は条件ごとに 1 行で，UAR と照合の相手の値を並べる．`<ターゲット>.json` に設定，コミット番号，所要時間，GPU の最大使用量，照合のまとめを書く．`provenance.json` に実行ごとの設定とコミット番号を足す．実行したコードの写しを `code/<開始時刻>/` に置く（`map.snapshot_code`）．

### 2.4 計算の後の解析（CPU．ステップ 4 で台本を書く．ここで決めた手順は結果を見てから変えない）

#### 2.4.1 地図の区間（筋 1．ML Major-1，感 Minor-1）

- **利得**：組（ターゲット T，ソース S）× K ごとに，反復 0〜9 の平均の「③ − ①」の UAR の差．同じコーパスの組は除く（地図と同じ）
- **主の区間：2 段のブートストラップ**．1 段目に T の話者群を戻して引き（引いた回数を重みにする），2 段目に反復 0〜9 を戻して引く．1 つの引き方の値は，引いた反復の「重みつき UAR の差」の平均である．重みつき UAR は，各感情の再現率を発話の重みで数え，重みが 0 の感情を除いた感情で平均する（除いた回数を記録する）．B = 2,000，百分位の 95% 区間．同じ T の組はすべて同じ引き方を共有する．話者は反復の間で重なるので，同じ話者には同じ重みがかかり，反復の間の依存が区間に入る．分類器は学び直さない（学習側の話者の揺れは反復の引き直しでだけ入る．限界に書く）
- **副の区間**：補正した resampled t（Nadeau & Bengio 2003．分散に 1/J + n_test/n_train を掛ける）．反復ごとの UAR だけで出るのでステップ 1 で出す．E76 では同じ反復 0〜9 で並べる
- **数え上げと多重性（S4）**：種類 × K ごとに，区間が 0 より上・下の組の数を数える．主の数は，ブートストラップの両側 p 値（2 × min(P(値 ≤ 0), P(値 ≥ 0))）に Holm 法を種類 × K の組の族でかけた後の数，表には補正しない数も並べる
- **K***：区間の下端が 0 を上回る最大の K（主の区間．補正しない）．分布を種類ごとに数える
- **平均の反復**：主の表の平均も反復 0〜9 にする．反復 0〜29 の平均は補足の行に置く（CPU．地図の CSV から）

**判定と書き方の決まり**（説明資料 p1 の 3 節の文「8 種類とも K が小さいと上がり，大きいと下がる」をどう書くか）

| 結果 | 書き方 |
|---|---|
| どの種類でも，K=1 で Holm の後に区間が 0 より上の組が 75% 以上 | 「どの種類でも K=1 で上がる」を残し，数を新しい区間の数に替える（A(HuBERT) は E76 に入れなければ副の区間で別に書く） |
| 75% 未満の種類がある | その種類の名前と数を書き，「どの種類でも」を満たす種類に限る |
| 全件で区間が 0 より下の組が半分未満の種類がある | その種類では「大きい K で下がる」を「下がる組がある（x/y 組）」に替える |
| K* の中央値が，同じ反復 0〜9 の反復を独立とみなした t 区間の K* から 2 段以上動く種類がある | 本文に「K* は区間の作り方に依る」と書き，両方の分布を補足に置く |

**表と図**：表 1（種類 × K）に平均の利得，2 段のブートストラップの 95% 区間（組の平均の区間．引き方は T ごとに共有し，組の平均を引き方ごとに取る），0 より上・下の組の数（Holm の後／補正なし），K* の分布．図 1 は種類ごとのパネルで，横軸 K（対数），縦軸利得，組ごとの細い線と種類の平均と区間の帯．ターゲットが 4〜7 群しかないので，種類の平均の区間は「この 4〜7 群の話者と K 本の揺れ」を表し，ほかのコーパスへの一般化は示さない（S2）．

#### 2.4.2 性別ごとの値とテストの部分集合（感 Minor-15，ML Minor-1，ML Minor-2）

- **性別**：IEMOCAP（`utterance_speaker`），AFEW（`gender`），RAVDESS（俳優番号の奇数が男性，偶数が女性．RAVDESS の配布の説明による）．CREMA-D は配布元の人口統計の表が要り，手元に無いので外す．MELD・MOSEI は性別の情報が無い．量は ①・②・③ の UAR と利得（K=5 を主，K=1・10 は記述）を性別ごとに出し，女性 − 男性の差に 2 段のブートストラップの区間（性別の中で話者を引く）を付ける
- **MOSEI のチャンネルの分かる発話**：テストのうちチャンネルが分かる動画の発話だけで利得を測り，全テストとの差を出す．学習側（プールとソース）は絞らないので，話者の漏れは半分しか除けない（限界）
- **IEMOCAP 台本の台詞の重なり**：言葉を含む 4 種類で，ターゲットが IEMOCAP-script のとき，テストの発話のうち，転写（小文字にし，句読点と空白をそろえたもの）が K 本のどれかと同じものを除いて UAR を出す．K=全件はプール全部を学ぶので除けず，この解析から外す．台本を除いた集計（言葉系の種類の平均を IEMOCAP-script 以外の 3 群で取る）は計画のステップ 0 のとおり別に出す

**判定と書き方の決まり**

| 結果 | 書き方 |
|---|---|
| 性別の差の区間が 0 を含む | 倫理の節に「性別ごとの利得の差は区間（± x 点）の中」と書く |
| あるコーパスで区間が 0 を含まない | そのコーパスと差の大きさを書く．性別で利得が違う理由は扱わない（記述） |
| MOSEI・台詞の部分集合での利得と全テストの利得の差が，全テストの区間の半幅以内 | 「部分集合でも結論は変わらない」と 1 文 |
| 半幅を超える | 両方の値を書き，言葉系の主張を IEMOCAP-script を除いた集計に限る（台詞のとき）．MOSEI はその向きを書く |

**表**：補足の表（コーパス × 性別：話者の数，① ② ③ の UAR，利得と区間）と，部分集合の表（全テストと部分集合の利得と区間，除いた発話の割合）．

#### 2.4.3 ターゲットのみの C の規則（筋 1・3．ML Minor-6，ML Major-4，感 Minor-6）

- **規則**：(主) 今の地図の規則（交差検証．交差検証ができなければ C=1，同点は 1 に近い方，なお同点なら小さい方）．(別) 仮のターゲットの規則：T と K ごとに，同じ種類の群のうちコーパスが T と違う群 G について，G の ① のテストの UAR（反復 0〜9 の平均）を C ごとに平均し，それが最大の C を選ぶ（同点の規則は主と同じ）．T のラベルは使わない．論文のほかのつまみを仮のターゲットで選ぶのと同じ考えである．(記述) C を 0.01，0.1，1，10 に固定した 4 本
- **量**：各規則の学習曲線（① の UAR），K=1 と K=5 の利得，K*（2.4.1 の区間），n の実測（E32 と同じ手順で学習曲線だけを替える），q（下）
- **q の当てはめ**：① の各規則の C でのテストの点数から，感情の対ごとに d_T(K) を測る（E28-9 と同じ `explore_pairs.measure` の定義）．D は E13 の own_d．(i) 主：d_T(K) = D/√(1 + q/K) を K ∈ {1, 5, 10} で最小 2 乗（E28-9 と同じ），(ii) 延長：K ∈ {1, 5, 10, 25, 50}．q の 95% 区間は 2 段のブートストラップ（2.4.1 と同じ引き方で d_T を測り直して当てはめ直す）．残差は K ごとに出す．別の関数形として M1（D と q を両方当てる），M2（d = a K^b）を当て，K を 1 つずつ抜いた予測の 2 乗誤差で比べる．言葉系 4 種類も同じ手順で出す
- **ターゲットの間の比べ（D5）**：順位相関は K ごと，ターゲットの中で取り，K を混ぜない

**判定と書き方の決まり**（別の規則は仮のターゲットの規則 1 つだけを判定に使い，C を固定した 4 本は記述にとどめる．多重性を避けるため）

| 結果 | 書き方 |
|---|---|
| どの種類でも，仮のターゲットの規則の K=1 の利得が主の規則の値から 1.0 点以内 | 「K=1 の利得はターゲットのみの C の規則に依らない（範囲 a〜b）」と 1 文．数は主の規則のまま |
| 1.0 点を超えて動くが正のまま | 本文の K=1 の利得を 2 つの規則の範囲で書き，要旨は小さい方の値を書く |
| ある種類で仮のターゲットの規則の K=1 の利得の区間が 0 を含むか 0 より下 | その種類の K=1 を主張から外し，「K=1 の利得はターゲットのみの C の規則に依る」と書く．要旨の K=1 の数を K=5 の数に替える |

### 2.5 再現の検算（台本の中で毎回．I7・I14）

幅 tol は条件ごとに max(0.002, 2 × u) とする．u はその反復のテストで発話 1 本が UAR を動かす最大の量で，u = 1 /（4 × テストで最も少ない感情の本数）である（AFEW では u ≈ 0.007，MOSEI では u ≈ 0.001）．

| 照合 | 相手 | 合格の基準 |
|---|---|---|
| ① の C，規則，UAR，C 4 つの UAR | C を固定した地図（`results/fixc_map/<kind>/<T>.csv` の tgt_only の `C`・`C_rule`・`uar`・`test_uar_C*`） | C と規則がすべて同じ．選ばれた C の UAR の差が 1e-6 以下．選ばれなかった C は差が tol の 2.5 倍以下で，1e-6 を超えた行の数を記録する（下の注） |
| ② の C，規則，UAR，C 4 つの UAR | 同じ地図の src_only | 同上 |
| ③ の UAR | 同じ地図の merged の `uar`（全 K） | 差が tol を超える条件が 1% 以下で，どの条件も tol の 2.5 倍以下 |
| h2〜h8 の UAR | E25（`results/interventions_<kind>/<T>.csv`） | 同上 |
| ① ② ③ の点数 | 前の点数（`merged_scores_*`，`tgt_scores_*`．K ≤ 10） | 記録する（点数の差の最大と argmax の一致の割合） |
| 係数から作り直した点数 | 保存した点数（最初の反復の ①，③，h3） | 記録する |

基準を満たさなければ台本はそのターゲットを書いた後に止まり，再開しても照合に落ちたファイルは飛ばさずに止まる．③ と手の基準に幅を持たせたのは，E15 の段階 B（`exp/merged_scores.py`）で，同じ C で解き直した合併の UAR が地図と最大 0.0019 ずれ，240 条件のうち 2 つが 0.001 を超えたためである（`logs/e15b_fixc.log`．止める基準 TOL = 1e-6 の範囲で argmax が変わる発話がある）．

**注（試しで基準を直した）**：初めの基準は ① と ② の C 4 つすべてに 1e-6 を求めた．試し 2（音声，MOSEI，反復 0〜2）で ② の選ばれなかった弱い罰則（C = 1 と 10）の UAR が地図と最大 0.0018 ずれ（18 行のうち 11 行が 1e-6 を超えた．ソース RAVDESS の C=10 など），試し 4（音声，IEMOCAP-impro ← IEMOCAP-script，反復 0〜2）で ① の K=全件・反復 1・C=10 が 0.0011 ずれて，台本が止まった．選ばれた C ではすべて 1e-16 の桁で一致した．地図のファイルは 2026-09-30 の未コミットのコードの実行（`dirty: true`）を含み，弱い罰則で行の多い問題は止める基準（勾配 1e-6）の範囲で解がずれ，数本の発話の argmax が変わる．選ばれなかった C の基準を緩め，ずれた行の数を `<T>.json` に残す．C の別の規則の解析（2.4.3）は地図の値ではなく E76 の値を使うので，このずれは解析の中では生じない．さらに試し 5（音声，AFEW ← RAVDESS，反復 0）で，② の選ばれなかった C の差 0.0069 が固定の幅 0.005 を超えて止まった．AFEW のテストは小さく，発話 1 本の argmax が変わるだけで UAR が 0.0071 動く．固定の幅では小さいテストを判定できないので，幅を発話の本数に合わせた tol に替えた．直した基準で試し 1・2・4・5 を判定し直すと，すべて合格した（差 ÷ tol の最大は 0.89．MOSEI の ② の選ばれなかった C）．

## 6. 限界

- 話者を単位にしたブートストラップは分類器を学び直さないので，学習側（K 本，プール，ソース）の話者の揺れは反復の引き直しでだけ入る
- 種類の平均の区間は，この 4〜7 群の話者と K 本の揺れを表す．ほかのコーパスへの一般化は示さない（S2）
- 中心合わせはターゲットの全発話（テストを含む）の特徴の平均を使う（E25 と同じ．ラベルは使わない）
- 性別は 3 コーパス（IEMOCAP，AFEW，RAVDESS）だけで，RAVDESS は映像が無い
- 仮のターゲットの規則は，ほかの群の ① のテストの UAR を使う．その群も別の回の評価のターゲットである（`docs/seen-data.md` 1 節の E65〜E71 と同じ事情）
