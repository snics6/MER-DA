## 2. 計算すること

### 2.1 (a) δ の計算（仮のターゲットの出力だけ）

**材料**：E77 の `<T>_ps_<c>_r<r>_none.npz`．評価のターゲット T ごとに，ソースの各群 c を仮のターゲットにしたときの none の，c のテストの発話の対数の確率とラベルである（反復 r = 0〜4，K = 0, 1, 5, 10, 25，生徒ごと）．種類の実行では生徒は種類そのもの，世界の実行ではモダリティごとの生徒と融合の生徒である．IEMOCAP の即興と台本は別の仮のターゲットとして数える（E78 の `choose_seeded` と同じ）．

**手順**
1. (実行, 生徒, T, c, K, r) ごとに，UAR（`measure/shift.py` の `uar`）と，6 対の A(d, 0) の平均を計算する．d は `exp/explore_synergy.py` の `d_o`，A は `exp/explore_pairs.py` の `ba` を呼ぶ（書き直さない）．単位はポイント（× 100）
2. (実行, 生徒, T, c, K) ごとに，反復 0〜4 の標準偏差（ddof = 1）を √10 で割り，s_u（UAR）と s_d（A(d, 0)）にする．評価の値は反復 0〜9 の 10 回の平均なので分母を √10 にする（設計の文書 7.2 節）
3. δ_u(実行, 生徒, K) ＝ 2 × 中央値_(T, c) s_u，δ_d も同じ．中央値は，その生徒の種類の全部の（評価のターゲット，仮のターゲット）の組をまとめて取る（E77 の関門 1 の直し）
4. 検算：npz から計算した UAR が `<T>_pseudo.csv` の none の行の UAR と 1e−9 以内で一致することを全部の行で確かめる（外れたら止まる）

**決めたこと**
- 生徒の種類は（実行, 生徒）の 10 通りにする：種類の A・V・T，AVT の世界の音声・顔・言葉・融合，AV の世界の音声・顔・融合．世界のモダリティの生徒は全モダリティのそろう発話に限った生徒で，E39 の設定も世界ごとに違うので，種類の生徒とまとめない（9 節の 1）
- δ_d は A(D, 0) − A(d, 0) ではなく A(d, 0) の揺れから作る．D は特徴が要り，仮のターゲットでは特徴を保存していない．判定は none と手法の差に当てるので D が打ち消し合い，この作り方で足りる（E77 の統計の再確認の記録）．δ を書くときにこのことを明記する
- 種類の生徒では，仮のターゲットの合併の C が 0.01，評価の C が E25 の値で違う．このことを δ の表の注に書く

**出力**：`delta_reps.csv`（反復ごとの値），`delta_units.csv`（組ごとの s_u・s_d と反復の数），`delta.csv`（実行, 生徒, 役, K, 組の数, s_u, s_d, δ_u, δ_d），`checks.csv`，`provenance.json`．**表 D1「判定の基準 δ（生徒の種類 × K）」**として E79 の節に書く．δ を半分と 2 倍にした判定は段 (d) で作る．

### 2.3 (c) 測る（評価のターゲット）

**読み込みと検算**（各評価のターゲット T と反復 r）
- `<T>.csv`・`_logp.npy`・`_pred.npy`・`_te.npy` を E77・E78 の両方から読む．ラベルと話者は `measure/data.py` の `load_any`（`data/metadata` から貼り直したラベル．取り決め 1〜3）で読み，`<T>_samples.csv` の sample_id の並びと一致することを確かめる（違えば止まる）．E77 と E78 の `_te.npy`・`_samples.csv` が同じことも確かめる
- 全行で，保存した予測から計算し直した UAR が `<T>.csv` の UAR と 1e−7 以内で一致するか，対数の確率の argmax が保存した予測と一致するかを確かめる
- `<T>.csv` のコミットが 1 つか，反復 0〜9 がそろっているか，反復ごとの行の数が同じか，同じ行が重複していないかを確かめる（I12）

**全行の点の値**（反復ごと）：UAR，6 対の d と o（ベクトルで計算し，各塊の最初の 3 行を `explore_synergy.d_o` と 1e−9 以内で照合する．外れたら止まる），位置の損 ＝ 100 × 6 対の平均 [A(d, 0) − A(d, o)]，向きの損 ＝ 100 × 6 対の平均 [A(D, 0) − A(d, 0)]．対数の確率の差は点数の差と同じなので，d と o は保存した対数の確率から直接測れる．`rows_<実行>.csv.gz` に全行を書く（選択の取りこぼしとオラクルに使う）．

**D の作り方**（設計の文書 1 節．評価のためにだけ使う）：(T, 生徒, r) ごとに，生徒の特徴（種類の実行は `load_any(T, 種類)`，世界のモダリティの生徒は融合の特徴の該当する列）を候補（反復 r のテスト以外の T の発話）の平均と標準偏差で標準化し，候補のラベルで LDA の向きを作る（クラスの中の共分散は Ledoit–Wolf．`explore_pairs.own_separation` と同じ式）．その向きで反復 r のテストの発話の 6 対の離れ方を測ったものを D とする．`own_separation` の両向きの平均と同じ値になることを実行ごとに 1 回確かめる（外れたら止まる）．D はブートストラップの抽出の前に固定する．

**向きの損が負になる対**：d が D より大きい対では A(D, 0) − A(d, 0) が負になる．負の値を 0 に切らずにそのまま平均する．切ると，none と手法の差で D が打ち消し合わなくなるからである．負の対の数を行ごとに数え（`n_neg_dir_pairs`），付録の表に出す（D7）．

**選んだ行の内訳**（`pairs_<実行>.csv.gz`．行ごとに 1 回）：6 対の d，o，D，2 感情の実際の正解率 ½[P(z > 0 | k) + P(z < 0 | l)]，模型の正解率 A(d, o)，2 つの山の分散の比，閾値に依らない分離の量 d_AUC ＝ √2 Φ⁻¹(AUC)（E77 の記録），切片だけを直した UAR．

**切片だけを直した UAR**（設計の文書の P5-3 の行を 4 クラスのまま分ける．E77 の定義の再確認の記録）：行の対数の確率に 4 つの切片を足し（1 つは 0 に固定），テストの発話で感情を釣り合わせた交差エントロピーを最小にする切片を L-BFGS で求め，その argmax の UAR を取る．向き（点数の差）は変えない．UAR − 切片だけを直した UAR を「切片で取り戻せる分」，切片だけを直した UAR の差を「向きの分」として，oursx と none の差を 2 つに分ける．点の値だけを出し，区間は作らない（6 節）．

**種**：種のある手法は，反復ごとに種の値（UAR と向きの損）を平均してから反復で平均する．3 つの分類器の合奏ではない（E78 の記録）．鍵ごとに「使える種の平均」（agg）と「種 0 だけ」（s0）の 2 つを作る．

**2 段のブートストラップ**（設計の文書 7.2 節）
1. コーパスごとに，反復 0〜9 のどれかでテストに出た話者を集める．IEMOCAP は即興と台本の両方の話者を 1 つの集合にする（`speaker_group` の名前は 2 つの群で同じ．`Ses01_F` など 10 人）
2. 各回で，話者を復元抽出し（話者の数だけ，等確率），反復 0〜9 から 10 個を復元抽出する
3. 抽出した反復のそれぞれで，抽出した話者のうちその反復のテストにいる話者の発話を，抽出の重複の数を重みにして使い，UAR と向きの損と位置の損を計算する．UAR は現れた感情で平均する．d と o は重みつきの平均と，重みを度数とみなした ddof = 1 の分散（発話を重複の数だけ並べて `d_o` を当てたのと同じ値）で計算する．発話が 2 本に満たない感情の対はその回の 6 対の平均から外す
4. 抽出した反復の値を，抽出の重複の数を重みにして平均する．抽出した話者がその反復のテストに 1 人もいない反復は平均から外す．全部の反復が外れた回は NaN にし，区間の計算から外す
5. none と手法は同じ抽出で計算し，判定の段で差を取る（対にする）．IEMOCAP の即興と台本には同じ抽出（話者と反復）を当て，判定の段で 2 つの群の値を回ごとに平均して 1 単位にする
6. 回数は 1,000．乱数は `numpy.random.default_rng([0, crc32(実行), crc32(コーパス)])` で，コーパスごとに決まる
7. 計算は話者ごとの十分統計（感情ごとの本数と正解の本数，6 対の z の和と 2 乗の和）と抽出の重みの行列の積で行う．近似ではない．重みを全部 1 にすると全テストの点の値に戻ることを，各反復で 1e−6 以内で確かめる（外れたら止まる）
8. 記録：回のうち，空の反復の抽出の割合，感情が欠けた抽出の割合，NaN の回の数（`boot_meta.csv`）．試しでは判定の段の `n_boot_valid` に有効な回の数を残す

IEMOCAP は反復 r と r ＋ 5 のテストが同じで（異なる集合は即興 5，台本 6），話者が 10 人なので，反復の段の揺れを小さく見積もり，区間は粗い．このことを本文に書く（E77 の記録）．

**診断**（`diag_<実行>.csv`）
- E77 と E78 の none のテストの対数の確率の差の最大（同じ解のはず）
- K = 0 の mapctl と none の対数の確率の差の最大（K = 0 では mapctl と none の W・b が一致するはず．E78 の記録）
- E77 と E78 の `_teachers.npz` の差の最大（第 2 波の Co-teaching に同じ教師を渡したか．評価のターゲットだけ．仮のターゲットの ref とは照合できない）
- 選んだ DANN・MME（種 0）と，同じ学習率・反復・μ の mapctl（種 0）のテストの予測が食い違う割合．none との食い違いの割合
- 選んだ Co-teaching の正規化した重なり ṽ，v，選んだ候補と落ちた候補の生徒と参照の一致の割合（E78 の `<T>_diag.csv` から，反復と種で平均）

**出力**：`rows_<実行>.csv.gz`，`pairs_<実行>.csv.gz`，`D_<実行>.csv`，`keys_<実行>.csv`（鍵 ＝ 生徒, K, 波, 方法, 設定, m_eff, 種の扱い），`boot_<実行>_<T>.npz`（回 × 鍵の UAR・向きの損・位置の損．float32），`diag_<実行>.csv`，`boot_meta.csv`，`checks.csv`，`provenance.json`．

## 7. 限界

- 評価のターゲットはすべて手法の設計の段で見ている（設計の文書 8 節）．筋の 5 の比較は探索として扱う
- MOSEI の発話一覧の 22,856 行のうち 16,134 行は話者を動画 ID で代用している．同じ人物がテストと学習側にまたがると UAR が上がる向きに働きうる．MOSEI（話者の多くが代用）と MELD（主役 6 人が発話の 83%）は，話者を単位にした区間が名目より狭く出やすい（E77 の記録）
- 対話の重なり：話者で分けても，同じ対話の別の話者の発話が学習側とテストにまたがる（IEMOCAP・MELD．目録の L7）
- 区間は話者と K 本の抜き方の揺れを含み，設定の選択の揺れを含まない．選択は仮のターゲットの反復 0〜4 で T と K ごとに 1 回だけ行い，評価の反復 0〜9 に共通だからである（設計の文書 7.2 節）
- δ は none の水準の反復の間の揺れから作り，判定は対の差に当てる．対の差の揺れは水準の揺れより小さいことが多いので，δ は大きめの基準になり，「減らした」「上回った」を出しにくく，「同じ水準」を出しやすい（設計の文書 7.2 節）
- 切片だけを直した UAR は点の値だけで，区間を作らない（回ごとに切片を解き直すと計算量が大きいため）
- 単位は 3〜6 コーパスで，コーパスを単位にした符号検定は有意になりえない場合がある（4 単位の両側の p 値の最小は 0.125）．判定は区間の規則で行う
- 学び直しが要る次の 3 つは範囲の外：MOSEI の学習側の話者の分離を直した版，C の規則を変えた版，MOSEI のラベルのしきい値の感度（E77 の記録）
