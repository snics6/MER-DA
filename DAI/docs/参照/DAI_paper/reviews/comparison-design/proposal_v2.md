## 1. この比較で確かめること

比較実験は，論文の筋の 4 と 5 を別々に確かめる．

- **筋の 4（ターゲットの価値）**：「E39 の出発点に残る向き d の誤りは，ラベル無しのターゲットのデータからは直らない」．ラベル無しのデータで向きを動かす DA・半教師あり学習の手法の**出力の d と向きの損**を，候補を使わない基準 none（K 本だけで E39 から学び直したもの）と比べて判定する．UAR で ours に届くかどうかでは判定しない
- **筋の 5（蒸留）**：「別のモダリティの分類器の答えを弱いラベルにすると，d が上がり UAR が上がる」．提案と，同じ教師を受け取った蒸留の相手，ラベル無しの手法の最良を UAR と d で比べて判定する．提案の部品を 1 つずつ外した除去実験で，得がどの部品から来るかを分ける（論文の 6「なぜ良いか」の材料）

o と d の測り方は説明資料 p2 の 2 節の手順（6 つの感情の対ごとに点数の差の平均と幅から d と o を出し，候補の全ラベルで学んだ最良の向き D と式 A で位置の損と向きの損に分け，6 対で平均する）を，全手法の K=0 と K=5 のテストの発話の出力に当てる．4 クラスの切片では 6 対の o を同時に 0 にできないので，「o の分」は 6 対の平均で定義した量であることを表の注に書く（`docs/methods.md` 9.3 節 D3）．D は評価のためにだけ使う．

## 2. 比較の表の形

相手を「使う情報」で群に分ける．「o と d のどちらを直すか」は手法の性質として書かず，計算の前の予言の列と，計算の後の測定の列に分ける．

| 群 | 使う情報 | 手法 | 計算の前の予言（o と d の変化） |
|---|---|---|---|
| 基準と参照 | — | none（主の基準），ソースのみ，ターゲットのみ，合併（S+T） | — |
| A | ラベル無しのターゲットの出力の割合 | massbal | o だけを変え，d は変えない |
| B1 | 自分の予測とラベル無しのターゲットの構造 | エントロピー最小化，自己学習，情報最大化（IM．SHOT の IM と TIM），T3A，ラベル伝播（K ≥ 1） | d を上げない（筋の 4） |
| B2 | ソースとターゲットの分布の違い | CORAL ＋ none，DANN | d を上げない（筋の 4） |
| B1＋B2 | 両方 | MME | d を上げない（筋の 4） |
| C | 別のモダリティの分類器の答え | 共訓練，共正則化，xMUDA 型の相互の模倣，温度つき蒸留 KD（ours・oursx と同じ参照の候補を渡す），ours，oursx | d を上げる（筋の 5） |

表の列は，(1) 使う情報（ソースのデータ，候補，別のモダリティの教師，K 本の別），(2) 計算の前の予言，(3) 測った o の変化と d の変化（none との差），(4) UAR の none との差，(5) 仮のターゲットで選ぶ候補の数，(6) 選択の取りこぼし（テストで選んだ最良 − 仮のターゲットで選んだ値），(7) 原論文との違い（学ぶパラメータ，学習の形，つまみの選び方），の 7 つにする．

除去実験の表（群 C の提案の内訳）は別に置く（5 節）．

## 3. 各手法の入れ方

### 3.1 共通

- 出発点は E39（中心化とラベル無しの散らばりから作る罰則の計量 ρ_M を含む）．すべての手法は E39 の W・b から出発し，出発点への罰則（C′，C_b）を同じにする
- ラベル無しのデータは ours と同じ候補（テストの話者を除く）だけを使う
- 設定は，ソースの 1 つを仮のターゲットにする手順（説明資料 p5 の 7 節）で K ごとに選ぶ．文献の既定値の版を「固定」として併記する
- K = 0, 1, 5, 10, 25．反復 0〜9

### 3.2 新しく足す手法

| 手法 | 入れ方 | 仮のターゲットで選ぶもの | 固定版 |
|---|---|---|---|
| 情報最大化（IM．Liang ほか ICML 2020 の SHOT の IM，Boudiaf ほか NeurIPS 2020 の TIM） | 候補の予測のエントロピーを小さくする項と，候補の予測の感情ごとの合計を一様に近づける項の和を，E61 のエントロピー最小化と同じ入口で目的関数に足す．W・b だけを学ぶ | 条件のエントロピーの重み α，全体の重み（m_eff と同じ候補） | TIM の既定値 α = λ = 0.1 |
| T3A（Iwasawa & Matsuo NeurIPS 2021） | E39 の予測で候補に感情を付け，エントロピーの小さい上位 M 本の特徴の平均で各感情の重みを作り直す．K ≥ 1 では K 本の特徴を各感情の支えに足す．誤差逆伝播は要らない | M | 原論文の既定値 |
| ラベル伝播（Zhou ほか 2004．Iscen ほか CVPR 2019） | 候補と K 本の特徴（E39 の座標）で k 近傍のグラフを作り，K 本のラベルを伝播させた結果を弱いラベル（硬いか，そのまま）にして E39 から学び直す．K ≥ 1 だけ | k，グラフの重み，弱いラベルの形，総重み | 原論文の既定値 |
| CORAL（Sun ほか AAAI 2016） | 前処理に置く．PCA の後か縮小推定で共分散を安定させ，ソースごとにかけてから E39 の下書きを作る．CORAL の後で E39 の C′・C_b・ρ_M を選び直す．CORAL ＋ none を群 B2 の相手にし，CORAL ＋ ours は併用の確かめとして別の表に置く | 縮小の強さか PCA の次元，C′・C_b・ρ_M | 縮小なし（単位行列を足すだけ） |
| DANN（Ganin ほか JMLR 2016） | 特徴に線形の写像 A をかけ，その上に W・b を置く（予測は W A z + b）．A は恒等の写像で，W・b は E39 で初期化する．A に ‖A − I‖² の罰則（Donahue ほか CVPR 2013 の MMDT と同じ形），W・b に E39 への罰則をかける．領域の判別器（学習のときだけ使う）は非線形でよい．主の版は仮説転移の形（K 本の損失＋出発点への罰則＋DA の項）で，ソースのデータは DA の項にだけ使う．原論文どおりの S+T の形は付録の補助の版 | 学習率，反復の回数，DA の項の重みと上げ方，‖A − I‖² の重み | 原論文の既定値 |
| MME（Saito ほか ICCV 2019） | DANN と同じ線形の写像 A と W・b．分類器はラベル無しの候補の予測のエントロピーを大きくし，写像 A は小さくする．主の版は仮説転移の形で，ソースのラベルの損失は小さい重みで足す（重みも選ぶ）．余弦類似度の分類器は使わない（原論文の表 4 は普通の線形層でも効くと報告） | 学習率，反復の回数，λ，ソースの損失の重み，‖A − I‖² の重み | λ = 0.1（原論文はターゲットの検証用ラベルで選んだと書く） |
| MME・DANN の同じ形の対照 | 同じ写像 A と W・b，同じ罰則と初期値で，DA の項の重みを 0 にして学ぶ | 同上（DA の項の重みを除く） | — |
| xMUDA 型の相互の模倣（Jaritz ほか CVPR 2020） | 音声・顔・言葉の線形の頭に，それぞれ模倣の線形の頭を足し，候補の上で相手のモダリティの頭の予測との KL を罰にする．出発点は各モダリティの E39 の頭 | 罰の重み | 原論文の既定値 |

- MME・DANN は初期化の種を 3 つで回し，種の平均を主の値にし，種の間の幅を付録に書く
- MME の「写像を置かずに分類器だけを動かす案」（第 1 版）は削った

### 3.3 入れ方を変える手法

- **KD**：ours・oursx と同じ参照の候補（融合の出発点，単モダリティの確率の積，oursx の参照 (a)・(b)）を渡し，温度 T ∈ {2, 4} で群 C の相手にする
- **同じ教師を渡した GD（T=1）と硬い疑似ラベル**：oursx の候補の部分集合なので，相手ではなく除去実験の行（「oursx から重みの付け方の選択を外した版」）として示す（5 節）
- **中心化**：E39 に含まれるので相手から外す．筋の 2 の確かめとして，除去実験の表に「中心化を外した E39」を置く
- **Saerens の EM**：ラベルの割合だけがずれるとき，UAR を最大にする判定の規則はターゲットの割合に依らないので，Saerens の補正は UAR を上げる理由を持たない．主表から外し，付録の確かめに置く

### 3.4 回さない手法と，本文に書く理由

| 手法 | 本文に書く理由 |
|---|---|
| 話者ごとの正規化（Schuller ほか 2010，Busso ほか 2013） | テストの話者のラベル無しの発話を使う条件になり，候補からテストの話者を除く今の設定と使う情報が違う．中心化がコーパスの単位であることを書く |
| データ拡張に頼る SSDA（APE，CDAC，AdaMatch，FixMatch 型） | 発話単位の凍結した特徴では弱い変換と強い変換を作れない |
| エンコーダを学ぶマルチモーダル DA（MM-SADA，Amanda） | 凍結した特徴の設定には移せない |
| 双方向のモダリティ間の蒸留（C2KD） | 深い網どうしの双方向の蒸留で，固定した教師と線形の生徒の形に合わない |
| 部分空間の合わせ込み（SA），線形の最適輸送（LinOT） | SKADA-Bench（固定した特徴の上の浅い DA 20 手法の比較）で単純な線形の写像が頑健だったことを引き，その代表として CORAL を選んだと書く |
| エンコーダの微調整 | 主張を凍結した特徴に限る．E63（LoRA）を付録に置く |

同じ仮のターゲットの手順で，oursx から部品を 1 つずつ外した版を回す．AVT の世界の 4 つの生徒と AV の世界の 3 つの生徒で，K = 0 と 5．

| 行 | 外す部品 |
|---|---|
| oursx | — |
| 参照を (a) だけに固定 | 2 段目の参照 (b) |
| 重みの付け方を ① 釣り合いだけに固定 | 重みの付け方の選択 |
| 重みの付け方を ② そのままだけに固定（＝同じ教師を渡した GD，T=1） | 釣り合いと選択 |

## 7. 統計と判定の基準（計算の前に決める）

### 7.1 主の比較

| 番号 | 比較 | 量 | 設定 |
|---|---|---|---|
| P4-1〜P4-8 | 群 A・B の各手法（massbal，エントロピー最小化，自己学習，IM，T3A，ラベル伝播，CORAL ＋ none，DANN，MME．massbal を除く 8 つ）と none | 向きの損の差（none − 手法．正なら向きの損を減らした） | 単モダリティの A・V・T，K = 0 と 5 |
| P5-1 | oursx と，同じ参照を渡した KD の選択 | UAR の差 | 筋の 5 の主の設定，K = 0 と 5 |
| P5-2 | oursx と，群 B の手法のうち仮のターゲットで最良のもの | UAR の差 | 同上 |
| P5-3 | oursx と none | d の差 | 同上 |

- 分析の単位はターゲット（コーパス）．IEMOCAP の即興と台本は同じ話者なので 1 単位にまとめた値も示す
- 主の比較の族ごとに Holm の補正をかける．ただし単位が 4〜7 なので，ターゲットの単位の符号検定は有意になりえない場合がある（4 単位の両側の符号検定の p 値の最小は 0.125）．そのため，ターゲットごとの値と，話者を単位にしたブートストラップの区間を主に示し，「上回る」はターゲットごとの内訳（上回ったターゲットの数）を添えて書く

### 7.2 判定の基準（数は関門 1 で確かめてから固める）

| 結果 | 判定 |
|---|---|
| 群 B のある手法が，ある特徴の種類で過半のターゲットの向きの損を 1.0 ポイント以上減らす（K = 0 か 5） | 筋の 4 の「ラベル無しのデータからは直らない」を，「ラベルを付ける発話の選び方では直らない」に狭める．直した向きの量を書く |
| 群 B の手法が一部のターゲットで向きの損を 1.0 ポイント以上減らし，別のターゲットで増やす | 筋の 4 を「ラベル無しの情報で向きが直るかどうかは，ターゲットのラベル無しには見分けられない」と書く．エントロピー最小化の IEMOCAP の得（説明資料 p5 の 8 節）をこの形で確かめる |
| 群 B の UAR の得が，ほぼ o の変化だけで説明できる（d の差が ±1% 以内） | 筋の 4 の証拠に加える |
| 除去実験で ③ だけに固定した版が oursx と 0.3 ポイント以内 | 得を重みの付け方ではなく教師の作り方に帰す |
| oursx の d が none から上がらない（+1% 未満）のに UAR が上がる | 筋の 5 の「別のモダリティの答えが向きを直す」を書き直し，ours を o の補正として書く |
| IM，CORAL ＋ none，DANN，MME のどれかが過半のターゲットで oursx と 0.3 ポイント以内 | 別のモダリティの教師が無くても同じ水準に届くと書き，ours の利点をその相手が損をするターゲットでの安定さに限る |
| CORAL ＋ ours が ours を上回る | 併用の効果として探索の扱いで書く |

## 8. 限界として本文に書くこと

- 評価のターゲットはすべて，手法（ours・oursx と E61 の相手の選び方）の設計の段で見ている（`docs/seen-data.md` の 1 節）．oursx は基本版の結果を見てから足した版である．この比較の値は「設計に使ったターゲットでの値」であり，見ていないデータ（MSP-IMPROV など．取得していない）での確かめは無い
- 第 2 のエンコーダの再現（E62）は同じターゲットと同じ話者なので，見ていないデータでの確かめにはならない
- 主張は凍結したエンコーダの特徴の上の線形の分類器に限る
