## 1. 問い

## 3. 量の定義

### 3.1 取り除き方 τ（候補で標準化した特徴に当てる）

- **raw**：そのまま（DAI-8 と同じ）．
- **gc**（グループの平均を引く）：
  - 候補の発話は候補のグループの平均を，テストの発話はテストのグループの平均を引く．テストのグループの平均は，テストのラベル無しの発話から作る．テストのラベルは使わないが，テストの話者の印を使う．
  - 3 本未満のグループの発話は，その集合の全体の平均を引く．当たる発話の割合（MOSEI で約 5%，MELD で約 1.6%）を候補とテストで残す（e5）．テストの側では，テストの全体の平均も引くことになるので，gc の判定はテストの集合の感情の割合に依る．AFEW の分割 0 では，gc はほぼ「テストの全体の平均を引く」操作になる（記録 5）．
  - 最後に候補の標準偏差で割り直し，同じ値をテストにも当てる．
- **nap10，nap50**（グループの間の向きを消す）：
  - 候補のグループの平均（重みつき）の散らばり S_g の上位 r 個の固有ベクトル V（r = 10，50）を求める．S_g の階数はグループの数 − 1 以下なので，消す数は min(r, 階数) にし，実際に消した数を残す（gate-probe の 1．IEMOCAP 即興の候補の話者は 8 人なので，消すのは 7 個以下になり，nap10 と nap50 は同じ操作になる）．消した向きの固有値（上位 60 個）と，消した向き（nap）・残した向き（pca）の 2 乗の重みのモダリティごとの割合を単位ごとに残す（e4）．
  - 候補の平均を引いた後，候補とテストの両方に x ← x − V(Vᵀx) を当てる．標準化し直さない．割り直すと，消した向きのグループの散らばりが一部戻るためである（gate-code の第 1 回の 1．AFEW の 1 単位で，消した 10 本の向きに 0.251 が戻った）．このため nap の後の各次元の分散は 1 より少し小さく，縮める先 I は少し強めに働く．gc と pca は標準化し直すので，縮める先 I の効き方が τ の間で少し違う．gc と nap を並べて優劣を書くときは，この違いを添える（dai-review-affect の第 2 回の f2）．
  - テストの話者の印は使わない．
- **pca64，pca256**（次元を落とす）：
  - 候補の共分散の上位 p 個の主成分（p = 64，256）に写し，各成分を候補の標準偏差で割る．この割り算は白色化を含むので，A = I になり，縮める先 I の意味も変わる．pca の得を，本数と次元の比の効果とだけ読まない（記録 3）．
  - テストには同じ写像を当てる．

### 3.2 方法（DAI-8 の関数をそのまま使う．`DAI/exp/dai8_probe.py` の `lda_from_R`，`em_fit`，`_top3` ほか）

- 縮める強さは α = 0.5 とする．縮める先は I で，各取り除き方の後で候補で標準化し直すので，各次元の分散は 1 である．
- 判定は等しい事前で行う．
- **LDA_O^τ**：候補の全ラベルで推定する．
- **LDA_K^τ**：K 本だけで推定する（K ∈ {1, 5, 10, 25}）．
- **EM_fromK^τ**：初期の重みを LDA_K^τ の確率 softmax(δ_K) にし，K 本を固定して β = 0 で回す．t = 10 の解（規則で数える）と，収束（r の変化が 1e-4 未満か 100 回）の解を残す．
- **EM_truth^τ，EM_rand^τ**：DAI-8 と同じ診断である．K 本を固定せず β = 0 で，候補の正解か，同じ割合ででたらめに並べ替えたラベル（種 0）から，収束まで回す．
- **Q3 の量**：DAI-8 の `_top3` と `_top3_resid`．上位 3 つの固有値の和から，並べ替え 5 回の帰無の平均を引いた値で比べる．
  - 感情：top3ex_emo
  - グループの感情で説明されない分：top3ex_grp_xe
  - 対話の感情で説明されない分：top3ex_dlg_xe
  - 帰無の最大も残す．
  - (c, f) ごとに，r = 0 の単位で 1 回だけ計算する．

## 4. 判定の規則（計算の前に固定）

- **区間**：`dai1_stats.effect_stats` を (f, r) を単位にして使う．実効の塊の数が 20 未満のコーパスは jackknife と t，MOSEI は塊の引き直しである．IEMOCAP の区間は 5 つのセッションの揺れしか表さない．
- **下限**：UAR の差は 0.5 ポイント．K ∈ {1, 5, 10, 25} のうち「区間の下端 > 0 かつ点推定 ≥ 0.5」の K を数える．
- **S1（Q1 の主）**：τ ごとに，EM_fromK^τ − LDA_K^τ の条件を満たす K が 3 つ以上のコーパスを数える．
  - 満たしたとき：「τ のもとで，ラベル無しの発話は K 本だけの LDA を上回った」と書く．
  - 区間の上端が 0 より下の K が 3 つ以上のとき：「τ のもとでも，ラベル無しの発話はガウスの判別を悪くした」と書く．
  - raw の値は DAI-8 の R3 と同じ問いである．
- **S2（Q2）**：τ ごとに，DAI-8 の R9 と同じ 3 段で読み分ける．
  1. EM_truth^τ − LDA_O^τ のテストの UAR の点推定が −2 以下なら (b)．
  2. EM_rand^τ が初期のラベルを 0.9 以上保つか，EM_truth^τ との保った割合の差が 0.2 未満なら (c)．
  3. どちらでもなければ (a)．
- **予想の書き方（計算の前に固定．gate-probe の 2）**：gc か nap10 か nap50 で，次の 3 つがすべて成り立つコーパスでは，「感情でないまとまりの成分を除くと，EM の尤度の頂上は感情の割り当てに近づいた」と書く．
  - raw の読みが (b) で，τ の読みが (a) である（(c) は EM が動かないだけで差が 0 に近づくので除く．dai-review-affect の E1）．
  - EM_truth^τ − LDA_O^τ が raw の同じ量より 2 ポイント以上大きい（点推定）．
  - 同じ差の差（(EM_truth^τ − LDA_O^τ) − (EM_truth^raw − LDA_O^raw)）の分割ごとの平均が，5 つの分割のうち 4 つ以上で正である．
  - EM_truth^τ − EM_truth^raw の区間の下端 > 0 かつ点推定 ≥ 2 ポイント（EM_truth そのものが良くなったこと．dai-review-ml の M1，dai-review-affect の E1．取り除き方が感情の違いまで消すと，基準の LDA_O^τ が下がって差だけが縮むため．人工データでは，感情でないまとまりが無くても gc で差が 7〜29 ポイント縮んだ）．
  - LDA_O^τ − LDA_O^raw（S5）が −2 ポイントより大きい．満たさないコーパスでは予想の文を書かず，「差の縮みは感情の情報が減ったことと分けられない」と書く．
  - 文には，どの取り除き方で満たしたかと，3 つのうち何個で満たしたかを添える．nap10 と nap50 がそのコーパスの全単位で同じ数の向きを消したとき（IEMOCAP 即興など）は，同じ操作なので 1 つとして数える（記録 2）．3 つの取り除き方のどれかで満たせばよい形なので，偶然に満たす見込みが上がると添える．
  - どのコーパスでも成り立たなければ，「取り除いても頂上は近づかなかった」と書く．
- **S3（記述）**：EM_fromK^τ − LDA_K^raw（取り除きとラベル無しの発話を合わせた得）と，LDA_K^τ − LDA_K^raw（取り除きそのものの得）を並べる．
- **S0（EM の仮定の表．DAI-8 の 3.3 節と同じ．記録 6）**：τ ごとに，n/d，t = 10 で動いた割合（EM_fromK の最後の割り当てと初期の割り当てが違う割合），t = 10 で変化が 0.01 以上の単位の数を並べる．t = 10 で動いた割合が 0.05 未満の (c, τ) では，S1 を「EM は初期値からほとんど動かなかった」と書き，得や損とは書かない（gate-probe の第 2 回の記録 1）．
- **S4（Q3．記述）**：τ ごとに，top3ex_emo と max(top3ex_grp_xe, top3ex_dlg_xe) のどちらが大きいかを書く．gc と nap は作りの上でグループの成分を消すので，その後のグループの量は小さく出る．S4 は対話の量と感情の量で読み，取り除きで感情の量（top3ex_emo）がどれだけ減ったかも並べる（記録 4）．「感情でないまとまりが分かれやすい」と書くのは，DAI-8 の R5 と同じく，5 つの分割のうち 3 つ以上で帰無の最大を超え，帰無を引いた値が感情以上のときだけである．
- **S5（Q4）**：LDA_O^τ − LDA_O^raw を並べる．点推定が −2 ポイント以下のコーパスでは，「τ は感情の違いも消した」と書く（E1）．Q3 の top3ex_emo の raw に対する比（top3ex_emo^τ ÷ top3ex_emo^raw）も並べる（dai-review-ml の m1）．gc と nap のグループの Q3 の値は作りの上で小さくなるので，S4 の比べに使わない（e3）．
- **感情ごとの主張はしない**（e6）．
- **向きの注**：
  - gc はテストの話者の印とラベル無しの発話を使う．このため S1〜S3 の gc の値は，テストの話者が分かる場面の値である．nap と pca はテストの話者の印を使わない．
  - K = 1 の LDA_K は感情ごとの発話が 1 本なので，最も近い平均の規則と同じ判定になる．
- どの規則も，満たしたかどうかによらず全部のセルの値と区間を表に出す．満たさなかった規則は「満たさなかった」と書く．

## 7. 見たデータと漏れ

- 使うのは仮のターゲットの回の保存と特徴だけである．評価のターゲット T のデータは単位に入らない．
- EM と LDA の推定に使うのは候補だけである．テストは判定するだけである．gc ではテストのラベル無しの発話のグループの平均を使う（3.1 節）．

## 8. 範囲の外と限界

- AVT の空間だけを扱う．単独の空間は扱わない．
- none・joint の頭は使わない．取り除いた空間で頭を学び直さないためである．比べの相手は K 本だけの LDA である．
- MOSEI と AFEW ではグループの中の感情の割合が偏るので，gc と nap はグループの間の感情の違いも一緒に消しうる．
- gc で 3 本未満のグループの発話（全体の平均だけを引く）は，MOSEI で 5.4%，MELD で 1.1〜1.6%，AFEW で 0.2〜1.9% である（gate-code の第 1 回の記録）．
- MOSEI の漏れ，IEMOCAP の筋書きの共有は DAI-8 と同じく残る．
- nap に，同じ本数のでたらめな向きを消す対照は置かない（dai-review-ml の m2．任意の指摘で，時間の都合で見送った）．nap の得をグループの向きを消したことによると書くときは，この対照が無いと添える．
- 結果は手法の固定ではない．得が出た形は，改めて設計して関門を通す．
