# 実験 10 の下調べ（DAI-10）：ラベル無しの発話を計量にだけ使うと，K 本のガウスの判別は良くなるか．EM の得を計量の分と割り当ての分に分ける（2026-11-08．第 1 版）

## 0. 位置づけと，案の出どころの申告

- **研究者の指示（2026-11-08 未明）**：「もう寝るのですが朝まで、仮に次のトライがダメそうでもそこから数理的知見を引き出して、先行研究を参照してトライを継続してして欲しい」「私の許可がなくても進めて欲しい」．
- **前の試しとの関係**：DAI-8（`DAI/docs/実験8_下調べ_設計.md`）と DAI-9（`DAI/docs/実験9_下調べ_設計.md`）の次の試しである．**この設計は DAI-8 と DAI-9 の値を見た後に書いた**（結果の文の下書き `DAI/docs/実験8・9_下調べ_結果の文の下書き_2026-11-08.md`）．見た値のうち，この設計の形を決めたのは次の 3 つである．
  - DAI-8 の R9：IEMOCAP，MELD，MOSEI では，候補の正解から始めた EM が，尤度の高い感情でない割り当てへ移った（テストの UAR で全ラベルの LDA より 2.8〜18.1 ポイント低い）．
  - DAI-8 の 0 回目（none[K] の予測を重みにして 1 回だけ推定した版）− none[K] は AVT で −0.4〜4.2 ポイントで，回を重ねると下がった．
  - DAI-9：感情でないまとまりの成分を先に除いても，EM は感情の割り当てに近づかなかった．
- **数理の筋**：特徴を候補で標準化（平均 0）し，T = XᵀX/N（候補の全部．ラベルに依らない），A = (1 − α)T + αI，感情の平均を並べた d × 4 の行列を M，割合の対角行列を Π とする．共通の共分散 Σ = (1 − α)S + αI（S は群内の散らばり）は Σ = A − (1 − α)MΠMᵀ と書け，Woodbury の恒等式から
  ```
  Σ⁻¹M = A⁻¹MC，  C = [I − (1 − α)ΠMᵀA⁻¹M]⁻¹
  ```
  である（DAI-8 の設計 0 節）．EM の判別は「ラベルに依らない計量 A⁻¹」と「割り当てで決まる M，Π」の 2 つでできている．DAI-8・DAI-9 は M，Π を割り当てで推定し直す部分が感情でない分け方へ移ることを示した．A⁻¹ の部分だけを使う版は，割り当てを回さないので，塊の仮定（ラベル無しのデータのまとまりがクラスに沿うこと）を要らない．
- **出どころ（先行研究．差分は prior-work-diff の調べ `research_notes/先行研究_モーメントだけを使う半教師ありLDA_2026-11-08/report.md` に置き，届いたら写す）**：
  - Krijthe & Loog 2014（ICPR）の表 II では，EM の LDA（EMLDA）は 10 データセットのうち 8 で教師ありの LDA より悪く（Ionosphere 0.21 → 0.57），全体の平均と共分散の制約だけを使う LDA（MCLDA）は誤り率で最も良かった（Ionosphere 0.18，SPECT 0.25）．`research_notes/先行研究_半教師ありのガウス判別_2026-11-08/report.md` 3.1 節．
  - Loog 2016（MCPL）の 6.2 節は，尤度の大きな改善を「共分散を全部の標本で推定できたこと」によると読む．
- **試した手法との違い**：DAI-8 の LDA_K は Σ を K 本だけから作るので，K ≤ 25 では 2,304 次元の大部分の方向で Σ = α·I になる．DAI-8 の EM は計量 A⁻¹ と割り当ての両方を変える．この試しは計量だけを変える．
- **探索であること**：仮のターゲットの回のラベルは，評価に使う 4 コーパスと同じ発話・同じラベルである．記述と，計算の前に固定した数え上げの規則（4 節）で書く．

## 1. 問い

- **Q1（主：計量の分）**：K 本のラベルで感情の平均を作り，共分散の代わりにラベル無しの候補の全体の散らばりから作る A を使う LDA（LDA_T）は，K 本だけの LDA（LDA_K）を上回るか．
- **Q2（割り当ての分）**：EM_fromK − LDA_T は正か負か．EM_fromK − LDA_K =（LDA_T − LDA_K）+（EM_fromK − LDA_T）と分ける．
- **Q3（識別型の頭との比べ）**：LDA_T は K 本だけの融合の頭 none[K] と，提案 joint を上回るか．
- **Q4（記述）**：単独の空間（A，V，T），縮める強さ α の格子，全体の平均の制約を足した版，群内の共分散の制約の版（MCLDA の形），AVT のブロック対角の A．

## 2. データと単位

- DAI-8 と同じ 120 単位（評価のターゲット T 4 × 仮のターゲット c 3 × 分割 f 5 × 種 r 2）を `dai1.Unit` で読む．取り決め 1〜6 は `measure/data.py` の `load_group` が引き受ける．並びとラベルの照合，`pseudo_commit` の確かめも DAI-8 と同じである．
- 比べる相手の判定は，DAI-8 の保存 `results/dai8_probe/rows/<単位>.npz` から読む（学び直さない）．テストの sample_id の並びが DAI-8 の保存と同じことを単位ごとに確かめ，違えば止める．
- 空間は A（1,024 次元），V（512），T（768），AVT（2,304）の 4 つ．規則は AVT で数える．
- K ∈ {1, 5, 10, 25}．K = 0 は感情の平均を作れないので扱わない．

## 3. 量の定義

- 特徴は候補の統計で標準化してある（DAI-8 と同じ）．判定は等しい事前で，δ_k(x) = μ_kᵀ Σ⁻¹ x − ½ μ_kᵀ Σ⁻¹ μ_k の argmax である．
- **LDA_T^α（計量だけ）**：μ_k は K 本の感情 k の発話の平均，Σ = A = (1 − α)T + αI，T = XᵀX/N（候補の全部）．
- **LDA_Tc^α（全体の平均の制約を足す．記述）**：μ_k から 4 つの平均の平均を引き，全体の平均（候補の標準化で 0）に合わせる．等しい事前のもとで，この移動は判定の切片だけを変える．
- **LDA_W^α（群内の共分散の制約．記述．MCLDA の形）**：prior-work-diff の調べで MCLDA の式を原文で確かめてから定義する（未定）．
- **LDA_Tblk^α（記述）**：AVT で，T のモダリティをまたぐブロックを 0 にした A を使う．ラベル無しの発話のモダリティをまたぐ共分散が判別に効くかを見る．
- **規則で数える点**：α = 0.5（DAI-8 と同じ．計算の前に固定）．格子 α ∈ {0.1, 0.5, 0.9} は記述．
- **比べる相手（DAI-8 の保存から読む）**：LDA_K^0.5，EM_fromK^0.5（β = 0，10 回），EM（固定の点 α = 0.5，β = 1，t = 10），none[K]，joint，LDA_O^0.5（全ラベル），oracle．

## 4. 判定の規則（計算の前に固定）

- **区間**：DAI-8 と同じ `dai1_stats.effect_stats` を，(f, r) を単位にし，3 つの T の数を平均して使う．実効の塊の数が 20 未満（AFEW，IEMOCAP，MELD）は塊の jackknife と種の項に t の区間，MOSEI は塊の引き直し 2,000 回である．IEMOCAP の区間は 5 つのセッションの揺れしか表さない．
- **下限**：UAR の差 0.5 ポイント．K ∈ {1, 5, 10, 25} のうち「区間の下端 > 0 かつ点推定 ≥ 0.5」の K を数える．K は同じテストと候補を共有するので，3 つ以上という数え方は 3 回の独立な確かめではない．
- **G1（Q1 の主）**：AVT で LDA_T − LDA_K の条件を満たす K が 3 つ以上のコーパスを「ラベル無しの発話の全体の散らばりを計量にすると，K 本だけの LDA を上回った」と書く．区間の上端が 0 より下の K が 3 つ以上なら「下回った」と書く．
- **G2（Q2）**：AVT で EM_fromK − LDA_T．上端が 0 より下の K が 3 つ以上のコーパスでは「割り当てを回すと，計量だけの版より悪くなった」，条件を満たす K が 3 つ以上なら「割り当てを回す分が得をした」と書く．どちらでもなければ「割り当てを回す分の得も損も，この基準では言えない」と書く．分け方 EM_fromK − LDA_K =（LDA_T − LDA_K）+（EM_fromK − LDA_T）の 3 つの点推定を K ごとに並べる．
- **G3（Q3）**：AVT で LDA_T − none[K] と LDA_T − joint．条件を満たす K が 3 つ以上なら「上回った」，上端が 0 より下の K が 3 つ以上なら「下回った」と書く．none[K] と joint は c のテストの UAR で選んだ点なので，この差は LDA_T に不利な向きに寄る．
- **向きの注**：LDA_T はラベル無しの候補を全部使うので，IEMOCAP 即興の筋書きの共有と MOSEI の同じ人物の別の動画が候補に残る漏れが，LDA_T の側に入る（DAI-8 の R1・R3 と同じ）．
- どの規則も，満たしたかどうかによらず全部のセルの値と区間を表に出す．満たさなかった規則は「満たさなかった」と書く．
