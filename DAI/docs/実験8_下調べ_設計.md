## 3. 量の定義

### 3.1 近傍と散らばり（Q1．主）

- 候補の発話の間で，標準化した特徴のコサイン類似度の k = 10 個の近傍（自分を除く）を取る．
- 感情の一致の割合（感情で平均．でたらめなら 0.25），グループの一致の割合，対話の一致の割合を出す．グループと対話のでたらめの水準は Σ_g p_g² である．IEMOCAP は筋書きの一致も出す．
- 同じ対話を外した近傍の感情の一致：同じ対話の発話を近傍の候補から外して探す．でたらめの水準は，外した後の候補での自分の感情の割合を発話ごとに求めて感情で平均する（dai-review-affect の A2）．
- 伸び (a − a₀)/(1 − a₀) で並べる．
- 散らばりの割合 tr(S_b)/tr(S_t) と，白色化した計量（A = 0.5·T + 0.5·I）での分かれやすさ tr(A⁻¹S_b) を，感情・グループ・対話のラベルで出す（記述）．でたらめの水準は，同じ大きさの組に並べ替えたラベル（種 0，1 回）での値である．
- **主の比べ（gate-probe の第 2 回の 1）**：4 成分の EM が判定に使える向きは 3 つなので，S_b v = λAv の上位 3 つの固有値の和を，感情・グループ・対話のラベルで出す．並べ替え 5 回の帰無の平均を引いた値（top3ex）で比べる．組の数の違うラベルどうしでも，引いた値は同じ単位で比べられる．
- Q1 は (c, f) ごとに 1 回だけ計算する（T が辞書順で最初で r = 0 の単位．候補と標準化が T と r に依らないため）．
- **対話の印（dai-review-affect の第 2 回の B1）**：splits と `dai_data` の dialogue 列は MELD 以外で空なので，台本で作る．
  - IEMOCAP：sample_id の最後の _ より前（80 対話）
  - MOSEI：同じく動画 ID（3,147）
  - AFEW：発話一覧の movie_title（92 作品）
  - MELD：dialogue 列（1,414）
  - 印に空があるか 1 種類しか無いとき，外した後の候補が k 本に足りないときは止める．
- **同じ筋書きを外した近傍（IEMOCAP．B2）**：同じ筋書きの発話を近傍の候補から外した感情の一致を，発話ごとのでたらめの水準とともに出す．
- **流れた先（gate-probe の第 2 回の 2）**：AVT で，none[K]，固定の点の収束の版，EM_truth，EM_rand の最後の割り当て（候補の全部．保存する）と，感情・グループ・対話の印との調整済み相互情報量（AMI．偶然の分を引く）を出す．正規化は 2 つのエントロピーの小さい方（`average_method="min"`．4 つに分ける EM の割り当ての側）にする．算術平均で正規化すると，組の数の多いラベル（MOSEI のグループは約 2,090）との AMI が作りの上で縮み，順が逆になりうる（gate-probe の第 3 回の 1）．
- グループの平均を引いた特徴での感情の近傍の一致と散らばりの割合も出す．グループの印は候補の発話の付帯情報で，配備の場面で使えるかは別の問いである（8 節）．MOSEI と AFEW ではグループの中の感情の割合が偏る（同じ塊の 2 本が同じ感情である確率は MOSEI 0.499（無作為 0.361），AFEW 0.304（同 0.251））ので，平均を引くとグループの間の感情の違いも一緒に消えると書く（dai-review-affect の b1）．MOSEI と AFEW ではグループと対話が同じか入れ子になるので，2 つの一致を別の原因の量として読まない（b3）．

### 3.2 ガウスの判別（Q2〜Q4）

- 共通の共分散のガウスの判別：
  ```
  δ_k(x) = μ_kᵀ Σ⁻¹ x − ½ μ_kᵀ Σ⁻¹ μ_k       （判定は argmax_k δ_k．感情の事前は等しくする）
  Σ = (1 − α)·S + α·I                         （S は感情の平均を引いた重みつきの散らばり，α は縮める強さ）
  ```
  - 縮める先は I にする．特徴は候補で標準化してあるので，各次元の全体の分散は 1 である．
  - K = 1 の LDA_K では S が 0 になり，tr S / d に縮めると Σ が特異になる．
  - 計算では，各行の重みの和が 1 なので Σ_i Σ_k r_ik x_i x_iᵀ = XᵀX が回によらず，S = (XᵀX − Σ_k n_k μ_k μ_kᵀ)/N で求める．
  - 感情の事前を等しくするのは，UAR を最大にする判定がクラスの割合によらないためである（Menon ほか 2021）．
- **LDA_oracle**：候補の全ラベルで μ と S を推定する．
- **LDA_K**：K 本のラベルだけで推定する（K ≥ 1）．K ≤ 10 では，2,304 次元の大部分の方向で Σ = α·I になる．K = 1 は最も近い平均の規則と同じ判定になる（gate-probe の記録 D4）．
- **EM**：
  - 初期値：ラベル無しの候補の発話の重み r_ik を，none[K] の頭の確率 q_ik にする（K = 0 は出発点＝ソースの平均の頭）．K 本は正解の one-hot に固定する．
  - M 段：
    ```
    n_k = Σ_{i∈L} 1[y_i = k] + Σ_{i∈U} r_ik，  μ_k = (Σ_L 1[y_i = k] x_i + Σ_U r_ik x_i) / n_k
    S = (XᵀX − Σ_k n_k μ_k μ_kᵀ) / Σ_k n_k，     π_k = n_k / Σ n_k
    ```
  - E 段：
    ```
    log r_ik = β·log q_ik + log π_k + δ_k(x_i) + 定数     （k について softmax）
    ```
    β は none[K] の予測を事前として残す強さで，β = 0 は素の EM である．E 段の π_k は推定した割合で，テストの判定は等しい事前で行う．
  - 回 t の分類器は，t 回の E 段の後の M 段の解とする．t = 0 は初期の重みで 1 回だけ解いた版である（gate-code の 4）．
  - **規則で数える点**：α = 0.5，β = 1，t = 10．計算の前に固定した．
  - **収束まで回す版（gate-code の 1）**：同じ点を，r の変化が 1e-4 未満になるか 100 回まで回し，t = 0，10，30，最後のテストの判定を残す．規則は t = 10 で数え，収束の版は記述とする．t < 10 で収束したときは，収束した解を t = 10 の解として使う．
- **格子（記述．全部の点を表に出す）**：α ∈ {0.1, 0.5, 0.9}，β ∈ {0, 1}，t = 10．
- **EM_fromK（gate-probe の 2）**：K ≥ 1 で，初期の重みを LDA_K（α = 0.5）の確率 softmax(δ_K) にし，β = 0 で回す．none[K] を使わないので，ソースの情報と選んだ引き戻しが入らない．
- **EM_T（選ばない引き戻し．gate-code の 7）**：K ≥ 1 で，引き戻しを計算の前に格子から固定した点 (C′, C_b) = (0.01, 1.0) にした none の頭（noneT）から，固定の点で回す．この点は，格子の C′ の 7 点の中ほどの値として，結果を見る前に決めた．固定のファイルの 112 個の選んだ点のうち，この点が選ばれたのは 8 個で，最も多いのは (0.003, 1.0) の 45 個である（dai-review-ml の第 2 回の記録）．
- **EM_μ（gate-probe の 5）**：固定の点と同じ初期値で，最初の M 段の Σ を固定し，μ と π だけを推定し直す．EM_μ の向きは A⁻¹M_t と A⁻¹M₀ が張る空間に入り，EM の向きの空間とは違う（gate-probe の第 2 回の 3，dai-review-ml の第 2 回）．
- **流れた理由を分ける診断の EM（dai-review-ml の M1）**：各空間で，K 本を固定せず β = 0 で，次の 2 つの初期値から回す（収束まで．t = 10 も残す）．候補のラベルだけを使い，テストのラベルは使わない．
  - EM_truth：候補の正解の one-hot から始める．
  - EM_rand：候補の正解を同じ割合のままでたらめに並べ替えたラベル（種 0）から始める．
  - 残す量：最後の r の候補の上の UAR，初期のラベルを保った割合．
- **AVT のブロック対角の版（Q4）**：S のモダリティをまたぐブロックを 0 にしてから縮める．
  - LDA_oracle と EM（固定の点．収束の版も）で出す．
  - I に縮めるので，LDA_oracle のブロック対角の版の判定は，A・V・T の各空間の δ の和の argmax と一致する．
  - EM のブロック対角の版は，3 つの空間で共通の r を使って同時に回すので，各空間で別々に回した EM とは一致しない（gate-probe の記録 D1）．
- **比べる頭**（保存から読む．学び直さない）：
  - none[K]：`dai1.none_wb` と同じ選んだ引き戻しの解．
  - joint：提案．固定のファイルの `<m>|<K>|joint|<主の版>`．
  - ttfused（gate-code の 8）：AVT の none[K] の確率を疑似ラベルにして ρ = 1，a = 1 で学び直した頭．`p3` の `method=tt, teacher=fused_AVT`．EM と同じ予測を受け取る識別型の相手である．
  - oracle：`all|C′|C_b`．K = 25 の引き戻し．DAI-7 と同じ．
  - AVT は融合の頭である．

### 3.3 診断と EM の仮定の表（記述）

- 候補のラベル無しの発話の上の UAR と感情ごとの再現率（候補の正解で測る．学習には使わない）を，none[K] と EM について回ごとに残す．感情ごとの主張はしない（dai-review-affect の a3）．
- EM の推定した割合 π と候補の真の割合の差．EM の判定が none[K] の判定と違う割合（テスト）．
- **EM の仮定の表（gate-probe の 3．基準は計算の前に固定）**：
  | 量 | 定義 | 基準と書き方 |
  |---|---|---|
  | n/d | 候補の本数 ÷ 空間の次元 | 1 未満の (c, 空間) では，共分散の推定が I に強く寄ると書く |
  | 動いた割合 | ラベル無しの候補の発話のうち，最後の r の argmax が初期値 q の argmax と違う割合 | 固定の点の AVT で，K ∈ {1, 5, 10, 25} の平均が 0.05 未満のコーパスでは，R1 の失敗を「EM が初期値からほとんど動かなかった」と書き，「EM が得をしない」とは書かない |
  | 項の大きさの比 | 1 回目の E 段で，ラベル無しの発話ごとの max_k δ_k − min_k δ_k の中央値 ÷ max_k log q_k − min_k log q_k の中央値 | 10 を超える (c, 空間) では，β = 0 と β = 1 の区別がほとんど無いと書く |
  | β の項の効き（dai-review-ml の m1） | 最後の E 段で，β·log q の項を外すと argmax が変わるラベル無しの発話の割合 | 記述．項の大きさの比より優先して β の効きの説明に使う |
  | 少ない本数の感情への不利（m3） | tr(Σ⁻¹S) と n_k．平均の推定の誤差の項 ½·tr(Σ⁻¹S)/n_k | 記述．R3 と R4 の読み方に添える |
  | r のエントロピー | 最後の r の平均のエントロピー（nat．最大 log 4 ≈ 1.386） | 記述 |
  | 収束 | 規則の回（t = 10）の r の変化 | 0.01 未満を「収束した」とし，満たさない単位の数を書く．収束の版の回の数も書く |

## 4. 判定の規則（計算の前に固定）

- **区間**：実験 1・5 と同じ `dai1_stats.effect_stats` を使う．
  - K 本の抜き方は T に依らない（`dai_data.k_orders` の乱数は (c, f, r) で決まる）ので，(f, r) を単位にし，同じ (f, r) の 3 つの T の塊ごとの正解の数と件数を足す（gate-probe の 1）．
  - こうして作った UAR は 3 つの T の UAR の平均と一致する．種の項は分割ごとの 2 つの種で作り，T の違いは平均に含めるだけである．実験 1・5 は (T, c) ごとに区間を作っていたので，(T, c) ごとの区間は rows から後で出せることを書く（gate-code の記録）．
  - 実効の塊の数が 20 未満（AFEW 14.99，IEMOCAP 4.91，MELD 8.59）は，塊の jackknife と種の項に t の区間（自由度 13，3，7）を使う．
  - MOSEI は塊の引き直し（`dai1_stats.N_BOOT` = 2,000 回）と種の項に正規の区間を使う．
  - IEMOCAP の区間は，5 つのセッションの揺れしか表さないと書く（gate-probe の記録 S3）．
- **下限**：UAR の差は 0.5 ポイント．「区間の下端 > 0 かつ点推定 ≥ 0.5」を満たす K を数える．
  - K = 0 は数えず，表に並べる．
  - K は同じテストと候補を共有するので，K ∈ {1, 5, 10, 25} の 3 つ以上という数え方は 3 回の独立な確かめではない．
- **R1（Q3 の主）**：AVT の空間で，EM（固定の点）− none[K] が K の 3 つ以上で条件を満たすコーパスを「EM が K 本だけの融合の頭を上回った」とする．4 コーパスのうち何個かを書き，IEMOCAP 即興を除いた数も書く．
- **R1 の書き方（計算の前に固定．dai-review-affect の A1）**：
  - R1 を満たしたコーパスが 0 なら，「DAI の設定でも，この族の EM は K 本だけの融合の頭を上回らなかった」と書く．「E28-10 と同じ向き（悪化）」とは，区間の上端が 0 より下の K が 3 つ以上のコーパスについてだけ書く（gate-probe の第 2 回の 5）．
  - 満たしたコーパスがあれば，「満たした．E28-10 の設定とは 0 節の 5 つの点で違い，どの違いから来たかは分けない」と書く．
- **R2**：同じ数え方を EM − joint で行う．
- **R7**：同じ数え方を EM − ttfused で行う．同じ予測を受け取る識別型の学び直しとの比べである．
- **R1・R2・R7 の向き（gate-probe の記録 C9）**：none[K] と joint は c のテストの UAR で選んだ点なので，差は EM に不利な向きに寄る．
- **R1・R3 のもう 1 つの向き（dai-review-affect の A3）**：ラベル無しの候補を全部使う EM の側にだけ，次のコーパスの構造が入る．none[K] と LDA_K は K 本しか使わないので，R1 と R3 は EM に有利な向きに寄ると書く．
  - IEMOCAP 即興の筋書きの共有：テストのセッションも候補のセッションも同じ筋書きを演じる．
  - MOSEI の漏れ：同じ人物の別の動画が候補に残りうる．
- **R1 の添え書き（dai-review-affect の A3．DAI-7 の設計 4 節の H1 の書き方に合わせる）**：
  - IEMOCAP で R1 を満たしたときは，「IEMOCAP 即興の得は，筋書きの話題の共有と分けられない」と添える．
  - MOSEI で R1 を満たした K のうち，チャンネルが分かる発話だけの EM − none（`dai3.subset_masks` の channel）が「区間の下端 > 0 かつ全体の点推定の半分以上」の K が 3 つ未満なら，「同じ人物の別の動画が候補に残る漏れと分けられない」と添える．
  - AFEW は asr_ok，MELD は face_single で絞った同じ差を記述として並べる（a7）．
- **R3（ラベル無しの発話の得．gate-probe の 2）**：EM_fromK − LDA_K（AVT）で同じ数え方をする．上端が 0 より下の K の数も書き，3 つ以上なら「ラベル無しの発話はガウスの判別を悪くした」と書く．
- **R3′（記述）**：EM − LDA_K は「ラベル無しの発話と none[K] の予測を合わせた得」として並べる．none[K] は選んだ点なので，この差は EM に有利な向きに寄る．
- **R8（選ばない引き戻し．gate-code の 7）**：EM_T − noneT（AVT）で同じ数え方をする．R1 を満たし R8 を満たさないコーパスでは「R1 は選んだ引き戻しの得を受け継いでいる」と書き，R8 を満たし R1 を満たさないコーパスでは「選んだ引き戻しから始めると EM の得が消える」と書く（gate-probe の第 2 回の 6）．IEMOCAP の筋書きと MOSEI の channel の添え書きを，R3 と R8 にも当てる（dai-review-affect の b2）．
- **R4（前提 Q2．gate-probe の 4）**：LDA_oracle − oracle（AVT，α = 0.5）の点推定が −2 ポイント以上なら「ガウスの形は線形の上限に近い」とし，区間も並べる．
  - 満たさないコーパスでは，R1 の失敗をガウスの形の誤りと分けられないと書く．
  - oracle も選んだ引き戻しの点なので，この差は負の側に寄る．
  - n/d < 1 のコーパスで満たさないときは，ガウスの形の誤りか共分散の推定の誤差かを分けられないと書く．
  - MOSEI の Neutral は消去法で決まるので，R4 の差をガウスの形の誤りと分けられない（dai-review-affect の a4）．
- **R9（流れた理由の読み分け．dai-review-ml の M1，第 2 回の N1．AVT，α = 0.5 だけ）**：コーパスごとに，次の順で 1 つに決める．
  1. EM_truth（収束の版）のテストの UAR − LDA_oracle のテストの UAR の点推定が −2 ポイント以下なら，「この形のモデルの尤度の頂上は，感情の割り当てから離れている」と書く．テストのラベルは採点にだけ使う．
  2. そうでなく，EM_rand が初期のラベルを 0.9 以上保つか，EM_truth と EM_rand の保った割合の差が 0.2 未満なら，「EM はどの初期値もほぼ保つ（本数が次元に比べて少ない）．EM が流れたかどうかから，分布が感情の情報を持つかは言えない」と書く．
  3. どちらでもなければ，「正解から始めれば感情の割り当てを保つ」と書く．「none[K] から始めた EM が流れた（初期値の問題）」は，次の「流れた」の定義を満たすときだけ添える．
  - **「流れた」の定義（gate-probe の第 2 回の 4）**：固定の点の EM（t = 10）の候補の上の UAR が，初期値の none[K] の候補の上の UAR より 0.5 ポイント以上低い単位が，K ∈ {1, 5, 10, 25} の単位の過半であること．台本は収束の版の回の記録の t = 10 の値で数える（dai-review-ml の第 3 回の n4）．3.3 節の仮定の表の量（動いた割合など）は，固定の点では収束の版の最後の r で測る．
  - 候補の上の UAR の半分の規則（第 3 版の段 2）は記述に回す．
  - 格子の α = 0.1・0.9 の EM には，R9 の読みを当てない（dai-review-ml の第 2 回の n2）．
  - E28-10 の「ラベル無しの分布は感情の情報を持たない」は，この読み分けをしていない結論なので，R9 の結果と並べて書き直す．
- **R10（流れた先．記述．gate-probe の第 2 回の 2）**：AVT の固定の点の収束の版の割り当てについて，感情・グループ・対話の AMI のうち最も大きいものを書く．none[K]，EM_truth，EM_rand の同じ量を並べる．グループや対話の AMI が感情の AMI より大きければ，「EM の割り当ては感情より〈グループ・対話〉に沿う」と書く．感情の AMI が最も大きいときは，「割り当てが感情に沿うことは示さない（感情とグループ・対話の印どうしも重なる）」と添え，ラベルどうしの AMI（感情とグループ，感情と対話）を並べる（dai-review-ml の第 3 回の n6）．AMI の差が小さいコーパスで「沿う」と書くときは，`ami_units.csv` から単位ごとの揺れを添える（gate-probe の第 4 回の記録）．
- **R5（Q1．記述）**：AVT で，上位 3 つの固有値の和の帰無を引いた値（top3ex）が最も大きいラベル（感情・グループ・対話）を書く．同じ対話を外した近傍の感情の一致の伸びが，グループの一致の伸びより小さい分割の数も書く．IEMOCAP は同じ筋書きを外した版も並べる．感情の一致は 4 感情の平均，グループの一致は発話の平均で，平均の取り方が違うと添える（dai-review-ml の m4）．白色化した計量での感情の分かれやすさと，グループ・対話の分かれやすさを，それぞれでたらめの水準との比で並べる．R5 は記述で，R1 の解釈には「流れる先の候補」としてだけ使う．
- **R6（記述）**：EM − EM_μ の値と区間を並べる．この差は「Σ を回ごとに推定し直す寄与」で，「ラベル無しの発話で Σ を推定する寄与」ではない（dai-review-ml の m6）．EM_μ の向きは A⁻¹M_t と A⁻¹M₀ が張る空間に入るので，この差には向きの空間の違いも入る（3.2 節．gate-probe の第 3 回の 2）．
- 単独の空間（A，V，T）の同じ量，格子の全部の点，0 回目と収束の版，ブロック対角の版は記述として並べる．どの規則も，満たしたかどうかによらず全部のセルの値と区間を表に出す．満たさなかった規則は「満たさなかった」と書き，ほかの量で言い換えない．

## 5. 出力（`results/dai8_probe/`）

- `rows/<単位>.npz`：
  - 単位のコミットと，テストの sample_id・塊・グループ・感情．

  - 主な方法の係数 A = Σ⁻¹μᵀ と μ（float16），c と π（float32）（gate-code の 2）．
  - 候補のラベル無しの発話の上の none と収束の版の判定（gate-code の 3）．
  - 診断：EM の各回の r の変化，各回の候補の上の UAR，π，3.3 節の仮定の表の量，感情ごとの候補の上の再現率．

- `diffs.csv`：比べの点推定と区間．比べは，EM − none・joint・ttfused・LDA_K，EM_fromK − LDA_K，EM_T − noneT，EM − 0 回目，0 回目 − none，収束の版 − none，EM − EM_μ，ブロック対角 − EM，格子の各点 − none，LDA_oracle − oracle，ブロック対角の LDA_oracle − LDA_oracle．AVT の EM − none と EM − joint は部分集合でも出す．

- `provenance.json`：次を書く．
  - コミット，dirty，台本の sha256
  - 入力の sha256（固定のファイル，各単位の p1・p3）
  - 乱数の種と定数
  - ソフトの版
  - 集計の段のコミット

## 6. 所要と計算機

- GPU（RTX A5000）で，共分散の推定と逆行列（2,304 次元まで）を EM の回ごとに解く．GPU のメモリは 6 割に抑える．
- 本体の試走（第 3 版の台本）：AFEW 25〜32 秒，IEMOCAP 51 秒，MOSEI 89〜108 秒．1 本で流すと約 2.4 時間なので，`--shard 0/2` と `--shard 1/2` の 2 本を同じ GPU で並べて流す（1 本あたりの GPU のメモリは約 3 GB）．組ごとの provenance は `provenance_shard<i>.json` に書き，集計の段が 2 つのコミットと dirty の一致を確かめてまとめる．
- DAI-6 の下調べがメモリ不足で止められた（2026-11-07 夜）ので，単位ごとに解放する．

## 7. 見たデータと漏れ

- 使うのは仮のターゲットの回の保存と特徴だけで，評価の回の値は使わない．評価のターゲット T のデータは単位に入らない．
- EM はテストの発話を使わない（推定は候補だけ．テストは判定するだけ）．候補の全ラベルは LDA_oracle と診断の測定にだけ使う．
- 規則で数える点は計算の前に固定した．格子の点を見てから規則の点を変えない．

## 8. 範囲の外と限界

- テストの話者は候補に入らない．EM が推定する平均と共分散は，候補の話者の分布である．
- MOSEI は同じ人物の別の動画が候補に残りうる（`data/README.md` 3 節）．
- none[K] と joint の点は，同じ c のテストの UAR で選んである（DAI-7 の設計 8 節と同じ）．EM の固定の点（α，β，t）は選んでいないが，初期値と事前は選んだ none[K] から来る（gate-probe の 2，gate-code の 7）．R8 がこの寄りを分ける．
- 3 つのモダリティの空間を 1 つにつないで扱う．モダリティごとの重みは推定しない．
- K 本が M 段の重みに占める割合は小さい（MOSEI の K = 1 で約 0.03%，AFEW の K = 25 で約 16%．dai-review-ml の m5）．EM を K 本の近くに留めるのは E 段の β の項だけである．
- 縮める先は I だけにする．Ledoit と Wolf の推定は使わない．
- 範囲の外（gate-code の 9）：
  - 第 2 のエンコーダ（保留．`DAI/CLAUDE.md`）．
  - 話者ごとの正規化を EM に入れること．Q1 でグループの平均を引いた版の近傍と散らばりを測るだけにする．グループの印は候補の付帯情報で，配備の場面で使えるかは別に決める．
  - ラベル無しの発話の本数を変えること．候補の全部を使う．
- 結果は手法の固定ではない．得が出た形は，改めて設計して関門を通す．
