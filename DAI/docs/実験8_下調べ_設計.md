## 1. 問い

- **Q1（前提：近傍）**：固定した特徴の空間（モダリティごとと，3 つをつないだ空間）で，発話の近傍は同じ感情か．同じ話者（塊）である度合いと比べてどうか．
- **Q2（前提：ガウスの形）**：候補の全ラベルで推定した共通の共分散のガウスの判別（LDA）は，同じ候補の全ラベルで学んだ線形の頭（oracle）の UAR にどれだけ近いか．
- **Q3（試し）**：K 本のラベルを固定し，K 本だけの頭（none[K]）の予測を初期値と事前に使って，ラベル無しの候補の発話の EM で平均と共通の共分散を推定し直すと，テストの UAR は none[K] より上がるか．提案（joint）と比べてどうか．ラベル無しの発話を使わない K 本だけの LDA と比べてどうか（ラベル無しの発話がガウスの判別を良くするか．Cozman ほか 2003 の問い）．
- **Q4（記述：依存の扱い）**：3 つをつないだ空間で，モダリティをまたぐ共分散を 0 にした版（ブロック対角．感情のもとでモダリティが独立とみなす積と同じ形）と，そのまま使う版を比べる．

## 3. 量の定義

### 3.1 近傍（Q1）

- 候補の発話の間で，標準化した特徴のコサイン類似度の k = 10 個の近傍（自分を除く）を取る．
- 感情の一致の割合（感情で平均）：感情 e の発話について「近傍のうち感情 e の割合」の平均を取り，4 感情で平均する．でたらめなら 0.25 である．
- 話者の一致の割合：近傍のうち同じグループの割合の平均．グループは IEMOCAP が話者（`speaker_id`），ほかは `cluster`（DAI-7 と同じ）．でたらめの水準は Σ_g p_g²（p_g はグループの割合）．
- 両方を，でたらめの水準からの伸び (a − a₀)/(1 − a₀) でも並べる．

### 3.2 ガウスの判別（Q2〜Q4）

- 共通の共分散のガウスの判別：
  ```
  δ_k(x) = μ_kᵀ Σ⁻¹ x − ½ μ_kᵀ Σ⁻¹ μ_k       （判定は argmax_k δ_k．感情の事前は等しくする）
  Σ = (1 − α)·S + α·I                         （S は感情の平均を引いた重みつきの散らばり，α は縮める強さ）
  ```
  縮める先は単位行列 I にする．特徴は候補の統計で標準化してあるので，各次元の全体の分散は 1 である．K = 1 の LDA_K では感情の中の散らばり S が 0 になり，tr S / d に縮めると Σ が特異になるためである（第 1 版の台本の試走の前に直した．値は見ていない）．計算では，各行の重みの和が 1 なので Σ_i Σ_k r_ik x_i x_iᵀ = XᵀX が回によらず，S = (XᵀX − Σ_k n_k μ_k μ_kᵀ)/N で求める．
  感情の事前を等しくするのは，UAR を最大にする判定がクラスの割合に依らないため（Menon ほか 2021．調べの報告の族 2）．
- **LDA_oracle**：候補の全ラベルで μ と S を推定する（Q2．テストのラベルは使わない．候補の全ラベルは oracle と同じ情報）．
- **LDA_K**：K 本のラベルだけで推定する（K ≥ 1）．
- **EM**：
  - 初期値：ラベル無しの候補の発話の感情の重み r_ik を，none[K] の頭の確率 q_ik にする（K = 0 は出発点＝ソースの平均の頭）．K 本は正解の one-hot に固定する．
  - M 段：
    ```
    n_k = Σ_{i∈L} 1[y_i = k] + Σ_{i∈U} r_ik
    μ_k = (Σ_{L} 1[y_i = k] x_i + Σ_{U} r_ik x_i) / n_k
    S   = Σ_k [ Σ_{L, y=k} (x − μ_k)(x − μ_k)ᵀ + Σ_{U} r_ik (x − μ_k)(x − μ_k)ᵀ ] / Σ_k n_k
    π_k = n_k / Σ n_k
    ```
  - E 段：
    ```
    log r_ik = β·log q_ik + log π_k + δ_k(x_i) + 定数     （k について softmax）
    ```
    β は none[K] の予測を事前として残す強さ．β = 0 は素の EM である．E 段の π_k は推定した割合で，ラベル無しの発話の割合の偏りを入れる（Saerens ほか 2002 の EM と同じ扱い）．テストの判定は等しい事前で行う．
  - 回数：10 回で固定する．各回の r の変化（平均の絶対差）を残す．
- **格子（記述．全部の点を表に出す）**：α ∈ {0.1, 0.5, 0.9}，β ∈ {0, 1}．**規則で数える点は α = 0.5，β = 1 に計算の前に固定する**（選ばない）．
- **AVT のブロック対角の版（Q4）**：S のモダリティをまたぐブロックを 0 にしてから縮める．LDA_oracle と EM（固定の点）で出す．I に縮めるので，LDA_oracle のブロック対角の版の判定は，A・V・T の各空間の LDA_oracle の δ の和の argmax と一致する．EM のブロック対角の版は，3 つの空間で共通の r を使って同時に回すので，各空間で別々に回した EM とは一致しない（gate-probe の記録 D1）．
- **K 本の LDA から始める素の EM（EM_fromK．gate-probe の 2）**：K ≥ 1 で，ラベル無しの候補の初期の重みを LDA_K（α = 0.5）の確率 softmax(δ_K) にし，β = 0 で回す．none[K] を使わないので，ソースの情報と選んだ引き戻しが入らない．α = 0.5 だけで出す．
- **共分散を固定する EM（EM_μ．gate-probe の 5）**：固定の点（α = 0.5，β = 1）と同じ初期値で，最初の M 段の Σ を固定し，μ と π だけを推定し直す．EM − EM_μ が共分散を推定し直した寄与である．
- **比べる頭**（保存から読む．学び直さない）：none[K]（`dai1.none_wb` と同じ選んだ引き戻し），joint（提案．固定のファイルの `<m>|<K>|joint|<主の版>`），oracle（`all|C′|C_b`．K = 25 の引き戻し．DAI-7 と同じ）．AVT は融合の頭である．

### 3.3 診断（記述）

- EM の後の候補のラベル無しの発話の上の UAR（候補の正解で測る．学習には使わない）と，none[K] の候補の上の UAR．EM がラベル無しの発話の感情の割り当てを良くしたか悪くしたかを見る．
- EM の推定した割合 π と候補の真の割合の差．
- EM の判定が none[K] の判定と違う割合（テスト）．
- **EM の仮定の表（gate-probe の 3．基準は計算の前に固定）**：
  | 量 | 定義 | 基準と書き方 |
  |---|---|---|
  | n/d | 候補の本数 ÷ 空間の次元 | 1 未満の (c, 空間) では，共分散の推定が縮める先 I に強く寄ると書く |
  | 動いた割合 | ラベル無しの候補の発話のうち，最後の r の argmax が初期値 q の argmax と違う割合 | 固定の点の AVT で，K ∈ {1, 5, 10, 25} の平均が 0.05 未満のコーパスでは，R1 の失敗を「EM が初期値からほとんど動かなかった」と書き，「EM が得をしない」とは書かない |
  | 項の大きさの比 | 1 回目の E 段で，ラベル無しの発話ごとの max_k δ_k − min_k δ_k の中央値 ÷ max_k log q_k − min_k log q_k の中央値 | 10 を超える (c, 空間) では，β = 0 と β = 1 の区別がほとんど無いと書く |
  | r のエントロピー | 最後の r の平均のエントロピー（nat．最大 log 4 ≈ 1.386） | 記述 |
  | 収束 | 最後の回の r の変化（発話ごとの絶対差の和の平均） | 0.01 未満を「収束した」とし，満たさない単位の数を書く |

## 4. 判定の規則（計算の前に固定）

- **区間**：実験 1・5 と同じ `dai1_stats.effect_stats` を使う．K 本の抜き方は T に依らない（`dai_data.k_orders` の乱数は (c, f, r) で決まる）ので，(f, r) を単位にし，同じ (f, r) の 3 つの T の塊ごとの正解の数と件数を足す．こうして作った UAR は 3 つの T の UAR の平均と一致する．種の項は分割ごとの 2 つの種で作る（gate-probe の 1）．
  - 実効の塊の数が 20 未満（AFEW 14.99，IEMOCAP 4.91，MELD 8.59）は，塊の jackknife と種の項に t の区間（自由度 13，3，7）を使う．
  - MOSEI は塊の引き直し（`dai1_stats.N_BOOT` = 2,000 回）と種の項に正規の区間を使う．
  - IEMOCAP は塊が 5 つ（分割ごとに 1 つのセッション）で，区間は塊の jackknife と自由度 3 の t で作る．この区間は 5 つのセッションの揺れしか表さないと書く（gate-probe の記録 S3）．
- **下限**：UAR の差は 0.5 ポイント．「区間の下端 > 0 かつ点推定 ≥ 0.5」を満たす K を数える．K = 0 は数えず，表に並べる．K は同じテストと候補を共有するので，K ∈ {1, 5, 10, 25} の 3 つ以上という数え方は 3 回の独立な確かめではない．
- **R1（Q3 の主）**：AVT の空間で，EM（固定の点）− none[K] が K の 3 つ以上で条件を満たすコーパスを「EM が K 本だけの融合の頭を上回った」とする．4 コーパスのうち何個かを書き，IEMOCAP 即興を除いた数も書く．
- **R2**：同じ数え方を EM − joint（提案の融合の頭）で行う．
- **R1・R2 の向き（gate-probe の記録 C9）**：比べる相手の none[K] と joint は c のテストの UAR で選んだ点なので，R1・R2 の差は EM に不利な向きに寄ると書く．
- **R3（ラベル無しの発話の得．gate-probe の 2）**：EM_fromK − LDA_K（AVT）で同じ数え方をする．上端が 0 より下の K の数も書き，3 つ以上なら「ラベル無しの発話はガウスの判別を悪くした」と書く．
- **R3′（記述）**：EM − LDA_K は「ラベル無しの発話と none[K] の予測を合わせた得」として並べる．none[K] は選んだ点なので，この差は EM に有利な向きに寄ると書く．
- **R4（前提 Q2．gate-probe の 4）**：LDA_oracle − oracle（AVT，α = 0.5）の**点推定**が −2 ポイント以上なら「ガウスの形は線形の上限に近い」とし，満たさないコーパスでは R1 の失敗をガウスの形の誤りと分けられないと書く．区間も並べる．oracle も選んだ引き戻しの点なので，この差は負の側に寄ると書く．n/d < 1 のコーパスで満たさないときは，ガウスの形の誤りか共分散の推定の誤差かを分けられないと書く．
- **R5（前提 Q1．記述）**：AVT の感情の一致の伸びが話者の一致の伸びより小さい分割の数を，コーパスごとに書く．R5 は記述で，R1 の解釈には使わない．
- **R6（共分散の寄与．記述）**：EM − EM_μ（AVT）の値と区間を並べる．0 節の「共分散を推定し直すことが要る」という案の根拠は，この差で確かめたときだけ書く．
- 単独の空間（A，V，T）の同じ量と，格子の全部の点は記述として並べる．どの規則も，満たしたかどうかによらず全部のセルの値と区間を表に出す．満たさなかった規則は「満たさなかった」と書き，ほかの量で言い換えない．

## 8. 範囲の外と限界

- テストの話者は候補に入らない．EM が推定する平均と共分散は，候補の話者の分布である．
- MOSEI は同じ人物の別の動画が候補に残りうる（`data/README.md` 3 節）．
- none[K] と joint の点は，同じ c のテストの UAR で選んである（DAI-7 の設計 8 節と同じ）．none と joint の UAR は上に偏る．EM の固定の点（α，β）は選んでいないが，初期値と事前は選んだ none[K] から来る（gate-probe の 2）．
- 3 つのモダリティの空間を 1 つにつないで扱う．モダリティごとの重みは推定しない．
- 縮める先は単位行列だけにする．Ledoit と Wolf の推定は使わない．
- K ≤ 10 の LDA_K は，2,304 次元の大部分の方向で Σ = α·I になる．K = 1 は感情ごとの発話が 1 本なので，判定は最も近い平均の規則と同じになる（gate-probe の記録 D4）．
- 結果は手法の固定ではない．得が出た形は，改めて設計して関門を通す．
