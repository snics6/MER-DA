## 1. 問い（2 つ）

- **Q1**：あるモダリティの判断を，別のモダリティの特徴からどれだけ再現できるか．特に「言葉の判断」と「顔の判断」を，声の特徴は他方の特徴より良く再現するか．
- **Q2**：その再現は，感情を通した一致（両方が同じ感情を当てていること）と，感情と塊（話者の代わりの単位）を通した一致を除いても残るか．残る分を D（感情と塊を除いた再現の分）と呼ぶ．

記述として，主張の 3 条件の表（`DAI/docs/主張_2026-11-12.md` 2 節）の条件 2・3 を，下調べではなく評価の回の値で作り直す．

## 2. データと単位

- 評価の回の単位：評価のターゲット T ∈ {AFEW, IEMOCAP, MELD, MOSEI} × 分割 f ∈ {0, …, 4} × 種 r ∈ {0, …, 9}（実験 1 の固定のファイルの n_seeds_eval．`results/dai1/eval/units/`）．計 200 単位．
- K = 5 を主，K = 25 を副の条件にする（同じ規則で判定し，並べて書く）．学び直す側（再現する側）の特徴は声（A．WavLM の最後の層），顔（V．ResNet-50），言葉（T．RoBERTa．AFEW は Whisper の書き起こし）．融合は扱わない．
- 候補：単位の候補（ラベル無しの発話）全部．K 本のラベル付きの発話も候補に含まれ，R の計算に入る（実験 3 と同じ）．
- 候補を塊（AFEW・MELD・MOSEI は対話か動画，IEMOCAP はセッション）で 2 組に分ける（実験 3 の `pool_halves`．ラベルを使わない）．**IEMOCAP の塊はセッションで，2 つの組が同じ対話を共有しない．**MELD は 2 つの組が同じ対話を共有する発話がありうる（`dlg_pool` で数える）．

## 3. 量

- **判断 J_m**：モダリティ m の K 本だけの分類器（実験 1 の `none`．実験 3 の `single_m`）の，候補の上の判定（argmax）．
- **提案の疑似ラベル J_prop**：実験 1 の主の版（固定のファイルの `main`．K ごとに決まる．K = 5・25 とも `one`）の疑似ラベル `prop_one`（3 つの確率の積）の判定．
- **再現できる度合い R(s ← m)**：J_m を硬いラベル（感情の釣り合いの重み）にし，生徒 s の特徴の上の線形の識別器を片方の組で学び，もう片方の組で予測する．入れ替えて両方の組の予測をそろえ（交差の予測），候補全体で J_m を正解とした釣り合いの一致（UAR と同じ式．現れた感情だけで平均）を取る．でたらめなら 25．読み出しは 2 つ：
  - **R1（そろえた読み出し．P1・P2・P4 の主）**：生徒の特徴を候補の上の主成分で 512 次元（顔の特徴の次元）にそろえ（ラベルを使わない．次元あたりの分散の平均を 1 にする），出発点 0，切片の C_b = 1，重みの C′ を格子 {0.001, 0.01, 0.1, 1, 10} から選ぶ．C′ は，学ぶ側の組を塊で 2 つに分けた内側の交差の予測で，**目標の判断 J_m との一致**が最大の点（同点は小さい C′）．本当の感情のラベルは使わない．入れ替えの対照には，同じ (生徒, 目標, 組) の真の目標で選んだ C′ をそのまま当てる．3 つの特徴の次元と調整の手順をそろえ，比べる 2 つの生徒の読み出しの差が「特徴の中身」以外から来る分を減らす．
  - **R0（実験 1 の作り．副と照合）**：生徒の出発点（`u.start[s]`）から，(s, K) の実験 1 の引き戻し（`sv.teth`）で学ぶ（実験 3 の 2 節と同じ）．実験 3 の定義（2 つの組の値の平均）を保存の `repro_units.csv` と照合し，差が 0.001 を超えたら止める．
  - **学び直す前の一致 R_start**（記述）：生徒の出発点の判定と J_m の一致．R0 が出発点からどれだけ動いたかを見るため．
- **入れ替えの対照**（目標の判断を層の中で入れ替える．入れ替えは単位・K・目標・版の名前から決まる乱数で 1 回）：
  - **#shuf**：本当の感情が同じ候補の間で入れ替える．
  - **#shufcl（P3・P4 の主）**：（本当の感情，塊）が同じ候補の間で入れ替える．感情ごと・塊ごとの判断の分布を保ち，発話ごとの対応だけを壊す．話者や対話に固有の偏りによる一致はこの対照に残るので，D から除かれる．入れ替えで目標が実際に変わった発話の割合（frac_changed）を出す．
  - **#shuffine（記述）**：IEMOCAP は（元のラベル emotion_raw，覚醒度の 3 区分），MOSEI は（4 つのラベル，感情の強さ int_* の最大の 3 区分）の中で入れ替える．3 区分の境は，DAI/splits の発話全体の 3 分位．覚醒度や強さを通した一致を除いた D を見る．AFEW・MELD には該当する注釈が無い．
- **D_x(s ← m) = R(s ← m) − R_x(s ← m)**（x は shuf，shufcl，shuffine）．D_shufcl を単に D と書く．特徴が感情と塊しか知らないなら 0 に近くなる．
- **当たる幅 Δ_s**（記述）：候補のうち K 本を除いた発話の上で，J_prop の UAR（本当の感情に対して）− s の K 本だけの分類器の UAR．並べて J_m の UAR（uar_judge）も出す．
- **評価の回の真似できる分 P_s**（記述）：J_prop を目標にして学んだ識別器の交差の予測の，K 本を除いた候補の上の本当の感情に対する UAR − 同じ発話の上の s の K 本だけの分類器の UAR．R0 と R1 の両方．下調べ 11 の「真似できる分」（リッジ回帰の交差予測）とは作りが違うので，表では「評価の回の真似できる分」と書く．

## 4. 区間

- 単位 (f, r) ごとに，候補の塊ごとの数（`dai1_stats.counts` と同じ形）を作り，量の線形の組み合わせ（差，差の差）を単位ごとに計算する．
- 塊の実効の数 g_eff（`dai1_stats.g_eff_of`．コーパス全体の塊から）が 20 未満（AFEW，IEMOCAP，MELD）は，塊を全分割から同時に除く jackknife と種の項（`dai1_stats.effect_stats` と同じ式．自由度 max(1, ⌊g_eff⌋ − 1)，t の 97.5% 点）．20 以上（MOSEI）は，全分割で共通の塊の重みを 1 組引く引き直し 2,000 回と種の項（実験 12 の `effect_stats_pool` と同じ式）．
- **分け方の揺れ**：R は候補を 2 組に分ける分け方に依る．r = 0 の単位（各分割に 1 つ）で，K = 5・R1 について，塊を乱数の順に並べて本数の少ない組へ配る別の分け方を 4 通り作り（元と同じか裏返しの分け方は除く．IEMOCAP はセッションが少なく，作れる分け方が少ない．作れた数を記録する），P1〜P4 の量を測る．分割 f ごとの分け方の間の分散 v_f を求め，(1/F²) Σ_f v_f を主の区間の SE² に足す．
- 区間は再現の識別器を学び直さない（塊を除いた値は保存した予測の数から計算する）．入れ替えの対照は 1 回で，入れ替えの揺れは種の項に入る分だけを含む．
- 区間は 95%．多重比較の補正はしない（予言は 5 つの量で，判定はコーパスの数え上げ）．

## 5. 予言（計算の前に固定．線引きは暫定）

量はすべて各評価のターゲットごと．主の判定は **K = 5，R1，対照 #shufcl，候補の全体**．

| 予言 | 量 | 主の数え |
|---|---|---|
| P1 | R(A ← T) − R(V ← T)：言葉の判断を，声の特徴は顔の特徴より良く再現する | AFEW を除く 3 コーパスで，区間の下端 > 0 が 2 以上 |
| P2 | R(A ← V) − R(T ← V)：顔の判断を，声の特徴は言葉の特徴より良く再現する | 4 コーパスで 3 以上 |
| P3 | D(A ← T)：声の特徴が言葉の判断を再現する分は，感情と塊を通した一致を除いても残る | AFEW を除く 3 コーパスで 2 以上 |
| P4a | D(A ← T) − D(V ← T) | AFEW を除く 3 コーパスで 2 以上 |
| P4b | D(A ← V) − D(T ← V) | 4 コーパスで 3 以上 |

- **AFEW を除く理由**：AFEW の言葉は音声の書き起こし（Whisper）なので，声と言葉の特徴は同じ信号から来る．言葉の判断 J_T を使う P1・P3・P4a は AFEW を主の数えに入れず，4 コーパスでの数えを並べる．
- **MELD**：候補の全体で「上回る」でも，2 つの組が共有する対話の発話を除いた版で「上回る」でなければ，主の数えで MELD を「上回る」に数えない．
- 副の条件（R0，K = 25，対照 #shuf，共有の対話を除いた版，記号の無い発話だけの版）も同じ規則で数え，主と判定が違えば書く．**R1 と R0 で判定が違う予言は，「読み出しの作りに依る」と書き，説明をその範囲に限る．**
- **線引きは暫定**（研究者の指示）．計算の後に主張の書き方を変えてよいが，その場合も上の規則での当たり外れを先に書き，変えた理由を書く．
- **P3 は P4a の前提の確かめ**で，P3 だけが当たっても説明の根拠に数えない（声の特徴が言葉の判断を感情以外の手がかりで再現しても，ほかの特徴も同じだけ再現するなら声に固有の話ではない）．

**書き方の対応（結果の文で使う）**：

| 結果 | 書く文 |
|---|---|
| P1 当たり | 「声の特徴は，言葉の分類器の判断を，顔の特徴より良く再現した」 |
| P4a 当たり | 「声の特徴は，言葉の分類器の判断のうち感情のラベルと塊（話者の代わり）で説明できない部分を，顔の特徴より多く再現した」 |
| P2・P4b 当たり | 上の 2 行の「言葉」と「顔」，「顔の特徴」と「言葉の特徴」を入れ替えた文 |
| P1・P2 当たり，P4 外れ | 「声の特徴はほかのモダリティの判断を最もよく再現した．ただし感情と塊を除くと差は判定できなかった」までにする |
| P1・P2 とも外れ | 説明（3 条件の理由づけ）を主張から外し，3 条件の表だけを残す |

- どの結果でも「声に言葉の中身が入っている」とは書かない．言葉の特徴にも韻律の手がかりの一部が書き起こしの記号として入っている（IEMOCAP の [LAUGHTER] などの記号は候補の約 2.5%，MELD の「!」は約 30.5%，AFEW の Whisper の書き起こしの「!」は約 16.8%．記号の無い発話だけの版を記述で出す）．
- 「判定できない」は「差が無い」ではない．否定の文（「言葉の特徴には声色が入っていない」「顔の特徴には言葉が入っていない」）はこの実験では検証しない．R(T ← A) などは記述として出すだけにする．

## 6. 記述として出すもの（判定に使わない）

- 3×3 の R，R_shuf，R_shufcl，R_shuffine，D_x（行：再現する特徴 A・V・T，列：判断 J_A・J_V・J_T と J_prop）．R1 と R0 の両方．対角（自分の判断）は出さない．学び直す前の一致 R_start．
- MELD で 2 つの組が同じ対話を共有する発話を除いた版（候補の数と共有の対話の数も）．
- 書き起こしに記号（[ ] か !）が無い発話だけの P1・P3・P4a（AFEW は `afew_transcript_whisper.csv` の `transcript_asr`）．
- 3 条件の表の評価の回の版（値と区間を並べ，「欠けた条件」の列は作らない．判定は読み手に委ね，文では区間の言えることだけを書く）：余地（`expl4_corpus_restored.csv` の room．計算しない），J_m の UAR，J_prop の UAR，Δ_s，P_s（R0・R1），本番の上がり幅（族 1．計算しない）．
- 収束の印（勾配の最大，後退の止まり），選ばれた C′ の数，入れ替えで変わった発話の割合の範囲，目標ごとの最も少ない感情の件数，各単位の候補の数と塊の数．
- 保存：単位ごとの npz に，目標（真と各対照），交差の予測（R0・R1，K = 5・25，各分け方），出発点の判定，K 本だけの分類器の判定，J_m と J_prop の確率の最大（float16），2 組の割り当て，別の分け方，K 本の発話の印，共有の対話の印，記号の印を残す．後から別の部分集合や別の量を，学び直さずに出せる．

## 9. 限界（結果の文に書く）

- 同じ 4 コーパスと 1 組のエンコーダ（WavLM の最後の層，ResNet-50，RoBERTa）．確認ではない．声の言葉の情報は層に依る（Pasad ほか 2023 は自己教師ありの音声モデルの中間の層ほど単語の情報が多いと報告した．Wagner ほか 2023 は微調整した音声モデルが言葉の感情の手がかりを拾うと報告した）．この実験は微調整していない最後の層だけを見る．
- D は感情と塊を通らない一致の全部を含む．言葉の中身のほかに，覚醒度や強さ（IEMOCAP・MOSEI は #shuffine で一部を除く），話者の属性（性別など．塊の中で一定でない分），発話の長さ，MOSEI のチャンネルの代わりの単位，MELD の顔が話者でない人の顔でありうること，IEMOCAP の台本の共有と書き起こしの記号，が入る．D が正でも「声に言葉の中身が入っている」とは言い切れない．
- J_m は K = 5 の分類器の判断で，当たり方は弱い．P4a と P4b は判断が違う（J_T と J_V）ので，その 2 つの大きさは比べない．
- 線形の識別器での再現．非線形なら変わりうる（実験 12 では隠れ層を足しても読める分はほぼ変わらなかった）．
- 区間は再現の識別器を学び直さない．入れ替えは 1 回．
- コーパスの数え上げは，コーパスをまたぐ検定ではない．多重比較の補正はしない．
- 3 条件の表は，結果を見てから立てた説明の材料で，この実験の判定には使わない．

## 10. 計算と置き場
