# 実験 14（DAI-14）：どのモダリティの特徴が，ほかのモダリティの判断を再現できるか（2026-11-12．第 1 版．計算の前）

## 0. 経緯と位置づけ

- 研究者の指示（2026-11-12）：主張「提案が効くための 3 つの条件」（`DAI/docs/主張_2026-11-12.md`）を採り，「音声には声色と話している言葉の両方が入っている．このため言葉から来た判断の一部は声の特徴から再現できる．言葉の特徴には声色も表情も入っていない．顔の特徴には言葉が入っていない．声だけが，ほかのモダリティの手がかりを自分の中に持っている」という説明を「可能な限り検証しよう」．計画は「なるべくミニマムに」「今までの実験結果も使えるところは使う」「条件が複雑になりすぎないようにシンプルに」．研究者は就寝前に「私の確認を待たずに進めてくれ」と言った．線引き（何個のコーパスで成り立てば主張とするか）は「まだ議論の余地があり，主張の仕方を変えられる」．
- **種類**：本番の評価の回（実験 1 の評価の回．コミット ba98974）の保存済みの出力の再解析．分類器を新しく学ぶのは，再現できる度合いを測る線形の識別器だけ（実験 3 の 2 節と同じ作り）．評価のターゲットのテストの発話は使わない．使うのは候補（ラベル無しの発話）と，候補の本当の感情のラベル（入れ替えの対照と，当たる幅・真似できる分の計算にだけ使う）．
- **確認ではない**：問いと予言は，同じ 4 コーパスの評価の回の値（下の「見た値」）を見てから立てた．結果は「予言を計算の前に固定した探索」として書く．
- **見た値**（`docs/seen-data.md` の 2026-11-12 の行）：評価の回の `decomp.csv`，`expl1.csv`，`expl1_tt.csv`（学び直す分類器自身のモダリティを含まない疑似ラベルでの向きの改善），`expl3.csv`（得と再現できる度合いの順位相関），`expl4_corpus_restored.csv`，族 1，下調べ 11 の `req_vs_gain.csv`．`repro_units.csv` は列の名前と 1 行目（AFEW の分割 0・種 0 の声の生徒，顔の判断の行の agree 44.4）だけを見た．`expl3_types.csv` は列の名前と出所の名前だけを見た．**この実験で予言に使う量（3×3 の再現できる度合いと入れ替えの対照）の値は見ていない．**

## 1. 問い（2 つに絞る）

- **Q1**：あるモダリティの判断を，別のモダリティの特徴からどれだけ再現できるか．特に「言葉の判断」と「顔の判断」を，声の特徴は他方の特徴より良く再現するか．
- **Q2**：その再現は，感情を通した一致（両方が同じ感情を当てていること）を除いても残るか．残る分を「発話ごとの分」と呼ぶ．

記述として，主張の 3 条件の表（`DAI/docs/主張_2026-11-12.md` 2 節）の条件 2・3 を，下調べではなく評価の回の値で作り直す．

## 2. データと単位

- 評価の回の単位：評価のターゲット T ∈ {AFEW, IEMOCAP, MELD, MOSEI} × 分割 f ∈ {0, …, 4} × 種 r ∈ {0, …, 9}（実験 1 の固定のファイルの n_seeds_eval．`results/dai1/eval/units/`）．
- K = 5 だけ．学び直す側（再現する側）の特徴は声（A．WavLM），顔（V．ResNet-50），言葉（T．RoBERTa．AFEW は Whisper の書き起こし）．融合は扱わない．
- 候補：単位の候補（ラベル無しの発話）全部．候補を塊（話者の代わりの単位）で 2 組に分ける（実験 3 の `pool_halves`．ラベルを使わない）．

## 3. 量（実験 3 の 2 節の再現できる度合いと同じ作り）

- **判断 J_m**：モダリティ m の K 本だけの分類器（実験 1 の `none`．K = 5．実験 3 の `single_m`）の，候補の上の判定（argmax）．
- **提案の疑似ラベル J_prop**：実験 1 の主の版の選んだ指数での 3 つの確率の積（実験 3 の `prop_sel`）の判定．
- **再現できる度合い R(s ← m)**：J_m を硬いラベル（感情の釣り合いの重み）にし，生徒 s と同じ形の線形の識別器（s の出発点から，(s, K) の実験 1 の引き戻しで）を片方の組で学び，もう片方の組で予測する．入れ替えて両方の組の予測をそろえ，候補全体で J_m を正解とした釣り合いの一致（UAR と同じ式）を取る．でたらめなら 25．確かめとして，実験 3 の定義（2 つの組の値の平均）も出し，保存の `repro_units.csv` と照合する．
- **入れ替えの対照 R_shuf(s ← m)**：J_m を，本当の感情が同じ候補の間で入れ替えた（単位と組の名前から決まる乱数）ものを目標にして，同じ手順で学び，入れ替えた目標との一致を測る．入れ替えは「本当の感情ごとの J_m の分布」を保ち，発話ごとの対応だけを壊す．
- **発話ごとの分 D(s ← m) = R − R_shuf**．特徴が感情しか知らないなら 0 に近くなる．
- **当たる幅 Δ_s**（記述）：候補のうち K 本を除いた発話の上で，J_prop の UAR（本当の感情に対して）− s の K 本だけの分類器の UAR．
- **真似できる分 P_s**（記述）：J_prop を目標にして上と同じ手順で学んだ識別器の，片方の組での本当の感情に対する UAR（K 本を除く）− 同じ発話の上の s の K 本だけの分類器の UAR．下調べ 11 の「真似できる分」（リッジ回帰の交差予測）とは作りが違うので，名前を同じにしない（表では「評価の回の真似できる分」）．

## 4. 区間

- 単位 (f, r) ごとに，候補の塊ごとの数（`dai1_stats.counts` と同じ形）を作り，量の線形の組み合わせ（差，差の差）を単位ごとに計算する．
- 塊の実効の数 g_eff（`dai1_stats.g_eff_of`）が 20 未満（AFEW，IEMOCAP，MELD）は，塊を全分割から同時に除く jackknife と種の項（`dai1_stats.effect_stats` と同じ式．自由度 max(1, ⌊g_eff⌋ − 1)，t の 97.5% 点）．20 以上（MOSEI）は，全分割で共通の塊の重みを 1 組引く引き直し 2,000 回と種の項（実験 12 の `effect_stats_pool` と同じ式）．
- 区間は 95%．多重比較の補正はしない（予言は 4 つで，判定は 4 コーパスの数え上げ）．

## 5. 予言（計算の前に固定．線引きは暫定）

| 予言 | 量（K = 5．各評価のターゲット） | 当たりの規則（暫定） |
|---|---|---|
| P1 | R(A ← T) − R(V ← T)：言葉の判断を，声の特徴は顔の特徴より良く再現する | 区間の下端 > 0 のコーパスが 4 中 3 以上 |
| P2 | R(A ← V) − R(T ← V)：顔の判断を，声の特徴は言葉の特徴より良く再現する | 同上 |
| P3 | D(A ← T)：声の特徴が言葉の判断を再現する分は，感情を通した一致を除いても残る | 同上 |
| P4 | D(A ← T) − D(V ← T) と D(A ← V) − D(T ← V)：発話ごとの分も声の特徴が大きい | 2 つの量それぞれで，同上 |

- **線引きは暫定**（研究者の指示）．計算の後に主張の書き方を変えてよいが，その場合も上の規則での当たり外れを先に書き，変えた理由を書く．
- **AFEW の注**：AFEW の言葉は音声の書き起こしなので，声と言葉は同じ信号から来る．AFEW を除いた 3 コーパスでの数え（3 中 2 以上）も並べる．
- 外れた予言はそのまま書き，説明をその範囲に限る．書き方の対応：P1・P2 が当たり P3・P4 が外れたら「声の特徴はほかのモダリティの判断を最もよく再現した」までにし，「声に言葉や表情の中身が入っている」とは書かない．P1・P2 も外れたら，説明（3 条件の理由づけ）を主張から外し，3 条件の表だけを残す．

## 6. 記述として出すもの（判定に使わない）

- 3×3 の R，R_shuf，D（行：再現する特徴 A・V・T，列：判断 J_A・J_V・J_T と J_prop）．対角（自分の判断）は出さない．
- MELD・IEMOCAP で 2 つの組が同じ対話を共有する発話を除いた版（実験 3 と同じ agree_nonshared）．
- 3 条件の表の評価の回の版：余地（`expl4_corpus_restored.csv` の room．計算しない），Δ_s，P_s，本番の上がり幅（族 1）．
- 収束と勾配の印（実験 3 と同じ），各組の発話の数と塊の数．

## 7. 範囲の外（シンプルにするため）

融合の分類器，K ≠ 5，全ソース設定，中間層，第 2 のエンコーダ（結果を見てから別に決める），非線形の識別器．

## 8. 限界（結果の文に書く）

- 同じ 4 コーパスと 1 組のエンコーダ．確認ではない．
- J_m は K = 5 の分類器の判断で，当たり方は弱い．J_m の雑音は「同じ判断を 2 つの特徴で比べる」P1・P2 では両方に等しくかかるが，P4 の 2 つの量は判断が違うので比べにくい．
- 発話ごとの分 D は，感情を通らない一致の全部を含む．言葉の中身のほかに，話者，録音の環境，映像の場面など，2 つのモダリティに共通する感情以外の手がかりも入る．D が正でも「声に言葉の中身が入っている」とは言い切れない．
- 線形の識別器での再現．非線形なら変わりうる（実験 12 では隠れ層を足しても読める分はほぼ変わらなかった）．
- MELD と IEMOCAP では，2 つの組が同じ対話を共有する（実験 3 と同じ）．
