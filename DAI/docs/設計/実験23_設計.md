- 位置づけ（`prior-work-diff` は使わない．手法の形を変えない解析の実験のため）：人の感情の知覚の研究は，言葉の中身を隠す操作（低域通過，切り貼り，逆再生など）がどれも言葉以外の手がかりの一部も壊すので，複数の操作を並べて共通に減る部分を内容の寄与と読む（Scherer ほか 1985，J Psycholinguist Res 14(4)，10.1007/BF01067884．Friend & Farrar 1994，JASA 96(3)）．低域通過は Lolli ほか 2015（Frontiers in Psychology，10.3389/fpsyg.2015.01340）の 500 Hz・48 dB/oct にならう（同論文は聞き取りやすさを測っていない）．自己教師ありの音声モデルの特徴にこれらの操作を当て，ほかのモダリティの分類器の判断の再現を測った先行研究は，本体と比較の関門の検索（2026-11-15）では見つかっていない．

## 1. 問い（2 つ）

- **Q1**：言葉を聞き取れなくすると，声の特徴が言葉の分類器の判断を再現する分のうち，感情のラベルと話者の単位を通した一致を除いた部分（D）は，顔の分類器の判断を再現する D より，同じ点数でも同じ割合でも多く減るか．2 つの操作（低域通過と逆再生）の両方で減るか．
- **Q2**：言葉を聞き取れなくした声の特徴は，それでも言葉の分類器の判断を顔の特徴より良く再現するか（記述）．

## 2. 操作：言葉を聞き取れなくした声の特徴

- 波形の作り方は `features/build_audio.py` と同じ（`path_audio` か `path_video` から ffmpeg で 16 kHz モノラル，60 秒で切る）．その波形に次の操作をかけ，そのあとで `build_audio.py` と同じ正規化（平均 0・標準偏差 1）をして，WavLM-large（`microsoft/wavlm-large`）の最後の層を時間方向に平均する（1024 次元）．
  - **L（低域通過）**：4 次の Butterworth の低域通過を前後 2 回かける零位相の濾波（`scipy.signal.butter(4, fc, fs=16000, output="sos")` と `sosfiltfilt`）．振幅は 4 次の 2 乗になり，fc で −6 dB，傾きは約 48 dB/oct（Lolli ほか 2015 と同じ傾き）．fc は下の規則で決める．
  - **B（逆再生）**：波形を時間の向きに反転する（`w[::-1]`）．長い区間の平均のスペクトル（声質，スペクトルの傾き，高い帯域のエネルギー），F0 の分布，声の大きさの分布，発話の長さは元のまま残り，言葉は聞き取れなくなる．時間の向きのある手がかり（音の高さの上がり下がり，語の順序）は反転する．
- 出力は `data/cache/audio_wavlm-lp<fc>_<コーパス>.npz` と `audio_wavlm-rev_<コーパス>.npz`（既存の `audio_wavlm_*` は書き換えない）．台本は `features/build_audio_lowpass.py`（`build_audio.py` の関数を呼び，操作の 1 段だけを足す）．L の特徴は `results/dai23/fc.json` の fc だけで作れる（台本が fc.json を読み，それ以外の fc は試しの名前でしか書かない）．
- **流れの照合**（特徴を作る前）：操作を外した同じ流れで，各コーパスの `sample_id` の sha256 の順の 64 発話の特徴を作り直し，既存の `audio_wavlm_<コーパス>.npz` の X との差の最大が 2 × 10⁻³ 以下であることを確かめる（`--check-identity`．実験 13 の照合の最大 9.16 × 10⁻⁴ の約 2 倍）．
- コーパス：IEMOCAP（取り出しは全発話．解析は即興の部），MOSEI，MELD．**AFEW は外す**（言葉が音声の Whisper の書き起こしなので，実験 14 でも声と言葉の比べから外した）．
- **fc の決め方（操作の確かめ．計算の前に固定）**：
  - 標本：各コーパスの解析に使う発話（`dai_data.load_corpus` の 3 モダリティがそろう発話．IEMOCAP は即興の部，MELD は複数の話者の発話を除いた後）のうち，人の書き起こしが 3 語以上で長さが 30 秒以下の発話を `sample_id` の sha256 の順に 100 本ずつ．テストの分割の発話も入るが，使うのは書き起こしと波形だけで，感情のラベルの値は使わない．
  - 条件：元の音声，逆再生，fc = 500，400，300 Hz の低域通過．Whisper large-v3（`features/build_transcript_afew.py` と同じ設定：英語に固定，書き起こし，ビーム幅 5，サンプリングなし，波形は正規化しない）で書き起こす．
  - 量：**一致率 H/N と，その偶然の水準からの超過**．人の書き起こしと Whisper の出力を小文字にし，角・丸・波括弧の注記と，アポストロフィ以外の記号を除いて単語に分け，参照の単語の列と出力の単語の列の最長共通部分列の長さ H を，参照の単語の数 N で割る（Whisper が無い文を作って足した単語は，参照の単語と順に一致しない限り H を増やさない）．一致率は Whisper の出力が長いだけで上がる（無関係な文でも参照の単語と順に一致する単語がある）ので，偶然の水準を「同じ条件の出力を，同じコーパスの別の発話の参照と組ませたすべての組の H/N の平均」とし，**超過 = H/N の平均 − 偶然の水準** を規則の量にする．参考として単語誤り率 WER と出力の単語の数も出す．
  - 規則：**3 コーパスのすべてで超過が 0.10 以下になる最も高い fc** を使う（0.10 は慣用の値で，根拠は無い）．どれも満たさないときは 300 Hz を使い，`fc.json` の `rule_met` を false にして，結果の文と限界に「Whisper では言葉の中身を十分に消せなかった」と書く．逆再生の超過も同じ基準で `fc.json` の `rev_ok` に書く．
  - 結果の文には，操作と条件ごとに H/N の平均，偶然の水準，超過を並べて書く（超過は H/N の絶対の値に上限を置かないため）．超過には区間を付けない．
  - 台本は `features/check_lowpass_asr.py`，出力は `results/dai23/asr_check.csv`（発話ごと），`asr_check_summary.csv`，`f0_check.csv`，`fc.json`（規則の値と，単語に分ける規則，標本の順，Whisper の revision，transformers と scipy の版，濾波の方式）．
- 操作の確かめで見るのは H/N，偶然の水準，超過，WER，F0 の割合だけである．言葉を消した音声の特徴から作る感情の量は，fc を決めて特徴を作るまで作らない．

## 3. 量

実験 14 の設計 3 節の定義をそのまま使う．違うのは次の点だけである．

- **再現する特徴（生徒）**：A（元の声），V（顔），L（低域通過），B（逆再生）．A と V の J_m の予測と，すべての目標と 2 組の分け方と別の分け方は，実験 14 の保存（`results/dai14/units/<T>_f<f>_r<r>.npz`）をそのまま使う．新しく学ぶのは，L と B の全部の目標と，A の本当の感情 y を目標にした識別器だけである．
- **L と B の前処理**：特徴は `measure/data.py` の `load_group` を `dai_data.load_corpus` から通して読む（npz の `label_4` は使わず，発話一覧のラベルを `sample_id` で貼り直す．取り決め 1〜6）．3 モダリティがそろう発話の集合が元の声と同じであることと，候補の `sample_id` の並びとラベルが実験 14 の保存と同じであることを確かめ，違えば止める．`dai1.Unit` と同じく候補の平均と標準偏差で標準化し（テストの発話は使わない），実験 14 の `aligned_features` で 512 次元にそろえる．
- **目標**：実験 14 の保存の目標（J_A，J_V，J_T，J_prop の真と #shuf・#shufcl）．入れ替えた目標は，実験 14 の規則で作り直して一致を確かめる（一致しなければ止める）．加えて本当の感情 y（真だけ．記述）．
- **読み出し**：R1 だけ（C′ の格子，内側の選び方，C_b，次元は実験 14 と同じ）．**K**：5 だけ．**分け方**：元の 2 組と，r = 0 の単位の実験 14 の別の分け方（`althalf__<i>`）．L と B の別の分け方の予測は，J_A・J_V・J_T の真と #shuf・#shufcl について作る．
- **主の量**（各操作 X ∈ {L, B}，各 T ∈ {IEMOCAP, MOSEI, MELD}．D は D_shufcl）：
  - **M1_X = D(A ← T) − D(X ← T)**：言葉の判断を再現する D が，言葉を消して減った点数．
  - **M2_X = M1_X − [D(A ← V) − D(X ← V)]**：同じ点数で減る帰無に対する，言葉の判断の再現の余分な減り．
  - **M3_X = M1_X − κ_T [D(A ← V) − D(X ← V)]**：同じ割合で減る帰無に対する余分な減り．κ_T = D(A ← T) ÷ D(A ← V) を実験 14 の点推定（R1・#shufcl・K = 5・候補の全体．`predictions.csv` の P3 ÷ P3b）で計算の前に固定する：**κ_IEMOCAP = 19.298 ÷ 6.002 = 3.215，κ_MOSEI = 10.512 ÷ 1.705 = 6.165，κ_MELD = 17.710 ÷ 9.087 = 1.949**（台本は同じファイルから計算し直し，小数 3 桁で一致を確かめる）．
    - **κ は部分集合ごとに固定する**（部分集合で D(A ← T) と D(A ← V) の比が違い，全体の κ を当てると割合の帰無の下でも M3 が 0 にならないため．MELD の共有を除いた版に全体の κ を当てると帰無で約 −1.6(1 − c)）：IEMOCAP 記号の無い版 19.679 ÷ 5.912 = 3.328，MOSEI 記号の無い版 10.070 ÷ 1.742 = 5.779（どの κ も丸める前の値の比を小数 3 桁に丸めた値．表示の分子と分母で割ると 3 桁目が 1 違うものがある），MELD 共有を除いた版 17.472 ÷ 9.793 = 1.784，MELD 記号の無い版 16.585 ÷ 8.469 = 1.958．
    - **M3d_X**：κ を推定した値として扱い，その揺れを 1 次で入れた版．M3 = D(A ← T) − D(X ← T) − κ̂ [D(A ← V) − D(X ← V)]，κ̂ = D(A ← T) ÷ D(A ← V) を 4 つの D の関数とみて 1 次で展開し，係数 D(X ← V)/D(A ← V)，−1，−κ̂ D(X ← V)/D(A ← V)，κ̂ を各 D に掛けた線形の組み合わせの区間を作る（点推定は M3 と同じ）．
    - **dV_X = D(A ← V) − D(X ← V)**（記述）：顔の判断の再現の減り．区間が 0 を下回るコーパスでは，操作の後に顔の判断の再現が増えている．
    - 帰無での値：D(X ← m) = c · D(A ← m)（c は目標によらない割合）なら，M2_X = (1 − c)[D(A ← T) − D(A ← V)] で，実験 14 の値では 3 コーパスとも正になる（D(A ← T) − D(A ← V) は IEMOCAP 13.3，MOSEI 8.8，MELD 8.6）．M3_X = (1 − c)[D(A ← T) − κ_T D(A ← V)] = 0 である．A の項は実験 14 と同じ予測なので，点推定では M3_X = κ_T D(X ← V) − D(X ← T) = D(A ← T) × [D(X ← V)/D(A ← V) − D(X ← T)/D(A ← T)] になり，「顔の判断の D が残った割合 − 言葉の判断の D が残った割合」に D(A ← T) を掛けた量である．
  - **L3_X = D(X ← T) − D(V ← T)**：言葉を消した声が，言葉の判断のうち感情と話者の単位で説明できない部分を，顔の特徴より多く再現する分（記述）．L3 は実験 14 の P4a と V の項と候補を共有するので，P4a の再現として数えない．
- **記述の量**（判定に使わない）：R の版の M1・M2・L3，#shuf を対照にした M1 と L3，D(X ← J_A)，D(X ← J_prop)，R(X ← y) と R(A ← y)，残った割合 D(X ← T)/D(A ← T) と D(X ← V)/D(A ← V)（点推定），書き起こしに記号の無い発話だけの M1・M2・M3・M3d・L3（実験 14 の `nomarker`．κ はこの部分集合の値），選ばれた C′ の数と端の割合，L・B・A の残した分散の割合と有効な階数．

## 4. 区間と検出の見込み

- 実験 14 の設計 4 節と同じ（`dai14.combo_stats`）．IEMOCAP と MELD は塊の jackknife と種の項（t 分布，自由度 max(1, ⌊g_eff⌋ − 1)），MOSEI は塊の重みの引き直し 2,000 回と種の項．r = 0 の単位の別の分け方から，分け方の揺れの保守的な上限を SE² に足す．95% 区間．多重比較の補正はしない．M3 は κ を固定の係数として扱い，M3d は κ の推定の揺れを 1 次で入れる．**同じ割合の帰無に対する判定は，M3 と M3d の両方の区間で行う**（広い方で判定するのと同じ）．台本は，作り直した D(A ← T) ÷ D(A ← V) が固定の κ と一致することを確かめる．主の区間は 2 操作 × 3 コーパス × 4 量（M1，M2，M3，M3d）と MELD の共有を除いた版で 32 本あり，補正はしない．検出の見込み（下）は M3 についての値で，M3d の区間は M3 より広いか同じなので，M3d を足しても見込みは良くならない．記述として 2 つの操作の M3 の差 M3_L − M3_B も出す．コーパスの数え上げは検定ではない（3 コーパスで全部が同じ向きでも符号検定の p は 0.25）．
- 検出の見込み（統計の関門が実験 14 の標準誤差から見込んだ値．推測を含む）：区間の下端が 0 を超えるのに要る大きさは，M1 で IEMOCAP 約 6.2，MOSEI 約 1.2，MELD 約 2.9（共有を除く版 約 4.6），M2 で 約 9.2，1.7，4.1（6.1），M3 で 約 22.7，7.0，6.4（8.6）点である．M1 の上限は D(A ← T)（19.3，10.5，17.7）．**IEMOCAP の M3 は上限を超える大きさを要するので，IEMOCAP では同じ割合の帰無に対する余分な減りを検出できない．**IEMOCAP の M3 の「判定できない」は検出の力が足りないためと書く．

## 5. 予言（計算の前に固定）

主の判定は **K = 5，R1，対照 #shufcl，候補の全体，分け方の揺れを足した区間**．「上回る」は区間の下端 > 0，「下回る」は上端 < 0，それ以外は「判定できない」．MELD は実験 14 と同じく，2 つの組が共有する対話の発話を除いた版でも「上回る」のときだけ数える．

| 予言 | 量 | 主の数え |
|---|---|---|
| E1_L，E1_B | M1_X > 0：言葉を消すと，声が言葉の判断を再現する D が減る | 操作ごとに，3 コーパスのうち 2 以上で上回る |
| E2_L，E2_B | M2_X > 0 かつ M3_X > 0 かつ M3d_X > 0：言葉の判断の再現は，同じ点数で減る帰無と同じ割合で減る帰無の両方より多く減る | 操作ごと・コーパスごとの判定（M1_X・M2_X・M3_X・M3d_X がすべて上回るコーパスを名指しする）．数の基準は置かない（4 節のとおり IEMOCAP では検出できない）．名指しは 2 操作 × 3 コーパスの 6 つの組からの選び出しで，補正はしない．E2_L と E2_B は A の項と κ を共有するので，2 つの操作の一致は独立な 2 回の確かめではない |

L3 には向きの予言を置かない（両側の記述）．前提：実験 14 の D(A ← V)（P3b）の区間は 3 コーパスとも 0 を上回る（IEMOCAP 6.0 [1.2, 10.8]，MOSEI 1.7 [0.9, 2.5]，MELD 9.1 [7.0, 11.2]）ので，顔の判断の D には 3 コーパスとも減る余地がある．

## 7. 範囲の外（理由）

- K = 25，#shuffine，#shufage：実験 14 の副の条件で，この実験の問いは実験 14 の主の作り（K = 5，#shufcl）の上の比べであるため．計算を半分にするため．
- R0：ソースの分類器（元の声で学んだ）を出発点にするので，L と B に当てられない．
- R1fixC：C′ の選び方の感度で，格子の全点の予測を保存する必要がある．この実験では選ばれた C′ の端の割合を出す（6 節）．
- AFEW（言葉が音声の書き起こし），言葉を消した声で学び直した分類器のテストの UAR（ソースの分類器も学び直す必要がある），ほかの fc での主の量，ほかのエンコーダ，人による聞き取りの試験，非線形の識別器，入れ替えの繰り返し．

- 台本：`features/check_lowpass_asr.py`（操作の確かめと fc），`features/build_audio_lowpass.py`（特徴．`--op lp` と `--op rev`），`exp/dai23.py`（段は `selftest`，`units`，`summary`．実験 14 の `dai14.py` の関数を import して使い，`dai14.py` は変えない）．
- 出力：`results/dai23/asr_check*.csv`，`f0_check.csv`，`fc.json`，`results/dai23/units/<T>_f<f>_r<r>.{npz,csv}`，`results/dai23/summary/{main,descriptive,assumptions}.csv`，`criteria.json`，`convergence.json`，`provenance.json`，`provenance_log.jsonl`（コミット，dirty，台本の sha256，fc.json と特徴のファイルの sha256，部分集合ごとの κ，transformers・scipy・ffmpeg の版）．特徴の npz に濾波の方式と WavLM の revision を残す．単位の npz に L と B の予測（元の分け方と別の分け方），確率（元の分け方），内側の曲線を残し，後から別の部分集合や量を学び直さずに出せるようにする．

- 順序：(1) 試し（`--check-identity`，`--verify`，L と B に元の声の特徴を入れた退化の試し（M1，M2，M3，M3d が 0 に近いはず）．退化の試しの単位と集計は `results/dai23/degenerate/` に残す．単位は 3 コーパスの f0 r0 と f1 r1 の 6 つ．`--verify` は真の目標の予測だけを照合するので，入れ替えた目標の予測の作り直しによるずれは退化の試しの M1〜M3d で測り，結果の文に検出に要る大きさと並べて書く），(2) 操作の確かめ → fc.json，(3) L と B の特徴，(4) 単位，(5) 集計．
- 計算機：研究室の GPU（RTX A5000），tmux の `mer-da`．GPU のメモリは 6 割に抑える．実験 22 の計算（別の作業木）が終わってから流す．所要の見込み：操作の確かめ 20〜40 分，特徴の取り出し 2 つで 1〜1.5 時間（実験 13 の取り出しの 1 発話あたり 0.04〜0.06 秒から），単位 2〜3 時間（実験 14 の 1 単位 72〜136 秒のうち，生徒 2 つ・R1・K = 5 の分）．

## 9. 限界（結果の文に書く）

- 低域通過は言葉の中身のほかに，fc より上の周波数にある声の手がかり（声質，スペクトルの傾き，子音の強さ）も消す．逆再生は言葉の中身のほかに，時間の向きのある手がかり（音の高さの上がり下がりの向き，語の順序）を反転する．どちらも WavLM の学習で見ていない種類の音声になる．2 つの操作で共通に減った分を言葉の中身の寄与と読むが，2 つが共通に壊すほかの手がかりがあれば，その分も入る．
- WavLM の最後の層は時間平均なので，逆再生でも順序に依らない音素の情報（母音の分布など）が平均の中に残りうる．操作の確かめは Whisper の書き起こしで測り，WavLM の特徴に音素の手がかりが残るかは測らない．
- κ は実験 14 の点推定で固定する（M3）．揺れを 1 次で入れた M3d と両方で判定するが，1 次の近似は D(A ← V) が小さい MOSEI（1.7．κ = 6.2）で粗い．
- E2_L と E2_B は A の項と κ を共有するので，2 つの操作で E2 がそろっても独立な 2 回の確かめではない．
- 顔の特徴にも口の動きのように言葉と結びつく手がかりが入りうるので，顔の分類器の判断は言葉の中身と無関係とは限らない．M2・M3 はこの分だけ言葉の判断の再現の余分な減りを小さく見せる向きである．
- fc は 1 つ（2 節の規則で選ぶ）．同じ 3 コーパスと 1 組のエンコーダ．確認ではない．参照の項は設計の前に見た値なので，選択の偏りが予言の向きに入りうる．
- IEMOCAP の 2 つの組は即興の 8 つの筋書きを共有する．元の声の特徴が筋書きの言葉を手がかりに言葉の判断を再現していれば，言葉を消すとその分が減るので，IEMOCAP の M1 は予言の向きに偏りうる（M2・M3 では顔の判断の項が筋書きを共有しない分だけ偏りが残る）．
- D には，言葉の中身のほかに，覚醒度，話者の単位の中で変わる属性，発話の長さ，録音や場面の手がかりを通した一致も入る．発話の長さは 2 つの操作で変わらないので，L と B の D に残る．実験 14 の 9 節の限界（MELD の顔は話者でない人の顔でありうる，など）はそのまま当てはまる．
