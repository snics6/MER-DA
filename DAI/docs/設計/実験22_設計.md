## 1. 問い

評価の回の 4 コーパスで，K = 5（主）と K = 25（副）のとき，融合の分類器について次の 2 つはいくらか．

- **当たる幅 Δ_AVT**：K 本を除いた候補の上で，提案の疑似ラベル q の判定の UAR から，融合の K 本だけの分類器の UAR を引いた値．
- **再現できる分 P_AVT**：q の判定を目標にして融合の特徴の上で線形の識別器を学び，候補を 2 組に分けて交差に予測したときの UAR から，同じ発話の上の融合の K 本だけの分類器の UAR を引いた値．

定義は実験 14 の Δ_s と「評価の回の真似できる分 P_s」（`docs/設計/実験14_設計.md` 3 節の 46〜47 行）と同じで，生徒 s を融合 AVT にしたものである．

## 2. データと単位

- 単位：評価のターゲット T ∈ {AFEW, IEMOCAP, MELD, MOSEI} × 分割 f ∈ {0, …, 4} × 種 r ∈ {0, …, 9}（実験 1 の固定のファイルの n_seeds_eval）．各コーパス 50 単位，計 200 単位．実験 14 と同じ．種が変えるのは K 本の抜き方だけで，分割と候補と 2 組は種で変わらない．
- 融合の特徴：実験 1 の生徒 AVT の特徴（声 1,024 次元，顔 512 次元，言葉 768 次元をつないだ 2,304 次元．候補の上で次元ごとに標準化．`dai1.U.Xp["AVT"]`）．次元ごとの標準化なので，`Xp["AVT"]` は `Xp["A"]`・`Xp["V"]`・`Xp["T"]` を横につないだものと同じである（単位ごとに差の最大を記録する）．
- 融合の K 本だけの分類器：実験 1 の `none`（`dai3.Saved.none("AVT", K)`．実験 1 の評価の回が保存した W・b をそのまま使う）．
- 候補：単位の候補の全部．Δ と P の UAR は K 本を除いた候補の上で測る（実験 14 と同じ）．候補には K 本と同じ話者の発話が残る（IEMOCAP は同じセッション，MOSEI は同じチャンネル）．3 条件の表の余地と gain はテストの発話（話者を分けた発話）の上の量なので，同じ表の中で性質の違う量が並ぶ．
- 塊と 2 組の分け方：実験 14 と同じ（`dai_data.clusters`，`dai3.pool_halves`．ラベルを使わない）．MELD は 2 つの組が同じ対話を共有しうる．

## 3. 量

- **提案の疑似ラベル J_prop**：実験 1 の主の版（固定のファイルの `main`．K = 5・25 とも `one`）の疑似ラベル `prop_one` の判定．実験 14 と同じ作り（`dai3.pool_teachers`）．
- **K 本だけの分類器の判定 J_none**：融合の `none` の候補の上の argmax．
- **融合の行に固有の作り（第 2 版で足した．査読想定の affect の A1，compare の 1・2，define の 2）**：
  - `prop_one` は，声・顔・言葉の線形の識別器（`ret_A`・`ret_V`・`ret_T`）の確率の積である（`dai1.product`）．確率の積の argmax は，3 つの識別器の点数（ロジット）の和の argmax と同じである（確率を 10⁻¹² で切る発話を除く）．融合の特徴は 3 つの特徴を同じ標準化のまま横につないだものなので，**3 つの識別器の重みを横につなぎ切片を足した線形の識別器が，融合の特徴の上で J_prop を出す**．したがって融合の行では，読み出しが q を全部の候補で再現すれば P_AVT = Δ_AVT になる．P_AVT − Δ_AVT ＝ UAR(読み出し) − UAR(J_prop) は，読み出しが q と違う判定を出した発話から生じ，正にも負にもなる（違う判定が本当の感情に当たる発話が多ければ P は Δ を超える．R0 は出発点へ引き戻すので，出発点が当たる発話で起こりうる）．**P は Δ で上から抑えられない．**読み出しの不足は P と Δ の差ではなく，読み出しと q の一致の割合で書く．**P_AVT < Δ_AVT を条件 3 の欠けの根拠にせず，P_AVT が小さくても「融合の特徴に q の手がかりが無い」と書かない．P_AVT > Δ_AVT になったらそのまま書き，読み出しと q の一致を並べ，「q 以上を取り込んだ」とは書かない．**単位ごとに，J_prop と，保存した `p2_K<K>_ret_<m>_W`・`_b` をつないだ線形の判定の一致の割合（見込みは 1.0）と，確率が切られた発話の数を記録する．
  - `ret_m` は，融合の K 本だけの分類器の確率を疑似ラベルにし，K 本のラベルを足して学び直した識別器である（`dai1.pass2`）．このため融合の行の Δ は，q と，q の材料を作った分類器自身との差である．声・顔・言葉の行の Δ は，q と，q の材料より少ないモダリティを見る分類器との差で，同じ種類の量ではない．記述として，K 本を除いた候補の上の J_prop と J_none の κ を単位ごとに出す．
- **R0（実験 1 の作り）**：融合の生徒の出発点（`u.start["AVT"]`．ソースの識別器の重みの平均）から，(AVT, K) の実験 1 の引き戻し（`sv.teth`）で J_prop を硬いラベル（感情の釣り合いの重み）にして片方の組で学び，もう片方の組で予測する．実験 14 の `fit_r0` をそのまま使う．引き戻しの強さは，K 本だけの分類器のために選んだ値の流用である．損失を本数で割る学習器なので，R0（学ぶ本数 315〜7,453）の罰則の実効の強さは K 本だけの分類器（K = 5 で 20 本）より 16〜370 倍弱い．学ぶ本数 ÷ 次元は AFEW 0.14，IEMOCAP 0.46 で，解は多くの方向で出発点に留まりうる．このため P には出発点と K 本だけの分類器の差が入りうるので，出発点の判定を保存し，`uar_start`，`start_minus_none`（出発点 − K 本だけ），`R0_minus_start`（R0 − 出発点）と，R0 と出発点の判定の一致，R0 と J_prop の判定の一致を出す．出発点への依存は同じ R0 の規則で学ぶ声・顔・言葉の行（実験 14）にも当てはまる．論文では融合の行だけの性質として書かない（声・顔・言葉の行の出発点の判定は実験 14 の npz にあり，学び直さずに同じ量を出せる）．
- **R1（そろえた読み出し）**：融合の特徴を候補の上の主成分で 512 次元にそろえ，出発点 0，切片の C_b = 1，重みの C′ を格子 {10⁻⁶, …, 10} から，学ぶ側の組を塊で 2 つに分けた内側の交差の予測で J_prop との一致が最大の点を選ぶ（同点は小さい C′）．実験 14 の `fit_r1` をそのまま使う．512 次元は実験 14 の声・顔・言葉の R1 と同じ次元である．2,304 次元から 512 次元に切るので，J_prop を出す線形の規則が切った後の空間に入らないことがある．
- 出す量（コーパス × K ごと．実験 14 の `conditions.csv` と同じ名前）：`uar_none`（J_none の UAR），`uar_pseudo`（J_prop の UAR），`delta`（`uar_pseudo` − `uar_none`），`uar_imitation_R0`，`imitable_R0`（`uar_imitation_R0` − `uar_none`），`uar_imitation_R1`，`imitable_R1`，`uar_start`（出発点の判定の UAR），`start_minus_none`，`R0_minus_start`．UAR は本当の感情に対する値で，候補のうち K 本を除いた発話の上で測る．
- **行どうしの差（第 2 版．stats の 1）**：`delta_minus_delta_<s>`（s = A，V，T）＝ Δ_AVT − Δ_s．q は 4 つの行で共通なので，これは単位ごとに UAR(J_none,s) − UAR(J_none,AVT) と同じ値になる．実験 14 の単位の npz の `none__K<K>__<s>` から，同じ候補・同じ塊で作る．
- **MELD の共有の対話を除いた版**：MELD では，2 つの組が共有する対話の発話を除いた候補の上でも全部の量を出す（実験 14 の npz の `nonshared`）．融合の特徴は言葉を含むので，共有の対話は P_AVT を大きく見せる向きに働きうる．

## 4. 区間

実験 14 の 3 条件の表と同じ作りにする（`dai14.combo_stats`）．単位ごとに塊ごとの数を作り，塊の実効の数 g_eff が 20 未満（AFEW，IEMOCAP，MELD）は塊を全分割から同時に除く jackknife と種の項，20 以上（MOSEI）は全分割で共通の塊の重みの引き直し 2,000 回と種の項．95% 区間．分け方の揺れは足さない（実験 14 の 3 条件の表も足していない．論文の表 8.2 は足しているので，表の注で区別する）．多重比較の補正はしない．区間は再現の識別器と J_prop と J_none を学び直さないので，狭めに出る．融合は次元が大きく AFEW では学ぶ本数が次元の 0.14 倍なので，この影響は声・顔・言葉より大きくなりうる．

MOSEI の区間は乱数の引き直しで作るので，同じ量（q の UAR など）でも実験 14 の行と少しずれる．表で 1 つの量に 1 つの区間を書くときは，その出所を表の注に書く．

## 5. 書き方

- 3 条件の表の融合の 4 行の「K 本だけ」「q」「当たる幅 Δ」「再現できる分 P」の欄を，K = 5 の `uar_none`，`uar_pseudo`，`delta`，`imitable_R0` で埋め，区間を添える．表の注に，各コーパス 50 単位であること，種が変えるのは K 本の抜き方だけであることを書く．K = 25 と R1 は付録か注で並べる．
- **融合の行の P の扱い**：表の題か注と P の定義の文に，融合の行では q を融合の特徴の線形の識別器で厳密に表せるので，読み出しが q を完全に再現すれば P = Δ になること，P と Δ の差は読み出しが q から外れた分で正にも負にもなることを書く．P > Δ の行はそのまま書く（3 節）．融合の行の P を声・顔・言葉の行の P と同じ意味で並べない．融合の行に条件 3 を当てはめる文は書かない．融合の行には P ÷ Δ の割合を書かない．
- **融合の行の Δ の扱い**：q の材料が融合の K 本だけの分類器を写したものであることを，条件 2 を当てはめる文に書く．
- **R0 と R1 が分かれたとき**：融合の行の P で，区間の下端が 0 を超えるかが R0 と R1 で分かれたら，本文に両方を書く（第 1 版の 60 行の AFEW の言葉と同じ扱い）．
- **行どうしを比べる文**：融合の行と声・顔・言葉の行の Δ を比べる文は，直接の差の区間（`delta_minus_delta_<s>`）で書く．この差は q に依らず，候補の上での K 本だけの分類器どうしの UAR の差に等しいので，文でもそう書く（「Δ の差は，K 本だけの分類器の当たり方の差である」）．区間が 0 を含むことを「条件が欠けた」の根拠にしない．分類器の行は同じ候補と同じ q を共有するので，分類器ごとの数え上げは検定ではないと書く．
- **数え上げ**：論文の第 1 版の 8 節の冒頭の数え上げは，条件 1（余地）と条件 2（当たる幅）は融合を含む 4 つの行で数え，条件 3（再現できる分）は声・顔・言葉の 3 つの行で数える．
- **MELD の共有を除いた版**：候補の約 3 割（分割 0 で 5,995 本のうち 1,715 本）しか残らない．発話の数と塊の数を添え，全部の版との差を「共有の効果」と読まない．区間は全部の候補の塊の実効の数で作るので，自由度が大きめに取られ狭めに出る．
- **P と Δ の大小**：P と Δ の大小は，対の差 `R0_minus_pseudo`（＝ P_R0 − Δ）と `R1_minus_pseudo` の区間で書く．
- **出発点への依存**：4 つの行に同じ量（`start_minus_none`，`R0_minus_start`，R0 と出発点・J_prop の一致，κ）を出し，同じ規則（8 節）で書く．声・顔・言葉の行の量は実験 14 の npz（`start__<s>`，`K<K>__main__R0__<s>__prop_one__true`）から学び直さずに作る．結果の文で出発点を書くときは「ターゲットのラベルを使わない出発点（ソースの識別器の重みの平均）」と書く．
- 文では点推定と区間を並べ，「区間の下端が 0 を超えた」「区間が 0 を含んだ」とだけ書く．3 条件の当てはめは値を見た後に行ったと書く．
- 仮のターゲットの値（下調べ 11）と評価の回の値の比べは，区間の無い点推定どうしの比べであると書く．違っても理由は名指ししない．2 つの作りの違い（仮のターゲットの回の P はリッジ回帰の交差予測，評価の回の P は R0 の線形の識別器）を書く．

- **解き直しで通した行が多すぎたら止める**：解き直しは同じ入力のまま基準を厳しくするだけなので，入力が系統的にずれていると全部の行が「同じ予測」で通りうる．コーパスごとに，通した行が 4 行とそのコーパスの R0 の行（100 行）の 25% の大きいほうを超えたら止める（単位の段ではそのコーパスを流し終えた時点で数え，要約の段でもコーパスごとに数える）．通した行の数，外れた差の最大，解き直しの勾配の最大と止まりの数（10⁻¹⁰ の解き直しは基準に届かずに止まることがある）は結果の文の限界に必ず書く．
- **止まった単位を流し直すとき**：止まった単位のファイル（`results/dai22/units/<T>_f<f>_r<r>.{npz,csv}`）と `check_fail_*.csv` を調べてから消し，そのうえで流し直す（消さないと，台本はその単位を済みとして飛ばし，要約の段で止まる）．
- **流し直しで素通りさせない**：単位の段は照合の前に単位のファイルを書く．要約の段で，照合が外れたまま解き直しで通っていない行が 1 行でもあれば止める（`--allow-partial` でも止める）．
- J_none と J_prop の K 本を除いた候補の上の UAR が，実験 1 の評価の回の保存と 10⁻⁶ 以内で一致する．J_none は `p2.csv` の teacher = none_AVT の `uar_pool`．J_prop は `p3.csv` の `_teacher_stats`・teacher = one の `uar_pool`（段 3 が受け取った J_prop で，保存した float32 の重みと同じ経路）か，`p2.csv` の product (1.0, 1.0, 1.0) の `uar_pool`（学んだ直後の重みの経路）のどちらかと一致すればよい．差は 3 つとも単位の csv に残し，照合に読む `p2.csv`・`p3.csv` の sha256 も残す．
- 要約の段で，`uar_pseudo` の点推定が実験 14 の `conditions.csv` の `uar_pseudo`（コーパスと K の組ごとに 3 行，計 24 行．生徒に依らない量）と 1e-9 以内で一致する．

## 9. 限界（結果の文に書く）

- 実験 14 の 3 条件の表の限界（同じ 4 コーパスと 1 組のエンコーダ，線形の識別器，区間は識別器を学び直さない，コーパスの数え上げは検定ではない，3 条件の表は結果を見てから立てた説明の材料）がそのまま当てはまる．
- 融合の行の余地と gain，q の UAR，声・顔・言葉の行の値，仮のターゲットの融合の Δ と P，融合の K 本だけの分類器と積のテストの UAR を見た後に行った．
- 融合の行の P は，読み出しが q を完全に再現すれば Δ に等しくなる量である．Δ との差は q と違う判定の発話から生じ，正にも負にもなり，大きさは感情ごとの不一致の割合の平均を超えない（3 節）．融合の行の Δ は，q と q の材料を作った分類器自身の差である．
- R0 は実験 1 の引き戻しの強さ（K 本だけの分類器のために仮のターゲットの回で選んだ値）と出発点に依る．融合の特徴は次元が大きく，学ぶ側の組の本数が次元より少ない（AFEW，IEMOCAP）．
- R1 は 2,304 次元を 512 次元に切る．
- 候補には K 本と同じ話者の発話が残る．MELD は 2 つの組が同じ対話を共有しうる（共有を除いた版を並べる）．IEMOCAP は 2 つの組が即興の 8 つの筋書きを共有し，融合の特徴は言葉を含むので，P_AVT を大きく見せる向きに働きうる．
- AFEW の言葉は Whisper の書き起こしで，声と言葉の特徴は同じ音から来る（実験 14 の 9 節）．
- 感情ごとの主張はしない．発話ごとの予測を保存するので，求められれば学び直さずに出せる．
