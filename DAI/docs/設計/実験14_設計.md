## 1. 問い（2 つ）

- **Q1**：あるモダリティの判断を，別のモダリティの特徴からどれだけ再現できるか．特に「言葉の判断」と「顔の判断」を，声の特徴は他方の特徴より良く再現するか．
- **Q2**：その再現は，感情のラベルと話者の単位（3 節の #shufcl の層）を通した一致を除いても残るか．残る分を D と呼ぶ．

記述として，主張の 3 条件の表（`DAI/docs/主張_2026-11-12.md` 2 節）の条件 2・3 を，下調べではなく評価の回の値で作り直す．

## 2. データと単位

- 評価の回の単位：評価のターゲット T ∈ {AFEW, IEMOCAP, MELD, MOSEI} × 分割 f ∈ {0, …, 4} × 種 r ∈ {0, …, 9}（実験 1 の固定のファイルの n_seeds_eval．`results/dai1/eval/units/`）．計 200 単位．
- K = 5 を主，K = 25 を副の条件にする（同じ規則で判定し，並べて書く）．学び直す側（再現する側）の特徴は声（A．WavLM の最後の層），顔（V．AffectNet の表情で微調整した ResNet-50），言葉（T．RoBERTa．AFEW は Whisper の書き起こし）．融合は扱わない．
- 候補：単位の候補（ラベル無しの発話）全部．K 本のラベル付きの発話も候補に含まれ，R の計算に入る（実験 3 と同じ）．
- **塊**（`dai_data.clusters`．区間の jackknife と 2 組の分け方の単位）：IEMOCAP はセッション（各セッションに女性と男性の話者が 1 人ずつ），AFEW は俳優と作品をつないだ成分（1 つの塊に複数の俳優），MELD は話者，MOSEI は YouTube のチャンネル（無ければ動画）．
- 候補を塊で 2 組に分ける（実験 3 の `pool_halves`．ラベルを使わない）．話者は 2 組をまたがない．MELD は 2 つの組が同じ対話を共有する発話がありうる（`dlg_pool` で数える）．IEMOCAP は 2 つの組が即興の 8 つの筋書きを共有する．MOSEI は同じ人物の別のチャンネルの動画が 2 つの組に分かれうる（P2 の R の差に予言の向きの偏りが入りうる．#shufcl は D からこの分をおおむね除く）．AFEW の `gender` は 7 人の俳優で発話ごとに食い違う（790 本のうち 50 本）．IEMOCAP の `utterance_speaker` は sample_id の話者の文字と全部一致する．

## 3. 量

- **判断 J_m**：モダリティ m の K 本だけで学んだ分類器（実験 1 の `none`．実験 3 の `single_m`）の，候補の上の判定（argmax）．
- **提案の疑似ラベル J_prop**：実験 1 の主の版（固定のファイルの `main`．K = 5・25 とも `one`）の疑似ラベル `prop_one`（3 つの確率の積）の判定．
- **再現できる度合い R(s ← m)**：J_m を硬いラベル（感情の釣り合いの重み）にし，生徒 s の特徴の上の線形の識別器を片方の組で学び，もう片方の組で予測する．入れ替えて両方の組の予測をそろえ（交差の予測），候補全体で J_m を正解とした釣り合いの一致（UAR と同じ式．現れた感情だけで平均するので，偶然の水準は 100 / 現れた感情の数）を取る．読み出しは 2 つ：
  - **R1（そろえた読み出し．主）**：生徒の特徴を候補の上の主成分で 512 次元（顔の特徴の次元）にそろえ（ラベルを使わない．次元あたりの分散の平均を 1 にする．残した分散の割合と，有効な階数 exp(−Σ p_i log p_i)（p_i は固有値の割合）を記録する），出発点 0，切片の C_b = 1，重みの C′ を格子 {10⁻⁶, 10⁻⁵, 10⁻⁴, 10⁻³, 10⁻², 10⁻¹, 1, 10} から選ぶ．C′ は，学ぶ側の組を塊で 2 つに分けた内側の交差の予測で，2 つの小さい組での目標の判断 J_m との一致の平均が最大の点（同点は小さい C′）．本当の感情のラベルは使わない．入れ替えの対照には，同じ (生徒, 目標, 組) の真の目標で選んだ C′ をそのまま当てる．C′ が小さいと重みは 0 に近づくが，判定（argmax）は感情ごとの重みつきの平均の差の向きに近づくので，下端でも識別器はつぶれない．
  - **R1fixC（C′ を固定した感度）**：K = 5，元の分け方，判断 J_m の真と #shufcl について，格子の全点で外側を解いた予測を残す（AFEW は #shufage も）．コーパスごとに，組 0 で学んだときに R1 で選ばれた C′ の最頻値（同数は小さい値）を組 1 の発話の予測に，組 1 の最頻値を組 0 の発話の予測に当て（同じ単位の中では予測する組の判断が C′ に入らない．最頻値はコーパスの全単位から取るので，別の分割で学ぶ側に入った同じ発話の判断はわずかに入る．値はコーパスに 1 つで全部の生徒と対照に共通なので，影響は無視できる大きさとみなす），全部の生徒と真の目標・対照に同じ値を当てた版で P1〜P4b を作る（候補の全体と，MELD の共有の対話を除いた版）．
  - **R0（実験 1 の作り．副と照合）**：生徒の出発点（`u.start[s]`）から，(s, K) の実験 1 の引き戻し（`sv.teth`）で学ぶ（実験 3 の 2 節と同じ）．実験 3 の定義（2 つの組の値の平均）を保存の `repro_units.csv` と照合し（単位あたり 18 行．相手の無い行か差が 0.001 を超えた行があれば止める）．
  - **学び直す前の一致 R_start**（記述．R0 だけに当たる）：生徒の出発点の判定と J_m の一致．
- **入れ替えの対照**（目標の判断を層の中で入れ替える．入れ替えは単位・K・目標・版の名前から決まる乱数で 1 回．同じ判断の入れ替えた目標は 3 つの生徒で共通）：
  - **#shuf**（副）：本当の感情が同じ候補の間で入れ替える．
  - **#shufcl（主）**：（本当の感情，塊，性別）が同じ候補の間で入れ替える．性別は IEMOCAP（`utterance_speaker`．セッションと合わせると話者と同じ層）と AFEW（`gender`）で使い，MELD（塊が話者なので性別は塊の中で一定）と MOSEI（性別の注釈が無い）では空にする．性別を通した一致が D から除かれるのは IEMOCAP・AFEW・MELD である．感情ごと・話者の単位ごとの判断の分布を保ち，発話ごとの対応だけを壊す．話者の単位に固有の偏りと，性別のように 2 組をまたいで共通な属性を通した一致は，この対照にも残るので D から除かれる．入れ替えで目標が実際に変わった発話の割合（frac_changed）と，1 本だけの層に入る発話の割合を出す．
  - **#shuffine（副．IEMOCAP・MOSEI だけ）**：#shufcl の層をさらに，IEMOCAP は（元のラベル emotion_raw，覚醒度の 3 区分），MOSEI は（6 つの感情の強さ int_* の最大の 3 区分．その発話の 4 つのラベルの感情の強さではない）で分けた層の中で入れ替える．3 区分の境は単位の候補の上で，本当の感情ごとに取った 3 分位（同じ値が多いので 3 等分にはならない．テストの発話を使わない）．#shufcl と入れ子である．ただし層が細かいほど入れ替えで目標が変わらない発話が増えて D は 0 に寄るので，D_shuffine と D の違いを覚醒度や強さに帰さない（判定の違いと frac_changed を並べて書くだけにする）．
  - **#shufage（副．AFEW だけ）**：#shufcl の層をさらにデータセットの注釈の年齢 actor_age（作品の時点の値で，同じ俳優に複数の値が付くことがある）の 3 区分（候補の上の 3 分位．欠けは別の区分）で分けた層の中で入れ替える．AFEW の層には同じ性別の複数の俳優が入り，年齢の手がかりを通した一致が D に残りうるため．年齢の区分は俳優も分けるので，#shufage は年齢だけでなく俳優ごとの偏りの一部も除き，入れ替えで目標が変わらない発話も増える（1 本だけの層は約 2 割）．AFEW が #shufage の規則で数えから外れても，それを年齢に帰さず，判定と frac_changed を並べる．0.40 の基準を #shufage にも当てる．
- **D_x(s ← m) = R(s ← m) − R_x(s ← m)**（x は shuf，shufcl，shuffine，shufage）．D_shufcl を単に D と書く．特徴が感情と話者の単位の手がかりしか持たないなら 0 に近くなる．負の D は「入れ替えた目標のほうが再現しやすい」で，作りの上では期待値 0 の揺れとして扱い，大きく負なら書く．
- 確率：K = 5，元の分け方の交差の予測の確率（float32）を，R0・R1 の全部の版（真と各対照）で保存する．argmax の代わりに確率で測った D を，学び直さずに後から出せる．C′ が格子の下端の識別器では 4 つの感情の確率がどれも 0.25 に近いので，確率で測る量を使うときは，判定には保存した予測を使い，確率は平均の量（正解の感情の確率の平均など）にだけ使う．
- **当たる幅 Δ_s**（記述．候補の上）：候補のうち K 本を除いた発話の上で，J_prop の UAR（本当の感情に対して）− s の K 本だけの分類器の UAR．並べて J_m の UAR（uar_judge）も出す．
- **評価の回の真似できる分 P_s**（記述．候補の上）：J_prop を目標にして学んだ識別器の交差の予測の，K 本を除いた候補の上の本当の感情に対する UAR − 同じ発話の上の s の K 本だけの分類器の UAR．R0 と R1 の両方．下調べ 11 の「真似できる分」（リッジ回帰の交差予測）とは作りが違うので，表では「評価の回の真似できる分」と書く．

## 4. 区間

- 単位 (f, r) ごとに，候補の塊ごとの数（`dai1_stats.counts` と同じ形）を作り，量の線形の組み合わせ（差，差の差）を単位ごとに計算する．
- 塊の実効の数 g_eff（`dai1_stats.g_eff_of`．コーパス全体の塊から）が 20 未満（AFEW，IEMOCAP，MELD）は，塊を全分割から同時に除く jackknife と種の項（`dai1_stats.effect_stats` と同じ式．自由度 max(1, ⌊g_eff⌋ − 1)，t の 97.5% 点）．20 以上（MOSEI）は，全分割で共通の塊の重みを 1 組引く引き直し 2,000 回と種の項（実験 12 の `effect_stats_pool` と同じ式）．
- **分け方の揺れ**：R は候補を 2 組に分ける分け方に依る．r = 0 の単位（各分割に 1 つ）で，K = 5・R1 について，判断 J_m の真と #shuf・#shufcl を，塊を乱数の順に並べて本数の少ない組へ配る別の分け方でも測る（元と同じか裏返しの分け方は除く．AFEW・MELD・MOSEI は 4 通り，IEMOCAP は作れる 2 通り）．分割 f ごとの分け方の間の分散 v_f を求め，**主の区間には保守的な上限 ((1/F) Σ_f √v_f)² を SE² に足す**（主の分け方は同じ規則で作るので，分割の間で分け方の誤差がそろいうる）．独立とみなした値 (1/F²) Σ_f v_f も列に残す．別の分け方の予測が無い量（R0，K = 25，#shuffine，#shufage，J_prop，R1fixC）には足さない．このため AFEW の #shufage の確かめは，揺れを足さない狭い区間で判定される（frac_changed が小さいと点推定も 0 に寄るので，どちらの向きに働くかは決まらない）．主の行で値が使えた分割の数 `n_split_folds` が 5 未満のときは，使えない分割の揺れを 0 として足すので，その数を書く．descriptive・conditions・robustness の区間には分け方の揺れが入らない（R1 − R0 の名指しの区間は狭めに出る）．共有の対話を除いた版と記号の無い版は，元の分け方の部分集合の印を別の分け方にも当てて足す．
- **主と副の判定を比べるときは，両方とも分け方の揺れを足さない区間（lo_ns・hi_ns）で比べる**（区間の作りの違いだけから判定が食い違うのを避けるため）．主の当たり外れは，揺れを足した区間で判定する．
- 区間は再現の識別器を学び直さない（塊を除いた値は保存した予測の数から計算する）．入れ替えの対照は 1 回で，入れ替えの揺れは種の項に入る分だけを含む．
- 作りの違いの差の区間（`robustness.csv`）は K = 5 の候補の全体だけで作る．K = 25，部分集合，R1fixC の #shufage で主と副の判定が分かれたときは，原因を名指しせず判定を並べる．R1 − R1fixC の差には，C′ を生徒と目標ごとに選ぶ効果と，対照に真の目標の C′ を当てる効果の両方が入る．比べる判定は，数えの規則を当てる前のコーパスごとの判定である．予言の当たりの数を独立な証拠として足し合わせない（予言どうしが同じ量を共有し，前提の規則でも結びついている）．
- 区間は 95%．多重比較の補正はしない（結果の文に「多重比較の補正をしていない」と書く）．余地（`expl4_corpus_restored.csv` の値）には区間を付けない．IEMOCAP は塊が 5 つで自由度が小さく，区間が広い（検出しにくい）．コーパスを単位にした数え上げは検定ではない（3 コーパスで全部が同じ向きでも符号検定の p は 0.25，4 コーパスで 0.125）．主張はコーパスごとの記述にとどめる．

## 5. 予言（計算の前に固定．線引きは暫定）

量はすべて各評価のターゲットごと．主の判定は **K = 5，R1，対照 #shufcl，候補の全体，分け方の揺れを足した区間**．「上回る」は区間の下端 > 0，「下回る」は上端 < 0，それ以外は「判定できない」．

| 予言 | 量 | 主の数え |
|---|---|---|
| P1 | R(A ← T) − R(V ← T)：言葉の判断を，声の特徴は顔の特徴より良く再現する | AFEW を除く 3 コーパスで，上回るが 2 以上 |
| P2 | R(A ← V) − R(T ← V)：顔の判断を，声の特徴は言葉の特徴より良く再現する | 4 コーパスで 3 以上 |
| P3 | D(A ← T)：声の特徴が言葉の判断を再現する分は，感情と話者の単位を通した一致を除いても残る | AFEW を除く 3 コーパスで 2 以上 |
| P4a | D(A ← T) − D(V ← T) | AFEW を除く 3 コーパスで 2 以上 |
| P4b | D(A ← V) − D(T ← V) | 4 コーパスで 3 以上 |

- **差の予言の前提**：P4a は同じコーパスで P3（D(A ← T)）も上回るときだけ，P4b は同じコーパスで P3b（D(A ← V)．P4b の前提として足した記述の量）も上回るときだけ「上回る」に数える（D(V ← T) や D(T ← V) が負に揺れただけで差が正になる場合を数えないため）．
- **AFEW の年齢**：AFEW の P3・P3b・P4a・P4b は，#shufcl に加えて #shufage でも上回るときだけ「上回る」に数える．AFEW がこの規則だけで外れて P4b が当たらなかったときは，frac_changed と規則を当てない AFEW の判定を並べ，「AFEW は年齢の層で入れ替えると目標がほとんど変わらず判定できなかった」と書き，P4b の外れを声の D が無い根拠にしない．#shufage の確かめは区間が狭いが点推定も 0 に寄るので，「通りやすい」とは書かない．

- **AFEW を除く理由**：AFEW の言葉は音声の書き起こし（Whisper）なので，声と言葉の特徴は同じ信号から来る．言葉の判断 J_T を使う P1・P3・P4a は AFEW を主の数えに入れず，4 コーパスでの数えを並べる．
- **MELD**：候補の全体で「上回る」でも，2 つの組が共有する対話の発話を除いた版で「上回る」でなければ，主の数えで MELD を「上回る」に数えない．
- **副の条件**（R0，R1fixC，K = 25，対照 #shuf と #shuffine，共有の対話を除いた版，記号の無い発話だけの版）も同じ規則で数え（#shuffine は 2 コーパスだけなので数えずにコーパスごとの判定を並べる），揺れを足さない区間で主と判定が違えば書く．**比べる水準はコーパスごとの判定（揺れを足さない区間）とする．判定が違ったとき，2 つの作りの差の区間（`robustness.csv`．R1 − R0，R1 − R1fixC，#shufcl − #shuffine，#shufcl − #shufage）が 0 を含まないなら，R1 と R0 は「読み出しの作りに依る」，R1 と R1fixC は「C′ の選び方に依る」と書き，説明をその範囲に限る．差の区間が 0 を含むなら「境目の近くで判定が分かれた」と書く．#shufcl と #shuffine・#shufage の違いは，判定と frac_changed を並べるだけにする．**
- **線引きは暫定**（研究者の指示）．計算の後に主張の書き方を変えてよいが，その場合も上の規則での当たり外れを先に書き，変えた理由を書く．
- **P3 は P4a の前提の確かめ**で，P3 だけが当たっても説明の根拠に数えない（声の特徴が言葉の判断を感情以外の手がかりで再現しても，ほかの特徴も同じだけ再現するなら声に固有の話ではない）．

**書き方の対応（結果の文で使う．判断は「K = 5 本ずつで学んだ分類器の判断」と書く）**：

| 結果 | 書く文 |
|---|---|
| P1 当たり | 「WavLM の最後の層の特徴は，K = 5 本ずつで学んだ言葉の分類器の判断を，顔の特徴より良く再現した」 |
| P4a 当たり | 「声の特徴は，言葉の分類器の判断のうち感情のラベルと話者の単位で説明できない部分を，顔の特徴より多く再現した」 |
| P2・P4b 当たり | 上の 2 行の「言葉」と「顔」，「顔の特徴」と「言葉の特徴」を入れ替えた文 |
| P1・P2・P4a・P4b がすべて当たる | 上の文を並べ，説明の「声だけが，ほかのモダリティの手がかりを自分の中に持っている」を「この 4 コーパスとこのエンコーダでは（P1・P4a は AFEW を除く 3 コーパスのうち x，P2・P4b は 4 コーパスのうち y で），声の特徴だけが，ほかの 2 つのモダリティの判断を，感情のラベルと話者の単位で説明できない部分まで含めて，ほかの特徴より多く再現した」と書き直して主張に残す |
| P4a と P4b の一方だけが当たる | 当たった向きの文だけを書き，「声だけが」は主張から外す |
| P1・P2 の両方が当たり，P4a・P4b が当たらない | 「声の特徴はほかのモダリティの判断を最もよく再現した．ただし感情のラベルと話者の単位を通した一致を除くと，差は数えの規則を満たさなかった」 |
| P1 と P2 の一方だけが当たる | 当たった向きの文だけを書き，説明の「声だけが」は主張から外す（「声の特徴は言葉の判断を（顔の判断を）ほかの特徴より良く再現した」までにする） |
| P1・P2 とも当たらない | 説明（3 条件の理由づけ）を主張から外し，3 条件の表だけを残す |
| 数えの中に「下回る」がある | 「判定できない」とは分けて，そのコーパスと量を名指しで書く（予言と逆向きの差が区間で言えた） |

- 文の主語はエンコーダの名前にする（「WavLM の最後の層の特徴」「AffectNet で微調整した ResNet-50 の特徴」「RoBERTa の特徴」．表の文の「声の特徴」などはこの意味）．顔のエンコーダを替えた確かめ（CLIP など）は範囲の外と 1 文書く（顔のエンコーダは表情のラベルで微調整されており，表情以外の手がかりが少ない可能性がある）．点推定と区間を並べて書く．
- 文には数えたコーパスの数（「AFEW を除く 3 コーパスのうち 2」など）とコーパスの名前を入れる．P3・P4a・P4b が当たったときは，層が話者そのものでないコーパス（AFEW は塊と性別と年齢，MOSEI はチャンネル）を名指しする．
- どの結果でも「声に言葉の中身が入っている」とは書かない．言葉の特徴にも声の手がかりの一部が書き起こしの記号として入っている（3 モダリティがそろう発話のうち，角・丸・波括弧か「!」を含む発話は IEMOCAP 4.6%，MELD 26.9%，AFEW の Whisper の書き起こし 14.7%，MOSEI 14.6%．MOSEI は (umm) などの丸括弧が多い．丸括弧には言いよどみの印と編集の補足が混ざり，角括弧は編集の補足なので，「記号は声の手がかり」と書くときはこれを断る．記号の無い発話だけの版を副の条件で出す．「?」は語順と疑問詞で言葉の中身に入るので記号に含めない）．
- 「判定できない」は「差が無い」ではない．否定の文（「言葉の特徴には声色が入っていない」「顔の特徴には言葉が入っていない」）はこの実験では検証しない．R(T ← A) などは記述として出すだけにする．

## 6. 記述として出すもの（判定に使わない）

- 3×3 の R，R_shuf，R_shufcl，R_shuffine，D_x（行：再現する特徴 A・V・T，列：判断 J_A・J_V・J_T と J_prop）．R1 と R0 の両方．対角（自分の判断）は出さない．R_start．
- 対照どうしの生徒の間の差 R_shufcl(A ← T) − R_shufcl(V ← T)，R_shufcl(A ← V) − R_shufcl(T ← V)（P1ctl，P2ctl．P1・P2 の差のうち感情と話者の単位を通る分）．
- MELD で 2 つの組が同じ対話を共有する発話を除いた版（候補の数と共有の対話の数も）．
- 書き起こしに記号が無い発話だけの版（AFEW は `afew_transcript_whisper.csv` の `transcript_asr`）．
- 3 条件の表の評価の回の版（値と区間を並べ，「欠けた条件」の列は作らない．判定は読み手に委ね，文では区間の言えることだけを書く．列ごとに測った発話を書く）：余地（テストの発話．`expl4_corpus_restored.csv` の room．計算しない），J_m の UAR，J_prop の UAR，Δ_s，P_s（R0・R1）（以上は K 本を除いた候補），本番の上がり幅（テストの発話．族 1．計算しない）．
- R_start の対照版（出発点の判定と入れ替えた目標の一致）は計算しない（出発点の判定と入れ替えた目標を保存するので後から出せる）．2 組ごとの最も少ない感情の件数は保存した目標から出せる．
- 仮定の印（`summary/assumptions.csv`．8 節），収束の印（外側と内側の勾配の最大，後退の止まり），選ばれた C′ の数，入れ替えで変わった発話の割合，1 本だけの層の割合，目標ごとの最も少ない感情の件数，各単位の候補の数と塊の数，作れた別の分け方の数．
- 保存：単位ごとの npz に，目標（真と各対照），交差の予測（R0・R1，K = 5・25，各分け方，R1 の格子の全点），交差の予測の確率（K = 5，元の分け方，真と各対照の全部の版，R0・R1．float32），R1 の内側の一致の曲線，出発点の判定，K 本だけの分類器の判定，J_m と J_prop の確率の最大（float16），2 組の割り当て，別の分け方，K 本の発話の印，共有の対話の印，記号の印，性別を残す．後から別の部分集合や別の量を，学び直さずに出せる．

## 9. 限界（結果の文に書く）

- 同じ 4 コーパスと 1 組のエンコーダ（WavLM の最後の層，AffectNet の表情で微調整した ResNet-50，RoBERTa）．確認ではない．声の言葉の情報は層に依る（Pasad ほか 2023 は自己教師ありの音声モデルの中間の層ほど単語の情報が多いと報告した．Wagner ほか 2023 は微調整した音声モデルが言葉の感情の手がかりを拾うと報告した）．この実験は微調整していない最後の層だけを見る．Albanie ほか 2018 は顔の分類器の判断を声の生徒にラベル無しで移した（P2 と同じ向き）．Albanie らは生徒の音声の識別器を学習し，この実験は凍結した特徴の上の線形の識別器である．
- D は，感情のラベルと話者の単位と性別を通らない一致の全部を含む．言葉の中身のほかに，覚醒度や強さ（IEMOCAP・MOSEI は #shuffine の判定と並べて見る），話者の単位の中で変わる属性，発話の長さ，録音や場面の手がかりが入る．MOSEI の層はチャンネルで，性別の注釈が無い．MELD の顔は話者でない人の顔でありうる（P1・P4a で声に有利な向き）．IEMOCAP は 2 つの組が即興の 8 つの筋書きを共有し，#shufcl はこの共有を除かない（言葉の生徒が筋書きを手がかりにできるので，P2・P4b に不利な向き）．IEMOCAP の顔の特徴の候補の約 51% にはモーションキャプチャのマーカーが写る（実験 3）．AFEW の層には同じ性別の複数の俳優が入り（候補の約 7 割が 2 人以上の俳優を含む層），俳優ごとの偏りは D に残り，声と顔に有利な向きになる（#shufage は年齢の区分で俳優の一部も分けるが，2 人以上の俳優を含む層の発話はなお約 4〜6 割ある）．AFEW の #shufcl の層に俳優を使わないのは，俳優あたりの発話の中央値が 1 本で，1 本だけの層が 3 割を超え，目標が変わる割合の見込みが 0.40 を下回るためである．AFEW の `gender` と `actor_age` は同じ俳優・同じ作品の中でも食い違うことがある（`actor_name` の誤りなら話者の分割から漏れうる．評価の回の分割から引き継いだ限界）．MOSEI の #shuffine は，Neutral と Angry では 3 区分のうち 1 つが空で，実際は 2 区分になる．記号の無い版の MELD には共有の対話の規則を当てない．MOSEI の 1 つのチャンネルに男女の話者がいると，性別を通した一致が D に残る（P4b で声に有利な向き．MOSEI は動画 1 本だけの塊に発話の約 86% がある）．AFEW の 2 つの組に同じ書き起こしがある発話が 1.7〜2.5% ある．AFEW の Whisper は声の無い区間で定型の文を作ることがある（`data/README.md` の繰り返しの疑いの 33 本．AFEW の言葉の生徒は P2・P4b に入る）．D が正でも「声に言葉の中身が入っている」とは言い切れない．
- J_m の確率は最大の値だけを保存する（判定の argmax と最大の確率から，判断の確からしさで分けた解析はできる）．K = 25 では K 本が AFEW の候補の約 16% を占める（K 本の印を保存するので，除いた版を後から出せる）．
- J_m は K = 5 の分類器の判断で，当たり方は弱い．P4a と P4b は判断が違う（J_T と J_V）ので，その 2 つの大きさは比べない．
- 線形の識別器での再現．非線形なら変わりうる（実験 12 では隠れ層を足しても読める分はほぼ変わらなかった）．
- 区間は再現の識別器を学び直さない．入れ替えは 1 回．
- コーパスの数え上げは，コーパスをまたぐ検定ではない．多重比較の補正はしない．
- 3 条件の表は，結果を見てから立てた説明の材料で，この実験の判定には使わない．
