## 1. 手法の定義

記号は実験 1 の設計 4 節と 7 節に従う．生徒 s ∈ {A, V, T, AVT}，K ∈ {0, 1, 5, 10, 25}．単位は実験 1 と同じ（評価のターゲット T，仮のターゲット c（評価の回は ALL），分割 f，種 r）．`dai1.Unit`（出発点，標準化，候補，テスト，K 本）をそのまま使い，分割を作り直さない．

- **教師 Q**：実験 1 の主の版（4 コーパス・全 K で「重みなしの積」．`teacher = one`）と同じ．段 2 で学び直した A・V・T の識別器（`p2_K<K>_ret_<m>_W/_b`．float32）を候補の標準化した特徴に当てた確率の積の softmax（`dai1.product(tk, (1,1,1), 0)` と同じ式）．float16 で保存した確率は使わない．K = 0 でも段 2 の `ret_m`（融合の出発点の予測で学び直した識別器）から作る．作り直した教師の判定と，実験 1 の段 3 の `_teacher_stats`（teacher = one）の `uar_pool` の一致を行に残す．
- **印 c_i ∈ {0, 1}**：候補の発話 i について，生徒 s 以外のモダリティの学び直した識別器の判定（上と同じ float32 の確率の argmax）が一致すれば 1，そうでなければ 0．s = A なら V と T，s = V なら A と T，s = T なら A と V．s = AVT は 3 つすべての一致（AVT の生徒には「以外」が無いため．3 節の見込みはこれを踏まえて別に書く）．印の元の識別器は融合の予測で学び直しているので，生徒のモダリティの情報を含みうる（比較の C1）．論文で「別のモダリティだけの情報」とは書かない．
- **印と重みを付ける発話**：印は候補の全発話（K 本を含む）に付け，疑似ラベルの重みも実験 1 の `joint` と同じく候補の全発話に置く（K 本の発話には gk の重みと疑似ラベルの重みの両方が乗る．γ = 1 で `joint` に一致させるため）．印の割合などの診断の量は K 本を除いた候補で数える（定義の 2）．印の割合は生徒で違う（A・V・T の生徒で 34〜59%，AVT の生徒で 22〜50%．仮のターゲットの回）．同じ γ でも重みの配分は生徒ごとに違うので，印の割合を必ず並べる．
- **重み**：m_i = 1（c_i = 1）または γ（c_i = 0）．G = gk + soft_rows(diag(m) Q, ρ n, balance=True)．展開すると，発話 i の感情 k の疑似ラベルの重みは G_ik = m_i Q_ik ρ n / (4 S_k)，S_k = Σ_i m_i Q_ik である（定義の 3）．読み方：(1) 感情の中では，印の無い発話の 1 本あたりの重みは印の有る発話の γ 倍．(2) 印の無い発話に置かれる重みの割合は感情ごとに違う（γ = 1/4 で 0.14〜0.55．仮のターゲットの回）．(3) 印の有る発話は少数派（22〜59%）なので，γ = 1/4 でも印の無い発話の絶対の重みは約 0.5〜0.65 倍にしか下がらず，代わりに印の有る発話が約 1.5〜2.5 倍になる．(4) γ = 0 では有効な本数が `joint` の 1/2〜1/5（最小 46 本）になる．感情ごとの S_k，有効な本数，印の無い発話に置かれた重みの割合を保存に残す．gk は K 本の one-hot（倍率 a = 1）．soft_rows は，m を掛けた後に感情ごとの総量をそろえ，全体の重みの合計を ρ n にする．したがって γ は感情の間の総量を変えず，各感情の内側で印の無い発話から印の有る発話へ重みを移す．γ = 1 で実験 1 の同時に解く版（a = 1）に一致する（学習器の許容 1e-6 の範囲）．γ = 0 で，ある感情に印の付いた発話が 1 つも無い (単位, 生徒, K) では，その感情の疑似ラベルの列の重みが 0 になる（soft_rows の clamp）．その数を行に残して報告する．
- **目的関数**：実験 1 の 4 節の形（K 本の交差エントロピー ＋ 疑似ラベルの交差エントロピー ＋ 引き戻し）÷ S．引き戻し (C′, C_b) は実験 1 の固定のファイルの値．出発点は実験 1 と同じ．学習器は `dai_solver.fit`（`dai1.solve_items` を使い回す）．
- **格子**：ρ ∈ {1/16, 1/4, 1, 4}（実験 1 と同じ），γ ∈ {0, 1/4, 1/2}（3 点）．12 点．γ = 1 は格子に入れない（実験 1 の `joint`（a = 1）の行がそれに当たる．したがって γ = 1 が仮のターゲットで最良のとき `cons` はそれを選べず，主の量は `cons` に厳しい向きの比べである．ML の m4）．
- **選択なしの値**：ρ = 1，γ = 1/4．γ の格子と向き（γ < 1）は評価の回の候補のラベルの診断を見た後に決めた（0 節．比較の C9）．1/4 は格子の中央で，成績（UAR）を見て選んではいない．
- **実験 1 の `agree`（一致した発話だけの疑似ラベル）との違い（6 点．比較の C8）**：(i) 誰の判定の一致か（`agree`：生徒自身の none[K] と教師．`cons`：生徒以外の学び直した識別器どうし），(ii) 確信度のしきい値 τ（`agree` にあり `cons` に無い），(iii) 硬いラベル対柔らかいラベル，(iv) 印の無い発話を捨てる対 γ 倍にする，(v) 感情ごとの総量をそろえる操作（`cons` は有り），(vi) f 重み対 ρ 重み．(i) だけの効果は `cons_own` との差（下）でだけ言う．
- **印の定義を替えた対照（比較の C3・C16，ML の M2）**：本番と同じ格子（ρ 4 × γ 3）と同じ選ぶ規則で解く．
  - `cons_self`：印＝生徒を含む全モダリティの学び直した識別器の判定の一致（AVT の生徒は本番と同じなので省く）．
  - `cons_own`：印＝生徒自身の none[K] の判定と教師 Q の判定の一致（別のモダリティを使わない版）．
  - `cons_conf`：印＝教師 Q の最大の確率が上位 q の発話．q はその (単位, 生徒, K) の本番の印の割合に合わせる（連続の信頼度で重みづける標準の対照に当たる）．
  - `cons_rand`：印＝本番と同じ割合で，固定の種（(T, c, f, r, 生徒, K) から決める）の乱数で付ける．
  これらとの差（`cons − cons_*`）は記述（p 値なし）．これらが無いと，「別のモダリティの一致が効いた」と「確信度の高い発話を重くすれば効く」を区別できない．

**主の量（族 6）**：`cons`（選んだ設定）− `joint`（主の版・選んだ設定）．生徒 4 × K ∈ {0, 5, 25} の 12 セル，コーパスごとに Holm．正が `cons` に有利．
**並べる量（記述．p 値なし．区間と単位の数つき）**：`cons − cons_g1`（選んだ ρ で γ だけ替えた差．印の効果に最も近い），`cons − none`，`cons − kd_one`，`cons − partner`，`cons − agree`，`cons − cotrain`，`cons − coreg`，`cons − cons_self/own/conf/rand`，選択なしどうし `cons(ρ = 1, γ = 1/4) − joint(ρ = 1, a = 1)`，ρ = 1 での γ の曲線（γ = 0, 1/4, 1/2, 1），`cons` の γ = 1/4 の列で ρ だけを選んだ版 − `joint_a1`（選択の自由度をそろえた比べ），K = 1・10 の全部，印の付いた発話の割合（感情ごと），印の有無ごとの教師の正解率と感情ごとの再現率（候補のラベルは評価の回の後の集計でだけ読む），有効な本数，正解の感情に置かれた重みの割合（感情 k ごとに Σ_{i: y_i = k} G_ik / Σ_i G_ik を求めて 4 感情で平均．`joint` と `cons` の選んだ設定で並べる．定義の D2．仮のターゲットの回の参考値：`joint` 51.5%，γ = 1/4 の `cons` は生徒 A・V・T・AVT で +5.1・+3.5・+4.7・+6.9 ポイント）．
**公平さ**：`cons` と `joint`・`kd` は同じ情報（K 本と 3 つの予測）を使う．格子の点の数は `cons` 12，`joint` 12（ρ 4 × a 3），`kd` 12（温度 3 × ρ 4）で同じだが，`joint` は実験 1 の選ぶ段で 80 セル中 75 セルが (ρ = 1, a = 1) に落ちたので実効の自由度は ρ の 4 点に近い（比較の C9・統計の S1）．そのため上の「選択の自由度をそろえた比べ」と「選択なしどうし」を必ず並べる．
**実験 1 の漏れの感度の引き継ぎ（漏れの L12）**：IEMOCAP 即興の筋書きと MELD の話の重なりは `cons` にも当てはまる．実験 3 の筋書きの対（生徒 T・AVT，K = 5）と実験 1 の 9.4 節の部分集合（AFEW の書き起こしの疑い，MELD の顔が競らない発話，IEMOCAP のマーカーの層）で `cons − joint` を記述として出す．

## 3. 診断を見たうえでの見込み（事前登録ではない．ML の M4，統計の S4，感情認識の A2）

|---|---|---|---|

- **評価の段の守り（`DAI/frozen/eval_gate_dai4.json`．漏れの関門の 6，ML の m7）**：実験 1 の `dai1.check_eval_gate` と同じ形で，DAI-4 用の守りを `dai4.py` の中に書く（`dai1.py` は変えない．`eval_gate.json` の sha256 を保つため）．動く条件は次のすべて．
  1. `DAI/frozen/dai4_frozen.json` がコミット済みで `results/dai4/select/frozen.json` と一致し，その中に detect の出力がある．
  2. 必須のファイル（この設計，`dai4.py`，`dai4_stats.py`，`dai1.py`，`dai_solver.py`，`dai_data.py`，`dai1_stats.py`，`dai1_frozen.json`，`dai4_frozen.json`，`DAI/checks/DAI-4/data/*.csv`）がコミット済みで sha256 が一致する（`committed_clean` と同じ，ファイルごとの検査）．
  3. `DAI/checks/DAI-4/` の 7 役（review_ml，review_affect，stats，leak，compare，define，code）の最新の版が「OK」「通す」である．
  4. 入力の完全性：`results/dai1/eval/units` に 4 T × 50 単位の p1・p2・p3 がそろい，その sha256 の一覧が `eval_gate_dai4.json` に記録されている（後で流し直されると印と教師が変わる）．
  5. `dai4_frozen.json` のコミット時刻が，評価の段の最初の保存より前である．
  6. 学習の経路がラベルを読まない：印・教師は保存した重みと切片だけから作り，候補・テストのラベルは stats の後処理でだけ読む（gate-code に確かめさせる）．

- 再開：保存があれば読む．コミットと固定のファイルの sha256 が違えば止まる（実験 1 と同じ）．
- 台本の自己検査（ML の M5）：`--selftest-g1` で γ = 1 を数単位で解き，実験 1 の p3 の `joint`（a = 1，同じ ρ，teacher = one）の判定と W・b との差を出す．

## 5. 統計

- 区間と自由度は実験 1 の 9.3 節の規則（AFEW・IEMOCAP・MELD は塊の jackknife ＋ 種の項，MOSEI は塊の引き直し ＋ 種の項．同じ判定の行は p = 1．K = 0 は 5 単位で種の項 0）．`dai1_stats.effect_stats` をそのまま使い，書き直さない．
- 対にする条件（統計の S3）：stats の前に，同じ (T, f, r) で，テストの `sample_id`・K 本の番号・塊の名前が実験 1 の保存と `cons` の保存で完全に一致することを assert し，一致しない単位の数を表に残す．
- 族 6 の Holm はコーパスごとに 12 セル．4 コーパスをまたぐ補正は置かず，数え上げの文は p 値なしで，選んだ設定が仮のターゲットの出力を共有することを添える．
- 取りこぼし（テストで最良の点 − 選んだ点）と差が無いときの水準は実験 1 の S8 と同じ形で，手法ごとに（格子の実効の点の数を添えて）出す．
- p 値が表すもの：実験 1 の 9.3 節の文（手法の形を同じ 4 コーパスで作ったので確認の検定ではない）に，「案の出どころが評価の回の診断である」ことを加える（ML の m2）．

## 6. 所要と計算機（ML の M3）

- 1 単位：本番 240 問 ＋ 対照 960 問 = 1,200 問（実験 1 の段 3 の約 3 分の 1）．H200 で 1 単位 1〜2 分，仮のターゲットの回 120 単位と評価の回 200 単位で合計 5〜10 時間の見込み．
- 仮のターゲットの回と評価の回はどちらも H200 で流す（`joint` の保存が H200 なので，機械の差を混ぜない）．計算機の名前を単位ごとに残す．研究室の A5000 は自己検査と試走だけに使い，同じ 1 単位を両方で解いて判定と W の一致を記録する（実験 1 の 9.1 節と同じ）．
- 教師と印は段 2 の保存した重みから作るので，段 1・2 は流し直さない．

## 7. 見たデータと漏れ

- 案のきっかけと設計の判断：0 節のとおり，評価の回の候補のラベルの診断（複数）を見た後に 1 つを選んだ．仮のターゲットの回の診断の表（`DAI/checks/DAI-4/data/consensus_pseudo_cells.csv`・`consensus_emotion_cells.csv`・`consensus_neff_cells.csv`．コミット済み）は同じ発話の再現で，定義の選択には使っていない．
- 設定の選択：仮のターゲットの回の出力だけ（T の選択は c ≠ T の 30 単位だけ．実験 1 の規則）．
- `cons` のテストの成績は，評価の段の後の stats まで存在しない．`joint`・`kd`・`none` の評価のターゲットの UAR は，一部の T について設計の前に見た（`docs/seen-data.md`）．
- 評価のテストの使われ方：実験 1 の 9.3 節の「各コーパスのテストの分割は，ほかの 3 つのターゲットの設定を選ぶ仮のターゲットとしても使った」を，この実験の方法の節にも置く．
- 台帳の時刻はコミットの時刻に合わせる（漏れの関門の記録）．

## 8. 範囲の外と限界

- 印を連続の信頼度にする版（対照 `cons_conf` で代える．それ以上は範囲の外）．
- 教師そのものを良くする版（ソースの重みづけ，共訓練の反復）．診断で MELD と MOSEI の教師の弱さ（一致しても正解率 4〜5 割）が見えたが，別の欠点なので別の実験にする（感情認識の a6）．
- 第 2 のエンコーダ：実験 1 の 9.5 節の回が流れたら同じ手順で繰り返す．ただし同じ発話を使うので独立した確認にはならない（ML の M1 の補足）．
- 限界に書く事柄：凍結した特徴の上の線形の識別器・1 組のエンコーダ（比較の C7）．印を歪めうる事情（顔の検出の失敗で落ちる発話，MOSEI の顔の 82% が 1 セグメント，AFEW の Whisper の繰り返し 33 本と "Thank you." 6 本，IEMOCAP 台本の言葉，MELD と MOSEI の Neutral の決め方．感情認識の a3）．MOSEI の話者の代用の不完全さ．

## 9. 仮定と測る量（D8．定義の関門の 7）

| 仮定 | 測る量（評価の回の保存から．候補のラベルは stats でだけ読む） | 読み方 |
|---|---|---|
| 一致は教師の正しさの手がかりである | 印の有無ごとの教師の正解率と感情ごとの再現率（生徒・K ごと） | 差が 10 ポイント未満のコーパス・生徒では，印の根拠が弱いと書く |
| 一致は生徒の情報から独立に近い | `cons − cons_self`，`cons − cons_own`（1 節の対照） | 差が区間の幅の中なら「独立の根拠は無い」と書く |
| 2 つの識別器の誤りの相関が小さい | 印の有る発話で教師が誤る割合（両方が同じ誤りをする割合） | 不一致の群の誤りの割合と並べる |
| 重みが少数の発話に集まらない | 感情ごとの有効な本数（γ 別），重みが 0 になった感情の数 | 有効な本数が 30 本未満の (単位, 生徒, K, 感情) の数を書く |
| γ = 1 が `joint` に一致する | 自己検査 `--selftest-g1` の判定と W・b の差 | 差が学習器の許容を超えたら止める |
| 直す・壊すの割合が見込みどおり | 印の有無ごとの直す・壊すの割合（評価の回） | 3 節の根拠の数と並べる |
