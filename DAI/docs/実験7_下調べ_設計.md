## 1. 問い

- **Q1（依存は増えるか）**：蒸留で学んだ単独の分類器（joint，joint_a1）の点数は，蒸留しない単独の分類器（none）に比べて，同じ感情の中でモダリティの間の依存が大きいか．正解の全ラベルでそれぞれ別に学んだ単独の分類器（oracle）よりも大きいか．増えた分は誤りの相関の増加を伴うか．3 つの単独の分類器が同じ疑似ラベルを共有したことによるか（各モダリティが自分のモダリティの疑似ラベルで学んだ対照との比べ）．
- **Q2（蒸留の量との関係）**：K 本の倍率 a を 1 に固定して疑似ラベルの項の重み ρ を大きくすると，依存は大きくなるか．
- **Q3（依存を無視した損と，得の足し合わせ）**：3 つの単独の分類器の点数を融合するとき，依存を無視した結合（ブロック対角の判別分析）と依存を入れた結合（完全な判別分析）の UAR の差（依存の分）は，joint の方が none より大きいか．単独の分類器の得は積の融合で足し合わさるか．
- **Q4（どの疑似ラベルで増えるか．記述）**：2 つの単独の分類器が同じ 1 つのモデルの予測だけを疑似ラベルにして学んだとき（none の積，ソースの融合の平均，第 3 のモダリティの none．融合の none は ret と同じ問なので数えない），依存はどれだけ増えるか．

## 3. 量の定義

### 3.1 点数

- 単独の分類器 m ∈ {A, V, T} の点数 Z_m = X_m W_mᵀ + b_m（4 感情）を，4 つに共通の足し算を除く 4×3 の正規直交の基底 H（1 のベクトルに直交）で z_m = Z_m H（3 個）にする．softmax の確率は 4 つに共通の足し算に依らないので，z_m は分類器の判定と確率を決める部分のすべてである．
- 3 つをつないだ z = (z_A, z_V, z_T)（9 個）．

| oracle | 候補の全ラベルでそれぞれ別に学んだ単独の分類器（正解だけで学んだときの依存の参照）．引き戻しは (m, K = 25) の値．K に依らない | `p1_<m>_W/b` の `all|C′|C_b` |
| tt[q] | 疑似ラベルを 1 つのモデル q の予測だけにした学び直し（ρ = 1，a = 1）．q ∈ {poe_none（none の積），start_AVT（ソースの融合の平均．ターゲットの情報を持たない），single_<第 3 のモダリティ>（組に入らないモダリティの none）}（Q4） | `p3_<m>_K<K>_W/b` の項目 `method=tt, teacher=q` |
| none_tw[C′, C_b] | none と同じ K 本だけの問を，引き戻しの格子の 14 点（`dai1.TETHER`）のすべてで解いたもの（K ≥ 1）．テストの D と φ だけを出す（記述．疑似ラベルの項を足すと出発点への引き戻しが相対的に弱まる効果の大きさを見るため．gate-code の R6）．none はモダリティごとに選んだ引き戻しを使うので，一般に 14 点のどれとも一致しない．none と比べるときは対ごとに，2 つのモダリティの引き戻しが同じ点か近い点を使う（gate-code の再検査の記録 1） | `p1_<m>_W/b` の `K|C′|C_b` |
| tt_ownret | 単独の分類器 m ごとに，疑似ラベルのモデルの因子のうち自分のモダリティの ret_m の予測だけを疑似ラベルにした学び直し（ρ = 1，a = 1．声は ret_A，顔は ret_V，言葉は ret_T）．joint_a1[ρ = 1] とは，学習の目標の式（`DAI/exp/dai1.py` の `a·gk + soft_rows(Q, ρ·n)`），ρ，a，出発点，引き戻し，候補，K 本が同じで，違うのは疑似ラベル Q を 3 つの分類器で共有するかだけである（dai-review-ml の M2）．このため D(joint_a1[ρ = 1]) − D(tt_ownret) は，疑似ラベルの項の重みと引き戻しの相対的な弱まりをそろえたうえで，段 3 の共有の効果を表す．ret_m 自身は融合の none[K] の予測で学び直した分類器なので，段 2 の共有（ret と none の違い）は分けない | `p3_<m>_K<K>_W/b` の項目 `method=tt, teacher=ret_<m>, rho=1, a=1` |
| tt[fused_AVT] | ret と同じ最適化の問（目標 `gK + soft_rows(none_AVT, n)`，同じ出発点と引き戻し．`DAI/exp/dai1.py` の `pass2` と `make_G`）．ret との D の差を数値の誤差の確かめに使うだけで，Q4 の証拠に数えない | 同上 |

- 組の 3 つのモダリティは同じ単位の同じ K の分類器である．tt[single_X] は，組 (m, m′) で X が m と m′ のどちらでもないときだけ使う（A–V なら single_T）．
- **比べる 2 つの組で違うつまみ**（C14 の案）：none と joint は，疑似ラベルの項（ρ）と K 本の倍率 a の 2 つが違う．none と joint_a1 は ρ だけが違う（a = 1，同じ出発点と引き戻し）．このため「疑似ラベルの項が依存を増やした」と書く根拠は joint_a1 とする（4 節）．ただし学習器は（損失 + 罰則）÷ 重みの和を最小にするので，疑似ラベルの項（重み ρn）を足すと罰則の比が下がり，出発点への引き戻しが相対的に弱まる．none_tw はこの効果の大きさの記述に使う．
- **固定のファイルの実際**（gate-code の I17）：4 コーパス × 3 モダリティ × 5 K の 60 セルすべてで，joint の選んだ a は 1 で ρ も joint_a1 と同じである．主の版も 4 コーパスと 5 K のすべてで `one` である．このため joint ≡ joint_a1 で，H1(joint) と H3(joint) は同じ値の確かめとして並べるだけである．`sel` の教師の点数の経路は動かない．

### 3.3 感情の中の点数の依存 D（Q1・Q2・Q4 の主の量）

- テストの発話のうち感情 e の発話について，モダリティの組 (m, m′) の 3 次元の点数 z_m と z_m′ の標本の共分散 S_mm，S_m′m′，S_mm′（平均を引く）から，正準相関の 2 乗の平均 d_e(m, m′) = (1/3)·tr(S_mm⁻¹ S_mm′ S_m′m′⁻¹ S_m′m) を出す（0 以上 1 以下）．S に tr(S)/3 × 1e-6 を足して逆行列を取る．
- 正準相関は，モダリティごとの点数に可逆な 1 次変換をしても変わらない（足した 1e-6 の分を除く）．したがって d は点数の尺度や温度，感情の間の混ざり方（較正）に依らず，2 つのモダリティの点数がどれだけ一緒に動くかだけを測る．
- **偶然の水準**：同じ感情の中で m′ の発話の並びを入れ替えた 200 回の d_e の平均 d_e⁰ を，観測したテストの上で 1 回だけ求める．並べ替えの添字は (単位, K, 対, 量の種類) だけで決まる乱数で作り，組の間で共有する（共通の乱数．同じ問の 2 組の D は一致し，Δd⁰ は点数の違いだけを表す．gate-code の I7）．D の各値は d_e − d_e⁰ とする．感情の発話が 15 本未満の (分割, 感情) は使わない（使った感情の数を出す）．
- D(m, m′) = 使えた感情の d_e − d_e⁰ の等しい重みの平均．D = 3 つの組の D(m, m′) の平均．
- **候補の上の D（副）**：同じ量を候補の発話と候補の正解で出す（偶然の水準は 50 回の並べ替え）．テストの D との差を，候補の上の楽観の大きさとして記述するだけで，判定には使わない．
- **話者か塊で中心化した版（副．dai-review-affect の a6・A2）**：テストの発話の点数から，(グループ, 感情) ごとの平均を引いてから同じ量を出す．グループは IEMOCAP が話者（`speaker_id`），MELD が話者（同じ人物の別名をまとめた後の塊），MOSEI がチャンネルか動画の塊，AFEW が俳優と作品のつながりの塊である（AFEW の分割 0 は 1 つの塊がテストの 97.5% を占めるので，この分割ではほとんど中心化されない）．3 本未満の (グループ, 感情) の発話は外し，外した数を残す．偶然の水準は，中心化した点数の上で，(グループ, 感情) の中で並べ替えて出す（中心化で減った自由度を帰無に入れるため）．比べられるように，中心化で外した発話を除いた同じ発話の上で，中心化しない D（keep）も出す．組の差 ΔD_cent と ΔD_keep に，4 節と同じ抜き直しで区間を付ける（4 節の H1 の添え書きに使う）．
- **筋書きで中心化した版（IEMOCAP だけ．副．dai-review-affect の A1）**：(筋書き, 感情) ごとの平均を引き，(筋書き, 感情) の中の並べ替えで偶然の水準を作る．筋書きは `sample_id` の `impro` の後の 2 桁で，05a・05b は 05，08a・08b は 08 とする（`DAI/exp/dai3.py` の `scenario`．実験 3 の設計 3 節の 5 と同じ）．3 本未満の (筋書き, 感情) の発話は外し，外した数を残す（行の `n_dropped_scen`）．ΔD に区間を付け，記述とする．
- **部分集合の版（副．dai-review-affect の A2・a5）**：`DAI/exp/dai3.py` の `subset_masks` の印でテストの発話を絞り，同じ量を出す．MOSEI はチャンネルが分かる塊の発話（同じチャンネルの別の動画が候補に残りうるので漏れは 0 にならない．`data/README.md` 3 節），AFEW は書き起こしの疑い（3 モダリティの集合で 35 本）を除いた発話，IEMOCAP はマーカーの側とマーカーの無い側のそれぞれ，MELD は顔が競らない発話である．偶然の水準はその発話の中で作り直し，区間はその発話を持つ塊だけで抜き直して作る．記述とし，MOSEI の版だけを 4 節の H1 の添え書きに使う．
- **話者を塊にした区間（IEMOCAP だけ．dai-review-ml の m2）**：抜き直しの塊をセッション（5 つ）の代わりに話者（10 人）にした区間を，D の差について記述として並べる．同じセッションの 2 人は同じ対話を一緒に演じるので，2 人を別の塊にすると塊どうしの相関を無視し，区間はセッションを塊にした区間よりさらに狭く出うる．このため区間が名目より狭いことの確かめには使わない（第 7 版．dai-review-ml の m9，dai-review-affect の b4）．
- **jackknife と t の区間（記述．第 7 版．dai-review-ml の m9）**：実効の塊の数 (Σn)²/Σn²（n は 5 つのテストを合わせた塊ごとの発話の数）が 20 未満のコーパス（`DAI/splits/` から数えると AFEW 14.99，IEMOCAP 即興 4.91，MELD 8.59 で，自由度は 13，3，7．MOSEI は 783 で付けない）で，ΔD（joint_a1 − none，joint_a1 − oracle，joint_a1[ρ = 1] − tt_ownret）に，塊を 1 つずつ抜く jackknife の分散と自由度 max(1, ⌊実効の数⌋ − 1) の t の 95% 区間を付ける．計画 8 節の規則のうち塊の jackknife と t の自由度を使い，K 本の抜き方の種の分散の項は足さない．主の抜き直しも種の項を含まないので，2 つの区間を同じ揺れの範囲で比べるためである（第 8 版．gate-code の第 4 回の記録 1，dai-review-ml の m12）．塊を抜いた分割の重みは，主の抜き直しと同じく残りの塊の割合（(塊の数 − 1)/塊の数）にする．実験 1 の規則は分割の重みを 1 のままにする点が違う（MELD の分割 4 は塊が 2 つなので違いが大きくなりうる．gate-code の第 4 回の記録 2）．IEMOCAP は塊が分割と同じなので，この区間は分割ごとの学習の違いも含む．「区間の下端 > 0」の合否が塊の抜き直しの区間と変わる K の数を `criteria.csv` に出す．
- **部分集合の版の感情**（第 7 版．dai-review-affect の b5）：部分集合の版では，15 本の規則で外れる感情が全体と違いうる（例：IEMOCAP のマーカーの無い側の Angry は分割 0・3・4 で 10・2・12 本）．このため部分集合の版の D は，平均する感情の組が全体の D と違うことがある．使った感情の数は行の `v_<変種>_n_e*` から出す．
- **教師の点数を除いた依存（副．記述だけ）**：joint の疑似ラベルの元の点数 t（主の版の積．`one` なら ret の 3 つの対数確率の和，`sel` なら学習で使った単位の `wsel` の指数の重みつきの和で，固定のファイルの `w` と一致するかを単位ごとに確かめる．4 つを H で 3 個にする）をテストの上で作り，感情 e の中で z_m と z_m′ をそれぞれ t（と定数）に回帰した残りの正準相関から同じ量を出す（偶然の水準は残りの並べ替え）．同じ t を none と oracle にも当てて出す．t は 3 つのモダリティの点数の和 r_A + r_V + r_T と一致するので（log softmax の 4 つに共通の項は H で消える），t を除いた後の依存は，依存がまったく無くても正になる（大きさのそろった 3 つの独立な量の和を除くと，2 つの残りの相関は −1/2，2 乗で 0.25．台本の検算 (10)）．各モダリティが自分で共有の向きを拾うだけの変化でも ΔD_t が小さく出るので，教師の写しの根拠には使わない（dai-review-ml の M1）．

### 3.4 誤りの相関 φ（Q1 の書き方に使う）

- 単独の分類器 m の判定が正しいかの 0/1 を，同じ感情 e の発話の中で組 (m, m′) について比べ，φ 係数（2×2 の表の相関）を出す．使えた感情の等しい重みの平均を φ(m, m′)，3 組の平均を φ とする（Kuncheva と Whitaker 2003 の相関の量を感情の中で取ったもの）．15 本未満の感情と，どちらかの分類器の正誤が感情の中で 1 通りしかない (分割, 感情) は使わない．

### 3.5 依存を無視した損と較正の分（Q3）

- 3 つの組の点数 z（9 個）に，感情で共通の共分散の判別分析（判定は感情の事前を等しくした δ_c(z) = μ_cᵀ P z − ½ μ_cᵀ P μ_c，P = (Σ + 1e-3·tr(Σ)/9·I)⁻¹）を当てる．μ と Σ はテストの正解の半分で推し，残りの半分に当てる（2 つに分けて入れ替える交差の当てはめ）．
- **分け方**（D21 の案）：テストの塊を大きい順に並べ（同じ大きさは名前の順），発話の少ない方の半分へ 1 つずつ入れる．こうして割った 2 つの半分が，(a) どちらも各感情 5 本以上で，(b) 小さい方の半分がテストの 30% 以上なら，塊の単位で分ける．そうでなければ，感情で層にした発話の単位で分ける（感情ごとに発話を種 0 で並べ替え，交互に割る）．どちらで分けたかと 2 つの半分の本数を `uar.csv` に残す．
  - full：Σ をそのまま使う（依存も入れた結合）．
  - blk：Σ のモダリティをまたぐ 3×3 のブロックを 0 にする（各モダリティの較正と感情の事前を直し，依存を無視した結合）．
  - prod：Σ_m Z_m の argmax（確率の積．Λ = I）．
- 依存の分 L_dep = UAR(full) − UAR(blk)，較正の分 L_cal = UAR(blk) − UAR(prod)．L_cal には，prod が単独の分類器の切片をそのまま使い，blk が感情の事前を等しくして判定することの差（感情の事前の補正）も入る（dai-review-ml の m5）．どちらもテストの正解で推した結合器の値で，配備できる量ではない（Averbeck ほか 2006 の ΔI_diag と同じ「相関を無視した最適な復号器の損」の考え方）．full の Σ は 45 個，blk は 18 個の母数を持つので，半分の本数が少ないと full の推定の揺れで L_dep が小さく出る向きがある．半分の本数を 9 で割った値を残す．
- **得の足し合わせ**：単独の得 G_m = UAR(joint_m) − UAR(none_m)，積の得 G_prod = UAR(prod[joint]) − UAR(prod[none])，完全な結合の得 G_full = UAR(full[joint]) − UAR(full[none])．joint_a1 についても同じ量を出す．
- **足し合わさらない分の分け方**（dai-review-ml の M3）：単独の得の平均を Ḡ = (1/3)Σ_m G_m，足し合わさらない分を S = Ḡ − G_prod とすると，定義から次の恒等式が成り立つ（台本の検算 (11)）．
  ```
  S = (Ḡ − G_full) + ΔL_dep + ΔL_cal
  ΔL_dep = L_dep(組) − L_dep(none)，ΔL_cal = L_cal(組) − L_cal(none)
  ```
  第 1 項 Ḡ − G_full は，依存を入れた結合器でも足し合わさらない分である．この分には，判別分析の結合器が none にも与える較正と感情の事前の直しの得が入る（dai-review-ml の再検査の M4．人工データで，joint と none の情報が同じでも none の単独の点数に感情の偏りがあれば，この分が 11〜21 ポイント出た）．このため第 1 項をさらに 2 つに分ける（第 7 版）．各モダリティの 3 次元の点数だけに同じ判別分析（感情の事前を等しくし，同じ 2 つの半分で交差の当てはめ）を当てた単独の UAR の得の平均を Ḡ_cal とする．
  ```
  Ḡ − G_full = (Ḡ − Ḡ_cal) + (Ḡ_cal − G_full)
  S = (Ḡ − Ḡ_cal) + (Ḡ_cal − G_full) + ΔL_dep + ΔL_cal
  ```
  Ḡ − Ḡ_cal は単独の分類器の較正と感情の事前の得（判別分析が none にも与える分），Ḡ_cal − G_full は較正をそろえた単独の分類器の得が完全な結合器で足し合わさらない分で，単独の分類器どうしの情報の重なりか UAR の天井を表す（この 2 つは分けない）．ΔL_dep が説明の筋の (iii) の分である．joint_a1 と，選んでいない joint_a1[ρ = 1] について，S，4 つの分，S に占める ΔL_dep の割合を，4 節と同じ抜き直しで区間つきで出す（4 節の H4）．割合の区間は，抜き直しの回で S が 0 に近いと極端な値になりうるので参考とし，結果の文には S と ΔL_dep の区間を並べて書く（gate-code の記録 6）．
- 感情ごとの再現率（単独の 3 つ，各モダリティだけの判別分析，prod，blk，full）とテストの感情ごとの本数を `uar.csv` に残す（記述．dai-review-affect の a2）．感情ごとの ΔD と再現率は記述だけで，感情ごとの主張はしない（第 7 版．dai-review-affect の b6）．

| 3 次元の点数で依存を表せる | D の意味 | — | z は判定と確率を決める部分のすべて（3.1 節）．点数の外の特徴の依存は測らない（8 節） |
| 判別分析の結合器の仮定（感情で共通の共分散） | L_dep と L_cal の意味 | テストの 9 次元の点数 z で，h = （15 本以上の感情 e についての）‖Σ_e − Σ‖_F / ‖Σ‖_F の平均（Σ_e は感情 e の発話の共分散，Σ は感情の平均を引いた共通の共分散）．偶然の水準 h⁰ は感情のラベルをテストの中で並べ替えた 50 回の h の平均で，h − h⁰ を使う | h − h⁰ ≥ 0.5 のセルでは，L_dep を「この結合器での差」とだけ書き，ΔI_diag の意味では書かない |
| 単独の分類器の得が積の融合で足し合わさらない（説明の筋の (iv)） | (ii)(iii) が説明する対象があるか | joint_a1 の G_prod − (1/3)Σ_m G_m（4 節と同じ塊の抜き直しで区間を作る）．選んでいない joint_a1[ρ = 1] の同じ量（区間つき）と，joint の同じ量（記述）を並べる | K ∈ {1, 5, 10, 25} のうち 3 つ以上で区間の上端が 0 より下のコーパスを「足し合わさらない」とする．満たさないコーパスでは，(ii)(iii) を「足し合わさらない理由」として書かない．判定を joint_a1 で行うのは H1 の根拠と同じ組にするためである．joint_a1 も ρ の 4 点から単独の UAR で選んだ点なので G_m がわずかに上に寄り，その向きは前提が成り立つ側である．joint は (ρ, a) の 12 点から選んだので寄りが大きい．joint_a1[ρ = 1] は ρ と a を選んでいない対照である（疑似ラベルの主の版の 2 択は K ごとに c のテストの UAR で選んである） |

## 4. 判定の規則（計算の前に固定）

- **K の間の依存**（dai-review-ml の m3）：4 つの K は同じテストと同じ候補を共有するので，どの規則の「K ∈ {1, 5, 10, 25} のうち 3 つ以上」も 3 回の独立な確かめではない．この注はすべての規則に当てる．
- **ばらつき**：実験 6 の下調べと同じく，c の 5 分割のテストの塊をまとめた 1 つの集まりから塊を抜き直し（1,000 回．同じ抜き直しを全部の量と全部の組に共通に使う），次の手順で値を作る．
  1. 単位ごとに，抜かれた塊の発話（重複を重みとして数える）で量を作る．D は (塊, 感情) ごとの点数の和と積の和から重みつきの共分散を作り直して求め，偶然の水準 d_e⁰ は観測の値に固定する．UAR と φ は (塊, 感情) ごとの数から作る．
  2. その回で重みつきの本数が 15 本未満になった (単位, 感情) は，その回だけその感情を外す（D と φ は残りの感情で平均する）．使える感情が 1 つも無い単位はその回だけ外す．UAR から作る量（L_dep，ΔL，G）は，その回にどれかの感情が 15 本未満になった単位をその回だけ外す（感情を外すと 3 感情の UAR が混ざるため．gate-code の I1-a）．
  3. 分割の値は，その分割のテストを共有する 6 単位（3 つの T × 2 種）のうちその回に値のある単位の平均とする．
  4. 抜かれた分割について，「抜かれた塊の数 ÷ 分割の塊の数」の重みで平均する（`DAI/exp/dai6_probe.py` の `_boot_fold_mean` と同じ重み）．
  5. 有効な回の数（値が有限の回）を `diffs.csv` に残す．
  6. 95% 区間を作る．d⁰ を固定するので，区間は ΔD・Δφ・ΔL などの**差**について判定に使い，D の水準の区間は参考とする．IEMOCAP は塊が 5 つ（分割ごとに 1 つ）なので，区間は名目の 95% より狭く出うる（5 つの値の抜き直しの区間の幅は自由度 4 の t の区間の約 6 割で，真の値を含む割合は約 84%．査読想定の役の人工データ）．このため IEMOCAP の「区間の下端 > 0」は，5 つのセッションのほぼすべてで差が正であることとほぼ同じ意味になると書く．MELD も各分割のテストの 71〜82% を主役 1 人が占めるので，同じ向きがあると書く（dai-review-ml の m2，dai-review-affect の a1）．この向きの確かめには，3.3 節の jackknife と t の区間（AFEW・IEMOCAP・MELD）を並べる．話者（10 人）を塊にした区間は記述だけで，この確かめには使わない（第 8 版．dai-review-ml の m12，dai-review-affect の c2）．
- **下限**：ΔD（依存）と Δφ（誤りの相関）は 0.02，ΔL（UAR の差）は 0.5 ポイントとする．「区間の下端が 0 より上」だけを満たしたセルと，「区間の下端が 0 より上で，点推定が下限以上」の両方を満たしたセルの数を `criteria.csv` に残す．判定には後者を使う．
- **H1（Q1．依存が増える）**：c ごとに，K ∈ {1, 5, 10, 25} のうち 3 つ以上で ΔD = D(joint_a1) − D(none) が「区間の下端 > 0 かつ ΔD ≥ 0.02 かつ \|Δd⁰\| < 0.1·\|ΔD\|」を満たせば，「c で疑似ラベルの項が依存を増やした」と書く．4 コーパスのうち 3 つ以上で満たせば，「この 4 コーパスと凍結したエンコーダで，実験 1 の提案の形の蒸留は単独の分類器どうしの依存を増やす」と書く（範囲を付ける．dai-review-ml の m1）．同じ数え方を D(joint) − D(none) でも行い，joint だけで満たしたコーパスは「K 本の倍率 a の効果を分けていない」と書く．区間の上端が 0 より下のセルがあれば，数を書く．
- **H1′（Q1．正解で学んだときより大きい）**：同じ数え方を D(joint_a1) − D(oracle) で行う．H1 を満たし H1′ を満たさないコーパスでは，「依存の増え方は，正解で別々に学んだ分類器の依存の水準の中に収まる」と書き，蒸留で生じた増加とは書かない．
- **全体の数と IEMOCAP 即興**（dai-review-affect の A1）：全体の数を出す規則（H1，H1(joint)，H1′，H2，H3，前提 (iv)，下の共有の比べ）はすべて，「4 コーパスのうち x（IEMOCAP 即興を除くと 3 つのうち y）」と書く．4 コーパスで 3 つ以上を満たし，IEMOCAP 即興を除くと 2 つ以下になる規則では，「この判定は IEMOCAP 即興の合否に依り，IEMOCAP 即興の依存の増加は筋書きの話題の共有と分けられない」と書く．声と顔の対の ΔD だけで H1 と同じ数え方をした結果（H1_AV）を記述として並べる．この対は言葉の点数を含まないが，疑似ラベルは言葉の分類器を含む積なので，言葉の情報が疑似ラベルを通して入りうる（第 7 版．dai-review-affect の b1）．
- **H1 の書き方**（dai-review-ml の M1・M2，dai-review-affect の A2）：結果の文に「写し」の語を使わない．H1 と H1′ の両方を満たしたコーパスについて，次の 1〜4 の文をこの順につなげて書く．
  1. Δφ = φ(joint_a1) − φ(none) が K の 3 つ以上で「区間の下端 > 0 かつ Δφ ≥ 0.02」なら「依存の増加（誤りの相関の増加を伴う）」と書く．満たさなければ「依存の増加」と書き，Δφ の区間の下端が 0 より上で 0.02 に届かない K が 3 つ以上なら「（誤りの相関の増加は下限 0.02 に届かない）」，そうでなければ「（誤りの相関の増加は規則を満たさない）」と添える（「誤りの相関は増えていない」とは書かない）．
  2. **共有の比べ**：D(joint_a1[ρ = 1]) − D(tt_ownret) が H1 と同じ条件（区間の下端 > 0，0.02 以上，偶然の水準の条件）を K の 3 つ以上で満たせば，「同じ疑似ラベルを共有したことが依存を増やした（段 3 の共有．段 2 の共有は分けていない．ρ = 1，a = 1 の点で比べた）」と書く．満たさなければ「依存の増加は，同じ重みで各モダリティ自身の疑似ラベルで学んだ場合と分けられない（ρ = 1，a = 1 の点で比べた）」と書く．H1 は選んだ ρ の点で決まるので，joint_a1 の ρ が 1 でない (単位, K, モダリティ) の数を添える（第 7 版．dai-review-ml の m10）．φ の同じ差が 1 の φ の条件を満たせば，「誤りの相関も共有で増えた」と添える．共有の比べを満たした K について，3 と 4 と同じ確かめを共有の比べの差にも当て，満たさなければ「共有の比べも，同じ人物の別の動画が候補に残る漏れと分けられない」「共有で増えた依存の多くは話者（塊）の水準の共有である」と添える（第 7 版．dai-review-affect の b3）．D(tt_ownret) − D(none) と φ の同じ差は記述として並べる．
  3. **MOSEI の漏れ**：MOSEI では，H1 の条件を満たした K のうち，チャンネルが分かる発話の ΔD（3.3 節の部分集合の版）が「区間の下端 > 0 かつ全体の ΔD の点推定の半分以上」の K が 3 つ未満なら，「同じ人物の別の動画が候補に残る漏れと分けられない」と添える．
  4. **塊の水準の共有**：どのコーパスでも，H1 の条件を満たした K のうち，同じ発話の上で ΔD_cent の点推定が中心化しない ΔD_keep の点推定の半分未満の K が 3 つ以上なら，「増えた依存の多くは話者（塊）の水準の共有である」と添える．
  5. **IEMOCAP 即興**：IEMOCAP で H1 を満たしたときは，H1′ の合否に依らず「IEMOCAP 即興の依存の増加は筋書きの話題の共有と分けられない（筋書きで中心化した D を並べる）」と添える（第 7 版．dai-review-affect の b2．H1 だけを満たす枝は第 8 版で c1 により足した）．3 と 4 の添え書き（MOSEI の漏れ，塊の水準）は，H1 と H1′ の両方を満たした枝でだけ付ける．H1 だけを満たした枝の文は「正解で別々に学んだ分類器の依存の水準の中に収まる」で，蒸留で生じた増加とは書かないので，増加の中身についての添え書きは要らないためである（第 8 版．gate-code の第 5 回の記録 1）．
  - 「半分」（0.5）は第 1 版の値を開く前に決めた．
- **H2（Q2．量との関係）**：(c, K) ごとに，30 単位の D の平均を joint_a1[ρ] の 4 点で並べ，ρ との Spearman の順位相関を出す．K ∈ {1, 5, 10, 25} のうち 3 つ以上で，順位相関が 0.8 以上（4 点で 1 か所の逆転まで）かつ D(ρ = 4) − D(ρ = 0.0625) が「区間の下端 > 0 かつ 0.02 以上」のコーパスが 3 つ以上なら，「依存は疑似ラベルの重みとともに増える」と書く．4 点のでたらめな並びで順位相関が 0.8 以上になる確率は 1/6 であり，4 つの K は同じテストを共有するので K の間で独立でないと添える．あわせて，同じ 4 点の単独の分類器の UAR の平均を並べる．
- **H3（Q3．依存を無視した損が増える）**：H1 と同じ数え方を ΔL = L_dep(joint_a1) − L_dep(none) で行う（下限 0.5 ポイント）．joint でも同じ量を出す．
- **H4（Q3．依存を無視した損は，足し合わさらない分をどれだけ説明するか．dai-review-ml の M3・M4）**：前提 (iv) を満たしたコーパスで，joint_a1 について，前提 (iv) の区間の条件（G_prod − Ḡ の区間の上端 < 0）を満たした K だけを数える（第 7 版．m8）．そのうち ΔL_dep の区間の下端 > 0 で，S に占める ΔL_dep の割合の点推定が 0.5 以上の K が 3 つ以上なら「依存を無視した損が，足し合わさらない分の半分以上を説明する」，0.25 以上の K が 3 つ以上なら「依存を無視した損が，足し合わさらない分の一部（4 分の 1 以上）を説明する」と書く．どちらも満たさなければ，同じ K ごとに 4 つの分（Ḡ − Ḡ_cal，Ḡ_cal − G_full，ΔL_dep，ΔL_cal）のうち点推定が最も大きい分を求め，最も多く現れた分を「足し合わさらない分のうち最も大きいのは〜である」と書く．同点は全部を書く．どの場合も K ごとの割合と，3.6 節の h − h⁰ ≥ 0.5 のセルの数を添える（第 7 版．m8）．前提 (iv) を満たさないコーパスでは，足し合わさらない理由を書かない．joint_a1[ρ = 1] の同じ量は記述として並べる．割合の下限 0.25 と 0.5 は第 1 版の値を開く前に決めた．
- **K = 0** は規則の数え上げに入れず，同じ表に並べる（none が出発点で，ターゲットのラベルを使わないため）．
- **書き方**：H1〜H3 は記述の規則であり，検定ではない．どの規則も，満たしたかどうかにかかわらず全部のセルの値と区間を表に出す．満たさなかった規則は「満たさなかった」と書き，ほかの量で言い換えない．

## 8. 範囲の外と限界

- 点数（各モダリティ 3 次元）の依存だけを測る．特徴の空間で点数の向きの外にある依存は測らない（実験 6 の下調べが別に測った）．
- 単独の分類器とその積の融合を対象にする．融合の分類器（つないだ特徴の 1 つの線形分類器）が疑似ラベルで伸びない理由には直接答えない．研究者の問いの融合の分類器については，実験 6 の 0 節の数理の導出（同じ形の式なので疑似ラベルの項から新しく学ぶものが無い）が扱う．この下調べはその導出を確かめず，単独の分類器の得が積で足し合わさらない理由を足すだけである．
- **教師の共有と引き戻しの弱まり**（gate-code の R6，dai-review-ml の M2・m4）：各モダリティが自分の none[K] の予測で学ぶ対照は保存に無い．自分のモダリティの ret で学ぶ対照（tt_ownret）は保存にあり，joint_a1[ρ = 1] と同じ重みで引き戻しの相対的な弱まりをそろえるので，段 3 の共有を分ける．段 2 の共有（ret が融合の none[K] の予測で学び直してあること）は分けない．引き戻しの格子の none_tw が表せる弱まりは「C′ の最大 ÷ none の C′」までで，疑似ラベルの項による弱まり (4K + ρn)/(4K)（n は候補の本数．K = 5，ρ = 1 で 33〜746 倍）に届かないことがある．両方を `tether_weakening.csv` に並べる．教師の点数を除いた ΔD_t は分ける材料に使わない（3.3 節．dai-review-ml の M1）．結果の文はこの範囲に限る．
- **足し合わさらない分の残り**（dai-review-ml の M3・M4）：Ḡ − G_full には，判別分析が none にも与える較正と感情の事前の得（Ḡ − Ḡ_cal）が入る．Ḡ_cal − G_full が大きいコーパスでは，足し合わさらない主な理由は結合の仕方ではなく，単独の分類器どうしの情報の重なりか UAR の天井である．この下調べはこの 2 つを分けない．
- **性別**（gate-code の記録 4）：性別ごとの解析は，IEMOCAP（sample_id の後ろの F・M．前の F・M はマーカーの側で，即興の 4,784 本のうち 51% でしか話し手と一致しない．dai-review-affect の c3）と AFEW（発話一覧の gender）だけで後から出せる．MOSEI には性別の記録が無く，MELD は人物の名前からしか作れないので，範囲の外とする．
- **コーパスに固有の共有の要因**（dai-review-affect の A1・A2・a3〜a7）：
  - IEMOCAP 即興の筋書きの話題：同じ感情のラベルの中でも話題が発話ごとに違い（例：分割 0 の Neutral 287 本は 6〜8 の筋書きに散らばる），言葉の分類器を含む教師が話題ごとに違う確率を付けうる．筋書きで中心化した D（記述）と，IEMOCAP 即興を除いた数（4 節）で扱う．話者で中心化しても筋書きの共有は除かれない．交差の当てはめの 2 つの半分も同じ筋書きを共有するので，H3 の L_dep にも入る．
  - MOSEI の話者の分離が不完全であること（同じ人物の別の動画が候補に残りうる）は，候補の全部で学ぶ joint・joint_a1 と K 本だけで学ぶ none に違う形で入り，joint の側で依存が増える向きに入りうる．チャンネルが分かる発話の版（4 節の添え書き）で扱う．人物の ID が無いので，漏れた人物の数は数えられない．
  - 同じ感情の中の依存には，4 つのラベルが拾わない感情の違いが入る．IEMOCAP 即興の Happy の 70% は元のラベルが excited で，MOSEI の Neutral の 62.2% はどれかの感情の強さが 0 より大きく 0.5 未満である．感情の強さの違いも入る．
  - D の水準の違いを，コーパスごとのモダリティの関連の仕方の違いとは書かない．D の水準には，ラベルの決め方（MOSEI の Neutral は消去法，IEMOCAP の Happy は excited を含む，AFEW はフォルダの名前，MELD は公式のラベル），産出の型（自然な発話は MOSEI だけ），テストの話者の作り（MELD は各分割の 71〜82% が主役 1 人，AFEW の分割 0 は 1 つの塊が 97.5%）が入る．
  - AFEW では言葉の特徴が同じ音声の Whisper large-v3 の書き起こしから作られるので，声と言葉の依存の一部は作りの上で生じる．
  - 測らない共有の要因として，発話の長さ（短い発話では顔の特徴が 1 つのセグメント，音声は短い区間，言葉は少ない語から作られる）と，MELD の対話の場面がある．
- エンコーダ 2 は範囲の外である（保留．`DAI/CLAUDE.md`）．
- AFEW の分割 0 は塊が 3 つで最大の塊が 97% なので，大きい塊が抜かれない約 3 割の回で，D と UAR から作る量の両方からこの分割が外れる．抜き直しの分布の中では分割 0 の重みが点推定（分割を等しく平均）より小さくなる．AFEW の区間を述べる文にはこの構造を添える（gate-code の再検査の記録 3）．
- 3.5 節の結合器はテストの正解で推すので，配備できる手法の値ではない．L_dep は「依存を無視したときの損の大きさ」の参照である．L_dep の水準をコーパスの間で比べる文には，半分の本数の違いを添える．発話の単位で分けた分割（3.5 節の規則で，IEMOCAP の全分割，AFEW の分割 0，MELD の分割 0〜3 が当たる見込み．実際の分け方は `uar.csv` に残す）では，2 つの半分が同じ話者を共有し，full が blk より同じ話者の相関を使えるので L_dep が大きく出る向きがある．
- 依存が増えても，それが UAR の損に結びつくとは限らない（Averbeck ほか 2006．相関の向きと信号の向きの関係による）．Q3 はそのために置く．同じ感情の中の依存には，ラベルが拾わない感情の強さの違いなど，誤りでない共有も入る．柔らかい疑似ラベルでは，誤りでない教師の確率の揺れも 2 つの生徒に写る．4 節の書き方の規則（φ と組にする）で分けて書く．
- joint の点と none の引き戻しは，D と UAR を測るのと同じ c のテストの UAR で選んである（`DAI/exp/dai1_select.py`，`dai1.select_tether`）．このため G_m と G_prod は上に偏る．D は選びの基準ではない．
- 単位は独立でない（T と種の 6 単位が同じテストを共有し，分割は候補を共有する）．区間はテストの塊の揺れだけを表し，K 本の抜き方とソースの組の揺れは平均に含めるだけである．
- 30 単位の平均は，3 つの評価のターゲット T の固定のファイルが選んだ ρ と a の点をまたぐ．
- 仮のターゲットの回の分類器は 2 つのソースから作った出発点を使う（評価の回は 3 つ）．
