# 実験 7 の下調べ（DAI-7）：ほかのモダリティの疑似ラベルで蒸留すると，単独の分類器どうしの点数の依存が増えるか（2026-11-07．第 1 版）

## 0. 位置づけと，案の出どころの申告

- **研究者の問い（2026-11-07）**：「疑似ラベルが融合の分類器に何も教えない理由について，式を融合は今までの知見を活かして直接いじる．あるいはマルチモーダル性や，別のコーパスではモダリティの関連の仕方が違うことを意識した取り組みにできたりする？」．続けて，単独の分類器の点数を依存で組み直す融合の先行研究の調べと軽い試しを指示し（「よい．先行研究の調べを進めて．同時に，軽くその方法がうまくいきそうか試してみて」），その報告の後にこの下調べの設計を指示した（「よい．その下調べの設計を進めて」）．
- **この下調べの目的**：蒸留（ほかのモダリティを含む疑似ラベルで単独の分類器を学び直すこと）が，単独の分類器どうしの点数を同じ感情の中で似せる（依存を増やす）かを測る．増えるなら，「蒸留した単独の分類器は同じ疑似ラベルの誤りを写すので，それらを掛け合わせると同じ証拠を 2 回数え，単独の分類器の得が融合で足し合わさらない」という説明の 1 つの部品になる．手法は作らない．結果は説明の節の材料と，次の相談の材料にする．
- **案の出どころ**：`prior-work-diff` の報告（`research_notes/先行研究_モダリティの依存で組み直す融合_2026-11-07/report.md` 5 節の 3）が挙げた差分である．報告は「蒸留で単独の分類器どうしの依存の増え方を測った研究は見つからなかった」とする（同 6 節）．共訓練の分析（Wang と Zhou 2007）は 2 つの学習器の違いを共訓練が働く条件に置き，分類器の集団の多様さの量（Kuncheva と Whitaker 2003）と，相関を無視した復号の損（Averbeck ほか 2006 の ΔI_diag）は既知である．したがって量の定義は既知の部品で，新しく書けるのは「MER の 4 コーパスで，ほかのモダリティの疑似ラベルでの蒸留が，単独の分類器どうしの感情の中の点数の依存をどれだけ変え，その依存を無視した積の融合がどれだけ損をするか」の測定である．
- **見たものの申告**：設計の前に，本体は次を見た（`docs/seen-data.md` の 2026-11-07 の行）．(a) 軽い試し（`DAI/exp/explore_depfusion.py`，同じ仮のターゲットの回の 120 単位）の UAR の表と，提案で蒸留した単独の分類器（下の joint）の点数の，候補の上での感情の中の最大の正準相関（AFEW・IEMOCAP・MELD・MOSEI で声と言葉 0.60〜0.64，声と顔 0.45〜0.54，顔と言葉 0.29〜0.40）．(b) 実験 6 の下調べの途中の値（特徴の相互の共分散の 93〜99% が感情の中）．蒸留していない分類器の依存と，テストの上の依存は見ていない．下の仮説の向きは (a) の値からではなく，先行研究の報告の推論から決めた．
- **探索であること**：仮のターゲットの回のラベルは，評価に使う 4 コーパスと同じ発話・同じラベルである（`DAI/docs/実験4_設計.md` 0 節）．この下調べは確認の検定ではなく，記述と，計算の前に固定した数え上げの規則（4 節）で書く．

## 1. 問い

- **Q1（依存は増えるか）**：提案の蒸留で学んだ単独の分類器（joint）の点数は，蒸留しない単独の分類器（none）に比べて，同じ感情の中でモダリティの間の依存が大きいか．正解の全ラベルでそれぞれ別に学んだ単独の分類器（oracle）よりも大きいか．
- **Q2（蒸留の量との関係）**：疑似ラベルの項の重み ρ を大きくすると，依存は大きくなるか．
- **Q3（依存を無視した損）**：3 つの単独の分類器の点数を融合するとき，依存を無視した結合（ブロック対角の判別分析）と依存を入れた結合（完全な判別分析）の UAR の差（依存の分）は，joint の方が none より大きいか．あわせて，各モダリティの較正の分（ブロック対角の判別分析 − 積）と，単独の分類器の得と積の得の大きさを並べる．
- **Q4（どの疑似ラベルで増えるか．記述）**：2 つの単独の分類器が同じ 1 つのモデルの予測だけを疑似ラベルにして学んだとき（融合の none，none の積，ソースの融合の平均，第 3 のモダリティの none），依存はどれだけ増えるか．

## 3. 量の定義

### 3.1 点数

- 単独の分類器 m ∈ {A, V, T} の点数 Z_m = X_m W_mᵀ + b_m（4 感情）を，4 つに共通の足し算を除く 4×3 の正規直交の基底 H（1 のベクトルに直交）で z_m = Z_m H（3 個）にする．softmax の確率は 4 つに共通の足し算に依らないので，z_m は分類器の判定と確率を決める部分のすべてである．
- 3 つをつないだ z = (z_A, z_V, z_T)（9 個）．

### 3.2 単独の分類器の組（どれも保存から読む．学び直さない）

| 組 | 中身 | 保存 |
|---|---|---|
| none | K 本だけ（K = 0 は出発点＝ソースの分類器の平均）．引き戻しは単位の保存の値（`tether`） | `p1_<m>_W/b` の `K|C′|C_b`（`dai1.none_wb`） |
| ret | 疑似ラベルのモデルの因子（融合の none[K] の予測と K 本で学び直した単独の分類器） | `p2_K<K>_ret_<m>_W/b` |
| joint | 提案（主の版の疑似ラベル．固定のファイルの T の選んだ ρ と a） | `p3_<m>_K<K>_W/b` の項目 `method=joint, teacher=主の版, rho, a` |
| joint[ρ] | joint と同じ疑似ラベルと a で，ρ ∈ {0.0625, 0.25, 1, 4} の 4 点（Q2） | 同上の格子 |
| oracle | 候補の全ラベルでそれぞれ別に学んだ単独の分類器（正解だけで学んだときの依存の参照）．引き戻しは (m, K = 25) の値 | `p1_<m>_W/b` の `all|C′|C_b` |
| tt[q] | 疑似ラベルを 1 つのモデル q の予測だけにした学び直し（ρ = 1，a = 1）．q ∈ {fused_AVT（融合の none[K]），poe_none（none の積），start_AVT（ソースの融合の平均．ターゲットの情報を持たない），single_<第 3 のモダリティ>（組に入らないモダリティの none）}（Q4） | `p3_<m>_K<K>_W/b` の項目 `method=tt, teacher=q` |

- 組の 3 つのモダリティは同じ単位の同じ K の分類器である．tt[single_X] は，組 (m, m′) で X が m と m′ のどちらでもないときだけ使う（A–V なら single_T）．

### 3.3 感情の中の点数の依存 D（Q1・Q2・Q4 の主の量）

- テストの発話のうち感情 e の発話について，モダリティの組 (m, m′) の 3 次元の点数 z_m と z_m′ の標本の共分散 S_mm，S_m′m′，S_mm′（平均を引く）から，正準相関の 2 乗の平均 d_e(m, m′) = (1/3)·tr(S_mm⁻¹ S_mm′ S_m′m′⁻¹ S_m′m) を出す（0 以上 1 以下．3 つの正準相関の 2 乗の平均）．S に tr(S)/3 × 1e-6 を足して逆行列を取る．
- 正準相関は，モダリティごとの点数に可逆な 1 次変換をしても変わらない．したがって d は点数の尺度や温度，感情の間の混ざり方（較正）に依らず，2 つのモダリティの点数がどれだけ一緒に動くかだけを測る．
- **偶然の水準**：同じ感情の中で m′ の発話の並びを入れ替えた 200 回の d_e の平均 d_e⁰ を，観測したテストの上で 1 回だけ求める．D の各値は d_e − d_e⁰ とする．感情の発話が 15 本未満の (分割, 感情) は使わない（使わなかった数を出す）．
- D(m, m′) = 4 感情（使えたもの）の d_e − d_e⁰ の等しい重みの平均．D = 3 つの組の D(m, m′) の平均．
- **話者で中心化した版（副）**：テストの発話の点数から，(塊, 感情) ごとの平均を引いてから同じ量を出す（IEMOCAP は `speaker_id`，ほかは塊．3 本未満の (塊, 感情) の発話は外す）．話者ごとにモダリティが一緒にずれる分を除いた依存である．

### 3.4 誤りの相関（副）

- 単独の分類器 m の判定が正しいかの 0/1 を，同じ感情 e の発話の中で組 (m, m′) について比べ，φ 係数（2×2 の表の相関）を出す．4 感情の等しい重みの平均を φ(m, m′)，3 組の平均を φ とする（Kuncheva と Whitaker 2003 の相関の量を感情の中で取ったもの）．どちらかの分類器の正誤が感情の中で 1 通りしかない (分割, 感情) は使わない．

### 3.5 依存を無視した損と較正の分（Q3）

- 3 つの組の点数 z（9 個）に，感情で共通の共分散の判別分析（判定は感情の事前を等しくした δ_c(z) = μ_cᵀ P z − ½ μ_cᵀ P μ_c，P = (Σ + 1e-3·tr(Σ)/9·I)⁻¹）を当てる．μ と Σ はテストの正解の半分で推し，残りの半分に当てる（2 つに分けて入れ替える交差の当てはめ）．分け方は，テストの塊が 2 つ以上ある分割は塊の単位（塊を並べ替えて発話の数が半分に近くなるよう貪欲に割る．種 0），塊が 1 つの分割（IEMOCAP の全分割と MELD の分割 4 の一部など．`cluster` の数で決める）は感情で層にした発話の単位とする．
  - full：Σ をそのまま使う（依存も入れた結合）．
  - blk：Σ のモダリティをまたぐ 3×3 のブロックを 0 にする（各モダリティの較正だけを直し，依存を無視した結合）．
  - prod：Σ_m Z_m の argmax（確率の積．Λ = I）．
- 依存の分 L_dep = UAR(full) − UAR(blk)，較正の分 L_cal = UAR(blk) − UAR(prod)．どちらもテストの正解で推した結合器の値で，配備できる量ではない（Averbeck ほか 2006 の ΔI_diag と同じ「相関を無視した最適な復号器の損」の考え方）．
- **得の足し合わせ（記述）**：単独の得 G_m = UAR(joint_m) − UAR(none_m)，積の得 G_prod = UAR(prod[joint]) − UAR(prod[none])，完全な結合の得 G_full = UAR(full[joint]) − UAR(full[none])．

### 3.6 前提の表（関門の D8）

| 前提 | 何に要るか | 確かめ方 |
|---|---|---|
| テストの点数は候補の学習に使っていない | 依存の楽観を避ける | テストの話者は候補に入らない（`DAI/splits/`）．同じ単位の候補の上の D も副に出し，テストとの差を並べる |
| 偶然の水準は組の間でほぼ同じ | none と joint の D の差が偶然の水準の違いで生じない | 組ごとの d_e⁰ を出し，none と joint の差を並べる |
| 3 次元の点数で依存を表せる | D の意味 | z は判定と確率を決める部分のすべて（3.1 節）．点数の外の特徴の依存は測らない（8 節） |
| 判別分析の結合器の仮定（感情で共通の共分散の正規分布） | L_dep と L_cal の意味 | 仮定が崩れても L_dep は「この結合器での差」として書く．感情ごとの共分散の違い（Box の M の代わりに，感情ごとの Σ_e と共通の Σ のフロベニウスの比）を出す |

## 4. 判定の規則（計算の前に固定）

- **ばらつき**：実験 6 の下調べと同じく，c の 5 分割のテストの塊をまとめた 1 つの集まりから塊を抜き直し（1,000 回．同じ抜き直しを全部の量に共通に使う），各塊が属する分割の中で量を作り，抜かれた分割について平均する（`DAI/exp/dai6_probe.py` の `_boot_fold_mean` と同じ重みのつけ方）．D は (塊, 感情) ごとの点数の和と積の和から重みつきの共分散を作り直して求める（偶然の水準 d_e⁰ は観測の値に固定する）．UAR は保存した判定から作る．φ は (塊, 感情) ごとの 2×2 の表の数から作る．95% 区間を出す．IEMOCAP は塊が 5 つ（分割ごとに 1 つ）なので区間は粗いと書く．
- **H1（Q1．依存が増える）**：c ごとに，K ∈ {1, 5, 10, 25} のうち 3 つ以上で ΔD = D(joint) − D(none) の区間の下端が 0 より上なら，「c で蒸留が依存を増やした」と書く．4 コーパスのうち 3 つ以上で満たせば，「蒸留は単独の分類器どうしの依存を増やす」と書く．区間の上端が 0 より下のセルがあれば，数を書く．
- **H1′（Q1．正解で学んだときより大きい）**：同じ数え方を D(joint) − D(oracle) で行う．H1 を満たし H1′ を満たさないときは，「依存の増え方は，正解で別々に学んだ分類器の依存の水準の中に収まる」と書き，写した誤りによる増加とは書かない．
- **H2（Q2．量との関係）**：(c, K) ごとに，30 単位の D の平均を ρ の 4 点で並べ，ρ との Spearman の順位相関を出す．K ∈ {1, 5, 10, 25} のうち 3 つ以上で順位相関が 0.8 以上（4 点で 1 か所の逆転まで）のコーパスが 3 つ以上なら，「依存は疑似ラベルの重みとともに増える」と書く．あわせて，同じ ρ の 4 点の単独の分類器の UAR の平均を並べる（依存の増え方が UAR の増え方と違う形かを記述する）．
- **H3（Q3．依存を無視した損が増える）**：H1 と同じ数え方を ΔL = L_dep(joint) − L_dep(none) で行う．
- **K = 0** は 4 つの規則の数え上げに入れず，同じ表に並べる（none が出発点で，ターゲットのラベルを使わないため）．
- **書き方**：H1〜H3 は記述の規則であり，検定ではない．どの規則も，満たしたかどうかにかかわらず全部のセルの値と区間を表に出す．満たさなかった規則は「満たさなかった」と書き，ほかの量で言い換えない．

## 8. 範囲の外と限界

- 点数（各モダリティ 3 次元）の依存だけを測る．特徴の空間で点数の向きの外にある依存は測らない（実験 6 の下調べが別に測った）．
- 3.5 節の結合器はテストの正解で推すので，配備できる手法の値ではない．L_dep は「依存を無視したときの損の大きさ」の参照である．
- 依存が増えても，それが UAR の損に結びつくとは限らない（Averbeck ほか 2006．相関の向きと信号の向きの関係による）．Q3 はそのために置く．同じ感情の中の依存には，ラベルが拾わない感情の強さの違いなど，誤りでない共有も入る．H1′ の oracle との比べと，3.4 節の誤りの相関で分けて書く．
- 単位は独立でない（T と種の 6 単位が同じテストを共有し，分割は候補を共有する）．区間はテストの塊の揺れだけを表し，K 本の抜き方とソースの組の揺れは平均に含めるだけである．
- 30 単位の平均は，3 つの評価のターゲット T の固定のファイルが選んだ ρ と a の点をまたぐ．joint の ρ と a は T ごとに違いうる．
- 仮のターゲットの回の分類器は 2 つのソースから作った出発点を使う（評価の回は 3 つ）．
- 実験 1 の固定のファイルの選び方は，この下調べとは別に，仮のターゲットの UAR で決めたものである．
