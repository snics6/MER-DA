## 1. 問い

- **Q1（依存は増えるか）**：蒸留で学んだ単独の分類器（joint，joint_a1）の点数は，蒸留しない単独の分類器（none）に比べて，同じ感情の中でモダリティの間の依存が大きいか．正解の全ラベルでそれぞれ別に学んだ単独の分類器（oracle）よりも大きいか．増えた分は，誤りの写しか，教師の点数の揺れの写しか．
- **Q2（蒸留の量との関係）**：K 本の倍率 a を 1 に固定して疑似ラベルの項の重み ρ を大きくすると，依存は大きくなるか．
- **Q3（依存を無視した損と，得の足し合わせ）**：3 つの単独の分類器の点数を融合するとき，依存を無視した結合（ブロック対角の判別分析）と依存を入れた結合（完全な判別分析）の UAR の差（依存の分）は，joint の方が none より大きいか．単独の分類器の得は積の融合で足し合わさるか．
- **Q4（どの疑似ラベルで増えるか．記述）**：2 つの単独の分類器が同じ 1 つのモデルの予測だけを疑似ラベルにして学んだとき（none の積，ソースの融合の平均，第 3 のモダリティの none．融合の none は ret と同じ問なので数えない），依存はどれだけ増えるか．

## 2. データと単位

- 実験 1 の**仮のターゲットの回**の保存（`results/dai1/pseudo/units/<T>_<c>_f<f>_r<r>_p{1,2,3}.npz`）だけを使う．3 本とも，固定のファイル `DAI/frozen/dai1_frozen.json` の T の `pseudo_commit` で作られたことを確かめる．単位は評価のターゲット T（4），仮のターゲット c（T 以外の 3），分割 f（5），K 本の抜き方の種 r（2）の 120 個で，ソースは T と c 以外の 2 コーパスである．評価のターゲット T のデータは単位に入らない．実験 1 の評価の回の保存（`results/dai1/eval/`）は使わない．
- 特徴は `dai1.Unit`（`dai_data.load_corpus` を通す．取り決め 1〜6 は `measure/data.py` の `load_group`）で読み，実験 1 と同じく候補の統計で標準化する．保存した W・b を候補とテストの特徴に当てて点数を作り直す．新しく学ぶのは 3.5 節の 9 次元の判別分析と，3.3 節の教師の点数への回帰だけである．発話の並びとラベルが保存と発話一覧に一致することを単位ごとに確かめる．
- K ∈ {0, 1, 5, 10, 25}．**依存と UAR はすべて仮のターゲット c のテスト（分割 f）の上で測る**．単独の分類器は候補の発話（K 本と疑似ラベルを付けたラベル無しの発話）で学んでいるので，候補の上の点数は学習に使った発話の値で，依存が楽観に偏る（先行研究の報告 5 節の 4，Duin 2002）．テストの話者は候補に入らない．
- **集計の単位**：(c, K) のセルごとに，3 つの T × 5 分割 × 2 種の 30 単位を平均する．同じ c の同じ分割のテストは，T と種の 6 単位で共有される．独立に近いのはテストの塊（話者の代わり．IEMOCAP はセッションで分割ごとに 1 つ）で，区間は 4 節の塊のブートストラップで作る．
- テストの大きさ（分割ごと）：AFEW 158 本（感情ごとに 21〜68．分割 0 は塊 3 つで最大の塊が 97%），IEMOCAP 521〜731 本（同 22〜287．塊は分割ごとに 1 つ），MELD 2,104〜2,850 本（分割 0〜3 は塊 65〜70 で最大の塊が 71〜82%，分割 4 は塊 2 つで各 50%），MOSEI 3,726〜3,727 本（塊 521〜524）．

## 3. 量の定義

### 3.1 点数

- 単独の分類器 m ∈ {A, V, T} の点数 Z_m = X_m W_mᵀ + b_m（4 感情）を，4 つに共通の足し算を除く 4×3 の正規直交の基底 H（1 のベクトルに直交）で z_m = Z_m H（3 個）にする．softmax の確率は 4 つに共通の足し算に依らないので，z_m は分類器の判定と確率を決める部分のすべてである．
- 3 つをつないだ z = (z_A, z_V, z_T)（9 個）．

### 3.2 単独の分類器の組（どれも保存から読む．学び直さない）

| 組 | 中身 | 保存 |
|---|---|---|
| none | K 本だけ（K = 0 は出発点＝ソースの分類器の平均）．引き戻しは単位の保存の値（`tether`） | `p1_<m>_W/b` の `K|C′|C_b`（`dai1.none_wb` と同じ） |
| ret | 疑似ラベルのモデルの因子（融合の none[K] の予測と K 本で学び直した単独の分類器） | `p2_K<K>_ret_<m>_W/b` |
| joint | 提案（主の版の疑似ラベル．固定のファイルの `<m>|<K>|joint|<主の版>` の ρ と a） | `p3_<m>_K<K>_W/b` の項目 `method=joint, teacher=主の版, rho, a` |
| joint_a1 | 提案の a を 1 に固定し ρ だけを選んだ点（固定のファイルの `<m>|<K>|joint_a1|<主の版>`） | 同上の項目（a = 1） |
| joint_a1[ρ] | a = 1 で ρ ∈ {0.0625, 0.25, 1, 4} の 4 点（Q2．joint_a1 はこのどれか 1 つと同じ） | 同上の格子 |
| oracle | 候補の全ラベルでそれぞれ別に学んだ単独の分類器（正解だけで学んだときの依存の参照）．引き戻しは (m, K = 25) の値．K に依らない | `p1_<m>_W/b` の `all|C′|C_b` |
| tt[q] | 疑似ラベルを 1 つのモデル q の予測だけにした学び直し（ρ = 1，a = 1）．q ∈ {poe_none（none の積），start_AVT（ソースの融合の平均．ターゲットの情報を持たない），single_<第 3 のモダリティ>（組に入らないモダリティの none）}（Q4） | `p3_<m>_K<K>_W/b` の項目 `method=tt, teacher=q` |
| tt[fused_AVT] | ret と同じ最適化の問（目標 `gK + soft_rows(none_AVT, n)`，同じ出発点と引き戻し．`DAI/exp/dai1.py` の `pass2` と `make_G`）．ret との D の差を数値の誤差の確かめに使うだけで，Q4 の証拠に数えない | 同上 |

- 組の 3 つのモダリティは同じ単位の同じ K の分類器である．tt[single_X] は，組 (m, m′) で X が m と m′ のどちらでもないときだけ使う（A–V なら single_T）．
- **比べる 2 つの組で違うつまみ**（C14 の案）：none と joint は，疑似ラベルの項（ρ）と K 本の倍率 a の 2 つが違う．none と joint_a1 は ρ だけが違う（a = 1，同じ出発点と引き戻し）．このため「疑似ラベルの項が依存を増やした」と書く根拠は joint_a1 とする（4 節）．

### 3.3 感情の中の点数の依存 D（Q1・Q2・Q4 の主の量）

- テストの発話のうち感情 e の発話について，モダリティの組 (m, m′) の 3 次元の点数 z_m と z_m′ の標本の共分散 S_mm，S_m′m′，S_mm′（平均を引く）から，正準相関の 2 乗の平均 d_e(m, m′) = (1/3)·tr(S_mm⁻¹ S_mm′ S_m′m′⁻¹ S_m′m) を出す（0 以上 1 以下）．S に tr(S)/3 × 1e-6 を足して逆行列を取る．
- 正準相関は，モダリティごとの点数に可逆な 1 次変換をしても変わらない（足した 1e-6 の分を除く）．したがって d は点数の尺度や温度，感情の間の混ざり方（較正）に依らず，2 つのモダリティの点数がどれだけ一緒に動くかだけを測る．
- **偶然の水準**：同じ感情の中で m′ の発話の並びを入れ替えた 200 回の d_e の平均 d_e⁰ を，観測したテストの上で 1 回だけ求める．D の各値は d_e − d_e⁰ とする．感情の発話が 15 本未満の (分割, 感情) は使わない（使った感情の数を出す）．
- D(m, m′) = 使えた感情の d_e − d_e⁰ の等しい重みの平均．D = 3 つの組の D(m, m′) の平均．
- **候補の上の D（副）**：同じ量を候補の発話と候補の正解で出す（偶然の水準は 50 回の並べ替え）．テストの D との差を，候補の上の楽観の大きさとして記述するだけで，判定には使わない．
- **話者で中心化した版（副）**：テストの発話の点数から，(グループ, 感情) ごとの平均を引いてから同じ量を出す（グループは IEMOCAP が `speaker_id`，ほかは塊．3 本未満の (グループ, 感情) の発話は外し，外した数を残す）．偶然の水準は，中心化した点数の上で，(グループ, 感情) の中で並べ替えて出す（中心化で減った自由度を帰無に入れるため）．
- **教師の点数を除いた依存（副．D20 の案．4 節の書き方の規則に使う）**：joint の疑似ラベルの元の点数 t（主の版の積．`one` なら ret の 3 つの対数確率の和，`sel` なら学習で使った単位の `wsel` の指数の重みつきの和で，固定のファイルの `w` と一致するかを単位ごとに確かめる．4 つを H で 3 個にする）をテストの上で作り，感情 e の中で z_m と z_m′ をそれぞれ t（と定数）に回帰した残りの正準相関から同じ量を出す（偶然の水準は残りの並べ替え）．同じ t を none と oracle にも当てて出す．

### 3.4 誤りの相関 φ（Q1 の書き方に使う）

- 単独の分類器 m の判定が正しいかの 0/1 を，同じ感情 e の発話の中で組 (m, m′) について比べ，φ 係数（2×2 の表の相関）を出す．使えた感情の等しい重みの平均を φ(m, m′)，3 組の平均を φ とする（Kuncheva と Whitaker 2003 の相関の量を感情の中で取ったもの）．15 本未満の感情と，どちらかの分類器の正誤が感情の中で 1 通りしかない (分割, 感情) は使わない．

### 3.5 依存を無視した損と較正の分（Q3）

- 3 つの組の点数 z（9 個）に，感情で共通の共分散の判別分析（判定は感情の事前を等しくした δ_c(z) = μ_cᵀ P z − ½ μ_cᵀ P μ_c，P = (Σ + 1e-3·tr(Σ)/9·I)⁻¹）を当てる．μ と Σ はテストの正解の半分で推し，残りの半分に当てる（2 つに分けて入れ替える交差の当てはめ）．
- **分け方**（D21 の案）：テストの塊を大きい順に並べ（同じ大きさは名前の順），発話の少ない方の半分へ 1 つずつ入れる．こうして割った 2 つの半分が，(a) どちらも各感情 5 本以上で，(b) 小さい方の半分がテストの 30% 以上なら，塊の単位で分ける．そうでなければ，感情で層にした発話の単位で分ける（感情ごとに発話を種 0 で並べ替え，交互に割る）．どちらで分けたかと 2 つの半分の本数を `uar.csv` に残す．
  - full：Σ をそのまま使う（依存も入れた結合）．
  - blk：Σ のモダリティをまたぐ 3×3 のブロックを 0 にする（各モダリティの較正だけを直し，依存を無視した結合）．
  - prod：Σ_m Z_m の argmax（確率の積．Λ = I）．
- 依存の分 L_dep = UAR(full) − UAR(blk)，較正の分 L_cal = UAR(blk) − UAR(prod)．どちらもテストの正解で推した結合器の値で，配備できる量ではない（Averbeck ほか 2006 の ΔI_diag と同じ「相関を無視した最適な復号器の損」の考え方）．full の Σ は 45 個，blk は 18 個の母数を持つので，半分の本数が少ないと full の推定の揺れで L_dep が小さく出る向きがある．半分の本数を 9 で割った値を残す．
- **得の足し合わせ**：単独の得 G_m = UAR(joint_m) − UAR(none_m)，積の得 G_prod = UAR(prod[joint]) − UAR(prod[none])，完全な結合の得 G_full = UAR(full[joint]) − UAR(full[none])．joint_a1 についても同じ量を出す．

### 3.6 前提の表（関門の D8．基準は計算の前に固定）

| 前提 | 何に要るか | 測る量 | 成り立つとみなす基準と，満たさないときの書き方 |
|---|---|---|---|
| テストの点数は候補の学習に使っていない | 依存の楽観を避ける | テストの話者が候補に入らないこと（`DAI/splits/`） | 分割の作りで成り立つ．候補の上の D との差は楽観の大きさの記述だけに使う |
| 偶然の水準は組の間でほぼ同じ | ΔD が偶然の水準の違いで生じない | Δd⁰ = d⁰(joint) − d⁰(none)（セルごと，3 組と 4 感情の平均） | \|Δd⁰\| < 0.1·\|ΔD\| のセルだけを H1 の「下限も満たした」に数える．満たさないセルは数を書く |
| 3 次元の点数で依存を表せる | D の意味 | — | z は判定と確率を決める部分のすべて（3.1 節）．点数の外の特徴の依存は測らない（8 節） |
| 判別分析の結合器の仮定（感情で共通の共分散） | L_dep と L_cal の意味 | テストの 9 次元の点数 z で，h = （15 本以上の感情 e についての）‖Σ_e − Σ‖_F / ‖Σ‖_F の平均（Σ_e は感情 e の発話の共分散，Σ は感情の平均を引いた共通の共分散）．偶然の水準 h⁰ は感情のラベルをテストの中で並べ替えた 50 回の h の平均で，h − h⁰ を使う | h − h⁰ ≥ 0.5 のセルでは，L_dep を「この結合器での差」とだけ書き，ΔI_diag の意味では書かない |
| 単独の分類器の得が積の融合で足し合わさらない（説明の筋の (iv)） | (ii)(iii) が説明する対象があるか | joint_a1 の G_prod − (1/3)Σ_m G_m（4 節と同じ塊の抜き直しで区間を作る）．選んでいない joint_a1[ρ = 1] の同じ量（区間つき）と，joint の同じ量（記述）を並べる | K ∈ {1, 5, 10, 25} のうち 3 つ以上で区間の上端が 0 より下のコーパスを「足し合わさらない」とする．満たさないコーパスでは，(ii)(iii) を「足し合わさらない理由」として書かない．判定を joint_a1 で行うのは H1 の根拠と同じ組にするためである．joint_a1 も ρ の 4 点から単独の UAR で選んだ点なので G_m がわずかに上に寄り，その向きは前提が成り立つ側である．joint は (ρ, a) の 12 点から選んだので寄りが大きい．joint_a1[ρ = 1] は選んでいない対照である |

## 4. 判定の規則（計算の前に固定）

- **ばらつき**：実験 6 の下調べと同じく，c の 5 分割のテストの塊をまとめた 1 つの集まりから塊を抜き直し（1,000 回．同じ抜き直しを全部の量と全部の組に共通に使う），次の手順で値を作る．
  1. 単位ごとに，抜かれた塊の発話（重複を重みとして数える）で量を作る．D は (塊, 感情) ごとの点数の和と積の和から重みつきの共分散を作り直して求め，偶然の水準 d_e⁰ は観測の値に固定する．UAR と φ は (塊, 感情) ごとの数から作る．
  2. その回で重みつきの本数が 15 本未満になった (単位, 感情) は，その回だけその感情を外す（D と φ は残りの感情で平均する）．使える感情が 1 つも無い単位はその回だけ外す．
  3. 分割の値は，その分割のテストを共有する 6 単位（3 つの T × 2 種）のうちその回に値のある単位の平均とする．
  4. 抜かれた分割について，「抜かれた塊の数 ÷ 分割の塊の数」の重みで平均する（`DAI/exp/dai6_probe.py` の `_boot_fold_mean` と同じ重み）．
  5. 有効な回の数（値が有限の回）を `diffs.csv` に残す．
  6. 95% 区間を作る．d⁰ を固定するので，区間は ΔD・Δφ・ΔL などの**差**について判定に使い，D の水準の区間は参考とする．IEMOCAP は塊が 5 つ（分割ごとに 1 つ）なので区間は粗いと書く．
- **下限**：ΔD（依存）と Δφ（誤りの相関）は 0.02，ΔL（UAR の差）は 0.5 ポイントとする．「区間の下端が 0 より上」だけを満たしたセルと，「区間の下端が 0 より上で，点推定が下限以上」の両方を満たしたセルの数を `criteria.csv` に残す．判定には後者を使う．
- **H1（Q1．依存が増える）**：c ごとに，K ∈ {1, 5, 10, 25} のうち 3 つ以上で ΔD = D(joint_a1) − D(none) が「区間の下端 > 0 かつ ΔD ≥ 0.02 かつ \|Δd⁰\| < 0.1·\|ΔD\|」を満たせば，「c で疑似ラベルの項が依存を増やした」と書く．4 コーパスのうち 3 つ以上で満たせば，「蒸留は単独の分類器どうしの依存を増やす」と書く．同じ数え方を D(joint) − D(none) でも行い，joint だけで満たしたコーパスは「K 本の倍率 a の効果を分けていない」と書く．区間の上端が 0 より下のセルがあれば，数を書く．
- **H1′（Q1．正解で学んだときより大きい）**：同じ数え方を D(joint_a1) − D(oracle) で行う．H1 を満たし H1′ を満たさないコーパスでは，「依存の増え方は，正解で別々に学んだ分類器の依存の水準の中に収まる」と書き，写しによる増加とは書かない．
- **H1 の書き方（誤りの写しか，教師の揺れの写しか）**：H1 と H1′ の両方を満たしたコーパスについて，次の順に当てはめる．
  1. Δφ = φ(joint_a1) − φ(none) が K の 3 つ以上で「区間の下端 > 0 かつ Δφ ≥ 0.02」なら，「誤りの写しを含む依存の増加」と書く．
  2. 1 を満たさず，教師の点数を除いた依存の差 ΔD_t = D_t(joint_a1) − D_t(none)（3.3 節の副．点推定）が，ΔD が H1 の条件（区間の下端 > 0，下限，偶然の水準）を満たした K のうち 3 つ以上で ΔD の半分以下なら，「教師の点数の揺れの写しによる依存の増加」と書く．
  3. 1 も 2 も満たさなければ，「依存は増えたが，誤りの写しとも教師の点数の揺れの写しとも分けられない」と書く．
  4. 2 と 3 で，Δφ の区間の下端が 0 より上で 0.02 に届かない K が 3 つ以上あれば，「誤りの相関の増加は下限 0.02 に届かない」と添える（「誤りの相関は増えていない」とは書かない）．
- **H2（Q2．量との関係）**：(c, K) ごとに，30 単位の D の平均を joint_a1[ρ] の 4 点で並べ，ρ との Spearman の順位相関を出す．K ∈ {1, 5, 10, 25} のうち 3 つ以上で，順位相関が 0.8 以上（4 点で 1 か所の逆転まで）かつ D(ρ = 4) − D(ρ = 0.0625) が「区間の下端 > 0 かつ 0.02 以上」のコーパスが 3 つ以上なら，「依存は疑似ラベルの重みとともに増える」と書く．4 点のでたらめな並びで順位相関が 0.8 以上になる確率は 1/6 であり，4 つの K は同じテストを共有するので K の間で独立でないと添える．あわせて，同じ 4 点の単独の分類器の UAR の平均を並べる．
- **H3（Q3．依存を無視した損が増える）**：H1 と同じ数え方を ΔL = L_dep(joint_a1) − L_dep(none) で行う（下限 0.5 ポイント）．joint でも同じ量を出す．
- **K = 0** は規則の数え上げに入れず，同じ表に並べる（none が出発点で，ターゲットのラベルを使わないため）．
- **書き方**：H1〜H3 は記述の規則であり，検定ではない．どの規則も，満たしたかどうかにかかわらず全部のセルの値と区間を表に出す．満たさなかった規則は「満たさなかった」と書き，ほかの量で言い換えない．

## 5. 出力（`results/dai7_probe_v2/`．第 1 版の台本の出力 `results/dai7_probe/` とは分ける）

- `rows/<単位>_units.csv`：単位 × K × 組 × モダリティの組ごとに，テストの D と d_e⁰（感情ごと），候補の上の D，話者で中心化した D と外した数，教師の点数を除いた D，φ，使った感情の数．
- `rows/<単位>_uar.csv`：単位 × K × 組ごとに，単独の 3 つの UAR，prod，blk，full のテストの UAR，L_dep，L_cal，h，交差の当てはめの分け方と 2 つの半分の本数．
- `cells.csv`・`uar_cells.csv`：(c, K, 組) ごとの 30 単位の平均．
- `diffs.csv`：ΔD・Δφ・ΔL・Δd⁰・G などの差の点推定と 95% 区間，有効な回の数．
- `criteria.csv`：H1・H1（joint）・H1′・H1 の書き方・H2・H3 と前提の表の数え上げ（区間だけのセルと下限も満たしたセルの両方）．
- `fits/<単位>.npz`：K × 組ごとのテストの点数 z（float32），教師の点数 t，単独・blk・full・prod の判定，テストの sample_id・塊・グループ・感情，交差の当てはめの半分．
- `provenance.json`：コミット，入力の sha256（固定のファイル，各単位の p1〜p3），乱数の種，定数，ソフトの版．

## 7. 見たデータと漏れ

- 使うのは仮のターゲットの回の保存だけで，評価の回の値は使わない．評価のターゲット T のデータは単位に入らない．
- 0 節の (a)〜(d) が設計の前と途中に見たものである．(a) では joint と ret の単独・積・判別分析（ブロックを 0 にした版を含む）のテストの UAR を見ており，Q3 の joint の部分は見た値と同じ種類の量である．none・oracle・tt の依存と UAR は，(c) の判定の数を除いて見ていない．
- 手法の形は決めないので，評価の回の「1 回だけ」の規則には触れない．この下調べから手法を作るときは，評価に使う 4 コーパスで作ったことを手法の設計と論文の限界に写し，その設計で改めて関門を通す．

## 8. 範囲の外と限界

- 点数（各モダリティ 3 次元）の依存だけを測る．特徴の空間で点数の向きの外にある依存は測らない（実験 6 の下調べが別に測った）．
- 単独の分類器とその積の融合を対象にする．融合の分類器（つないだ特徴の 1 つの線形分類器）が疑似ラベルで伸びない理由には直接答えない．研究者の問いの融合の分類器については，実験 6 の 0 節の数理の導出（同じ形の式なので疑似ラベルの項から新しく学ぶものが無い）が扱う．この下調べはその導出を確かめず，単独の分類器の得が積で足し合わさらない理由を足すだけである．
- 3.5 節の結合器はテストの正解で推すので，配備できる手法の値ではない．L_dep は「依存を無視したときの損の大きさ」の参照である．L_dep の水準をコーパスの間で比べる文には，半分の本数の違いを添える．発話の単位で分けた分割（3.5 節の規則で，IEMOCAP の全分割，AFEW の分割 0，MELD の分割 0〜3 が当たる見込み．実際の分け方は `uar.csv` に残す）では，2 つの半分が同じ話者を共有し，full が blk より同じ話者の相関を使えるので L_dep が大きく出る向きがある．
- 依存が増えても，それが UAR の損に結びつくとは限らない（Averbeck ほか 2006．相関の向きと信号の向きの関係による）．Q3 はそのために置く．同じ感情の中の依存には，ラベルが拾わない感情の強さの違いなど，誤りでない共有も入る．柔らかい疑似ラベルでは，誤りでない教師の確率の揺れも 2 つの生徒に写る．4 節の書き方の規則（φ と組にする）で分けて書く．
- joint の点と none の引き戻しは，D と UAR を測るのと同じ c のテストの UAR で選んである（`DAI/exp/dai1_select.py`，`dai1.select_tether`）．このため G_m と G_prod は上に偏る．D は選びの基準ではない．
- 単位は独立でない（T と種の 6 単位が同じテストを共有し，分割は候補を共有する）．区間はテストの塊の揺れだけを表し，K 本の抜き方とソースの組の揺れは平均に含めるだけである．
- 30 単位の平均は，3 つの評価のターゲット T の固定のファイルが選んだ ρ と a の点をまたぐ．
- 仮のターゲットの回の分類器は 2 つのソースから作った出発点を使う（評価の回は 3 つ）．
