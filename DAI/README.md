# DAI：少数のターゲットラベルでのマルチモーダル感情認識の転移の解析

新しいコーパス（ターゲット）に感情ごとに K 本のラベルしか無いとき，ほかのコーパス（ソース）のデータと分類器を使うと
声・顔・言葉の分類器の UAR がどう変わるかを測り，その仕組みを解析し，解析から作ったまとめ方の手法を評価する研究のコードと記録である．
論文は Discover Artificial Intelligence に出す解析論文で，原稿は `paper/` にある．

このフォルダは，データ（コーパスの音声・映像・書き起こしと，そこから作った特徴）と大きい中間の結果を除けば，
単独で論文の実験を流し直せるようにまとめてある（2026-11-15 に整理した．整理の前の置き場との対応は `docs/整理の対応表_2026-11-15.tsv`）．

## 入口

| 知りたいこと | 文書 |
|---|---|
| 論文の節ごとに，どの実験・台本・結果・結果の文を使うか | `docs/実験の地図.md` |
| 環境を作り，特徴を作り，実験を流す手順 | `docs/再現の手順.md` |
| データの扱い（ラベルの貼り直し，話者の分け方，特徴の作り方） | `data/README.md` |
| 採用した主張 | `docs/主張/主張_採用した説明_2026-11-13.md` |
| 作業の決まり（実験の関門，査読想定の役） | `CLAUDE.md`，`docs/methods.md` 9 節 |

## フォルダ

| 場所 | 中身 |
|---|---|
| `exp/` | 論文に使う実験の台本．論文の前半（E75・E76・E77〜E80・E79・付録の E32）と後半（実験 1〜3，11〜18，20，21）の両方 |
| `run/` | 起動の台本（段を続けて流すもの） |
| `tools/` | 結果の表を書き出す道具，計算の後の解析，整理の道具 |
| `measure/`，`features/` | 特徴の読み込み・話者の分割・ずれの指標の部品と，特徴を作る台本 |
| `data/` | 発話一覧（ラベルと話者の正本），顔の座標，データの文書．特徴（`data/cache/*.npz`）は git に入れない |
| `frozen/`，`splits/` | 計算の前に固定した設定と，コーパスごとの 5 分割 |
| `docs/` | 設計（`設計/`），結果の文と表（`結果/`），主張（`主張/`），計画（`計画/`），説明の資料（`説明/`），記録（`記録/`），MER-DA から移した共有の文書 7 本（研究計画・方法・台帳など．直下），読むだけの資料（`参照/`） |
| `results/` | 結果の集計と記録（git に入れる分の一覧は `results/MANIFEST.tsv`，git の外の分は `results/MANIFEST_outside_git.tsv`） |
| `checks/` | 計算の前後の検査役と査読想定の役の報告（`checks/README.md`） |
| `paper/`，`reviews/` | 論文の原稿と，原稿の段の査読想定の報告 |
| `slides/` | 発表資料の原稿（再現の対象にしない） |
| `research_notes/` | 調べ直しのノートと論文の相談のノート（2026-11-15 に MER-DA の直下から移した） |
| `archive/` | 論文に使わない実験の台本・設計・検査の報告（`archive/README.md`） |

## 公開の前に決めること

- `data/metadata/` と `splits/`・`frozen/subsets.csv` は，コーパスの発話の ID・話者・ラベル・書き起こしを含む．公開のリポジトリに入れるかは，各コーパスの利用条件を確かめてから決める．
- `docs/` の直下の 7 本（`researchvision.md`・`methods.md` など）は MER-DA から移した共有の文書の正本で，研究の経緯（使わなかった実験を含む）が書いてある．中のパスは MER-DA の直下から書いてある．`research_notes/` は調べ直しと論文の相談のノートである．`docs/参照/DAI_paper/` は旧版の論文の執筆フォルダで，投稿要項（`docs/venue.md`）と参照論文の要点のノートがある（参照論文の PDF は著作権があるので git に入れていない）．
