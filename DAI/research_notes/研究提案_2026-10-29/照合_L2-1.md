## 3. 設計の前提の確かめ（台本）

**結論：ソースのみの分類器では，中心化は「ターゲットの各感情の点数に定数 Δb_k = w_kᵀD⁻¹(μ_S − μ_T) を足す操作」と同じである．同じ発話の集合なら μ_S，μ_T，D はソースのラベルに依らないが，Δb_k は係数 w_k を通じてラベルに依る．**

台本で確かめた順は次のとおりである．

1. 学習器は学習に使う行の平均と母標準偏差で特徴を標準化する（`exp/logreg.py:108-111`）．目的関数は係数 W にだけ罰則をかけ，切片 b に罰則をかけない（同 71-75 行．`fit_batch` も `Cb` を渡さない限り同じ．同 136・142 行）．感情の重みは `balanced_weights` の n/(k·n_y)（同 78-82 行）．
2. `fit_batch` は問ごと（交差検証の袋ごとと全体）に，その問の行の平均と標準偏差で標準化する（`exp/logreg.py:191-199`）．返す分類器はその平均 μ と標準偏差 D を持つ（同 335 行）．
3. E12 の中心化（`exp/mech.py:80-86` の `centered`）は，ソースでは学習に使う行の平均を引き（同 203 行），ターゲットでは全発話の平均を引く（同 195 行）．ソースの分類器は中心化してもしなくても同じ `M.train(…, M.SRC_CV_SEED)` で，出発点なしで学ぶ（同 205-209 行）．
4. 1〜3 より，ソースの全行から同じベクトルを引いても，各袋の標準化した特徴 z は変わらない．したがって交差検証の成績，選ばれる C，W，b は中心化の前と後で同じである．
5. 点数は `((x − μ)/D) Wᵀ + b`（`exp/logreg.py:57-58`）で，テストの UAR は選んだ C の全体の分類器で出す（`exp/map.py:242-246`）．中心化した分類器では μ が 0，ターゲットの x は x − μ_T になる．差はターゲットのどの発話でも Δb_k = w_kᵀD⁻¹(μ_S − μ_T) で，感情ごとの定数である．

**案の文の問題**：案の 10 行目「ソースのみの分類器では，ラベル無しの中心化は『各感情の点数に，コーパスの平均から決まる定数を足す操作』と同じで，同じ発話の集合ならソースのラベルに依らない」は，足す定数がラベルに依らないと読める．定数がラベルに依らないなら，E1 = G_u − G_c が 0 から離れる理由は UAR の非線形さ（再査読 3.2 節の経路 (ii)）だけになり，案が補助に置く「Δb の版による差」は常に 0 になる．再査読 3.1 節の正確な文は「同じ発話の集合なら μ_S，μ_T，D は版に依らない．版によって変わるのは W（したがって Δb）と b だけである」である．7.1 節の 2 に直した文を書いた．

**付記 1**：E1 = G_u − G_c は，学習器の性質と関係なく成り立つ代数の恒等式である．案の「したがって … 恒等的に等しく」の「したがって」は，3.1 節の性質から恒等式が出るように読める．性質から出るのは「E1 は付け方が作ったずれの割合を測らない」の方である（反例 1・2 とあわせて）．

**付記 2**：ソースのみの分類器は C をソースの中の交差検証で選ぶので，C を固定した地図と交差検証の地図で同じになる．E13 では 2 つの地図のファイルの再現率と位置による損が 900 行すべてで一致した（1 節の 5）．E12 の中心化と D1 は，C を固定した学び直しのファイルが無いので数値では確かめていないが，構成から同じ値になる．案の「解析は C を固定した地図の値で書く」は段 0・段 1 に関係しない（再査読 2 節の直し 5 の指摘と同じ）．

## 5. 論理の確かめ

### 5.1 主な量どうし

- G_u，G_c，E1 = G_u − G_c，E3，E2 は互いに矛盾しない．E1 は G_u と G_c から決まるので，独立の量ではない．案はこれを「中心化の代わりになる分」と読み，主に読む量を G_c にしている．再査読の結論と合う．
- G_u と G_c の単位（4 感情の UAR か，対ごとの量か）が書かれていない．予言の表の 1〜3 行目は 4 感情の UAR，段 0 の 2 行は対の中の再現率，平静–怒りの行は E13 の位置による損と読める．行ごとに単位を書く（7.2 節）．

## 6. 研究者に出すときの要約（7.1 節の直しを入れた後の版）

演技のコーパス CREMA-D と RAVDESS の感情ラベルは，役者に演じさせた感情（意図）で付いているが，両コーパスは聞き手がどう聞いたかの多数決（知覚）も公開している．本案は，同じ発話のラベルを意図から知覚の多数決に付け替えてソースの分類器を学び直すと，自然な会話のターゲット（IEMOCAP 即興・台本，MELD，AFEW，MOSEI）での成績（4 感情の再現率の平均 UAR）がどれだけ変わるかを測る．効果は，中心化（ソースとターゲットのそれぞれで特徴の平均を引く操作．ラベルは使わない）をしないときの G_u と，したときの G_c に分けて測り，G_c を主に読む．MER-DA の学習器では中心化は感情ごとの点数に定数を足すことと同じで，E12 では CREMA-D から自然な会話への 4 組で中心化の後に K=5 本で切片を直すと成績がかえって下がる（平均 −1.05 点）．このため，付け替えが判断の境目の位置しか動かさないなら G_c は 0 以下になり，感情を見分ける向きも良くするなら G_c は正になると予言できる．あわせて，CREMA-D と RAVDESS の間で，ソースとターゲットのラベルの付け方（声だけで聞いた評定の多数決か意図か）が合うと成績が上がるかを 2×2 の交互作用で測る．比べる相手は，同じ発話の集合の意図のラベル，同じ本数を無作為に平静へ移したラベル（20 回以上），切片だけを知覚の版に合わせた分類器の 3 つである．ソースの同じ発話をそのコーパス自身の知覚の評定に付け替えてコーパス間の成績を比べた研究は，2 回の査読の計 20 回の検索で見つからなかった．最も近い Giordano ほか 2026 は 1 コーパスの中だけで学ぶラベルを比べている．計算は，段 0 が保存済みの点数の採点し直しで CPU で数分，段 1 がソースのみの分類器の学び直しで 2 ソース合わせて約 90 版，A5000 で 2〜3 時間（ソースの話者の再標本化を除く）の見込みである．研究者の承認が要るのは，発話一覧に付け替えたラベルの列を足すこと，RAVDESS の評定（PLoS ONE の補足資料）を取り込むこと，段 1 の計算の 3 つである．本案は分析であり，手法の新しさには直接は貢献しない．
