## 3. 3 案を作った方針

- **新しい情報源を使う**：会話の順序（L6-1）と話者の構造（L6-2）は，oursx の疑似ラベルに入っていない．どちらも発話一覧の列にあり，ラベル無しで使える（8 節）．L6-3 は，第 1〜7 回の多視点の案（F，L4-1，L1-2，E60 の Dawid–Skene，E72・E73）が共通に置く仮定（感情を固定するとモダリティの誤りが独立）を測る
- **仮定を測れる形で書く**：各仮定に「仮のターゲットのラベルで何を数えれば成り立つか分かるか」を書いた
- **上限を先に数える**：手法を流す前に，仮のターゲットのラベルで上限の得（本当の母数で平滑化した教師，本当の話者の誤りを除いた生徒）を数え，進む基準を数値で書いた（T3 の対策）
- **比べる相手は oursx**：同じ教師の候補，同じ重みの候補，同じ仮のターゲットの選び方を与える（T4 の対策）
- **D1**：L1-2 改，L2-1 改 2，L3-3 改 2 と問いが違う．査読中の L5-2・L5-3 との違いは各案に書いた．L6-1 と L6-2 はどちらも話者の水準の誤りを扱うので，問いの違いを 4.2 節と 5.2 節に書いた．両方が通れば，L6-2 の話者の誤りの推し方を L6-1 の手順 3 に使える
- **検討して外した案**：会話の相手の発話（別の話者）を第 2 の見方にして，生徒の特徴の空間で正準相関から感情の向きを推す案．感情の対比 3 本の向きで，相手の発話との正準相関は概算で 0.2 前後になる（IEMOCAP 即興の音声．隣の別の話者の感情の一致 0.637 と偶然 0.30 から感情の相関約 0.48，L4-1 の査読の Δ = 2.37 から感情で説明される分散の割合約 0.41．本案出しの概算）．発話の対は約 2,000，前処理の主成分を 16 本にしても，雑音の正準相関の端は約 0.18 で，信号と区別できない（T6）．問いも L1-2 改と同じ型になる（T8）ので外した

## 4. 案 L6-1：会話の中の感情の持続で，別のモダリティの教師の疑似ラベルを直す

### 4.1 題

- 会話を学習のときだけの特権情報として使う：感情の持続と，話者と収録に由来する教師の誤りの持続をラベル無しで分けて推し，コーパスをまたぐ疑似ラベルを直す
- Conversation as Training-Time Privileged Information for Cross-Corpus Emotion Recognition: Separating Emotion Persistence from Speaker- and Session-Driven Teacher-Error Persistence to Denoise Pseudo-Labels

### 4.2 問い

ターゲットの候補の発話が会話（対話，動画）の中で時刻順に並んでいるとき，

1. ソースだけで学んだ融合の教師（pF，ref）の疑似ラベルの誤りを，同じ会話の隣の発話への教師の出力で減らせるか
2. 隣をどれだけ信じるか（平滑化の強さ）を，ターゲットのラベル無しで決められるか．難しさは，隣どうしの教師の出力の一致が「感情が続くこと」と「同じ話者・同じ収録の誤りが続くこと」の両方から生じることにある．前の案の人工の計算（M6）では，ラベル無しの最尤の推しが持続を大きく出し，MELD では平滑化で 46.5 から 40.2 に下がった
3. 直した疑似ラベルで学んだ生徒（運用時は 1 発話ずつ判定）は，oursx を K=0 と K=5 で上回るか．AV の世界の融合の生徒（別のモダリティという特権情報を持たない）でも上回るか

L6-2 との違い：L6-1 の問いは会話の順序の価値であり，話者の誤りは平滑化を正しくするための邪魔な成分として推す．L6-2 の問いは，平滑化をしなくても生徒が話者の誤りを受け継ぐかである．

### 4.3 手法（手順）と理論の骨子

**記号と模型**：ターゲットの候補の発話 i について，教師のロジットから平均を除いた 3 次元の対比を z_i と書く．発話は会話 g(i)，会話の中の順番 t(i)，話者 s(i)，収録のまとまり c(i)（IEMOCAP のセッション，MELD の話数）に属する．真の感情を y_i とする（ラベル無しでは見えない）．模型は次のとおりである．

z_i = μ(y_i) + u_{s(i)} + v_{c(i)} + e_i

μ(c) はターゲットでの感情 c の教師のロジットの平均，u_s は話者に一定の誤り（共分散 Σ_u），v_c は収録のまとまりに一定の誤り（共分散 Σ_v），e_i は発話ごとの誤り（共分散 Σ_e）である．M = Σ_c π_c (μ(c) − μ̄)(μ(c) − μ̄)ᵀ を感情による教師のロジットの散らばりとする．

**仮定と測り方**（測るのは仮のターゲットのラベルを使う段 0 である）

| 番号 | 仮定 | 測り方 |
|---|---|---|
| H1 | 感情の持続：同じ会話の中で，隣へ移るとき感情は確率 λ でそのまま，1 − λ で感情の割合 π から引き直す．λ は話者が替わる遷移で λ_D，同じ話者が続く遷移で λ_S をとる．離れた対の感情の一致は，間の遷移の λ の積で下がる | 遷移の並びの種類ごと（D，S，DD，DS など）に感情の一致率を数え，積の形からのずれを出す．M-情報源の M2 は隣の対だけを数えた |
| H2 | 誤りの分け方：u_s と v_c は感情と独立で，e_i は発話の間で独立．会話の水準で一定の誤り（話題など）は無い | 残り r_i = z_i − μ̂(y_i) を作り，対の種類ごとの残りの相関を出す．「同じ会話・違う話者・違うまとまり無し」の対の残りの相関が 0 に近いこと，「同じ話者・同じ会話」の残りの相関が離れ方によらないことを確かめる |
| H3 | 話者ごとの感情の割合の違いが小さい | 話者の感情の割合の違い η²（M-情報源の M1：IEMOCAP 即興 0.03，台本 0.04，MELD 0.02，MOSEI 0.29） |
| H4 | 識別に要る対がある：同じ話者が 2 つ以上の会話に出る | 発話一覧で数える．IEMOCAP と MELD（主な登場人物が多くの対話に出る）は満たす見込み，MOSEI は話者と動画がほぼ一致するので満たさない |

**命題 1（識別．2 次の積率だけを使う）**：H1〜H4 のもとで，教師のロジットの対の共分散は対の種類ごとに次の形になる（同じまとまりの対には Σ_v が足される）．
- 同じ会話の隣で話者が替わる対：C(D) = λ_D M
- 同じ会話の隣で同じ話者が続く対：C(S) = λ_S M + Σ_u
- 同じ会話で 2 つ離れ，話者が替わって戻る対（2 人の対話でよくある並び）：C(DD) = λ_D² M + Σ_u
- 同じ話者で違う会話の対：C(X) = Σ_u + O(η²)
- 違う話者で，同じまとまりの違う会話の対：C(V) = Σ_v + O(η²)

したがって Σ_v = C(V)，Σ_u = C(X) − C(V)，λ_D = tr[C(DD) − Σ_u − Σ_v] ／ tr[C(D) − Σ_v]，M = [C(D) − Σ_v] ／ λ_D，λ_S は C(S) − Σ_u − Σ_v と M の比で決まり，すべてラベル無しで推せる．O(η²) の項は H3 の η² で上から抑えられる．最尤の推し（M6）が持続を大きく出すのは，C(S) と C(DD) に入る Σ_u を感情の持続と数えるためである，と読める（これは段 0 で確かめる予言である）．
- 新しさの位置：変動を「安定した個人の成分・持続する状態・その場の誤り」に分ける形は心理測定の trait–state–error 模型（Kenny & Zautra 1995）と同じ型であり，新しさにしない．新しさは，この分け方をコーパスをまたいで使う分類器の出力に当て，「ずれが作る誤りの持続」と「感情の持続」を分けることにある

**命題 2（平滑化の得の条件．既知の結果を使う）**：誤りが発話の間で独立（Σ_u = Σ_v = 0）なら，前向き後ろ向きで出した事後確率の UAR は，持続 λ が大きいほど上がる．Σ_u が残ると，同じ話者の隣どうしの誤りが一緒に動くので得は小さくなり，λ を大きく推しすぎると負になる（人工の計算：台本で S = 0.5 のとき 51.8 → 43.1，MELD で推した λ = 0.85 のとき 46.5 → 40.2）．得の大きさの式は隠れマルコフ鎖の平滑化の既知の結果で，新しさにしない．予言は，M4〜M6 と同じ人工の計算を，命題 1 で推した (λ_S, λ_D, M, Σ_u, Σ_v) と教師の正解率で回して数で出す．

**命題 3（生徒が受け継ぐもの．既知の型）**：Dong ほか（ICML 2025）の定理 1 と Xue ほか（ICML 2025）の定理 3.8 の型により，生徒は疑似ラベルの誤りのうち自分の特徴で表せる部分を受け継ぐ．平滑化は教師の誤りを減らすが，残る誤りのどれだけが生徒の特徴で表せるかは変わりうる．したがって生徒の得と教師の得の比は U19 の値（別のモダリティの教師で約 0.45）を既定の予言にし，ずれは測って報告する．

**手順**
1. 教師の出力：pF と ref のロジットを候補の上で出す（K=0）．テストの発話は使わない．テストの発話が会話から抜けた位置は，観測の無い点として鎖に残す（特徴は使わない）
2. 積率：対を種類（遷移の並び，同じ話者か，同じ会話か，同じまとまりか）で分け，命題 1 で (λ_S, λ_D, M, Σ_u, Σ_v) を推す．H4 を満たさない群（MOSEI の見込み）は「識別できない」と記録し，平滑化しない（oursx のまま）
3. 話者とまとまりの誤りを引く：û_s，v̂_c を，話者とまとまりの教師のロジットの平均から，推した Σ_u，Σ_v と本数で縮めて引く（最良線形不偏予測の形．縮める式は既知）．自分の発話を含む平均で引くと水増しが出る（N 情報源の査読：発話 8 本の話者で +2.0〜+3.3）ので，自分を除いた平均を使う
4. 平滑化：会話ごとに，遷移の行列を (λ_S, λ_D, π̂) で作り，放出を「教師の事後確率 ÷ π̂」で作って，前向き後ろ向きで事後確率を出す．π̂ で割るのは，ならすと多い感情へ寄って UAR が下がる問題（E42 の記述 2：MELD で正解率 +1.36，UAR −1.43）への対策である．π̂ は教師の出力の平均で推す
5. oursx に入れる：平滑化した pF と ref を教師の候補に足し，重みの付け方と総重みは今の oursx と同じ候補から仮のターゲットで選ぶ．平滑化の強さは仮のターゲットで選ばず，ターゲット自身で推した値を使う．仮のターゲットで選ぶと，コーパスの間の並びの違い（H の計算 6）で「平滑化しない」が選ばれる見込みが高い（IEMOCAP の仮のターゲットは MELD と MOSEI で λ が小さい）．推した λ_D が計算の前に決めた値（案：0.3）未満なら平滑化しない
6. K ≥ 1：K 本のラベルを (a) 鎖の中で状態を固定することと，(b) ラベルの付いた発話の残りで Σ_u と放出の混同を推し直すことに使う．人工の計算（M5）では (a) の得は見えなかった（即興の S = 0 で 80.0 対 80.7）ので，(b) を主にする．(b) は MOSEI のように H4 を満たさない群で，K 本のラベルから Σ_u を推して平滑化を使えるようにする

### 4.4 なぜ重要か（誰のどの判断が変わるか）

- **研究者（手法の新しさ）**：oursx の教師を変えずに，教師の誤りを減らす別の経路を足せるかが決まる．K=0（教師なしの DA）と K≥1（半教師ありの DA）を同じ模型で扱え，命題 1 は「ラベル無しで何が推せるか」の数理になる．教師の余地は大きい（E60 の下調べ 3：融合の出発点 61.2 に対し候補全体のラベルで学んだ融合の分類器 69.2（AV），52.3 対 65.9（AVT））
- **研究者（論文の糸 3）**：「ラベル無しのターゲットから向きは分からない」（`docs/results.md` 3.9 節）は，1 発話ずつの統計（E58，E74）で確かめた．会話の順序で教師と生徒が良くなるなら，糸 3 を「1 発話ずつのラベル無しの統計では」と範囲をつけて書き直す必要がある
- **研究者（AV の世界の融合の生徒）**：この生徒は別のモダリティという特権情報を持たないので，どの手法も得を出せない（E61：K ≥ 5 で +0.5〜1.0，K=0 で +1.3 以下）．会話の文脈は，この生徒に初めて学習のときだけの情報を与える
- **実務者**：会話の録音（コールセンター，面談，会議）でラベル無しのデータを集めるとき，発話を切り離して保存するか，会話の順序と話者の情報を残すかの判断が変わる．運用時のモデルは 1 発話ずつのままでよい

### 4.5 主張の候補

- **C1（識別．条件：仮のターゲットのラベルで，推した λ_D・λ_S が本当の値と ±0.1 以内，Σ_u の推しが本当の値と相対 30% 以内）**：コーパスをまたいで使う分類器の出力の対の共分散を，遷移の種類と話者・収録の関係で分けると，感情の持続と，ずれに由来する誤りの持続をラベル無しで分けて推せる．最尤の推しが持続を大きく出す理由は，誤りの持続を感情の持続と数えることにある
- **C2（手法．条件：4.10 節の段 0 と段 1 の基準を満たす）**：分けて推した強さで教師の疑似ラベルを平滑化すると，oursx の生徒が K=0 と K=5 で上がる．得は推した λ と話者の誤りの割合で予言した順に群が並ぶ
- **C3（範囲．C2 が一部の群でしか成り立たない場合も）**：会話の文脈で疑似ラベルを直せる範囲は持続 λ と誤りの持続の比で決まり，λ が小さい群と識別できない群では平滑化しない規則で損が出ない

### 4.6 落ちる型をどう避けたか

- T1：平滑化，縮め方，trait–state–error の分け方，受け継ぎの型はすべて既知と書いた．新しさは，コーパスのずれが作る誤りの持続を分ける識別（C1）と，その結果で平滑化を正しくした手順（C2）に置いた
- T2：前提に反しうる記録を 4.11 節に列挙した
- T3：段 0 で上限（本当の母数で平滑化した教師の得）を数え，基準に届かなければ止める．人工の計算の上限は即興 +18.8，台本 +13.2，MOSEI +2.3，MELD +1.6（S = 0）で，群ごとに差が大きいことを先に書いた
- T4：比べる相手は oursx（ref）．対照に，平滑化しない教師，特徴の近所でならす教師（E42 の型），会話ごとに感情の割合だけをそろえる教師（順序を使わない．massbal の会話版），話者の誤りを引かずに平滑化する教師を入れる．会話の文脈を使う教師あり学習（ソースの対話で学ぶ文脈つきの教師）も対照に入れる
- T5：主な量は教師と生徒の UAR と，ラベルで測った本当の母数との誤差である
- T6：推す母数は 3 次元のロジットの 2 次の積率で，対の数は群ごとに数千ある
- T7：手法が働かない条件（λ が小さい，H4 を満たさない，Σ_u が大きい）で使わない規則を手順 5 に入れた
- T8：L1-2 改（別のモダリティの部分空間），L5-3（ラベル無しの目的関数が話者の塊を追う）とは使う情報も問いも違う．L5-3 は特徴の空間の塊を扱い，本案は会話の時刻の並びを扱う
- T9：設計は文書の値（M-情報源の M1〜M6，E14，E42，E60）と仮のターゲットだけで決める．M-情報源の M1・M2 はラベルから数えた値なので，`docs/seen-data.md` に記録されているかを関門の前に確かめる

### 4.8 MER-DA の何を使うか

- 発話一覧の列：IEMOCAP の `dialog_id`・`session`・`utterance_speaker`・`speaker_id`・`start_sec`，MELD の `dialogue_id`・`utterance_id`・`season`・`episode`・`speaker_id`，MOSEI の `video_id`・`clip_id`・`youtube_channel_id`（8 節）
- 読み込み：`measure/data.py` の `load_group`，話者分割 `measure/split.py`
- 教師と生徒：E60 の下調べ 3 の台本 `exp/check_e60_refuse.py`（融合の出発点と ref），E61・E66 の oursx の台本，E66 の `exp/explore_move_then_learn.py`
- 比べる相手と対照：E42 の `exp/belief_check.py`（特徴の近所でならす），massbal
- 記録：M-情報源の M1〜M6（持続，η²，人工の計算），E14（話者の割合 S），E42，E60，E61，U19

### 4.9 新しい計算の規模

- 段 0（仮のターゲット，ラベルを使う．`gate-probe` の 1 体）：教師のロジットの計算（線形の分類器なので数分．ref は E60 の下調べ 3 と同じで GPU 十数分），対の積率と前向き後ろ向き（CPU で数分），本当の母数と推した母数の比べ．合わせて CPU で数十分
- 段 1（仮のターゲット．GPU）：oursx に平滑化した教師を 3 通り（話者の誤りを引く・引かない・会話の割合だけ）足して流す．E66 の規模（AV 2,323 秒，AVT 1,243 秒）の 3〜4 倍で約 2〜3 時間
- 段 2（評価のターゲット，設計に使っていない反復 10〜29．関門 1 の 4 体）：AVT の 4 ターゲットと AV の会話のある 4 ターゲットで，oursx と平滑化した版だけを流す．E61 の AVT は全部の相手を含めて 1 ターゲット 2.6〜6.1 時間なので，相手を流し直さなければ合わせて 10〜20 時間の見込み．研究者の承認が要る
- 新しい特徴の抽出は要らない

### 4.12 最も強い反論と答え

**反論**：「会話の文脈で感情認識が良くなることは Metallinou 2012 以来の会話の感情認識の常識で，ドメインをまたぐ会話の感情認識（DAN-CDERC，DGDA）もある．得は IEMOCAP の即興の台本の設計から来る人工的なもので，現実の会話（MELD）では持続が弱い．分け方は trait–state–error 模型の教科書の形である．」

**答え**：
- 本案の生徒は運用時に 1 発話ずつ判定し，会話はターゲットの学習のときだけ使う．会話の感情認識（運用時に文脈を使う）とは問題が違う．会話の文脈を使う教師あり学習の教師を対照に入れ（4.6 節の T4），違いを数で示す
- 本案は平滑化の強さをターゲット自身の推しで決め，持続が弱い群と識別できない群では使わない．主張は「どの群でどれだけ使えるかが推した持続と誤りの持続で決まる」ことで，即興の得の大きさを一般化しない（P1-6）
- 分け方の型は既知と書く．新しさは，コーパスのずれが作る誤りの持続を分ける識別と，それを疑似ラベルの平滑化に入れたときに M6 の失敗が消えるかの実測に置く．計画した段 0（P1-1）と段 1（P1-3，P1-4）の結果で答えられる

## 5. 案 L6-2：生徒は教師の「話者ごとの誤り」を覚える

### 5.1 題

- 生徒は教師の話者ごとの誤りを覚える：別のモダリティの教師の疑似ラベルから話者の水準の誤りを縮めて除き，学習に出ない話者への転移を守る
- Students Memorize Their Teacher's Speaker-Specific Errors: Shrinking Speaker-Level Error out of Cross-Modal Pseudo-Labels to Protect Transfer to Unseen Speakers

### 5.2 問い

1. 別のモダリティの教師（とくに顔を含む教師）の疑似ラベルの誤りには，話者ごとに一定の成分 u_s がどれだけあるか．ソースのみの分類器では，感情で説明できない点数のばらつきのうち話者による割合 S が映像で 0.09〜0.67，音声で 0.03〜0.47 ある（E14）
2. 生徒の特徴は話者を見分けられる（音声の特徴にも同じ人の声が出る．E42 で特徴の近所が同じ話者である割合は音声 0.29，映像 0.67）．生徒は u_s を「この声ならこの感情」という対応として覚え，テストの話者（話者分割で学習に出ない話者）ではその対応が雑音になる．この損はどれだけか
3. u_s を，話者の感情の割合の違い（η²）を引かないように縮めて除いた疑似ラベルで学ぶと，生徒はテストの話者で良くなるか

L6-1 との違い：L6-1 は会話の順序で教師の誤りを減らす．L6-2 は平滑化をしない oursx そのものについて，生徒が話者の誤りを受け継ぐ損を問う．会話の無い CREMA-D，RAVDESS，AFEW にも当たる．L5-3（査読中）はラベル無しの目的関数（エントロピー最小化，EM）が話者の塊へ動く問題で，本案は教師の疑似ラベルの誤りの受け継ぎを扱う．N 情報源の案 A（不合格）は生徒の特徴を話者ごとに正規化した．本案は特徴を変えず，学習のときの疑似ラベルだけを直し，運用時は何も変えない．

### 5.3 手法（手順）と理論の骨子

**模型**：教師のロジットの対比を z_i = μ(y_i) + u_{s(i)} + e_i と書く（L6-1 と同じ．収録の成分はここでは u に含める）．話者 s の感情の割合を π_s とし，話者の平均は z̄_s = Σ_c π_{s,c} μ(c) + u_s + ē_s である．第 1 項（話者の感情の割合による平均の違い．大きさを V_mix と書く）は本当の信号で，引くと損をする．E14 のラベル無しの版（全部引く）が平均で音声 −1.0，映像 −0.4 だったのはこのためと読める．

**命題 1（受け継ぎの損の大きさ．E69・E70 の 2 次の模型の上で導く）**：生徒をアンカーに寄せたロジスティック回帰の 2 次の近似（E74 の A1 で使ってよいとされた形）で書くと，u による生徒の頭の誤差は Δθ_u ≈ (H + P)⁻¹ (1/N) Σ_s n_s g_s u_sᵀ になる（g_s は話者 s の特徴の平均の，候補全体の平均からのずれ）．u_s が話者の間で独立なら，学習に出ない話者での予測の損の期待値は，おおよそ S_T × B ／ n_eff に比例する．S_T は教師の誤りに占める話者の割合，B は話者の平均の特徴の散らばりのうち頭が反応する部分，n_eff = N² ／ Σ_s n_s² は話者の実効の数である．
- 予言の形：損は話者の誤りが大きい群ではなく，**話者の実効の数が少ない群**で大きい．IEMOCAP（候補の話者 8 人）は大きく，MOSEI（動画の ID が数百）は S が最も大きいのに損は小さい，と予言する．MELD は発話の 94% が 10 本以上の話者に属し（`査読_L1-2.md`），主な登場人物に発話が集まる見込みなので n_eff が小さく（登場人物の数は本案出しの知識で，発話一覧で数えていない），S が小さくても損が出うる．CREMA-D は S が大きく（映像 0.59）n_eff も大きい（候補の話者約 73 人）
- 新しさの位置：生徒が教師の誤りのうち自分の特徴で表せる部分を受け継ぐことは Dong 2025・Xue 2025 の型で既知である．本案は，その中の「話者ごとに一定の誤り」が話者分割の評価でだけ損になることと，損が n_eff で決まることを示す

**命題 2（縮めて除く．最良線形不偏予測の型で既知）**：û_s = A_s (z̄_s^{(−i)} − z̄) と置き，A_s = Σ_u (Σ_u + V_mix + Σ_e ／ n_s)⁻¹ とする（z̄_s^{(−i)} は発話 i を除いた話者の平均）．分散成分が分かっていれば，縮めて除いた疑似ラベルの誤差の 2 乗の期待値は，除かない場合と全部引く場合（E14 のラベル無しの版）のどちらより小さい．縮める式そのものは既知であり，新しさにしない．

**分散成分の推し方**（L6-1 の命題 1 と違い，会話の順序を使わない）
- K=0：(i) 話者 × 会話（IEMOCAP の対話，MELD の対話）で入れ子にした分散の分け方で，会話の間で変わる感情の割合と，会話をまたいで一定の u_s を分ける．(ii) 演技のコーパス（CREMA-D，RAVDESS）は各話者が全部の感情を同じ数ずつ演じる設計なので V_mix ≈ 0（η² = 0．M-情報源の M1）で，話者の平均の散らばりはほぼ Σ_u である．(iii) MOSEI と AFEW（η² 0.29，0.22）では，2 つのモダリティの単独のアンカーの話者の平均どうしの共分散で V_mix を推す（話者の水準でモダリティの誤りが独立という仮定．L6-3 の表で確かめる）
- K ≥ 1：ラベルの付いた発話の残り z_i − μ̂(y_i) から u_s と Σ_u を直接推し，K=0 の推しと合わせる

**手順**
1. 教師（oursx の pF，pFK，ref）のロジットを候補の上で出す
2. 分散成分 Σ_u，V_mix，Σ_e を上の方法で推す
3. 自分を除いた話者の平均から û_s を縮めて引き，直した疑似ラベルを作る
4. oursx の重みの付け方と総重みの候補をそのまま使い，直した教師を候補に足す．縮める強さは仮のターゲットで選ばず，分散成分から決める
5. 生徒の特徴とテストの手順は変えない（運用時は何も足さない）

### 5.4 なぜ重要か（誰のどの判断が変わるか）

- **研究者**：oursx のすべての生徒と世界に当たる直しになるか，ならないかが決まる．教師は顔を含むことが多く（ref，pFK），顔の誤りは話者の割合が大きい（E14）．損が n_eff で決まるなら，話者の少ない IEMOCAP の 2 群（AVT の 4 ターゲットの半分）の結果の読み方が変わる．模擬査読の Major-3（`paper/reviews/round1/review-affect.md`）が求める「話者ごとの正規化」に，「正規化するなら特徴ではなく疑似ラベルの側で，縮めて」という根拠のある答えを出せる
- **実務者**：社内で集める少ない話者のラベル無しのデータ（10 人前後）で疑似ラベルの蒸留をするとき，話者の誤りを除く前処理を入れるかの判断．損が n_eff ＜ 20 で大きいなら，そこで入れる
- **L5-3・N 情報源の線との関係**：話者の構造が手法に効くのは，ラベル無しの目的関数（L5-3）か，特徴の正規化（N 情報源）か，疑似ラベルの受け継ぎ（本案）かを分けられる

### 5.5 主張の候補

- **C1（測定．条件：段 0 で S_T と上限の得を測ったとき）**：別のモダリティの教師の疑似ラベルの誤りのうち話者に一定の成分は，蒸留した生徒に受け継がれ，話者分割の評価で損になる．損は話者の実効の数 n_eff が少ない群で大きい
- **C2（手法．条件：段 1 の基準を満たす）**：分散成分から決めた強さで話者の誤りを縮めて除いた疑似ラベルは，oursx の生徒を IEMOCAP の 2 群で K=0 と K=5 に上げ，ほかの群では下げない．全部引く版（E14 の型）は MOSEI と AFEW で下げる
- **C3（範囲．条件：C1 が成り立たないとき）**：疑似ラベルの蒸留では話者の誤りは受け継がれない（アンカーへの罰則が話者の向きを抑える）．このとき，話者の構造が手法に効く経路は L5-3 と L6-1 に限られると記録する

### 5.6 落ちる型をどう避けたか

- T1：受け継ぎの型（Dong・Xue）と縮める式（最良線形不偏予測，MAP 適応）は既知と書いた．新しさは損の大きさを決める量（S_T と n_eff）と，その予言の確かめに置いた
- T2：E14 のラベル無しの版の負の平均と，N 情報源の査読の水増しを 5.10 節で扱った
- T3：段 0 で，仮のターゲットの本当のラベルで話者の誤りを除いた生徒の得（上限）を先に数え，基準に届かなければ止める
- T4：比べる相手は oursx．対照に，全部引く版（E14 の型），特徴を話者ごとに正規化する版（Major-3 の比べる相手），会話ごとの割合だけをそろえる版を入れる

- T6：u_s は 3 次元のロジットの話者ごとの平均で推す．話者が 8 人しかいない IEMOCAP では Σ_u の推しの揺れが大きいので，話者 × 会話の入れ子の分け方を使い，推しの区間を段 0 で出す
- T7：命題 2 の縮め方は，分散成分が正しければ除かない場合と全部引く場合のどちらより悪くならない．分散成分の推しが外れる条件（V_mix が大きく，モダリティの話者の誤りが相関する）は L6-3 の表で確かめる
- T8：L5-3，N 情報源，L6-1 との違いを 5.2 節に書いた

## 6. 案 L6-3：モダリティの分類器はなぜ一緒に間違うか（測定）

### 6.1 題

- モダリティごとの感情の分類器は，なぜ感情を固定しても一緒に間違うのか：話者・会話・表出の強さ・その他に分けた測定と，多視点の推定が働く条件
- Why Do Modality-Specific Emotion Classifiers Err Together? Decomposing Label-Conditional Error Dependence into Speaker, Conversation, Intensity, and Residual Components, and When Multi-View Estimators Can Work

### 6.2 問い

ソースで学んだ音声・顔・言葉の単独の分類器（E39 の出発点）は，ターゲットで同じ発話を，感情を固定しても独立の予言より多く同時に間違う．文書の値からの概算では，AV の 6 ターゲットで音声と映像の票が一致する割合は 40%（独立なら約 35%），一致したときの正解率は 69.8%（独立なら約 78%）である（E60 の下調べ 1 の音声単独の正解率 53.6% と映像の出発点の UAR 50.0 を正解率の代わりに使い，誤りが 3 つの感情に等しく散ると置いた，本案出しの概算）．同じ向きの記録は U7（見方どうしの誤差の相関 0.77〜1.00）と E60 の Dawid–Skene の失敗（AV 52.0 対 融合 61.2）である．

1. この依存のうち，(i) 話者に一定の要因，(ii) 会話（対話，動画）に一定の要因，(iii) 発話の表出の強さ（弱い表出は全部のモダリティで間違う），(iv) その他の発話ごとの要因，はそれぞれどれだけか
2. 同じモダリティの 2 つのエンコーダ（WavLM と HuBERT，ResNet-50 と CLIP，RoBERTa と DeBERTa）の依存を「同じ信号の依存」の基準にすると，モダリティの間の依存はその何割か
3. 依存の (i)(ii) を除いた出力で，Dawid–Skene は融合の出発点に近づくか

### 6.3 量と手順（理論の骨子）

- **量 1（感情を固定した同時の誤りの超過）**：モダリティ m と m′ の誤りの指標 E_m = 1[予測 ≠ 正解] について，D_mm′ = (1/4) Σ_y [P(E_m ∧ E_m′ | y) − P(E_m | y) P(E_m′ | y)]．独立なら 0 である．感情の釣り合いの重みで平均するので UAR と単位がそろう
- **量 2（残りのロジットの相関の分け方）**：r_m = z_m − E[z_m | y]（感情ごとの平均を引いた 3 次元の残り）について，モダリティの間の共分散を，話者・会話・発話の入れ子の分散の分け方で 3 つの水準に分ける．発話の水準の共分散を，表出の強さの共変量（CREMA-D・RAVDESS の `emotion_intensity`，MOSEI の感情の強さの最大値，IEMOCAP の `arousal`）で回帰し，強さで説明される割合を出す
- **量 3（同じ信号の基準）**：同じモダリティの 2 つのエンコーダの出発点の D を同じ手順で出し，D_モダリティ間 ／ D_エンコーダ間 を出す（第 2 のエンコーダは E62 の AVT の世界にある）
- **帰結の確かめ（手法の小さな腕．本案の新しさにはしない）**：E60 の下調べ 3 の Dawid–Skene を，(a) そのまま，(b) 話者と会話の水準の成分を引いたロジットで，(c) 表出の強い発話だけで，流して UAR を融合の出発点と比べる
- **仮定**：仮のターゲットのラベルで E[z | y] を推すので，本案は測定である．感情ごとの平均の推しの揺れは，AVT の 4 群では候補の数（2,000〜15,000．`査読_L4-1.md` 5.1 節）で小さい．RAVDESS は全体で 672 本と少ないので区間を別に出す．会話の水準が無い群（CREMA-D，RAVDESS，AFEW）では話者と発話の 2 水準で分ける

### 6.4 なぜ重要か（誰のどの判断が変わるか）

- **研究者（多視点の線を続けるか）**：第 1〜7 回の F（対ごとの重み），L4-1（3 次の積率），L1-2 改（正準部分空間），E60 の Dawid–Skene，E72・E73（三つ組の合わせ方），oursx の票の積（ref）は，どれも「感情を固定するとモダリティの誤りが（ある程度）独立」を置く．依存の大部分が発話の水準（表出の弱さ）なら，ラベル無しの多視点の推定はどれも MER で働かないと理由つきで閉じられる．話者か会話の水準が大きいなら，その成分を引いてから使う線が残る．L1-2 改の 1 段が負になったときの理由の説明にもなる
- **研究者（論文）**：要旨の「ラベル無しでは向きを直せない」（模擬査読の Major-3 が確かめを求めた）に，多視点の側から理由を書ける．U7 と E60 の記録に，今は無い説明を与える
- **L6-2 の前提**：L6-2 の K=0 の推し方 (iii) は「話者の水準でモダリティの誤りが独立」を置く．本案の量 2 の話者の水準の相関がその確かめになる
- **実務者**：遅い融合で確率の積を取る（独立を置く）とき，どの種類のコーパスで二重に数える誤りが大きいかが分かる

### 6.5 主張の候補

- **M1（測定）**：コーパスをまたいで使う単独のモダリティの感情の分類器の，感情を固定した同時の誤りの超過を，話者・会話・表出の強さ・その他の水準に分けた．顔を含む組では話者の水準，音声と言葉の組では表出の強さと発話の水準が大きい（予言．結果がどちらでも主張になる）
- **M2（基準つきの比）**：モダリティの間の依存は，同じモダリティの 2 つのエンコーダの依存の何割かで表せる．この比が大きいほど，そのモダリティの組で多視点の推定が働かない
- **M3（帰結．条件つき）**：話者と会話の水準を引くと Dawid–Skene の UAR は上がるが，発話の水準の依存が残る群では融合の出発点に届かない

### 6.6 落ちる型をどう避けたか

## 7. 推す 1 案と理由

**推すのは L6-1 である．**

1. **落ちる型の中心を避けている**：第 1〜7 回の手法の案はすべて oursx の中のつまみを変え，T1〜T3 で落ちた．L6-1 は oursx の外の情報（会話の順序）を足すので，つまみの余地が尽きていること（J の計算 12）に縛られない
2. **余地が大きいことが先に分かっている**：人工の教師の計算で，教師の誤りが独立なら IEMOCAP 即興で 61.9 → 80.7，台本で 51.8 → 65.0 であり，話者のずれを除けば S = 0.5 でも 75.9，60.8 に戻る（`M_第7回_案出し_情報源.md` の M4・M5）．会話の隣の感情の一致は即興 0.77，台本 0.69 で，偶然 0.30，0.26 より大きい
3. **前の版の弱点に答えている**：持続をラベル無しで推すと大きく出る問題（M6）を，対の種類で分けた 2 次の積率（命題 1）で扱い，段 0 でラベルで測った本当の値と比べる
4. **研究者の目標に直接当たる**：K=0 と K≥1 を同じ模型で扱い，識別の命題（C1）という数理の主張を持つ．AV の世界の融合の生徒という，今どの手法も得を出せない対象に特権情報を与える
5. **負でも残る**：段 0 で止まっても，「コーパスをまたぐ教師では会話の文脈で疑似ラベルを直せない」か「持続をラベル無しで分けて推せない」という否定の記録が残り，論文の糸 3 の範囲が決まる

合格の見込みの順は L6-1 ≧ L6-3 ＞ L6-2 と見る．L6-3 は測定で前提に反する記録が無いが，「当たり前」と「判断はすでに下された（U6）」の反論で V1 が条件つきになりうる．L6-2 は E14 の負の平均と N 情報源の不合格に近く見えるので，査読者が T2 と T8 を厳しく見る見込みがある．L6-1 の最大の危険は N2（原文で確かめた近い先行研究が 1 本）で，関門の前に DAN-CDERC，CycDA，Kenny & Zautra の原文を読めば直せる．
