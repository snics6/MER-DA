## 0. 結論

1. **L4-2 は不合格と判定する．**N2・F1・S1 は満たし，N1・V1・D1・V3・R1 は条件つきで満たすが，V2 と V4 を満たさない（7 節）．
2. **中心の手順は，案自身の模型の中で目的を達成できない．**教師の入力 u をラベル無しに全体の共分散で生徒の特徴 x_s へ回帰した残り u_⊥ は x_s と無相関になる．このとき「感情の間の交差共分散 = −感情の中の交差共分散」が恒等的に成り立つ（4.1 節）．生徒の感情の平均が 3 次元を張る限り，教師が感情の情報を持つことと，教師が生徒の特徴と条件つきで無相関であることは両立しない．Dong 2025 の線形の枠組みでは生徒は教師の信号も誤差も受け継がず（γ = ρ = 0），蒸留した生徒は定数になる．人工データでは，教師の UAR が直交化の前の 77〜84% から 51〜55% に，生徒が 76〜81% から 39〜57% に下がった．
3. **記録とも食い違う．**E71 では，生徒のモダリティを含まない教師（直交化の前）から解いた生徒が，pF の生徒を K=0 で平均 3.6〜7.8 ポイント下回る（本査読の集計．5 節）．案の予言 P2-4（0〜2 ポイント低い）は直交化の前の段で外れている．
4. **新しさ**：命題 1・4 は Lee ほか 2021 の補題 3.1・定理 3.2 と同じ形で，漏れの量 M2′ は同論文の定義 4.1 の ε_CI である．段 3 は行列のスケーリング（Kull ほか 2019 の ODIR）と GLC（Hendrycks ほか 2018）にあたる．入力から別の変数で線形に表せる部分を除く操作は LEACE（Belrose ほか 2023）と同じ型である．見つからなかったのは，(a) 疑似ラベルで動かした単独のモダリティの生徒の誤差を，温度・感情ごとの尺度・非対角の混ぜ方・残りに分けて実データで測り，U7・U8・A2・M2 を説明できるかを確かめる測定と，(b) 教師の入力を感情の中の共分散で生徒の特徴に直交させる作り方である．
5. **合格に要る直し（7.3 節）**：全体の共分散の直交化を感情の中の直交化（ソースのラベルで推す）に替える．比べる相手を oursx と「oursx ＋ 混ぜ方の学び直し」にする．φ の比を判定から外して絶対の UAR で判定する．N2-d を外し，K=1 では係数を 8 個以下に限る．直しは手法の中身を変えるので，再査読が要る．
6. **勧める扱い**：研究者に出す 3 案には入れない．段 0 の測定（8 節の主張 1）だけを，L1-2 改の 1 段の台本と表に行として足すことを勧める．

## 2. 評価した案の読み方と読めなかった点

- **直交化の Γ̂**：案は「コーパスごとに u を x_s へリッジ回帰した残り u_⊥ = u − Γ̂ x_s．話者で分けた交差あてはめで出し，ラベルを使わない」（`案_L4.md:164`）と書く．本査読はこれを，全体の共分散による回帰 Γ = Cov(u, x_s) Cov(x_s)⁻¹ の推定と読んだ．ソースの各コーパスとターゲットの候補で別々に Γ̂ を出すので，教師が学ぶ u_⊥ と当てる u_⊥ は違う Γ̂ で作られる
- **AV の世界の u**：AV の音声の生徒では u は顔の特徴だけで，直交化の前の教師は E71 の見方 t_video と同じ作り方（そのモダリティのアンカーの予測確率）になる．AVT の音声の生徒では u は顔と言葉で，その教師（VT の教師）の記録は MER-DA に無い（`I_第4回.md:45` と同じ点）
- **φ の定義**：φ_UAR = (混ぜ方を当てはめた後の UAR − θ_Q の UAR) ÷ (θ\* の UAR − θ_Q の UAR) と読んだ．分母は生徒が悪いほど大きくなる（4.6 節）
- **係数の数**：案は「20 個（ソフトマックスで同じになる分を除くと 15 個）」と書く．θ\* と W_Q は感情の平均を除いて測る（`docs/exploratory-analyses.md:7412`）ので，ロジットは中心化されている．このとき A の効く部分は 3×3 = 9 個，切片の効く部分は 3 個で，識別できる係数は 12 個である（L4-1 の「12 個の係数と切片」と同じ数）
- **N2-d の条件つき独立**：「顔だけ・言葉だけの直交させた教師モデル q_V⊥，q_T⊥ と生徒モデルの特徴 x_s の 3 つ組は条件つき独立を作ってある」（`案_L4.md:165`）と書くが，直交化は各教師と x_s の間だけで行い，q_V⊥ と q_T⊥ の間では行わない．3 つ組の条件つき独立は作られていない（3.4 節）

## 4. 理論の点検（γ の扱い）

### 4.1 全体の共分散で直交化したときの恒等式（本査読の導出）

記号：感情 y の割合 π_y，生徒の特徴の感情ごとの平均 μ_y，u_⊥ の感情ごとの平均 ν_y．N を行 ν_y − ν̄（π で重みづけて中心化），B を行 μ_y − μ̄ の行列，D_π = diag(π)，C_w = E[Cov(u_⊥, x_s \| Y)]（感情の中の交差共分散）とする．

全体の交差共分散は「感情の間 + 感情の中」に分かれるので，
  Cov(u_⊥, x_s) = Nᵀ D_π B + C_w
である．全体の共分散で回帰した残りは Cov(u_⊥, x_s) = 0 を満たすので，
  **Nᵀ D_π B = −C_w**
が恒等的に成り立つ．

- **系 1（両立しない）**：生徒の感情の平均が C − 1 = 3 次元を張る（B の階数が 3）とき，D_π^{1/2} N の列は π^{1/2} と直交する空間にあり，Bᵀ はその空間の上で単射である．したがって C_w = 0（感情の中で無相関．正規で共分散が等しい模型では条件つき独立と同じ）なら N = 0，つまり u_⊥ の感情ごとの平均がすべて等しく，u_⊥ の線形の関数である教師のロジットは感情の情報を持たない
- **系 2（量の関係）**：‖D_π^{1/2} N‖_F ≤ ‖C_w‖_F / σ_3(D_π^{1/2} B)．教師に残る感情の情報（感情の平均の広がり）は，漏れの大きさ ÷ 生徒の最も弱い感情の対比の強さ，で上から抑えられる．教師が情報を残せるのは，生徒が弱い対比の向きだけで，その分だけ漏れも生じる
- **系 3（漏れを作る）**：もとの u が条件つき独立（C_w(u, x_s) = 0）で両方が感情の情報を持つ場合でも，直交化すると C_w(u_⊥, x_s) = −Γ Cov(x_s \| Y) ≠ 0 になる．直交化は条件つき独立を壊す

案の命題 3（`案_L4.md:175`）は「感情の信号が弱いとき Cov(u_⊥, x_s \| Y) はクラスの間とクラスの中の比の大きさになり，L もその大きさまで小さくなる」と書く．展開すると Cov_w(u_⊥, x_s) ≈ −(感情の間の交差共分散のうち，感情の中の回帰 Γ_w で説明できない部分) であり，系 1 の恒等式から，それは教師に残る感情の信号の交差共分散と同じ大きさである．命題 3 は漏れが小さくなる側だけを書き，信号が同じ割合で小さくなる側を書いていない．

### 4.2 Dong 2025 の枠組み（κ = (q_s/q_T)·γ/ρ）での判定

- Dong 2025 の線形の弱から強への一般化では，生徒は教師の予測を生徒の特徴の張る空間へ射影したもの f_w2s = P_s f_w になる（I の調査 3.1 節）．教師の予測が u_⊥ の線形の関数で，u_⊥ が生徒の特徴と（標本の上で）直交するなら，P_s f_w = 0 である．生徒は教師の信号も誤差も受け継がない．γ（教師の信号のうち生徒が表せる割合）= 0，ρ（教師の誤差のうち生徒が表せる割合）= 0 で，κ は 0/0 になり，生徒は定数の予測になる．LEACE の定理（3.2 節．交差共分散 0 ⟺ 凸な損失の線形の予測が定数を超えない）も同じことを言う
- 案の意図は ρ を下げて γ/ρ を上げることだが，線形の直交化は γ と ρ を同じ操作で 0 に向けて下げる．γ の扱いは命題 3 の最後の 1 文（「教師モデルの正解率は下がる」）と P2-4（0〜2 ポイント下がる）だけで，量は導かれていない
- MER-DA の生徒は確率の疑似ラベルに交差エントロピーで合わせるので，softmax の非線形の分だけ情報が通る（Cov(q, x_s) は Cov(ロジット, x_s) = 0 でも 0 にならない）．この通り道は Dong・Lee の線形の理論の外にあり，大きさは人工データで測った（4.3 節）
- リッジと話者で分けた交差あてはめでは標本の上の直交は近似になる．生徒が線形に受け取る情報は，直交化が取り残した分（リッジの縮みと交差あてはめの揺れ）から来る．手法の得が直交化の不完全さに依ることになる
- **正しい作り方**：条件つき独立に要るのは感情の中の交差共分散を 0 にすることで，それには感情の中の回帰 Γ_w = Cov_w(u, x_s) Cov_w(x_s)⁻¹ を使う．このとき u_⊥w の感情ごとの平均は ν_y − Γ_w μ_y で，感情の情報は Γ_w μ_y の分しか減らない．Dong の枠組みでは，ρ のうち感情の中の（話者などの）共有から来る分だけを下げ，γ をほぼ保つので γ/ρ が上がる．Γ_w の推定には感情のラベルが要るが，教師はもともとソースのラベルで学ぶので，ソースのコーパスで感情ごとに中心化して回帰すれば作れる．仮定は「感情の中の交差共分散の形がソースとターゲットで近い」で，仮のターゲットのラベルで確かめられる

### 4.4 案の命題 1・2・4 と系

- 命題 1 の証明の骨子（x_⊥ が (Y, x_∥, q) と独立になり，Jensen の不等式で ⊥ 成分を 0 にした頭の損失が小さいか等しい）は正しい．中身は Lee 2021 の補題 3.1 に LDA の構造を足したもので，混ぜ方の行列が階数 C であることが要る（案はこの条件を M4′ の目安「最小特異値 ≥ 0.1」としてだけ置く）
- 命題 2 は Dong 2025 の「表せる誤差の受け継ぎ」と Lee 2021 の ε_CI の言い換えで，案もそう書く
- 命題 4 は Lee 2021 の定理 3.2 と同じ形．推定の超過は d によらないが，近似の誤差 (1 − φ) × 超過は残る．K=1 では n = 4 本で 12 個の係数を決めることになり，罰則が値を決める（4.7 節）
- 系（U8・A2 を尺度で説明する）は筋が通り，E74 の C1 の記録（5.2 節）と合う．ただし θ\* は原点へのリッジで解き，その強さ C′ は話者の半分の UAR で選んでいる（`docs/exploratory-analyses.md:7413`，`:7293`）．UAR は尺度で変わらないので，θ\* の尺度は交差エントロピーから見て任意に近く，「生徒が大きすぎる」と「θ\* が縮みすぎる」を区別できない．U7・M2 の高い相関の一部は，基準 θ\* の尺度から来る可能性がある（7.3 節の直し 4）

### 4.5 φ の比を判定に使う問題

φ_UAR は分母に θ\* と生徒の差を持つので，生徒が悪くなるほど大きくなりやすい．4.3 節では全体の直交化で φ が上がり（0.38 → 0.70），生徒も混ぜ方の後の UAR も下がった．P2-3（「φ_UAR が pF より 0.15 以上高い」）は，悪い手法でも満たせる．判定は混ぜ方の後の絶対の UAR（K 本で学んだ値）で行う必要がある．

### 4.6 係数の数と K=1

識別できる係数は 12 個（2 節）で，K=1 のラベルは 4 本である．E66 の h_b の探索では，切片の罰則を強めると K=1 が 0.1〜0.2 ポイント上がるだけだった（`docs/exploratory-analyses.md:7074`）．K=1 では温度と感情ごとの切片（BCTS の形．4 + 3 個）か，対角だけ（ベクトルのスケーリング）に限るのが妥当で，P2-5 の「K=1 で B を +0.5」は 12 個の係数を前提にできない．

## 6. 研究価値

### 6.1 (a) 誰のどの判断が変わるか

- **研究者**：段 0 の結果で 2 つの判断が変わる．(i) φ（絶対の UAR で測る）が大きければ，oursx の K ≥ 1 の生徒の上に 12 個以下の係数の学び直しを足す計算に進む．小さければ進まない．(ii) θ_Q の誤差の大部分が温度の成分なら，E71・E73 のパラメータの物差しは尺度を除いた物差しに替える必要があり，流れ A の分析（新しい 3）の書き方が変わる
- **実務者**：案の「教師に生徒のモダリティを入れない」という作り方の勧めは，E71 と E60 の記録（pF が最良）に反し，記録が支える判断にはならない．感情の中の直交化に替えても，その得は話者の割合 S の大きいコーパス（MOSEI）と顔を含む教師に限られる見込みである
- **感情認識の外**：特権情報の蒸留で「教師を生徒の入力と独立にする」ときは，ラベル無しの全体の共分散ではなく感情の中の共分散で行う必要がある，という注意（4.1 節）は一般に使える．ただし LEACE と Frisch–Waugh–Lovell の回帰から数行で出るので，独立の貢献にはならない

### 6.2 (b) 査読者の最も強い反論と，答えられるか

**反論**：「命題 1 と命題 4 は Lee ほか 2021 の補題 3.1 と定理 3.2，漏れの量は同論文の ε_CI，段 3 は行列のスケーリング（Kull 2019）と GLC である．新しいのは教師の入力を生徒の特徴へ回帰で除く 1 行だが，LEACE の定理と Frisch–Waugh–Lovell の回帰から，生徒の特徴と無相関にした入力の線形の教師は，感情の情報を持つなら条件つき独立にならず，条件つき独立なら感情の情報を持たない．残るのは MER-DA の中の説明できない実測の診断だけである」．

### 6.3 (c) 予言が外れた場合に残るもの

- 段 0 で φ（絶対の UAR）が小さい場合：「疑似ラベルで動かした生徒の誤差は θ\* の混ぜ方では表せない」という否定の記録が残る．U7 の説明の候補はアンカー（推測 (a)）と θ\* の尺度に絞られる．統合論文では分析の節の 1 段落と 1 表になる
- 段 0 で温度の成分が大きい場合：U8・A2 の説明が 1 つ確かめられる．E71・E73 の物差しの限界の記録として，論文の分析の節に入る
- 段 1・2：全体の共分散の直交化の結果は 4.1 節の恒等式で予言でき，外れても新しい知見にならない．感情の中の直交化に替えれば，「条件つき独立に近い別のモダリティの教師 ＋ 少数の係数の学び直し」が oursx に勝つかどうかという判断の材料が残る

### 6.4 (d) 投稿先の候補

- 段 0 の測定だけなら，MER-DA の統合論文（分析の部）の 1 節で，単独の論文にはならない
- 感情の中の直交化と少数の係数の学び直しが oursx を上回った場合：ICASSP・Interspeech の短い論文か，IEEE Transactions on Affective Computing の統合論文の手法の一部．Lee 2021 と GLC があるので，機械学習の主会議（ICML・NeurIPS）に出せる理論の新しさは見込めない

1. **直交化を感情の中の共分散で行う．**Γ_w = Cov_w(u, x_s) Cov_w(x_s)⁻¹ を，ソースの各コーパスで感情ごとに中心化した回帰で推し，ソースとターゲットに当てる（ターゲットで推すなら教師の確率で重みづけた中心化）．全体の共分散の直交化は，4.1 節の恒等式を根拠に，結果を先に予言した負の対照としてだけ残す．仮定「感情の中の交差共分散の形がコーパスの間で近い」を，仮のターゲットのラベルで Γ_w を推し直して比べて確かめる
2. **比べる相手と土台を oursx にする．**K ≥ 1 の主な比べる相手を oursx（K ごとに仮のターゲットで選ぶ）にし，「oursx の生徒 ＋ 混ぜ方の学び直し」と「感情の中の直交化の教師を oursx の候補に足した版」を並べる．E66 の B は 2 番目の相手にする．標準の少数係数の較正（温度，BCTS，ベクトルのスケーリング，MS-ODIR）を同じ K 本で θ_Q と oursx の生徒に当てた版も比べる相手に入れる
3. **腕を 3 つにする．**pF（生徒のモダリティを含む），なし（生徒のモダリティを除いた教師．AVT では VT・AT・AV の教師を新しく作る），感情の中の直交化．直交化の効果と「生徒のモダリティを除く」効果を分ける．P2-4 は E71 の集計（5.1 節）から書き直す（K=0 で pF の生徒より 3〜8 ポイント低い，を基準にする）

5. **φ の比を判定から外す．**判定は K 本で学んだ混ぜ方の後の絶対の UAR（と pF・oursx との差）で行い，φ は記述にする（4.5 節）

## 8. 新しさが残る最小の主張（条件つき）

1. **（測定）疑似ラベルで動かした単独のモダリティの生徒の誤差の分解**：仮のターゲットで，pF の疑似ラベル（m = 2000）でアンカーを動かした生徒 θ_Q の，θ\* に対する交差エントロピーの超過と UAR の差のうち，温度・感情ごとの尺度・非対角の混ぜ方・切片でそれぞれ取り除ける量を測る．温度の成分を除いた後に，見方どうしの誤差の相関（U7．0.77〜1.00）が下がるか，誤差と UAR の順位相関（U8．0.16〜0.41）が上がるかを示す．条件：θ\* の尺度を整えた基準でも同じ結論になること（直し 4），判定を絶対の値で行うこと（直し 5）．調べた範囲で，別のモダリティの教師による蒸留の生徒の誤差をこの形で分けた研究は見つからなかった．負の結果でも記録として残る
2. **（注意．新しさは小さい）ラベル無しの線形の直交化の限界**：教師の入力を生徒の特徴と無相関にすると，感情の間の交差共分散は感情の中の交差共分散の符号を変えたものに等しくなり（4.1 節），生徒の感情の平均が C − 1 次元を張る限り，教師は「感情の情報を持つ」と「生徒の特徴と条件つきで無相関」を同時には満たせない．LEACE と Frisch–Waugh–Lovell の回帰から数行で出るので，論文では注意の 1 段落として書く
3. **（手法．条件つき）感情の中の直交化で作る別のモダリティの教師**：ソースのラベルで推した感情の中の回帰で教師の入力を生徒の特徴に直交させると，生徒のモダリティを除いただけの教師より ε_CI が下がり，混同行列の最小特異値は下がらない．その生徒に K 本で少数の係数を学び直した版が，oursx を K = 5〜10 のどこかで上回る．条件：主張 1 で混ぜ方の成分が大きいこと，関門 1 を通すこと．E71 の集計（5.1 節）から，K ≤ 1 で oursx を上回る見込みは低い

## 9. 本査読の限界

- 4.3 節の人工データは正規の模型で，次元と標本の比が MER-DA と違う．MER-DA の特徴での直交化の効果は測っていない（特徴を読み込む計算は本査読の範囲の外とした）
- 5.1 節の E71 の t_* は別の 1 つのモダリティのアンカーを教師にした値で，AVT の 2 つのモダリティをまとめた教師（VT など）の値ではない．案の AVT の教師は t_* より強い可能性がある
- Li & Duan 1989，MISA，Chen 2023，BCTS は抄録，NAP は二次資料だけで確かめた．Lachenbruch 1966 の主張（誤ったラベルで LDA の方向が変わらない）は確かめられなかったので使っていない
- 4.1 節の恒等式は母集団の量で書いた．リッジと交差あてはめで推す Γ̂ では標本の上の直交は近似で，取り残した相関の分だけ線形の情報が通る（4.2 節）
- 5.1 節と 4.3 節の計算は関門を通していない
