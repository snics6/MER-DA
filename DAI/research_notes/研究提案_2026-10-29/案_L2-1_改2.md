# L2-1 改 2：演技のコーパスのラベルを知覚の多数決に付け直すと，中心化では直らない誤りは減るか（同じ発話の付け替えによるコーパス間の感情認識の測定）

作成：2026-10-29．本体のセッション．`査読_L2-1_改.md` の 6.2 節の直し (A)〜(D) を 1 つずつ照らして入れた版である．再査読の判定は「(A)〜(D) は書き換えで済む．本体が 6.2 節の項目を照らして入れたことを確かめれば，3 回目の深い査読なしで研究者に出してよい」．前の版は `案_L2-1_改.md`，元の案は `案_L2.md` の L2-1．

## 題（直し A）
- 演技のコーパスのラベルを知覚の多数決に付け直すと，中心化では直らない誤りは減るか：同じ発話の付け替えによるコーパス間の感情認識の測定
- Does Relabeling Acted Corpora with Perceived-Emotion Majorities Reduce the Errors That Centering Cannot Fix? A Same-Utterance Relabeling Study of Cross-Corpus Emotion Recognition

## 設計の前提として書く性質（直し A．再査読 3.1 節）
MER-DA の学習器は学習データの平均を引いて標準化し，切片に罰則をかけない．このためソースのみの分類器では，ラベル無しの中心化は「各感情の点数に定数を足す操作」と同じである．足す定数は Δb_k = w_kᵀD⁻¹(μ_S − μ_T)（D は学習データの標準偏差の対角行列）である．同じ発話の集合なら μ_S，μ_T，D はソースのラベルに依らず，ラベルに依るのは係数 W（したがって Δb）と切片 b だけである（照合で `exp/logreg.py`・`exp/mech.py` を読んで確かめた）．したがって「中心化の上がり幅の差」E1 は，中心化しないときの付け替えの効果 G_u から中心化したときの効果 G_c を引いた値に恒等的に等しく，「付け方が作ったずれの割合」を測らない（人工の反例 2 つ：付け方のずれが 0 でも E1 が上がり幅の 100% になる例，ずれの全部が付け方でも E1 が 0 になる例．再査読の付録 B）．

## 問い
演技のソース（CREMA-D，RAVDESS）のラベルを，そのコーパス自身が公開する知覚の多数決に付け替えると，(1) 中心化しないときと (2) 中心化したときに，自然な会話のターゲットの成績はどれだけ変わるか．(3) 付け替えは判断基準 o だけを動かすか，識別力 d も変えるか．(4) 2 つの演技のコーパスの間で，ソースとターゲットの付け方が合うと成績が上がるか．

## 主な量（直し A）
- G_u：中心化しないときの付け替えの効果（知覚の版 − 同じ発話の集合の意図の版）
- G_c：中心化したときの付け替えの効果（同上）．**主に読む量**
- E3：付け替えによる o と d の変化（E13 の 2 つの山の模型，`exp/explore_pairs.py`）．平静を含む対とそれ以外で分ける
- E1 = G_u − G_c：「付け替えの効果のうち中心化の代わりになる分」と読む．割合は計算の前に決めた CREMA-D の 4 組の和の比で出す
- E2：2×2 の交互作用（付け方が合う組の平均 − 合わない組の平均）．CREMA-D ⇄ RAVDESS の 2 方向
- 補助 1：Δb の版による差．対 (k, l) ごとに Δb_k − Δb_l を意図の版と知覚の版で比べる（ターゲットのラベルを使わない）．G_c が切片を合わせた対照を上回るとき，その分に W の変化による定数の違いが含まれるかをこの量で確かめる
- 補助 2：中心化した点数の上の E13 の位置による損（段 1 で出す）

## 対照（直し B）
- 同じ発話の集合の意図の版（主の比べる相手）
- 無作為の対照：同じ本数を無作為に平静へ移す（`flip_labels_pair`）．20 回以上引き，その分布を偶然の水準にする．予言は D3a の式（log(1/(1−2ρ))）を使わず，感情の重みを釣り合わせた学習（`exp/logreg.py` の `balanced_weights`）で導き直すか，人工データで向きを確かめてから書く（再査読の検算では式の 2.02 に対し 0.35）
  - 予言：釣り合いの重みのもとでは，悲しみを無作為に平静へ移しても平静–悲しみの境目はほとんど動かず（再査読の人工の例で，ρ = 0.434 のとき対数オッズで +0.35），平静–喜びの境目が平静の側へ動く（+1.01 → +0.82）．平静と答える範囲が縮む向きである．UAR の上での向きは関門 1 の前に人工データで確かめる
- 切片を合わせた対照：意図の版の分類器に感情ごとの定数を足し，ソースの交差当てはめの予測の感情の割合を知覚の版の分類器と同じにする（ターゲットのラベルは使わない．学び直しは要らない）．G_c のうち切片で説明できる分を除く
- 付け替えの量と効果の関係：感情ごとに平静へ移る割合（CREMA-D の声だけで喜び 51.5%・悲しみ 66.6%・怒り 16.8%，両方の評定で 3.5%・43.4%・7.0%）と，対ごとの G_c と d の変化を版と対をまたいで並べる

## E2 を測れる形にする（直し C）
- 主を声だけの評定の版にし，両方の評定の版を副にする（RAVDESS で平静へ移るのは両方の評定で 672 本中 22 本，声だけで 127 本．どちらも落ち着き（calm）の票を平静に合わせた数）
- ターゲットの 2 版で発話の集合をそろえる．RAVDESS の calm の票と同票の扱いを計算の前に決める
- 推定の揺れに，ソースの話者の再標本化（C を固定して学び直す）を入れる
- 平静–怒り（付け替えで縮まない）を負の対照として予言の表に入れる
- M1′ の範囲を「2 つの演技のコーパスの間」に限り，「感情と呼ぶ強さの境目が合うか」と書く

## 誰のどの判断が変わるか（再査読 5.1 節）
- 研究者：主張契約の最小の証拠 1（`paper/CLAIM.md` 4 節．E12 を「o の損が中心化で消える証拠」とする）の読み方と，模擬査読 Minor-3（閾値のずれにラベルの定義の違いが入りうる）への答え．答えの半分は 3.1 節の性質から計算なしで書ける
- 演技のコーパスをソースに使う人：G_c > 0 か，E3 で d が上がるときだけ，CREMA-D と RAVDESS を知覚の多数決に付け直す判断が変わる．G_c ≤ 0 なら「中心化をすれば付け直しは要らない」という助言になる
- 本案は分析であり，手法の新しさには直接は貢献しない

## 最も強い反論と答え（再査読 5.2 節）
1. 「E1 は付け方がずれを作らなくても正になる」：主の量を G_c と E3 にし，E1 は中心化の代わりになる分と読むことで答える
2. 「自然な会話のターゲットの付け方は，クラウドの知覚と手順が違う」：計画した実験では答えられず限界として書く．E2 は演技どうしに限り，自然な会話のターゲットは「付け直しが成績を変えるか」として報告する．IEMOCAP 即興の本人の評定の版を，偏りの向きが無い負の対照に使う
3. 「付け替えは雑音の減少，感情の強さによる選別，付け方の一致を同時に起こす」：E2 の交互作用と無作為の対照と切片を合わせた対照で分ける

## 新しさの主張（再査読 7 節）
- M3′（条件：G_c の区間が 0 を含まず正で，2 つの対照の分布を上回り，E3 で平静を含む対の d が上がる）：ソースのラベルを知覚の多数決に付け替えると，自然な会話のターゲットで中心化では直らない誤り（向き d）が減る
- M1′（条件：声だけの評定の E2 が 2 方向とも区間で 0 を含まず，無作為の対照を上回り，平静–怒りでは 0 に近い）：2 つの演技のコーパスの間で「感情と呼ぶ強さの境目」が合うと成績が上がる
- M2′（条件：CREMA-D の 4 組で G_u の区間が 0 を含まない．新しさは小さい）：付け直しの効果のうち中心化で代わりに得られる割合 (G_u − G_c)/G_u

## 規模と承認
段 0 は保存済みの点数の採点し直しで CPU で数分．段 1 はソースのみの分類器の学び直しで，1 ソースあたり約 45 版（意図，同じ集合の意図 2 通り，知覚 2 通り，無作為 2 通り × 20 回），2 ソースで A5000 で 2〜3 時間．承認が要るのは発話一覧の列の追加（`data/README.md` の更新），RAVDESS の評定の取り込み，段 1 の計算．解析は C を固定した地図の値で書く．
