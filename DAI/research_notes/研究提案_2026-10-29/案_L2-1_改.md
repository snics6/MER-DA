# L2-1 改：演技のコーパスのラベルの付け方は，中心化で消える判断基準のずれを作っているか（同じ発話の付け替えによるコーパス間の感情認識の測定）

作成：2026-10-29．本体のセッション．`査読_L2-1.md` の 6.2 節の直し 1〜5 をすべて入れ，6.3 節の骨子に沿って書いた版である．元の案は `案_L2.md` の L2-1．

## 題
- 演技のコーパスのラベルの付け方は，中心化で消える判断基準のずれを作っているか：同じ発話の付け替えによるコーパス間の感情認識の測定
- Do Labeling Conventions of Acted Corpora Create the Criterion Shift That Centering Removes? Relabeling the Same Utterances in Cross-Corpus Emotion Recognition

## 問い
演技のソース（CREMA-D，RAVDESS）から自然な会話のターゲットへ移るとき，ラベル無しの中心化で消える判断基準のずれ（E12 で，演技 → 自然の 10 組で中心化だけで平均 +4.0 点．その後の K=5 の切片の直し D1 は +0.15 点）のうち，ソースのラベルをそのコーパス自身が公開する知覚の多数決に付け替えると消える分はどれだけか．付け替えは識別力 d も変えるか．

## 量（定義は関門 1 の gate-define に渡す）
- E1：中心化の上がり幅の差 ＝〔意図の版のソースでの中心化の上がり幅〕−〔知覚の版のソースでの中心化の上がり幅〕．E1 を意図の版の上がり幅で割った値を「中心化が消すずれのうち付け方が作る割合」とする
- E2：2×2 の交互作用 ＝ 付け方が合う組（意図×意図，知覚×知覚）の成績の平均 − 合わない組の平均．CREMA-D と RAVDESS の 2 方向で作る
- E3：付け替えによる o と d の変化（E13 の 2 つの山の模型．`exp/explore_pairs.py`）．平静を含む対とそれ以外で分ける

## 設計
- ソースの版：意図，知覚（声と顔の両方の評定の多数決．主），知覚（声だけ．副）．対照：同じ発話の集合の意図，同じ本数を無作為に移した意図（`flip_labels_pair`）
- ターゲット：自然な会話の 5 群（知覚の版だけ），CREMA-D と RAVDESS（意図と知覚の 2 版．RAVDESS の評定は PLoS ONE の補足資料 S5 Table），IEMOCAP 即興の本人の評定の版（1,579 本．副）．MOSEI の平静の定義 3 版は段 0 の感度として出す
- 主はソースのみの分類器（段 0 と段 1）．K 本の地図（段 2）は，E1〜E3 の結果を見てから承認を取る
- E8 の軸（ターゲット側の重みの 67% が RAVDESS の 1 行）は副に下げ，CREMA-D ⇄ RAVDESS を 2×2 で直接測る．U24 の 6 組を使う予言は検出力が無いので外す
- 統計の単位は（ソース，ターゲット）の組．ターゲットの話者を単位にしたブートストラップの区間で記述し，検定は計算の前に数を絞って gate-stats に渡す
- 段 0（採点し直し．CPU で数分）を関門にする：意図のソース × ターゲットの 2 版と MOSEI のしきい値の感度を先に出し，段 1 に進む基準を計算の前に書く

## 予言と外れ（基準の数値は関門 1 で決め直す）
- 付け方が判断基準のずれの一部を作るなら：E1 は正で，CREMA-D の両方の評定の版では平静–悲しみの対に集まり，平静–喜びではほぼ 0（両方の評定で喜びから平静に移るのは 3.5% のため）．E2 は正．無作為に移す対照では E1 が負になる
- 付け方が判断基準のずれを作らないなら：E1 はほぼ 0，E2 はほぼ 0
- ターゲットごと：MOSEI（平静の取りこぼしが無い），演技どうしの組（付け方が同じでも CREMA-D → RAVDESS の位置による損 17.2 点），自然 → 演技の平静–悲しみ（偏りが無いか逆向き）を予言の表に入れる
- どちらの結果も論文の読み方（`paper/CLAIM.md:64`）の判断材料になるので，両方の書き方を計算の前に決める

## 新しさの主張（査読の 7 節を引き継ぐ）
- M1（条件：E2 が 2 つの対照を超えて正）：同じ発話のまま付け方だけを変えた比較で，コーパス間の感情認識の判断基準のずれにラベルの付け方が寄与することを示した最初の測定．最も近い Giordano 2026（arXiv 2610.26446）は 1 コーパスの中だけで比べ，コーパス間を今後の課題とした
- M2（条件：E1 の区間が 0 を含まない．向きはどちらでもよい）：ラベル無しの中心化が消す判断基準のずれのうち，ソースの付け方が作る割合の推定
- M3（条件：E3 で付け替えが d を変える）：付け方の違いが o と d のどちらに出るか．d に出れば，演技のソースを知覚の多数決に付け直す実務の助言が立つ
- 表 1-1 の割合は Lei & Cao 2023（TAC）の表 1 と同じで既知の数として帰す

## 規模と承認
段 0 は CPU で数分，段 1 は A5000 で 1 時間以内．新しい特徴と新しい注釈は要らない．承認が要るのは，発話一覧の列の追加（`data/README.md` の更新），RAVDESS の評定の取り込み，段 1 の計算の 3 つ．解析は C を固定した地図の値で書く．
