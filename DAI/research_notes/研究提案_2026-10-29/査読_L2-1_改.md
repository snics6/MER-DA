## 3. 中心の量の判定

### 3.1 前提：ソースのみの分類器では，中心化はラベル無しで決まる切片の足し算と同じである

- 学習器（`exp/logreg.py` の `fit`）は，学習データの平均 μ と標準偏差 D で特徴を z = D⁻¹(x − μ) に直し，切片 b に罰則をかけず，感情の重みを n/(k·n_y) にそろえて解く．
- E12 の中心化（`exp/mech.py` の `centered`）は，ソースから学習に使う行の平均 μ_S を引いてから学ぶ．平均を引いた特徴を同じ学習器に入れても z は変わらないので，W と b は中心化しない分類器と同じになる．C を選ぶ交差検証も袋ごとに同じ標準化をするので，同じ C が選ばれる．
- ターゲットは自分の全発話の平均 μ_T を引く．したがってターゲットの発話 x での点数は，中心化しない分類器の点数に，感情 k ごとの定数 Δb_k = w_kᵀ D⁻¹ (μ_S − μ_T) を足したものと等しい．
- **ソースのみの分類器での中心化は，K 本のラベルの代わりにコーパスの平均から決める D1 である．**E12 で中心化の後の D1 が +0.15 点しか上がらないのは，2 つの操作が同じもの（感情ごとの定数）を動かすためである．
- 付け替えとの関係：同じ発話の集合なら μ_S，μ_T，D は版に依らない．版によって変わるのは W（したがって Δb）と b だけである．

### 3.2 E1（中心化の上がり幅の差）

**(a) 定義は一意に決まるが，読み方が成り立たない**

- 恒等式：U_u(v) と U_c(v) を，版 v のソースで学んだ分類器の中心化の前と後の UAR とすると，
  E1 = [U_c(I) − U_u(I)] − [U_c(P) − U_u(P)] = [U_u(P) − U_u(I)] − [U_c(P) − U_c(I)] = G_u − G_c．
  G_u は中心化しないときの付け替えの効果，G_c は中心化したときの付け替えの効果である．
- 3.1 節から，同じ発話の集合では E1 が 0 から離れる経路は 2 つしかない．(i) 付け替えが W を変え，中心化が足す定数 Δb が変わる．(ii) 付け替えが b を動かし，UAR が境目の位置について非線形（最適の位置の近くで平ら）なので，中心化の前と後で付け替えの効果の大きさが違う．(ii) は付け方がずれを作ったかどうかに関係なく起きる．
- **反例 1（付け方のずれが 0 でも E1 は上がり幅の 100%）**：1 次元，平静 N(0,1) と悲しみ N(−2,1) のソースで，意図の版の境目を −1，知覚の版の境目を −1.5 とする．ターゲットは両方の感情とも平均が 1 低いだけ（付け方は同じ）とする．中心化の上がり幅は意図の版で 10.3 点，知覚の版で 0.0 点，E1 = 10.3 点，割合 1.00 である．このとき G_u = +7.4 点，G_c = −2.9 点である（付録 B の 1）．
- **反例 2（ずれの全部が付け方によるときに E1 は 0）**：ターゲットがソースと同じ分布で，ターゲットの付け方だけが「x > −1.5 の悲しみも平静」とすると，中心化は何も動かさないので E1 = 0 である．ソースを同じ付け方に付け替えると G_u = G_c = +9.2 点である（付録 B の 2）．
- **したがって E1 は「付け方が作った割合」ではなく，「付け替えの効果のうち，中心化をすれば要らなくなる分（中心化の代わりになる分）」を測る．**この読み方なら定義は一意で，「演技のソースを付け直す必要は中心化の後にも残るか」という実用の問いに答える．付け方がずれを作ったかどうかを測れるのは，ソースとターゲットの両方で付け方を変えられる E2 だけである．
- 割合の分母が 0 に近い組が多い．E12 の 10 組の中心化の上がり幅は，CREMA-D → IEMOCAP 即興・台本・MELD・AFEW の 4 組で +6.2〜+12.0 点，残る 6 組（CREMA-D → MOSEI と RAVDESS をソースにした 5 組）で −0.5〜+2.6 点である（前の査読 4.2 節の表）．割合を出すなら，計算の前に決めた 4 組の和の比にする．
- 単位がずれている．E1 は 4 感情の UAR で定義されているが，予言は対ごと（平静–悲しみに集まる）に書かれている．対ごとの予言を書くなら，E13 の 2 つの山の模型の o と位置による損の単位で G_u と G_c を定義する．

**(b) 予言は E12・E13 と両立するが，2 つの仮説を区別しない**

- 改の版の「付け方が作るなら E1 は正，作らないなら E1 ≈ 0」の後半は，反例 1 のとおり導けない．
- E12 と 3.1 節から，区別できる予言が導ける．意図の版では中心化の後に切片のずれがほとんど残っていない（D1 が +0.15 点）．よって付け替えが切片だけを動かすなら，中心化の後の付け替えは最適の位置から境目をずらすので **G_c ≤ 0** になる．付け替えが向き（d）を良くするなら **G_c > 0** になる．どちらも E12 と両立し，互いに区別できる．
- K=5 の D1 は切片の推定の揺れを含むので，+0.15 点は中心化の後に残る切片のずれの上限としては緩い．段 1 で中心化した点数の上で E13 の位置による損（ターゲットの全ラベルで測る）を出せば，残りのずれを K 本の揺れなしで測れる．計算は段 1 の点数から CPU で済む．
- E13 との関係：演技 → 自然の 6 組の位置による損は 4.8 点，向きによる損は 7.8 点（`docs/exploratory-analyses.md` の E13 の 5）である．G_c > 0 の予言は向きの損の一部が付け替えで縮むことを意味し，E13 の値の範囲と矛盾しない．

**(c) 2 つの対照で除ける交絡と除けない交絡**

- 同じ発話の集合の対照（知覚の版で同票か 4 感情以外になる発話を，意図の版からも除く）は，μ_S と D が版で変わる分を除く．G_u・G_c・E1 の比べる相手として要り，その目的には足りる．
- 無作為の対照は 3.5 節のとおり予言が導かれていない．
- どちらの対照も，「付け替えが境目を中心化と同じ向きに動かした」ことと「ソースの付け方がターゲットの付け方に合った」ことを分けない．自然な会話の 5 群はターゲットの版が 1 つしか無いので，この 2 つはこの設計では分けられない．
- **足すべき対照：切片を合わせた対照．**意図の版の分類器に感情ごとの定数を足し，ソースの交差当てはめの予測の感情の割合を知覚の版の分類器と同じにする（ターゲットのラベルは使わない）．知覚の版がこの対照を上回る分は，切片では表せない効果（向き）である．学び直しは要らない．

**(d) ラベル無しで測れる補助の量**

3.1 節の Δb を版ごとに出せば，「ソースのラベルが，コーパスの平均のずれに対する点数の反応をどれだけ変えるか」（経路 (i)）をターゲットのラベル無しで測れる．対 (k, l) ごとに (Δb_k − Δb_l) を意図の版と知覚の版で比べる．付け方が中心化の消すずれの大きさを変えたと言えるのは，この量が版で変わる場合だけである．

### 3.3 E2（2×2 の交互作用）

**(a) 定義**

- 2×2 は CREMA-D → RAVDESS と RAVDESS → CREMA-D の 2 方向で作る．次の 3 点を計算の前に決めれば一意に決まる．改の版はどれも書いていない．(1) ターゲットの 2 版で発話の集合をそろえる（知覚の版で落ちる発話を意図の版からも落とす）．(2) RAVDESS の知覚の多数決で calm の票を平静に合わせるか（前の査読の表 3-1 は合わせた）．(3) 同票の扱い．
- **主の版（両方の評定）では E2 がほぼ測れない．**RAVDESS で両方の評定に付け替えると，平静へ移るのは 22 本（喜び 2，悲しみ 19，怒り 1．表 3-1）で，ほかに約 40 本が同票か 4 感情以外で落ちる．RAVDESS → CREMA-D ではソースの分類器がほとんど変わらず，CREMA-D → RAVDESS ではターゲットの 2 版の違いが 22 本しかない．交互作用は，ソースの版の違いとターゲットの版の違いの両方が大きいときにだけ大きくなるので，両方向とも小さくなる．声だけの評定では RAVDESS で 127 本（喜び 62，悲しみ 56，怒り 9），CREMA-D で 1,716 本が平静へ移る．
- MER-DA の RAVDESS の音声の特徴は音声のみのファイル（先頭が 03）から作られており（1 節の 3），声だけの評定はこのファイルに付く．両方の評定は映像＋音声のファイル（先頭が 01）に付き，同じ録音かは確かめていない（前の査読 3.2 節）．**E2 の主を声だけの評定にすれば，版の差が大きくなり，ファイルの対応の問題も生じない．**両方の評定は副にする．

**(b) 予言と記録**

- E13 の CREMA-D → RAVDESS の平静–怒りの位置による損 17.2 点は，同じ意図のラベルどうしの損である．怒りはほとんど平静へ移らない（CREMA-D の声だけで 16.8%，RAVDESS の声だけで普通の強さの 9 本）ので，付け替えではこの損は縮まないと予言できる．この対は 2×2 の中の負の対照になる．
- E2 の正の予言は平静–喜びと平静–悲しみに集める．これは E13 と両立する．

**(c) 対照**

- 交互作用は，ソースの版の主効果（雑音が減る，はっきりした発話だけが感情のクラスに残る）とターゲットの版の主効果を打ち消すので，「付け方が合うか」を測る設計として正しい．
- 「付け方」と「感情と呼ぶ強さの境目」は，CREMA-D と RAVDESS の知覚の付け替えではほぼ同じものである（移るのは普通の強さの喜びと悲しみ）．この 2 つは分けられず，分ける必要もない．M1 の文は「感情と呼ぶ強さの境目が合うか」と具体的に書く．
- 無作為の対照は，E2 では「無作為に付け替えたソース × ターゲットの 2 版」の交互作用を 20 回以上引いた分布として使い，偶然の水準にする．
- 統計：方向は 2 つしかない．ターゲットの話者のブートストラップ（RAVDESS 24 人，CREMA-D 91 人）は，ソースの標本の揺れを含まない．ソースの話者の再標本化（C を固定して学び直す）を足す．
- 範囲：E2 は 2 つの演技のコーパスの間の測定であり，演技 → 自然についての主張の根拠にはならない．

### 3.4 E3（付け替えによる o と d の変化）

- **(a)** `exp/explore_pairs.py` の d と o（対ごと，ターゲットのラベルで測る）で一意に決まる．「d が変わる」の基準（区間と最小の幅）は関門 1 で決める．
- **(b)** E13（2 つの山の模型は実際の正解率を誤差平均 1 点以内で再現する）と E58（向きの質はラベルの中身で決まる）と両立する．付け替えはソースのラベルの中身を変えるので，d を変えうる．
- **(c)** 無作為の対照は感情ごとの本数を知覚の版と同じにするので，本数が減ったこと（CREMA-D の両方の評定で悲しみは 1,271 本から 417 本）による d の低下を除ける．知覚の版は d を上げ，無作為の版は雑音を足すので d を下げる，という向きの違う予言が立つ．3 つの量のうち，2 つの対照で仮説を区別できるのは E3 である．ただし知覚の版で残るのははっきりした悲しみだけなので，自然な会話の弱い悲しみに対しては向きが合わなくなる可能性もある．どちらの向きでも結果になる．
- **E3 は 3 つの量のうちで定義と対照が最も整っている．**G_c と並べて主の量にする．

### 3.5 無作為の対照と D3a の式

- D3a の式（感情 a の割合 ρ を b へ移すと，a と b の境界が対数オッズで log(1/(1−2ρ)) 動く．`docs/methods.md` 7.4 節）は，ラベルの割合をそのまま使う学習の境界である．
- MER-DA の学習器は感情の重みを n/(k·n_y) にそろえるので，母集団の極限では各感情の密度 p(x|y) を比べる判断になる．悲しみの割合 ρ を無作為に平静へ移すと，悲しみの密度は p_S のままで，平静の密度は (1−w)p_N + w·p_S（w は平静に混ざった悲しみの割合）になる．悲しみと判断する条件 p_S > (1−w)p_N + w·p_S は p_S > p_N と同じなので，**悲しみと平静の境界は動かない**．動くのは平静とほかの感情（喜び，怒り）の境界で，平静と判断される範囲が縮む．
- 人工の 1 次元の例（4 感情．平均は悲しみ −2，平静 0，喜び +2，怒り +4，分散 1，計 20,000 本．sklearn のロジスティック回帰，C = 10⁴）で，ρ = 0.434（CREMA-D の両方の評定で悲しみが平静へ移る割合）のとき，元の境目 x = −1 での平静と悲しみの対数オッズの変化は，釣り合いの重みで +0.35，重みなしで +1.23 だった．式の値は 2.02 である．釣り合いの重みでも少し動くのは，混ざった平静の密度を線形の対数オッズで表せないためである．平静と喜びの境目は，釣り合いの重みで +1.01 から +0.82 へ平静の方へ動いた（付録 B の 3）．
- したがって，改の版の「無作為に移す対照では E1 が負になる」と，前の査読の「境界は対数オッズで約 2.0 動く」（`査読_L2-1.md` 5.2 節）は，どちらもこの学習器では導けない．無作為の対照の予言は，釣り合いの重みのもとで導き直すか，人工データで向きを確かめてから書く．
- 付記（本査読の範囲の外．本体のセッションへの申し送り）：同じ理由で，`docs/methods.md` 7.4 節の D3a の導出と予言 P4-3 も，学習器の釣り合いの重みを入れていない．

## 5. 研究価値

### 5.1 (a) 誰のどの判断が変わるか

- **研究者（MER-DA の論文）**：主張契約の最小の証拠 1（`paper/CLAIM.md` 4 節の 1．E12 を「o の損が中心化で消える証拠」とする）の読み方と，模擬査読 Minor-3（`paper/reviews/round1/review-affect.md` の Minor-3．閾値のずれにラベルの定義の違いが入りうる）への答えが決まる．3.1 節の性質から，答えの半分は計算なしで書ける．中心化はコーパスの平均から決める感情ごとの定数であり，E12 ではその後に K 本で切片を直しても +0.15 点しか上がらない．したがって，ラベルの定義の違いが作る切片のずれのうち，コーパスの平均のずれと別に残る分は小さい．残る半分（ソースの付け方の違いが向きを変えるか，演技のコーパスどうしで付け方の一致が成績を変えるか）は G_c・E3・E2 で答える．

### 5.2 (b) 査読者の最も強い反論と，答えられるか

1. **「E1 は付け方がずれを作らなくても正になるので，表題の問いに答えない」**（本査読の 3.2 節）．今の設計では答えられない．直し (A) で答えられる：E1 を「中心化の代わりになる分」と読み直し，G_u・G_c・切片を合わせた対照・E3 で「付け替えが切片だけを動かすか，向きも変えるか」を測る．
2. **「自然な会話のターゲットの付け方（IEMOCAP は映像と音声と文脈を見た評価者 3 人，MELD は対話の文脈を見た注釈者，MOSEI は強度の評定）は，クラウドの知覚と手順が違う．演技 → 自然の結果を付け方の一致として読む根拠が無い」**．計画した実験では答えられず，限界として書くしかない．答えられる範囲は，E2 で演技どうしについて付け方の一致の効果を示すことと，自然な会話のターゲットについて G_u・G_c を「付け直しが成績を変えるか」として報告することまでである．IEMOCAP 即興の本人の評定の版は，平静の向きの偏りが無い（評価者が平静で本人が感情 55 本，逆 70 本．前の査読 1 節の 3）ので，付け方の違いはあるが偏りの向きが無い負の対照として使える．
3. **「知覚の多数決への付け替えは，雑音の減少，感情の強さによる選別，付け方の一致を同時に起こす」**（前の査読 5.2 節）．E2 の交互作用と無作為の対照で答えられる（3.3 節 (c)）．

### 5.3 (c) 予言が外れた場合に残るもの

### 6.2 合格に要る直し

**(A) 主の量と表題を直す（V2・V4）**
- 主の量を G_u（中心化しないときの付け替えの効果）と G_c（中心化したときの付け替えの効果）と E3 にする．どれも同じ発話の集合の意図の版と比べる．
- E1 = G_u − G_c は「付け替えの効果のうち中心化の代わりになる分」と読み，割合は計算の前に決めた CREMA-D の 4 組の和の比で出す．

**(B) 対照を直す（V2・V4）**
- 無作為の対照の予言を，感情の重みを釣り合わせた学習で導き直すか，人工データで向きを確かめてから書く（3.5 節）．D3a の式の値（log(1/(1−2ρ))）を予言に使わない．
