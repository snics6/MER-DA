# 査読：L1-2「別のモダリティが張る部分空間で少数のラベルを足りるようにする」（流れ B 第 1 回）

## 0. 結論

1. **現状の L1-2 は不合格と判定する．**N2・V1・F1・S1 は満たし，N1 は条件つきで満たすが，V2 と V4 を満たさない（8 節）．9 節の直しを入れれば，合格の見込みがある．
2. **定理 C1 は既知である．**C1 の 1 と，C1 の 3 の K ≥ 1 の部分は，Foster, Kakade, Zhang 2008 の定理 3，Ando & Zhang 2007 の定理 1，Chaudhuri ほか 2009 の補題 1，Lee ほか 2021 の定理 4.2 に書かれている（原文で確かめた）．ふるいが指摘した階数の条件は，Foster ほか 2008 の仮定 1 と Lee ほか 2021 の仮定 4.1 そのものである．C1 の 2（話者の平均を引く）は，部分正準相関（共変量を除いた正準相関分析）の手続きを話者に当てたものである．
3. **提案の判定 P2-1 は C1 を確かめない．**C1 が述べるのは「ターゲットの最良の頭 θ\* が部分空間 S に入る」ことで，「アンカーの誤差 e が S に入る」ことではない．θ\* が S に入るとき，K=0 でアンカーを S に射影して減る誤差は e の S の外の成分であり，capx(e, S) が小さいほど射影の得は大きい．判定を「θ\* を S が含む割合」「射影の損得」「capx」の 3 つに分ける必要がある（4.1 節）．
4. **V4：提案が扱っていない記録が 2 つある．**(i) E58 の結果を見た後の確かめで，K=5 の直しを候補の上位 k 主成分（k = 10〜100）に限ると UAR は −0.4〜+0.2，罰則を 10 倍緩めると −3.3〜−5.6 だった（`docs/exploratory-analyses.md:6408`）．ラベル無しで決めた低い次元の部分空間に直しを限る手続きが UAR を上げなかった直接の記録である．(ii) E74 の PCA の並びの r=16 の capx(e_Q) は，音声と顔の 6 群のうち 4 群で，θ\* の推定の揺れ（雑音）の capx との差が −0.26〜+0.10 である（本査読の計算．`results/explore_relation/e74_groups.csv`）．capx の物差しは分散の大きい向きを構造的に有利にするので，「CCA が PCA を上回るか」の比べ方を計算の前に直す必要がある（4.3 節）．
5. **実行（F1）は高い．**1 段は E74 の台本 `exp/explore_theory_assumptions.py` に方向の並び 2 つ（cca，cca_w）と 2 つの診断を足すだけで，E74（AV 2,361 秒，AVT 1,332 秒）の 1.5 倍程度，約 1.5〜2 時間の見込みである．
6. **新しさが残る最小の主張**は 2 つで，どちらも条件つきである（10 節）．M1：話者の平均を引いた別のモダリティとの正準部分空間が，コーパス間で学んだアンカーの誤差とターゲットの最良の頭をどれだけ含むかを，E74 と同じ物差しで PCA・共分散の差・でたらめな方向と比べた測定．M2：その部分空間にアンカーを射影し K 本で直す手続きが，E39 と，同じ次元の PCA に限った版を UAR で上回ること．

## 2. 案の中心の主張の言い直し

案（`案_L1.md` 2.4 節）の主張は 4 つである．

- **C1（定理）**：z_m = A_m e(y) + B_m u + ε_m の模型で，(1) 生徒のモダリティ s の最良の線形の頭は Σ_ss⁻¹ col(Σ_st)（以下 S．次元は (C − 1) + r_u 以下）に入る，(2) 話者ごとの平均を引くと r_u が下がる，(3) S の中だけで K 本で直すと向きの誤差は ((C − 1) + r_u)/K になり，K=0 ではアンカーを S に射影しても誤差は増えない
- **C2（測定）**：E74 の物差し capx で，話者の平均を引いた正準方向の並び（cca_w）は r=16 で e_Q と e0 を PCA の並びより多く含み，話者の平均を引かない並び（cca）より多く含む
- **C3（仮定の測定）**：話者の中の正準相関は 3 本の後で大きく下がる．下がらない群では C2 も成り立たない
- **C4（手法）**：アンカーを cca_w の部分空間の中で直し，外ではアンカーに強く留める学習器が，K ≤ 5 で E39 と oursx を上回る．部分空間の中の学習曲線の学びにくさ q_S は全空間の q より小さい

このほか，次を確かめた．
- **Kakade & Foster 2007（COLT）**：本文は取得できなかった（Harvard のサイトは移転し，新しいサイトは JavaScript で書かれた目録だけ）．Foster ほか 2008 の 1.1 節が「冗長性の仮定のもとで縮める推定（罰則）と次元の削減の 2 つを示し，削減は Foster ほか 2008 で罰則と同じ程度に良いと示した」と書き，Foster の講演スライド（◎）に罰則 Σ(1 − λ_i)/λ_i β_i² の式がある．水準は ○ である
- **部分正準相関と多水準の手続き**：共変量（ここでは話者の指示変数）の線形の効果を除いてから CCA を取る部分正準相関と，被験者の中の変動に PLS を当てる多水準の sPLS（mixOmics．Liquet ほか 2012）がある（△．検索の要約）．案の C1 の 2 の計算はこの型に入る
- **固有声（eigenvoice）**：Kuhn ほか 2000（IEEE TSAP）は，多数の話者の模型の主成分が張る低い次元の空間に新しい話者の模型を限り，少ない適応データで推定する（△）．「ソースの散らばりが張る低い次元の空間に直しを限る」型で，MER-DA の E58 の U_A（ソース間の向きの散らばり）がこれに当たり，E_0 の 9.8〜12.2% しか捕らえなかった（`docs/exploratory-analyses.md:6363`）
- **音声と顔の結びつき**：Busso & Narayanan 2007（IEEE TASLP）は，文の単位で音響の特徴から顔の動きを予測する相関が 0.8 を超え，口の周りが最も強いと報告した（○．抄録）．音声と顔の共有の成分の多くは調音（話す内容に伴う口の動き）であることを示す記録で，発話の平均を取った MER-DA の特徴でどれだけ残るかは測っていない
- **感情認識の CCA**：Gajšek ほか 2010 は正準相関を部分空間どうしの角度として使うだけで，モダリティ間の CCA を少数ラベルの直しに使ってはいない（◎）．Nicolaou ほかの相関空間の回帰，ICCN（Sun ほか AAAI 2020）は融合の表現の学習である（△）
- **見つからなかったもの**：別のモダリティとの正準部分空間を，ソースで学んだ単一モダリティのアンカーの直しの空間として使い，K=0 と K ≥ 1 で比べた研究．ラベル付きの別コーパスで，その部分空間がアンカーの誤差とターゲットの最良の頭を含むかを測った研究（17 回の検索の範囲．付録 A）

### 3.2 主張ごとの判定

| 主張 | 判定 | 根拠 |
|---|---|---|
| C1 の 1（最良の頭は S に入る．次元は (C − 1) + r_u） | **既知** | Foster ほか 2008 の定理 3（隠れた状態 H．回帰），Ando & Zhang 2007 の定理 1（多クラス），Chaudhuri ほか 2009 の補題 1（ガウスの混合で平均の空間），Lee ほか 2021 の仮定 4.1 と定理 4.2（分類，潜在変数）．等しい共分散のガウスでは最良の判別の向き（LDA）と最小 2 乗の向きの張る空間が一致するので，回帰の定理から分類の主張が出る（教科書の事実） |
| C1 の 1 の階数の条件（ふるいの指摘） | **既知の仮定** | Foster ほか 2008 の仮定 1，Chaudhuri ほか 2009 の仮定 2，Lee ほか 2021 の仮定 4.1．案に書くべき条件で，新しい発見ではない |
| C1 の 2（話者の平均を引くと r_u が下がる） | **部分的に既知** | 計算は部分正準相関（話者を共変量とする）．話者で決まる成分が消えることは代数の帰結．実データで r_u がどれだけ下がるかは見つからない |
| C1 の 3（K ≥ 1：誤差 ((C − 1) + r_u)/K） | **既知** | Foster ほか 2008 のアルゴリズム 1，Lee ほか 2021 の注意 4.1（σ² km/n₂） |
| C1 の 3（K=0：アンカーの射影で誤差は増えない） | **部分的に既知** | θ\* ∈ S のときの計量の直交射影の性質（1 行の系）．ターゲットのラベル無しの CCA の部分空間でソースの予測を移す手続きは Blitzer ほか 2009／2011．アンカーを射影する形と，その 2 次の局所版は見つからない |
| C2（cca_w の capx が PCA を上回る） | **見つからない** | MER-DA の物差しでの測定で，先行研究に同じ量は無い．ただし 4.1 節のとおり，C2 は C1 を確かめる量ではない |
| C3（正準相関の落ち方で仮定の成否を判定する） | **部分的に既知** | 0 でない正準相関の本数の検定は Bartlett（1941）以来の古典．「落ち方が誤差を含むかを予言する」は見つからないが，群が 6・4 個では関係を示せない |
| C4（cca_w の中でアンカーを直す学習器） | **見つからない（組み合わせとして）** | 部品はすべて既知（CCA の部分空間の回帰，CCA の DA，アンカーへの L2 罰則，別のモダリティの疑似ラベル）．組み合わせは見つからない |

**新しさのまとめ**：案が新しさの候補に挙げた 3 つ（`案_L1.md` 2.5 節の末尾）のうち，(a)「K=0 の射影と K ≥ 1 の学び直しを同じ定理から出す」は既知の定理の系で，新しさとして主張できない．(b)「r_u を話者の中で測り，仮定の成否をラベル無しで判定する」は計算が古典の手続き（部分正準相関，正準相関の本数の検定）で，新しさは小さい．(c)「Ha & Chen の部分空間の仮定が，共分散の差では成り立たず，モダリティ間の共分散では成り立つかを同じ物差しで示す」は見つからず，残る新しさの中心になる．ただし (c) は 4.1 節と 4.3 節の直しを入れないと，結果が出ても何を示したかが曖昧になる．

## 4. 理論の検討（本査読が見つけた設計の穴）

### 4.1 P2-1 は C1 を確かめない（最も重い指摘）

C1 の 1 が述べるのは θ\* ∈ S である．E74 の capx(e, S) が測るのは，誤差 e = θ − θ\* のうち S の中だけで直せる割合である．2 つは別の量で，C1 から capx(e, S) の大きさは出ない．

- θ\* ∈ S が正しいとする．アンカー a0 を損失の計量 F で S に射影した P a0 の誤差は P a0 − θ\* = P e0 で，その大きさの 2 乗は cap(e0, S) × ‖e0‖²_F である．射影で減る損失は (1 − cap(e0, S)) × ‖e0‖²_F / 2 で，**capx が小さいほど K=0 の射影の得は大きい**．射影の後に S の中で K 本で直せば，原理的には誤差は全部直る
- 逆に capx(e, S) が大きいことが K ≥ 1 の利点になるのは，射影をせずにアンカーから S の中だけで直す場合（Ha & Chen の見方）である．このとき θ\* ∈ S は要らない
- したがって，案の C1（定理）と C2（測定）と C4（手法）は別々の仮定に立っている．C1 を確かめるには θ\* を S が含む割合を測る必要があり，C4 の K=0 の手続きを確かめるには射影の損得を測る必要がある

**直し**：1 段で次の 3 つを分けて測る（どれも仮のターゲットのラベルを使い，E74 と同じ反復と群の単位）．
- Q1（C1 の結論）：候補の全部のラベルで，頭を S_r（と切片）に限って解いた θ\*_S の，θ\* に対する損失の増え方と UAR の差．S が θ\* を含めば両方とも 0 に近い
- Q2（K=0 の手続き）：ラベル無しで決まる計量（候補の共分散 Σ_ss）で a0 と θ_Q を S_r に射影した頭の，損失と UAR の変化
- Q3（Ha & Chen の見方）：E74 と同じ capx(e0, S_r)，capx(e_Q, S_r)

### 4.2 階数の条件は既知の仮定として書き，測る

Foster ほか 2008 の仮定 1（Lee ほか 2021 の仮定 4.1）は，隠れた状態のすべての向きが両方の視点から予測できることを求める．感情については，生徒のモダリティ s で分けられる感情の対比（例：怒りと悲しみ）が，別のモダリティ t でも分けられることを求める．t で分けられない対比の向きは S に入らない．

- MER-DA の記録では，各モダリティの出発点は 4 感情の UAR が偶然の 25% を大きく上回る（AV の E39：音声 52.58，映像 49.59．`docs/exploratory-analyses.md:6586` の表）ので，どの対比も 0 ではない見込みである．問題は 0 か否かではなく大きさで，Chaudhuri ほか 2009 の λ_min（最小の 0 でない正準相関）が小さいと，感情の向きが話者や内容の共有の成分より下の順位に並び，r=16 の S に入らない
- **測り方**（仮のターゲットのラベルを使う）：t の特徴から 3 つの感情の対比（one-hot から感情の平均を除いたもの）を回帰したときの決定係数を対比ごとに出し，最小の値を群ごとに記録する．この値が小さい群では Q1 も小さいと予言できる．計算の前に書く予言として使える

### 4.3 capx の物差しは分散の大きい向きを有利にする

- F は候補の上の交差エントロピーの 2 階微分で，特徴の共分散を予測の確率で重みづけた形をしている．分散の大きい向きほど F が大きく，capx に効く．E74 で，でたらめな 16 本の向きが音声で 0.205，顔で 0.363 を捕らえる（16/1024 = 0.016 や 16/512 = 0.031 の 10 倍以上）のは，F の実効の次元が小さいためである（E58 の z の実効次元は音声 40，顔 36．`docs/exploratory-analyses.md:6353`）
- θ\* は候補の全部のラベルで 0 に向けた罰則つきで解いた頭である（`exp/explore_view_fusion.py:121〜128`．C′ は話者の半分で選ぶ．E58 では平均 0.03〜0.07）．罰則は分散の小さい向きの重みを小さくするので，θ\* 自身が分散の大きい向きに寄る
- 本査読の計算（`e74_groups.csv` の群の値）：r=16 の PCA の並びで，capx(e_Q) − capx(θ\* の揺れ) の群の中央値は，音声 0.057，顔 0.027，言葉 0.202 である．音声と顔では 6 群のうち 4 群（AFEW，CREMA-D，IEMOCAP の 2 群）で差が −0.26〜+0.10 にとどまり，PCA の並びが e_Q を捕らえる割合は，θ\* の推定の揺れを捕らえる割合と区別できない．差が大きいのは MELD と MOSEI（音声 0.29・0.42，顔 0.51・0.39）だけである
- CCA は尺度によらない手続きなので，正則化が弱いと分散の小さい向きを選びうる．F で測る capx ではその向きは不利になり，S が正しく θ\* を含んでいても capx が PCA を下回ることがありうる．逆に正則化を強くすると，CCA は Σ_st の特異値分解（PLS）に近づき，分散の大きい共有の向きを選ぶので PCA に近づく．**CCA が PCA を上回るかどうかは正則化の選び方でかなり決まる**

**直し**：
- CCA の正則化の強さ κ（と，前処理で主成分の数を切るならその数）を，ラベルを使わずに計算の前に決める．例：候補を話者で 2 つに分け，片方で求めた先頭 r 本の正準方向の，もう片方での正準相関の和が最大になる κ を選ぶ
- capx は θ\* の揺れの capx を引いた値でも出す（PCA・cca・cca_w・でたらめで同じ扱い）
- 主成分で前処理した場合，cca の r 本は先頭 p 本の主成分の中に入るので，capx(cca_r) ≤ capx(pca_p) になる．p を書き，pca_p の値を上限として並べる
- Q1 と Q2 は UAR でも判定する（E74 の A2 で，損失の得は群の中で UAR の得の順位を予言しなかった．順位相関の中央値 −0.37〜0.28．`checks/E74/results_draft.md:14,50`）

### 4.4 アンカーつきの学習器では「d/K から r/K へ」の話がそのままは当てはまらない

Foster ほか 2008 と Lee ほか 2021 の「要るラベルが次元に比例する」は，罰則の無い（または弱い）最小 2 乗の分散の話である．MER-DA の生徒はアンカーへの強い L2 罰則で解く学習器で，次の記録がある．
- 直し W − W_0 の各行は，ラベルを付けた発話の z が張る高々 4K 次元の空間に入る（E58 の命題 1．`docs/exploratory-analyses.md:6315` 付近）．K=5 の 20 本で動く長さは E_0 の 8〜10% で，罰則の強さ C′ が決める（同 6393 行）
- 学び直しで残る動きは (P + H)⁻¹ P Δa で，誤差 1〜2% で説明できる（E69．同 7235 行）

この学習器で S に限ることの効果は，「分散が d/K から r/K に下がる」ではなく，「K 本の張る空間のうち S の外の成分への動きを止める」ことである．E58 では，ランダムな 20 本の直しの向きと E_0 の cos は音声 0.17，映像 0.20，言葉 0.13 だった（同 6369〜6375 行の表）．S に射影した直し P_S ΔW と E_0 の cos が上がるかは，学習なしで既存の量から計算できる．案の P2-5（q_S ÷ q）はターゲットだけの学習曲線（アンカー無し）で測るので，Foster ほか 2008 の定理の確かめにはなるが，C4 の学習器の利点の確かめにはならない．

## 7. 研究価値

### 7.1 (a) 誰のどの判断が変わるか

- **実務者**：学習のときだけ複数のモダリティがあり，運用は音声だけの場面で，新しいコーパスのラベル無しの映像も集めるべきか（部分空間を作るため）．この判断が変わるのは結果が正のときだけである

### 7.2 (b) 査読者の最も強い反論と答え

**反論**：「C1 は Foster, Kakade, Zhang 2008 の定理 3 と Lee ほか 2021 の定理 4.2 の系であり，CCA の部分空間を DA に使うことは Blitzer ほか 2009／2011 にある．しかも著者自身の E58 で，ラベル無しの部分空間（主成分）に直しを限っても UAR は上がらなかった．CCA にしても，主成分と同じく損失の計量の形を測っているだけではないか」

**今ある記録で答えられる部分**：主成分の部分空間が θ\* の揺れと同じ程度にしか e_Q を捕らえないこと（4.3 節）は，今ある E74 の値で示せる．これは「CCA は主成分と同じものを測っている」という反論に対して，比べる基準をどう置くべきかの根拠になる．

**計画した実験でしか答えられない部分**：(1) cca_w が θ\* と誤差を，主成分と θ\* の揺れの基準を超えて含むか（Q1・Q3），(2) 射影と S に限った直しが E58 の主成分の確かめ（−0.4〜+0.2）を超えて UAR を上げるか（Q2 と 2 段）．定理の新しさの反論には，案を定理でなく「既知の定理の仮定を，ソースで学んだアンカーの誤差について実データで測る」主張に書き直して答える．提案の答え (a)〜(c) は，(a) が既知の系なので，そのままでは答えにならない．

### 7.3 (c) 予言が外れた場合に残るもの

- Q1 も Q2 も否：「別のモダリティとの共分散の部分空間は，同じ次元の主成分の部分空間より θ\* とアンカーの誤差を多くは含まない」という否定の記録が残る．E58 の結論（同じモダリティのラベル無しの情報）を別のモダリティの構造まで広げ，論文の糸 3 と問い 4〜6 の「ソースの情報を向きに流し込む道は疑似ラベル」の根拠を強める．論文の 1 段落と 1 つの表になる．単独の論文にはならない
- Q1 が可で Q2 と 2 段が否：S は θ\* を含むが，アンカーつきの学習器ではその知識が UAR に移らないことになる．4.4 節の読み（学習器の罰則が動きを止めている）を確かめる次の問いが残る
- 話者の平均を引く効果（cca_w と cca の差）は，結果の向きによらず記述として残る

## 9. 合格に要る直し（直した案の骨子）

**直し 1：定理を新しさから外す．**C1 は「Foster ほか 2008 の定理 3 と Lee ほか 2021 の定理 4.2 の仮定のもとで成り立つ既知の事実」として書き，階数の条件（Foster ほか 2008 の仮定 1，Chaudhuri ほか 2009 の仮定 2）を明記する．新しさは「その仮定が，コーパス間で学んだアンカーの誤差について実データで成り立つかを測ること」と「成り立つときの手続き」に置く．

**直し 2：1 段の判定を 3 つの量に分ける（4.1 節）．**
- Q1：S_r に限って全ラベルで解いた頭の，θ\* に対する損失の増え方と UAR の差（C1 の結論そのもの）
- Q2：a0 と θ_Q を Σ_ss の計量で S_r に射影した頭の，損失と UAR の変化（K=0 の手続き．ラベル無しで実行できる）
- Q3：capx(e0, S_r)，capx(e_Q, S_r)（Ha & Chen の見方．E74 と同じ）
- 補助：別のモダリティの特徴から 3 つの感情の対比を回帰した決定係数の最小値（階数の条件．4.2 節），射影した K=5 の直しと E_0 の cos（4.4 節）

**直し 3：比べ方を計算の前に固定する（4.3 節）．**
- CCA の正則化 κ と前処理の主成分の数 p は，候補を話者で 2 つに分けた正準相関の再現で，ラベルを使わずに決める
- 比べる並びは cca_w，cca，pca，shift，でたらめで，r ∈ {4, 16, 64} をすべて出す．判定は同じ r の pca との差で行い，θ\* の揺れの capx を引いた値も並べる．p 本で前処理したときは pca_p を上限として書く
- 基準は E74 の群の値から現実的な大きさにする．例：「Q1 の UAR の差が，同じ r の pca の Q1 より群の中央値で 1 ポイント以上小さい（S が θ\* をよりよく含む）生徒が 3 つのうち 2 つ以上」「Q2 の UAR の変化が群の中央値で 0 以上」．数値は関門 1 の前に研究者と決める

**直し 4：E58 の確かめを比べる相手に入れる．**2 段（とその前の 1 段の小さな版）で，K=5 の直しを cca_w の S_r に限った学習器を，同じ r の pca に限った学習器（E58 の確かめの形）と制限なしの E39 と比べる．E58 の値（UAR −0.4〜+0.2）は反復 0・1 の結果を見た後の探索なので，同じ反復 0〜4 で pca 版を測り直して基準にする．

**直し 5：話者の除き方を群ごとに決める．**IEMOCAP の 2 群，CREMA-D，MELD は話者の平均を引く（5 節の表）．AFEW は話者の平均を引かない版（cca）だけで判定し，cca_w は記述にする．MOSEI は両方を出す．仮のターゲットで「感情のラベルの分散のうち話者の間にある割合」を数えるなら，先に `docs/seen-data.md` に書く．

**直し 6：数値の誤りを直す．**ふるいの報告と案の「MELD は話者ごとの発話が少なく話者の中の共分散が安定しない」は，94% の発話が 10 本以上の話者に属するので当たらない（5 節）．Yeh ほか 2014 の書誌は IEEE TIP 23(5):2009–2018 である（PDF の頁の頭．ふるいの 23:3369–3383 は別の記録と食い違う．引用の前に IEEE Xplore で確かめる）．

**直した案の骨子**：
- 題：別のモダリティとの正準部分空間は，コーパス間で学んだ単一モダリティの頭の誤差を含むか――多視点の理論の仮定の実データでの測定と，K=0 と K ≥ 1 の手続き
- 問い：ターゲットのラベル無しの対の発話から（話者を除いて）求めた正準部分空間は，(1) ターゲットの最良の頭を，同じ次元の主成分の部分空間より多く含むか，(2) そこへのアンカーの射影は UAR を上げるか，(3) そこに限った K 本の直しは，主成分に限った直しと制限なしの直しを上回るか
- 予言：計算の前に，Q1〜Q3 と階数の条件の補助の量の向きと基準を書く．階数の条件の決定係数が小さい群では Q1 も小さいと予言する
- 外れたとき：否定の記録として，論文の糸 3 の範囲を別のモダリティの構造まで広げる

## 10. 新しさが残る最小の主張

- **M1（測定．条件：直し 2・3 の比べ方で測ったとき）**：話者の平均を引いた別のモダリティとの正準部分空間が，コーパス間で学んだ単一モダリティのアンカーの誤差（e0，e_Q）とターゲットの最良の頭 θ\* をどれだけ含むかを，損失の 2 階微分の計量と UAR の両方で，主成分・共分散の差・でたらめな方向と同じ次元で比べた．多視点の CCA の理論（Foster ほか 2008，Lee ほか 2021）の仮定を，ソースで学んだ出発点の誤差について，ラベル付きの別のコーパスで測った研究は見つからなかった．結果が正でも負でも主張になるが，負のときは「別のモダリティの構造でも向きは分からない」という範囲の主張になる
- **M2（手続き．条件：Q2 と 2 段で UAR の得が出たとき）**：アンカーを別のモダリティとの正準部分空間に射影し（K=0），その部分空間の中で K 本と疑似ラベルで直す（K ≥ 1）手続きは，同じ次元の主成分に限った版と E39 を K ≤ 5 で上回る．部品は既知（Blitzer ほか 2009 の CCA による DA，アンカーへの L2，別のモダリティの疑似ラベル）で，新しさは組み合わせと，主成分に限った版を比べる相手にした検証にある
- **M3（記述．条件：M1 を測ったとき）**：話者を共変量として除くと（部分正準相関），正準部分空間がアンカーの誤差を含む割合がどれだけ変わるか．計算は既知で，新しさは小さい．単独では主張にしない
