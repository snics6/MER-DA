### このノートの語

- **蒸留元のモデル**（論文の語で teacher）：予測を学習の目標として渡すモデル．
- **蒸留先のモデル**（論文の語で student）：その予測を目標にして学ぶモデル．
- 以下では「蒸留元」「蒸留先」と書き，それぞれがどの入力を見て，どの学習データでどの損失を最小にするかを各論文の項に書く．
- **ソフトターゲット**（soft target）：正解の 1 クラスだけを 1 とするラベル（ハードラベル）の代わりに，各クラスの確率を並べた学習の目標．
- **ロジット**（logit）：ソフトマックス（点数を足して 1 になる確率に直す関数）に入れる前の，クラスごとの点数．
- **温度 T**：softmax(z / T) の T．T を大きくすると，確率の分布が平らになる．
- **交差エントロピー** CE(p, q) = − Σ_k p_k log q_k．**KL ダイバージェンス** KL(p ‖ q) = Σ_k p_k log(p_k / q_k)．どちらも 2 つの分布の違いを測る量で，KL は p = q のとき 0 になる．
- **疑似ラベル**：ラベル無しのデータに，モデルの予測から付けたラベル．
- **蒸留用のデータ**（論文の語で transfer set）：蒸留先の学習に使う入力の集まり．ラベルが無くてもよい．
- **自己蒸留**（self-distillation）：蒸留元と蒸留先が同じ構造のモデルである蒸留．

### 「MER-DA との接点」で前提にした設定

4 コーパス（AFEW，IEMOCAP 即興，MOSEI，MELD）の 1 つをターゲット，残り 3 つをソースにする leave-one-corpus-out である．凍結したエンコーダの特徴（音声 WavLM 1024 次元，顔 ResNet-50 512 次元，言葉 RoBERTa 768 次元）の上に，線形のソフトマックスの分類器を学ぶ．分類器は単独のモダリティ 3 つと，3 つの特徴をつないだ融合の 1 つである．ターゲットのラベルは感情ごとに K 本（K = 0, 1, 5, 10, 25）で，ラベル無しのターゲットの発話も使える．感情は 4 つで，指標は UAR（感情ごとの再現率の平均）である．
提案は，単独の分類器の確率の積で作った疑似ラベルと K 本のラベルで各モダリティの分類器を学ぶ．損失は「K 本の交差エントロピー」＋「感情の数を釣り合わせた軟らかい疑似ラベルの交差エントロピー」＋「ソースの分類器の平均への L2 の引き戻し」である．単独の分類器は伸びるが，融合の分類器の改善は小さい．
各論文の「MER-DA との接点」は，この設定に当てはめたこちらの推測であり，どれも検定していない．

## 1. 分野の流れ

**2006 年：モデルの関数を別のモデルに写す．** Bucilă，Caruana，Niculescu-Mizil は，大きなアンサンブル（複数のモデルの予測を平均する方法）の予測をラベル無しのデータに付け，その予測を目標にして小さいニューラルネットを学んだ．この論文が，「正解のラベルの代わりに別のモデルの予測で学ぶ」という蒸留の基本の形を作った．ラベル無しのデータが足りないときのために人工データの作り方も提案しており，蒸留用のデータの質が結果を左右するという論点もここで始まった．

**2009 年：学習のときだけ使える情報．** Vapnik と Vashist は，学習のときにだけ使える追加の情報（特権情報．論文の語で privileged information）を使って学ぶ枠組み LUPI と，それを SVM に入れた SVM+ を提案した．この系統は蒸留とは別に始まったが，2016 年に Lopez-Paz らが蒸留と同じ枠組みにまとめた．

**2014〜2015 年：ロジットと温度．** Ba と Caruana は，深いネットのロジットを浅いネットに二乗誤差で写すと，浅いネットが深いネットに近い成績になることを示した．Hinton，Vinyals，Dean は，ソフトマックスに温度 T を入れて確率を平らにし，その確率を目標にする方法を「蒸留」と名づけた．温度が高い極限ではロジットの二乗誤差に一致すると示し，Ba と Caruana の方法を特別な場合として含めた．Hinton らは，学習データの 3% だけで学ぶときも，全データで学んだモデルのソフトターゲットを目標にすれば成績がほぼ保たれることを示し，ソフトターゲットが過学習を抑えるという見方を出した．

**2015〜2020 年：出力以外を写す．** Romero らの FitNets は，蒸留元の中間層の出力を蒸留先の中間層に回帰させた．Zagoruyko と Komodakis は，中間層の活性の空間的な強さの地図（attention map）を写した．Tian らの CRD は，蒸留元と蒸留先の表現の相互情報量（一方を知るともう一方がどれだけ分かるかの量）の下界を対照学習で大きくした．この系統はエンコーダを学ぶ設定の話である．

**2016 年：モダリティをまたぐ．** Gupta，Hoffman，Malik は，ラベルの多い RGB 画像のネットの中間層を，対になる深度画像のネットに写した．Aytar らの SoundNet は，画像の分類器の予測を，同じ動画の音のネットに KL で写した．Hoffman らは，学習のときだけ深度画像を使い，RGB 画像から深度のネットの中間層を再現するネットを学んだ．同じ年に Lopez-Paz らが蒸留と特権情報を「一般化蒸留」としてまとめ，別のモダリティの入力を特権情報と見る見方を示した．

**2017〜2018 年：蒸留先が蒸留元を超える．** Li，Seltzer らは，同じ発話を雑音のない条件と雑音のある条件で対にしたデータを使い，ソースのドメインの音響モデルの予測を目標にして，ターゲットのドメインの音響モデルを書き起こし無しで学んだ．Furlanello らの Born-Again Networks は，蒸留元と同じ構造の蒸留先が蒸留元より正確になることを示した．Zhang らの Deep Mutual Learning は，学習済みの蒸留元を置かずに，複数のネットが互いの予測をまねると全部のネットが良くなることを示した．同じ年に Albanie らが，顔の表情のモデルの予測で音声の感情のモデルを学んだ．これらの研究から，蒸留は小さくする手段から，同じ大きさのまま成績を上げる手段にも広がった．

**2019〜2020 年：何が伝わるのかを問う．** Müller，Kornblith，Hinton は，ラベル平滑化（正解のラベルに一様分布を少し混ぜる正則化）で学んだ蒸留元は，正解率が高くても蒸留先を良くしないことを示し，クラスどうしの似かたの情報が消えるためだと説明した．Cho と Hariharan は，大きく正確な蒸留元ほど良い蒸留元になるとは限らないことを示した．Yuan らは，正解率の低い蒸留元でも蒸留先を良くすることを示し，蒸留をラベル平滑化の一種と見る説明を出した．理論では，Phuong と Lampert が線形の分類器で蒸留の収束を解析し，Mobahi，Farajtabar，Bartlett が自己蒸留は正則化を強めることを示した．

**2020〜2021 年：疑似ラベルで同じ大きさか大きいモデルを学ぶ．** Xie らの Noisy Student は，ラベルで学んだモデルがラベル無しの画像に付けた疑似ラベルで，同じ大きさか大きいモデルを雑音を入れて学び，これを繰り返した．Pham らの Meta Pseudo Labels は，蒸留先がラベル付きのデータで出した成績を使って蒸留元も更新した．Menon らは，蒸留元の確率が本当のクラスの確率（ベイズ確率）に近いほど蒸留先の目的関数の分散が減るという統計の見方を示した．Stanton らは，蒸留先が蒸留元の予測にあまり一致しないこと，一致を高めても汎化が良くなるとは限らないことを示した．Jaritz らの xMUDA は，モダリティをまたぐまねをドメイン適応に使った．

**2022〜2023 年：一致のさせ方と理論．** Beyer らは，蒸留元と蒸留先に同じ入力を見せ，長く学ぶと蒸留がよく働くことを示した．Allen-Zhu と Li は，データが複数の「見方」を持つという構造のもとで，アンサンブルと蒸留と自己蒸留が成績を上げることを証明した．Nagarajan らは，蒸留先が蒸留元の確信度を誇張し，その誇張が汎化の改善と同時に起こることを示した．Xue らは，モダリティをまたぐ蒸留の成否を「両方のモダリティに共通してラベルを決める特徴の割合」で説明した．Du らは，融合のモデルの各モダリティの部分に単独のモデルの特徴を写す方法を示した．

**2023〜2026 年：小さいモデルの予測で大きいモデルを学ぶ．** Burns らは，小さい言語モデルが付けたラベルで大きい言語モデルを学ぶと，大きいモデルが小さいモデルを超えることを示し，weak-to-strong generalization と名づけた．Lang，Sontag，Vijayaraghavan と，Charikar，Pabbaraju，Shiragur がその理論を出した．Huo らの C2KD は，モダリティをまたぐ蒸留で普通の蒸留が成績を下げる例を示し，その原因をモダリティの間の差に求めた．2026 年に Li，Han，Yang，Tong は，ドメインのずれのもとで蒸留元の予測と正解のラベルを混ぜる最適な重みを線形回帰で閉じた形に出した．

### Bucilă, Caruana, Niculescu-Mizil 2006（KDD 2006．arXiv なし）Model Compression

- **問い**：数百〜数千の分類器を混ぜたアンサンブルは正確だが，大きくて遅い．その予測の関数を，小さく速いニューラルネットに写せるかを調べた．
- **方法**：アンサンブルにラベル無しのデータを通して予測を付け，その予測を目標にしてニューラルネットを学ぶ．ラベル無しのデータが無い分野のために，人工データの作り方 MUNGE（学習データの各例と最も近い例の間で属性の値を入れ替えたりずらしたりする方法）を提案した．
  ```
  1. 学習データ T（4,000 件）でアンサンブル A を学ぶ
  2. 人工データ D を MUNGE で作る（D の大きさは T の k 倍）
  3. D の各入力 x に A(x)（アンサンブルの予測）を付ける
  4. ニューラルネット g を，D の上で g(x) が A(x) に近づくように学ぶ
  評価：テストでの g(x) と 0/1 の正解の差の二乗平均の平方根（RMSE）
  ```
- **分かったこと**：
  - 8 つの 2 値分類問題の平均で，MUNGE のデータで学んだネットは，「元の 4,000 件だけで学んだネット」から「アンサンブル」までの改善のうち 97% を取り戻した（表 2 を説明する段落．RMSE の平均から計算した比）．比が 0.8 を下回ったのは ADULT だけだった．
  - ネットはアンサンブルより 1,000 倍以上小さかった（表 3 の説明）．
  - COVTYPE では，本当の分布から取ったラベル無しのデータは，MUNGE のデータより 2〜8 倍少ない量で同じ成績に達した（図 4 の説明）．
- **前提と限界**：著者は，ラベル無しのデータが大量にあることが前提であり，無い分野では人工データの質が成績を決めると書いた．ADULT で成績が上がらなかった理由について，著者は「名義属性の値の種類が多いこと」と「MUNGE の作るデータの質」の 2 つの可能性を挙げ，どちらかは決めていない．
- **MER-DA との接点**（推測．検定していない）：MER-DA のラベル無しのターゲットの発話は，この論文の「本当の分布から取ったラベル無しのデータ」にあたる．この論文が最も有利とした場合と同じ条件である．
- **確認の水準と出典**：◎．Crossref の記録（DOI 10.1145/1150402.1150464，pp. 535–541），本文は https://www.cs.cornell.edu/~caruana/compression.kdd06.pdf

### Ba, Caruana 2014（NeurIPS 2014．arXiv 1312.6184）Do Deep Nets Really Need to be Deep?

- **問い**：深いネットが浅いネットより正確なのは，深さが無いと表せない関数を学んでいるからか，それとも学習の手続きの違いのためかを調べた．
- **方法**：深いネット（またはそのアンサンブル）を正解のラベルで学び，そのロジットを目標にして，隠れ層が 1 層の浅いネット（SNN-MIMIC）を回帰で学ぶ（2.2 節，式 1）．
  ```
  L(W, β) = (1 / 2T) Σ_t ‖ g(x_t; W, β) − z_t ‖²₂
  g(x; W, β) = β f(W x)
  x_t：t 番目の入力，z_t：深いネットが x_t に出したロジット（ソフトマックスの前の値）
  f：隠れ層の活性化関数，T：データの数（ここでは温度ではない）
  ```
- **分かったこと**：
  - TIMIT の音素誤り率（表 1）：元のラベルで学んだ浅いネット SNN-8k は 23.1%，深い DNN は 21.9%，CNN は 19.5%，CNN 9 個のアンサンブルは 18.5% だった．アンサンブルのロジットで学んだ浅いネットは，SNN-MIMIC-8k で 21.6%，SNN-MIMIC-400k で 20.0% だった．
  - 損失として KL ダイバージェンスと確率の二乗誤差も試したが，ロジットの回帰が最も良かった（2.2 節）．
  - 元のラベルより蒸留元の予測で学ぶ方が良くなる理由として，著者は 3 つを挙げた（5.1 節）．(1) 蒸留元がラベルの誤りを取り除く．(2) 特徴から学びにくい領域で，蒸留元がより単純な目標を渡す．(3) 1 クラスだけが 1 のラベルより，各クラスの確率の方が情報が多い．著者はこれらを過学習を抑える正則化の一種と見ている．
- **前提と限界**：TIMIT には同じ分布のラベル無しのデータが無いため，著者は元の学習データで蒸留した．著者は，蒸留用のデータがラベル付きのデータよりずっと大きいときに蒸留が最もよく働くと書き，この条件を満たせないことが蒸留元と蒸留先の差を広げると述べた（3.2 節）．
- **MER-DA との接点**（推測．検定していない）：MER-DA は疑似ラベルの確率に対する交差エントロピーを使う．この論文の条件ではロジットの二乗誤差の方が良かったが，凍結した特徴の上の線形の分類器で両者を比べた結果は，この論文には無い．
- **確認の水準と出典**：◎．https://arxiv.org/abs/1312.6184 （本文の頭に "Draft for NIPS 2014"），NeurIPS の論文集の頁 https://papers.nips.cc/paper/5484-do-deep-nets-really-need-to-be-deep

### Hinton, Vinyals, Dean 2015（NIPS 2014 Deep Learning Workshop．arXiv 1503.02531）Distilling the Knowledge in a Neural Network

- **問い**：大きなモデルやアンサンブルが学んだことを，配備しやすい小さいモデルに移す一般的な方法を作る．
- **方法**：蒸留元のロジット v と蒸留先のロジット z を，同じ高い温度 T のソフトマックスで確率に直し，その間の交差エントロピーを最小にする．正解のラベルがあるときは，T = 1 での正解のラベルの交差エントロピーとの重み付きの和にする（2 節）．
  ```
  q_i = exp(z_i / T) / Σ_j exp(z_j / T)      （蒸留先の確率）
  p_i = exp(v_i / T) / Σ_j exp(v_j / T)      （蒸留元の確率）
  損失 = w_soft · T² · CE(p, q) + w_hard · CE(y, softmax(z))
  ∂CE(p, q)/∂z_i = (1/T)(q_i − p_i)
  T がロジットより十分大きく，ロジットの平均を 0 にそろえると
  ∂CE/∂z_i ≈ (1 / (N T²)) (z_i − v_i)      （N はクラスの数．式 4）
  ```
  ソフトターゲットの勾配の大きさは 1/T² に比例するので，T² を掛けてハードラベルとの釣り合いを保つ．
- **分かったこと**：
  - 温度が高い極限では，蒸留はロジットの二乗誤差の最小化に一致する（2.1 節，式 4）．Ba と Caruana の方法はこの特別な場合にあたる．
  - MNIST（3 節）：正則化を強くかけた大きなネットはテストで 67 個を誤り，正則化なしの小さいネットは 146 個を誤った．小さいネットに温度 20 で大きなネットのソフトターゲットを学ばせると 74 個になった．蒸留用のデータから数字の 3 を全部除くと，蒸留先は 206 個を誤り，そのうち 133 個がテストの 3（1,010 個）だった．3 のクラスのバイアスを 3.5 だけ上げると誤りは 109 個（うち 3 は 14 個）になった．著者は，誤りの多くは 3 のクラスのバイアスが低すぎることから来ると書いた．

- **前提と限界**：著者は，低い温度ではロジットの大きな負の値を無視することになり，それが雑音を除く利点にも情報を捨てる欠点にもなりうると書き，どちらが勝つかは実験で決める問題だとした（2.1 節）．蒸留先が蒸留元よりずっと小さいときは，中くらいの温度が最も良かった．
- **MER-DA との接点**（推測．検定していない）：数字の 3 を除いた実験は，蒸留先のクラスごとのバイアスが大きくずれうること，バイアスを動かすだけで大きく直ることを示す．MER-DA で疑似ラベルの感情ごとの総量をそろえる操作は，この「クラスのバイアスのずれ」を直す操作に近い．また，K 本の交差エントロピーと疑似ラベルの交差エントロピーの重みを比べるときは，温度を使うなら T² の掛け方に注意が要る．

### Romero, Ballas, Kahou, Chassang, Gatta, Bengio 2015（ICLR 2015．arXiv 1412.6550）FitNets: Hints for Thin Deep Nets

- **問い**：蒸留元より細く深いネット（FitNet）を，蒸留でうまく学ばせる方法を作る．
- **方法**：2 段で学ぶ．1 段目で，蒸留先の中間層（guided layer）の出力を小さな回帰器 r で変換し，蒸留元の中間層（hint layer）の出力に二乗誤差で近づける（式 3）．2 段目で，ネット全体を Hinton の蒸留で学ぶ．
  ```
  L_HT(W_Guided, W_r) = ½ ‖ u_h(x; W_Hint) − r(v_g(x; W_Guided); W_r) ‖²
  u_h：蒸留元の入力から hint layer までの関数
  v_g：蒸留先の入力から guided layer までの関数
  r：v_g の出力を u_h の出力の大きさに合わせる畳み込みの回帰器
  ```
- **分かったこと**：CIFAR-10（表 1）で，約 250 万個のパラメータの FitNet が 91.61%，約 900 万個のパラメータの蒸留元が 90.18% で，蒸留先が蒸留元を超えた．著者は，中間層を写す学習は Hinton の蒸留より強い正則化になると書いた（図 2 の説明）．
- **前提と限界**：著者は，guided layer を深くするほど蒸留先の自由度が減り，過剰に正則化されると書いた．そのため hint と guided layer を中間の層に置いた．

### Zagoruyko, Komodakis 2017（ICLR 2017．arXiv 1612.03928）Paying More Attention to Attention: Improving the Performance of Convolutional Neural Networks via Attention Transfer

- **問い**：畳み込みネットの中間層が「画像のどこに強く反応しているか」を，蒸留元から蒸留先へ移せば，蒸留先が良くなるかを調べた．
- **方法**：中間層の活性 A（チャンネル C 個 × 縦 × 横）から，チャンネル方向に絶対値の p 乗を足した空間の地図を作り，L2 で正規化してから蒸留元と蒸留先の差を罰する（式 2）．
  ```
  F(A) = Σ_{i=1..C} |A_i|^p                    （空間の地図．実験では p = 2）
  Q = vec(F(A))                                （地図を 1 列に並べたもの）
  L_AT = L(W_S, x) + (β/2) Σ_{j∈I} ‖ Q_S^j / ‖Q_S^j‖₂ − Q_T^j / ‖Q_T^j‖₂ ‖_p
  L：蒸留先の正解のラベルの交差エントロピー，I：地図を比べる層の組，β は 0.1 程度
  ```
- **分かったこと**：
  - CIFAR-10 の誤り率（表 1．5 回の中央値）：蒸留先 WRN-16-1，蒸留元 WRN-16-2 の組では，蒸留先だけで学ぶと 8.77%，この方法で 7.93%，Hinton の蒸留で 7.41%，両方で 7.51%，蒸留元は 6.31% だった．
  - ImageNet では，ResNet-34 を蒸留元にして ResNet-18 の top-1 正解率が 1.1 点上がった．著者は，同じ設定で Hinton の蒸留は正の結果を出せなかったと書いた（ImageNet の節．付録の表 5）．
- **前提と限界**：著者は，ImageNet の実験ではハイパーパラメータを調整する時間が無く，残差ブロックの 4 群のうち 2 群にしか損失を置いていないと書いた．
- **MER-DA との接点**（推測．検定していない）：空間の地図を持つ中間層を学ぶ設定の方法なので，凍結した特徴の上の線形の分類器には当てはまらない．

### Tian, Krishnan, Isola 2020（ICLR 2020．arXiv 1910.10699）Contrastive Representation Distillation

- **問い**：Hinton の蒸留の損失はクラスごとの項の和なので，出力の次元どうしの依存（構造）を写せない．表現の構造を写す損失を作る．
- **方法**：同じ入力に対する蒸留元の表現 T と蒸留先の表現 S の組を「正の組」，別の入力から取った組を「負の組」とし，組を見分ける関数 h を学びながら蒸留先を学ぶ．目的関数は，蒸留元と蒸留先の表現の相互情報量の下界を大きくする（式 17〜19）．
  ```
  max_{f_S} max_h  E_{正の組}[ log h(T, S) ] + N · E_{負の組}[ log(1 − h(T, S)) ]
  h(T, S) = exp(g_T(T)ᵀ g_S(S) / τ) / ( exp(g_T(T)ᵀ g_S(S) / τ) + N / M )
  g_T, g_S：表現を同じ次元に移して L2 で正規化する線形写像
  N：負の組の数，M：データの数，τ：温度
  ```
- **分かったこと**：CIFAR-100 で 12 の蒸留法と比べ，CRD は Hinton の蒸留より平均で相対 57% 良かった（1 節）．この「相対の改善」は，蒸留先のモデルごとの (CRD の正解率 − Hinton の蒸留の正解率) / (Hinton の蒸留の正解率 − 蒸留なしの正解率) の平均と定義されている（1 節の脚注）．著者は，Hinton の蒸留が 2 番目に良く，ほかの方法は単独では Hinton の蒸留をいつも上回るわけではなかったと書いた（表 1・表 2 の説明）．蒸留元と蒸留先の構造の型が違うとき，中間層を写す FitNets と注意の転移は蒸留なしの学習を下回った．
- **前提と限界**：負の組を多く取るほど下界が締まるので，著者は過去の表現を記憶する仕組みを使った（実装の段落）．
- **MER-DA との接点**（推測．検定していない）：表現を学ぶ設定の方法なので，凍結したエンコーダには当てはまらない．構造の型が違う組で中間層の模倣が成績を下げたという結果は，モダリティが違う組での模倣の難しさと同じ向きに読める．
- **確認の水準と出典**：◎．https://arxiv.org/abs/1910.10699 （arXiv のコメント欄：ICLR 2020）

### Vapnik, Vashist 2009（Neural Networks 22(5–6):544–557．arXiv なし）A New Learning Paradigm: Learning Using Privileged Information

- **問い**：学習のときにだけ使える追加の情報 x*（例：画像の診断を学ぶときの病理医の所見）を使って，テストでは x だけを見る分類器を速く学べるか．
- **方法**：SVM+．SVM の各例の「はみ出し量」（スラック変数．その例がどれだけ境界の内側に食い込んでいるか）を，特権情報 x* の関数 f*(x*) で表し，分類の関数 f(x) と同時に推定する．以下は同じ第一著者の 2015 年の論文（Vapnik, Izmailov, JMLR 16:2023–2049）の 3 節が Vapnik and Vashist（2009）の結果として書いた形である．
  ```
  最小化：Σ_i max{0, f*(x*_i, α*)}
  制約：y_i f(x_i, α) > − f*(x*_i, α*)     （i = 1, …, ℓ）
  結果（2015 年の論文の命題 2）：
    P(y f(x, α_ℓ) < 0) ≤ P(f*(x*, α*_ℓ) ≥ 0) + O*((h + h* − ln η) / ℓ)
  h, h*：f と f* の関数の集合の VC 次元，ℓ：学習データの数，確率 1 − η で成り立つ
  ```
- **分かったこと**：2015 年の論文の 3 節によると，VC 理論の誤差の上界は，データが分離できる場合は 1/ℓ の速さで，分離できない場合は 1/√ℓ の速さで縮む．はみ出し量を正しく教えられる場合（Oracle SVM）は，分離できない場合でも 1/ℓ の速さになる．SVM+ は，はみ出し量を特権情報の関数で近似してこの速さに近づける．
- **前提と限界**：2015 年の論文は，本当のはみ出し量は誰も知らないので，特権情報の空間で近似するしかないと書いた．2009 年の論文の本文は取得できず，実験の数値はこのノートに書いていない．
- **MER-DA との接点**（推測．検定していない）：配備で 1 つのモダリティだけを使うなら，ほかのモダリティは特権情報にあたる．SVM+ は特権情報を「例ごとの難しさ」の推定に使う．蒸留の確率を「各クラスの目標」ではなく「例ごとの重み」として使う読み方の原型にあたる．
- **確認の水準と出典**：○（2009 年の論文は Crossref の記録で書誌を確かめた．式は 2015 年の論文の本文で確かめた）．Crossref：DOI 10.1016/j.neunet.2009.06.042．2015 年の論文：https://jmlr.org/papers/volume16/vapnik15b/vapnik15b.pdf

### Lopez-Paz, Bottou, Schölkopf, Vapnik 2016（ICLR 2016．arXiv 1511.03643）Unifying Distillation and Privileged Information

- 蒸留と特権情報を「一般化蒸留」にまとめた．蒸留元 f_t を特権情報 x* で学び，温度 T の確率 s_i = softmax(f_t(x*_i)/T) を作り，蒸留先を通常の特徴 x で次の損失で学ぶ．

### Furlanello, Lipton, Tschannen, Itti, Anandkumar 2018（ICML 2018．arXiv 1805.04770）Born-Again Neural Networks

- **問い**：蒸留元と全く同じ構造の蒸留先を蒸留で学ぶと，蒸留元を超えるかを調べた．超えるなら，その得はどの成分から来るかを分ける．
- **方法**：蒸留元の出力との交差エントロピーで，同じ構造のネット（BAN）を学ぶ．これを世代ごとに繰り返し，各世代を平均したアンサンブルも作る．得の成分を分けるため，正解のクラスへの勾配を次のように分解した（式 7〜9）．
  ```
  1 つの例の勾配：∂L/∂z_i = q_i − p_i      （q：蒸留先の確率，p：蒸留元の確率）
  b 個の例の正解のクラス * の成分：(1/b) Σ_s (q_{*,s} − p_{*,s} y_{*,s})
    → 蒸留元の正解のクラスの確率 p_{*,s} が，例ごとの重みとして働く
  CWTM：正解のラベルの交差エントロピーを，蒸留元の最大の確率で例ごとに重み付けする
  DKPP：蒸留元の確率のうち，最大のクラス以外の値をクラスの間で入れ替えて使う
  ```
- **分かったこと**：CIFAR-100 の誤り率（表 2）で，DenseNet-112-33 の蒸留元は 18.25%，BAN は 16.95%，CWTM は 17.84%，DKPP は 17.84% だった．DenseNet-80-80 では 3 世代目の BAN が 15.5% だった（抄録と表 2）．CWTM と DKPP も蒸留元より良かったので，著者は，得の一部は例ごとの重みから，一部は正解以外のクラスの確率から来ると解釈した．CIFAR-10（表 1）でも，Wide-ResNet-28-10 と DenseNet-80-80，80-120 を除く組で BAN が蒸留元を下回る誤り率になった．
- **前提と限界**：著者は，言語モデル（PTB）では正解のラベルとの損失を併せたときにだけ BAN が働いたと書いた（表 6 の説明）．CIFAR-10 の大きなモデルでは，蒸留元を超えない組があった（表 1）．
- **MER-DA との接点**（推測．検定していない）：確率の積で作った疑似ラベルは，3 つの特徴をつないだ入力の上の線形のソフトマックスで書ける（3.5 節）．そのため，融合の線形の分類器と疑似ラベルの関数は同じ関数の集合に入り，この論文の「同じ構造の蒸留」に近い条件になる．ただし MER-DA の分類器は凸の問題を解くので，深いネットの学習の経路から来る得は起こりにくい可能性がある．
- **確認の水準と出典**：◎．https://arxiv.org/abs/1805.04770 （arXiv のコメント欄：Published @ICML 2018）

### Zhang, Xiang, Hospedales, Lu 2018（CVPR 2018．arXiv 1706.00384）Deep Mutual Learning

- **問い**：学習済みの強い蒸留元を用意しなくても，学習中の複数のネットが互いの予測をまねれば，全部のネットが良くなるかを調べた．
- **方法**：2 つのネットを同時に学び，各ネットは「正解のラベルの交差エントロピー」と「相手の予測との KL」の和を最小にする．K 個のネットでは，自分以外の予測との KL を平均する．
  ```
  L_Θ1 = L_C1 + KL(p₂ ‖ p₁)
  L_Θ2 = L_C2 + KL(p₁ ‖ p₂)
  L_C：正解のラベルの交差エントロピー，p₁, p₂：2 つのネットのクラスの確率
  ```
- **分かったこと**：CIFAR-100 の top-1 正解率（表 2）で，MobileNet 2 つの組は単独の 73.65% から 76.21% と 76.10% に上がった．WRN-28-10 と ResNet-32 の組では，大きい WRN-28-10 も 78.69% から 78.96% に上がり，ResNet-32 は 68.99% から 70.73% に上がった．同じ組で WRN-28-10 から ResNet-32 への一方向の蒸留は 69.48% で，相互の学習の 70.73% より低かった（表 4）．著者は，相手の予測をまねると各ネットの予測のエントロピーが上がり，より平らな最小点に達すると説明した（1 節）．
- **前提と限界**：K 個のネットの予測を平均して 1 つの目標にすると，目標が正解のクラスに尖り，エントロピーを上げるという狙いに反し，成績も下がったと著者は書いた（2.3 節．実験は 3.6 節）．
- **MER-DA との接点**（推測．検定していない）：MER-DA の提案は，単独の分類器の積から各モダリティの分類器への一方向の蒸留である．大きいネットが小さいネットとの相互の学習でも良くなったという結果は，融合の分類器が単独の分類器から得る可能性の先例として読める．
- **確認の水準と出典**：◎．https://arxiv.org/abs/1706.00384 ，CVF の頁 https://openaccess.thecvf.com/content_cvpr_2018/html/Zhang_Deep_Mutual_Learning_CVPR_2018_paper.html

### Müller, Kornblith, Hinton 2019（NeurIPS 2019．arXiv 1906.02629）When Does Label Smoothing Help?

- **問い**：ラベル平滑化（正解のラベルに一様分布を混ぜて学ぶ正則化）が成績と確率の較正（予測の確率が実際の正解率と合うこと）をなぜ良くするのか，蒸留とどう関わるのかを調べた．
- **方法**：ラベル平滑化の目標は次の式である．蒸留の実験では，ラベル平滑化で学んだ蒸留元と，ハードラベルで学んだ蒸留元を比べた（4 節）．
  ```
  y_k^LS = y_k (1 − α) + α / K        （K：クラスの数，α：平滑化の強さ）
  蒸留先の損失：(1 − β) H(y, p) + β H(p_t(T), p(T))     （実験は β = 1）
  ```
- **分かったこと**：
  - ラベル平滑化は，最後の層の手前の表現で同じクラスの例を密な塊に集め，塊どうしの距離をそろえる（Penultimate layer representations の節の可視化）．
  - MNIST（4 節）：ドロップアウトで学んだ蒸留元の誤り率は 0.67% で，そこから蒸留した蒸留先は 0.74% だった．ラベル平滑化で学んだ蒸留元は 0.59% と少し良かったが，蒸留先は 0.91% と悪かった．
  - CIFAR-10 で ResNet-56 から AlexNet へ蒸留すると，ラベル平滑化で正解率の上がった蒸留元から学んでも，蒸留先にラベル平滑化をかけて直接学ぶのと同じか悪かった（4 節）．著者は，ラベル平滑化が例ごとのロジットの違いの情報を "erase"（消す）するためだと説明し，入力とロジットの間の相互情報量の推定で示した（図 6）．
- **前提と限界**：著者は，ラベル平滑化と情報ボトルネックの原理の関係を今後の方向とした（結論）．

### Cho, Hariharan 2019（ICCV 2019．arXiv 1910.01348）On the Efficacy of Knowledge Distillation

- **問い**：正確な蒸留元ほど良い蒸留元になるのかを，蒸留元と蒸留先の構造を変えて調べた．
- **方法**：Hinton の蒸留（τ = 4，α = 0.9．著者は「よく使われる値は τ ∈ {3, 4, 5}，α = 0.9」と書いた．3 節）を，蒸留先を固定して蒸留元の大きさを変えながら行う．蒸留を学習の途中で止める方法（ESKD）も試した．
  ```
  L = α L_cls + (1 − α) L_KD                      （3 節の式をそのまま写した）
  L_KD = − τ² Σ_k p̃_t,k(x) log p̃_s,k(x)
  L_cls：正解のラベルの交差エントロピー
  p̃_t, p̃_s：温度 τ で平らにした蒸留元と蒸留先の確率
  ESKD：蒸留の項を学習の途中で外し，残りは正解のラベルだけで学ぶ
  ```
- **分かったこと**：
  - ImageNet の top-1 誤り率（表 1）：ResNet-18 を単独で学ぶと 30.24% だった．蒸留元を ResNet-18（誤り率 30.24%），ResNet-34（26.70%），ResNet-50（23.85%）と大きくすると，蒸留先の誤り率は 30.57%，30.79%，30.95% と悪くなった．
  - 著者は，大きい蒸留元の解が小さい蒸留先の関数の集合の中に無いこと（容量の不一致）が原因だとした（5.2 節）．蒸留を段階的に重ねる方法は，この問題を解かなかった．
  - ESKD では，表 3 の全部の蒸留先が単独の学習の 30.24% より良くなった．ただし，大きい蒸留元ほど良いという関係は ESKD でも現れなかった．
- **前提と限界**：著者は，ImageNet で蒸留先が学習の終わりに蒸留の損失と学習の損失の両方を下げられない「学び足りない状態」にあると推測した（5.2 節）．
- **MER-DA との接点**（推測．検定していない）：単独のモダリティの線形の分類器は，ほかのモダリティの特徴に依存する積の疑似ラベルを表せない．これはこの論文の「容量の不一致」に近い状況である．

### Yuan, Tay, Li, Wang, Feng 2020（CVPR 2020．arXiv 1909.11723）Revisiting Knowledge Distillation via Label Smoothing Regularization

- **問い**：蒸留の得は，蒸留元がクラスどうしの似かたを教えることから来ると言われる．それなら，正解率の低い蒸留元や，蒸留先より弱い蒸留元からは得が無いはずである．これを確かめた．
- **方法**：(1) 弱いモデルから強いモデルへの逆向きの蒸留（Re-KD）と，ほとんど学んでいない蒸留元からの蒸留（De-KD）を行った．(2) 蒸留の損失とラベル平滑化の損失を同じ形に書き直した．(3) 蒸留元を使わない蒸留（Tf-KD）を提案した．
  ```
  蒸留：L_KD = (1 − α) H(q, p) + α KL(p^t_τ, p_τ)
  ラベル平滑化：L_LS = (1 − α) H(q, p) + α KL(u, p)       （u：一様分布）
    → 蒸留は，一様分布 u を蒸留元の確率 p^t_τ に置き換えたラベル平滑化と同じ形
  Tf-KD_reg：L_reg = (1 − α) H(q, p) + α KL(p^d_τ, p_τ)
    p^d：正解のクラスに確率 a，残りのクラスに (1 − a)/(K − 1) を置いた手作りの分布
  q：正解のラベル，p：蒸留先の確率，τ：温度
  ```
- **分かったこと**：CIFAR-100（表 4）で，1 エポックだけ学んだ正解率 15.48% の ResNet-18 を蒸留元にすると，MobileNetV2 は 68.38% から 70.65%（+2.27）に，ShuffleNetV2 は 70.34% から 71.82%（+1.48）に上がった．著者は，蒸留の得は似かたの情報だけによらず，ソフトターゲットによる正則化が "equally or even more important" だと結論した（抄録）．
- **前提と限界**：著者は抄録で "not fully due to the similarity information" と書いており，似かたの情報が全く寄与しないとは主張していない．Tf-KD は，強い蒸留元を用意できない場合の代わりとして提案された（抄録）．
- **MER-DA との接点**（推測．検定していない）：この見方に立つと，MER-DA の単独の分類器の得の一部は，ほかのモダリティの情報ではなく，軟らかい目標による正則化から来ている可能性がある．MER-DA では，この 2 つを分ける比較をしていない．
- **確認の水準と出典**：◎．https://arxiv.org/abs/1909.11723 （arXiv のコメント欄：CVPR2020 Oral）

### Mobahi, Farajtabar, Bartlett 2020（NeurIPS 2020．arXiv 2002.05715）Self-Distillation Amplifies Regularization in Hilbert Space

- **問い**：自己蒸留では新しい情報が入らないのに，なぜテストの成績が上がるのかを理論で調べた．
- **方法**：ヒルベルト空間（カーネルで定まる関数の空間）での，L2 の正則化つきの回帰を考える．各回で，前の回のモデルの学習データ上の予測を新しい目標にして学び直す（正解のラベルは最初の回だけ使う）．
  ```
  学習データの入力のグラム行列 G = Vᵀ D V（D：固有値を並べた対角行列）
  t 回目の目標：y_t = Vᵀ D (c_{t−1} I + D)⁻¹ V y_{t−1}
  t 回目の解：f_t(x) = g_xᵀ Vᵀ D⁻¹ (Π_{i=0..t} A_i) V y_0，A_i = D (c_i I + D)⁻¹
  c_i：i 回目の正則化の強さ（学習の誤差の許容量から決まる）
  ```
  各回で，固有値 d_k の小さい方向の成分が d_k / (c + d_k) の割合で縮む．
- **分かったこと**：回を重ねると，解を表すのに使われる基底の関数の数が減り（疎になり），正則化が強まる（3 節）．そのため，数回の自己蒸留は過学習を減らしうるが，さらに重ねると学び足りなくなる（抄録）．回を重ねると，ある回で解がゼロの関数になる（著者の語で collapse）．CIFAR-10 と CIFAR-100 の ResNet と VGG で，学習データの正解率は回ごとに下がり，テストの正解率は初めに上がってから下がった（図 4 は二乗誤差，図 5 は交差エントロピー）．自己蒸留と早期終了は，正則化の働き方が違う（3.4 節，図 6）．
- **前提と限界**：理論は二乗誤差の回帰だけを扱う．交差エントロピーでは，同じ現象を実験で観察しただけである．
- **MER-DA との接点**（推測．検定していない）：MER-DA の L2 の引き戻しは明示の正則化で，疑似ラベルの目標は前の分類器の予測である．疑似ラベルを付けて学び直す回を重ねると，この論文の見方では正則化が回ごとに強まる．
- **確認の水準と出典**：◎．https://arxiv.org/abs/2002.05715 （本文の脚注に NeurIPS 2020）

### Stanton, Izmailov, Kirichenko, Alemi, Wilson 2021（NeurIPS 2021．arXiv 2106.05945）Does Knowledge Distillation Really Work?

- **問い**：蒸留先は本当に蒸留元の予測を写しているのかを，汎化の良さとは別に，一致の度合い（著者の語で fidelity）として測った．
- **方法**：一致の度合いを，テストでの top-1 の予測の一致率と，蒸留元の予測から蒸留先の予測への KL で測る．蒸留用のデータを増やす，データ拡張を変える，初期値を蒸留元に近づける，などの介入で一致がどう変わるかを調べた．
  ```
  平均 top-1 一致率 = (1/n) Σ_i 1[ argmax_j p̂_t(j | x_i) = argmax_j p̂_s(j | x_i) ]
  損失：KL(p̂_t ‖ p̂_s)      （p̂_t：蒸留元の確率，p̂_s：蒸留先の確率）
  ```
- **分かったこと**：
  - MNIST の LeNet-5 の自己蒸留では，蒸留用のデータを足すと一致率が 99% を超え，蒸留先と蒸留元の正解率の差は試行のばらつきの範囲だった（図 2）．
  - CIFAR-100 の ResNet-56 の自己蒸留では，GAN で作った画像を足しても一致率は 99% に遠く及ばなかった．蒸留用のデータが小さいときは蒸留先が蒸留元より正確で，一致を高めると蒸留先の汎化が悪くなった（図 1 と 4.1 節）．
  - ResNet-56 を 3 個合わせたアンサンブルを蒸留元にすると，一致の度合いと汎化が同じ向きに動いた（図 1(b)）．
  - 著者は，一致が低い主な原因を最適化の難しさに求めた．蒸留先の初期値を蒸留元の重みに十分近づけるとほぼ 100% 一致した（6 節）．
- **前提と限界**：著者は結論で，深い学習では最適化を厳密に解かなくても汎化するが，蒸留では一致の度合いが "an exceptionally difficult optimization problem" を解くことに直結すると書いた（7 節）．
- **MER-DA との接点**（推測．検定していない）：MER-DA の分類器は凸の損失の線形の分類器なので，この論文が指摘した最適化の難しさは小さいと考えられる．そのため，同じ関数の集合に入る疑似ラベルなら，蒸留先はそれをかなり正確に写す可能性が高い（3.5 節）．
- **確認の水準と出典**：◎．https://arxiv.org/abs/2106.05945 （arXiv のコメント欄：NeurIPS 2021）

- **問い**：大きな画像のモデルを ResNet-50 程度に小さくするとき，蒸留がうまくいくかを決める設計の選択を明らかにした．

  fixed teacher：蒸留元の予測を画像ごとに事前に計算して固定する

- **前提と限界**：著者は，新しい方法の提案ではなく，既存の手続きの暗黙の設計の選択を明らかにすることが目的だと書いた（抄録）．必要な計算量は大きい．

### Phuong, Lampert 2019（ICML 2019，PMLR 97．arXiv なし）Towards Understanding Knowledge Distillation

- **問い**：線形の分類器どうしの蒸留で，蒸留先が何に収束し，どれだけ速く蒸留元に近づくかを証明した．
- **方法**：蒸留元は固定した線形の分類器 h*(x) = 1{w*ᵀx ≥ 0} である．蒸留用のデータの各入力に軟らかいラベル y_i = σ(w*ᵀx_i)（σ はシグモイド関数）を付け，蒸留先 w を交差エントロピーの勾配降下法で学ぶ（式 1）．初期値は 0 である．
  ```
  L₁(w) = − (1/n) Σ_i [ y_i log σ(wᵀx_i) + (1 − y_i) log(1 − σ(wᵀx_i)) ] − L*
  定理 1：w(t) → ŵ，ŵ = w*（n ≥ d のとき），ŵ = X (XᵀX)⁻¹ Xᵀ w*（n < d のとき）
  リスク：R(h) = P[h(x) ≠ h*(x)]      （蒸留元との不一致の確率）
  定理 3：n ≥ d なら E[R(ĥ)] = 0．n < d なら任意の β ∈ [0, π/2] で
          E[R(ĥ)] ≤ p(β) + p(π/2 − β)^n
  p(θ)：入力と w* のなす角が θ 以上の確率に関する量，d：特徴の次元，n：蒸留用のデータの数
  ```
- **分かったこと**：データが特徴の次元 d 以上あれば，蒸留先は蒸留元の重みをそのまま取り戻す（定理 1）．クラスの間に余白がある分布では，n < d でも誤差が n について指数的に減る（定理 3 と系 1）．著者は蒸留の成否を決める 3 つの要因として，データの形（クラスの分かれ方），最適化の偏り（0 から始めた勾配降下法が良い解を選ぶこと），強い単調性（データを足すと蒸留先のリスクが必ず減ること）を挙げた．深い線形のネットでも同じ結果を出した（定理 2）．
- **前提と限界**：蒸留元と蒸留先が同じ入力を見る線形の分類器であることが前提で，リスクは正解との誤りではなく蒸留元との不一致である．著者は，非線形のモデルへの拡張を主な今後の方向とした（6 節）．
- **MER-DA との接点**（推測．検定していない）：単独の分類器の確率の積は，3 つの特徴をつないだ入力の上の線形のソフトマックスで書ける（3.5 節）．この論文の結果を多クラスに広げて当てはめると，融合の線形の分類器を疑似ラベルだけで学べば，ラベル無しの発話が特徴の次元（2,304）より多いときに，疑似ラベルの関数そのものに収束すると予想される．MER-DA の損失には K 本のラベルと L2 の引き戻しも入るので，この予想は近似である．
- **確認の水準と出典**：◎．https://proceedings.mlr.press/v97/phuong19a/phuong19a.pdf （本文の頭に PMLR 97, 2019）

### Menon, Rawat, Reddi, Kim, Kumar 2021（ICML 2021，PMLR 139:7632–7642．arXiv 2005.10419）A Statistical Perspective on Distillation

- **問い**：蒸留はなぜ蒸留先を良くするのかを，統計の見方で説明した．arXiv の版の題は "Why distillation helps: a statistical perspective" である．
- **方法**：蒸留元が本当のクラスの確率 p*(x)（ベイズ確率）を出す「ベイズの蒸留元」なら，蒸留の経験リスク（学習データでの損失の平均）は，ハードラベルの経験リスクと同じ期待値を持ち，分散は小さい（補題 1，3.1 節）．蒸留元の確率 p_t がベイズ確率からずれている場合については，偏りと分散の上界を出した（命題 3，式 7）．
  ```
  蒸留の経験リスク：R̃(f; S) = (1/N) Σ_n p_t(x_n)ᵀ ℓ(f(x_n))
  命題 3：E[(R̃(f; S) − R(f))²] ≤ (1/N) · V[p_t(x)ᵀ ℓ(f(x))] + O( (E‖p_t(x) − p*(x)‖₂)² )
  R(f)：本当のリスク，ℓ(f(x))：各クラスを正解としたときの損失を並べたベクトル
  N：データの数，V：分散
  ```
- **分かったこと**：良い蒸留元とは，正解率が高いモデルではなく，ベイズ確率に二乗誤差で近い確率を出すモデルである（4 節）．CIFAR-100 で深さの違う ResNet の蒸留元を比べると，蒸留元が深くなるとテストでの確率の推定が悪くなり，確率の推定が最も良い深さ 14 の蒸留元が最も正確な蒸留先を作った（図 1(a)，4.3 節）．
- **前提と限界**：ベイズ確率は観測できないので，蒸留元の確率がどれだけ近いかを直接は測れないと著者は書いた（4 節）．
- **MER-DA との接点**（推測．検定していない）：ソースで学んだ分類器の積は，コーパスのずれのために，ターゲットのベイズ確率から偏った確率を出す．命題 3 の見方では，疑似ラベルが蒸留先を良くするのは，分散の減り分が偏りの項より大きいときである．
- **確認の水準と出典**：◎（ICML の版の PDF を読んだ）．https://proceedings.mlr.press/v139/menon21a.html ，https://arxiv.org/abs/2005.10419

### Allen-Zhu, Li 2023（ICLR 2023．arXiv 2012.09816）Towards Understanding Ensemble, Knowledge Distillation and Self-Distillation in Deep Learning

- **問い**：同じ構造・同じデータで，初期値の乱数だけを変えて学んだネットのアンサンブルは，なぜ単独より正確なのか．その正確さはなぜ蒸留で 1 つのネットに移せるのか．

  ```
  w_{i,r} ← w_{i,r} − η ∇ L(F) − η' E_{(X,y)∼Z}[ (logit^τ_i(F, X) − logit^τ_i(G, X))⁻ ∇ F_i(X) ]
  logit^τ_i(F, X) = exp(min{τ² F_i(X), 1}/τ) / Σ_j exp(min{τ² F_j(X), 1}/τ)

  ```

  ```
  定理 4.1（非形式）：β_k(t)，β̃_k(t)：時刻 t の蒸留元と蒸留先の重みの，

  ```

### Xie, Luong, Hovy, Le 2020（CVPR 2020．arXiv 1911.04252）Self-training with Noisy Student Improves ImageNet Classification

- **問い**：ラベル付きのデータが多い ImageNet でも，ラベル無しの画像に付けた疑似ラベルで成績を上げられるか．
- **方法**：アルゴリズム 1．(1) ラベル付きの画像で蒸留元を学ぶ．(2) 雑音を入れない蒸留元で，ラベル無しの画像に軟らかいか硬い疑似ラベルを付ける．(3) 蒸留元と同じ大きさか大きいモデルを，雑音（RandAugment のデータ拡張，ドロップアウト，確率的深さ）を入れて，ラベル付きと疑似ラベル付きの両方で学ぶ．(4) 学んだモデルを蒸留元にして繰り返す．
  ```
  (1/n) Σ_{i=1..n} ℓ(y_i, f^noised(x_i, θ_s)) + (1/m) Σ_{i=1..m} ℓ(ỹ_i, f^noised(x̃_i, θ_s))
  ỹ_i = f(x̃_i, θ*_t)：雑音なしの蒸留元が付けた疑似ラベル
  n：ラベル付きの数，m：ラベル無しの数
  ```
  疑似ラベルは確信度 0.3 を超える画像だけを使い，クラスごとに枚数をそろえ，少ないクラスは画像を複製した（130M 枚のうち重複を除くと 81M 枚．3 節）．
- **分かったこと**：3 億枚のラベル無しの画像を使い，ImageNet の top-1 正解率 88.4% に達した（抄録）．雑音の除去実験（表 6．蒸留元は EfficientNet-B5，ラベル無しは 130M 枚）では，雑音を全部入れると 85.1%，データ拡張とドロップアウトと確率的深さを全部外すと 84.3% だった．著者が挙げた知見には，「蒸留先のモデルが大きいことが重要」「データの釣り合いは小さいモデルで役立つ」「軟らかい疑似ラベルは，分布の外のデータで硬い疑似ラベルより良い場合がある」がある（4 節の知見の一覧）．
- **前提と限界**：蒸留先に雑音を入れることと，蒸留先を蒸留元と同じかそれ以上の大きさにすることが前提である．
- **MER-DA との接点**（推測．検定していない）：MER-DA は凍結した特徴の上の線形の分類器なので，データ拡張とドロップアウトの雑音は入れていない．この論文の「クラスごとに疑似ラベルの量をそろえる」操作は，MER-DA の感情ごとの総量をそろえる操作と同じ目的を持つ．

### Pham, Dai, Xie, Le 2021（CVPR 2021，pp. 11557–11568．arXiv 2003.10580）Meta Pseudo Labels

- **問い**：疑似ラベルの手法では，蒸留元が誤った疑似ラベルを付けると蒸留先がその誤りを学び，蒸留元はそれを直せない（著者の語で confirmation bias）．蒸留先の成績を使って蒸留元を直せるか．
- **方法**：蒸留元と蒸留先を並行に学ぶ．蒸留先は蒸留元の疑似ラベルで 1 歩更新する．蒸留元は，その更新後の蒸留先がラベル付きのデータで出す損失を小さくするように更新する（式 1〜3）．
  ```
  蒸留先：θ'_S = θ_S − η_S ∇_{θ_S} L_u(θ_T, θ_S)
          L_u = E_{x_u}[ CE(T(x_u; θ_T), S(x_u; θ_S)) ]      （ラベル無しでの疑似ラベルの損失）
  蒸留元：min_{θ_T} L_l(θ_S − η_S ∇_{θ_S} L_u(θ_T, θ_S))     （ラベル付きでの蒸留先の損失）
  ```
- **分かったこと**：ImageNet をラベル付き，JFT-300M をラベル無しにして，EfficientNet-L2 の top-1 正解率 90.2% を出した（抄録）．小さい規模の比較（表 2）では，CIFAR-10 のラベル 4,000 枚で 96.11 ± 0.07%（FixMatch は 95.74 ± 0.05%），ImageNet のラベル 10% で top-1 73.89%（SimCLR は 71.7%）だった．ラベル無しのデータを使わずに正則化として使っても，CIFAR-10-4K で 83.71%（ラベルだけの学習は 82.14%，ラベル平滑化は 82.21%）だった（付録の表 9）．
- **前提と限界**：蒸留元と蒸留先を両方メモリに置く必要があり，大きいモデルでは 16 GB を超えたと著者は書いた（付録）．
- **MER-DA との接点**（推測．検定していない）：MER-DA の疑似ラベルの元の分類器は，ソースで学んだまま固定されている．この論文は，ターゲットの少数のラベルを疑似ラベルの元の更新に使う構造の先例にあたる．

### Burns, Izmailov, Kirchner, Baker, Gao, Aschenbrenner, Chen, Ecoffet, Joglekar, Leike, Sutskever, Wu 2024（ICML 2024，PMLR 235:4971–5012．arXiv 2312.09390）Weak-to-Strong Generalization: Eliciting Strong Capabilities With Weak Supervision

- **問い**：小さい言語モデル（論文の語で weak supervisor）が付けたラベルで大きい言語モデル（strong student）を学ぶと，大きいモデルは小さいモデルの誤りをまねるのか，それとも小さいモデルを超えるのか．
- **方法**：小さいモデルを正解のラベルで学び，その予測をラベルにして大きいモデルを学ぶ．正解のラベルで学んだ大きいモデルを上限にして，取り戻した差の割合 PGR（performance gap recovered）を測る（3 節）．補助の確信度の損失も提案した（4.3.2 節，付録 A.4 の式 1・2）．
  ```
  PGR = (小→大の成績 − 小の成績) / (大を正解のラベルで学んだ成績 − 小の成績)
  L_conf(f) = (1 − α) · CE(f(x), f_w(x)) + α · CE(f(x), f̂_t(x))
            = CE(f(x), (1 − α) · f_w(x) + α · f̂_t(x))
  f_w(x)：小さいモデルの予測，f(x)：大きいモデルの予測
  f̂_t(x) = 1[f(x) > t]：大きいモデル自身の予測を閾値 t で 0/1 にしたもの
  t はバッチの例のちょうど半分が f(x) > t になるように決める（ラベルの事前の分布を入れる釣り合いの仕組み）
  α は学習の最初の 20% で 0 から α_max（最大のモデルで 0.75，ほかで 0.5）まで上げる
  ```
- **分かったこと**：
  - NLP の課題で GPT-2 程度のモデルのラベルで GPT-4 を学ぶと，差のおよそ半分を取り戻した（1 節）．
  - 確信度の損失を足すと，最も小さいモデルから最も大きいモデルへの組で PGR の中央値がおよそ 25% から 80% 近くに上がった（4.3.2 節）．小さい蒸留先のモデルでは，この損失は素朴な方法より少し悪かった．小さいモデルと大きいモデルの差が小さい組でも，役立たないか悪くする場合があった．
  - チェスのパズルでは，同じ小さいモデルのラベルに対して，大きいモデルを大きくするほど PGR が下がった．ChatGPT の報酬モデルでは，取り戻せた差はおよそ 10% で，差が小さい組でも PGR がほとんど 20% を超えなかった（4.2 節）．
  - 線形の探り（凍結した表現の上のロジスティック回帰）の比較（図 11）：正解のラベルで学んだ線形の探りは平均 72%，正解のラベルで微調整すると 82% だった．小さいモデルのラベルで微調整してから正解のラベルで線形の探りを学ぶと 78% になった．
- **前提と限界**：著者は "None of our methods work consistently in all settings" と書いた（1 節）．大きいモデルが人の振る舞いをまねる表現を持つかどうかと，事前学習のデータに人の監督が含まれていることの 2 点を，本来の問題との違いとして挙げた（3 節の限界）．釣り合いの仕組みは，多くの組で小さいか中立の効果で，一部の設定でだけ大きく改善したと書いた（付録 A.4）．
- **MER-DA との接点**（推測．検定していない）：確信度の損失の釣り合いの仕組み（バッチの半分を正にそろえる）は，MER-DA で疑似ラベルの感情ごとの総量をそろえる操作と同じ目的を持つ．この損失は，蒸留先が疑似ラベルと違う予測を自信を持って出すことを許す．MER-DA の損失には，この働きを持つ項は無い．

### Lang, Sontag, Vijayaraghavan 2024（NeurIPS 2024．arXiv 2405.16043）Theoretical Analysis of Weak-to-Strong Generalization

- **問い**：疑似ラベルで学んだモデルが，疑似ラベルの誤りを直すこと（著者の語で pseudolabel correction）と，疑似ラベルが付かなかった例でも正しく予測すること（coverage expansion）を説明する理論を作る．
- **方法**：入力の近傍 N(x)（例：表現の空間で距離 r 以内の点）を決め，「拡張」（expansion）の条件を置く．大まかには，疑似ラベルの正しい例の大きな部分集合は，疑似ラベルの誤った例の近くにもたくさん近傍を持つ，という条件である．蒸留先がほとんどの点で近傍と同じ予測を出す（平均の意味で頑健）なら，疑似ラベルの誤りに合わせるには近傍で余分な誤りを払う必要が生じる．
  ```
  定義 3（(c, q)-拡張）：P(U | B) > q を満たす全ての U ⊂ B で P(N(U) | A) > c · P(U | B)
  定理 4.1（疑似ラベルの訂正）：
    err(f, y | S_i) ≤ (2α_i / (1 − 2α_i)) · P(f が頑健でない点 | S_i) + err(f, ỹ | S_i) + α_i (1 − (3/2) c)
  比べる自明な上界：err(f, y | S_i) ≤ err(f, ỹ | S_i) + α_i
  α_i：疑似ラベル ỹ の誤りの割合，err(f, y)：正解との誤り，err(f, ỹ)：疑似ラベルとの不一致
  ```
- **分かったこと**：拡張の強さ c が大きく，疑似ラベルとの不一致と頑健でない点の割合が小さいと，蒸留先の誤りは疑似ラベルの誤り α_i より小さくなる（定理 4.1 の説明）．疑似ラベルの付かない例の誤りの上界（定理 4.2）は，Blum と Mitchell の共訓練（2 つの見方の分類器が互いにラベルを付け合う手法）の結果を特別な場合として含む．著者は，拡張の条件を有限のデータから確かめる手続きを示し，実データで条件が成り立つ証拠を出した（5・6 節）．
- **前提と限界**：著者は，最も拡張しない集合を探す手続きはまだ発見的な方法であり，実験の範囲は限られ，新しい学習法は提案していないと書いた（限界と結論）．
- **MER-DA との接点**（推測．検定していない）：この理論の核は「蒸留先が疑似ラベルの誤りに合わせようとすると余分な誤りを払う」ことである．融合の線形の分類器は，単独の分類器の積の疑似ラベルの関数を正確に表せる（3.5 節）ので，その誤りにも余分な誤りなしに合わせられる．単独の分類器は，ほかのモダリティから来る誤りの部分を表せない．この違いは，「単独の分類器は伸びるが融合は伸びにくい」という観察と同じ向きである．
- **確認の水準と出典**：◎．https://arxiv.org/abs/2405.16043 ，NeurIPS の頁 https://neurips.cc/virtual/2024/poster/95840

### Charikar, Pabbaraju, Shiragur 2024（NeurIPS 2024．arXiv 2405.15116）Quantifying the Gain in Weak-to-Strong Generalization

- **問い**：小さいモデルのラベルで学んだ大きいモデルが，小さいモデルをどれだけ超えるかを量で表す．
- **方法**：回帰と二乗誤差の設定で，大きいモデルは凍結した表現 h_s の上で，凸集合 F_s（例：線形の関数の全体）から関数を選ぶ．小さいモデルの予測 f_w ∘ h_w に最も近い関数を選ぶ（式 1）．
  ```
  d_P(f, g) = E_{x∼P}[(f(x) − g(x))²]
  f_sw = argmin_{f ∈ F_s} d_P(f ∘ h_s, f_w ∘ h_w)
  定理 1（実現可能のとき）：f_s ∘ h_s = f* ∘ h* となる f_s ∈ F_s があれば
    d_P(f_sw ∘ h_s, f* ∘ h*) ≤ d_P(f_w ∘ h_w, f* ∘ h*) − d_P(f_sw ∘ h_s, f_w ∘ h_w)
  f* ∘ h*：本当の関数
  ```
  右辺の第 2 項（大きいモデルが小さいモデルのラベルに合わせきれない量）を，著者は misfit と呼ぶ．
- **分かったこと**：大きいモデルの誤りは，小さいモデルの誤りより少なくとも misfit だけ小さい（定理 1）．証明は，凸集合への射影のピタゴラスの不等式による．実現可能でない場合と有限の標本の場合も，小さな誤差の項を足して同じ形が成り立つ（定理 2）．著者は，misfit で得を予測し，複数の小さいモデルから選べると書いた（抄録）．
- **前提と限界**：著者は結論で，F_s が凸でないときには定理が当てはまらないこと，"Our work also does not address classification tasks" と書いた．付録 E では，分類でも得は misfit で特徴づけられると考えるが，追加の正則化の項などが要るとした．
- **MER-DA との接点**（推測．検定していない）：MER-DA の分類器は凍結した特徴の上の線形の関数なので，F_s が凸である条件は満たす（損失は交差エントロピーで，二乗誤差ではない）．融合の分類器では，積の疑似ラベルの関数が F_s に入るので misfit はほぼ 0 になり，定理 1 の見方では疑似ラベルを超える得はほぼ 0 である．単独の分類器では misfit は 0 にならないが，実現可能の条件（本当の関数を単独の特徴の線形の関数で表せること）は成り立たないと考えられる．

### Gupta, Hoffman, Malik 2016（CVPR 2016．arXiv 1507.00448）Cross Modal Distillation for Supervision Transfer

  ```
  KRC(f_T, f_S) = (2 / (C (C − 1))) Σ_{i<j} sign(f_T,i − f_T,j) · sign(f_S,i − f_S,j)
  η = 1（KRC(f_T, f_S) > ω のとき），η = 0（それ以外）    （例ごとの選別．式 3 とその下の式）
  f_T, f_S：蒸留元と蒸留先のロジット，C：クラスの数
  ```
- **分かったこと**：AVE と VGGSound（表 1）で，映像の蒸留元から音声の蒸留先への Hinton の蒸留は，AVE で 52.8% から 46.6% に，VGGSound で 59.4% から 56.3% に成績を下げた．音声の蒸留元から映像の蒸留先への蒸留は，AVE で 31.6% から 32.3% と少し上げた．この方法は AVE の音声で 54.9%，映像で 34.7% だった．
- **前提と限界**：蒸留元を蒸留と同時に更新するので，蒸留元を固定する設定とは違う．
- **MER-DA との接点**（推測．検定していない）：正解率の低いモダリティの蒸留元が，正解率の高いモダリティの蒸留先を下げるという結果は，MER-DA で「別のモダリティ 1 つだけの疑似ラベルは弱い」とした観察と同じ向きである．

- **MER-DA との接点**（推測．検定していない）：MER-DA の「K 本の交差エントロピー」と「疑似ラベルの交差エントロピー」の重みの比は，この論文の ξ にあたる．この論文では蒸留元と蒸留先が同じ入力を見て，蒸留元の予測をラベル付きの N2 本の上でだけ使う点が MER-DA と違う．

## 3. 分野で標準とされていることと，未解決とされていること

### 3.1 標準とされていること

1. **損失の形**：正解のラベルの交差エントロピーと，温度 T で平らにした蒸留元の確率との交差エントロピー（または KL）の重み付きの和を使い，蒸留の項に T² を掛ける（Hinton 2015 の 2 節）．Cho と Hariharan 2019 は，よく使われる値を τ ∈ {3, 4, 5}，α = 0.9 と書いた（3 節）．一般化蒸留の λ（Lopez-Paz 2016）も同じ重みである．
2. **ラベルが少なくラベル無しのデータが多いときに得が大きい**：Bucilă 2006（本当の分布のラベル無しのデータは人工データより 2〜8 倍少ない量で同じ成績），Hinton 2015（ラベル 3% で 44.5% → 57.0%），Lopez-Paz 2016（CIFAR-10 のラベル 300 枚と 50,000 枚のラベル無し），Ba と Caruana 2014（蒸留用のデータがラベル付きより大きいときに最もよく働く）．
3. **蒸留元と蒸留先は同じ例を見る**：同じモダリティでは同じ入力の同じ切り抜き（Beyer 2022），モダリティをまたぐ場合は同じ場面や同じ発話の組（Gupta 2016，Aytar 2016，Li と Seltzer 2017）．
4. **蒸留元の正解率は蒸留先の成績を決めない**：大きい蒸留元が悪い蒸留元になる（Cho と Hariharan 2019 の表 1），ラベル平滑化で正確になった蒸留元が悪い蒸留元になる（Müller 2019），正解率 15% の蒸留元が蒸留先を良くする（Yuan 2020 の表 4），正確な多モダリティの蒸留元が悪い蒸留元になる（Xue 2023 の表 1），正確さより確率の推定の良さが大事（Menon 2021）．
5. **蒸留先が蒸留元を超えることがある**：同じ構造（Furlanello 2018），細く深い構造（Romero 2015），同じか大きい構造と雑音（Xie 2020），小さいモデルのラベルで学ぶ大きいモデル（Burns 2024）．

### 3.2 「蒸留で何が伝わるか」についての食い違い

| 説明 | 主な論文 | 根拠 |
|---|---|---|
| 正解以外のクラスの確率に含まれる，クラスどうしの似かたの情報（dark knowledge） | Hinton 2015，Müller 2019，Allen-Zhu と Li 2023，Huo 2024 | ラベル平滑化で似かたを消した蒸留元は蒸留先を良くしない（Müller）．アンサンブルの出力に「複数の見方」の情報が隠れている（Allen-Zhu と Li）．正解以外のクラスの順位がモダリティ間で食い違うと蒸留が成績を下げる（Huo） |
| 軟らかい目標による正則化 | Yuan 2020，Mobahi 2020，Ba と Caruana 2014，Romero 2015 | 正解率の低い蒸留元や手作りの分布でも蒸留先が良くなる（Yuan）．自己蒸留は回ごとに正則化を強める（Mobahi） |
| 例ごとの重み | Furlanello 2018，Vapnik と Vashist 2009 | 蒸留元の最大の確率で正解のラベルを重み付けるだけ（CWTM）でも得の一部が出る（Furlanello） |
| 目的関数の分散の減少 | Menon 2021 | ベイズ確率を目標にすると経験リスクの分散が減る．蒸留元の確率の偏りは上界の第 2 項になる |
| 最適化の偏り | Phuong と Lampert 2019，Nagarajan 2023 | 0 から始めた勾配降下法が良い解を選ぶ（Phuong と Lampert）．大きい固有値の方向を先に学ぶ偏りを蒸留が強める（Nagarajan） |
| 両方のモダリティに共通してラベルを決める特徴 | Xue 2023，Jaritz 2020 | 共通の特徴の割合 γ が大きい蒸留元ほど蒸留先を良くする（Xue）．頭が 1 つだと固有の情報が捨てられる（Jaritz） |

最も直接に食い違うのは，**似かたの情報を重く見る Müller 2019** と，**正則化を重く見る Yuan 2020** である．Müller は「ラベル平滑化で似かたの情報が消えると，正確な蒸留元でも蒸留先を良くしない」と示した．Yuan は「似かたの情報を持たない手作りの分布でも蒸留先を良くする」と示し，"the success of KD is not fully due to the similarity information between categories from teachers, but also to the regularization of soft targets, which is equally or even more important" と書いた．2 本はどちらも「蒸留元の正解率が蒸留先を決めない」点では一致している．

**写す度合いと汎化の関係**でも食い違いがある．Bucilă 2006 と Hinton 2015 は，蒸留先が蒸留元の関数を写すことを蒸留の目的とした．Phuong と Lampert 2019 は，線形の場合にデータが次元以上あれば蒸留先が蒸留元をそのまま取り戻すと証明した．一方で Stanton 2021 は，深いネットでは蒸留先が蒸留元にあまり一致せず，自己蒸留では一致を高めると汎化が悪くなると示し，"more closely matching the teacher paradoxically does not always lead to better student generalization" と書いた．Nagarajan 2023 は，蒸留先が蒸留元の確信度を誇張してずれることと，蒸留先が良くなることが同時に起こると示した．Beyer 2022 は，同じ入力を見せて長く学べば一致させるほど良い蒸留先になると示した．Stanton の結果は，アンサンブルを蒸留元にした場合は一致と汎化が同じ向きに動いたので，Beyer の結果と両立する．

### 3.3 「蒸留先が蒸留元を超えるのはいつか」についての食い違い

- **超えないとする見方**：Lopez-Paz 2016 は，良い蒸留元の確率で学ぶ蒸留先の方針を "whatever my teacher could not do, I will not do" と書いた（4.1 節）．λ を下げて通常の学習に戻れる点を，その安全策とした．
- **同じ構造でも超える**：Furlanello 2018（CIFAR-100 で 18.25% → 16.95%），Mobahi 2020（数回までは良くなり，その後は学び足りなくなる），Allen-Zhu と Li 2023（自己蒸留は誤りを 0.49µ 以上から 0.26µ 以下にする）．
- **蒸留先が大きいか，雑音を入れると超える**：Xie 2020，Burns 2024．
- **超える量を決める条件の理論**：
  - Charikar 2024：凸の関数の集合と実現可能の条件のもとで，蒸留先は蒸留元より少なくとも misfit（蒸留先が蒸留元のラベルに合わせきれない量）だけ良くなる．
  - Lang 2024：近傍の拡張の条件と蒸留先の頑健さのもとで，蒸留先は疑似ラベルの誤りを直せる．"weak-to-strong generalization occurs when the strong model is unable to fit the mistakes of the weak teacher without incurring additional error"（抄録）．
  - 2 本とも，「蒸留先が蒸留元の誤りを表せないこと」を得の源としている．
- **大きいほど良いとは限らない**：Cho と Hariharan 2019（大きい蒸留元で蒸留先が悪くなる．段階的な蒸留でも直らない），Mirzadeh 2020（中くらいのモデルを挟むと直る）．段階的な蒸留の効果について，この 2 本の結論は一致しない．
- **モダリティをまたぐと下がることがある**：Xue 2023（正確な多モダリティの蒸留元からの蒸留先が，同じモダリティの蒸留元からの蒸留先を下回る），Huo 2024（正解率の低いモダリティの蒸留元で 52.8% → 46.6%）．

### 3.5 MER-DA の観察と並べた読み（推測．どれも検定していない）

研究者の観察は「単独の分類器は疑似ラベルで伸びるが，融合の分類器の改善は小さい」である．上の論文から，この観察について次の読みができる．これは説明の候補であり，MER-DA のデータで確かめていない．

**事実（こちらの計算）**：単独の分類器の確率の積を，クラスについて足して 1 になるように割ると，3 つの特徴をつないだ入力の上の線形のソフトマックスになる．
```
p_m(k | x_m) = exp(z_mk) / Σ_j exp(z_mj)，z_m = W_m x_m + b_m     （m は音声・顔・言葉）
Π_m p_m(k | x_m) / Σ_j Π_m p_m(j | x_m) = exp(Σ_m z_mk) / Σ_j exp(Σ_m z_mj)
                                         = softmax(W_cat x_cat + Σ_m b_m)_k
W_cat = [W_A  W_V  W_T]，x_cat = [x_A; x_V; x_T]
```
感情ごとの総量をそろえるために各感情の列を定数 S_k で割る操作は，行ごとに割り直せばロジットに −log S_k を足すことにあたり，行ごとの総量の違いは発話ごとの重みになる．どちらも，十分なデータでの最小化の解が線形のソフトマックスの形に入ることを変えない（MER-DA の実装の細部とは照合していない）．

**この事実から出る読み**：
1. 融合の線形の分類器は，疑似ラベルの関数そのものを表せる．Phuong と Lampert 2019 の定理 1 を多クラスに広げて当てはめると，疑似ラベルの項だけで学ぶ融合の分類器は，ラベル無しの発話が特徴の次元（1024 + 512 + 768 = 2,304）より多いとき，疑似ラベルの関数に収束すると予想される．Allen-Zhu と Li 2023 の定理 3 と Hinton 2015 のアンサンブルの蒸留も，蒸留先がアンサンブルの成績に近づくことを示す．
2. Charikar 2024 の定理 1 の見方では，融合の分類器の misfit はほぼ 0 なので，疑似ラベルを超える得はほぼ 0 になる（定理は二乗誤差の回帰についてのもので，交差エントロピーの分類では証明されていない）．Lang 2024 の見方でも，融合の分類器は疑似ラベルの誤りに余分な誤りなしで合わせられるので，誤りを直す力が働かない．
3. 単独の分類器は，ほかのモダリティの入力に依存する部分を表せない．交差エントロピーで軟らかい目標を学ぶとき，関数の制約が無ければ最小化の解は「その分類器の入力が与えられたときの目標の条件つき期待値」である．単独の分類器が受け取るのは，疑似ラベルのうち自分のモダリティから予測できる部分であり，Xue 2023 の「共通してラベルを決める特徴」に近い．違いは，Xue の γ がラベルを決める手がかりだけを数えるのに対し，ここでは疑似ラベルの誤りのうち自分のモダリティから予測できる部分も含む点である．
4. 3 つの単独の分類器が同じ共通の部分を受け取るなら，それらを融合しても同じ情報を重ねて数えるだけで，得は足し合わさらない．Du 2023 の付録 A.7.1 は，凍結した特徴の上でも連結の線形分類器と単独の予測の平均のどちらが良いかがデータで変わると報告している．
5. 一方，MER-DA の損失には K 本のラベルと L2 の引き戻しが入るので，融合の分類器の解は疑似ラベルの関数そのものにはならない．読み 1・2 は，疑似ラベルの項の重みが大きいときの近似である．
