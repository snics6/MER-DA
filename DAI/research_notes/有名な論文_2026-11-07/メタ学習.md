|---|---|
| 課題（task） | 1 つのデータ集合と損失の組．少数ショット学習ではクラスの組，ドメイン汎化ではドメイン，MER-DA ではコーパス |

| 内側と外側 | 内側の学習は 1 つの課題の上での学習，外側の学習は内側の学習の仕方（初期値・罰則・設定）を多くの課題の成績で学ぶこと．二段の最適化（bilevel optimization）とも呼ぶ |
| メタ学習・メタ検証・メタ試験 | 外側の学習に使う課題，外側の設定を選ぶのに使う課題，最終の評価に使う課題．少数ショット学習ではクラスを分けて作る |
| 偏った正則化（biased regularization） | 係数 w を 0 ではなく，ある中心 h に寄せる罰則 λ‖w − h‖²/2 をつけて学ぶこと．MER-DA の「ソースの分類器の平均を中心にした L2 罰則」はこの形である |
| 転移リスク（transfer risk） | 新しい課題を課題の分布から引き，その課題の少数の例で学んだときの誤差の期待値 |
| 独立学習（ITL） | 各課題をほかの課題を使わずに学ぶこと（偏った正則化で h = 0 にした場合） |
| 転導的（transductive） | テストの例をまとめて見て（ラベルは見ずに）学習や正規化に使うこと |

## 1. 分野の流れ

### 1.1 1987〜2000 年：「学ぶことを学ぶ」という問いと最初の理論

Schmidhuber は 1987 年の卒業論文で，学習の仕組みが自分自身の学び方を改良するという考えを書いた（書誌のみ確認）．Thrun & Pratt が 1998 年に編んだ論文集 *Learning to Learn* が，この問いを一つの分野の名前にした．Baxter 2000 は，関連する課題が共通の分布（環境）から引かれるという仮定を置き，学習器の仮説空間（候補の関数の集まり）を多くの課題から選べば，新しい課題で要る例が減ることを，PAC 学習（誤差 ε 以下を確率 1 − δ 以上で保証する枠組み）の上界で示した．Maurer 2005 は同じ問いを学習アルゴリズムの安定性（学習データを 1 つ抜いたときに出力がどれだけ変わるか）で解析した．この時期の保証は，課題の数と各課題の例の数の両方が十分大きいことを前提にしている．

### 1.2 2015〜2017 年：深層学習での少数ショット学習と，距離の学習

Koch ほか 2015 は，2 つの入力が同じクラスかを判定する Siamese 網（重みを共有する 2 本の網）を学び，Omniglot の 1 例の分類に使った．Vinyals ほか 2016 は "test and train conditions must match" を原則に掲げ，学習時にも本番と同じ形のエピソードを作って学ぶエピソード学習を提案し，評価用の miniImageNet を作った．Snell ほか 2017 は，クラスの埋め込みの平均（原型）への 2 乗距離で分類する原型ネットワークがそれまでの複雑な方法を上回ることを示し，この分類器が線形の分類器と同じ形であることを書いた．

### 1.3 2016〜2019 年：学び方（最適化）そのものを学ぶ

Andrychowicz ほか 2016 と Ravi & Larochelle 2017 は，LSTM に重みの更新量を出させる方法を作った．Finn ほか 2017 の MAML は，更新則を勾配降下に固定して，「数回の勾配の更新でよく働く初期値」だけを外側で学ぶ形にし，勾配法で学ぶどのモデルにも使えるようにした．その後，2 階微分を省く方法（Nichol ほか 2018 の Reptile），内側の学習を「初期値からの 2 乗距離を罰則にした最小化」に置き換え，陰関数の微分で外側の勾配を求める方法（Rajeswaran ほか 2019 の iMAML），内側を閉じた形や凸の問題として解ける線形の分類器にする方法（Bertinetto ほか 2019 の R2D2，Lee ほか 2019 の MetaOptNet）が続いた．Grant ほか 2018 は，線形回帰では数回の勾配降下が初期値を平均にしたガウスの事前分布のもとでの MAP 推定（事後分布の最頻値）と同じであることを使い，MAML を階層ベイズモデルの経験ベイズ推定として読み直した．

### 1.4 2016〜2021 年：偏った正則化と表現学習の理論

Denevi ほか 2018・2019 は，内側の学習を「共通のベクトル h への 2 乗距離を罰則にしたリッジ回帰や SGD」に限り，h を課題の流れから学ぶ問題を解析した．課題の係数のばらつきがその 2 乗平均より十分小さいときに独立学習より得をすること，罰則の強さは課題のばらつきと各課題の例の数に反比例させるのがよいことを示した．Balcan, Khodak, Talwalkar 2019 と Khodak ほか 2019（ARUBA）は，同じ考えをオンライン凸最適化（データが順に届き，後から見た最良の固定解との損失の差＝後悔（regret）で成績を測る枠組み）で表し，課題の最適解どうしの近さで平均の後悔が小さくなることを示した．Konobeev ほか 2021 は，課題の係数がガウス分布に従う線形回帰で下界を導き，課題の共分散の逆行列で重みづけた偏った正則化がその下界に定数倍で一致することを示した．共有の特徴抽出（表現）を学ぶ側では，Maurer ほか 2016，Tripuraneni ほか 2020，Du ほか 2021 が，課題の数と課題の多様性に依存する上界を出した．

### 1.5 2019〜2022 年：単純な基準線との比較

Chen ほか 2019 は，実装をそろえると単純な転移（特徴を凍結して新しい線形分類器を学ぶ）が過小評価されていたこと，ドメインがずれると単純な方法がメタ学習の全手法に勝つことを示した．Raghu ほか 2020 は，MAML の成績のほとんどが特徴の再利用から来ており，内側の更新を最終層だけに限っても（ANIL）成績が変わらないことを示した．Tian ほか 2020 は，全学習クラスをまとめて普通に学んだ埋め込みの上のロジスティック回帰が当時のメタ学習を上回ると報告した．Dhillon ほか 2020 は，クエリの例の予測のエントロピーを罰則にする転導的な微調整を基準線として出した．Triantafillou ほか 2020 の Meta-Dataset は 10 のデータ集合の混合で評価し，複数のデータ集合で学ぶとメタ学習の得が消える場合があることを示した．Guo ほか 2020 は，学習のドメインと大きく違うドメインではメタ学習が微調整に平均 12.8 点負けると報告した．一方で Hu ほか 2022 は，大規模な事前学習の上に原型ネットワークのエピソード学習を重ねると，Meta-Dataset の成績がさらに上がると報告した．

### 1.6 2015〜2019 年：ドメイン汎化と，設定・重みの二段の最適化

Li ほか 2018（MLDG）はソースのドメインを仮の学習側と仮のテスト側に分け，MAML と同じ形の目的で学んだ．Balaji ほか 2018（MetaReg）は特徴の網を固定し，分類の網にかける正則化項の係数を，あるドメインで学んだ分類の網が別のドメインでよく働くように学んだ．同じ時期に，設定（ハイパーパラメータ）を検証誤差の勾配で学ぶ方法が整理され（Maclaurin ほか 2015，Franceschi ほか 2018），学習データの例ごとの重みを少数の正しいラベルのデータで学ぶ方法（Ren ほか 2018，Shu ほか 2019）が出た．DomainBed（Gulrajani & Lopez-Paz．`docs/related-work.md` 2.6 節）は設定の選び方をそろえると，MLDG を含む手法が ERM（全ソースをまとめて普通に学ぶ方法）と同程度になることを示した．

### 1.7 課題が少ないときの問題と総説

Hospedales ほか 2021 の総説は，メタ過学習（ソースの課題で学んだものがターゲットの課題に汎化しないこと）がソースの課題が少ないときによく起きると書き，課題の分布が学習時と本番で違う場合を未解決の問題に挙げた．Yao ほか 2022（MLTI）は，課題が少ないときに 2 つの課題の特徴とラベルを内挿して課題を増やす方法を出した．

### 1.8 感情認識でのメタ学習

Fujioka ほか 2020 は，感情のラベルの曖昧さに対して，例ごとの重みと修正したラベルを学習中に推定した．Chopra ほか 2021 は，言語を課題にした MAML で少資源の言語（ペルシア語・イタリア語・ウルドゥー語）の音声感情認識を行った．Feng & Chaspari（TAC 2023）は，Siamese 網による距離の学習で，台本の演技音声のコーパスから自然な発話のコーパスへ少数ラベルで移した．Gandhi ほか 2023 は MLDG を音声感情認識のコーパス間に当てはめ，log-mel の特徴では MLDG に要る違いが表れないと報告した．Shen ほか 2025（Meta-PerSER）は聴取者（注釈者）ごとを課題にした MAML で個人化した．感情認識で「ソースのコーパスを 1 つ仮のターゲットにして，K ごとに罰則の強さや重みを選ぶ」研究は，この調べの範囲では見つからなかった（`docs/related-work.md` 1.12 節 Q5 の結論と同じ）．

## 2. 論文ごとの要点

### 2.1 理論の始まり

#### Baxter 2000（JAIR 12:149–198．arXiv 1106.0245）A Model of Inductive Bias Learning

- **問い**：学習器の帰納的な偏り（inductive bias．データだけでは決まらず，学習器が前もって持つ好み．ここでは仮説空間の選び方）を，関連する多くの課題から自動で学べるか．課題が何個，各課題に例が何個あれば，新しい課題でもうまくいくと保証できるか．
- **方法**：
  ```
  環境 Q：課題の分布 P を生む分布．P₁,…,Pₙ ~ Q を n 個引き，各 Pᵢ から m 例を引く（(n, m) 標本 z）
  仮説空間の族 ℍ = {H}．H は関数の集まり
  経験誤差  êr_z(H) = (1/n) Σᵢ min_{h∈H} (1/m) Σⱼ ℓ(h(xᵢⱼ), yᵢⱼ)
  真の誤差  er_Q(H) = E_{P~Q}[ inf_{h∈H} E_{(x,y)~P} ℓ(h(x), y) ]
  定理 2：n ≥ max{ (256/ε²) log(8C(ε/32, ℍ*)/δ), 64/ε² }
          m ≥ max{ (256/(nε²)) log(8C(ε/32, ℍⁿ_l)/δ), 64/ε² }
          なら，確率 1 − δ で全ての H ∈ ℍ について er_Q(H) ≤ êr_z(H) + ε
  （C(·) は被覆数．関数の集まりの大きさの尺度）
  ```
- **分かったこと**：神経網の前半の特徴を全課題で共有する場合，各課題に要る例の数の上界は O(a + b/n)（a は正しい特徴が分かっているときに要る数，b は特徴の集まりの複雑さ，n は課題の数），課題の数の上界は O(b) である（1 節）．共有する特徴の重みの数を W，課題ごとの出力の重みの数を k とすると，各課題に要る例は O(k + W/n) で，課題が増えると最小の O(k) に近づく（3.3 節）．
- **前提と限界**：著者は "both the number of tasks n and the number of examples of each task m must be sufficiently large" と書いている（定理 2 の後の注意 2）．課題の数の上界は O(W) で，特徴の網が大きいと多くの課題が要る（3.3 節の注意 4）．こちらの計算：定理 2 の条件 n ≥ 64/ε² は，ε = 0.1 なら n ≥ 6400 課題を求める．
- **MER-DA との接点**（推測，検定していない）：ソースが 3 つなので，この型の保証から数値は出ない．「共有部分が固定されていれば，課題ごとに要る例は出力の重みの数 k で決まる」という形は，凍結したエンコーダの上で線形の分類器だけを学ぶ MER-DA の設定と同じ形である．
- **確認**：◎（要旨，1 節，2 節の定理 2，3.3 節）．https://arxiv.org/abs/1106.0245

#### Maurer, Pontil, Romera-Paredes 2016（JMLR 17(81):1–32．arXiv 1505.06279）The Benefit of Multitask Representation Learning

- **問い**：T 個の課題で共有の表現 h を学び，新しい課題では課題ごとの部分 f だけを学ぶとき（learning-to-learn，LTL），課題を別々に学ぶよりどれだけ得をするか．
- **方法**：
  ```
  min_{h∈H, (f₁,…,f_T)∈Fᵀ}  (1/(nT)) Σ_{t=1..T} Σ_{i=1..n} ℓ( f_t(h(X_ti)), Y_ti )          （式 1）
  定理 2（LTL）：表現 ĥ の過剰リスクの上界 ＝
      （表現の複雑さ G(H(X̄)) を T と n で割った項） ＋ （課題ごとの予測器の項．n とともに減る）
      ＋ √(8 ln(4/δ) / T)
  （G はガウス複雑度．定数の細部は抽出で崩れたので形だけを書いた）
  ```
- **分かったこと**：上界は 3 項から成り，1 項目は表現を推定する費用で課題の数 T とともに減り，2 項目は課題ごとの予測器の費用で各課題の例の数 n とともに減り，3 項目は信頼度の項である（2 節）．線形の特徴学習では "the burden of high dimensions vanishes in the limit T → ∞"（3 節）．線形分類（半空間）の学習について，標本数・課題数・内在次元の関数として，多課題で表現を学ぶ方が得になる領域を導いた（要旨，3.1 節）．
- **前提と限界**：課題は環境 η から独立同分布に引かれる．こちらの計算：3 項目 √(8 ln(4/δ)/T) は T = 3，δ = 0.05 で √(8 × 4.38 / 3) ≈ 3.4 になり，損失が 0 から 1 の値をとる場合は意味のない上界になる．
- **MER-DA との接点**（推測，検定していない）：MER-DA は表現を学ばない（凍結）ので，1 項目にあたる部分は無い．課題が 3 つでは 3 項目が大きすぎるので，この上界は保証として使えない．
- **確認**：◎（要旨，1 節，2.2 節の定理 2，3 節）．https://arxiv.org/abs/1505.06279 ，https://www.jmlr.org/papers/v17/15-242.html

### 2.2 距離を学ぶ方法

#### Koch, Zemel, Salakhutdinov 2015（ICML 2015 Deep Learning Workshop．arXiv なし）Siamese Neural Networks for One-shot Image Recognition

- **問い**：新しいクラスに 1 例しかない（one-shot）とき，「2 つの入力が同じクラスか」を判定する網を別のクラスで学び，それを新しいクラスの分類に使えるか．
- **方法**：
  ```
  重みを共有する 2 本の網で 2 枚の画像 x₁, x₂ を特徴 h(x₁), h(x₂) にする
  p(x₁, x₂) = σ( Σ_j α_j |h_j(x₁) − h_j(x₂)| )      （σ はシグモイド，α_j は学ぶ重み）
  損失：同じクラスなら y = 1，違えば y = 0 とした 2 値の交差エントロピー ＋ L2 罰則
  one-shot 分類：C 個のクラスの例 x_c のうち p(x, x_c) が最大のクラスを答える
  ```
- **分かったこと**：Omniglot の 20 方向 1 例の分類（20 クラスから 1 例ずつ）で，畳み込みの Siamese 網は 92.0% だった（表 2．人は 95.5%，階層ベイズの方法 HBPL は 95.2%）．学習を止める基準には，検証用の one-shot 試行 320 回の正解率を使い，検証の対の誤差を使うより少なくとも同程度に良かった（4 節）．
- **前提と限界**：網は「同じか違うか」の判定で学び，one-shot 分類の課題そのものでは学ばない．
- **MER-DA との接点**（推測，検定していない）：Feng & Chaspari（2.10 節）がこの型の網を音声感情認識の少数ラベルの転移に使った．MER-DA は Siamese 網を使わず，線形の softmax 分類器を学ぶ．
- **確認**：◎（全 6 頁．3・4 節，表 2）．PDF の頭書きは ICML 2015 の書式であり，一般には同年の Deep Learning Workshop の論文として引かれる（ワークショップの頁は確かめていない）．https://www.cs.cmu.edu/~rsalakhu/papers/oneshot1.pdf

#### Vinyals, Blundell, Lillicrap, Kavukcuoglu, Wierstra 2016（NIPS 2016．arXiv 1606.04080）Matching Networks for One Shot Learning

- **問い**：少数のラベル付き例（サポート集合）とラベル無しの例を受け取り，微調整なしで答えを出す網を作れるか．
- **方法**：
  ```
  ŷ = Σ_{i=1..k} a(x̂, xᵢ) yᵢ ，  a(x̂, xᵢ) = exp(c(f(x̂), g(xᵢ))) / Σⱼ exp(c(f(x̂), g(xⱼ)))
  （c はコサイン類似度，f と g は埋め込みの網．FCE はサポート集合全体を見て埋め込みを作る拡張）
  学習：θ = argmax_θ E_{L~T}[ E_{S~L, B~L}[ Σ_{(x,y)∈B} log P_θ(y | x, S) ] ]
  （課題の分布 T からラベル集合 L を引き，L からサポート集合 S と評価用の束 B を引く）
  ```
- **分かったこと**：学習の原理を "test and train conditions must match" とし，少数例の課題を束ごとに切り替えて学んだ（1 節）．このとき作った miniImageNet（100 クラス，各 600 枚．この論文では 80 クラスで学び 20 クラスで試した）の 5 方向で，1 例 46.6%，5 例 60.0%（FCE と微調整あり．表 2）．ImageNet の犬の 118 クラスだけを試す設定では，Inception の特徴の 59.8% に対して 58.8% で 1 点下がった（表 3）．著者は，学習時のサポート集合は無作為なクラスから引かれるのに，試験時の犬のクラスは互いに似ている（細かい分類）ためだと推測し，細かいクラスの組から学習の課題を作ることを今後の課題にした（4.1.2 節）．
- **前提と限界**：学習と試験の課題の分布が同じであることを前提にする．犬の結果は，その前提が崩れると得が消える例である．
- **MER-DA との接点**（推測，検定していない）：「仮の課題を本番の課題と同じ形で作る」という原則は，ソースの 1 つを仮のターゲットにして設定を選ぶ leave-one-source-out の考え方と同じである．犬の結果は，仮の課題と本番の課題の性質が違うと選んだものが合わない例として引ける．
- **確認**：◎（要旨，1〜4 節，表 2・3）．https://arxiv.org/abs/1606.04080 ，https://papers.nips.cc/paper_files/paper/2016/hash/90e1357833654983612fb05e3ec9148c-Abstract.html

#### Snell, Swersky, Zemel 2017（NIPS 2017．arXiv 1703.05175）Prototypical Networks for Few-shot Learning

- **問い**：少数ショット分類で，もっと単純な帰納的な偏りを持つ方法のほうが良いのではないか．
- **方法**：
  ```
  c_k = (1/|S_k|) Σ_{(xᵢ, yᵢ)∈S_k} f_φ(xᵢ)                      （クラス k の原型＝埋め込みの平均）
  p_φ(y = k | x) = exp(−d(f_φ(x), c_k)) / Σ_{k′} exp(−d(f_φ(x), c_{k′}))
  d が 2 乗ユークリッド距離なら
    −‖f(x) − c_k‖² = −f(x)ᵀf(x) + 2c_kᵀf(x) − c_kᵀc_k
    → 線形モデル w_k = 2c_k，b_k = −c_kᵀc_k と同じ（式 7・8）
  ```
- **分かったこと**：miniImageNet（Ravi & Larochelle の 64・16・20 クラスの分割）の 5 方向で，1 例 49.42 ± 0.78%，5 例 68.20 ± 0.66%（表 2．600 エピソードの平均と 95% 信頼区間）．コサイン類似度より 2 乗ユークリッド距離が大きく良かった（著者の推測：コサインは Bregman 発散でないので，混合密度推定との対応が成り立たない）．学習時に試験時より多いクラス数（way）で学ぶと大きく良くなり，例の数（shot）は学習と試験でそろえるのが通常は最良だった（2.6 節）．
- **前提と限界**：学習時の way は検証集合で選んだ（2.6 節）．
- **MER-DA との接点**（推測，検定していない）：原型分類器は「感情ごとの K 本の特徴の平均」を重みにした線形の分類器である．Meta-Dataset の Proto-MAML（2.5 節）と Dhillon 2020 の重みの初期化（2.5 節）も同じ式を初期値に使う．
- **確認**：◎（要旨，2 節，3.2 節，表 2）．https://arxiv.org/abs/1703.05175 ，https://papers.nips.cc/paper_files/paper/2017/hash/cb8da6767461f2812ae4290eac7cbc42-Abstract.html

### 2.3 最適化（学び方）を学ぶ方法

#### Andrychowicz ほか 2016（NIPS 2016．arXiv 1606.04474）Learning to learn by gradient descent by gradient descent

- **問い**：手で設計してきた最適化の更新則（SGD，RMSprop，ADAM など）を，学習で作れるか．
- **方法**：
  ```
  θ_{t+1} = θ_t + g_t(∇f(θ_t), φ)                         （g は LSTM，φ はその重み）
  L(φ) = E_f[ Σ_{t=1..T} w_t f(θ_t) ] ，  θ_{t+1} = θ_t + g_t ，  [g_t; h_{t+1}] = m(∇_t, h_t, φ)
  LSTM は座標ごとに同じ重みで働く（coordinatewise）
  ```
- **分かったこと**：学んだ最適化器は，学習に使った種類の問題で手で設計した方法を上回り，構造の似た新しい問題にも汎化した（要旨）．MNIST の多層パーセプトロン（隠れ層 1 つ，20 単位，シグモイド）で学んだ最適化器は，隠れ単位を 40 にしても，隠れ層を 2 つにしても汎化したが，活性化を ReLU に変えると汎化しなかった（3.2 節，図 5 の説明）．
- **前提と限界**：著者は，ReLU に変えると学習の動き方が十分違うので汎化しないと書いた（3.2 節）．
- **MER-DA との接点**（推測，検定していない）：MER-DA が選ぶのは数個の設定であり，更新則ではない．「学習に使った問題の種類から外れると，学んだものが使えない」という結果は，仮のターゲットで選んだ設定を本当のターゲットに使うときの一般的な注意として引ける．
- **確認**：◎（要旨，1〜3 節）．https://arxiv.org/abs/1606.04474 ，https://papers.nips.cc/paper_files/paper/2016/hash/fb87582825f9d28a8d42c5e5e5e8b23d-Abstract.html

#### Ravi & Larochelle 2017（ICLR 2017．arXiv なし．OpenReview rJY0-Kcll）Optimization as a Model for Few-Shot Learning

- **問い**：少数ショットの状況で，学習器の網をどう更新するか（更新則と初期値）を LSTM で学べるか．
- **方法**（原典は取得できなかった．Huisman ほか 2021 の 5.3 節の説明による）：
  ```
  LSTM の記憶（cell state）c_t を学習器の重み θ_t とみなす
  c_t = f_t ⊙ c_{t−1} + α_t ⊙ c̄_t ，  c̄_t = −∇_{θ_{t−1}} L
  f_t = 1，α_t = 一定 のとき勾配降下と同じ．忘れる門 f_t と学習率 α_t は，勾配・損失・前の重みから LSTM が出す
  記憶の初期値 c₀ = θ₀（課題に共通の初期値）も学ぶ
  ```
- **分かったこと**：要旨："this meta-learning model is competitive with deep metric-learning techniques for few-shot learning"．miniImageNet 5 方向で 1 例 43.44 ± 0.77%，5 例 60.60 ± 0.71%（Snell 2017 の表 2 に引かれた値．原典の表は見ていない）．
- **前提と限界**：原典を読めていないので書かない．
- **MER-DA との接点**（推測，検定していない）：miniImageNet の 64・16・20 クラスのメタ学習・メタ検証・メタ試験の分割はこの論文のものとして広く使われている（Snell 2017 の 3.2 節，MetaOptNet の 3 節）．メタ検証の課題で設定を選ぶ慣行の出典として引かれることが多い．
- **確認**：○（要旨は mlanthology の頁で確かめた．OpenReview は自動の取得を拒んだ）．https://mlanthology.org/iclr/2017/ravi2017iclr-optimization ，https://openreview.net/forum?id=rJY0-Kcll

#### Finn, Abbeel, Levine 2017（ICML 2017，PMLR 70:1126–1135．arXiv 1703.03400）Model-Agnostic Meta-Learning for Fast Adaptation of Deep Networks（MAML）

- **問い**：勾配法で学ぶどのモデルにも使え，新しい課題で少数の勾配の更新でよく働く初期値を学べるか．
- **方法**：
  ```
  内側（課題 Tᵢ に合わせる）：θ′ᵢ = θ − α ∇_θ L_{Tᵢ}(f_θ)
  外側（初期値 θ を学ぶ）：  min_θ Σ_{Tᵢ~p(T)} L_{Tᵢ}(f_{θ′ᵢ}) = Σ_{Tᵢ} L_{Tᵢ}( f_{θ − α∇_θ L_{Tᵢ}(f_θ)} )
                            θ ← θ − β ∇_θ Σ_{Tᵢ} L_{Tᵢ}(f_{θ′ᵢ})                         （式 1）
  外側の勾配はヘシアンとベクトルの積を含む．これを省いたものを一次近似（first-order MAML）と呼ぶ
  ```
- **分かったこと**：miniImageNet 5 方向で 1 例 48.70 ± 1.84%，5 例 63.11 ± 0.92%（表 1）．一次近似は 48.07 ± 1.75%，63.15 ± 0.91% でほぼ同じで，計算は約 33% 速かった（5.2 節）．
- **前提と限界**：損失が初期値について十分滑らかであることだけを仮定する（2 節）．Nichol ほか 2018 は，MAML の評価がバッチ正規化の統計をテストの例全体から計算する転導的な評価だったと指摘している（Reptile の論文の 6 節）．
- **MER-DA との接点**（推測，検定していない）：Grant ほか 2018（2.4 節）によれば，線形回帰では内側の数回の勾配降下は「初期値を中心にした 2 次の罰則つきの推定」と同じである．MER-DA の「ソースの分類器の平均を中心にした L2 罰則」は，中心を外側で学ばずにソースの分類器の平均に固定した版にあたる．
- **確認**：◎（2・3 節，5.2 節，表 1）．https://proceedings.mlr.press/v70/finn17a.html

#### Nichol, Achiam, Schulman 2018（arXiv 1803.02999．プレプリント）On First-Order Meta-Learning Algorithms（Reptile）

- **問い**：2 階微分を使わずに，初期値を学ぶメタ学習ができるか．なぜそれで良いのか．
- **方法**：
  ```
  課題 τ を引き，k 回の SGD（または Adam）で φ̃ = U_τᵏ(φ) を求めて
  φ ← φ + ε(φ̃ − φ)            並列版：φ ← φ + ε (1/n) Σᵢ (φ̃ᵢ − φ)
  ```
- **分かったこと**：k = 1 のときは期待損失 E_τ[L_τ] の SGD と同じになる（3 節）．テイラー展開により，Reptile と MAML の更新の主な項は「期待損失を下げる項（同時学習）」と「同じ課題の別の束どうしの勾配の内積を大きくする項」から成る（5 節）．miniImageNet 5 方向で Reptile は 47.07 ± 0.26%（1 例），62.74 ± 0.37%（5 例），転導的な評価では 49.97 ± 0.32%，65.99 ± 0.58%（表 1）．
- **前提と限界**：著者は，MAML の結果は転導的な評価によると指摘し，転導的な評価と転導的でない評価を分けて報告した（6 節）．
- **MER-DA との接点**（推測，検定していない）：「k = 1 なら同時学習と同じ」という結果は，内側の学習が短いとメタ学習が全ソースの合併に近づくことを示す．評価で転導的な処理（テストの例全体の統計を使う処理）を入れるかどうかで数値が変わる点は，コーパスごとの標準化をテスト側の統計で行うかどうかの記録の仕方と関係する．
- **確認**：◎（要旨，3・5・6 節，表 1・2）．https://arxiv.org/abs/1803.02999

#### Rajeswaran, Finn, Kakade, Levine 2019（NeurIPS 2019．arXiv 1909.04630）Meta-Learning with Implicit Gradients（iMAML）

- **問い**：内側で多くの勾配の更新をすると，MAML は計算と記憶の負担が大きく，初期値への依存が消えていく．内側の解だけから外側の勾配を求められないか．
- **方法**：
  ```
  内側：φᵢ = Alg*(θ, Dᵢᵗʳ) = argmin_{φ′} L(φ′, Dᵢᵗʳ) + (λ/2) ‖φ′ − θ‖²                     （式 3）
  外側：min_θ Σᵢ L( Alg*(θ, Dᵢᵗʳ), Dᵢᵗᵉˢᵗ )
  補題 1：dAlg*(θ)/dθ = ( I + (1/λ) ∇²_φ L̂ᵢ(φᵢ) )⁻¹         （内側の解 φᵢ だけで決まる）
  ```
- **分かったこと**：λ は MAML の学習率 α と同じ役割で，初期値（事前の知識）とデータの重みの釣り合いを決める．λ も学べ，スカラーでもベクトルでも行列でもよい（2.2 節）．miniImageNet 5 方向 1 例で iMAML（ヘシアンを使わない最適化）49.30 ± 1.88%，MAML 48.70 ± 1.84%（表 3．λ = 0.5，内側 10 回）．
- **前提と限界**：著者は λ をスカラーの設定として扱い，設定の広い探索はしていないと書いた（4 節）．
- **MER-DA との接点**（推測，検定していない）：内側の式 3 は，MER-DA の「中心のまわりの L2 罰則つきの学び直し」と同じ形である．違いは，iMAML は中心 θ を外側で学び，MER-DA は中心をソースの分類器の平均に固定し，罰則の強さ λ を仮のターゲットで選ぶ点である．補題 1 の式は，罰則の強さを勾配で学ぶ場合に使える．
- **確認**：◎（要旨，2・3 節，4 節の表 3）．https://arxiv.org/abs/1909.04630 ，https://papers.nips.cc/paper_files/paper/2019/hash/072b030ba126b2f4b2374f342be9ed44-Abstract.html

#### Raghu, Raghu, Bengio, Vinyals 2020（ICLR 2020．arXiv 1909.09157）Rapid Learning or Feature Reuse? Towards Understanding the Effectiveness of MAML

- **問い**：MAML の成績は，内側の更新で表現が速く変わること（rapid learning）から来るのか，初期値の特徴をそのまま使うこと（feature reuse）から来るのか．
- **方法**：
  ```
  ANIL：内側の更新を最終層（head）の重みだけに限り，前半（body）は外側だけで学ぶ
  NIL ：テスト時に内側の更新をせず，最終層も外し，凍結した特徴の類似度でサポート集合と比べて分類する
  ```
- **分かったこと**：表現の類似度の解析と除去実験から，特徴の再利用が主な要因である（要旨）．miniImageNet 5 方向で，1 例は MAML 46.9 ± 0.2%，ANIL 46.7 ± 0.4%，NIL 48.0 ± 0.7%，5 例は 63.1 ± 0.4%，61.5 ± 0.5%，62.2 ± 0.5%（表 4）．著者は，テスト時の成績は学んだ特徴の質で決まると書いた（5 節："performance on the test tasks is entirely determined by the quality of the learned features"）．
- **前提と限界**：結論は，著者が調べた少数ショットの画像分類と強化学習のベンチマークでのものである．
- **MER-DA との接点**（推測，検定していない）：ANIL は「特徴は固定し，最終層の線形の分類器だけを課題に合わせる」形で，MER-DA の設定と同じである．この論文によれば，その形でも MAML と同程度の成績が出る．
- **確認**：◎（要旨，1 節，4・5 節，表 2・4）．https://arxiv.org/abs/1909.09157

#### Lee, Maji, Ravichandran, Soatto 2019（CVPR 2019，pp. 10649–10657．arXiv 1904.03758）Meta-Learning with Differentiable Convex Optimization（MetaOptNet）

- **問い**：少数ショットでも，最近傍法より識別的に学んだ線形の分類器のほうが良く汎化するのではないか．その線形の分類器の上で特徴をエピソード学習できるか．
- **方法**：
  ```
  内側（多クラス SVM，Crammer–Singer）：
    θ = A(Dᵗʳᵃⁱⁿ; φ) = argmin_{w_k} min_{ξ} (1/2) Σ_k ‖w_k‖² + C Σ_n ξ_n
       制約 w_{y_n}·f_φ(x_n) − w_k·f_φ(x_n) ≥ 1 − δ_{y_n,k} − ξ_n  （全ての n, k）       （式 4）
  外側：min_φ E_T[ L^meta(Dᵗᵉˢᵗ; θ = A(Dᵗʳᵃⁱⁿ; φ), φ) ]
  外側の勾配は KKT 条件（凸問題の最適性の条件）の陰関数の微分で求める．双対問題で解くので計算は特徴の次元ではなく例の数で決まる
  ```
- **分かったこと**：miniImageNet 5 方向で MetaOptNet-SVM は 1 例 62.64 ± 0.61%，5 例 78.63 ± 0.46%，リッジ回帰版（RR）は 61.41 ± 0.61%，77.88 ± 0.46%（表 1．ResNet-12）．メタ学習の終わりには学習の課題でほぼ 100% の正解率になり（メタ過学習），メタ学習とメタ検証のクラスを合わせて学ぶと良くなった（4.5 節）．
- **前提と限界**：設定は，別に取っておいたメタ検証の集合で選んだ（3 節："we keep an additional held-out meta-validation set to choose the hyperparameters of the meta-learner"）．
- **MER-DA との接点**（推測，検定していない）：内側を凸の線形の分類器にする点は MER-DA と同じである．MetaOptNet は罰則の中心が 0 で，ソースの分類器に寄せる項は無い．
- **確認**：◎（要旨，3 節，4 節，表 1）．https://arxiv.org/abs/1904.03758 ，https://doi.org/10.1109/CVPR.2019.01091

#### Bertinetto, Henriques, Torr, Vedaldi 2019（ICLR 2019．arXiv 1805.08136）Meta-learning with differentiable closed-form solvers（R2D2）

- **問い**：内側の学習を，閉じた形で解けて微分できるリッジ回帰にすれば，速くて強い少数ショット学習になるか．
- **方法**：
  ```
  W = Λ(Z) = (XᵀX + λI)⁻¹ XᵀY = Xᵀ(XXᵀ + λI)⁻¹ Y      （式 4・5．ウッドベリーの恒等式で n×n の逆行列にする）
  予測：Ŷ = α X′W + β                                 （式 6．α と β は出力の尺度と偏りの補正）
  λ, α, β は内側の学習器の設定として，特徴の網の重みと一緒に外側で学ぶ
  付録：λI の代わりに diag(λ) を使う版 W = diag(λ)⁻¹ Xᵀ(X diag(λ)⁻¹ Xᵀ + I)⁻¹ Y
  ```
- **分かったこと**：miniImageNet 5 方向で R2D2 は 1 例 51.8 ± 0.2%，5 例 68.4 ± 0.2%，CIFAR-FS では 65.4 ± 0.2%，79.4 ± 0.2%（表 1）．付録 C：出力の尺度 α を学ぶことは非常に重要で，λ を学ぶかどうかは成績にほとんど関係しなかった（"it is very important to learn the scalar α ... while it is indifferent whether or not to learn λ"）．
- **前提と限界**：リッジ回帰は回帰の方法で，one-hot のラベルに当てはめて分類に使うので，出力の尺度の補正が要る（3.2 節）．
- **MER-DA との接点**（推測，検定していない）：「罰則の強さ λ をメタ学習しても成績がほとんど変わらず，出力の尺度（温度）の補正のほうが大事」という付録 C の結果は，MER-DA で罰則の強さを K ごとに選ぶ効果の大きさを見積もるときの比べる材料になる．ただし R2D2 は特徴の網も同時に学ぶので，特徴を凍結した MER-DA と条件が違う．
- **確認**：◎（要旨，3 節，4 節の表 1，付録 C）．https://arxiv.org/abs/1805.08136

### 2.4 ベイズの見方

#### Grant, Finn, Levine, Darrell, Griffiths 2018（ICLR 2018．arXiv 1801.08930）Recasting Gradient-Based Meta-Learning as Hierarchical Bayes

- **問い**：MAML は確率モデルとして何を推定しているのか．
- **方法**：
  ```
  線形回帰で，初期値 φ⁽⁰⁾ = θ から k 回の勾配降下
    φ⁽ᵏ⁾ = φ⁽ᵏ⁻¹⁾ − α Xᵀ(Xφ⁽ᵏ⁻¹⁾ − y)                       （式 4）
  は，次の正則化つき最小二乗の解と同じ（Santos 1996）
    min_φ ‖y − Xφ‖² + ‖θ − φ‖²_Q ，  ‖z‖_Q = zᵀQ⁻¹z          （式 5）
  すなわち事後分布 p(φ | X, y, θ) ∝ N(y; Xφ, I) N(φ; θ, Q) の最頻値（MAP 推定）       （式 6）
  Q は学習率 α，更新の回数 k，X の共分散で決まる
  ```
- **分かったこと**：線形回帰の 2 乗誤差では MAML は MAP 推定を点推定に使う経験ベイズ（事前分布の母数をデータから推定する方法）そのものであり，非線形の場合も同じ手続きの近似である（3 節）．課題ごとの母数の不確かさをラプラス近似（最頻値のまわりで 2 次の形に近似する方法）で入れた LLAMA は，miniImageNet 5 方向 1 例で 49.40 ± 1.83%（MAML 48.70 ± 1.84%．表 1）．
- **前提と限界**：MAP との厳密な一致は線形回帰の 2 乗誤差の場合に限る（3 節）．
- **MER-DA との接点**（推測，検定していない）：「中心のまわりの L2 罰則つきの学び直し」は，中心を平均とするガウスの事前分布のもとでの MAP 推定である．罰則の強さは事前分布の分散の逆数にあたり，Konobeev ほか 2021（2.6 節）の「課題の母数の共分散の逆行列で重みづける」結果と同じ見方になる．
- **確認**：◎（要旨，3 節，4.1 節，5 節の表 1）．https://arxiv.org/abs/1801.08930

#### Chen, Liu, Kira, Wang, Huang 2019（ICLR 2019．arXiv 1904.04232）A Closer Look at Few-shot Classification

- 詳しくは `docs/related-work.md` 2.6 節と付録の読書メモ．
- **問い**：実装と背骨（特徴抽出の網）をそろえると，メタ学習は単純な転移より本当に優れているか．
- **方法**：Baseline（全学習クラスで普通に学び，特徴を凍結して新しいクラスの線形分類器だけを学ぶ），Baseline++（コサイン距離の分類器），MatchingNet，ProtoNet，MAML，RelationNet を同じ条件で比べた．

- **MER-DA との接点**（推測，検定していない）：「凍結した特徴＋線形の分類器」が，ドメインのずれがあるときの強い基準線であることの出典になる．
- **確認**：◎（`docs/related-work.md` の記録．今回は表 3 と 4.4 節を読み直した）．https://arxiv.org/abs/1904.04232

#### Tian, Wang, Krishnan, Tenenbaum, Isola 2020（ECCV 2020，LNCS pp. 266–282．arXiv 2003.11539）Rethinking Few-Shot Image Classification: a Good Embedding Is All You Need?

- **問い**：少数ショット分類の成績は，メタ学習の方法から来るのか，学んだ表現から来るのか．
- **方法**：
  ```
  全てのメタ学習の課題のデータをまとめた Dⁿᵉʷ で埋め込み φ を普通の交差エントロピーで学ぶ
    φ = argmin_φ L_ce(Dⁿᵉʷ; φ)                                        （式 5）
  テスト時：埋め込みを凍結し，サポート集合でロジスティック回帰を学ぶ
    θ = {W, b} = argmin Σ_t L_ce(W f_φ(x_t) + b, y_t) + R(W, b)        （式 6）
  自己蒸留：前の世代のモデルの出力確率を目標の一部にして次の世代のモデルを学び直す
  ```
- **分かったこと**：miniImageNet 5 方向で，蒸留なし 62.02 ± 0.63%（1 例），79.64 ± 0.44%（5 例），蒸留あり 64.82 ± 0.60%，82.14 ± 0.43%（表 1．ResNet-12．同じ表の MetaOptNet は 62.64，78.63）．Meta-Dataset では 10 のテストのデータ集合のうち 9 で，元の論文の最良の値を上回った（5 節，表 7）．1 例の場合でもロジスティック回帰は最近傍法より明らかに良く，特徴の長さを 1 にそろえると同程度になり，5 例では長さをそろえてもロジスティック回帰が良かった（4.7 節）．共有の埋め込みと課題ごとの頭を持つ多課題学習で埋め込みを作ると 58.53 ± 0.8% で，全クラスをまとめた分類で作る 62.02 ± 0.63% より低かった（4.9 節）．
- **前提と限界**：著者は，少数ショット分類の課題はクラスが互いに重ならないので全課題を 1 つの多クラス分類にまとめられ，そのことが単純な方法を強くしていると書いた（4.9 節，6 節）．メタ学習全体を否定するものではなく，"methods like MAML may still be favorable in other meta-learning domains (e.g., meta-reinforcement learning)" と書いた（6 節）．
- **MER-DA との接点**（推測，検定していない）：MER-DA は課題（コーパス）の間でラベル（4 感情）が共通なので，全ソースをまとめた学習（合併）が Tian の基準線にあたる．Tian の議論では，ラベルが共通の場合ほどまとめた学習が強いことになる．
- **確認**：◎（要旨，3 節，4.7〜4.9 節，5 節，6 節，表 1）．https://arxiv.org/abs/2003.11539 ，https://doi.org/10.1007/978-3-030-58568-6_16

#### Dhillon, Chaudhari, Ravichandran, Soatto 2020（ICLR 2020．arXiv 1909.02729）A Baseline for Few-Shot Image Classification

- **問い**：普通の交差エントロピーで学んだ網を微調整するだけの方法は，少数ショット学習の基準線としてどれだけ強いか．
- **方法**：
  ```
  重みの初期化（support-based initialization）：w_y = z(x;θ)₊ / ‖z(x;θ)₊‖ ，b_y = 0       （式 6．クラス y の例の特徴の平均を長さ 1 にしたもの）
  転導的な微調整：
    Θ* = argmin_Θ (1/N_s) Σ_{(x,y)∈D_s} −log p_Θ(y | x) + (1/N_q) Σ_{x∈D_q} H(p_Θ(· | x))     （式 8）
  （D_s はサポート集合，D_q はラベル無しのクエリ集合，H はシャノンのエントロピー）
  ```
- **分かったこと**：miniImageNet 5 方向で転導的な微調整は 65.73 ± 0.68%（1 例），78.40 ± 0.52%（5 例），転導的でない微調整は 57.73 ± 0.62%，78.17 ± 0.49%（表 1．WRN-28-10，学習クラスだけで事前学習）．多くの手法の正解率の標準偏差は大きく，平均の信頼区間だけを見ると進歩が実際より大きく見える（1 節，図 1）．
- **前提と限界**：著者は "We do not advocate our approach as the solution for few-shot learning, but simply use the results to highlight limitations of current benchmarks and few-shot protocols" と書いた（要旨）．エピソードの難しさを数える指標を提案し，平均の信頼区間ではなく標準偏差の報告を勧めた（4 節）．
- **MER-DA との接点**（推測，検定していない）：式 8 のエントロピーの項は，ターゲットのラベル無しの発話を使う最も単純な半教師ありの項であり，MER-DA の疑似ラベルの重みを選ぶ実験の比べる相手の候補になる．標準偏差を報告する勧めは，ターゲットの K 本の抽出による成績のばらつきの報告と関係する．
- **確認**：◎（要旨，1 節，3 節，4.1 節，表 1，付録 C.10）．https://arxiv.org/abs/1909.02729

#### Triantafillou ほか 2020（ICLR 2020．arXiv 1903.03096）Meta-Dataset: A Dataset of Datasets for Learning to Learn from Few Examples

- **問い**：同じデータ集合の中でクラスを分けるだけのベンチマークではなく，性質の違う多くのデータ集合をまたいで少数ショット学習を評価するとどうなるか．
- **方法**：
  ```
  10 のデータ集合（ImageNet，Omniglot，Aircraft，鳥，模様，QuickDraw，菌類，花，交通標識，MSCOCO）
  エピソードの way と shot をデータ集合ごとに変えて引く
  Proto-MAML：MAML の最終層の初期値を原型ネットワークと同じ値にする
    W_k = 2c_k ，  b_k = −‖c_k‖²            （c_k はクラス k のサポートの埋め込みの平均）
  設定は ImageNet のメタ検証の成績だけで選ぶ
  ```
- **分かったこと**：データ集合ごとの順位の平均で fo-Proto-MAML（一次近似の Proto-MAML）が最良で，原型ネットワークも強く，微調整の基準線は "a worthy opponent" だった（5 節，表 1）．ImageNet だけでなく全データ集合で学ぶと，Omniglot・QuickDraw・Aircraft では大きく上がったが，残りでは上がらなかった（図 1）．メタ学習をせずに普通に学んで評価だけエピソードで行う基準線は強く，ImageNet だけで学ぶとメタ学習の得は小さく，全データ集合で学ぶとその得はしばしば消え，メタ学習が悪くすることもあった（5 節，図 3c・3d）．原型ネットワークと fo-Proto-MAML は例の数が非常に少ないときに強いが早く頭打ちになり，微調整の基準線は例が増えると速く伸びた（図 2b）．
- **前提と限界**：著者の結論："it remains unclear what is the best strategy for creating training episodes, the most appropriate validation creation and the most appropriate initialization. Current models don't always improve when trained on multiple sources and meta-learning is not always beneficial across datasets"（6 節）．ImageNet の検証だけで設定を選んだことの限界を付録で述べている（`docs/related-work.md` 1.8.3 節）．
- **MER-DA との接点**（推測，検定していない）：複数のソースで学ぶとメタ学習の得が消える場合があるという結果と，「例の数によって良い方法が入れ替わる」という結果は，MER-DA で K ごとに設定を選ぶ理由として引ける．
- **確認**：◎（要旨，3〜6 節）．https://arxiv.org/abs/1903.03096

#### Guo, Codella ほか 2020（ECCV 2020，LNCS pp. 124–141．arXiv 1912.07200）A Broader Study of Cross-Domain Few-Shot Learning（BSCD-FSL）

- 詳しくは `docs/related-work.md` 2.6 節と付録の読書メモ．
- **問い**：ImageNet と大きく違う画像分野（農作物の病害・衛星・皮膚・胸部 X 線）で，少数ショット学習の手法はどれが良いか．

#### Hu, Li, Stühmer, Kim, Hospedales 2022（CVPR 2022．arXiv 2204.07305）Pushing the Limits of Simple Pipelines for Few-Shot Learning: External Data and Fine-Tuning Make a Difference（P>M>F）

- **問い**：外部のラベル無しデータでの事前学習（P），基底クラスでのエピソード学習（M），新しい課題での微調整（F）の 3 ステップの単純な流れで，少数ショット学習はどこまで良くなるか．

### 2.6 偏った正則化とオンライン学習の理論

#### Denevi, Ciliberto, Stamos, Pontil 2018（NeurIPS 2018．arXiv なし）Learning To Learn Around A Common Mean

- **問い**：内側の学習を「未知の共通の平均ベクトルへの 2 乗距離を罰則にしたリッジ回帰」に限ったとき，その平均を課題の流れから学ぶ問題はどう解けて，どれだけ得をするか．
- **方法**：
  ```
  内側：w_h(Z_n) = argmin_{w∈ℝᵈ} (1/n)‖X_n w − y_n‖² + λ‖w − h‖²                     （式 3）
        閉じた形 w_h(Z_n) = C_{λ,n}⁻¹ (X_nᵀy_n/n + λh) ，  C_{λ,n} = X_nᵀX_n/n + λI      （式 4）
  転移リスク E_n(h) は h について最小二乗の問題になる（命題 1）
  外側：課題のデータを r 個（内側の学習用）と n − r 個（誤差の推定用）に分け，h を SGD で更新（アルゴリズム 1）
  ```
- **分かったこと**：転移リスクは h について凸の 2 次関数になり，課題を 1 つずつ処理する SGD で h を学べる（2.3 節，3 節）．課題の係数の平均が w̄，分散が σ_w² の環境（例 1）では，最適な h は w̄ であり，ノイズが小さく，σ_w² が小さいときに独立学習（h = 0）より大きく得をする（注意 3）．命題 3 の上界は課題の数 T について 1/(T + 1) で減り，例 1 では分割の r = 0（全ての点を誤差の推定に使う）が最良だった（4 節）．人工データ（学習の課題 100，設定の選択に 50，試験に 200，d = 30，n = 20）と School データ（学習 75 課題）で，課題が増えると独立学習を速く上回った（5 節，図 2）．
- **前提と限界**：課題は線形回帰で，入力の分布に関する仮定を置く（仮定 1）．著者："A complete statistical analysis for more general environments remains an interesting open problem"（4 節）．課題が 2 つの群から成る例 2 では，最適な h が例の数 n によって変わる（2.4 節）．
- **MER-DA との接点**（推測，検定していない）：MER-DA の「ソースの分類器の平均を中心にした罰則」は式 3 の h を課題の係数の平均にした場合である．例 2（課題が群に分かれる環境）では最適な中心が例の数で変わるという結果は，MER-DA で K ごとに中心や罰則の強さが変わりうることと同じ形である．
- **確認**：◎（全文．付録は未読）．https://papers.nips.cc/paper_files/paper/2018/hash/b9a25e422ba96f7572089a00b838c3f8-Abstract.html

#### Denevi, Ciliberto, Grazzi, Pontil 2019（ICML 2019，PMLR 97:1566–1575．arXiv 1903.10399）Learning-to-Learn Stochastic Gradient Descent with Biased Regularization

- **問い**：偏った正則化つきの SGD を内側の学習にしたとき，良い中心 h を使う得はどれだけあり，h を課題の流れからどう推定するか．
- **方法**：
  ```
  内側：R_{Zn,h}(w) = (1/n) Σ_k ℓ_k(⟨x_k, w⟩) + (λ/2)‖w − h‖² を，w の初期値 h から 1 例ずつの SGD で最小化（アルゴリズム 1）
  課題のばらつき：Var²_h = (1/2) E_{μ~ρ} ‖w_μ − h‖² ，  m = E_{μ~ρ} w_μ（課題の係数の平均）
  系 3：ITL（h = 0）    E_n(w̄₀) − E_ρ ≤ Var₀ · 2RL √((2 log n + 1)/n)
        理想の中心     E_n(w̄_{hn}) − E_ρ ≤ Var_m · 2RL √((2 log n + 1)/n)
  定理 6（h を課題の流れから推定）：λ = (2RL/Var_m) √((log n + 1)/n) とすると
        E[E_n(w̄_{h̄T})] − E_ρ ≤ Var_m · 4RL √((log n + 1)/n) ＋ ‖m‖LR · (定数) · √(1/T) 型の項
        すなわち O(Var_m/√n) + O(1/√T)                                               （式 26）
  （R は入力の大きさの上限，L は損失のリプシッツ定数）
  ```
- **分かったこと**：理想の中心を使う得は，各課題の例の数 n が大きくなく，課題の係数の分散 Var²_m がその 2 乗平均 Var²_0 より十分小さいときに大きい（4 節）．罰則の強さは課題のばらつき Var_m と例の数 n に反比例させるのがよい（定理 2 の後の段落："the strength of the regularization ... is inversely proportional to both the variance of the bias h and the number of points"）．h の推定を入れても，最悪の場合は独立学習の上界に戻るので負の転移は起きないと著者は書いた（定理 6 の後）．
- **前提と限界**：損失は凸でリプシッツ連続，入力は有界（仮定 1・2）．著者の今後の課題："to derive fully dependent bounds, in which the hyperparameters are self-tuned during the learning process"（7 節）．
- **MER-DA との接点**（推測，検定していない）：定理 6 の λ の式は，「K が小さいほど，またソースどうしの分類器のばらつきが小さいほど，中心に強く寄せる」ことを理論上の最適とする．MER-DA が罰則の強さを K ごとに選ぶ設計と同じ向きである．課題が 3 つでは O(1/√T) の項が小さくならないので，平均の中心の推定誤差は理論の上では消えない．
- **確認**：◎（要旨，1・3・4・5 節の定理 6，6 節の実験の設定，7 節）．https://proceedings.mlr.press/v97/denevi19a.html ，https://arxiv.org/abs/1903.10399

#### Khodak, Balcan, Talwalkar 2019（NeurIPS 2019．arXiv 1906.02717）Adaptive Gradient-Based Meta-Learning Methods（ARUBA）

- **問い**：課題どうしの近さ（task-similarity）を前もって知らなくても，それに合わせて初期値と学習率を学ぶメタ学習を，理論の保証つきで作れるか．
- **方法**：
  ```
  ARUBA（Average Regret-Upper-Bound Analysis）：各課題の後悔の上界 U_t(x) を，設定 x（初期値 φ と学習率 η）の
  関数として順に学ぶ．平均の後悔 R̄_T ≤ Ū_T = (1/T) Σ_t U_t(x_t)
  定理 3.2：R̄_T ≤ Ū_T = Õ( min{ (1 + 1/V)/√T , 1/T^{1/4} } + V ) √m
            V² = min_φ (1/T) Σ_t B_R(θ_t* ‖ φ)        （課題の最適解 θ_t* の平均的なばらつき，m は課題ごとの例の数）
  実用版：座標ごとの学習率 η_j = √(b_j / g_j)．b は初期値から課題の解までの 2 乗距離の累積，g は 2 乗勾配の累積（6 節）
  ```
- **分かったこと**：V が T に依らず一定なら，平均の後悔は Õ(1/√T) の速さで O(V√m) に近づく（3 節）．V は「任意の 2 つの最適解の最大の距離」D* 以下で，外れた課題があるときは D* よりずっと小さくなりうる．Reptile に座標ごとの学習率を足すと，miniImageNet 5 方向 1 例で 49.97 ± 0.32% から 50.73 ± 0.32% になったが，Omniglot 20 方向 1 例では 89.43 ± 0.14% から 86.67 ± 0.17% に下がった（表 1）．
- **前提と限界**：損失は凸で，課題は順に届く（3 節）．非凸の深層網での実験は理論の外である．
- **MER-DA との接点**（推測，検定していない）：V（課題の最適解のばらつき）は，MER-DA ではソースごとの分類器が平均からどれだけ離れているかにあたる．課題が 3 つでは min{…} の項が大きく残る．座標ごとの罰則の強さを「各座標で課題の解がどれだけ初期値から動いたか」で決める実用版は，罰則を特徴の次元ごとに変える場合の先例になる．
- **確認**：◎（要旨，1〜3 節，5 節，6 節，表 1）．https://arxiv.org/abs/1906.02717 ，https://papers.nips.cc/paper_files/paper/2019/hash/f4aa0dd960521e045ae2f20621fb4ee9-Abstract.html

#### Konobeev, Kuzborskij, Szepesvári 2021（ICML 2021，PMLR 139:5697–5706．arXiv 2011.00344）A Distribution-Dependent Analysis of Meta-Learning

- **問い**：課題の分布が転移リスクにどう影響するかを，下界と上界が一致する形で言えるか．
- **方法**：
  ```
  課題 i の係数 θᵢ ~ N(α, Σ)，観測 Y = θᵢᵀx + ε，ε ~ N(0, σ²)（固定された入力の線形回帰）
  重みつきの偏った正則化（WBRLS）：
    θ̂ₙ = argmin_θ L̂ₙ(θ) + (λ/2) ‖θ − b‖²_Γ = (XₙᵀXₙ + λΓ)⁻¹ (XₙᵀYₙ + λΓb)
  b = α̂（α の推定），Γ = Σ⁻¹，λ = σ² のとき，事後平均による予測と一致する（3.2 節）
  系 4.3（入力が等方，Σ = τ²I）：n → ∞ でも
    (E[L(x)] − σ²)/σ² ≥ ( mₙ/d + σ²/τ² )⁻¹                                             （式 8）
  ```
- **分かったこと**：任意のアルゴリズムの転移リスクの下界を課題の分布に依存する形で出し，WBRLS（α の最尤推定を中心にしたもの）がその下界に定数倍で一致した（4 節）．系 4.3 の上界の 1 項目は課題が増えると消え，2 項目はターゲットの例の数 mₙ を増やさないと消えない．著者："for any τ² > 0, there is a limit on how much the data of previous tasks can help"（4 節）．Σ が低ランクの場合が表現学習（Du ほか 2021 の設定）にあたり，Σ が未知のときは EM 法（観測されない変数を含むモデルの最尤推定を，期待値の計算と最大化を繰り返して求める方法）で推定し，課題が増えると EM 法が下界に近づいた（5・6 節）．
- **前提と限界**：固定された入力，ガウスのノイズ，ガウスの課題の分布という強い仮定を置く（2 節）．著者の今後の課題："The most interesting narrower question is to theoretically analyze the EM algorithm"（7 節）．
- **MER-DA との接点**（推測，検定していない）：最適な罰則は「ノイズの分散 σ² を課題の母数の共分散 Σ で割った」重み λΓ = σ²Σ⁻¹ であり，等方なら罰則の強さはノイズの分散と課題のばらつき τ² の比 σ²/τ² になる．MER-DA の罰則は等方（全ての次元で同じ強さ）なので，この結果の Σ = τ²I の場合にあたる．ソースが 3 つでは，課題の係数の共分散 Σ（特徴の次元 × 特徴の次元）は，ソースの分類器 3 つから中心を引いた残り（たかだか 2 方向）しか推定できない（こちらの読み）．
- **確認**：◎（要旨，1〜4 節，6 節の一部，7 節）．https://proceedings.mlr.press/v139/konobeev21a.html ，https://arxiv.org/abs/2011.00344

#### Tripuraneni, Jordan, Jin 2020（NeurIPS 2020．arXiv 2006.11650）On the Theory of Transfer Learning: The Importance of Task Diversity

- 詳しくは `docs/related-work.md` 2.12 節と付録の読書メモ．
- **問い**：t 個の訓練の課題で共有の表現 h を学び，新しい課題を m 件で学ぶとき，要る標本の数は何で決まるか．
- **方法**：
  ```
  過剰リスク ≈ Õ( √((C(H) + t·C(F))/(nt)) / ν + √(C(F)/m) )
  （C は関数の集まりの複雑さ，ν は課題の多様性．線形なら課題のベクトルの行列の最小特異値に対応）
  ```
- **分かったこと**：表現の複雑さは全課題の合計 nt で払い，新しい課題では課題ごとの部分 C(F) だけを払えばよい．鍵は課題の多様性で，訓練の課題が表現の全方向を使っていないと，新しい課題が使う方向を学べない．
- **前提と限界**：全課題で入力の分布が共通であると仮定する（`docs/related-work.md` の記録）．
- **MER-DA との接点**（推測，検定していない）：コーパス間では入力の分布が違うので前提が崩れる．課題が 3 つでは，多様性で覆える方向は多くとも 3 つである（こちらの読み）．
- **確認**：◎（`docs/related-work.md` の記録．今回は書誌を確かめた）．https://arxiv.org/abs/2006.11650 ，https://papers.nips.cc/paper_files/paper/2020/hash/59587bffec1c7846f3e34230141556ae-Abstract.html

#### Du, Hu, Kakade, Lee, Lei 2021（ICLR 2021．arXiv 2002.09434）Few-Shot Learning via Learning the Representation, Provably

- 詳しくは `docs/related-work.md` 2.12 節と付録の読書メモ．
- **問い**：T 個のソースの課題（各 n₁ 件）で表現を学び，ターゲットの課題を n₂ 件で学ぶとき，どれだけ標本を減らせるか．
- **方法**：
  ```
  低次元の線形表現で 過剰リスク ≈ Õ( dk/(n₁T) + k/n₂ )（表現を使わなければ d/n₂）
  仮定 4.2（共分散の支配）：Σ_t ⪰ c·Σ_{T+1}（各ソースの入力の共分散がターゲットのそれを覆う）
  仮定 4.3（課題の多様性）：W* = [w₁*,…,w_T*] ∈ ℝ^{k×T} について σ_k²(W*) ≥ Ω(T/k)
  ```
- **分かったこと**：ソースの全 n₁T 件を表現の学習に合算できる．多クラスの問題では課題の代わりにクラスの多様性を使える（注意 4.1）．
- **前提と限界**：仮定 4.3 は W* の階数が k であることを含むので，課題の数 T は表現の次元 k 以上でなければならない（こちらの読み）．
- **MER-DA との接点**（推測，検定していない）：共分散の支配の定数 c は凍結した特徴の上で測れる量である．注意 4.1 により，4 感情 × 3 ソースのクラスの多様性を使う読み方はありうるが，検定していない．
- **確認**：◎（`docs/related-work.md` の記録．今回は 4 節の仮定 4.2・4.3 と注意 4.1 を読み直した）．https://arxiv.org/abs/2002.09434

### 2.7 課題が少ないとき

#### Yao, Zhang, Finn 2022（ICLR 2022．arXiv 2106.02695）Meta-Learning with Fewer Tasks through Task Interpolation（MLTI）

- **問い**：メタ学習の課題の数が少なく，課題の空間をまばらにしか覆わないとき，どう汎化を保つか．
- **方法**：
  ```
  2 つの課題 Tᵢ, Tⱼ を引き，ある層 l の隠れ表現とラベルを内挿して新しい課題を作る
    H̃ = λ Hᵢ + (1 − λ) Hⱼ ，  Ỹ = λ Yᵢ + (1 − λ) Yⱼ ，  λ ~ Beta(α, β)
  ラベルが課題の間で共通の場合（label-sharing）とそうでない場合で内挿の仕方を分ける
  理論：MLTI はデータに依存したメタ正則化にあたり，汎化の上界を改善する
  ```
- **分かったこと**：要旨："the bottleneck of current meta-learning algorithms is the requirement of a large number of meta-training tasks"．課題が少ないとメタ学習はメタ学習の課題を記憶してしまう（1 節）．ラベルが共通の設定で，化学のデータ NCI（学習に 6 つのデータ源，試験に 3 つ，5 例）では MAML 77.09 ± 0.85% が 79.14 ± 0.73%，原型ネットワーク 74.84 ± 0.87% が 76.90 ± 0.81% に上がった（表 1）．ラベルが共通でない miniImagenet-S の 1 例では MAML 38.27% が 41.58% に上がった（表 3）．
- **前提と限界**：内挿した課題が本当の課題の分布に近いことを前提にする．
- **MER-DA との接点**（推測，検定していない）：MER-DA は 4 感情のラベルが全コーパスで共通なので，label-sharing の設定にあたる．課題（コーパス）の数が少ないときの対処の先例である．
- **確認**：◎（要旨，1 節，4〜6 節の表 1〜3）．https://arxiv.org/abs/2106.02695

#### Li, Yang, Song, Hospedales 2018（AAAI 2018，32(1)．arXiv 1710.03463）Learning to Generalize: Meta-Learning for Domain Generalization（MLDG）

- **問い**：ソースのドメインの中で，学習とテストのドメインのずれを模擬して学べば，見たことのないドメインに汎化するモデルを作れるか．
- **方法**：
  ```
  各反復でソースのドメイン S を仮の学習側 S̄ と仮のテスト側 V に分ける
  F(Θ)：仮の学習側の損失，G(Θ)：仮のテスト側の損失
  argmin_Θ F(Θ) + β G(Θ − α F′(Θ))
  一次のテイラー展開：≈ argmin_Θ F(Θ) + β G(Θ) − βα ( G′(Θ) · F′(Θ) )
  （仮の学習側と仮のテスト側の勾配の内積を大きくする項が入る）
  ```
- **分かったこと**：PACS（4 つの画風のドメイン，7 クラス．3 つのドメインで学び 1 つで試す）の平均で，全ソースをまとめて学ぶ方法（Deep-All）67.24% に対し MLDG 70.01%（表 1・2．AlexNet）．α = 0（仮のテスト側の損失を足すだけ）では 67.93% で，得はメタ最適化から来ていた（表 2）．
- **前提と限界**：DomainBed（`docs/related-work.md` 2.6 節）は設定の選び方をそろえて比べ直し，PACS で学習ドメインの検証集合による選択では ERM 85.7 ± 0.5%，MLDG 84.8 ± 0.6%，leave-one-domain-out 交差検証による選択では ERM 83.3 ± 0.6%，MLDG 82.4 ± 0.7% だった（DomainBed の表 4．ResNet-50）．
- **MER-DA との接点**（推測，検定していない）：PACS は MER-DA と同じく「4 つのドメインのうち 3 つがソース」の構造である．MLDG はその構造でメタ学習の得を報告したが，DomainBed の比べ直しでは得が消えた．DomainBed では leave-one-domain-out 交差検証で選ぶと，学習ドメインの検証集合で選ぶより低かった（ERM の PACS で 83.3% 対 85.7%）．MER-DA の leave-one-source-out による設定の選択を論じるときに両方を引く必要がある．
- **確認**：◎（要旨，3 節，4 節の表 1〜3）．DomainBed の数値は arXiv 2007.01434 の表 4 で確かめた．https://arxiv.org/abs/1710.03463 ，https://doi.org/10.1609/aaai.v32i1.11596

#### Balaji, Sankaranarayanan, Chellappa 2018（NeurIPS 2018．arXiv なし）MetaReg: Towards Domain Generalization using Meta-Regularization

- **問い**：あるドメインで学んだモデルが別のドメインでよく働くような正則化項を，メタ学習で学べるか．
- **方法**：
  ```
  特徴の網 F は全ソースで学んだ後に固定し，分類の網 T の重み θ にかける正則化項を学ぶ
  R_φ(θ) = Σᵢ φᵢ |θᵢ|                         （重みつき L1．φᵢ が学ぶ係数）
  メタ更新：ソースのドメインの対 (a, b) を無作為に選び，
    β¹ = θ_a ，βⁱ = βⁱ⁻¹ − α₂ ∇[ L⁽ᵃ⁾(ψ, βⁱ⁻¹) + R_φ(βⁱ⁻¹) ]（l 回）， θ̂_a = βˡ
    φ ← φ − α₂ ∇_φ L⁽ᵇ⁾(ψ, θ̂_a)               （アルゴリズム 1）
  最後に φ を固定し，分類の網を全ソースで R_φ つきで学び直す
  ```
- **分かったこと**：PACS の平均で，基準線 69.28%（MLDG の論文の値は 67.24%）に対し MetaReg 72.62%，MLDG は 70.01%（表 1．AlexNet，5 回の平均）．
- **前提と限界**：著者は，MLDG の目的は速い適応のためのもので，ドメイン汎化では新しいドメインの例が無いので合わない可能性と，深い網に広げにくいことを MLDG の限界として挙げ，特徴の網を固定して分類の網だけでメタ学習することで後者に対処した（2 節）．
- **MER-DA との接点**（推測，検定していない）：特徴を固定して分類の層だけで「ソースの対の間の汎化」を基準に正則化を学ぶ点は，凍結した特徴の上の線形の分類器で罰則を選ぶ MER-DA に最も近い．違いは，MetaReg は罰則の中心が 0 の重みつき L1 であり，ターゲットのラベルを使わないことである．
- **確認**：◎（要旨，1〜4 節，表 1）．https://papers.nips.cc/paper_files/paper/2018/hash/647bba344396e7c8170902bcf2e15551-Abstract.html

#### Franceschi, Frasconi, Salzo, Grazzi, Pontil 2018（ICML 2018，PMLR 80:1568–1577．arXiv 1806.04910）Bilevel Programming for Hyperparameter Optimization and Meta-Learning

- **問い**：設定の最適化とメタ学習を，同じ二段の最適化として扱い，内側を有限回の反復で近似したときに元の問題の解に近づくことを保証できるか．
- **方法**：
  ```
  min { f(λ) : λ ∈ Λ } ，  f(λ) = inf{ E(w_λ, λ) : w_λ ∈ argmin_u L_λ(u) }           （式 1・2）
  E は外側の目的（検証誤差），L_λ は内側の目的（学習誤差＋正則化）
  例：L_λ(w) = 学習誤差 + λ‖w‖² ならリッジ回帰の罰則の強さを検証誤差で選ぶ問題
  メタ学習では外側の変数 λ を全課題に共通の表現の層（hyper-representation）にする
  内側を T 回の勾配降下で近似し，その反復を逆向きに微分して外側の勾配を得る
  ```
- **分かったこと**：内側の解が一意で，反復が一様に収束するなどの条件のもとで，近似問題の最小値と最小解は元の問題のものに収束する（定理 3.2）．Omniglot の特徴の上の線形の表現を外側の変数にした実験で，内側の反復の回数 T が小さいほうがテストの成績が良い場合があった．著者は，外側の変数の次元が内側の変数と同じ程度なので外側の目的（検証誤差）に過学習しうると書いた（5.1 節）．
- **前提と限界**：収束の保証は上の条件のもとでのものである．
- **MER-DA との接点**（推測，検定していない）：MER-DA の「仮のターゲットでの成績で罰則の強さなどを選ぶ」手続きは，式 1・2 の外側の目的を仮のターゲットの UAR，内側を罰則つきの学び直しにした場合にあたる．外側の変数が少ない（数個の設定）ほど，外側の目的への過学習は起きにくいと読める（こちらの読み）．
- **確認**：◎（要旨，1〜3 節，5.1 節）．https://proceedings.mlr.press/v80/franceschi18a.html

#### Ren, Zeng, Yang, Urtasun 2018（ICML 2018，PMLR 80:4334–4343．arXiv 1803.09050）Learning to Reweight Examples for Robust Deep Learning

- **問い**：学習データにクラスの偏りやラベルの誤りがあるとき，少数の正しいラベルの検証データを使って，例ごとの重みを学習中に決められるか．
- **方法**：
  ```
  θ_{t+1}(ε) = θ_t − α ∇ Σᵢ εᵢ fᵢ(θ_t)                          （例 i の重み εᵢ を摂動とみなす）
  u_{i,t} = −η ∂/∂ε_{i,t} [ (1/m) Σⱼ fⱼᵛ(θ_{t+1}(ε)) ] |_{ε=0}     （式 7．検証の損失を 1 歩先で微分）
  w̃_{i,t} = max(u_{i,t}, 0) ，  w_{i,t} = w̃_{i,t} / Σⱼ w̃_{j,t}       （式 8・9）
  u は学習の例と検証の例の入力の内積と勾配の内積の積の和になる（3.2 節の式 12）
  ```
- **分かったこと**：MNIST の 4 と 9 の 2 値分類でクラスの比を偏らせた実験では，釣り合った検証データ 10 枚で，偏りの比 200:1 でも誤り率の増加が 2% 程度にとどまった（4.1 節）．CIFAR のラベルの雑音の実験では正しいラベルの画像 1,000 枚を検証に使った（4.2 節）．
- **前提と限界**：著者は，学習データの偏りを一般に扱うには偏りの無い小さな検証データが要ると書いた（1 節）．
- **MER-DA との接点**（推測，検定していない）：「少数のラベル付きのターゲットの例で，ソースの例や疑似ラベルの例の重みを決める」形にそのまま対応する．MER-DA の K = 1〜25 は，この論文の検証データ 10 枚と同じ程度の大きさである．

#### Shu ほか 2019（NeurIPS 2019．arXiv 1902.07379）Meta-Weight-Net: Learning an Explicit Mapping For Sample Weighting（MW-Net）

- **問い**：例の損失から例の重みへの関数を手で決めずに，少数の偏りの無いデータ（メタデータ）から学べるか．
- **方法**：
  ```
  内側：w*(Θ) = argmin_w (1/N) Σᵢ V(Lᵢᵗʳᵃⁱⁿ(w); Θ) Lᵢᵗʳᵃⁱⁿ(w)          （V は隠れ層 1 つの MLP．損失を受けて重みを出す）
  外側：Θ* = argmin_Θ (1/M) Σᵢ Lᵢᵐᵉᵗᵃ(w*(Θ))                          （式 2．メタデータでの損失）
  二重の反復を，内側 1 歩の近似で交互に更新する
  ```
- **分かったこと**：CIFAR-10 で 40% のラベルを一様に誤らせたとき，正しいラベルの検証画像 1,000 枚を使い，MW-Net 89.27 ± 0.28%，Ren ほか 2018（L2RW）86.92 ± 0.19%，メタデータでの微調整 80.47 ± 0.25%，基準のモデル 68.07 ± 1.23%（表 2．WRN-28-10，5 回の平均）．クラスの偏りの実験では，学んだ重みは損失の大きい例に大きい重みをつけ，ラベルの誤りの実験では損失の大きい例に小さい重みをつけた（4 節）．
- **前提と限界**：偏りの無い少数のメタデータがあることを前提にする（要旨）．

- **確認**：◎（要旨，2 節，4 節の表 1・2）．https://arxiv.org/abs/1902.07379 ，https://papers.nips.cc/paper_files/paper/2019/hash/e58cc5ca94270acaceed13bc82dfedf7-Abstract.html

## 3. 分野で標準とされていることと，著者たちが未解決と書いていること

### 3.1 標準とされていること

1. **評価はエピソードの平均で行う．**N 方向 K 例のエピソードを 600 回（Snell 2017 の表 2，Chen 2019），または 1,000 回（Dhillon 2020）引き，平均と 95% 信頼区間を報告する．Dhillon 2020 は，平均の信頼区間ではなく正解率の標準偏差の報告を勧めた（4 節）．
2. **設定はメタ検証の課題で選ぶ．**MetaOptNet は "we keep an additional held-out meta-validation set to choose the hyperparameters of the meta-learner"（3 節），Tian 2020 は "Model selection is done on the validation set"（4.6 節），Meta-Dataset は ImageNet のメタ検証だけで選んだ（5 節）．ドメイン汎化では DomainBed が学習ドメインの検証・leave-one-domain-out・テストドメインの検証（オラクル）の 3 つを定義した（`docs/related-work.md` 1.8.3 節）．
3. **学習時の課題を本番の課題と同じ形にする．**Vinyals 2016 の "test and train conditions must match"．ただし Snell 2017 は，学習時の way を試験時より多くするほうが良いと報告した．
4. **特徴を固定して最終層だけを合わせる形が強い．**Chen 2019 の Baseline，Raghu 2020 の ANIL・NIL，Tian 2020，MetaReg（特徴の網を固定）．
5. **理論で扱いやすい内側の学習は偏った正則化である．**Konobeev 2021 の 1 節："This procedure implements the maxim 'learn on a new task, but stay close to what is already learned', which is the basis of many successful meta-learning algorithms, including the above, and MAML"．iMAML の内側，Grant 2018 の MAP 推定，Denevi 2018・2019，Khodak 2019 が同じ形を使う．

| Denevi 2019（理論） | 中心を学ぶ得は，課題の係数のばらつきが 2 乗平均より十分小さく，課題ごとの例が少ないときだけ大きい | 凸でリプシッツ連続な損失 | 系 3，定理 6 |

こちらの読み（検定していない）：食い違いの多くは，「メタ学習」で何を学ぶかの違いから来ている．Chen・Tian・Raghu・Guo が比べたのは，特徴の網そのものをエピソードで学ぶメタ学習と，普通の教師あり学習で作った特徴である．Hu 2022 が得を報告したのも，特徴の網のエピソード学習である．MER-DA は特徴を凍結しているので，ここで比べられているのは「数個の設定（罰則の強さ，疑似ラベルの重み）を仮のターゲットで選ぶこと」と「既定の設定のまま使うこと」または「K 本の中の交差検証で選ぶこと」である．この比較に最も近い原典の結果は，R2D2 の付録 C（罰則の強さ λ を学んでも成績はほとんど変わらず，出力の尺度 α を学ぶことが重要），DomainBed の表 4（leave-one-domain-out の交差検証による選択は学習ドメインの検証による選択より低い），Guo 2020 の未解決の記述，Hu 2022 の 3.3 節（ドメインごとに少数の課題で学習率を選ぶ）である．

### 3.3 食い違い (b)：課題の数が少ない（MER-DA ではソースが 3 つ）ときに何が言えるか

**理論の側**．どの上界も課題の数 T が大きくなる極限で意味を持つ形であり，T = 3 で意味のある数値を出す理論は見つからなかった．

| 論文 | 課題の数に関わる項 | T = 3 での読み（こちらの計算・読み） |
|---|---|---|
| Baxter 2000 | 課題の数 n ≥ max{(256/ε²) log(8C/δ), 64/ε²}（定理 2） | ε = 0.1 で n ≥ 6400 |
| Maurer ほか 2016 | √(8 ln(4/δ)/T)（定理 2） | δ = 0.05 で約 3.4．損失が 0〜1 なら意味のない上界 |
| Denevi 2019 | O(1/√T)（式 26） | 1/√3 ≈ 0.58 倍の項が残る |
| Balcan ほか 2019 | D log T/(D* T)（定理 2.1） | (D/D*) × 0.37 程度が残る |
| Khodak ほか 2019 | min{(1 + 1/V)/√T, 1/T^{1/4}}（定理 3.2） | 1/3^{1/4} ≈ 0.76 の項が残る |
| Du ほか 2021 | 課題の多様性 σ_k²(W*) ≥ Ω(T/k)（仮定 4.3） | 表現の次元 k は 3 以下でなければならない |
| Konobeev ほか 2021 | 1 項目は課題が増えると消え，2 項目は残る（系 4.3） | 課題が無限にあっても得には上限がある．著者："for any τ² > 0, there is a limit on how much the data of previous tasks can help" |

**実験の側**．課題が少ないとメタ過学習が起きるという報告と，3 つのソースのドメインで得が出たという報告が並んでいる．

- Hospedales 2021：メタ過学習は "relatively common, especially in the case where only a small number of source tasks are available"（2 節）．
- Yao 2022：課題が少ないとメタ学習は課題を記憶してしまう（1 節）．課題を内挿で増やすと，学習に 6 つのデータ源を使う NCI で MAML が 77.09% から 79.14% に上がった（表 1）．
- Triantafillou 2020：8 つのデータ集合で学ぶと，ImageNet だけで学んだときにあったメタ学習の小さな得がしばしば消えた（5 節）．
- MLDG 2018・MetaReg 2018：PACS（3 つのソースのドメイン）で全ソースをまとめた学習より 2.8〜3.3 点上がった（各表 1）．DomainBed は設定の選び方をそろえると MLDG の得が消えることを示した（PACS で 85.7% 対 84.8%）．
- Denevi 2018 の実験は学習の課題 100 個（School は 75 個）で行われ，課題が少ない側の挙動は図 2 の曲線の左端でしか見えない．
- Franceschi 2018：外側の変数の次元が内側の変数と同じ程度だと，外側の目的（検証誤差）に過学習しうる（5.1 節）．

こちらの読み（検定していない）：MER-DA で leave-one-source-out により選ぶのは数個の設定なので，外側の変数は少ない．Franceschi 2018 の指摘（外側の変数が多いと外側の目的に過学習する）は当てはまりにくい．一方で，仮の課題が 3 つしか無いので，「ソースどうしのずれ」と「ソースとターゲットのずれ」が同じ型でないと，選んだ設定が本当のターゲットに合わない（Vinyals 2016 の犬の結果，Hospedales 2021 の第 2 の未解決の問題）．理論の上界はこの状況について何も保証しない．

### 3.5 MER-DA の設計の各部分と，対応する原典（こちらの読み．検定していない）

| MER-DA の設計 | 対応する原典の形 | 原典が言っていること |
|---|---|---|
| ソースの分類器の平均を中心にした L2 罰則で学び直す | Denevi 2018 の式 3，Denevi 2019，iMAML の式 3，Grant 2018 の式 5・6，Konobeev 2021 の WBRLS（Γ = I の場合） | 中心を課題の係数の平均にするのが最適の場合がある（Denevi 2018 の例 1）．罰則はガウスの事前分布の MAP 推定と同じ（Grant 2018） |
| 中心を学ばず，ソースの分類器の平均に固定する | Konobeev 2021 の 1 節（"α̂ could be obtained, for example, by averaging parameters estimated on previous tasks"） | 課題が少ないと平均の推定誤差の項 O(1/√T) が残る（Denevi 2019） |
| 罰則の強さを K ごとに選ぶ | Denevi 2019 定理 6 の λ = (2RL/Var_m)√((log n + 1)/n)，Konobeev 2021 の λΓ = σ²Σ⁻¹ | 最適な強さは例の数と課題のばらつきで変わる |
| ソースの 1 つを仮のターゲットにして設定を選ぶ | DomainBed の leave-one-domain-out，MLDG・MetaReg のドメインの分割，Vinyals 2016 の「学習と試験の条件をそろえる」 | DomainBed では leave-one-domain-out による選択が学習ドメインの検証による選択より低かった |
| 凍結した特徴の上の線形の分類器 | Chen 2019 の Baseline，Raghu 2020 の ANIL，Tian 2020，MetaReg（特徴の網を固定） | ドメインがずれるときは強い基準線．Hu 2022 は大規模な事前学習の上でも線形の読み出しだけでは強くないと報告 |
| ラベル無しのターゲットの発話の重み | Dhillon 2020 の式 8（エントロピーの項），Ren 2018，Shu 2019 | 例の重みは少数の正しいラベルのデータの勾配で決められる（Ren 2018） |
