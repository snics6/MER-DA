## 0. 検査した案（本体の文の要約）

DAI-15 は，疑似ラベルのモデルの 4×4 の取り違えの表を，ターゲットの K 本（K = 5 なら 20 本）だけで交差に推し，GLC の前向き補正に使った．案は，LOCO の残りの 3 コーパスを仮のターゲットにしたときの全ラベルの表を事前の表とし，ターゲットの K 本の数えと合わせて推す（例：事前の表を擬似的な数として足すディリクレの事後平均．足す強さは仮のターゲットの回で選ぶ）．補正の式は DAI-15 と同じ前向き補正である．

## 1. 新規性

### 1.1 結論

案の部品はすべて先行研究にある．組み合わせ（ほかのドメインのラベル付きデータで測った疑似ラベルの誤り方を，ターゲットの少数の正解と合わせて推し，前向き補正に使う）をそのまま行った論文は，今回の検索では見つからなかった．ただし「部品の組み合わせが見つからない」ことは手法の新しさの根拠にならない．論文の枠（解析論文の最後の「分析を受けた改善の試み」）では，手法の新しさは書かず，既知の部品の名前を挙げて書くことになる．

### 1.3 書けること・書けないこと

- 書けないこと：「疑似ラベルの誤り方をほかのコーパスで測っておく新しい補正」「普通の蒸留と違う新しい手法」．MetaCorrection（ソースで疑似ラベルの遷移行列を推す），CommunityBCC と Li ほか（似た対象の表を事前として移す），Ji ほか（混同行列のディリクレの事後）の組み合わせで説明できる．
- 書けること：「疑似ラベルの誤り方がコーパスをまたいで移るかを，LOCO の仮のターゲットの表で測った」という解析の結果．これは BBSE 型の仮定（p(疑似|本当) の不変）を，マルチモーダルの疑似ラベルのモデルとコーパスの組で確かめた記述になる．2.2 節のとおり，この測定は UAR の実験を流さなくても，保存済みの仮のターゲットの表から書ける．
- 普通の蒸留との違いとして本体が挙げた「教師の誤り方をほかのコーパスで測っておき，少数のラベルで調整してから差し引く」は，MetaCorrection と CommunityBCC を挙げれば先行研究の範囲の中にある．

## 2. 研究価値

### 2.1 当たる見込みの上限：全ラベルの表でも声はほぼ上がらない

案の推す表は，ターゲットの K 本とほかのコーパスの表を混ぜたものである．どの推し方をしても，ターゲット自身の候補の全ラベルで数えた表（DAI-15 の oracle）より真の表に近くはならない．oracle は設計で「参照．上限ではない」とされている（推定の揺れを抑える縮小が oracle を超える可能性は理屈の上では残る）．それでも，案が狙える得の目安は oracle の行で読める．DAI-15 の結果の文 4 節の K = 5 の値は次のとおりである．

| 生徒 | 量 | AFEW | IEMOCAP | MELD | MOSEI |
|---|---|---|---|---|---|
| 声 | oracle − I | −0.1 [−1.1, 1.0] | +0.8 [−2.1, 3.6] | −0.5 [−1.3, 0.3] | +1.0 [0.2, 1.8] |
| 声 | oracle_adj − I_adj | −0.0 | −0.8 | −0.5 | +0.8 [0.1, 1.6] |
| 融合 | oracle − I | +1.6 [0.4, 2.9] | +1.2 [−1.0, 3.4] | +0.0 | +2.4 [1.8, 3.0] |
| 融合 | oracle_adj − I_adj | +1.2 [0.1, 2.4] | −0.6 | −0.2 | +1.5 [0.9, 2.0] |

- 主の生徒である声の分類器では，真の表に最も近い表を使っても，上回ったのは MOSEI だけで，その幅は +0.8〜+1.0 点だった．DAI-15 の H1 と同じ規則（4 コーパスのうち 3 以上）は，oracle でも満たさない．
- 融合では AFEW と MOSEI で oracle が上回る．言葉では AFEW・MELD・MOSEI で oracle − I が +1.8〜+3.6 点上回る（結果の文 4 節）．案が狙える余地はこれらのセルに限られる．

### 2.2 測った：ほかのコーパスの表は，ターゲットの表から K 本の推定と同じくらい離れている

仮のターゲットの回の表で，案の前提（取り違えの表がコーパスをまたいで似ている）を確かめた．台本は付録．単位は表の成分（確率）である．

**(a) 表はコーパスで決まり，ソースの組み合わせではほとんど変わらない．**同じコーパス c を，評価のターゲット T を変えて（つまり疑似ラベルのモデルのソースの組を変えて）仮のターゲットにしたとき，全ラベルの表の成分の差の絶対値の平均は K = 5 で 0.017（12 組），K = 25 で 0.012 だった．同じ T の中で別のコーパスどうしを比べると 0.101（12 組），K = 25 で 0.112 だった．コーパスが替わると表は約 6〜9 倍大きく変わる．

**(b) 全ラベルの表の対角（K = 5．単位の平均．N, H, S, A の順．T を替えた 3 通りの範囲）**

| 仮のターゲットのコーパス | 対角 |
|---|---|
| AFEW | 0.52〜0.60, 0.66〜0.72, 0.59〜0.63, 0.73 |
| IEMOCAP | 0.47〜0.49, 0.69〜0.72, 0.72〜0.74, 0.77〜0.79 |
| MELD | 0.30〜0.35, 0.46〜0.49, 0.45〜0.48, 0.51〜0.55 |
| MOSEI | 0.31〜0.32, 0.43〜0.46, 0.42〜0.45, 0.30〜0.34 |

Angry の対角は IEMOCAP で 0.77〜0.79，MOSEI で 0.30〜0.34 で，差は約 0.45 ある．

**(c) 評価のターゲットに使う事前の表（その T の仮のターゲット 3 つの全ラベルの表の平均．K = 5）と，評価の回のターゲット自身の全ラベルの表の対角（DAI-15 の結果の文 5 節）**

| T | 事前の表の対角 | ターゲット自身の全ラベルの表の対角 | 対角の差の最大 |
|---|---|---|---|
| AFEW | 0.38, 0.54, 0.55, 0.54 | 0.57, 0.68, 0.63, 0.75 | 0.21（Angry） |
| IEMOCAP | 0.38, 0.52, 0.49, 0.53 | 0.47, 0.70, 0.73, 0.78 | 0.25（Angry） |
| MELD | 0.47, 0.63, 0.59, 0.60 | 0.34, 0.48, 0.48, 0.55 | 0.15（Happy） |

事前の表は，AFEW と IEMOCAP では対角を低く，MELD と MOSEI では対角を高く見積もる．向きがコーパスで逆になるので，足す強さを 1 つ選んでも 4 コーパスで同時に良くはならない．MOSEI は oracle で声が上がった唯一のコーパスで，事前の表が最も外れるコーパスでもある．MOSEI では事前の表が補正を弱める向き（単位行列に近い向き）に働くので，案は I に近づき，oracle の +0.8 点からは遠ざかる見込みである．

**(d) 仮のターゲットの回の中での事後平均の誤差（K = 5．案の選ぶ段を真似た計算）**

仮のターゲットの単位 (T, c, 分割, 種) ごとに，同じ T のほかの 2 つの仮のターゲットの全ラベルの表の平均を事前 P とし，事後 (K·Ĉ + α·P)/(K + α) を作った．Ĉ は DAI-15 の交差の表である．c 自身の全ラベルの表との差を行ごとの絶対値の和で測り，行と単位で平均した．比べる相手は DAI-15 で既に評価の回まで流した縮小（λ0.5，sym）である．

| 推し方 | 誤差（120 単位の平均） | 最小の特異値の平均 | 対角が非対角の最大を下回る行（単位あたり） |
|---|---|---|---|
| 交差の表 Ĉ（DAI-15 の λ0） | 0.342 | 0.17 | 0.73 |
| λ0.5（DAI-15） | 0.223 | 0.26 | 0.17 |
| sym（DAI-15） | 0.222 | 0.38 | 0.03 |
| 事後平均 α = 2 | 0.270 | 0.19 | 0.26 |
| 事後平均 α = 5（α を 0〜50 で振って誤差が最小） | 0.255 | 0.21 | 0.04 |
| 事前の表だけ（α → ∞） | 0.357 | 0.24 | 0.00 |
| K 本の上でそのまま（naive） | 0.615 | 0.70 | 0.00 |

- 事前の表だけの誤差（0.357）は，20 本の K 本で交差に推した表の誤差（0.342）とほぼ同じだった．ほかの 2 コーパスの表は，ターゲットの 20 本と同じくらいの情報しか持たない．
- 事後平均の誤差は最良の α でも 0.255 で，DAI-15 の λ0.5（0.223）と sym（0.222）より大きい．仮のターゲットのコーパスごとに見ても，事後平均（α = 5）は AFEW 0.257，IEMOCAP 0.246，MELD 0.229，MOSEI 0.288 で，4 つすべてで λ0.5（0.220，0.218，0.219，0.234）より大きかった．
- K = 25 では事後平均（α = 5）0.144，λ0.5 0.134，交差の表 0.151 で，ほかのコーパスの表を足す得はさらに小さい．
- 評価の回では事前を 3 コーパスから作るので（仮のターゲットの回では 2 つ），この計算は案をやや不利に見積もる．ただし (c) の表のとおり，3 つの平均でもターゲットとの差は対角で 0.15〜0.38 ある．

**この誤差は UAR ではない．**DAI-15 では，表の誤差が小さい λ0.5 と sym も，声では補正しない版を上回らなかった（λ0.5 − I：MELD −1.6，MOSEI −1.6．sym − I：MELD −0.8，MOSEI −1.1．結果の文 4 節）．表の誤差と UAR は単調な関係ではない．それでも，案の推す表は，既に評価の回で上がらなかった縮小より真の表から遠いので，案が λ0.5 と sym を超える根拠は見当たらない．

### 2.3 外れる理由（記録と先行研究から）

1. **ラベルの決め方がコーパスで違う．**IEMOCAP の Happy は excited と happy を合わせたもの，MOSEI の Neutral は感情の強さが全部 0 の発話を消去法で選んだもの（Mao ほか 2021．DAI-15 の設計 7 節の限界）．MOSEI の 4 クラスは強さの最大で決めるので，疑似ラベルのモデルの判断と人のラベルの食い違いの形が，演技の IEMOCAP や映画の AFEW と違う．2.2 (b) の Angry の対角の差 0.45 は，この違いと矛盾しない（原因の切り分けはしていない）．
2. **特徴の分布もコーパスで違う．**BBSE の仮定（p(x|y) の不変）が成り立てば p(疑似|本当) は移るが，LOCO のコーパスの間では成り立たない．2.2 (a) で，疑似ラベルのモデルのソースを替えても表はほとんど変わらず（0.017），コーパスを替えると大きく変わった（0.10）．表は「モデルの性質」より「コーパスの性質」で決まっている．
3. **過去の記録：仮のターゲットで選んだ値は移りにくい．**`過去の試み.md` 208 行に「仮のターゲットで選んだ指数は移らない」とある．案の α も仮のターゲットの回で選ぶので，同じ弱さを持つ．さらに 2.2 (c) のとおり事前の外れの向きがコーパスで逆なので，1 つの α は少なくとも 2 つのコーパスで逆向きに働く．
4. **DAI-15 で表の推定以外の詰まりが見えている．**声では oracle でも 4 のうち 1 しか上がらず，λ0 の損の多くは π′ の発散（表の特異さ）と予測の割合の変化から来ていた（結果の文 5 節の A8，6 節）．事後平均は特異さを和らげる（最小の特異値 0.17 → 0.21）が，それは sym（0.38）と λ0.5（0.26）が既に行った方向で，評価の回で声は上がらなかった．

### 2.4 当たる見込みと上限のまとめ

- 声：上がりうるのは MOSEI だけで，目安の上限は oracle の +0.8〜+1.0 点．MOSEI は事前の表が最も外れるコーパスなので，案の値は I（差 0）と oracle の間で I に近い側に来る見込みである．DAI-15 の H1 と同じ規則（4 のうち 3）が当たる見込みは無い．
- 融合と言葉：oracle が上がるセル（融合の AFEW・MOSEI，言葉の AFEW・MELD・MOSEI）では余地がある．しかし事前の表の誤差は λ0.5 と sym より大きく，それらの版がこれらのセルで上回ったのは，融合の AFEW の λ0.5 − I（+1.3．割合をそろえた版は判定できない），言葉の MELD・MOSEI の sym − I と MOSEI の λ0.5_adj − I_adj（+0.4〜+1.3）だけだった（結果の文 4 節）．案がこれを超える根拠は無い．
- 検出できる差の目安（DAI-15 の設計 4 節）は声で 0.2〜2.2 点，融合で 0.4〜2.5 点で，上の上限に対して余裕が無い．

### 2.5 判定の理由と，代わりに書けること

判定を NG とした理由は次の 4 点である．

1. 主の生徒（声）の目安の上限が 1 コーパスの +0.8〜+1.0 点で，案はそのコーパスで最も不利である（2.1，2.2 (c)）．
2. 案の推す表は，DAI-15 で評価の回まで流して上がらなかった縮小（λ0.5，sym）より真の表から遠い（2.2 (d)）．
3. 手法は既知の部品の組み合わせで，論文の枠でも新しさとしては書けない（1 節）．
4. DAI-15 の設計は関門を 6 版回した．同じ規模の関門と計算（評価の回 約 85 分）に見合う得が見込めない．

代わりに，次の記述は UAR の実験を流さずに，保存済みの仮のターゲットの表から書ける．「疑似ラベルのモデルの取り違えの表は，ソースの組を替えてもほとんど変わらず（成分の差の平均 0.017），コーパスを替えると大きく変わる（0.10）．ほかの 2 コーパスの表の平均は，ターゲットの 20 本で推した表と同じくらいターゲットの表から離れている（誤差 0.357 と 0.342）．したがって，教師の誤り方をほかのコーパスで測って移す補正（MetaCorrection 型，BBSE 型の仮定）は，この 4 コーパスでは前提を満たさない．」これは DAI-15 の「K 本の表は単位の平均では全ラベルの表に近いが単位ごとの揺れが大きい」と並べて，「表の推定は，ターゲットの少数のラベルからもほかのコーパスからも足りない」という解析の結論になる．書く前に，この集計を台本として `DAI/exp` に置き，gate-claim に照合させる必要がある（この検査の集計は付録の台本で，関門を通していない）．

## 3. それでも実験するときに必ず守る点

研究者が流すと決めた場合に，設計で外せない点を挙げる．

1. **漏れ（入れ子の LOCO）**：評価の回の事前は，T のソース 3 つの表だけから作る（T のラベルは入らない）．選ぶ段では，仮のターゲット c の事前を同じ T のほかの 2 つの仮のターゲット c′ の表から作ることになる．c′ の疑似ラベルのモデルは c をソースに含み，c のソースの識別器は c の全発話（c の仮のターゲットの回のテストを含む）で学んでいる（`DAI/docs/実験1_設計.md` 52 行）．c のラベルが，c の識別器 → c′ の疑似ラベルのモデル → c′ の表 → c の事前，の経路で選ぶ段に入る．弱い経路だが新しい経路なので，gate-leak に判定させ，`docs/seen-data.md` に書く．あわせて，この検査が仮のターゲットの表を見たこと（冒頭）を台帳に書く．
2. **比べる相手**：(a) 同じディリクレの形で事前を「ほかのコーパスの表」ではなく対称の表 S(Ĉ) か一様な対角の表にした版を，同じ α の格子で選ぶ．これが無いと，得が「ほかのコーパスの情報」によるのか「縮小」によるのかを分けられない．(b) DAI-15 の λ0.5 と sym（同じ単位で解き直す）．(c) 事前の表だけ（α → ∞）．(d) I，提案，oracle．主の差は「事後平均 − 縮小の対照（(a)）」と「事後平均 − I」，それぞれの割合をそろえた版である．
3. **選び方**：α は仮のターゲットの回だけで選び，固定のファイルをコミットしてから評価の回を 1 回流す（DAI の取り決め）．仮のターゲットでは事前が 2 コーパス，評価では 3 コーパスから作られる違いを設計に書く．α の格子に 0（DAI-15 の λ0 と同じ）と ∞（事前だけ）を入れ，選ばれた α が格子の端かを報告する．
4. **予言を計算の前に置く**：2.2 (d) の結果から，「事後平均は λ0.5 と sym を超えない」が既定の予想になる．得を主張する規則（上回るコーパスの数）は DAI-15 の H1 と同じ厳しさで計算の前に固定し，2.2 (c) の事前の外れの向き（AFEW・IEMOCAP は対角を低く，MELD・MOSEI は高く見積もる）をコーパスごとの予言に書く．
5. **確認ではない**ことを書く：案は DAI-15 の評価の回の結果（oracle の行と，K 本の表の揺れ）を見た後に出た．

## 付録：2.2 節の集計の台本（仮のターゲットの表だけを読む）

`.venv/bin/python` で流した．入力は `results/dai15/pseudo/units/*.npz`（ファイル名は `<T>_<c>_f<分割>_r<種>`）．出力は画面だけで，ファイルは書いていない．

```python
import numpy as np, glob, os, itertools
D='/home/snics/MER-DA/results/dai15/pseudo/units'
Cs=['AFEW','IEMOCAP','MELD','MOSEI']
tabs={}
for f in sorted(glob.glob(D+'/*.npz')):
    T,c,fo,r=os.path.basename(f)[:-4].split('_')
    z=np.load(f); tabs[(T,c,int(fo[1:]),int(r[1:]))]={k:z[k] for k in z.files if k.startswith('C_')}
def S(C):
    d=np.mean(np.diag(C)); M=np.full((4,4),(1-d)/3); np.fill_diagonal(M,d); return M
def bad(C): return sum(C[i,i]<max(C[i,j] for j in range(4) if j!=i) for i in range(4))
for K in (5,25):
    M={}
    for (T,c,f,r),v in tabs.items(): M.setdefault((T,c),[]).append(v[f'C_oracle_K{K}'])
    M={k:np.mean(v,0) for k,v in M.items()}          # (T,c) ごとの全ラベルの表の単位の平均
    same=[np.abs(M[(a,c)]-M[(b,c)]).mean() for c in Cs for a,b in itertools.combinations(Cs,2) if (a,c) in M and (b,c) in M]
    diff=[np.abs(M[(T,a)]-M[(T,b)]).mean() for T in Cs for a,b in itertools.combinations(Cs,2) if (T,a) in M and (T,b) in M]
    print(K,'same corpus',np.mean(same),'diff corpora',np.mean(diff))
    for T in Cs:                                         # 評価のターゲット T の事前の表
        P=np.mean([M[(T,c)] for c in Cs if (T,c) in M],0); print(T,np.diag(P))
    for c in Cs+['ALL']:                                 # 仮のターゲットの中での推し方の誤差
        res={}
        for k,v in tabs.items():
            if c!='ALL' and k[1]!=c: continue
            Cc=v[f'C_cf_K{K}']; O=v[f'C_oracle_K{K}']
            P=np.mean([M[(k[0],cc)] for cc in Cs if (k[0],cc) in M and cc!=k[1]],0)
            ests={'cf':Cc,'lam05':0.5*Cc+0.5*S(Cc),'sym':S(Cc),'dir5':(K*Cc+5*P)/(K+5),
                  'dir2':(K*Cc+2*P)/(K+2),'prior':P,'naive':v[f'C_naive_K{K}']}
            for n,E in ests.items():
                res.setdefault(n,[]).append((np.abs(E-O).sum(1).mean(),np.linalg.svd(E,compute_uv=False)[-1],bad(E)))
        print(K,c,{n:np.round(np.mean(x,0),3) for n,x in res.items()})
```

α の格子（0，1，2，5，10，20，50，∞）での全体の誤差は，K = 5 で 0.342，0.294，0.270，0.255，0.269，0.298，0.328，0.357，K = 25 で 0.151，0.146，0.144，0.144，0.159，0.199，0.272，0.395 だった．
